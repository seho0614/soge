# 661. 일본어 · 중국어(간체) (v10.523 · 2026-11-20)

## 1. 결론
사용자 웹 · 서버 문장에 **일본어(ja) · 중국어 간체(zh)** 사전 틀을 더했습니다. 사전은 **기계 번역 초안**(검수 전)이고, **빠진 문장은 영어 → 한국어** 순으로 나갑니다. 언어 단추는 지금 규칙 그대로 **다국어(i18n.enabled) on + 그 언어 켜짐**일 때만 보이며, ja · zh 는 **검수 기록(사용자 웹 사전 · 서버 문장)이 둘 다 「승인」이어야 켤 수 있습니다**(DB 트리거 — 번역 검수 전 공개 안 함). 위치: **관 관리 › 일본어 · 중국어 검수** · SB-ADM-OAPI-030.

## 2. 사전
| 자리 | 파일 | 지금 |
|---|---|---|
| 사용자 웹 바탕 | `site/src/i18n/messages/ja.json` · `zh.json` | 머리줄 · 바닥줄 · 로그인 · 오류 화면 등 86문장(바탕 456 중 — 처음 354 · 다른 묶음이 더해 456) · 맨 위 `_draft` = 기계 번역 초안 표시(화면으로 내려가지 않음) · 묶음(ko/*.json)은 아직 없음 |
| 사용자 웹 묶기 | `messages/index.ts` | ja · zh 는 영어 사전을 바탕으로 덮음(`LANG_FALLBACK` · `site/src/i18n/drafts.ts`) |
| 서버 문장 | `src/common/i18n/server-text.ja.ts` · `zh.ts` | 자주 나오는 글 · 파트너 API 글 27문장 · `*_META.state = MACHINE_DRAFT` · 없으면 영어 사전 |
| DB 문구 | 기존 content_translations | 기존 「번역」 탭 그대로(AI 기계 번역 지시문에 zh 「Simplified Chinese」 더함) |

- 값은 **글자만**(배열 · 객체 값 없음) · 자리표시 · `<b>` 짝은 한국어와 같음 · 복수형은 일본어 · 중국어 규칙대로 `other` 하나.
- 일본어 · 중국어 사전은 **영어 사전 시험(test_v1095 · 1097 · 1113 · 1116 · 1125 …)이 보는 파일을 고치지 않음** — ko.json · en.json · en/*.json 그대로.

## 3. 켜는 순서
1. 번역 검수자가 ja.json · zh.json · server-text.ja.ts · zh.ts 를 고침(판을 올림 · drafts.ts · lang-drafts.ts 의 state 를 REVIEWED).
2. 운영 화면 › 관 관리 › 일본어 · 중국어 검수 — SITE · SERVER 「승인」 기록(SUPER · 쌓기만).
3. 같은 화면(또는 「번역」 탭)에서 그 언어 켜기 — 승인 전이면 422 `I18N_REVIEW`.
4. 다국어 전체(i18n.enabled)가 켜져 있으면 언어 단추에 나옴.
