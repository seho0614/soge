# 578. 업무별 권한 표 · 처음 변환 (v10.441 · 2026-11-20)

> 대표 11/19 22:10 「업무 권한 업무별로 관리 · 권한그룹 · 개인권한(업무용 · 관리자) · 권한 관리는 super」 → 계획 승인(「승인 + 통과하면 병합」 · 수준 4단계).

## 1. 결론
- 업무 = 운영 화면 탭 하나(113개) · 업무그룹 = 메뉴 그룹(22개) · 권한그룹 = 업무 × 수준(보기 VIEW · 고치기 EDIT · 승인 APPROVE · 내려받기 EXPORT) · 개인권한 = 권한그룹 여러 개 + 개별 더하기/빼기 + 기한.
- **처음 변환:** 기존 역할마다 같은 범위의 권한그룹 R_역할(운영 관리자 · 지급 담당 · 검수 담당 · 안심 파트너 담당 · 제휴 파트너 담당 · 세무사)을 만들어 그 역할을 가진 사람에게 붙임 — 적용 날 보는 범위가 지금과 같음.
- 앞으로 역할을 받으면 같은 R_역할 그룹이 저절로 붙음(`perm.auto_role_group` on · 붙이기가 막혀도 역할 주기는 그대로).
- 구분: 업무용(STAFF) · 관리자(MANAGER · ADMIN 역할이면 관리자). 관리자 권한그룹은 관리자 구분에게만(DB 가 막음 PERM_KIND).
