## 1. 결론

| 항목 | 내용 |
|---|---|
| 하는 일 | 로그인 회원이 AI 상담에서 「주문 1234 반품하고 싶어요」 · 「정산 문의 남기고 싶어요」라고 하면 AI 가 **신청서 초안**을 만들어 대화창에 카드로 보여 줌 → 「신청서 열기」 → **지금 쓰는 신청 화면이 초안으로 채워져 열림** → **회원이 그 화면에서 직접 제출** |
| AI 가 못 하는 것 | 접수 · 취소 · 판정 — 초안 서비스에 접수하는 길이 없음(시험이 코드에서 확인 · AI 대화만으로 접수 0건 확인) |
| 켜는 곳 | 운영 화면 › AI 에이전트 › 「AI 스위치」 › **「AI 상담 — 신청서 초안」**(SUPER · 켜기 전 확인 문장) · **꺼짐** · 「AI 상담 — 내 정보 조회」가 켜져 있어야 동작 |
| 알림톡 | 쓰지 않음 — 결정 기록 ai-agent #2 의 「알림톡 연동 뒤」를 대표 결정으로 고침(#25) |

## 2. 흐름 · 안전장치

| 항목 | 내용 |
|---|---|
| 도구 | `draft_inquiry`(유형 DEAL · SETTLE · ACCOUNT · ETC — **분쟁은 없음** · 제목 60자 · 내용 2,000자) · `draft_return`(주문 끝 4자리 · CANCEL · RETURN · EXCHANGE · 사유 6개 · 상세 500자). 회원 번호 칸 없음 |
| 반품 초안의 주문 | 서버가 **본인 진행 중 주문에서 끝 4자리로** 찾음 — 없거나 둘 이상이면 초안을 만들지 않고 AI 에게 「다시 물어보라」. **전체 주문번호는 AI 에게 보내지 않음**(카드 주소에만 · 회원 브라우저로) |
| 횟수 | 한 질문에 초안 1개 · 도구 왕복 2번(3단계와 함께) · 하루 횟수는 질문 1번 |
| 저장 | `agent_drafts` — 상담 · 질문 · 답과 **한 거래**로 · 글은 상담 가림(연락처 · 계좌 · 주민번호)을 거침 · 조회 기록(`agent_tool_calls`)에도 도구 이름 · 칸 이름만 |
| 신청 화면 | `/support/new?draft=…` · `/my/health/returns/new?o=…&draft=…` — 본인 초안 · 7일 안 · 제출 전만 채움(남의 것 · 만료면 빈 화면) · 맨 위 「AI 초안으로 채웠습니다 — 아직 접수되지 않았습니다」 · 반품은 같은 주문일 때만 · **제출 단추 · 법정 안내 · 판정은 지금 그대로** |
| 제출 기록 | 신청 API 의 선택 칸 `agentDraftId` — 본인 · 같은 종류 초안이면 「제출됨」과 접수 번호만 적음(틀려도 접수는 그대로 · 오류 없음) |
| 7일 뒤 | 배치 `agent_chat_purge`(매일)가 초안 **내용을 비움** — 숫자(만듦 · 엶 · 제출)는 대화와 함께 5년 뒤 지움. 설계 docs/208 3-2 의 「7일 뒤 지움」을 「내용만 비움」으로 바꿈(30일 숫자를 보려고) |
| 운영 화면 | 상담 기록의 「조회」 줄에 `draft_inquiry · 1건` 처럼 · 「답 · 넘김 비율」에 초안 · 회원이 엶 · 화면에서 제출 수 |
| 지시문 | 초안은 접수 아님 · 「접수됐다」고 말하지 않음 · 분쟁 · 신고는 초안 없이 넘김 · 반품은 먼저 my_orders 로 주문 확인 |

## 3. 처리방침

AI 에게 새로 보내는 정보가 없습니다(회원이 쓴 글 — 2단계 · 주문 끝 4자리 — 3단계 ④ 줄). 그래서 약관 · 처리방침은 바꾸지 않았습니다. **「AI 가 신청서 초안을 만든다」를 고지에 넣을지는 법무 확인이 필요합니다.**

## 4. 켜기 전 (대표 · 법무)
1. 3단계 「내 정보 조회」를 켜고 며칠 — 상담 기록의 「조회」 줄 확인(docs/204 2-4)
2. 법무 — 초안 고지 여부
3. 「AI 스위치」 › 「AI 상담 — 신청서 초안」 켜기 → 「답 · 넘김 비율」의 초안 · 제출 수 · 상담 기록 며칠 확인
