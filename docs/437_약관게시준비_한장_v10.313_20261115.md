## 1. 바뀐 것 (정확한 위치)

| 곳 | 내용 |
|---|---|
| 운영 화면 맨 위 **관 관리** › 탭 **「약관」** › 초안 · 법무 검토 줄 **「게시 준비」** | 줄 아래 한 장 — 항목마다 **됨 / 아직 / 알아 둘 것** |

| 항목 | 내용 |
|---|---|
| 빈칸(〔미확정〕) | 남은 빈칸(같은 것은 한 번) — 있으면 「아직」 |
| 시행일 | 넣을 수 있는 가장 이른 날 — 보통 7일 뒤 · 회원에게 불리한 변경이면 30일 뒤(이용약관 제14조) · 처음 게시면 「게시하는 순간 시행」 |
| 재동의 | 필수 약관이면 활동 중 계정 수가 시행일부터 다음 로그인 때 동의 |
| 회원 알림 | 「약관 변경 안내」 알림이 가는지(설정 terms.notify_members · 제휴 약관 · 처음 게시는 없음) |
| 처리를 맡기는 곳(위탁) 표 | 처리방침 · 위탁 안내 — 지금 쓰는 외부 서비스가 표에 없으면 「아직」 |
| 국외 이전 조항 · AI | 처리방침 — 시행되면 AI 잠금이 풀리는지 · 빠진 것 |
| 제17조 요율 | 입점 약관 — 운영 「입점 유형 요율」과 다르면 「아직」(v10.310) |
| **게시 뒤 켤 수 있게 되는 것** | 처리방침: 「주민등록번호 받기」(이 판에 「주민등록번호(암호화)」 줄이 있을 때) · AI · 입점 약관: 소개몰 입점 신청 받기 · 위치기반: 동네 인증 |

- 게시 규칙(빈칸 · 시행일 · 서버 검사)은 그대로입니다. 「게시」 확인 창도 지금처럼 경고를 띄웁니다.
