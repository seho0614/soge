### 3-1. 알아 둘 것(이번 판에서 고치지 않음)

- 언어 목록(`/i18n/langs`, 60초 캐시)을 부르는 `apiGet` 이 로그인 토큰(Authorization)을 붙여, **캐시가 토큰마다 따로** 생깁니다. 그래서 운영에서 다국어를 켠 직후 로그인한 사람의 첫 요청 한 번은 꺼져 있던 때의 한국어가 나올 수 있습니다(다음 요청부터 영어 · 2-1 부터 있던 동작). 공개 API 를 토큰 없이 부르게 하면 풀리지만 `apiGet` 전체에 걸린 일이라 따로 정합니다.
