## 3. 낯선 기기 로그인 알림 (D191 ② ③)

| 무엇 | 내용 |
|---|---|
| 언제 | 비밀번호 로그인 성공 때 · 이번 로그인을 남기기 **전에** 지난 90일 성공 로그인과 (IP 앞 두 마디 + 브라우저 종류)를 견줌 → 없던 조합이면 알림 |

| 알림 | `LOGIN_NEW_DEVICE`(수신 거부 불가 · 조용한 시간 무시 · 주황) 「새 기기에서 로그인했습니다」 — 「2026-11-09 21:30(한국 시간) Firefox · Mac · 121.168.*.* 에서 로그인했습니다. 직접 하신 것이 아니라면 로그인 기록 화면에서 「모든 기기 로그아웃」을 누르고 비밀번호를 바꿔 주십시오.」 · 링크 `/my/account/security` |
| 메일 | 알림 표에 들어가면 메일 채널이 준비된 뒤 `notify_dispatch` 가 보냄(지금 운영은 메일 준비 안 됨 — 사이트 안 알림만) |
| 개인정보 | 원래 IP · 브라우저 글자는 쓰지 않음(로그인 기록과 같은 가린 값) · 처리방침 이용 목적 안(대표 11/9) |
| 이미 있던 것 | 비밀번호 변경 · 재설정 알림(`PASSWORD_CHANGED` · D102) · 비밀번호 바꾸면 다른 기기 로그아웃(token_version) — 그대로 |
