# 674. 운영 대시보드 위젯 배치 (v10.536 · 2026-11-20)

## 1. 결론
운영자마다 첫 화면(대시보드) 카드의 **차례 · 숨김**을 고르고, 그 배치를 **계정마다 서버 저장**(`staff_dash_layouts`)합니다 — 다른 PC · 휴대폰에서 열어도 같습니다. **저장한 배치가 없으면 기본 배치 그대로**(지금 화면과 똑같은 차례 · 모든 카드)이고, 「기본으로」를 누르면 저장한 줄을 지웁니다. 위치: **대시보드 › 「첫 화면 꾸미기」** · SB-ADM-DTX-020.

## 2. 카드(열쇠 15 · 기본 차례)
| 열쇠 | 카드 | 열쇠 | 카드 |
|---|---|---|---|
| todo | 오늘 할 일 | tiles | 처리 대기 숫자 |
| notices | 관리자 공지 | cap | 검수 처리 여력 |
| launch | 공개 직후 지켜보기 | alerts | 확인이 필요한 것 |
| state | 운영 상태 한눈에 | cs | 고객센터 한눈에 |
| owner | 대표 할 일 | runway | 활주로 |
| release | 지금 판 · 적용 기록 | more | 다른 운영 화면 |
| apply | 운영 적용 확인표 | server | 서버 자원 추세 |
| acct | 이번 달 매출 · 이익(SUPER) | | |

- 목록은 서버 `src/modules/dtx/dash-layout.ts` 와 화면 `web/src/app/admin/DashWidgets.tsx` 두 곳 — **같아야 함**(test_v1536 이 대조).
- 권한이 없는 카드는 골라도 나오지 않음(카드 안에서 권한을 그대로 봄 · 예: acct 는 SUPER 만).
- 나중에 카드를 더하면 저장한 차례에 없는 카드는 **기본 차례대로 끝에** 붙음(숨김은 저장한 것만).
- 대상: 대시보드 요약을 보는 ADMIN · SUPER. 지급 담당 · 검수 · 파트너 담당 첫 화면(안내 한 장)은 그대로.

## 3. 저장 규칙
| 항목 | 규칙 |
|---|---|
| 열쇠 모양 | `^[a-z][a-z0-9-]{1,23}$` — 서버 DTO · 서비스 · DB CHECK(쉼표로 이은 글자에 같은 모양) 모두 같음 · 40개까지 |
| 모르는 카드 · 같은 카드 두 번 | 422 `DASH_KEY` |
| 모두 숨김 | 422 `DASH_ALL_HIDDEN`(하나 이상 남김) |
| 범위 | **자기 계정 것만** — 다른 운영자의 배치는 읽지도 쓰지도 않음 · 감사 기록 없음(화면 꾸미기) |
| 권한 표(D258) | 주소 맵에 넣지 않음(자기 것만이라 업무 권한과 무관 · @Roles ADMIN · SUPER) |

## 4. API
| API | 설명 |
|---|---|
| GET /admin/dash-layout | 내 배치(없으면 saved=false · 기본 차례) · 카드 목록 |
| PUT /admin/dash-layout | 차례 · 숨김(보낸 칸만 · 안 보낸 칸은 저장한 값) |
| DELETE /admin/dash-layout | 기본으로(내 줄 지움) |

## 5. 화면
대시보드 맨 위 오른쪽 「첫 화면 꾸미기」 → 카드마다 보이기 체크 · ▲ ▼ · 저장 · 기본으로. 불러오지 못하면(서버 오류 · 권한) **기본 배치 그대로** 그립니다. 카드 내용 · 표식(data-*) · 옛 시험이 보는 글자는 바꾸지 않았습니다(패치 7-2).

## 6. 처리방침 고칠 곳
없음 — 회원 정보가 아니라 운영자 화면 설정(카드 열쇠 목록)만 저장.
