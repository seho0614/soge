# 811. 초안 ↔ 게시 판 차이 보기 · 운영 화면 안 미리보기 (v10.703 · 2026-11-24)

> 대표 11/24 다음개발 「★ 초안 ↔ 게시 판 차이 보기」 · 「★ 운영 화면 안 미리보기」.

## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 페이지 목록 › 편집 › **「게시하면 바뀌는 것」** | 게시된 판(없으면 처음 배치)과 지금 고친 초안의 차이 — 구역 순서 · 구역 보이기 · 숨기기 · 글자(전 → 후) · 안내 장 · 고른 상품 수 · 블록 자리마다 수 · 저장 안 한 고침 포함 · 「게시」 확인 창에도 15줄까지 |
| 같은 화면 › **「옆에서 보기」** | 「PC 폭」 · 「휴대폰 폭(375)」 — 미리보기 링크로 사용자 웹을 운영 화면 안에 그대로 띄움 · 초안을 저장하면 다시 그림 · 링크가 없으면 하나 만듦(24시간) |

## 2. 사용자 웹 머리글(보안)

- 사용자 웹은 다른 사이트 안에 끼워 보이기를 막습니다(`frame-ancestors 'self'` · X-Frame-Options SAMEORIGIN).
- **미리보기 링크(`?lp=<40자>`)일 때만** `frame-ancestors 'self' <운영 화면 주소>`(사이트 환경 ADMIN_ORIGIN · 없으면 https://admin.sogaebank.com) — 그 밖 주소는 그대로.
- 미리보기 링크는 운영자가 만든 40자 토큰이 살아 있을 때만 초안을 보여 줌(끊으면 처음 배치).
