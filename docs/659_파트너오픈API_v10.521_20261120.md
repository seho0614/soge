# 659. 파트너 오픈 API (v10.521 · 2026-11-20)

## 1. 결론
안심소개 파트너사의 **사내 시스템이 소개뱅크 자료를 읽어 갈 수 있는 API** 를 만들었습니다. 주소는 운영 화면 아래가 아닌 **`/api/partner/v1/*`**, 들어가는 열쇠는 회원 로그인이 아니라 **파트너별 API 키**입니다. **읽기만**(배정 리드 · 내 서비스 · 리드 이용료) 열고, **연락처는 API 로 내보내지 않습니다**(파트너센터 열람 한 길). 리드가 배정 · 상태가 바뀌면 **서명한 웹훅**으로 알립니다. **처음에는 모두 꺼져 있고**(`papi.enabled` off · `papi.hook_enabled` off · `papi.hook_mode` ASSUME), 6절 보안 검토 뒤 최고 관리자가 켭니다. 위치: **파트너사 › 오픈 API** · SB-ADM-OAPI-010.

## 2. 구조
| 구성 | 내용 |
|---|---|
| 키 | `sgbp_<앞 8자>_<비밀 32자>` · DB 에는 **앞머리 + sha256 지문만**(ptn_api_keys) · 원문은 발급 응답에 **한 번만** · 파트너마다 살아 있는 키 5개 · 기한 1 ~ 730일(처음 365) · 거둔 키 되살리기 · 기한 늘리기 DB 가 막음 |
| 범위 | `leads:read` · `services:read` · `cash:read` — 쓰기 범위 없음 |
| 사용 한도 | 키마다 1분 `rate_per_min`(1 ~ 600 · 처음 `papi.default_rate` 60) · 넘으면 429 `PAPI_RATE_LIMIT` + Retry-After · 서버 메모리에서 셈(서버 1대) · 사이트 전체 IP 한도(D165)도 그대로 |
| 요청 기록 | ptn_api_requests — 키 · 주소(쿼리 뺌) · 응답 코드 · ms · 막힌 까닭 · IP 는 **하루마다 바뀌는 HMAC 지문 앞 16자**만 · `papi.log_keep_days`(90) 뒤 지움 |
| 웹훅 | 파트너마다 https 주소 하나(ptn_api_hooks) · 비밀값 `whsec_…` 는 **암호문**(pgp_sym_encrypt · fn_enc_key) · 원문은 만들 때 · 바꿀 때 한 번 |
| 웹훅 줄 | lead_deliveries 트리거(`trg_papi_lead_event`) — 배정(lead.delivered) · 상태 바뀜(lead.state_changed) · 두 스위치 on + 살아 있는 웹훅일 때만 · **트리거가 실패해도 배정은 막지 않음** · 같은 배정 · 상태는 한 줄 |
| 보내기 | 정기 작업 `papi_hook_send` 1분마다 50줄 · 실패 1분 · 5분 · 30분 · 2시간 · 6시간 · 12시간 뒤 다시 · 6번째 실패 GIVEUP · 연속 20번 실패한 주소는 끄고 운영 알림 `PAPI_HOOK_DISABLED` |
| 하루 정리 | `papi_daily` 03:50 — 기록 정리 · 3일 넘은 줄 포기 · 기한 7일 안 키 `PAPI_KEY_EXPIRING` · 틀린 키 하루 500번 넘음 `PAPI_KEY_ABUSE` |

## 3. API
### 3-1. 운영 화면(SB-ADM-OAPI-010)
| API | 권한 | 설명 |
|---|---|---|
| GET /admin/papi | ADMIN · PARTNER_MAL | 설정 · 키 · 웹훅 · 24시간 호출 |
| GET /admin/papi/requests?keyId=&failed=1 | 〃 | 요청 기록 200 |
| POST /admin/papi/keys | **SUPER** | 발급(원문 한 번) — @Audit 을 달지 않고 서비스가 원문 없이 `PAPI_KEY_ISSUE` |
| PUT /admin/papi/keys/{id} | **SUPER** | 이름 · 범위 · 한도 |
| POST /admin/papi/keys/{id}/revoke | ADMIN · PARTNER_MAL | 거두기(사유) — 바로 401 |
| POST /admin/papi/hooks · /hooks/{id}/rotate | **SUPER** | 웹훅 만들기 · 비밀값 바꾸기(원문 한 번) |
| POST /admin/papi/hooks/{id}/disable · /test · /admin/papi/events/{id}/retry · GET /hooks/{id}/events | ADMIN · PARTNER_MAL | 끄기 · 시험(ping) · 다시 보내기 · 보낸 줄 |
| POST /admin/papi/run · PUT /admin/papi/settings | **SUPER** | 지금 보내기 · 설정(사유) |

### 3-2. 파트너 시스템(API 키)
| API | 범위 | 돌려주는 것 |
|---|---|---|
| GET /api/partner/v1/me | — | 회사 · 등급 · 키 이름 · 범위 · 한도 · 기한 · 웹훅 호스트 |
| GET /api/partner/v1/leads?state=&since=&limit= | leads:read | 배정 번호 · 상태 · 시각 · 지역 · 급함 · 등급 · 업종 · 요약 (회수 뺌 · 연락처 없음) |
| GET /api/partner/v1/leads/{deliveryId} | leads:read | 위 + 예상 확인비용 · 이용료 상태 |
| GET /api/partner/v1/services | services:read | 서비스 이름 · 상태 · 업종 |
| GET /api/partner/v1/cash | cash:read | 리드를 받을 수 있는지 · 잔액 |
| GET /api/partner/v1/docs | — | 주소 · 범위 · 오류 · 웹훅 안내 |

오류: 503 PAPI_OFF · 401 PAPI_KEY_INVALID(지문이 틀리면 앞머리가 있어도 같은 답) · PAPI_KEY_REVOKED · PAPI_KEY_EXPIRED · 403 PAPI_PARTNER_INACTIVE · PAPI_SCOPE · 429 PAPI_RATE_LIMIT · 422 PAPI_QUERY · 404.

## 4. 파트너에게 줄 안내
### 4-1. 부르기
```
curl -H "X-Partner-Key: sgbp_xxxxxxxx_…" https://sogaebank.com/api/partner/v1/leads?limit=20
```
### 4-2. 웹훅 몸통
```
{ "event": "lead.delivered", "eventUid": "…", "deliveryId": "…", "state": "DELIVERED", "expiresAt": "2026-11-21T03:00:00Z", "at": "2026-11-20T03:00:00Z" }
```
### 4-3. 서명 확인(X-Sgb-Signature: t=…,v1=…)
```
expected = HMAC_SHA256(whsec_비밀값, t + "." + 받은 본문 그대로).hex()
· v1 과 고정 시간 비교 · t 가 5분 넘게 지났으면 버림 · 같은 X-Sgb-Delivery 는 한 번만 처리 · 2xx 로 바로 답하고 일은 뒤에서
```
