# 86. P2P — 모든 업무 개인 회원 허용 · 인증이 필요한 등록만 그 인증 — v10.37 (2026-10-13 · 대표 지시)

> 바탕 v10.36(`a9c1a64`). 지시: 「모두 개인에게 허용. 단 등록 시 인증을 받아야 하는 경우만 인증 받고 가능 · 이외의 제약이 없음 · **B2B 가 아니고 P2P**」 · 「1. 개인도 가능 2. 사용 3. 개인도 가능 4. 급구 · 급매 개인 가능」.

## 1. 결론 — 규칙 한 줄

**본인인증을 한 개인 회원은 모든 업무를 합니다. 사업자 여부는 어디에서도 보지 않습니다. 등록에 인증이 필요한 업종만 그 인증을 받은 뒤 등록합니다.** 사업자 인증은 「사업자로 소개비(세금계산서)를 받을 때」 하는 선택입니다.

## 3. 그대로 둔 것 — 「등록 시 인증이 필요한 경우」

| 무엇 | 필요한 인증 | 근거 |
|---|---|---|
| 보험 · 의료 업종(GATED) 게시 | 자격 심사 승인 | 의료법 27조 · 보험업법 · 의료기기법 24조 |
| 부동산 매물 공개 | 공인중개사 인증(개설등록번호) 또는 소유 확인 | 공인중개사법 18조의2 |
| 제한업종(다단계 · 대부 · 사행성 등) | 등록 불가 (INV-6) | 법령 |
| 안심소개 입점 승인 스위치(`mal.partner_only` · 지금 꺼짐) | 입점 승인 | 운영 스위치 |

이 인증들의 신청서(파트너센터 입점 · 공인중개사 인증 · 소개창업 빠른 매칭 「인력대행」 회신)는 지금 **사업자 정보 아래에 접수**됩니다 — 업체 등록증 · 개설등록 · 직업소개 등록처럼 인증 자체가 업체를 대상으로 하기 때문입니다. 개인 자격(예: 보험설계사 개인)으로 신청하게 하려면 파트너센터를 계정 기준으로 바꾸는 큰 작업이라 이 판에 넣지 않았습니다.
