# 631. 사내 설문 (v10.493 · 2026-11-20)

## 1. 결론
ADMIN · SUPER 가 설문을 만들어(질문 유형 · 대상 역할 · 기간 · 익명) 열고, 대상 운영 계정이 **사무 › 사내 설문**에서 답합니다. **익명 설문은 답에 계정을 저장하지 않고**, 결과는 **마감한 뒤 · 응답이 its.survey_min_count(처음 3) 이상일 때만** 보입니다. CSV 는 내려받기 승인(ITS_SURVEY). SB-ADM-ITS-040(관리) · 041(답하기).

| 질문 유형 | 답 | 결과 |
|---|---|---|
| 하나 고르기(SINGLE) | 보기 2 ~ 12 중 하나 | 보기마다 수 |
| 여럿 고르기(MULTI) | 하나 이상 | 보기마다 수 |
| 점수(SCALE) | 1 ~ N(3 ~ 10) | 점수마다 수 · 평균 |
| 글(TEXT) | 1000자 | 글 목록(**가나다순** · 낸 차례 아님) |

## 2. 익명을 지키는 방법
1. 낸 사실(its_survey_takers: 설문 · 계정 — 두 번 내기 막기 · 응답률)과 답(its_survey_answers)을 **다른 표**에 · 답에는 계정 칸이 비어 있음(트리거가 지움) · **두 표 모두 시각 칸 없음** · 답 번호는 무작위 uuid.
2. **받는 중에는 결과를 보지 않음**(한 사람 낼 때마다 들여다보면 그 사람 답이 드러남) · 마감 뒤에도 응답이 최소 수 밑이면 응답 수까지 감춤.
3. 익명 설문에서는 낸 사람 이름 목록을 보여 주지 않음(수만) · CSV 도 집계 · 글 답만.
4. 답 넣기 API 에 감사 기록 · 권한 주소 맵을 붙이지 않음.
이름을 밝히는 설문(anonymous = false)은 답에 계정이 남고, 받는 중에도 결과 · 낸 사람 이름 · 사람마다 한 줄 CSV 를 봅니다.

## 3. API
| 방법 | 주소 | 누가 | 설명 |
|---|---|---|---|
| GET · POST | /admin/its/surveys | ADMIN | 목록(낸 사람 / 대상 수) · 만들기(고치는 중) |
| GET · PUT | /admin/its/surveys/{id} | ADMIN | 자세히 · 고치기(고치는 중이면 모두 · 받는 중이면 마감일 늦추기만) |
| POST | /admin/its/surveys/{id}/open · close · cancel | ADMIN | 열기(질문 1개 이상 · 마감일 안 지남) · 마감 · 취소(사유) |
| GET | /admin/its/surveys/{id}/results | ADMIN | 집계(감춤 이유 OPEN · MIN · CANCELED) |
| GET | /admin/its/surveys/{id}/export?ticket= | ADMIN | CSV(내려받기 승인 ITS_SURVEY) |
| GET | /admin/its/my-surveys · /{id} | 운영 계정 | 답할 설문 · 질문(대상 밖 · 받는 중 아님 404) |
| POST | /admin/its/my-surveys/{id}/answer | 운영 계정 | 답(한 번 · 고칠 수 없음) |

오류: 404 · 409 ITS_SURVEY_STATE · ITS_SURVEY_TAKEN · 422 ITS_SURVEY_TITLE · DATE · AUDIENCE · QUESTION · ANSWER · EMPTY · REASON · CLOSED · HIDDEN · EXPORT_NEED_APPROVAL.

## 4. 표 · 설정 (D270)
- its_surveys(DRAFT → OPEN → CLOSED · CANCELED · 기간 92일) · its_survey_questions(고치는 중만) · its_survey_takers · its_survey_answers(유형 검사 트리거 = 서버 검사 · 쌓기만).
- 설정 its.survey_min_count(3 · 2 ~ 20) · 정기 작업 its_office_daily 08:55 — 기간 지난 받는 중 설문 마감.
- 내려받기 승인 대상 ITS_SURVEY — D270 이 지금 CHECK 목록을 읽어 하나만 더함(다른 묶음이 더한 대상을 지우지 않음).
- 권한(D258): 업무 its-survey(사무) · 주소 맵은 관리 10줄만.
