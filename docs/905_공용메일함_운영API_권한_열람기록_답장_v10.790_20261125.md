# 905. 사내 웹메일 W1-2 — 공용 메일함 운영 API · 메일함별 권한 · 열람 기록 · 답장 — v10.790 (2026-11-25)

## 1. 결론

- 공용 메일함을 다루는 운영 API 를 더했습니다. 모두 ADMIN · SUPER 역할 + **메일함마다 업무 권한**으로 거릅니다.
  1. SUPER 는 모두. 업무 권한 판정을 켜 둔 경우(perm.enforce ON/SHADOW 또는 perm.mode GROUPS/COMPARE)는 `mailbox-privacy` · `mailbox-help` · `mailbox-admin` 중 **VIEW 가 있는 메일함만**. 둘 다 꺼진 처음 상태는 ADMIN 이면 모두(다른 운영 화면과 같은 기준).
  2. 열기 · 맡기기 · 끝냄 · 다시 열기 · 스팸 · 답장 · 첨부 받기는 **열람 기록(mail_access_log)** 한 줄 — 고치기 · 지우기는 DB 가 막음.
  3. 답장은 SES(MailService) — **보내는 주소 = 그 공용 주소** · 이름 「소개뱅크 〔메일함〕」 · In-Reply-To · References. 메일 보내기 준비가 안 됐으면 422 `MAIL_NOT_READY`.
  4. 바이러스 판정 FAIL 메일의 첨부는 내려받기 422 `MAIL_VIRUS`.
- 발송기(smtp.ts)에 **선택 칸**(보내는 주소 · 이름 · In-Reply-To · References)을 더했습니다 — 칸을 비우면 지금과 같습니다(알림 메일 · 인증번호 그대로).

## 2. API

| API | 권한(주소 표) | 내용 |
|---|---|---|
| `GET /admin/mailbox/messages` | mailbox-* VIEW | 권한 있는 메일함 · 메일함 · 상태 · 찾기 · 30개씩 |
| `GET /admin/mailbox/messages/{id}` | VIEW | 본문 · 첨부 목록 · 같은 대화 · 열람 기록 · 「보낸 사람 확인 안 됨」 · 열면 VIEW 기록 |
| `POST …/{id}/assign` | EDIT | 운영자에게 · null 이면 풀기 · 감사 MAILBOX_ASSIGN |
| `POST …/{id}/state` | EDIT | DONE · NEW · SPAM · 감사 MAILBOX_STATE |
| `POST …/{id}/reply` | EDIT | 답장 · done=true 면 끝냄 · 감사 MAILBOX_REPLY |
| `GET /admin/mailbox/attachments/{id}` | VIEW | Base64 · DOWNLOAD 기록 |

## 3. 운영 적용

- 코드만(D330 은 v10.789). 메일 보내기(SES · docs/892)와 루트 도메인 DKIM(docs/902 W0 블록 2)이 되어야 답장이 나갑니다.
