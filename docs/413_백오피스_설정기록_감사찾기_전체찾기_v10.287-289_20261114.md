### 전체 찾기 — 역할별 묶음

| 묶음 | 찾는 것 | 볼 수 있는 역할 | 누르면 |
|---|---|---|---|
| 회원 | 이름 · 이메일 일부 · 휴대폰 4자리 이상 · 번호 | 관리자 · 최고 관리자 | 회원 › 회원 |
| 소개몰 주문 | 주문번호 · 번호 | 관리자 · 최고 관리자 | 소개몰 › 소개몰 주문 |
| 소개몰 판매자 | 상호 · 판매자 코드 · 번호 | + 안심 파트너 담당 | 소개몰 › 소개몰 판매자 |
| 공지 | 제목 · 번호 | 운영 계정 모두 | 노출 › 메인 운영 |
| 매물 | 제목 · 번호 | + 검수 | 검수 › 검수 큐 |
| 거래 | 번호 앞부분(6자 이상) · 매물 제목 | + 지급 | 거래 › 거래 모니터링 |

## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `GET /admin/site-settings` | ADMIN · SUPER | 줄마다 `updatedAt` · `updatedBy`(이름) 더함 |
| `GET /admin/site-settings/history?key&from&to&page` | ADMIN · SUPER | 바뀐 기록 · 50줄씩 · key 는 정확한 키 또는 앞부분 |
| `GET /admin/audit/search?who&action&target&from&to&kind&page` | ADMIN · SUPER | 100줄씩 · 422 `BAD_PERIOD` · `PERIOD_TOO_LONG` |
| `GET /admin/audit/logs/{id}` | ADMIN · SUPER | 상세(전 · 후 내용 · IP · 브라우저) · 404 |
| `GET /admin/audit/export?…` | SUPER | CSV(엑셀용 · 1만 줄 · 수식으로 읽히는 칸 막음) · 감사 `AUDIT_LOG_EXPORT` |
| `GET /admin/search?q` | 운영 계정 모두 | 묶음별 5건 · 422 `QUERY_TOO_SHORT` · 감사 `ADMIN_SEARCH` |
