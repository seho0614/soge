# 753. 1:1 문의 사진 첨부 (v10.611 · 2026-11-21)

> 18차 ㉗. 새 탭 없음 — 운영 「1:1 문의」 한 건 화면 · 사용자 웹 「내 문의 내역」에 붙임. SQL `sql/bzx_611_inquiry_photos.sql`.

## 1. 결론

- **이미 있는 것은 그대로**: 문의 접수 때 첨부 3개(`inquiries.attachment_keys` · 파일 용도 `INQUIRY_ATTACHMENT` · 이미지 · PDF 10MB · v10.31 D049).
- **더하는 것**(스위치 `bzx.inquiry_photos` · 처음 off):
  - 회원 — 접수 뒤에도 **닫히지 않은 내 문의에 사진 더 붙이기**(한 번에 3장 · 문의마다 6장 · JPG · PNG).
  - 운영 — **답변에 사진 붙이기**(문의마다 6장) · 회원은 내 문의 내역에서 봄.
- **운영 한 건 화면 그림 미리 보기**(접수 첨부 · 회원이 더한 사진 · 답변 사진)는 스위치와 상관없이 늘.
- 파일 저장 · 형식 검사(매직바이트)는 기존 파일 올리기 그대로 · **새 파일 용도 없음**(`ck_files_purpose` · `fn_file_can_read` 안 고침). 회원이 답변 사진을 볼 때는 이 기능 API 가 바이트를 줍니다(내 문의에 붙은 사진만).
- 운영도 `INQUIRY_ATTACHMENT` 를 올리도록 파일 올릴 수 있는 역할에 ADMIN 을 더했습니다(SUPER 는 원래 모두).
