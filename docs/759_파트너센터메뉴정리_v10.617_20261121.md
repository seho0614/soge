# 759. 파트너센터 메뉴 정리 (v10.617 · 2026-11-21)

> 대표 11/21 승인. 안심소개 파트너센터 상단바(site/src/components/partner/PartnerShell.tsx)에 그동안 메뉴 밖에 있던 화면 세 개를 이어 줍니다. 패치 `patches/3_ptc_menu_site.md`(6).

## 1. 결론

- **메뉴 줄 12개는 그대로**(시안 D.partner.nav · 옛 시험) 두고, 켜진 메뉴 아래 **하위 링크 한 줄**(`PTC_SUB` · `data-ptc-sub`)을 더했습니다.

| 메뉴 | 하위 링크 | 화면 |
|---|---|---|
| 정산 | 정산 내역 · **정산 예측** | /partner/settlement · /partner/settlement/forecast(v10.580) |
| 실적 | 실적 · **자료 내려받기** | /partner/stats · /partner/export(v10.544 · 리드 CSV 는 내려받기 승인 뒤) |
| 회사 · 계정 | 회사 · 계정 · **계약** | /partner/business · /partner/contracts(v10.609 · 갱신 계약 서명 · 대표 계정만) |

- /partner/contracts · /partner/export 를 열면 각각 「회사 · 계정」 · 「실적」 메뉴가 켜짐(BELONGS) · 정산 예측은 주소 앞머리로 「정산」이 켜짐.
- 글자는 사전 `partner.shell.sub.*` · `partner.shell.subAria`(ko · en) — 일본어 · 중국어는 빠진 문장을 영어로 채움(LANG_FALLBACK). 코드에 한글 없음(test_v1100 규칙).
- 권한은 그대로 — 각 화면 · API 가 막음(계약은 대표 계정 · 내려받기는 대표 · 정산 권한 직원 · 정산 예측은 파트너).
