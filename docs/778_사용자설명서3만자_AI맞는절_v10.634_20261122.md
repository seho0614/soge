# 778. 사용자 설명서 3만 자 · AI 상담은 맞는 절부터 — v10.634 (2026-11-22)

## 1. 결론

- 사용자 설명서는 지금 **18,829자로 한도(2만 자)의 94%** 입니다(v10.622 회원 기능 절 15개 뒤). 절을 하나 더 넣으면 막힙니다.
- 이번 판부터 **저장 한도를 3만 자**로 올립니다(95KB 크기 한도 안 · 한글 3만 자는 약 9만 바이트).
- AI 상담이 한 번에 읽는 설명서 양은 **그대로 2만 자**입니다. 설명서가 2만 자 안이면 지금처럼 모두 읽고, 넘으면 **질문(과 바로 앞 질문)에 맞는 절부터** 골라 2만 자까지 읽습니다(절 제목에 낱말이 있으면 3점 · 본문에 있으면 1점 · 고른 절은 원래 순서로).
- 답의 출처(설명서 m번호 · /guide/manual#m번호)는 그대로입니다.

## 2. 바뀐 것

| 항목 | 내용 |
|---|---|
| 서버 | `help.service.ts` `HELP_MAX_CHARS = 30000` · `HELP_AI_MAX_CHARS = 20000` |
| AI | `agent-chat.service.ts` `manualBlock()` · `manualScore()` — 다 들어가면 지식 묶음에 넣어 둠(캐시 그대로) · 넘을 때만 질문마다 고름 |
| DB | D307 — `help_docs_body_len` 설명서 3만 자(운영 화면 도움말 4만 자 그대로) |
| 화면 | 관 관리 › 사용자 설명서 — 「n자 / 30,000자」 |

## 3. 운영 적용

- 마이그레이션 D307 에 포함(검사 하나 바꿈 · 줄은 고치지 않음).
- 적용 뒤 확인: 관 관리 › 사용자 설명서 편집 칸 아래 「… / 30,000자 · …KB / 95KB」.
