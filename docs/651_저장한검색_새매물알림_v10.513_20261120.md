# 651. 저장한 검색 · 새 매물 알림 (v10.513 · 2026-11-20)

## 1. 결론
회원이 매물 검색 조건(관 · 업종 · 검색어 · 지역 · 안심소개 축)을 **이름 붙여 저장**하고, 그 조건에 **새로 게시된 매물**이 있으면 **하루 한 번(매일 08:10) 한 통**으로 알립니다. 사람마다 **최대 10개**(`lsx.saved_search_max` · 1 ~ 10). 알림은 회원의 **알림 수신 설정을 따릅니다**(끌 수 있는 종류 `LSX_SAVED_SEARCH`). 스위치 `lsx.saved_search` **처음 꺼짐**.

## 2. 흐름
| 단계 | 내용 |
|---|---|
| 저장 | 통합 검색 결과(SB-HOM-SRC-010) 「이 검색 저장」 → `POST /me/saved-searches`(검색어 · 관) · API 는 업종 · 지역 · 축도 받음 |
| 관리 | 나의공간 › 저장한 검색(SB-MYP-LSX-010 · `/my/saved-searches`) — 이름 · 알림 켜고 끄기 · 지우기(스위치가 꺼져도 지우기는 됨) |
| 묶음 알림 | 정기 작업 `lsx_daily`(08:10) — 조건마다 「지난 확인 뒤 ~ 지금」 게시된 매물 수 → 회원마다 한 통(조건 이름 3개 + 건수) · `lsx_search_digests`(회원 · 한국 날짜 UNIQUE)라 두 번 돌아도 한 통 |
| 운영 | 검수 › 저장한 검색(SB-ADM-LSX-040) — 모은 숫자만(저장 수 · 회원 수 · 알림 켠 수 · 7일 보낸 묶음 · 관별 · 3명 이상이 저장한 검색어) |

- 세는 규칙은 목록과 같음 — 동의어 넓히기(`expandKeyword`) · 낱말별 판정(`fn_search_match`). 우선노출(광고) 매물 · **내 매물은 세지 않음**.
- 알림 글에는 **조건 이름과 건수만** — 매물 제목 · 등록자는 싣지 않음. 알림을 다시 켜면 확인 시각을 지금으로(옛 매물이 한꺼번에 오지 않게).

## 3. 표 · 설정 · API
| 종류 | 이름 |
|---|---|
| 표 | `lsx_saved_searches`(조건 하나 이상 CHECK · 지역 `^[0-9A-Z]{2,10}$` = 서버 정규식) · `lsx_search_digests`(쌓기만) · 트리거 `trg_lsx_saved_max`(사람마다 최대 · 잠금) |
| 설정 | `lsx.saved_search`(off) · `lsx.saved_search_max`(10) |
| API | `GET · POST /me/saved-searches` · `PUT · DELETE /me/saved-searches/{id}` · `GET /admin/lsx/saved-searches/stats` · `GET /admin/lsx/overview` · `PUT /admin/lsx/settings`(SUPER) · `GET /site/lsx/switches` |
| 오류 | 422 `LSX_OFF` · `LSX_SAVED_MAX` · `LSX_SAVED_EMPTY` · `LSX_SAVED_FIELD` · 409 `LSX_SAVED_DUP` |
