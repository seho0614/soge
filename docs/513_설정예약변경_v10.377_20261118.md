# 513. 설정 예약 변경 (v10.377 · 2026-11-18)

> 대표 11/18 「모두개발」 → ⑧ ① 설정 예약 변경 · ② 탈퇴 유예 끝 전날 알림 · ③ 점검 예정 회원 알림 · ④ 내 로그인 기기 목록 → 계획 「승인 + 통과하면 병합」(여덟 번째 묶음 · 운영은 v10.331 → v10.376 한 번에 다음 묶음). 이 문서는 ①. 마이그레이션 **D241**.

## 1. 왜

- 탈퇴 유예 7일(docs/511)은 처리방침 · 약관 새 판 **시행일**에 켜야 합니다. 지금은 그날 00:00 에 누군가 「전체 설정」에서 직접 바꿔야 해 늦거나 잊을 수 있습니다.

## 3. 쓰는 예 — 탈퇴 유예 7일

1. 처리방침 · 약관 새 판(docs/511 §3-1 문구)을 게시합니다(시행일 예: 2026-12-01).
2. 정책 › 전체 설정 › 예약 변경 — 키 `member.withdraw_grace_days` · 값 `7` · 시각 `2026-12-01 00:00` · 사유 「처리방침 시행 — 탈퇴 유예 7일」 → 예약.
3. 시행일 00:05 안에 바뀝니다. 「바뀐 기록」 · 운영 알림(중요 설정 바뀜)으로 확인합니다.
