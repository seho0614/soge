# 487. 막힌 접속 기록 (v10.353 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 막힌 접속 기록 · ② 월간 보안 보고 · ③ 운영자 활동 요약 · ④ 감사 기록 위변조 확인 「모두」 → 계획 「승인 + 통과하면 병합」(감사 · 감시 목록 정리의 빈 곳). 이 문서는 ①. 마이그레이션 없음.

## 1. 왜

- 운영 화면은 허용 IP 에서만 열립니다(Nginx). 밖에서 들어오려다 막힌 기록은 Nginx 로그에만 있어 운영 화면에서 볼 수 없었습니다. 우리 IP 가 바뀌어 막혔는지 · 누가 두드리는지 알 길이 없었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 허용 파일(`/etc/nginx/snippets/sgb-admin-allow.conf`) | 끝에 운영 화면 전용 접속 기록 한 줄 `access_log /var/log/nginx/sgb-admin-access.log;` — 루트 적용 스크립트 · 반영 스크립트 · 처음 준비 스크립트가 모두 넣음 |
| 새 `deploy/aws/nginx_deny_summary.py` | 루트 타이머가 10분마다 — 최근 7일 403(화면 · 파일 주소만 · `/api/` 뺌) IP 마다 7일 · 24시간 · 마지막 때 · 주소 3개 · 상위 50 → `/var/lib/sgb-nginx-allow/denied.json` |
| `nginx-allow-watch-install.sh` | 타이머 `sgb-nginx-deny.timer`(10분) · 서비스 · `/usr/local/sbin/sgb-nginx-deny-summary`(root 복사) 더함 — **이미 설치한 서버도 이 판 뒤 한 번 더 침** |
| 새 API `GET /admin/staff-access/denied` | ADMIN · SUPER · 읽기만 — SUPER 는 IP 전부 · ADMIN 은 가림 · 지금 허용됨 표시 |

| 정기 작업 `sla_alert` | 한 IP 가 24시간 100번 넘으면 운영 알림 **NGINX_DENIED_SPIKE**(경고 · IP 가림 · 줄면 풂) |
