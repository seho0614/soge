## 9부 — 이번에 찾아 고친 오류

| # | 오류 | 심각도 | 조치 |
|---|---|---|---|
| 1 | 기준 데이터에 시험 흔적이 굳음 | 중간 | `C960`으로 삭제 |
| 2 | **가짜 계좌로 오픈 검정 통과** | **높음** | 뷰가 시험값을 잡도록 수정 |
| 3 | **감시 뷰 2개가 목록에서 빠짐** | **높음** | `C961`로 문구 표준화 |

### ②가 가장 위험했습니다

```
company.bank_account  999999-99-999999
v_company_account     missing = 0  ← 「정상」으로 나옴
```

이대로 열었다면 **입금 안내에 가짜 계좌번호가 나갔을 것입니다.** 지금은 `missing = 3`입니다.

### ③으로 숨어 있던 것이 드러났습니다

감시 뷰 **64 → 66**. 새로 잡힌 `v_assumed_on`이 3건을 보고합니다.

```
assume.payment  실제 결제 안 일어남
assume.broker   국토부 대조 안 함
assume.bank     가상 계좌로 돌고 있음
```

**연동 후 셋 다 off로 바꾸셔야 합니다.**
