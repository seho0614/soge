# 813. 관 안 페이지도 관 열림 규칙 (v10.705 · 2026-11-24)

> 대표 11/24 「모두 동일하게 적용」(관 안 페이지에도 「관이 열려 있으면 편집 불가」를 넣을지 물음에). 앞 판 docs/809 · 812.

## 1. 바뀐 것

| 무엇 | 전(v10.701) | 지금 |
|---|---|---|
| 관 안 페이지 · 새 관 첫 화면 | 수정 가능 스위치만 | **그 관이 열려 있으면** 만들기 · 초안 저장 · 게시 · 숨김 · 다시 보임 · 예약 · 되돌리기 · 번역 초안 모두 422 **GWAN_PAGE_GWAN_OPEN** — 관 관리 › 관 설정에서 관을 닫은(중지) 뒤 고치고, 다 고친 뒤 다시 엶 |
| 예약 게시 | 수정 불가면 기다림 | 관이 열려 있어도 기다림(닫히면 게시) |
| 공통 조각 한꺼번에 다시 게시 | — | 열린 관의 페이지는 「FAILED: 관이 열려 있어 …」로 건너뜀 |
| 편집 화면 맨 위 · 페이지 목록 아래 표 「수정」 칸 | 가능 · 불가 | 「가능 · 관 열림(닫아야 편집)」 · 열려 있으면 「초안 저장」 · 「게시」 꺼짐 |

- 이제 꾸밀 페이지(관 메인 · 허브 메인)와 관 안 페이지가 **같은 규칙**입니다. 메인(HOME)만 관이 없어 수정 가능 스위치만 따름.
- 미리보기 링크 · 수정 가능 스위치(SUPER)는 관이 열려 있어도 됩니다.
- 수정 가능 스위치의 처음 값은 그대로 — 꾸밀 페이지 수정 불가 · 관 안 페이지 수정 가능.
- 새 관(준비중 · 닫힘)은 지금처럼 만들고 고칠 수 있음 — 열고 나면 같은 규칙.
