# 423. 요율 공지 안 읽은 판매자 자동 다시 알림 — v10.302 (2026-11-15)

> 대표 결정(11/15): 「다음」 → 「A · B · C 모두」 · 계획 「승인 + 통과하면 병합」.
> **마이그레이션 D218(v10.301 과 같음).** 지금까지는 운영자가 「안 읽은 n곳 다시 알림」을 눌러야 했습니다. 이제 설정을 켜면 **시행 n일 전**에 정기 작업이 한 번 보냅니다. **처음에는 꺼져 있습니다(0).**

## 1. 바뀐 것 (정확한 위치)

| 판 | 곳 | 내용 |
|---|---|---|
| v10.302 | 설정 **`hlt.rate_auto_remind_days`** — 운영 화면 맨 위 **정책** › 탭 **「전체 설정」** 에서 찾기 → 「고치기」 | **0 = 끔(처음)** · 1 ~ 30(일) · 켜면 보통 **7** · 바꾸기는 **최고 관리자만**(ADMIN 은 403 `RATE_REMIND_SETTING_SUPER`) · 바뀐 기록에 남음 |
| v10.302 | 정기 작업 `hlt_rate_schedule`(매일 00:05) · DB `fn_hlt_rate_auto_remind` | **시행 n일 전 안**이 된 예정 예약 중 **예약 안내 공지를 게시했고(게시 시각이 지남)** — 공지를 **펼치지 않은 대상 판매자에게만** 「[다시 알림] 판매 수수료율 변경 예정 안내」(판매자센터로 · 사람이 누른 다시 알림과 같은 글 · 메일 · 문자도 같은 길) |
| v10.302 | 같은 작업 | **예약마다 자동은 한 번** · **사람이 24시간 안에 다시 알렸으면 그날은 건너뜀**(다음 날 다시 봄) · 보낼 곳이 없으면(모두 읽음) 기록을 남기지 않음 · 보낸 기록 `hlt_rate_reminds`(`auto` = 예 · 사람 없음) · 발송 현황 연결(`REMIND`) |
| v10.302 | 운영 화면 › 운영 알림 | 보냈으면 **`RATE_AUTO_REMIND`(INFO)** 「요율 공지 자동 다시 알림 — 예약 n건 · 안 읽은 판매자 n곳에 보냄」 |
| v10.302 | **소개몰** › **「소개몰 정산」** › **「요율 변경 예정」** 상자 맨 위 | 「자동 다시 알림: **꺼짐** / **시행 n일 전 — 공지를 안 펼친 대상 판매자에게 한 번(매일 00:05)**」 한 줄(예약이 있을 때) · 「공지」 칸 「다시 알림 n번**(자동 m)**」 |

- 자동으로 보낸 뒤 24시간 안에는 운영자의 「다시 알림」도 막힙니다(409 `REMIND_TOO_SOON` · 지금 규칙 그대로).
- 시행 n일 전보다 늦게 공지를 게시했다면, 게시한 다음 날 00:05 에 보냅니다(시행 전이면).
