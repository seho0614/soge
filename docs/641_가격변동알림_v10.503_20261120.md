# 641. 가격 변동 알림 (v10.503 · 2026-11-20)

> ㊸ 회원 2 의 ③. 스위치 `mbx.price_alert` **처음 off**. 정기 작업 `mbx_price_digest`(매일 08:30).

## 1. 결론
회원이 **직접 켠** 관심 매물 · 상품의 가격이 바뀌면 **하루 한 번 묶음 알림**(MBX_PRICE_DIGEST · 인앱)으로 알려 줍니다. 매물은 **기존 관심 목록(favorites)** 을 그대로 씁니다 — 관심에 담은 것만 켤 수 있고, 관심에서 빼면 알림도 지워집니다(DB 트리거). 소개몰 상품은 찜이 없어 상품 화면 「가격 알림 받기」가 바로 켭니다. 화면 `/my/price-alerts`(SB-MYP-MBX-030).

## 2. 동작
| 항목 | 규칙 |
|---|---|
| 보는 값 | 매물 = 거래 금액(deal_amount) · 희망 소개비(desired_fee) / 상품 = 판매가(price · 옵션에서 셈한 대표 값) |
| 기준값 | 켤 때 지금 값 · 알림을 보내면 지금 값으로 바뀜 |
| 묶음 | 매일 08:30 — 회원마다 바뀐 것을 모아 한 통(5줄 + 「외 n건」) · **하루 두 번 보내지 않음**(`mbx_price_digests` 회원 · 날 고유 — 오늘 보냈으면 기준값을 그대로 두어 내일 묶음에 들어감) |
| 내릴 때만 | `drop_only` 면 오른 것은 알리지 않고 기준값만 새로 |
| 건너뜀 | 게시 중이 아닌 매물 · 판매하지 않는 상품 · 활동 중(ACTIVE)이 아닌 회원 |
| 수신 설정 | `fn_notify` 가 회원의 인앱 수신 설정을 봄 — 나의공간 › 알림 · 설정에서 「관심 가격 변동」을 끄면 보내지 않음(기록은 남음) |
| 개수 | `mbx.price_watch_max`(50 · 1 ~ 200) 넘으면 422 `MBX_WATCH_MAX` |
| 꺼짐 | 새로 켜지 못함(422 `MBX_OFF`) · 정기 작업도 보내지 않음 · 켜 둔 것은 남음 |
| 탈퇴 | 매일 04:35 `mbx_daily` 가 지움 |

## 3. 표 · API · 알림
| 표 | 내용 |
|---|---|
| `mbx_price_watches` | 회원 · 대상 · 내릴 때만 · 기준 금액 · 기준 소개비(매물만) · 마지막 확인 · 알림 |
| `mbx_price_digests` | 보낸 날 · 바뀐 건수(금액 · 이름 없음) · 쌓기만 |
| 트리거 | `trg_mbx_fav_unwatch`(favorites 지우면 매물 알림 지움) |

| API | 권한 |
|---|---|
| GET /me/price-alerts · POST /me/price-alerts · DELETE /me/price-alerts/{type}/{key} | 회원 |
