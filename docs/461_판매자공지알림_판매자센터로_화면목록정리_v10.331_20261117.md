# 461. 소개몰 공지 알림 — 판매자는 판매자센터로 · 화면 목록 「시안만」 정리 (v10.331 · 2026-11-17)

> 대표 「다음개발」 → 「후보 찾아 추천」 → 「① + ② 묶어서」 · 「승인 + 통과하면 병합」(11/17). 마이그레이션 **D223**(260 → 261 · 스냅샷 필요).

## 1. 왜

- v10.320(D221)부터 공지 알림은 모두 **소개광장 › 공지**로 갑니다. 소개몰(HLT) 공지도 마찬가지라, 판매자가 요율 변경 공지 알림을 누르면 판매자센터가 아닌 소개광장에서 공지를 엽니다.
- 판매자센터 › 소개몰 공지(v10.330)는 요율 공지를 **판매자가 직접 펼친 기록**을 남기는 자리입니다. 알림도 그 자리로 보내야 합니다.
- 화면 목록(`spec/screens.json`)에서 3개 화면이 「시안만 — 실제 웹 개발중」(v10.27 · G-130)으로 남아 있었습니다. 실제로는 v10.31 · 32 에서 이미 만들어졌으므로 매트릭스 「이연」 수가 틀렸습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D223** `fn_notice_notify` | D221 을 그대로 다시 만들고, 알림 이동 주소만 **받는 사람마다** 정합니다. 소개몰(HLT) 공지이고 받는 사람이 입점 판매자(TENANT · BRAND · ACTIVE · PAUSED)이면 `/health/seller/center/notices#n-<id>`, 그 밖은 지금처럼 `/community?board=NOTICE#n-<id>` 입니다. 이미 보낸 알림은 그대로 둡니다. 지우는 문장은 없습니다. |
| 새 API `GET /me/health/seller/notices/{id}` | 판매자 공지 한 건입니다. 목록과 같은 기준(소개몰 공지 · 게시 중 · 끝나지 않음 · 이 판매자 등급)이 아니면 404, 판매자가 아니면 403 `NOT_SELLER` 입니다. |
| 공통 부품 `NoticeHashOpen` | `onePath`(한 건 부르는 주소) · `readPath`(읽음 기록 주소) 칸을 더했습니다. 비우면 지금처럼 `GET /notices/{id}` · `POST /me/notices/{id}/read` 입니다. |
| 사용자 웹 **소개몰 › 판매자센터 › 소개몰 공지** | 알림에서 온 공지(`#n-<id>`)가 첫 30개 안이면 그 줄이 펼쳐집니다(v10.330 그대로). **30개 밖이면 찾기 칸 아래 「지난 공지」로 펼친 채** 보여 주고, 판매자 읽음 기록을 남깁니다. 볼 수 없는 공지면 「이 공지는 볼 수 없습니다 — …」 안내가 나옵니다. |
| `spec/screens.json` | 이연(deferred)에서 SB-BIZ-POL-030(지원사업 공고 원문) · SB-ADS-LND-010(광고주 랜딩) · SB-ADM-SEG-020(옮길 대상 미리보기)를 뺐습니다(이연 17 → 14). 두 화면의 note 에서 「시안만」을 지웠습니다. SB-HLT-SEL-030 에 새 API 를 이었습니다. |

- 판매자가 아닌 회원이 받는 소개몰 공지 알림은 지금처럼 소개광장 › 공지로 갑니다(판매자센터는 판매자만 열림).
- 판매자도 소개광장 › 공지에서 소개몰 공지를 볼 수 있습니다(바뀌지 않음).

## 3. 시험 (test_v1331)

1. ① 코드 — D223(지우는 문장 없음) · API · 부품 `onePath` · `readPath` · 화면 · screens.json(이연 3건 빠짐 · 새 API) · 문서 461 · 판 v10.331 · 마이그레이션 261
2. ② DB — 소개몰 공지 알림: 판매자는 판매자센터 주소, 판매자가 아닌 회원은 소개광장 주소 · 일반 공지는 판매자도 소개광장 주소
3. ③ API — 한 건 200 · 다른 관 공지 404 · 판매자 아님 403
4. ④ 판매자 화면 — 31번째보다 오래된 공지를 `#n-<id>` 로 열면 「지난 공지」로 펼침 → 판매자 읽음 기록(bulk 아님)

## 4. 운영 적용

- 마이그레이션 D223 하나(260 → 261) — **RDS 스냅샷을 만듭니다.** 설정은 없습니다.
- 운영은 소개몰 입점(`mall.tenant`)이 꺼져 있어 판매자가 없으면 화면에 바뀌는 것이 없습니다. 판매자가 생긴 뒤 소개몰 공지를 「알림」을 켜고 등록하면 판매자 알림이 판매자센터로 갑니다.
- 되돌리기(rollback): 프로그램만 v10.306 으로 돌아가도 D223 함수는 남습니다. 그사이 판매자에게 간 알림 주소 `/health/seller/center/notices#n-…` 는 v10.306 에 없는 화면이라 열리지 않습니다(판매자 없으면 해당 없음).
