# 554. 품의 금액 지키기 (v10.417 · 2026-11-20)

## 1. 결론
매입 · 경비 청구에 **품의 번호**를 붙이고, 한 품의에 붙인 합계가 **품의 금액 × (1 + 허용 %)** 를 넘으면 DB 가 막습니다(REQ_OVER · 다시 품의).

| 항목 | 내용 |
|---|---|
| 칸 | acct_purchases.requisition_id · acct_expense_claims.requisition_id |
| 붙일 수 있는 품의 | 승인(APPROVED) · 쓰는 중(USED) — 승인 전 · 반려 · 취소는 REQ_STATE |
| 합계 | 매입 합계(취소 뺌) + 경비 금액(취소 · 반려 뺌) |
| 허용 % | acct.req_tolerance_pct(⑯ · 처음 10) |
| 처음 붙으면 | 품의 USED(⑯ used_* = 처음 붙은 것) |
| 바꾸기 | 한 번 붙인 품의 번호는 못 바꿈(REQ_LINK_FIXED · 취소하고 다시) |
| 쓴 돈 · 남은 돈 | v_acct_req_spend · 품의 목록 금액 칸 아래 |
| 화면 | 매입 넣기 · 경비 청구에 「품의」 고르기(남은 돈 표시) |

- ⑯ 「연결」(POST /admin/acct/requisitions/{id}/use)도 이제 매입 · 경비 쪽 품의 번호로 붙임(한도는 DB).
- 매입 가드 · 경비 가드의 「못 고치는 칸」에는 품의 번호가 없어 별도 가드가 지킴.

## 2. 시험 (test_v1417)
