## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 관 관리 › 페이지 목록 › 아래 표 「편집」 | 관 관리로 옮기지 않고 **그 자리에서 바로 편집**(관 관리 › 관 하나 › 「관 페이지」와 같은 편집 화면 · 블록 · 게시 · 예약 · 미리보기 · 판 기록 그대로) · 「← 페이지 목록」으로 돌아오면 목록을 다시 읽음 |
| 같은 표 「수정」 칸 | 수정 가능 · 불가 · SUPER 스위치(docs/809) |
| 편집 화면 맨 위 | 수정 가능 · 불가 표시 · SUPER 스위치 · 수정 불가면 「초안 저장」 · 「게시」 꺼짐 |
