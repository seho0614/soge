## 2. DB (D177)

1. 설정 `mall.order_open_until`(빈 값 · GLOBAL — 운영 화면 띠가 공개 설정으로 읽음)
2. `ops_alerts.resolved_at timestamptz` · `resolve_note text`(200자) · 색인 `ix_ops_alerts_unresolved`
3. `fn_ops_alert_mail_pending` · `fn_ops_alert_remail_pending` — 풀린 것 빼기 · 처음 보낼 종류에 `ORDER_OPEN_EXPIRED`(결과 모양 같음)
4. `fn_check_sla_alert` — 묶기 · 0건이면 풀림(등록자 안내는 그대로)
5. 이미 쌓인 알림은 고치지 않음 — 적용 뒤 첫 정기 작업(검수 기한은 1시간마다 `sla_alert`)이 원인이 없어진 것에 「풀림」 · 지우는 문장 없음 · 재실행 안전
