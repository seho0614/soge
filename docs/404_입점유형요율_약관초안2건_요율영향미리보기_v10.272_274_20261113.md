# 404. 입점 유형 요율 · 약관 초안 2건 · 요율 바꾸기 영향 미리보기 — v10.272 ~ v10.274 (2026-11-13)

> 대표 「다음개발」 → A · B · C 모두 · 요율 순서 「판매자 → 유형 → 갈래」 → 계획 「승인 + 통과하면 병합」(11/13).
> **마이그레이션 2개(243 → 245)** — D206(입점 유형 요율) · D207(약관 초안 2건 · 데이터만). v10.271(docs/402 · 403) 위에 만듦.
> 계획 때 바로잡은 것: 「처음 값 10%」로 두면 갈래 요율(건강기능식품 · 의료기기 12% · 운동 · 요양 8%)을 덮어써 지금 동작이 바뀜 → **처음엔 비워 둠**.

## 1. 바뀐 것

| 판 | 곳 (정확한 위치) | 내용 | 돕는 대표 할 일 |
|---|---|---|---|
| v10.272 | 운영 화면 맨 위 **소개몰** › 탭 **「소개몰 정산」** › 「수수료율」 제목 아래 **「입점 유형 요율」** 상자 | 브랜드 직영관(BRAND) · 일반 입점(TENANT) 기본 요율. 요율 고르는 순서 = **판매자 지정 → 입점 유형 → 갈래 → 기본(*) → 10%**. **처음엔 둘 다 비어 있음** — 비어 있으면 지금과 같이 갈래 요율. 바꾸기 ADMIN · SUPER · 사유 2자 이상 · 바꾼 기록(고치거나 지울 수 없음) · 감사 기록 `HLT_TYPE_RATE` · 새 주문부터(주문 때 요율을 박음) · 소개뱅크 직판관(DIRECT · 0%)은 해당 없음 · 추천 몫(referral_pct)은 갈래 기준 그대로 | 입점 약관 제17조 요율 2칸 → 정하면 여기 적음 |
| v10.273 | 운영 화면 맨 위 **관 관리** › 탭 **「약관」** | **입점 약관(HLT_SELLER) 1.0 초안** 본문을 docs/400 으로 · **처리방침(PRIVACY) 새 판 초안**(게시된 판 다음 번호 · 보통 1.1 · DRAFT · 시행일 비움) 본문 docs/401. **게시하지 않음** — 빈칸(입점 〔 〕% 2칸 · 처리방침 〔법령 근거〕 · 〔보관 근거 법령〕)이 있어 게시는 지금처럼 막힘. 운영에서 「고치기」로 이미 고친 입점 초안 · 이미 있는 처리방침 초안은 **덮어쓰지 않음**(apply 출력에 NOTICE) | 빈칸 채우고 「게시」 |
| v10.274 | 위 상자 · 같은 탭 갈래 요율 「바꾸기」 · **소개몰** › 탭 **「소개몰 판매자」** › 판매자 줄 「수수료율」 | 요율을 저장하기 전에 확인 창 — **최근 30일 결제된 실제 주문**(대기 · 취소 뺌)에 지금 요율 · 새 요율을 적용한 수수료와 차이. 순서상 그 칸이 실제로 쓰이는 주문 줄만 셈(판매자 요율이 있는 판매자는 유형 · 갈래를 바꿔도 그대로). **읽기만** — 「취소」면 아무것도 바뀌지 않음 | 요율 정할 때 |

판매자 목록의 요율이 비어 있는 줄은 「기본」 대신 **「기본(입점 유형 · 갈래)」** 로 보임.

## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `GET /admin/health/type-rates` | ADMIN · SUPER | 두 유형 요율(비면 null) · 판매 중 · 정지 판매자 수 · 판매자 지정 요율 있는 곳 수 · 바꾼 기록 수 |
| `PATCH /admin/health/type-rates/{sellerType}` | ADMIN · SUPER | `{rate, reason}` — rate 0 ~ 50 또는 null(비움) · 422 BAD_TYPE · REASON_REQUIRED · BAD_RATE · 409 SAME_RATE |
| `GET /admin/health/rate-impact?scope=…&key=…&rate=…` (scope SELLER · TYPE · CATEGORY) | ADMIN · SUPER | 읽기만 · `rate` 비우면 「비움」 · `{lines, orders, sales, recorded, nowFee, newFee, diff, days: 30}` · 기본 갈래(*) 422 |
