# 883. 운영자 2단계 인증 켜기 준비 — 이날부터 필수 · 등록 안내 (v10.775 · 2026-11-24)

## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 내 2단계 인증(SUPER) › 「이날부터 필수(예약)」 | 날짜(한국)를 넣으면 그날부터 admin.mfa_required 가 off 여도 운영 역할 모두(ALL)로 봄 · 비우면 예약 없음 · 넣는 사람이 먼저 등록해야 함(MFA_ENROLL_FIRST · 켜기와 같음) |
| 같은 상자 「등록 안 한 운영자에게 알림」 | 등록 안 한 운영 역할 계정마다 내 알림 한 통(MFA_ENROLL_REMIND · 하루 한 번 · 예약 날짜가 있으면 적음) · 운영 알림 INFO 한 줄 |

- **이미 있던 것(v10.180 · 236 · 266)**: 등록 · 켜기 전 점검(등록 안 한 사람 목록) · 켜는 순서 3단계 — 이번에는 「날짜 예약」과 「알림 보내기」만 더함.
- 설정 admin.mfa_from 은 「중요 설정 바뀜」 알림 목록(D193 · D195 트리거)에는 넣지 않음 — 바꾼 기록(site_setting_changes)에는 남음.
- 기본 동작은 그대로(비어 있으면 전과 같음).
