## 1. 결론

1. **오픈 날 켜는 22단계를 운영 화면 API 로 순서대로 켰을 때 모두 통과**했습니다(지키는 규칙을 그대로 거침). 소개비 스위치는 기대대로 본인인증 · 계좌인증 LIVE 전에 **막혔습니다**.
2. 간주 모드 4개를 끄고 · 알림톡 · 전자계약 · 안심번호 · AI 를 모두 켠 상태에서 흐름 시험과 화면 돌기를 돌렸습니다 — **고장 1건(카드 등록) 발견 · 이번 판에서 고침**. 나머지는 시험 환경 특성이었습니다.
3. 업체 응답이 있어야 갈 수 있는 값(LIVE · NICE · HTTP)을 DB 에 넣으면 **오픈 차단은 1건 — 파트너 이용약관 미게시**만 남습니다(이미 아는 항목 · terms-publishing 미정 2).
4. 오픈 날 **켜는 순서가 중요한 곳이 3군데** 있습니다(4절 순서표에 반영) — 세금계산서 간주 끄기 · 본인인증 NICE · 메일 보내는 주소.
