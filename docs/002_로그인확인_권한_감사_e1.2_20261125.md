# 002. ERP 로그인 확인 · 권한 · 감사 기록 — e1.2 (2026-11-25)

## 1. 결론

- ERP 는 비밀 키를 갖지 않습니다. 화면이 낸 **소개뱅크 운영자 증표**를 소개뱅크 `GET /auth/introspect`(v10.799)에 물어 확인합니다 — 증표마다 **60초 기억**.
- 모든 길에 전역 가드(`ErpAuthGuard`) · `@Public()` 만 뺌(건강 확인 · 로그인 넘겨받기).

| 판정 | 결과 |
|---|---|
| 로그인 아님 · 증표 무효 | 401 `UNAUTHENTICATED` |
| 운영자 아님(회원) | 403 `ERP_NOT_STAFF` |
| 2단계 인증 · 패스키 확인 전 | 403 `MFA_REQUIRED` |
| SUPER | 늘 통과(2026-10-21 결정) |
| 소개뱅크 판정이 GROUPS(권한그룹) 또는 권한 걸기 ON | `@Task('acct', 'VIEW')` 의 업무 권한이 목록에 있어야 |
| 그 밖(ROLE 판정 · 지금) | `@Roles` 의 운영 역할(없으면 ADMIN) 또는 업무 권한 |
| 소개뱅크 연결 실패 / 서비스 토큰 틀림 | 503 `ERP_SGB_DOWN` / `ERP_SGB_TOKEN` |

- 로그인 넘겨받기 `POST /api/v1/auth/handoff {code}` → 소개뱅크 `POST /internal/erp/handoff/redeem`(v10.800) → 증표 · 감사 `ERP_LOGIN`.
- 내 정보 `GET /api/v1/me`.
- E002 `erp_audit`(쌓기만 — 고치기 · 지우기 트리거가 막음 · 계정 번호는 외래 키 없음).
- 설정(ERP 서버 .env): `SGB_API_URL` · `SGB_SERVICE_TOKEN`(소개뱅크 운영 화면 › 외부 연동 › ERP 연동 「토큰 만들기」).
