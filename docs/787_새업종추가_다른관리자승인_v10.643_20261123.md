# 787. 새 업종 추가 — 「승인 대기」로 만들고 다른 관리자가 승인 — v10.643 (D308 · 2026-11-23)

## 1. 결론

- 11/23 대표 「업종을 해당 관에 배정하는 화면」 → 그런 화면이 없었습니다. 운영 화면은 **승인 대기 업종을 승인 · 반려**만 할 수 있었고, 업종은 마이그레이션으로만 늘었습니다. 새 관 만들기 안내 글(「업종 승인 화면에서 붙입니다」)과도 맞지 않았습니다.
- 대표 「모두 반영」 · 「다른 사람이 승인」 → 이번 판부터
  1. **업종 › 업종 승인 › 「새 업종 추가」** — 관 · 업종 코드 · 이름 · 직업안정법 판정 · (메모 · 소개비 부담 주체 · 안심소개 축 · 제한업종)을 넣으면 **「승인 대기」** 로 만듭니다(ADMIN · SUPER · 감사 `CATEGORY_CREATE`).
  2. **만든 사람은 그 업종을 승인할 수 없습니다** — 다른 관리자가 승인합니다(DB 가 막음 · 422 `CATEGORY_SAME_PERSON`). 마이그레이션으로 넣은 옛 업종(만든 사람 없음)은 그대로입니다.
  3. **허브 관 · 소개리드에는 업종을 넣지 않습니다**(422 `CATEGORY_GWAN_NOT_ALLOWED`) — docs/786.
  4. **관은 만든 뒤 바꿀 수 없습니다**(422 `CATEGORY_GWAN_LOCKED`) — 매물 · 검수 · 정산이 관에 딸립니다. 다른 관에는 새로 만듭니다.
  5. 승인 칸에 **소개비 부담 주체** 고르기를 더했습니다 — 오픈 점검 「소개비 부담 주체 지정」을 화면에서 맞출 길이 생겼습니다.

## 3. 쓰는 순서 (운영 화면)

1. 관리자 A — 업종 › 업종 승인 › 「새 업종 추가」 펼침 → 관 · 코드 · 이름 · 직업안정법 판정(등록 대상이면 승인 불가) · 부담 주체 → 「승인 대기로 만들기」.
2. 관리자 B(다른 사람) — 같은 화면 「승인 대기」 줄에서 직업안정법 판정 · 부담 주체 확인 → 「승인」.
3. 관 설정 › 오픈 점검에서 「업종 1종 이상 승인」 · 「소개비 부담 주체 지정」이 통과인지 봅니다.

- 운영 관리자가 한 사람뿐이면 승인할 수 없습니다 — 운영 관리자는 지금 2명입니다(11/23 postcheck).
