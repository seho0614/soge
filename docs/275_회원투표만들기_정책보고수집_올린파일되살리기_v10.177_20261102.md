### 정책 「보고만 하기」 내용
`default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https:; media-src 'self' blob: https:; font-src 'self' data:; connect-src 'self'; frame-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; report-uri /api/v1/csp-report`
— 그림 · 영상은 https 어디서나 허용(상품 그림 등이라 보고가 넘침). 1 ~ 2주 모은 뒤 실제 쓰는 출처(카카오 지도 · 결제창 등)를 넣어 **막는 정책으로 바꿀지 대표 결정**.

## 4. 운영에서 (적용 뒤)
1. 회원 투표는 **꺼진 채로** 들어감 — 켜기는 운영 화면 › 소개광장 › 「이건 어때? 투표」 › 「회원이 투표 만들기 · 켜기」(대표 결정 · 오픈 뒤 권함)
2. 정책 보고는 적용 즉시 모임 — 「지켜보기」 「정책 보고(24시간)」 · 많이 걸린 출처를 1 ~ 2주 보고 알려 주시면 막는 정책 판을 만듦
3. 되살리기 — `bash ~/sgb/deploy/aws/uploads-restore.sh`(목록) · 파일 하나 `… file latest 2026/11/a.jpg` · 통째로 `… extract latest` 뒤 눈으로 확인하고 `cp -n -r` 로 옮김

## 5. 넣지 않은 것
- 회원 투표의 그림 · 비교해요(VS) — 남의 그림 · 상표 비교 분쟁 위험
- 정책을 실제로 막기(Content-Security-Policy) — 보고를 모은 뒤 판단
- 정책 보고 DB 저장 — 메모리 24시간으로 충분(API 를 다시 띄우면 비워짐)
