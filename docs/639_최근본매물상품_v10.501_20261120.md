# 639. 최근 본 매물 · 상품 (v10.501 · 2026-11-20)

> 대표 11/20 「지금 바로 동시 착수」 ㊸ 회원 2 의 ①. 마이그레이션 D273(#311 · 640 ~ 642 와 한 파일). 스위치 `mbx.recent` **처음 off**.

## 1. 결론
매물 상세 · 소개몰 상품 상세를 열면 **최근 본 목록**에 남깁니다. **로그인 회원은 서버**(사람마다 20개 · 90일), **로그인 전은 이 브라우저(localStorage)에만** — 서버로 보내지 않습니다. 로그인하면 이 브라우저의 것을 한 번 합칩니다. 화면 `/recent`(SB-HOM-MBX-010 · 로그인 전후 같은 화면). 켜기 전 **처리방침 「서비스 이용 기록」** 게시가 먼저입니다(4절 · 법무 확인).

## 2. 동작
| 항목 | 규칙 |
|---|---|
| 적는 때 | 상세 화면 아래 줄(`MbxItemTools`)이 열릴 때 한 번 — 로그인 `POST /me/recent` · 로그인 전 localStorage `sgb_mbx_recent` |
| 적지 않는 것 | 내 매물 · 게시 중이 아닌 매물 · 판매하지 않는 상품 · 스위치 off(saved=false · 오류 아님) |
| 개수 | `mbx.recent_max`(20 · 5 ~ 50) — 넘으면 **DB 트리거**(`trg_mbx_recent_trim`)가 오래된 것부터 지움 · 같은 것은 시각만 새로 · 본 횟수 +1 |
| 보관 | `mbx.recent_keep_days`(90 · 7 ~ 365) 지나면 매일 04:35 `mbx_daily` 가 지움 · **탈퇴(WITHDRAWN) 회원 것도 지움** · 스위치를 꺼도 정리는 돎 |
| 합치기 | `POST /me/recent/merge` — 최대 `mbx.recent_max` · 미래 · 보관 기간 밖 시각 · 없는 것은 건너뜀 · 서버에 있으면 더 늦은 시각만 |
| 지우기 | 하나 `DELETE /me/recent/{type}/{key}` · 모두 `DELETE /me/recent` · 로그인 전은 브라우저에서 |
| 내려간 것 | 목록에 「(내려간 매물 · 상품)」 — 눌러도 열리지 않음(제목 · 금액 안 보임) |

## 3. 표 · API · 설정
| 표 | 내용 |
|---|---|
| `mbx_recent_views` | 회원 · 대상(LISTING · PRODUCT) · 대상 번호 · 본 때 · 본 횟수 — 회원 · 대상 고유 |

| API | 권한 |
|---|---|
| GET /site/mbx/switches | 공개(스위치만 · 개인정보 없음) |
| GET · POST · DELETE /me/recent · POST /me/recent/merge · DELETE /me/recent/{type}/{key} | 회원(MEMBER · BIZ_OWNER · BIZ_STAFF) |

설정: `mbx.recent`(off) · `mbx.recent_max`(20) · `mbx.recent_keep_days`(90) — 운영 화면 **회원 › 회원 편의 기능**(SB-ADM-MBX-010 · 바꾸기 SUPER · 사유).
