# 475. 리드관 경고를 운영 알림으로 (v10.342 · 2026-11-17)

> 대표 11/17 「다음개발」 → ③ 리드관 경고를 운영 알림으로(docs/473 머리말의 네 가지 중 셋째) · 「승인 + 통과하면 병합」. 마이그레이션 **D232**(269 → 270 · 스냅샷 필요).

## 1. 왜

- v10.338 「리드 현황」은 운영자가 화면을 열어야 보입니다. 리드관을 켠 뒤 받을 업체가 없는 업종에 신청이 오면 소비자는 기다리기만 하고, 운영자는 모릅니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D232** | 함수 `fn_lead_alert()` — **리드관(LED)이 켜져 있을 때만** ① 공개 상담 업종(안심소개 상담 축 · 정액 노출형 뺌) 중 받을 인증 업체 0곳 → 운영 알림 `LEAD_NO_PARTNER`(WARN · 업종 이름 목록) ② 24시간 안 「받을 업체 없음」 신청 3건 이상 → `LEAD_UNDELIVERED`(**CRITICAL** — 급한 알림 메일 · 텔레그램 · 슬랙 길 그대로). 같은 알림이 열려 있으면 숫자만 고치고, 원인이 없어지거나 리드관을 끄면 풂. 지우는 문장 없음 |
| 정기 작업 `sla_alert`(매시간) | 검수 · 1:1 문의 기한과 함께 `fn_lead_alert()` 를 부름(새 작업 없음) |
| 운영 화면 **위험감지 › 「운영 알림」** | 한국어 이름 「리드관 받을 업체 없는 업종」 · 「리드관 상담 신청 전달 못 함」 |

- 리드관이 꺼진 동안(지금 운영)은 알림이 생기지 않습니다.
- 알림을 받으면 **파트너사 › 파트너 › 「리드 현황」**에서 업종을 보고, 입점 신청 · 인증 심사 › 자격 심사로 업체를 늘립니다.
