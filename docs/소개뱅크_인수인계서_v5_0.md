## 3-2. 처음 받았을 때

```bash
unzip sgb-integrated-kit.zip && cd sgb
npm install          # 3~5분
npm run local        # DB · 스키마 · 시드 · 계정을 한 번에
```

**로그인 계정**

```

회원     seed1@seed.local / sgb-dev-1234
```

## 3-3. ★ 반드시 알아야 할 것 다섯

### ① 검정을 통과하지 못하면 배포하지 마십시오

```bash
npm run deploy:check      # 이것 하나가 8부를 다 봅니다
```

**"배포 가능"이 안 나오면 올리지 마십시오.**

### ② 마이그레이션은 고치지 말고 새로 만드십시오

```
이미 적용된 SQL 을 고치면 변경 감지가 막습니다.
```

**정당한 방어입니다.** 운영 DB 와 어긋나는 것을 막습니다.

### ③ `npm run attack` 은 시드를 날립니다

```bash
# 공격 시험 뒤 로그인 실패 시
node scripts/seed-realistic.js
node scripts/seed-dev-passwords.js
```

**반드시 겪습니다.** 당황하지 마십시오.

### ④ 한글에서 pg_trgm 이 안 통합니다

```sql
SELECT show_trgm('카페');   -- []  빈 배열
SELECT similarity('franchise','francise');  -- 0.58  영문은 됨
```

오타 교정은 **`fuzzystrmatch` 의 levenshtein** 으로 합니다.
이걸 모르고 pg_trgm 을 쓰면 **안 도는데 검정은 통과**합니다.

### ⑤ 48KB 응답은 「없는 화면」입니다

시안에서 주소를 시험할 때

```
48KB 대  →  없는 화면 안내
50KB 이상 →  진짜 화면
```

**주소가 틀려도 200 이 나옵니다.** 크기로 판단하십시오.

# 8부. 용어와 코드 — Glossary and Code Prefixes

| 접두어 | 읽는 법 | 무엇 | 예 |
|---|---|---|---|
| `INV-` | Invariant | **불변식** — 절대 깨지면 안 되는 규칙. 깨지면 배포가 막힙니다 | `INV-9` |
| `RSK-` | Risk rule | **위험감지 규칙** — 의심스러운 것을 찾아 경보를 냅니다 | `RSK-05` |

| `A-` | Action | **실행 항목** — 사람이 해야 할 일 | `A-07` |
| `T-` | Task | **막힌 일** — 본사가 열어 줘야 진행됩니다 | `T-01` |
| `R-` | Rule | **운영 규칙** — 검수·반려 기준 | `R-05` |
| `G-` | Governance | **정책** — 알림·공개 범위 등 | `G-03` |
| `C` + 숫자 | Change (migration) | **마이그레이션 번호** — DB 변경 순서 | `C930` |
| `CT`·`CU`·`CV`·`CW` | Check group | **검정 묶음** — 공격 시험의 분류 | `CT-01` |

## 8-2. 자주 나오는 말 — Common Terms

| 우리말 | 영문 | 뜻 |
|---|---|---|
| 관 | Vertical | 소개머니·소개몰·소개창업·건강몰 — 성격이 다른 네 영역 |
| 소개비 | Referral fee | **소개한 사람이 받는 돈.** 회사 몫이 아닙니다 |
| 리드 이용료 | Lead fee | 소개를 받은 업체가 회사에 내는 돈 |
| 제휴 수수료 | Affiliate commission | 파트너가 판 것에서 나오는 회사 몫 |
| 귀속 | Attribution | 이 거래가 누구의 소개인지 정하는 것 (90일) |
| 간주 모드 | Assume mode | 연동 전에 **"됐다고 치고"** 넘기는 것 |
| 검정 | Gate / Check | 배포 전에 자동으로 돌리는 확인 |
| 불변식 | Invariant | 절대 깨지면 안 되는 규칙 |
| 감시 뷰 | Watch view | **결과가 0이어야 정상**인 DB 뷰 |
| 오탐 | False positive | 위험이 아닌데 경보가 뜬 것 |
| 세그먼트 | Segment | 관심사로 나눈 회원 묶음 (SEG-A ~ SEG-F) |
| 어휘집 | Vocabulary | 분류에 쓰는 단어와 점수 |
| 시안 | Prototype | 화면만 있는 HTML 파일 |
| 킷 | Kit / Package | 서버 코드 전체 압축본 |

## 8-3. ★ 헷갈리기 쉬운 것 — Easily Confused

```
소개비   Referral fee      소개한 사람이 받습니다 — 회사 몫 아님
리드료   Lead fee          회사가 받습니다
```

**이 둘을 섞으면 INV-9 가 깨집니다.** 소개비에서 수수료를 떼면 안 됩니다.

```
중개만   Broker only       하자·환불 책임 없음 (소개머니·소개몰·소개창업)
직판     Direct seller     ★ 책임 있음 (건강몰)
```

**건강몰만 회사가 파는 사람입니다.**

# 10부. 인계하는 사람이 남기는 말 — Notes from the Outgoing Team

## 10-1. 가장 중요한 것 — The One Thing

```
기능을 더 만들지 마십시오. 외부 연동을 신청하십시오.
```

프로그램은 충분합니다. **한 달째 신청이 안 되어 못 여는 중**입니다.

## 10-2. 검정을 믿으십시오 — Trust the Gates

개발하는 동안 검정이 여덟 번 잡았습니다.

| 무엇 / What was caught | 왜 정당했나 / Why the gate was right |
|---|---|
| 소개비에서 수수료 공제<br><sub>Commission deducted from referral fee</sub> | INV-9 |
| 남의 돈 보관 | INV-11 |
| 적용된 마이그레이션 수정 | 운영 DB 와 어긋남 |
| 10만 건에서 느린 뷰 | 30건으로는 안 보임 |
| 약관 시행일 원복 | 한 곳만 고치면 되돌아감 |
| 광고 만료 임박 | 시드 날짜가 지나감 |
| 정상 단어를 오타로 교정 | 사전 40개 넣고서야 보임 |
| **한글 pg_trgm 무효** | **설계서 방법이 틀렸음** |

**"검정이 까다롭다" 고 느슨하게 만들지 마십시오.** 이것이 돈과 법을 지킵니다.

## 10-3. 작은 것이 큰 것을 막습니다 — Small Things Block Big Ones

```
start 스크립트 한 줄이 없어 AWS 에서 서버를 못 띄울 뻔했습니다.
```

**절차서대로 한 번 끝까지 해 보십시오.** 머리로 하면 이런 게 안 보입니다.
