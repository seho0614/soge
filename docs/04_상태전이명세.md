# 소개뱅크 — 상태 전이 명세 v1

**자동 생성** · 전이는 **도메인 서비스 한 곳에서만** 일어납니다. 컨트롤러에서 `status = ...` 를 쓰지 않습니다.

## `listing.status` — 매물

테이블 `listings`

| From | To | 조건 |
|---|---|---|
| DRAFT | **IN_REVIEW** | 제출 |
| IN_REVIEW | **PUBLISHED** | 승인 (자동 또는 수동) |
| IN_REVIEW | **REJECTED** | 반려 — 사유 코드 필수 |
| REJECTED | **IN_REVIEW** | 재제출 |
| PUBLISHED | **IN_REVIEW** | 수정 (version+1, 배지 회수) |
| PUBLISHED | **SUSPENDED** | 노출 중단 · 제한업종 지정 · 슬롯 초과 |
| SUSPENDED | **PUBLISHED** | 재개 |
| SUSPENDED | **ARCHIVED** | 보관 |

**불변 조건**

- INV-6 제한업종은 PUBLISHED 전이 시 차단
- 슬롯 초과 시 PUBLISHED 불가 (B-13R2)

## `deal.status` — 거래

테이블 `deals`

| From | To | 조건 |
|---|---|---|
| INQUIRY | **NEGOTIATING** | 조건 협의 시작 |
| NEGOTIATING | **CONTRACTED** | 계약서 발급 (합의 LOCKED) |
| CONTRACTED | **PAYMENT_REPORTED** | 대금 지급 신고 |
| PAYMENT_REPORTED | **CONFIRMED** | 양측 서명 → 자동 확정 (A-15) |
| PAYMENT_REPORTED | **CONFIRMED** | 7일 무응답 자동 확정 (B-01) |
| CONFIRMED | **SETTLED** | 정산 지급 완료 |
| CONFIRMED | **DISPUTED** | 분쟁 접수 |
| INQUIRY | **CANCELLED** | 취소 |
| NEGOTIATING | **CANCELLED** | 취소 |
| CONTRACTED | **CANCELLED** | 취소 |

**불변 조건**

- INV-4 CONFIRMED 는 deal_confirmations 2행 필수
- INV-2 CONFIRMED 시 귀속 스냅샷 확정
- INV-1 tier=1 고정
- CONFIRMED 이후 CANCELLED 불가

## `settlement.status` — 정산

테이블 `settlements`

| From | To | 조건 |
|---|---|---|
| — | **REQUESTED** | 성사 확정 시 자동 신청 |
| REQUESTED | **APPROVED** | 관리자 승인 |
| APPROVED | **PAID** | 주 1회 수요일 배치 |
| REQUESTED | **HELD** | 분쟁 접수 (B-11 자동) |
| APPROVED | **HELD** | 분쟁 접수 |
| HELD | **APPROVED** | 분쟁 해소 |
| REQUESTED | **REJECTED** | 반려 |

**불변 조건**

- INV-3 CONFIRMED 이후에만 생성
- INV-9 amount = agreed_fee
- INV-10 사업자로 받으면 인증된 사업자 · INV-10R 개인으로 받으면 본인인증 + 확인된 받을 계좌

## `review.status` — 검수

테이블 `review_items`

| From | To | 조건 |
|---|---|---|
| — | **QUEUED** | 개입 사유 있음 |
| — | **APPROVED** | 개입 사유 없음 → 자동 승인 |
| QUEUED | **IN_PROGRESS** | 담당 배정 |
| IN_PROGRESS | **APPROVED** | 승인 |
| IN_PROGRESS | **REJECTED** | 반려 — 사유 코드 필수 |
| QUEUED | **APPROVED** | 승인 |
| QUEUED | **REJECTED** | 반려 |

**불변 조건**

- SLA 24시간
- 반려 시 reject_reason_code NOT NULL
- 자동 승인 건은 5% 표본 감사

## `badge.status` — 매물 배지

테이블 `listing_badges`

| From | To | 조건 |
|---|---|---|
| — | **REQUESTED** | 신청 |
| REQUESTED | **IN_REVIEW** | 검수 큐 적재 (전건 수동) |
| IN_REVIEW | **GRANTED** | 승인 → 노출 반영 |
| IN_REVIEW | **REJECTED** | 반려 |

**불변 조건**

- 급구 최대 14일 · 동시 3건
- 매물 version 변경 시 REVOKED
