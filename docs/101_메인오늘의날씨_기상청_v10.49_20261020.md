## 2. 구조

```
사용자 웹 page.tsx ── GET /weather/today?region=(쿠키) · 10분 캐시 ──▶ API WeatherService
                                                                        │ 발표 시각 × 격자마다 한 번만
                                                                        ▼

운영 화면 › 외부 연동 › 날씨 키 ── GET · PATCH /admin/weather · PUT · DELETE /admin/weather/key · POST /admin/weather/test (SUPER)
```

| 파일 | 내용 |

| `src/modules/weather/weather.service.ts` | 스위치 · 키(운영 화면 먼저, 없으면 .env) · 캐시 · 화면 값 만들기 · 운영 기능 |
| `src/modules/weather/weather.controller.ts` | 공개 1 · 운영 5 API |
| `site/src/components/home/Weather.tsx` | 한 줄 띠 · 지역 고르기 |
| `web/src/app/admin/WeatherKeys.tsx` | 운영 화면 › 외부 연동 › 날씨 키 |

### 호출 수 · 실패
- 지역 하나에 하루 최대 실황 24 + 예보 8 + 최저 · 최고 1 = **33번**. 17곳을 다 보여도 약 560번입니다. 개발계정 한도(1만 회로 알려져 있음 — 신청 화면에서 확인 필요) 안입니다.
- 실패하면 그 지역은 2분 동안 다시 부르지 않습니다. 직전에 받은 값이 있으면 그 값을 쓰고, 「N시 기준」으로 시각을 보입니다.
- 3초 안에 답이 없으면 실패로 봅니다(`KMA_TIMEOUT_MS`).
- 응답 코드: 00 정상 · 03 자료 없음(한 시간 전 자료로 다시) · 22 한도 초과 · 30 · 31 · 32 키 문제.

## 4. 대표님이 하실 일 (키 받기)

1. 공공데이터포털(data.go.kr) 로그인 → 「기상청_단기예보 ((구)_동네예보) 조회서비스」 → **활용 신청**(개발계정 · 보통 자동 승인)
2. 마이페이지 › 활용 신청 현황 › 그 서비스 › **일반 인증키(Decoding)** 복사. 채팅 · 메일에 붙이지 않습니다.
3. 집 PC 운영 화면(5173) › 사이트 › 외부 연동 › 맨 아래 「날씨 키」에 붙여 넣기 → 저장
4. 「시험 호출」 → 「기상청 호출 성공 — 서울 지금 N°C」. 신청 직후에는 키 반영까지 시간이 걸릴 수 있습니다(AUTH 로 나오면 1시간쯤 뒤 다시).
5. 「날씨 사용 켜기」 → 메인 새로고침(최대 10분 캐시)
