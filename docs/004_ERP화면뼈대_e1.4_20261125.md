# 004. ERP 화면 뼈대 — e1.4 (2026-11-25)

## 1. 결론

- `web/` — Vite · React 18 · 디자인 시트(`sgb-tokens.css` · `sgb-buttons.css` 를 소개뱅크 운영 화면에서 복사 · 색 · 글자 · 모서리는 토큰만).
- 흐름: 소개뱅크 운영 화면 › 외부 연동 › ERP 연동 › **「ERP 열기」** → 새 창 `ERP_WEB_URL/#/handoff?code=…` → 화면이 코드를 주소에서 지우고 `POST /api/v1/auth/handoff` → 증표를 **sessionStorage 에만**(창 닫으면 사라짐) → `GET /me` → 메뉴.
- 메뉴: 회계 · 세무(E3) · 인사 · 급여 · 사무(E4) · 그룹웨어(E4G) · 영업 · 구매 · 무역 · 품질 · 법무 · 자산(E5) — 지금은 「준비 중」 · **정기 작업**(e1.3)만 실제 화면.
- 로그인 없이 열면 「운영 화면에서 ERP 열기로 들어오십시오」.
- 점검판 포트 15175(e1.5) · 판 번호 e1.4.
