# 655. 메인 팝업 공지 (v10.517 · 2026-11-20)

## 1. 결론
사용자 웹 메인에 **팝업 공지**를 띄웁니다. 운영자가 **기간 · 대상(비로그인 · 회원 · 파트너) · 순서**를 정하고, 처음에는 **꺼진 채** 만들어 미리 본 뒤 켭니다. 여러 개면 순서대로 **하나씩**(「다음」 · n / 전체) 보이고, 회원은 **「오늘 하루 안 보기」**로 그 팝업을 오늘만 숨깁니다(그 브라우저에만 적힘 · 서버 기록 없음 — v10.326 메인 공지 띠와 같은 방식).
위치: 운영 **노출 › 메인 팝업**(SB-ADM-PRX-010) · 사용자 웹 메인(SB-HOM-PRX-010) · API `GET /popups` · `/admin/prx/popups`.

## 2. 규칙
| 항목 | 규칙 |
|---|---|
| 대상 | GUEST 로그인 안 함 · MEMBER 로그인 회원 · PARTNER 안심소개 · 제휴 파트너 활동 중 — 판단은 DB `fn_prx_popup_audience`(공지 등급 `fn_notice_grades` D210 를 그대로 씀) · 하나라도 맞으면 보임 |
| 기간 | 시작 ≤ 지금 < 끝 · 최대 1년(DB CHECK) |
| 순서 | priority 작은 것 먼저 → 시작 늦은 것 · 한 번에 `prx.popup_max`(처음 3 · 1 ~ 5)개까지 서버가 보냄 |
| 켜기 | 처음 꺼짐 · 끝 시각 지난 팝업은 켤 수 없음(409 PRX_POPUP_ENDED) |
| 단추 | 주소는 `/` 로 시작하는 사이트 주소 또는 `https://` 주소만(서버 정규식 = DB CHECK) · 바깥 주소는 새 창 |
| 글 | 글자 그대로(HTML 아님) · 1,000자 |
| 오늘 하루 안 보기 | localStorage `sgb.homePopupHide` = { 한국 날짜 · 숨긴 번호들 } · 날짜가 바뀌면 다시 보임 · 저장소를 못 쓰면 이번 화면에서만 |
| 닫기 · Esc | 이번 화면에서만 닫음(다음 팝업으로) |

## 3. 표 · API
| 표 · 함수 | 내용 |
|---|---|
| `prx_popups` | 제목 · 글 · 단추 주소 · 이름 · 대상 · 기간 · 순서 · 켜짐 · 만든 · 고친 사람 |
| `fn_prx_popup_audience(계정)` | 보는 사람의 대상 배열 |

| API | 권한 | 설명 |
|---|---|---|
| GET /popups | 누구나 | 지금 보일 것(보는 사람 기준 · 캐시 안 함) |
| GET /admin/prx/popups | ADMIN · SUPER | 모두 · 지금 보이는지 |
| POST /admin/prx/popups | 〃 | 만들기(꺼진 채) · 형식 400 · 422 |
| PUT /admin/prx/popups/{id} | 〃 | 고치기 |
| POST /admin/prx/popups/{id}/toggle | 〃 | 켜기 · 끄기 · 끝난 팝업 409 |

## 4. 화면
- 운영: 입력 칸 바로 아래 **미리 보기**(사용자 웹 모양) · 목록(보이는 중 · 켜짐(기간 밖) · 꺼짐) · 고치기 · 켜기/끄기.
- 사용자 웹: `site/src/components/home/HomePopups.tsx`(page.tsx 가 `GET /popups` 를 다른 조회와 함께 시작) · 디자인 값은 sgb-tokens 토큰만(`styles/popup.css`) · 누름 44px · 640px 아래 여백 줄임. 사전 `main.popup`(ko · en · 글자 값만).

## 5. 처리방침 고칠 곳
- 새로 모으는 개인정보 **없음** — 「오늘 하루 안 보기」는 회원 브라우저 저장소에만 적고 서버로 보내지 않습니다(누가 닫았는지 모름). 대상 판단은 이미 있는 로그인 · 파트너 상태를 그 자리에서 읽기만 합니다.
- 처리방침의 「쿠키 · 브라우저 저장」 줄에 「화면 설정(공지 숨김 등)을 이 기기에만 저장」 문구가 있는지 **법무 확인 권함**(공지 띠 v10.326 과 같은 쓰임 — 없으면 한 줄 더함).
