## 3. 규칙

| 규칙 | 지키는 곳 |
|---|---|
| 한국어는 원문 — 끌 수 없고 번역 줄도 없음 | 트리거 `trg_i18n_lang_guard` · 제약 `content_translations_not_ko` · API 409 |
| 원문이 고쳐지면 번역은 낡음 → 승인 안 됨(손님 화면에도 안 나감 · 3단계) | 뷰 `is_stale`(md5 비교) · 승인 API 409 `TRANSLATION_STALE` |
| 원문이 없어지면 승인 안 됨 | `source_missing` · 409 `SOURCE_MISSING` |
| 번역문에 차단 금칙어가 있으면 승인 안 됨 | `fn_check_banned_words(번역문, 원문의 관)` · 422 `BANNED_WORD` |
| 반려는 사유 2자 이상 · 감사 기록에 사유 | 제약 `content_translations_reject_reason` · 답에 `reason` |
| 넣거나 고치면 다시 승인 대기 | 넣기 API 가 `DRAFT` 로 되돌림 · 원문 해시 새로 |
| 받는 대상 · 칸 | 공지(제목 · 본문) · 자주 묻는 질문(질문 · 답) · 약관(제목 · 본문 · 번호 `code@version`) · 매물 · 요청 · 소개광장 글(제목 · 본문) · 댓글(본문) |
