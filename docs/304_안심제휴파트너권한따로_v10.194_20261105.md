# 304. 안심 파트너 · 제휴 파트너 권한 따로 관리 — v10.194 (2026-11-05)

> 대표 지시: 「파트너 권한 부여 — 안심 파트너와 제휴업체 파트너 권한 따로 관리」 → 물음에 **「둘 다」**(운영자 역할 · 회원 자격) · **「ADMIN 은 둘 다 유지」** → 계획 **「승인」**.
> 마이그레이션 **1개(D173 · 210 → 211)** — 운영 적용 때 **스냅샷 필요**.

## 1. 전에는

| 항목 | 내용 |
|---|---|
| 운영자 | 파트너 승인 · 관리는 **ADMIN 하나가 두 쪽 다**(안심소개 운영 API 6묶음 · 제휴 14개). 일부만 맡길 역할이 없었음 |
| 회원 | `partners` 한 줄을 안심소개 파트너센터(/partner)와 제휴 파트너센터(/partners)가 같이 씀 — **한쪽에서 승인하면 두 센터가 함께 열림** · 따로 정지할 수 없음. 제휴 신청 API 도 따로 없었음(입점 신청이 곧 제휴 신청) |
| 권한 주기 | 운영 화면 「권한」에 **주는 칸이 없었음**(회수만) · 권한 변경 기록에 PAYOUT 이 빠져 있었음 |

## 2. 운영자 역할 2개 (D173 · 서버 · 운영 화면)

| 역할 | 화면 이름 | 할 수 있는 것 | 못 하는 것(ADMIN 만) |
|---|---|---|---|
| `PARTNER_MAL` | 안심 파트너 담당 | 운영 화면 › 파트너사(목록 · 상세 · 입점 심사 · 서비스 검수 · 리드 반려 기각 · 리드 이용료 보기) · 안심소개 입점 심사 · 법률 · 세무 정액 노출 · 인증 · 자격 심사(공인중개사 포함) | 리드 충전 조정 · 자동 충전 실행 · 리드 이용료 계산서 만들기 · 발행 · 등급 · 보너스 규칙 · 이용료 무효(직접 · 반려 인정) · 정액 노출 계산서 발행 |
| `PARTNER_AFF` | 제휴 파트너 담당 | 운영 화면 › 제휴(입점 심사 · 제휴 파트너 현황 · 제휴상품 · 단가 · 목표 · 마케팅자료 · 가이드) | 트랙별 정산(조회 · 실행 — 탭이 안 보임) |

1. ADMIN · SUPER 는 그대로 두 쪽 다.
2. **PAYOUT 과 함께 가질 수 없음** — 승인하는 사람과 돈을 보내는 사람을 나눔(C710 · `fn_duty_separation` · `v_duty_conflict` · 권한 계층 화면 · 운영 점검 「지급 담당이 운영 역할도 가짐」). SUPER 는 예외(전과 같음).
3. 운영 역할로 다룸: 2단계 인증 대상 · 권한 정기 점검 · 권한 변경 기록(사유 · 처리자 — PAYOUT 도 이제 남음) · 권한 보유자 목록 · 운영자 계정 재설정 링크 금지 · 요청 한도 · 새 회원 매물 상한 예외 · 감사 기록 「운영」 거르기.
4. 파일 열람 — 안심 담당은 중개 서류 · 파트너 사진(BROKER_DOC · PARTNER_MEDIA), 제휴 담당은 홍보 자료 · 안내(MARKETING_MATERIAL · PARTNER_GUIDE)만.
5. 운영 화면 — 메뉴는 맡은 쪽만(홈 · 내 2단계 인증 포함) · 홈은 「안심/제휴 파트너 담당 계정입니다」 안내와 바로가기 · **「권한 › 권한 보유자」에 「역할 주기」 칸**(이름 · 이메일로 찾기 → 역할 · 사유 → 주기 · SUPER 만) · 역할 이름을 우리말로.

## 3. 회원 파트너 자격 분리 (D173 · 서버 · 사용자 웹)

| 항목 | 내용 |
|---|---|
| 칸 | `partners.status` = **안심소개 자격**(그대로) + 새 값 `NONE`(안심 신청 없음 · 제휴만 신청한 줄) · 새 칸 `aff_status`(NULL · APPLIED · ACTIVE · SUSPENDED · WITHDRAWN · REJECTED) · `aff_applied_at` · `aff_approved_at` · `aff_approved_by` · `aff_reason` |
| 기존 줄 | 마이그레이션이 지금 상태를 제휴 칸에 그대로 복사 — **누구도 접근이 끊기지 않음**. 규칙(승인자 · 활동 자격 · 사유)에 걸리는 줄은 건너뛰고 NOTICE |
| 규칙 | 제휴 활동(ACTIVE)은 승인자 · 승인 시각 · 활동 자격(사업자 인증 · 개인은 본인인증) · 정지 · 반려는 사유(`trg_partner_aff_guard`) |
| 제휴 신청 | 새 `POST /partner/affiliate/apply` — 계정 기준(D096) · 줄이 없으면 `status = NONE` 으로 만듦 · 반려되면 다시 신청 · 두 번째 409 `ALREADY_APPLIED` |
| 안심 신청 | `POST /partner/apply` 그대로 — 제휴만 신청한 줄(NONE)이면 그 줄을 APPLIED 로(제휴 자격 그대로) |
| 제휴 쪽 판정 | 제휴 센터 API · 정산 계좌 · 홍보 자료 열람 · **링크 클릭(`fn_plink_click`)** 모두 `aff_status = ACTIVE` |
| 안심 쪽 판정 | 그대로 `status` · 「내 파트너」 찾기와 운영 목록(목록 · 이용료)에서 NONE 줄을 뺌 |
| 정지 · 다시 열기 | 안심: 운영 화면 › 파트너사 상세 「자격」 줄(`POST /admin/partners/{id}/suspend · resume`) · 제휴: 운영 화면 › 제휴 › 입점 심사 아래 「제휴 파트너 현황」(`GET /admin/affiliates/partners` · `POST …/{id}/suspend · resume`) — 사유 필수 · 감사 기록 · 한쪽만 바뀜 |
| 사용자 웹 | 제휴 센터(/partners) 신청 단계가 제휴 자격으로 — 신청 전 · 심사 중 · **정지(사유)** · **반려(사유 · 다시 신청)** · 안내 문구 「제휴 파트너 신청은 안심소개 입점 신청과 따로입니다」 |
| 탈퇴 막기 | 안심 또는 제휴가 신청 · 활동 중이면 탈퇴 전에 알림(전에는 안심만) |
