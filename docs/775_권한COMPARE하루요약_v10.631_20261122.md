# 775. 권한 COMPARE 「다름」 하루 요약 PERM_COMPARE_DIFF — v10.631 (2026-11-22)

## 1. 결론

- 판정 방식 COMPARE(docs/706)는 권한그룹 판정이 역할 판정과 다르면 기록만 남깁니다. GROUPS 로 바꾸려면 「최근 24시간 다름 0」이어야 하는데, 지금은 **화면에 들어가 봐야만** 알 수 있었습니다.
- 이번 판부터 `perm.mode = COMPARE` 인 동안 **매일 08시(한국) 뒤 어제 하루치를 운영 알림 한 줄**로 올립니다.
  - 다름 있음 → **WARN** 「어제 다름 n건 · 주소 m곳」 + 많은 주소 5개
  - 다름 0 → **INFO** 「어제 다름 0 — GROUPS 조건 하루치 채움」
- 설정은 없습니다. ROLE · GROUPS 일 때는 아무것도 하지 않습니다.

## 3. 운영 적용

- 코드만(D307 에 설정 없음). COMPARE 로 바꾼 다음 날 08시 뒤 운영 알림에 한 줄이 생기는지 봅니다.
