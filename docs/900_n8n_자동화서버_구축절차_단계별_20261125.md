## 1. EC2 만들기 (AWS 콘솔 · 대표)

```
EC2 → 인스턴스 시작 → 이름 sgb-auto → Ubuntu Server 24.04 LTS → t3.medium
 → 키 페어 없음(Session Manager 로 접속) → 네트워크: 운영과 같은 VPC · 보안 그룹 새로 「sgb-auto-sg」(인바운드 없음 · 아웃바운드 443)
 → 스토리지 gp3 40GiB → 고급: IAM 인스턴스 프로파일 = AmazonSSMManagedInstanceCore + S3 백업 경로 쓰기 정책
 → 시작 → 탄력적 IP 할당 → sgb-auto 에 연결 → 결제 › 예산 → 월 60달러 경보
```

## 3. n8n + 전용 Postgres (버전 고정)

```bash
sudo mkdir -p /opt/n8n && cd /opt/n8n
# 설치 당일 n8n 안정판 번호를 적습니다(예: 1.x.y) — latest 금지(#16)
N8N_VER=〔안정판 번호〕
sudo tee /opt/n8n/.env >/dev/null <<EOF
N8N_VER=$N8N_VER
POSTGRES_PASSWORD=$(openssl rand -hex 24)
N8N_ENCRYPTION_KEY=$(openssl rand -hex 32)
EOF
sudo chmod 600 /opt/n8n/.env
sudo tee /opt/n8n/docker-compose.yml >/dev/null <<'EOF'
services:
  db:
    image: postgres:16
    restart: unless-stopped
    environment: { POSTGRES_USER: n8n, POSTGRES_PASSWORD: "${POSTGRES_PASSWORD}", POSTGRES_DB: n8n }
    volumes: [ "db:/var/lib/postgresql/data" ]
    healthcheck: { test: ["CMD-SHELL", "pg_isready -U n8n"], interval: 10s, retries: 10 }
  n8n:
    image: docker.n8n.io/n8nio/n8n:${N8N_VER}
    restart: unless-stopped
    depends_on: { db: { condition: service_healthy } }
    ports: [ "127.0.0.1:5678:5678" ]      # 밖에 열지 않음 — Session Manager 포트 포워딩으로만
    environment:
      DB_TYPE: postgresdb
      DB_POSTGRESDB_HOST: db
      DB_POSTGRESDB_DATABASE: n8n
      DB_POSTGRESDB_USER: n8n
      DB_POSTGRESDB_PASSWORD: "${POSTGRES_PASSWORD}"
      N8N_ENCRYPTION_KEY: "${N8N_ENCRYPTION_KEY}"
      GENERIC_TIMEZONE: Asia/Seoul
      N8N_DIAGNOSTICS_ENABLED: "false"
    volumes: [ "n8n:/home/node/.n8n" ]
volumes: { db: {}, n8n: {} }
EOF
cd /opt/n8n && sudo docker compose up -d && sleep 20 && sudo docker compose ps
```
- [ ] db · n8n 둘 다 running(healthy) · [ ] **N8N_ENCRYPTION_KEY 를 서버 밖(대표 보관)에 적어 둠** — 잃으면 저장한 자격 증명을 못 엶

## 6. 첫 워크플로 ② 백업 (매일 04:40 · 서버 밖)

```bash
sudo tee /opt/n8n/backup.sh >/dev/null <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
D=$(date +%Y%m%d); T=$(mktemp -d)
cd /opt/n8n
docker compose exec -T n8n n8n export:workflow --all --output=/tmp/wf.json >/dev/null
docker compose exec -T n8n n8n export:credentials --all --output=/tmp/cred.json >/dev/null   # 암호화된 채
docker compose cp n8n:/tmp/wf.json "$T/" && docker compose cp n8n:/tmp/cred.json "$T/"
tar czf "$T/n8n_$D.tgz" -C "$T" wf.json cred.json
aws s3 cp "$T/n8n_$D.tgz" "s3://〔백업 버킷〕/n8n/n8n_$D.tgz"
rm -rf -- "$T"
EOF
sudo chmod 700 /opt/n8n/backup.sh && sudo /opt/n8n/backup.sh && echo "40 4 * * * root /opt/n8n/backup.sh" | sudo tee /etc/cron.d/n8n-backup
```
- [ ] S3 에 파일 생김 · [ ] 되살리기 연습 1번(`n8n import:workflow --input=…`)
