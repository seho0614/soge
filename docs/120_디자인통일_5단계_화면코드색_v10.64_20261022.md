## 2. 남은 것 — 시안 화면 코드 안 색

시안(proto.html) 화면 코드 안 style="color:…" 에 흰 바탕 기준 대비 4.5 미달 글자색이 약 70곳(#6E7A96 · #12B886 · #C3CCE3 · #9AA5BE 등) 있습니다. 대부분 파트너센터 어두운 띠 위의 밝은 글자로 보여(바탕이 다른 곳에 적혀 있음) 기계적으로 바꾸면 오히려 읽기 어려워질 수 있습니다. **6단계(시안 · 문서)에서 화면을 보며 따로 확인**합니다.
