# 590. 법인카드 한도 · 사용자별 사용 (v10.453 · 2026-11-20)

## 1. 결론
법인카드(끝 4자리)마다 **이름 · 쓰는 사람 · 달 한도**를 정하고, 이번 달 사용을 카드별 · 사람별로 봅니다. 한도의 **80%**를 넘으면 한 번, **한도를 넘으면** 한 번 더 운영 알림이 뜹니다. 위치: **회계 › 자금 › 법인카드 한도** · SB-ADM-FIN-010.

| 항목 | 내용 |
|---|---|
| 카드 알아보기 | ⑫ 법인카드 CSV 의 카드 끝 4자리(acct_card_txns.card_tail) — CSV 에 카드 번호 칸이 없으면 「(번호 없음)」 한 줄로 모임 |
| 달 사용 | 그 달(한국 날짜) 이용 줄 합 — 취소(음수) 포함 · 「넣지 않음」 줄 뺌 · 장부에 넣었는지와 상관없음 |
| 한도 정하기 | SUPER · 사유 필수 · 바꾼 기록(acct_card_limit_changes · 쌓기만) |
| 알림 | 정책 › 전체 설정 `acct.card_alert`(처음 on) · `acct.card_alert_pct`(처음 80 · 50 ~ 100) · 정기 작업 acct_card_limit 매일 09:40 · 운영 알림 ACCT_CARD_LIMIT(카드 · 달마다 기준 한 번 · 넘음 한 번) · 달이 바뀌면 지난달 알림은 풀림 |
| 보는 사람 | SUPER · PAYOUT · 세무사(읽기) |

## 2. 주의
1. 카드사 CSV 를 올려야 사용이 잡힙니다 — 올리기 전 사용은 알 수 없습니다(카드사 실시간 연동 없음).
2. 카드 끝 4자리가 같은 카드가 둘이면 한 줄로 셉니다 — 카드사 CSV 의 「카드 번호」 칸을 확인하십시오.
