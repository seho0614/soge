# 583 휴가 신청 → 승인 — v10.446 (D259 · 2026-11-20)

## 1. 결론
- 직원이 **사무 › 내 인사**에서 휴가(종일 · 오전 반차 · 오후 반차)를 신청하면, 관리자가 **회계 › 인사 › 휴가 신청**에서 승인 · 반려합니다.
- 승인하면 ⑮ **연차 쓴 날**(회계 › 인사 › 퇴직금 · 연차)에 영업일마다 한 줄(`LR-번호`)이 들어가 남은 연차가 줄어듭니다.

## 2. 규칙
1. 영업일만 셈(주말 · 공휴일 빠짐 · fn_is_business_day) · 반차 0.5일(하루).
2. 겹치는 신청은 409(오전 · 오후 반차는 같은 날 둘 다 가능).
3. 해를 넘는 휴가는 해마다 나눠 신청 · 한 번 40일까지 · 30일 넘게 지난 날은 관리자에게.
4. 승인 · 반려는 ADMIN · SUPER · **본인 신청은 다른 관리자**(HR_SELF) · 반려는 사유.
5. 남은 연차보다 많으면 승인 막음(LEAVE_SHORT) — 설정 `hr.leave_allow_negative`(처음 off)를 켜면 허용.
6. 본인 취소는 승인 전만 · 승인된 휴가는 관리자가 「승인 취소」(사유 · 연차 쓴 날을 음수 줄로 되돌림).
7. DB 가 막음: 지우기 · 신청 내용 고치기 · 상태 거꾸로.

| 승인 · 반려 · 승인 취소 | 운영 화면 **회계** › 「인사」 › 탭 **「휴가 신청」** |
