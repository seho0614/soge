# 552. 업무 보고 보내기 · 내려받기 (v10.415 · 2026-11-20)

> ⑰ 네 번째(D250).

## 1. 결론

- 일보 · 주보 · 월보를 **운영 알림 채널 그대로** 보냅니다 — 텔레그램(급한 알림 대화방) · 슬랙 · 메일(`ops.digest_to` · 메일 준비됐을 때).
- 설정 `report.send`(**처음 꺼짐** · SUPER) · `report.send_kinds`(DAY · WEEK · MONTH) — 보고 › 일보 아래 「보고 보내기」 상자.
- 켜 두면 정기 작업 `ops_report` 가 **새로 만든** 보고 중 고른 종류만 보냅니다. 「지금 보내기」(SUPER)는 스위치와 상관없이 그 보고 한 번.
- 채널마다 결과를 `report_sends` 에 남김(`SENT` · 준비 안 됨 까닭 · 실패) — 화면 「보낸 결과」.
- 글은 숫자만(이름 · 연락처 없음). CSV · 인쇄는 v10.413.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D250** | `report_sends`(쌓기만) · 설정 `report.send` · `report.send_kinds` |
| API | `POST /admin/work-reports/snapshots/{id}/send` · `GET · PATCH /admin/work-reports/settings` · 감사 `REPORT_SEND` · `REPORT_SETTING` |

## 3. 주의 · 대표 확인

1. 켜기 전에 운영 알림 채널(텔레그램 대화방 · 슬랙 · 메일)이 준비됐는지 — 준비 안 된 채널은 보내지 않고 까닭만 남깁니다.
2. 하루 요약(09:00)도 텔레그램으로 가므로 일보까지 켜면 아침에 두 통이 됩니다 — 주보 · 월보만 켜는 것도 방법입니다.
