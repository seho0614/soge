# 611 회의실 · 장비 예약 — v10.473 (D265 · 2026-11-20)

## 1. 결론
- 운영 화면 **사무 › 탭 「회의실 · 장비 예약」**에서 운영 역할이 있는 사람 누구나 날 · 자원 · 시작 · 끝 · 제목으로 예약합니다(세무사 계정 빠짐).
- **같은 자원의 시간이 겹치면 DB 가 막습니다**(배제 제약 `ex_hrx_booking_overlap` · 서버가 먼저 겹친 예약을 알려 주고, 두 사람이 동시에 눌러도 DB 가 하나만 받음 → 409 `HRX_BOOK_OVERLAP`).
- 자원(회의실 · 장비)은 ADMIN 이 넣고 고칩니다(지우지 않음 · 쓰지 않음으로).

## 2. 규칙
| 항목 | 규칙 |
|---|---|
| 구간 | [시작, 끝) 반열린 구간 — 10:00 ~ 11:00 과 11:00 ~ 12:00 은 겹치지 않음 · 같은 날 안 |
| 길이 | 한 번에 `hrx.book_max_hours`(처음 8시간)까지 |
| 언제까지 | 오늘부터 `hrx.book_ahead_days`(처음 90일) 안 · 지난 시각은 안 됨 |
| 취소 | 예약한 사람 · ADMIN · SUPER · 끝나기 전 · 남의 예약은 사유 2자 이상 · 한 번 · 취소한 예약은 겹침에서 빠짐(그 자리 다시 예약 가능) |
| 고치기 | 예약 내용은 못 고침(취소하고 다시) · 지우지 않음(DB 가 막음) |
| 쓰지 않는 자원 | 새 예약 못 넣음 · 이미 있는 앞으로의 예약은 남음(개수를 알려 줌 · 필요하면 취소) |

## 3. DB 배제 제약(btree_gist)
```sql
CONSTRAINT ex_hrx_booking_overlap EXCLUDE USING gist (resource_id WITH =, tstzrange(start_at, end_at, '[)') WITH &&) WHERE (canceled_at IS NULL)
```
- btree_gist 확장은 B010 · D092 에서 이미 켜져 있어 D265 는 `CREATE EXTENSION IF NOT EXISTS btree_gist`(있으면 그대로)만 둡니다 — 운영 적용 때 새 확장 설치 없음.
- 같은 모양으로 연장 근로 신청 겹침(`ex_hrx_ot_overlap` · docs/609)도 막습니다.

## 4. 사내 일정 캘린더(㉜ D263)
- 내 예약은 사내 일정(사무 › 사내 일정)에 「회의실 · 장비 예약」 줄로 보이게 합니다 — 읽기 함수 `bookingCalItems`(hrx-booking.ts)를 ㉜ 캘린더에 연결(합칠 때 · NOTES 「앞 묶음 ㉜ 에 기댐」).
