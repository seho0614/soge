# 767. GROUPS 로 바꾸기 전 점검표 — v10.624 (2026-11-22)

## 1. 결론

- 권한그룹 판정(`perm.mode = GROUPS`)으로 바꾸는 코드 준비는 docs/757 에서 끝났습니다(역할 이름으로 막는 곳 중 남은 것 0). 남은 일은 운영에서 ROLE → COMPARE → GROUPS 로 바꾸는 것뿐입니다.
- 이번 판은 그 순서를 실수 없이 하도록 **직원 · 권한 › 업무별 권한 › 「판정 방식」 상자에 점검표 5줄**을 보여 줍니다.

| 줄 | 종류 | 뜻 |
|---|---|---|
| 연결 안 된 /admin 주소 0 | 꼭 | 서버가 GROUPS 를 막는 조건(그대로) |
| 최근 24시간 COMPARE 다름 0 | 꼭 | 〃 |
| 역할 이름으로 막는 곳 중 맞추지 않은 곳 0 | 꼭 | 〃(docs/757) |
| COMPARE 로 24시간 이상 | 권장 | 다름 0 이 하루치여야 뜻이 있음 — COMPARE 로 바꾼 지 몇 시간인지 |
| 검사 모드 perm.enforce = ON | 권장 | SHADOW 기록을 본 뒤 ON |

- 권장 줄이 아직이면 「권한그룹으로」 단추를 눌렀을 때 **한 번 더 묻습니다**. 서버가 막는 조건은 꼭 3줄 그대로입니다(시험 test_v1564 의 GROUPS 확인을 막지 않으려고 24시간은 서버 조건으로 넣지 않음).

## 2. 바뀐 것

| 항목 | 내용 |
|---|---|
| 서버 | GET /admin/perm/mode 응답에 `checklist`(5줄) · `compareHours` · `enforce` 더함 · `groupsReady` 조건 그대로 |
| 화면 | 「판정 방식」 상자 점검표 · GROUPS 전 확인 창 |
| DB | 없음 |

## 3. 운영 적용

- 마이그레이션 없음. 순서: 적용 다음 날 SHADOW 기록 확인 → `perm.enforce` ON → 「역할로 · 권한그룹과 비교 기록」(COMPARE) → 24시간 뒤 점검표 5줄 모두 통과 → 「권한그룹으로」.
