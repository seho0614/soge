### 4-2. 알아 둘 것

1. **처리방침** — 이제 **모든 회원**이 자기 아래(여러 번째까지) 가린 이름 · 가입 월을 봅니다. 11/9 법무 확인(추천한 분에게 가린 이름 · 가입일)과 같은 정보지만 보는 사람이 넓어졌으니 처리방침 「추천 관계」 줄 확인을 권합니다(docs/388).
2. **주간 알림**은 월요일 09:05 · 텔레그램 · 슬랙이 꺼져 있으면 나가지 않고 「운영 알림」(INFO · `OWNER_TODO_WEEKLY`)에만 「보낸 길 없음」으로 남습니다. 끄려면 설정 `ops.owner_todo_weekly` = off.
3. 「적기」는 **실제로 끝낸 일만** — 기록은 지울 수 없습니다. 적용 확인 중 시험 삼아 적지 마십시오.
4. **적용 기록 첫 줄은 이번 적용 때 생깁니다**(첫 기록). `pm2 restart` · 재부팅으로 같은 판이 다시 떠도 줄이 늘지 않습니다.
5. 결과 파일 · postcheck · precheck 시각은 **운영 서버 시각**(파일 이름) — 서버가 UTC 면 한국 시각보다 9시간 이르게 보입니다. 기록 줄 시각은 한국 시각입니다.
6. 서버 오류 「최근 7일」은 10분마다 DB 에 넣습니다 — API 가 다시 뜨면 아직 넣지 않은 몫(최대 10분)은 빠집니다.
7. 운영의 처리방침 등 8종은 본문 시행일이 11-30이라 **11-27 09:00 · 11-30 09:00** 에 약관 INFO 알림이 한 번씩 뜹니다.
8. 개발 서버 `~/kits/release` 에 다른 판 킷(v10.237 · 240 · 243 · 246)이 있어도 **v10.256 킷만** 올립니다.

## 5. 되돌리기

| 상황 | 할 일 |
|---|---|
| 화면이 이상함 | `bash ~/sgb/deploy/aws/rollback.sh` → `yes` — 코드만 **v10.240** 으로 돌아갑니다. DB 는 242 그대로 남지만 표 · 설정 · 정기 작업을 더한 것뿐이라 v10.240 코드가 그대로 돕니다(v10.240 은 `owner_todo_weekly` 작업 이름을 몰라 월요일에 그 작업이 아무것도 하지 않고 「끝남」으로 지나감 — 다시 v10.256 으로 올리면 정상). 나의공간 메뉴 · 관계도 · 정산 내역 · 「대표 할 일」 새 줄 · 「지금 판」 카드는 없어지고, **v10.240 에는 적용 기록 기능이 없어 「되돌림」 줄도 생기지 않습니다** |
| 되돌린 뒤 다시 v10.256 으로 | `bash ~/sgb/deploy/aws/rollback.sh` 를 한 번 더 → `yes`(v10.256 판 폴더가 남아 있음) — 마지막 줄과 판이 같아 줄을 더하지 않습니다 |
| DB 까지 | 보통 필요 없습니다. 하려면 RDS → `sgb-before-v10-256-YYYYMMDD` 복원 → `.env` 접속 주소 교체 → `pm2 restart sgb sgb-site sgb-jobs` 순서로 합니다. 스냅샷 뒤에 생긴 자료(가입 · 신청 등)는 사라집니다 |
