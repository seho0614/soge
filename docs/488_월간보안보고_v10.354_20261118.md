# 488. 월간 보안 보고 (v10.354 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 막힌 접속 기록 · ② 월간 보안 보고 · ③ 운영자 활동 요약 · ④ 감사 기록 위변조 확인 「모두」 → 계획 「승인 + 통과하면 병합」(감사 · 감시 목록 정리의 빈 곳). 이 문서는 ②. 마이그레이션 **D235**(272 → 273 · 스냅샷 필요 · v10.356 과 같은 파일).

## 1. 왜

- 권한 · 설정 · 개인정보 열람 · 접속 기록은 화면마다 흩어져 있어, 한 달을 돌아볼 보안 정리가 없었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D235** | 설정 `ops.security_monthly`(on) · 정기 작업 `security_monthly`(매일 09:20 — 지난달 보고를 아직 안 보냈으면 보냄 · 같은 달은 한 번) |
| 보고 글(지난달 · 한국) | 운영 권한 주기 · 거두기(role_changes) · 설정 바뀜 · 중요 설정 알림 · 개인정보 열람 횟수 · 사람 수 · 운영자 낯선 로그인 · 접속 인증 통과 · 잠김 · 막힌 접속(최근 7일) · 급한 알림 수 · 확인 · 확인까지 평균 분 · 감사 기록 줄 · 위변조 확인 결과 |
| 정기 작업 | 텔레그램 · 슬랙(켜 둔 길만) · 운영자 게시판 · 운영 알림 **SECURITY_MONTHLY**(INFO · detail.month) |
| 새 API `GET /admin/security/monthly` | SUPER · 미리 보기 |
| 운영 화면 **위험감지 › 「감사」** | 맨 위 상자 › **「월간 보안 보고 미리 보기」**(SUPER) |
