### 상태

| 상태 | 뜻 |
|---|---|
| 다음 정기 작업에 감 | 다음 00:05 에 보냄(안 읽은 대상이 있음) |
| 그날 감 | 「다시 알림」 칸 날짜의 00:05 에 보냄 |
| 자동 다시 알림 이미 보냄 | 예약마다 자동은 한 번 |
| 공지를 아직 게시하지 않음 | 공지 게시 뒤부터 |
| 시행 전에 돌 차례가 없음 | 일수가 너무 짧음 |
| 대상이 모두 읽음 | 지금은 보낼 곳 없음(그사이 바뀔 수 있음) |

- 계산은 실제 작업 `fn_hlt_rate_auto_remind` 와 같은 조건: 예정 · 시행 전 · 게시된 공지 · 예약마다 자동 한 번 · **운영자가 24시간 안에 다시 알렸으면 그날 건너뜀(하루 미룸으로 표시)** · 공지를 안 펼친 대상 판매자만. 다시 알림 날짜 = 「시행일 − n일」 · 「공지 게시」 · 「지금」 뒤 첫 00:05(한국).
