# 371. 운영 알림 한꺼번에 확인 — v10.232 (2026-11-10)

> **마이그레이션 없음(237 그대로)** · 새 API 2개 · 운영 화면 「운영 알림」 종류별 표 위 한 줄.

## 1. 왜

- 「같은 종류 모두 확인」은 있었지만, 텔레그램을 켜기 전에 여러 종류로 쌓인 알림을 정리하려면 종류마다 눌러야 했습니다.

## 2. 바뀐 것

| 곳 | 내용 |
|---|---|
| API | `GET /admin/ops-alerts/ack-bulk/preview?scope=resolved` · `?scope=older&hours=6|24|72` — 몇 건인지(읽기만) |
| API | `POST /admin/ops-alerts/ack-bulk` `{ scope, hours?, note? }` — ADMIN 이상 · 감사 OPS_ALERT_ACK_BULK · 그 밖의 값은 422 ACK_BULK_SCOPE |
| 기준 | 확인 안 한 것만 · **CRITICAL 은 늘 뺌**(하나씩 · 종류별로) · resolved = 원인이 없어진(풀린) 것 · older = 정한 시간보다 먼저 생긴 INFO · WARN |
| 화면 | 「풀린 것 모두 확인」 · 시간 고르기(6 · 24 · 72) + 「넘은 INFO · WARN 모두 확인」 — 몇 건인지 먼저 보이고 메모 하나 |

- 확인 기록(누가 · 언제 · 메모)은 하나씩 확인한 것과 같고 고칠 수 없음(DB `fn_ops_alert_ack_guard`).
