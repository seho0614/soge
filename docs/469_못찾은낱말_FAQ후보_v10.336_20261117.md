# 469. 고객센터 「못 찾은 낱말」 → 자주 묻는 질문 후보 (v10.336 · 2026-11-17)

> 대표 11/17 「다음개발」 → ① 못 찾은 질문 → FAQ 후보 · ② 1:1 문의 처리 지표 · ③ 리드관 운영 현황 · ④ 업무 안내 「모두」 → 계획 「승인 + 통과하면 병합」. 이 문서는 ①. 마이그레이션 **D228**(265 → 266 · 스냅샷 필요).

## 1. 왜

- v10.334 「많이 찾는 질문 후보」는 **있는 질문** 중 많이 펼친 것만 보여 줍니다. 회원이 찾았는데 **질문이 없어서 못 찾은 것**은 알 길이 없었습니다.
- 못 찾은 회원은 1:1 문의를 넣습니다. 자주 못 찾는 낱말로 질문을 만들면 문의가 줄어듭니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D228** | 표 `faq_search_misses`(낱말 · 날짜 · 횟수 — 사람 정보 없음) · 표 `faq_search_miss_done`(운영자가 「다룸」 표시한 낱말 · 누가 · 언제). 지우는 문장 없음 |
| 새 API `POST /faq/miss` | 공개(로그인 없이) · 낱말을 다듬어(소문자 · 빈칸 하나) 그날 줄에 +1. 2 ~ 40자만 · **숫자 4자리 이상 · @ · 주소 모양은 세지 않음**(전화번호 · 메일이 섞여 들어오지 않게 — `kept false`) |
| 사용자 웹 **고객센터** 찾기 | 결과가 0건이면 1.2초 멈춘 뒤 그 낱말을 한 번 보냄(이 화면에서 같은 낱말은 한 번) |
| API `GET /admin/faqs` | `misses` — 최근 30일 못 찾은 낱말 20개(많이 찾은 순 · 마지막 날짜). 「다룸」 뒤 다시 찾은 낱말만 다시 나옴 |
| 새 API `POST /admin/faqs/misses/done` | ADMIN · SUPER · 감사 `FAQ_MISS_DONE` · 목록에 없는 낱말 404 |
| 운영 화면 **관 관리 › 「자주 묻는 질문」** | 「많이 찾는 질문 후보」 아래 **「못 찾은 낱말 30일」** 표(낱말 · 30일 횟수 · 마지막) · **「이 낱말로 새 질문」**(질문 칸 · 챗봇 낱말 칸에 채워 「새 질문」을 엶) · **「다룸」** |
