# 577. 장부 보관 · 내부통제 보고 (v10.440 · 2026-11-20)

> 대표 11/19 「다음개발」. 마이그레이션 D257 ④.

## 1. 결론

해 마감(⑭) 뒤 **그 해 장부 · 증빙의 지문(sha256)을 보관 기록으로 남기고(지우지 않음 · 5년)**, 달마다 **내부통제 숫자**(다시 볼 일)를 봅니다. 월보(⑰)에 한 줄 들어갑니다.

## 2. 보관

| 항목 | 내용 |
|---|---|
| 조건 | 해 마감한 해만(fn_acct_year_closed) |
| 담는 것 | 전표 수 · 줄 수 · 차변 합 · 전표 CSV sha256 · 증빙 파일 목록(매입 · 경비 · 계약 · 파일 sha256) |
| 판 | 같은 해를 다시 만들면 새 판 · 앞 판과 CSV 지문이 다르면 「바뀜」 |
| 기한 | keep_until = 다음 해 1월 1일 + 5년(국세기본법 장부 · 증빙 보관) — 지나도 지우지 않음 |
| 내려받기 | 승인 대상 ACCT_ARCHIVE — 전표 CSV + 증빙 목록 CSV · 지금 장부가 보관 때와 같은지 |

## 3. 내부통제 보고(달마다 · 계산만)

| 줄 | 근거 |
|---|---|
| 전표 규칙 바꿈 | acct_rule_changes |
| 해 마감 풀기 | acct_year_closings REOPEN |
| 마감한 달에 늦게 넣은 전표 | acct_entries.late |
| 수동 전표 | source MANUAL |
| 큰 금액 전표 | 한 전표 차변 합 ≥ acct.control_big_amount(처음 1,000만 원) |
| 운영 권한 주기 · 거두기 | role_changes |
| 회계 자료 내려받기 요청 | export_requests ACCT_* |
| 세무사 계정 접속 | acct_accountant_access |
| 통장 「맞출 것 없음」 | acct_bank_txns IGNORE |

- 예외 = 규칙 바꿈 + 해 마감 풀기 + 늦은 전표 + 큰 금액.
- 본인 결재 시도는 DB 가 막기만 하고 기록하지 않아 셈에 없습니다.
