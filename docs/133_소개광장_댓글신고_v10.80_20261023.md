## 1. 결론 — 댓글도 글과 같은 규칙으로 신고

| # | 무엇 | 내용 |
|---|---|---|
| 1 | 신고 | 로그인한 회원이 **남의 공개 댓글**마다 「신고」 → `/report/comment/{id}` · 본인인증한 회원만(글 · 매물과 같음) · 자기 댓글 · 지운 댓글은 DB 가 거절 |
| 2 | 자동 가림 | **서로 다른 회원 3명**이 신고하면 댓글이 가려짐(지우지 않음) — 신고 트리거(D110 · 글과 같은 규칙) |
| 3 | 회원 화면 문구 | 신고 3건으로 가려짐 → 「신고가 들어와 가려진 댓글입니다.」 · 운영자가 가림 → 「운영 기준에 따라 가려진 댓글입니다.」(댓글 표에 사유 칸이 없어 신고 수로 구분) |
| 4 | 운영 화면 | 「소개광장 검수」에 **신고된 댓글**(신고 3건 이상) 표 — 감추기 · 되살리기 · 글 찾기 › 댓글 펼침에 신고 수 칸 |
| 5 | 되살리기 | 글(v10.72 결정 A)과 같게 — 처리 전 신고는 **기각**으로 닫고 신고 수 0 · 신고한 사람에게 결과 알림 · 새 신고 3건이 쌓여야 다시 가려짐 |
| 6 | 신고 이름 | 「내 신고」 · 운영 「신고 처리」에 「소개광장 글」 · 「소개광장 댓글」(전에는 글도 영어 코드 POST 로 보였음) |
