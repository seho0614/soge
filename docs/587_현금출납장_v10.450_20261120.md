# 587. 현금출납장 (v10.450 · 2026-11-20)

> 대표 11/20 03:30 「다음개발」 ㉗ 장부 보강. 마이그레이션 D260 ①(계정) · ④(권한 업무).

## 1. 결론

**보통예금(CASH)** 과 새 계정 **현금(시재 · CASH_HAND · 코드 101)** 의 **기초 · 날짜별 들어옴 · 나감 · 잔액**을 봅니다. 셈은 ⑬ 계정별 원장(docs/534)과 같아 기말이 원장과 늘 같습니다.

## 2. 규칙

| 항목 | 내용 |
|---|---|
| 들어옴 · 나감 | 차변 = 들어옴 · 대변 = 나감 |
| 기초 | 확정한 기초 잔액 판 + 그 뒤 전표(시산표와 같음) |
| 현금(시재) | 자동 전표는 없음 — 사무실 현금은 수동 전표(차변 현금 / 대변 보통예금 등)로 들고 남을 적음 |
| 잔액 0 아래 | 「기초 잔액이나 빠진 전표 확인」 경고 |
| CSV | 내려받기 승인 ACCT_LEDGER |

## 3. 위치 · API

| 항목 | 값 |
|---|---|
| 화면 | 회계 › 장부 › 현금출납장 (SB-ADM-LDG-020) — 「줄째 보기」로 전표 줄 |
| API | GET /admin/acct/cashbook?role=CASH 또는 CASH_HAND&from=&to= · GET /admin/acct/cashbook/export?…&ticket= |
| 권한 | SUPER · PAYOUT · 세무사(읽기 · 내려받기) — 업무 acct-cashbook |

## 4. 운영 확인

1. 현금(시재)을 쓰면 기초 잔액 판에 시재 금액 줄을 넣고 확정(회계 › 장부 › 재무제표 › 기초 잔액).
2. 계정 코드 101 은 세무사랑 표준 「현금」 — 다르면 회계 › 설정 · 보고 › 계정 · 규칙에서 고침.
