# 184. 로그인 전 관심 성향 — v10.120 (2026-10-26)

> 대표 「나머지 개발」 3번 · 결정 **「가」(답만 채워 두기)** · 2026-10-26 승인. **마이그레이션 없음**(163) · 사용자 웹만 · API · 운영 화면 그대로.

## 1. 결론

| 항목 | 내용 |
|---|---|
| 문제 | 로그인 화면의 「관심 성향 등록」 칸(시안 loginCta)을 누르면 `/ai/profile` 이 손님을 다시 로그인 화면으로 보냄 — 제자리 |
| 고침 | 손님도 성향 화면을 엶 — 문항 · 분석 결과(공개 진단 · 저장 안 함) · 「로그인하고 등록」 · 「가입하고 등록」 |
| 시안과 다른 점 | 시안 「로그인하면 이 계정에 그대로 이어집니다」(자동 저장) 대신 **답만 채워 둠** — 성향 저장 = 맞춤형 광고 약관 동의(D123)라, 동의는 계정 주인이 직접 켜고 눌러야 함(대표 결정 「가」) |
| 답 보관 | 손님이 고른 답은 **이 탭에만**(sessionStorage · `lib/profileDraft.ts`) — 서버 · DB 에 보내지 않고 탭을 닫으면 지워짐. 저장 · 「다시 하기」 · 「성향 쓰지 않기」 뒤 지움 |
| 로그인 · 가입 뒤 | 성향 화면 · 가입 5단계가 답을 채운 채로 열림(안내 한 줄) · 동의 칸은 비어 있음 · 이미 등록한 회원은 채우지 않음 |
| 광고 | 그대로 — 손님 · 비동의자는 성향을 정하지 않은 광고만(D123) |
