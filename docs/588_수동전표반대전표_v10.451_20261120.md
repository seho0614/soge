# 588. 승인된 수동 전표 반대 전표(역분개) (v10.451 · 2026-11-20)

> 대표 11/20 03:30 「다음개발」 ㉗ 장부 보강. 마이그레이션 D260 ②.

## 1. 결론

장부에 들어간(승인된) 수동 전표가 틀렸으면 **지우지 않고 차대를 바꾼 반대 전표 한 장**을 넣습니다(전표는 쌓기만 · D242). SUPER 만 · 사유 5자 이상 · 한 수동 전표에 한 번. 바른 내용은 새 수동 전표로 다시 씁니다.

## 2. 규칙

| 항목 | 내용 |
|---|---|
| 대상 | acct_manual_entries 상태 APPROVED(전표 있음)만 — 요청 · 반려 · 취소는 409 |
| 날짜 | 비우면 오늘 · 원래 전표 날짜 이후(앞이면 422 ACCT_REVERSE_DATE) |
| 마감 | 반대 전표 날짜가 마감한 달 · 해면 422(ACCT_MANUAL_CLOSED) · DB 도 막음 |
| 전표 | acct_entries source MANUAL_REVERSE · source_key = 수동 전표 번호(같은 근거 한 번) · 줄은 원래 줄의 차대 반대 |
| 기록 | acct_entry_reversals(수동 전표 · 원래 전표 · 반대 전표 · 날짜 · 사유 · 한 사람) — 쌓기만(DB 가 고치기 · 지우기 막음) |
| 감사 | ACCT_MANUAL_REVERSE |

## 3. 위치 · API

| 항목 | 값 |
|---|---|
| 화면 | 회계 › 장부 › 수동 전표 — 승인된 줄의 「반대 전표」 단추(SUPER) · 만든 뒤 「반대 전표 n (날짜) · 사유」 표시 |
| API | POST /admin/acct/manual/{id}/reverse { reason, reverseOn? } |
| 권한 | SUPER(업무 acct-manual APPROVE) |
