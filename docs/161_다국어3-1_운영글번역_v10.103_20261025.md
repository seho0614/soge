| 규칙 | 이유 |
|---|---|
| 원문이 고쳐지면 번역은 낡음 → 원문이 나감(다시 넣고 승인할 때까지) | 「승인된 번역만」(결정 #6) |

### 3-1. 알아 둘 것

- **승인한 번역이 손님 화면에 나오기까지 최대 몇 분** — 사용자 웹이 API 응답을 화면마다 저장해 둡니다(분류 목록 5분 · 대부분 30초 ~ 5분). 언어끼리는 따로 저장되어 섞이지 않습니다(시험으로 확인).
- 분류 · 상품 목록의 정렬은 원문(한국어) 기준 그대로입니다.
- 소개몰 카드의 갈래 이름 · 업종 이름이 나오는 덜 보이는 화면(후기 · 상담 분류 · 파트너 화면 등)은 아직 원문 — 필요하면 다음 판에서.
