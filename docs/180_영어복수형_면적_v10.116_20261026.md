## 1. 결론

| 항목 | 내용 |
|---|---|
| 복수형 | 영어 문장 중 개수를 세는 **85곳**을 ICU 복수형으로 — 「1 listings」 → 「1 listing」 · 「2 listings」 |
| 방식 | `{n, plural, one {{n} item} other {{n} items}}` — 고르는 데만 복수 규칙을 쓰고 화면에는 **넘겨받은 글자 그대로**(「1,234」 그대로) → 부르는 코드는 고치지 않음 |
| 뺀 곳 | 이름 · 금액 · 날짜 자리(「{cur} stays」 · 「{name} is」 · 「{n} less」(금액) 등) |

| 한국어 사전 | 바뀌지 않음 |
