# 597 근로계약서 전자서명 — v10.459 (D262 · 2026-11-20)

## 1. 결론
- 운영 화면 **회계 › 「인사」 › 탭 「근로계약서」**에서 양식 + 조건으로 직원별 근로계약서 초안을 만들고(본문 · SHA-256 지문 고정) 「보내기」를 누릅니다.
- 직원은 **사무 › 「내 인사」** 아래 상자 「근로계약서」에서 본문을 읽고 동의 · 이름을 적어 서명합니다. 서명본(본문 + 지문 + 서명 시각 · 서명자)은 고칠 수 없게 보관되고 언제든 다시 보고 인쇄합니다.
- **전자서명 연동은 처음 꺼짐**(`hr.contract_esign` off) — 지금은 간주(ASSUME) 서명이라 화면과 인쇄본에 「법적 전자서명 아님」이 찍힙니다.

## 2. 서명 길
| 설정 | 서명 길 | 직원이 서명하는 곳 | 법적 효력 |
|---|---|---|---|
| hr.contract_esign off(처음) | ASSUME(간주) | 내 인사(이름 적기) | 없음 표시 |
| on · esign.provider STUB | STUB | 내 인사 | 없음 표시 |
| on · esign.provider MOCK(점검판만) | MOCK | 내 인사 | 없음 표시 |
| on · esign.provider HTTP | HTTP(기존 ESIGN 어댑터 HttpESign) | 업체 화면(메일 · 문자 주소) | 업체 서명 |

- HTTP 인데 ESIGN 키(ESIGN_API_KEY · ESIGN_WEBHOOK_SECRET · ESIGN_URL)가 없으면 보내기가 **422 NOT_READY**. 키는 통합 현황 › 외부 연동 키(기존 ESIGN 줄 그대로).
- HTTP 로 보낸 것은 「상태 확인」 단추가 업체 상태를 읽어 서명 · 취소를 반영(지문이 다르면 서명으로 보지 않음). 웹훅(/webhooks/esign)은 거래 계약용이라 근로계약서는 아직 잇지 않음(NOTES).

## 3. 규칙
1. 처음 양식 STANDARD 1판(근로기준법 제17조 필수 명시 사항: 임금 · 소정근로시간 · 휴일 · 연차 · 일하는 곳 · 하는 일) — **노무사 확인 필요**. 양식을 고치면 새 판(옛 판은 쓰지 않음 · 옛 판 계약서는 그대로).
2. 자리표: name · signedOn(서버가 넣음) · company · startOn · endOn · place · duties · workTime · breakTime · workDays · holiday · wageType · wage · payDay · payMethod.
3. 계약서 본문 · 조건 · 지문은 못 고침(취소하고 새로) · 상태 DRAFT → SENT → SIGNED / CANCELED(앞으로만) · 서명본은 취소 못 함 · 지우지 않음.
4. 보내려면 직원이 운영 계정과 연결돼 있어야 함(회계 › 인사 › 근태 · SUPER).
5. 본인 서명: 동의 체크 · 이름 = 직원 이름 · 본 본문 지문이 같아야 함 · HTTP 계약서는 화면 안 서명 막힘(409 ESIGN_EXTERNAL).
6. 근로계약서 교부 의무(근로기준법 제17조 · 전자문서 교부 가능)는 서명본 「보기 · 인쇄」로 — 교부 방식은 노무사 확인.
