## 2. 결제 키 확인 (돈 안 나감)

`GET {TOSS_API_BASE}/v1/payments/orders/sgb-keycheck-<무작위>` (Basic 인증)

| 응답 | 뜻 |
|---|---|
| 404 `NOT_FOUND_PAYMENT`(또는 코드 없음) | **키가 맞음** — 없는 주문이라 없다고 답함 |
| 401 · 403 | 키가 틀림(AUTH) |
| 5xx | 토스 서버 오류(UPSTREAM) |
| 응답 없음 | 지연(TIMEOUT) · 연결 실패(NETWORK) — 운영 서버 바깥 연결 확인 |
| 2xx | 이상(BAD_RESPONSE) — 주문 번호 규칙 확인 |

⚠ 404 응답 모양은 토스 문서 기준 — **시험 키로 한 번 실제 확인이 필요**하다.

## 3. 1원 계좌인증 시험

1. SUPER 가 본인 계좌(은행 코드 3자리 · 계좌번호 · 예금주) → 「1원 보내기」(확인 창) — 하루 3번(스텁은 안 셈) · 1분 안 연속 409
2. 통장 입금자명의 코드 → 「코드 확인」 — 30분 · 다섯 번 틀리면 닫힘
3. 기록에는 계좌 끝 4자리 · 코드 해시(행 번호 소금)만. 키가 없으면 스텁(코드 SGB01) — **LIVE 근거가 되지 않음**
