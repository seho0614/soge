## 1. 결론

- **openapi 두 판을 비교**해 「더해진 · 없어진 · 바뀐 API」를 마크다운(운영 절차서 · 인계 메모에 붙임)과 JSON 으로 만듭니다.
- 이미 있는 문서 생성(`npm run docs` → `docs:swagger` = `scripts/dump-swagger.ts` → `docs/_swagger_from_code.json` · `merge-openapi.js` → `docs/06_openapi.json`)의 결과를 그대로 씁니다.
- **앞 판 화면 · 앱이 깨질 수 있는 것**(없어진 API · 필수가 된 매개변수 · 요청 칸 · 없어진 응답 칸)은 맨 위 「주의」에 모읍니다.
- 새 패키지 · 네트워크 · DB 없음.

## 2. 쓰는 법

```bash
# 옛 판 = 운영에 있는 킷(~/kits/release/<운영 판>/sgb/docs/_swagger_from_code.json) · 새 판 = 이번 판 docs 생성 결과
npm run docs:swagger
node scripts/api-diff.js ~/kits/release/v10.456/sgb/docs/_swagger_from_code.json docs/_swagger_from_code.json \
     --screens spec/screens.json --title "v10.456 → v10.596" \
     --out docs/7xx_API바뀐점_v10.456_v10.596.md --json /tmp/api-diff.json
```
- `docs/06_openapi.json`(merge 결과)을 주면 역할(`x-roles`) 바뀜까지 봅니다.
- `--screens` 를 주면 API 마다 쓰는 화면 ID 가 붙습니다.
