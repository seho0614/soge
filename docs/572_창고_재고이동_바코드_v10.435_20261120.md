# 572. 창고 여러 곳 · 재고 이동 · 바코드 (v10.435 · 2026-11-20)

## 1. 결론
창고를 여러 곳 두고 **창고별 수량 · 창고 간 이동 · 창고 입고 · 창고 실사**를 합니다. 직판 상품 옵션마다 **바코드(Code128)**를 정해 인쇄하고 휴대폰 카메라로 읽습니다. 위치: **회계 › 창고 · 바코드**(매입 · 경비 묶음) · SB-ADM-ACC-400.

| 항목 | 내용 |
|---|---|
| 창고 | acct_warehouses · 처음 「본 창고」(MAIN) 하나 · 본 창고 · 재고 남은 창고는 못 끔 |
| 원가 | ⑫ 이동평균은 **회사 전체(옵션마다) 그대로** — 창고는 수량만 나눔 |
| 수불부 | acct_stock_moves.warehouse_id(비면 본 창고 — 옛 줄 · 결제 자동 출고 · 취소 반입) |
| 이동 | acct_stock_transfers(보낸 창고 MOVE_OUT · 받은 창고 MOVE_IN 을 한 줄로 · 쌓기만 · 원가 전표 없음 · 보내는 창고 수량 넘지 못함 ACCT_WH_STOCK) |
| 창고별 수량 | v_acct_wh_stock(수불부 + 이동) |
| 창고 입고 | ⑫ 입고와 같음(매입 번호면 입고 전표 없음) · 창고만 적음 |
| 창고 실사 | 센 수량 → 그 창고 장부 수량과 차이만 ⑫ 실사 조정(ADJUST · 매출원가 조정 전표) · SUPER · 사유 |
| 바코드 | acct_barcodes(옵션마다 하나 · 비우면 「상품 코드-옵션 순서」 · 한 번 정하면 못 바꿈) · Code128-B SVG(화면에서 그림 · 인쇄) · 읽기는 브라우저 BarcodeDetector(없으면 글자 넣기) |

## 2. 주의
1. 결제 자동 출고는 본 창고에서 나간 것으로 셉니다 — 다른 창고에서 보냈으면 「이동」으로 맞추십시오(출고 창고 고르기는 소개몰 주문 쪽 변경이라 다음에).
2. 카메라 읽기는 크롬 · 안드로이드 등 BarcodeDetector 를 지원하는 브라우저만 · 아이폰 사파리는 글자를 넣습니다.
