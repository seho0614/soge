# 677 소개몰 재구매 알림 — v10.539 (D283 · 2026-11-20)

> 대표 11/20 「(53) ② 재구매 알림」 · mkx.rebuy 처음 off · 광고성 정보 — 마케팅 수신 동의자만

## 1. 결론
- 상품마다 **사용 일수**를 정해 두면, 산 날(결제일 · 한국) + 사용 일수 − **며칠 전**에 회원 알림 한 번(「(광고) 다시 주문할 때예요」).
- 개월 옵션(1 · 3 · 6개월 분)이 있는 품목은 **개월 × 30일**이 먼저이고, 수량만큼 곱합니다.
- 품목 하나에 한 번 · 회원 하루 한 통 · 하루 전체 상한 300 · 웹 푸시(①)가 켜진 기기면 그대로 푸시도 갑니다.

## 2. 보내지 않는 경우(기록에 까닭)
| 까닭 | 뜻 |
|---|---|
| NO_CONSENT | 지금 마케팅 수신 동의 없음(광고) |
| REBOUGHT | 그 결제 뒤 같은 상품을 또 삼 |
| NOT_ON_SALE | 상품이 판매 중 아님 |
| INACTIVE | 쓰지 않는 계정 |
| OPTED_OUT | 회원이 이 알림 종류를 끔 |
| TOO_LATE | 알릴 날에서 mkx.rebuy_late_days(7일) 넘게 지남 — 켤 때 옛 주문이 한꺼번에 나가지 않게 |
- 21시 ~ 8시에는 돌리지 않습니다(정기 작업 10:05 · 운영 「지금 한 번」도 밤에는 422) — 야간 광고 동의를 따로 묻지 않으려는 것.
