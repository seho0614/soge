# 756. 인건비 시뮬레이션 (v10.614 · 2026-11-21)

> 18차 ㉚. 회계 › 인사 › 새 탭 「인건비 시뮬레이션」(키 `bzx-hc-sim` · 퇴직금 · 연차 뒤). SQL `sql/bzx_614_hc_sim.sql`.

## 1. 결론

- 채용 계획(자리 · 인원 · 월 기본급 · 비과세 · 입사 달 · 퇴사 달)을 넣으면 **달마다 인원 · 지급액 · 회사 4대보험 · 퇴직금 적립 · 합계**를 셈합니다. 지금 직원(재직자)을 함께 넣을지 고르고, 「지금 직원만」과 차이(늘어나는 몫)도 보여 줍니다.
- 요율은 **급여 대장 요율표 그대로**(`acct_payroll_rates` · `ratesOf` · 해마다) — 일반 원칙 값(docs/555 「일반 원칙 값 적용」 표 · 2026 고시)이 처음 값이고 **SUPER 가 회계 › 급여 › 요율에서 고침**.
- 결과는 **합계만**(사람 이름 · 개인 급여 없음) · 실제 급여 · 장부에는 아무것도 쓰지 않음 · 계획만 저장(`bzx_hc_plans`).

## 2. 셈(일반 원칙 · 급여 셈 calcLine 과 같은 식)

| 항목 | 식 |
|---|---|
| 과세 | 지급액 − 비과세 |
| 국민연금(회사) | 과세를 기준소득 하한 ~ 상한(`np_base_min` · `np_base_max`)으로 자른 값 × `np_rate` |
| 건강(회사) · 장기요양 | 과세 × `hi_rate` · 건강보험료 × `ltc_rate` |
| 고용(회사) · 산재 | 과세 × `ei_company_rate` · 과세 × `ia_company_rate` |
| 끝수 | 모두 10원 미만 버림 |
| 퇴직금 적립 | 지급액 ÷ 12(퇴직급여보장법 1년 30일분 평균임금의 달 근사) — 1년이 안 돼 나가는 자리는 실제 지급 없음(줄에 「1년 미만」) |
| 인상 | 시작 달부터 12개월마다 한 번 `raise_pct`% |

- 소득세는 회사 비용이 아니라 뺍니다(간이세액표를 사람 · 달마다 묻지 않음). 상여 · 수당 · 연차수당은 넣지 않음.
- 요율이 「초안」이거나 빠지면 화면에 경고(노무사 확인 전).
