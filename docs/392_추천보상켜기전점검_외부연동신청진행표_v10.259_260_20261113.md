## 2. 지키는 것

| 지키는 것 | 어떻게 |

| 보상 규칙 | 점검은 읽기만(SELECT) — 켜기 · 점수 · 상한은 전처럼 SUPER 가 「바꾸기」로 |

| 적은 날짜 | 업체에 확인하지 않고 적은 값을 그대로 보여 줌 |

## 3. 알아 둘 것

1. 운영은 지금 본인인증이 시험용(STUB)이라 켜기 전 점검이 **「위험 1」**로 나옵니다 — NICE 연동 뒤 「됨」. 그 전에 켜면 가짜 계정으로 보상을 받을 수 있다는 뜻입니다(막지는 않음).
2. 처리방침 줄은 「추천」이라는 글자가 있는지만 봅니다 — docs/393 1.1 을 게시하면 「됨」.
3. 진행표의 「신청」은 IP 가 필요 없는 연동(전자계약 등)이면 지금 「신청일」(= IP 신청일 칸)을 그대로 씁니다.
