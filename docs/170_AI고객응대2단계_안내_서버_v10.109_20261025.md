### 3-1. 알아 둘 것

- 같은 상담에 동시에 두 번 보내는 것을 막는 잠금은 API 한 프로세스 안에서만 듣습니다(지금 운영은 API 프로세스 1개). 여러 개로 늘리면 DB 잠금으로 바꿀 것.
- D121 을 점검판에 적용한 뒤 고쳐서 점검판 DB 를 처음부터 다시 만들었습니다(`docker compose down -v` → 시험 자료 다시 채움 · 운영에는 D121 이 아직 없어 상관없음).
- MOCK 엔진은 늘 같은 시험 답을 냅니다. 실제 답 품질(근거 밖 질문을 넘기는지)은 운영에서 켠 뒤 목록으로 봅니다.
- 프롬프트 캐시는 지시문이 일정 길이 이상일 때만 걸립니다(모델마다 최소 길이가 다름 · 적용일 Anthropic 문서로 확인). 걸리지 않아도 동작은 같고 비용만 조금 늘어납니다.
- 요금(Haiku 5.5 입력 $0.10 · 출력 $0.50 / 100만 토큰)은 D116 요금표(10/06 사본) — 계약 전 다시 확인.
