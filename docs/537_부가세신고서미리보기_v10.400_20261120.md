# 537. 부가세 신고서 미리보기 (v10.400 · 2026-11-20)

> ⑭ 첫째(D247). 대표 11/19 「부가세 신고서 미리보기」.

## 1. 결론

- 운영 화면 **회계 › 부가세 신고서**(SUPER · PAYOUT): 분기를 고르면 **일반과세자 부가세 신고서 칸**을 전표 · 매입 관리로 채워 보여 줍니다.
- 매출 — (1) 과세 세금계산서 발급분 · (3) 신용카드 · 현금영수증 발행분 · (4) 기타 · (5)(6) 영세율(지금 0) · (9) 매출세액 합계 · 면세 수입금액(소개몰 면세 상품) 따로.
- 매입 — (10) 세금계산서 수취분 일반매입 · (11) 고정자산 매입(⑬ 고정자산 계정이 같은 전표에 있으면) · (14) 그 밖의 공제(카드 · 현금영수증 수령) · (15) 공제 매입세액 합계 · (16) 공제받지 못할 매입세액(⑫ 불공제 · 참고).
- 납부(환급)세액 = 매출세액 − 매입세액 · 확정 신고 분기(2 · 4분기)는 **전자신고 세액공제**(`acct.vat_efile_credit` 처음 10,000원) 뺌.
- **미리보기**입니다 — 예정고지세액 · 감면 · 가산세 · 영세율은 넣지 않습니다. 실제 신고는 세무사 · 홈택스. 칸 번호 · 공제액은 **세무사 확인**.
- CSV 내려받기는 기존 내려받기 승인 대상 **ACCT_TAX**.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D247** | 설정 `acct.vat_efile_credit` |
| API | `GET /admin/acct/tax/vat-form?q=YYYY-n` · `GET /admin/acct/tax/vat-form/export?q=`(승인) |
| 운영 화면 | 회계 › **부가세 신고서**(SB-ADM-ACC-150) |

## 3. 셈 근거

| 칸 | 어디서 |
|---|---|
| 매출 | 전표 중 부가세예수금(VAT_OUT) · 면세 매출 줄이 있는 것 — 수익 계정 공급가 · VAT_OUT 을 전표 증빙별로 |
| 매입 | 전표 중 부가세대급금(VAT_IN) 이 있는 것 — 증빙 세금계산서 / 그 밖 · 같은 전표에 비품(FIXED_ASSET) 차변이면 고정자산 |
| 불공제 | ⑫ 매입 관리 `deductible = false`(간이영수증 · 기업업무추진비 등) — 이미 비용에 들어가 납부세액 셈에는 없음 |
