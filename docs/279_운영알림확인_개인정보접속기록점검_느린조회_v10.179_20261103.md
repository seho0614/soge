## 3. 운영에서 (적용 뒤)
1. 운영 화면 › 위험감지 › **운영 알림** — 지금까지 쌓인 알림(하루 요약 · 시험 결제 주문 등)을 종류별로 「모두 확인」하면 「확인 안 한 알림」이 0 이 됩니다. 긴급(CRITICAL)이 남아 있으면 postcheck 가 실패로 봄.
2. 매달 초 — 위험감지 › **개인정보 접속기록**(SUPER)에서 지난달을 열어 「살펴볼 것」 운영자를 확인하고 메모로 「점검 완료」.
3. 「지켜보기」 느린 조회가 자주 쌓이면 그 SQL 모양을 알려 주십시오(색인 · 조회 고치기).

## 4. 넣지 않은 것
- 개인정보 접속기록 내려받기(엑셀) — 화면 요약 · 점검 기록으로 시작
- 느린 조회 알림 · DB 저장
- 회원 상세 외의 조회 화면(매물 · 거래 상세 등)을 접속기록에 더하기 — 어디까지가 「개인정보 조회」인지 법무 확인 뒤

## 5. 확인이 필요한 것
- **개인정보의 안전성 확보조치 기준**(개인정보보호위원회 고시)이 정한 접속기록 점검 주기 · 보관 기간 · 대상 — 고시는 바뀔 수 있어 **최신판 확인 필요**. 이 판은 「월 1회 점검 · 기록을 지우지 않음」을 기준으로 만듦(보관 기간 정리는 넣지 않음).
