# 736. 운영 화면 「?」 도움말 (v10.594 · 2026-11-21)

> 15차 보안 · 기반 ⑩. **사용자 설명서 표(help_docs · v10.203 D180)를 그대로** 씁니다.

## 1. 결론

- 운영 화면 모든 탭의 제목 옆에 **「?」** 단추. 누르면 그 탭 설명이 제목 아래 펼쳐집니다(누를 때만 부름 · 탭을 옮기면 닫힘).
- 글은 help_docs 의 새 종류 **`ADMIN_GUIDE`(운영 화면 도움말)** — 1판을 마이그레이션이 넣음(없을 때만 · 절 15개). 회원용 `USER_MANUAL`(AI 상담이 읽는 글)은 건드리지 않습니다.
- 탭 → 절 찾기: ① 이은 것(`sec2_tab_help`) ② ADMIN_GUIDE 절 제목 끝 **`[탭 키]`** ③ ADMIN_GUIDE 절 제목에 탭 이름 ④ USER_MANUAL 절 제목에 탭 이름. 없으면 「아직 없습니다」.
- 고치기는 관 관리 › **화면 도움말**(SUPER · 새 판 · 옛 판은 남음 — DB 가 고치기 · 지우기를 막음). 잇기는 「?」 안에서(SUPER · 절 고르기).

## 2. API

| 방법 | 주소 | 역할 | 설명 |
|---|---|---|---|
| GET | `/api/v1/admin/help/tab?key=&label=` | 운영 역할 모두 | 절 하나(4000자까지) · SUPER 는 이을 절 목록 |
| GET | `/api/v1/admin/help/tab-links` | ADMIN · SUPER | 이은 것 |
| PUT | `/api/v1/admin/help/tab-links/{key}` | SUPER | 잇기(그 절이 지금 판에 있어야) · 감사 SEC2_TAB_HELP_SET |
| POST | `/api/v1/admin/help/tab-links/{key}/remove` | SUPER | 잇기 지우기 |
| GET | `/api/v1/admin/help/guide` | ADMIN · SUPER | 지금 판 · 절(탭 키) · 판 목록 |
| POST | `/api/v1/admin/help/guide` | SUPER | 새 판(100 ~ 20000자 · ### 절 하나 이상 · 같은 본문이면 안 만듦) · 감사 HELP_GUIDE_SAVE(판 · 글자 수만) |

- 화면 SB-ADM-SCX-020(관 관리 › 화면 도움말 · `scx-help` · 사용자 설명서 뒤).
- `GET /admin/help/tab` 은 perm_route_map 에 다섯 업무(scx-help · home · manual · my-hr · ofc-notify)로 걸어 둠 — 권한그룹 판정(GROUPS)에서도 대부분의 운영자가 「?」를 씀(하나라도 VIEW 면 통과).

## 3. 절 쓰는 법(ADMIN_GUIDE)

```
## 묶음 이름
### 탭 이름 [탭-키]
- 무엇을 하는 화면인지 한 줄
- 기한 · 주의 · 누가
```
- 탭 키는 운영 화면 주소 `#/탭-키` 의 그 글자(adminMenu TABS).
- 「?」 화면은 줄 · `- ` 목록 · `**굵게**` 만 그림(HTML 은 그리지 않음).

## 4. 시험 (test_v1594)

② API — 탭 키로 찾음(ops-alerts · via KEY) · 이름으로 찾음 · 없는 탭 found false · 잘못된 키 422 · SUPER 잇기 → via LINK · 없는 절 422 · 지우기 · REVIEWER 도 tab 읽음 · ADMIN 잇기 403 · 새 판 저장 → 판 +1 · 같은 본문 판 그대로 · USER_MANUAL 판 그대로
