# 370. 업종 정정신고(통신판매중개) 기록 — 입점 열기 준비 — v10.231 (2026-11-10)

> **마이그레이션 1개 D199(236 → 237)** · 새 API 1개 · 운영 화면 「소개몰 판매자」 탭 맨 위 「입점 열기 준비」 한 줄.

## 1. 왜

- v10.229(docs/367) 「입점 열기 준비」의 업종 정정신고 줄은 기록할 곳이 없어 늘 「대표 확인」이었고 판매 열기 판단에서 뺐습니다.

## 2. 바뀐 것

| 곳 | 내용 |
|---|---|
| D199 | 설정 `mall.biz_report_no`(접수번호 · 형식 검사) · `mall.biz_report_at`(신고 날짜 YYYY-MM-DD) — 처음은 비어 있음 |
| API | `POST /admin/health/tenant/biz-report`(SUPER · 감사 HLT_BIZ_REPORT) — 둘 다 적거나 둘 다 비움(422 BIZ_REPORT_BOTH) · 날짜는 2020-01-01 ~ 오늘 한국 날짜(422 BIZ_REPORT_DATE) · 돌려주는 값은 입점 열기 준비 점검 |
| 준비 점검 | 업종 정정신고 줄 — 둘 다 있으면 「준비됨」(`2026-11-20 신고 · 접수번호 …`) · 없으면 「막힘」(기록 없음) · **판매 열기 판단에 다시 넣음** · 응답에 `bizReport` |
| 일반 설정 | `PATCH /admin/site-settings` 로 `mall.biz_report_*` 를 바꾸는 것도 SUPER 만(403 BIZ_REPORT_SETTING_SUPER) |
| 화면 | 그 줄에 「적기」(SUPER) → 날짜 · 접수번호 · 저장 · 비우기 · 취소 |

- 적은 값을 그대로 믿습니다 — 신고가 실제로 처리됐는지는 확인하지 않습니다.
- 스위치를 막는 규칙은 그대로(이 줄이 준비돼도 판매 열기 스위치를 저절로 켜지 않음).
