# 642. 회원 간 1:1 대화 (v10.504 · 2026-11-20)

> ㊸ 회원 2 의 ④. 스위치 `mbx.dm` **처음 off** · **켜기 전 법무 확인**(5절). 정기 작업 `mbx_daily`(매일 04:35 · 보관 기간 정리).

## 1. 결론
**이미 있는 거래 · 문의의 당사자끼리만** 글로 대화합니다(파일 없음). 거래(deals)의 **사는 쪽 · 파는 쪽 · 소개자** 중 두 사람, 문의 대화(conversations)의 **문의한 사람 · 등록자**. 연락처 · 계좌 · 메일 글자를 감지해 **경고하고 가리며**(INV-9 · INV-11 정신 — 소개비를 빼고 대금을 직접 주고받자는 유도를 막음), 신고된 대화만 운영자가 **사유를 적고** 엽니다. 화면 `/my/messages`(대화함 SB-MYP-MBX-040) · `/my/messages/{id}`(대화 SB-MYP-MBX-050) · 운영 **회원 › 회원 대화 신고**(SB-ADM-MBX-020).

## 2. 1:1 문의(SB-HOM-MCH-010)와의 관계
| | 1:1 문의(그대로) | 회원 대화(새로) |
|---|---|---|
| 근거 | 매물 · 요청 하나 | 거래 또는 문의 대화 하나 |
| 당사자 | 문의한 사람 · 등록자 | + **소개자**(거래 3자 중 두 사람) |
| 귀속 | 대화를 여는 순간 소개코드 귀속(INV-2) | **귀속을 바꾸지 않음**(이미 있는 거래 · 문의에서만 열림) |
| 연락처 | 가림(mask) | 감지 → 경고 → 방식대로(3절) |
| 신고 · 보관 · 운영 열람 | 없음 | 있음 |
- 1:1 문의 코드(conversation.service.ts)는 **고치지 않음**. 둘을 하나로 합치는 것은 다음 후보.

## 3. 규칙
| 항목 | 규칙 |
|---|---|
| 열기 | `POST /me/dm` { basisType(DEAL · INQUIRY) · basisId · side(BUYER · SELLER · INTRODUCER · INITIATOR · COUNTERPART) } — **상대 계정 번호를 화면에 내리지 않음** · 본인인증 · 이미 있으면 그 대화 · 상대가 활동 중이 아니면 409 `MBX_DM_GONE` |
| DB 도 봄 | `trg_mbx_dm_thread_guard` — 근거의 당사자 두 사람이 아니면 넣지 못함 · 근거 · 당사자 바꾸지 못함 |
| 글 | 1 ~ 1,000자(서버 · DB CHECK 같음) · **고치지 않음**(읽음 표시만 · DB 트리거) · 지우기는 보관 정리(`app.mbx_purge`)만 |
| 수 제한 | 1분 `mbx.dm_rate_per_min`(10) · 하루 `mbx.dm_rate_per_day`(300) — 넘으면 422 `MBX_DM_RATE` |
| 감지 | 전화번호(휴대폰 · 지역번호) · 메일 주소 · 계좌번호로 보이는 숫자(하이픈 묶음 · 10 ~ 14자리 · 은행 이름 + 숫자) · 플랫폼 밖 표현(직거래 · 카톡 · 계좌로 보내 …) |
| 방식 `mbx.dm_pattern_mode` | **WARN** 경고 → 「그래도 보내기」면 그대로 · **MASK**(처음) 경고 → 「그래도 보내기」면 연락처 · 계좌 · 메일을 `***` 로 가려 저장 · **BLOCK** 연락처 · 계좌 · 메일이 있으면 보내지 않음(422 `MBX_DM_BLOCKED`) — 플랫폼 밖 표현은 어느 방식이든 경고만 |
| 경고 | 422 `MBX_DM_WARN`(details.reasons) → 화면 「고치겠습니다 · 그래도 보내기(confirm=true)」 · 보내기 전 확인 `POST /me/dm/check`(저장 안 함) |
| 감지 기록 | 메시지 줄 `hit_codes`(종류만) — 운영은 종류별 수(30일)만 봄 |
| 차단 | 한쪽이 차단하면 서로 못 보냄(409 `MBX_DM_BLOCKED_BY`) · 차단한 사람만 풂 |
| 새 글 알림 | `MBX_DM_NEW`(인앱 · 끌 수 있음) — 같은 대화의 안 읽은 알림이 30분 안에 있으면 또 보내지 않음 |
| 꺼짐 | 새로 열기 · 보내기 422 `MBX_OFF` · 목록 · 읽기 · 차단 · 신고는 됨 |
