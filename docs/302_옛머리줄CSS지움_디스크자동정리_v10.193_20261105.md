## 1. 옛 머리줄 CSS 지움 (sgb-core `site/src/styles`)

v10.189(docs/296)에서 옛 머리줄 코드를 지울 때, CSS 는 시안 · 옛 시험이 읽고 있어 남겨 두었다. 이번에 지웠다.

| 파일 | 지운 것 | 남긴 것 |
|---|---|---|
| `b2.css` | `.b2-hd` · `.b2-hdr` 이 든 규칙 13개(묶음 `.b2-hd, .b2-ft, .main-b2` 에서는 `.b2-hd` 만 뺌) | 바닥줄 `.b2-ft` · `.main-b2` 값 이름 · `.b2-in` |
| `home.css` | `.home-hd` · `.home-hdr` 이 든 규칙 22개 | `.home-in` · `.home-txt` 등 본문 · 바닥줄 규칙 |
| `money.css` | `[data-b2-tone=money] .b2-hd` · `.b2-hdr` 규칙 8개 | 생활금융 본문 · 메뉴 규칙 |

- 화면 코드(tsx · ts)에서 옛 이름을 쓰는 곳 없음(주석 한 곳뿐). 시안(`spec/proto.html` · `site/public/proto`)은 그대로.
- 휴대폰에서 「파트너센터」 글자 숨김은 공통 머리줄 `site-head.css` 의 `.sh-txt` 가 맡고 있음(지운 `.home-hdr .home-txt.pc-only` 는 닿지 않던 규칙).

## 2. 점검 전 개발 쪽 디스크 자동 정리 (sgb-infra `qa/sgb-check.sh` · `tools/home/sgb-check.sh` · `~/sgb-check.sh`)

11/5 운영 적용 때 디스크가 84% 였다(개발 · 운영이 같은 48GB 디스크 · 개발 쪽 25GB). 손으로 정리해 55% 로 내렸고, 앞으로는 `~/sgb-check.sh` 가 점검을 시작할 때마다 스스로 정리한다(`down` 에서는 안 함).

| 지우는 것 | 기준 |
|---|---|
| 점검 결과 `~/check-results` | 최근 19개 + 이번 것 = 20개만 남김 |
| 도커 이미지 | 이름 없는(dangling) 것만 — 기준 이미지(sgb-qa · playwright · node · postgres)는 그대로 |
| 도커 볼륨 | 어느 컨테이너에도 매이지 않은 이름 없는 볼륨만 |
| 빌드 캐시 | 4GB 넘는 부분만(다 지우면 다음 점검이 오래 걸림 — 11/5 확인) |

- 정리 뒤 `== 디스크 정리 뒤 사용 NN%` 한 줄. 85% 이상이면 `[주의]` 한 줄(운영 쪽 `cleanup.sh` 확인 권함).
- 운영 킷 `~/kits/release` 는 건드리지 않음. 건너뛰려면 `SGB_NO_CLEAN=1 ~/sgb-check.sh …`.
