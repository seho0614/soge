# 761. 사용자 설명서 — v10.559 ~ 617 회원 기능 절 더하기 (v10.622 · 2026-11-22)

> 대표 11/22 승인(다음 개발 묶음 v10.618 ~ 626 · 후보 ②). 회원용 사용자 설명서(help_docs `USER_MANUAL` · D180 · 1판 = docs/323)에 **v10.559 ~ 617 에서 회원 화면에 생긴 기능 15개**의 절을 새 판으로 더합니다. 사용자 웹 `/guide/manual` 과 AI 상담이 지금 판을 읽으므로, 이 판이 들어가면 두 곳 모두 새 기능을 안내합니다. 마이그레이션 **D304**.

## 1. 결론

1. 설명서 끝에 「## 10. 새로 생긴 기능(2026-11)」 묶음과 절 **15개**(10-1 ~ 10-15)를 붙인 **새 판**을 만듭니다. 1판(또는 SUPER 가 화면에서 저장한 지금 판)은 지우거나 고치지 않습니다(help_docs 는 쌓기만).
2. 근거: 판 문서(docs/698 ~ 759)의 결론 · 스위치 처음 값(마이그레이션 `site_settings` 줄) · 사용자 웹 화면 글자(site/src 의 ko 사전 · 화면 파일) · 서버 오류 문구. **절에 적은 「」 화면 이름 · 안내 글은 모두 사용자 웹 소스 · 서버 문구에 있는 글자**이고(시험이 하나씩 확인), 주소는 실제 화면(page.tsx)이 있는 것만 적었습니다.
3. **처음 꺼진 기능 12개**는 절 끝에 「(운영에서 켠 뒤 보입니다)」를 붙였습니다. 켜진 채 나간 것(첫 거래 안내 `grw.first_steps` · 매물 등록 도우미 `grw.fill_helper`) · 스위치 없이 늘 보이는 것(낯선 기기 로그인 · 파트너센터 하위 메뉴)에는 붙이지 않았습니다.
4. 본문 길이 **18,797자**(1판 15,348 + 구분 줄 · 묶음 제목 · 절 3,449) — 한도 20,000자 안. SUPER 가 화면에서 더 쓸 자리는 약 1,200자 남습니다. 지금 판이 길어 자리가 모자라면 **앞 절부터 들어가는 것만** 붙입니다(넘쳐서 실패하지 않음).
5. 같은 「### 제목」이 지금 판에 이미 있으면 그 절은 건너뜁니다 — 다시 돌려도 새 판이 생기지 않습니다(버리는 DB 에서 두 번 돌려 2판 하나만 확인).

## 3. SQL 이 하는 일(`prisma/migrations/D304_help_user_manual_v1559_617/migration.sql`)

- 지금 판(`v_help_doc_current` · USER_MANUAL)을 읽고, 그 본문에 「### 제목」이 없는 절만 고릅니다.
- 2만 자에서 지금 본문 · 구분 줄(`---`) · 묶음 제목 몫을 뺀 자리 안에 들어가는 절만 앞에서부터 붙입니다.
- `max(version) + 1` 판으로 INSERT 한 번(제목은 지금 판 그대로 · 메모 「회원 기능 절 더함(v10.622 · docs/765 · v10.559 ~ 617)」). 붙일 절이 없으면 아무것도 하지 않습니다.
- 표 · 함수 · 트리거 · 설정을 새로 만들거나 고치지 않습니다. UPDATE · DELETE 없음.

## 4. 운영 적용

- 마이그레이션 D304 가 apply 때 함께 돕니다 — 따로 할 일 없음.
- 적용 뒤 확인(보기만): 사용자 웹 `/guide/manual` 맨 아래에 「10. 새로 생긴 기능(2026-11)」 절 15개 · 운영 화면 › 관 관리 › 사용자 설명서 에서 지금 판 번호가 하나 올라감.
- 운영에서 SUPER 가 설명서를 이미 고쳐 저장했다면 그 글 끝에 붙습니다(고친 글은 그대로). 자리가 모자라면 들어간 절까지만 붙으니, 빠진 절은 화면에서 직접 더하십시오.
- 「(운영에서 켠 뒤 보입니다)」 절은 그 스위치를 켤 때 고객센터 안내에 함께 쓰십시오. 특히 `sec2.member_mfa` 는 docs/734 대로 이 절(10-4)이 있어야 켭니다.

## 5. 되돌리기

- 옛 판으로 돌아가려면 운영 화면 › 관 관리 › 사용자 설명서 에서 앞 판 본문으로 **새 판 저장**(SUPER) — 판은 지우지 않습니다.
- 앱을 v10.617 로 되돌려도(rollback) 옛 판은 설명서 표를 같은 방식으로 읽으므로 그대로 보입니다(새 판에 절이 더 있을 뿐 · 해 없음).
