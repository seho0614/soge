## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `POST /me/health/seller/notices/{id}/read` | 판매자 | 읽음 기록 · 이 판매자에게 보이는 소개몰 공지만(아니면 404) · 판매자 아님 403 |
| `POST /admin/health/rate-schedules/{id}/remind` | ADMIN · SUPER | 안 읽은 영향 판매자에게만 `SELLER_RATE_SCHEDULED` 「[다시 알림] …」 · 409 `REMIND_NOT_READY`(공지 게시한 예정 예약만) · `REMIND_TOO_SOON`(24시간) · `ALL_READ` · 감사 `HLT_RATE_NOTICE_REMIND` |
| `GET /admin/health/rate-schedules` | ADMIN · SUPER | `noticeReads` · `remindedAt` · `reminds` 더함 |
| `GET /admin/launch-watch/owner-todo` · `POST …/owner-todo/mark` | SUPER(적기) | 새 4줄 · 직접 확인 키 `rate-legal` |
| `POST /admin/notices` · `PATCH /admin/notices/{id}` · `POST /admin/notices/{id}/publish` | SUPER | `notifyConfirm` — 기준 이상이면 「모두에게 알림」 · 422 `NOTIFY_CONFIRM_REQUIRED` |
| `GET /admin/notices/audience` | SUPER | `confirmMin` · `needsConfirm` · `confirmText` 더함 |
| `GET /admin/notices` | SUPER | `notifying`(보내는 중) 더함 |
