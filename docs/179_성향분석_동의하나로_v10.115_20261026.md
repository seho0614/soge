# 179. 관심 성향 — 동의를 맞춤형 광고 약관 하나로 · v10.115 (2026-10-26)

> 대표 「성향 분석 새로 점검 및 수정」 → 점검(정적) → 결정 **「가. 약관(ADPERSONAL) 하나로」** → 계획 「승인」
> 마이그레이션 **D123**(합계 161) · 서버 · 손님 화면 · 운영 화면 문구

## 1. 점검에서 찾은 것 (고치기 전)

| # | 결함 | 심각도 |
|---|---|---|
| H1 | 광고 고르기 · 기록은 설문 저장만 보고 약관 ADPERSONAL 은 보지 않음 — **약관을 꺼도 타게팅이 계속됨** · 성향도 남음 | 높음 |
| H2 | 행동 학습의 「동의한 사람만」 조건(`consented_at IS NOT NULL`)이 늘 참 · 등록 전 클릭도 학습 · 화면은 「행동 데이터를 보지 않습니다」 | 높음 |
| H3 | 설문 체크 상자는 약관 판 · 시각을 남기지 않음 | 높음 |
| M | 다시 등록해도 「행동 학습」 출처 · 입력 검증 없음(점수 부풀리기 · 큰 입력 500) · `/me/persona` 가 설문과 따로 계산 · 「추천 정렬에 쓰입니다」(사실과 다름) · 비동의자에게도 성향 겨냥 광고 · 해지가 클릭 기록을 남김 · **광고 기록 익명화가 「고칠 수 없음」 둑에 막혀 실제로는 실패**(계정 삭제의 회원 칸 비우기도) | 보통 |

## 2. 고친 것

| # | 무엇 | 내용 |
|---|---|---|
| 1 | 동의 하나로 | 성향 저장 · 바꾸기(학습 포함) · 광고 고르기 · 기록이 모두 **약관 ADPERSONAL 의 지금 동의**(`fn_adpersonal_on`)를 봄 |
| 2 | 등록 = 약관 동의 | 설문의 동의 체크로 등록하면 약관 동의 기록(판 · 시각 · IP)을 같은 트랜잭션에 남김 · 체크 옆 「약관 전문 보기」 · 약관이 발행 전이면 422 `CONSENT_UNAVAILABLE`(진단은 됨) |
| 3 | 철회하면 정리 | 약관 화면이나 「성향 쓰지 않기」로 끄면 DB 트리거가 성향 삭제 · 광고 기록의 회원 연결 끊음(익명화 · 유출 감사 줄) · 다시 등록해도 옛 클릭은 안 씀 |
| 4 | 광고 기록 둑 | 여전히 고치기 · 지우기 금지 — **회원 칸(account_id · member_hash)만 비우는 익명화**만 허용(과금 칸은 그대로인지 비교) |
| 5 | 광고 고르기 | 동의가 없거나 비회원이면 **성향 지정이 없는 소재만** |
| 6 | 행동 학습 | 약관 동의가 있는 회원의 **등록 뒤** 클릭만 · 감시 보기는 「그 시각 약관 동의 없이 바뀐 건」 · 다시 등록하면 출처 MEMBER |
| 7 | 답 검사 | 있는 문항 · 보기만 · 한 개만 고르는 문항 1개 · 중복 · 문항 20개 넘으면 422 `BAD_ANSWER` |
| 8 | 문구 | 「답한 내용과, 맞춤형 광고에 동의한 뒤 광고를 누른 기록으로 성향이 바뀔 수 있습니다」 · 「광고를 고르는 데만」 · 「전체 공개 광고」 → 「성향을 쓰지 않는 광고」 |
| 9 | `/me/persona` | 등록된 성향을 그대로 |
| 10 | 가입 5단계 | 4단계에서 맞춤형 광고에 동의한 경우에만 성향 저장(5단계 체크로 4단계 「동의 안 함」을 뒤집지 않음) · 문구 |
| 11 | 운영 화면 | 「옮길 대상 미리보기」 칸 이름을 실제 값(동의 없이 바뀐 건 — 0 이어야 함)으로 |
| 12 | 정리(D123 ⑤) | 약관 동의 없이 저장돼 있던 성향 삭제 · 그 회원의 광고 기록 익명화 · 그때 옮겨진 학습 기록은 지우지 않고 「되돌림」 표시 |
| 13 | 동시 처리 | 등록과 철회가 동시에 와도 회원 단위로 차례(`pg_advisory_xact_lock`) |

불변식 PRF-1 ~ 3(약관 동의 없는 성향 0 · 철회 트리거 켜짐 · 동의 없이 바뀐 학습 0) 을 통합 검정에 더함.

## 4. 운영에서

- **약관 ADPERSONAL 이 운영에서 발행되어 있어야** 성향 등록이 됩니다(발행 전이면 진단만 · 「약관 준비 중」 안내). 운영 DB 상태는 sgbdev 가 볼 수 없음 — 확인 필요.
- 반영할 때 약관 동의 없이 저장돼 있던 성향은 지워집니다(운영 회원 8명 · 영향 작음).
- **약관 본문**은 아직 「이용 기록 기반」 — 실제(설문 답 + 동의 뒤 광고 클릭)에 맞게 고치는 것은 처리방침 개정(docs/176)과 함께 법무 확인 뒤 새 판으로.
