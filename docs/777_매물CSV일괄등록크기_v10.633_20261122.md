# 777. 매물 CSV 일괄 등록 — 받는 크기 300KB — v10.633 (2026-11-22)

## 1. 결론

- 매물 CSV 일괄 등록(v10.602 · docs/744)은 화면 안내와 서버 검사가 **「CSV 200KB 까지」** 인데, 서버가 한 번에 받는 본문은 기본 **100KB** 라 100KB 를 넘는 CSV 는 미리보기에서 500 오류(v10.632 부터 413)로 실패했습니다. 한글 CSV 50줄이면 넘을 수 있습니다.
- 이번 판부터 **이 주소(POST /api/v1/lsq/me/bulk/preview)만 본문 300KB** 까지 받습니다. CSV 를 JSON 으로 감싸면 줄바꿈 · 따옴표가 늘어나 200KB CSV 가 200KB 를 조금 넘기 때문입니다. CSV 자체는 그대로 200KB 까지(LSQ_BULK_TOO_BIG).
- 다른 API 는 그대로 100KB 입니다.

## 2. 바뀐 것

| 항목 | 내용 |
|---|---|
| 서버 | `src/common/security-headers.ts` — 이 주소에만 본문 읽기(300KB) · 이름 감싼 함수 `lsqBulkBody`(v10.177 함정 · Nest 전체 본문 읽기를 건너뛰지 않게) |
| 오류 | 300KB 넘음 → 413 PAYLOAD_TOO_LARGE · JSON 깨짐 → 400 VALIDATION_ERROR · 영어 글 2줄 |

## 3. 운영 적용

- 코드만. 스위치 `lsq.bulk` 는 처음 꺼진 채 그대로입니다.
