# 534. 계정별 원장 · 매입매출장 (v10.397 · 2026-11-20)

> ⑬ 두 번째(D246). 대표 11/19 「승인 + 통과하면 병합」 — 계정별 원장 · 매입매출장 · CSV(내려받기 승인).

## 1. 결론

- 운영 화면 **회계 › 원장**(SUPER · PAYOUT)에서 **계정별 원장 · 매출장 · 매입장**을 봅니다.
- **계정별 원장** — 계정 하나의 기간 줄(일자 · 전표 · 근거 · 적요 · 거래처 · 증빙 · 차변 · 대변 · **잔액**) · 기초(시산표와 같은 셈) · 기말. 1년 · 5,000줄까지.
- **매출장** — 매출 · 부가세예수금 줄이 있는 전표(공급가 · 세액 · 면세 · 취소 · 환불은 음수) · 거래처별 합.
- **매입장** — 부가세대급금 줄이 있거나 ⑫ 매입 · 경비 · 법인카드 전표(공급가 · 세액 · 공제 · 불공제) · 거래처별 합.
- **CSV** — 거래처 이름이 들어가 **내려받기 승인 ACCT_LEDGER**(지급 담당 요청 → SUPER 승인 · 24시간 한 번).

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D246** | 내려받기 대상 CHECK 에 `ACCT_LEDGER` · 색인 `ix_acct_lines_role_entry` |

| 운영 화면 | 회계 › **원장**(SB-ADM-ACC-120) |

## 3. 주의

1. 매입매출장은 전표 기준입니다. 부가세 신고 서식(⑭ v10.400)과 같은 숫자인지는 세무사 확인.
2. 거래처가 빈 매출 줄은 카드 · PG 결제(개인 회원)입니다.
