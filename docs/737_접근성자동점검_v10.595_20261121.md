| 종류 | 정도 | 기준 |

| HEADING | 경고 | h1 없음 · 단계 건너뜀 |

## 3. 쓰는 법

```bash
# 점검판이 떠 있을 때(~/sgb-check.sh 갈래 · 화면 확인 부탁 때) — qa 이미지 안이나 playwright 있는 곳
SITE=http://localhost:15174 python3 qa/a11y_check.py                    # 결과 qa/out_a11y/a11y_YYYYMMDD_HHMM.html · .json
SITE=http://localhost:15174 python3 qa/a11y_check.py --pages /,/login --fail-on 0
python3 qa/a11y_check.py --selftest                                        # 사이트 없이 — 문제 10종을 일부러 넣은 쪽에서 모두 찾는지
```
- 종료 코드: 0(문제 수 상관없이) · `--fail-on N` 이면 오류가 N 개 넘을 때 1 · 사이트가 안 열리면 2.
- realcheck 단계에는 아직 넣지 않음(첫 결과로 기준을 정한 뒤 대표 결정 — 넣으면 `--fail-on` 값만 정하면 됨).
