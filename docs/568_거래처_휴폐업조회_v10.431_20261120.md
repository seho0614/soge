# 568. 거래처 휴폐업 조회 (v10.431 · 2026-11-20)

> 대표 11/19 20:35 「모두개발」 → 후보 B7(외부 연동 필요 → 어댑터 · 스위치 처음 꺼짐 · 간주).

## 1. 결론
- 회원 사업자 인증이 쓰는 국세청 사업자 상태 조회(공공데이터포털 odcloud `nts-businessman/v1/status`)를 **그대로 재사용**(identity/verification.provider · resolveBizStatusProvider) — 새 어댑터 없음.
  - 키 `NTS_SERVICE_KEY`(외부 연동 키 화면 「NTS」)가 있으면 실제 조회, 없으면 **간주(VALID · stub)** — 화면에 「(간주)」 · 판단 근거로 쓰지 않음.
- 스위치 `acct.biz_status_check` **처음 off** — 켜는 것은 SUPER(정책 › 전체 설정). off 면 조회 422 BIZ_CHECK_OFF.
- 회계 › 거래처 표 사업자번호 칸에 상태(계속 · 휴업 · 폐업 · 확인 안 됨) · 「조회」 단추.
- 휴업 · 폐업(간주 아님)이면 운영 알림 `ACCT_PARTY_CLOSED`(거래처마다 한 번 · 다시 계속사업자면 풀림).
- ⑫ 매입 넣을 때 공급자가 휴업 · 폐업 거래처면 **경고만**(막지 않음 · 세금계산서 공제 확인 안내).
- 정기 작업 `acct_biz_check` 매일 06:10 — 켜져 있으면 조회한 지 30일 지난 거래처 50곳까지 다시 조회.

## 2. API
- `POST /admin/acct/parties/{id}/biz-check`(SUPER · PAYOUT · 감사 ACCT_PARTY_BIZ_CHECK)

## 3. 켜는 순서 (대표)
1. 공공데이터포털에서 「국세청_사업자등록정보 진위확인 및 상태조회 서비스」 활용 신청 → 인증키.
2. 운영 화면 › 외부 연동 키 「NTS」에 키 저장(회원 사업자 인증과 같은 키).
3. 정책 › 전체 설정 `acct.biz_status_check` = on.
