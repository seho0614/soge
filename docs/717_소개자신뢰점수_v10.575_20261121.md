# 717. 소개자 신뢰 점수 (v10.575 · 2026-11-21)

> 대표 11/21 「16개 모두 동시에」 — 11차 회원 · 거래 ③. 스위치 `mtr.trust` **처음 off**.

## 1. 결론

- 인증 · 성사 · 받은 후기 · 응답 속도 · 인정된 신고로 셈한 **0 ~ 100 점**을 **운영 화면과 본인 화면(나의공간)에서만** 보여 줍니다.
- **노출 순위 · 검색 정렬 · 광고 · 소개비 계산에 쓰지 않습니다.** 매물 · 검색 · 공급자 목록 · 광고 · 정산 · 거래 코드는 이 점수(`fn_mtr_trust` · `mtr_trust_scores`)를 읽지 않으며, 시험 `test_v1575` 가 코드에서 확인합니다.
- 산식은 초안이고 SUPER 가 칸마다 점수 · 기준을 고칩니다(사유 · 감사).

## 2. 기존 「소개 신뢰도」와의 관계 — 왜 새로 셈하나

- 이미 **「소개 신뢰도」(`fn_trust_score` · `v_account_trust` · v10.31)** 가 있고, 매물 카드 · 상세 「신용 N점」 · 나의공간 「거래신용 812」에 보입니다.
- 그런데 그 점수는 **공급자 목록 정렬(`market.service` ORDER BY trust_score)** 과 **검색 「믿을만」 거르기(trust_score ≥ 700)** 에 이미 쓰입니다. 거기에 응답 속도 등을 더하면 **노출 순서가 바뀌므로** 이번 요구(노출 순위에 쓰지 않음)와 맞지 않습니다.
- 그래서 같은 출처(본인인증 · 사업자 · 성사 · 거래 후기 · 인정된 신고)를 읽되 **따로 셈**하고(`fn_mtr_trust`), 기존 함수는 **고치지 않았습니다**.
- 두 점수가 이용자에게 함께 보이면 헷갈릴 수 있어 이번 점수는 **본인 화면에만** 둡니다(남에게 공개하지 않음).
- **대표 결정 필요**: 기존 소개 신뢰도가 노출 정렬에 쓰이는 것을 그대로 둘지(INV-11 은 자금 배지 금지라 행동 점수 정렬 자체는 위반 아님 — 광고 · 노출 정책 판단).
