## 1. 약관 화면 옛 판 정리 (TermsPanel.tsx)

| 바뀐 것 | 전 | 후 |
|---|---|---|
| 같은 약관 줄 순서 | 서버 순서(표시 순서 → 코드 → 시행일) — 초안 · 보관이 모두 시행일 「무한」이면 옛 판이 먼저 나올 수 있음 | 같은 약관끼리는 **높은 판이 위**(약관끼리 순서는 그대로) |
| 더 새 초안 · 법무 검토 판이 있는 옛 판(게시 · 보관)의 단추 | 「고치기」 → 옛 본문으로 새 판(예 2.1) 칸 | **「2.0 초안 고치기」** → 그 초안 편집 칸을 열고 그 줄로 이동 · 옛 판에서 새 판을 또 만들지 않음 |
| 옛 판 「확인」 칸 | — | 「새 판 2.0 초안이 있음 — 그 판을 고치십시오」 |

- 더 새 초안이 없으면 지금처럼 「고치기」(게시된 판 → 다음 번호 새 판).
