# 916. ERP 연결 ② — ERP 운영 알림 · 회원 알림 쓰기 길 · 로그인 넘겨주기 코드 — v10.800 (2026-11-25)

## 1. 결론

- E1 소개뱅크 쪽 둘째 판. ERP 가 소개뱅크에 쓰는 길은 **이 세 가지뿐**입니다(설계서 4-4) — 모두 ERP 서비스 토큰(v10.799)으로만.

| 길 | 내용 |
|---|---|
| `POST /internal/erp/alerts` | 운영 알림 — 종류는 ERP 업무 앞마디만(`ACCT_` · `HR_` · `HRA_` · `HRX_` · `OFC_` · `QLT_` · `LGL_` · `ITS_` · `PRR_` · `SAL_` · `ERP_` · `TRD_`) · `RAISE`(같은 시각 겹침만 막음) · `ONCE`(풀리지 않은 같은 알림이 있으면 안 올림) · `RESOLVE`(풀림) · 텔레그램 · 슬랙 · 게시판은 소개뱅크가 그대로 |
| `POST /internal/erp/notify` | 회원 화면 알림(급여 명세 · 결재 요청 …) — 종류 `ERP_…` · 받는 사람은 쓰는 계정만 · 링크는 `/…` 또는 `https://erp.sogaebank.com/…` |
| `POST /internal/erp/handoff/redeem` | 넘겨주기 코드 → 그 운영자의 증표(**같은 기기 줄 · 같은 2단계 확인 시각** — ERP 에서 2단계를 다시 묻지 않음) · 지난 코드 409 · 없거나 쓴 코드 404 |

- **로그인 넘겨주기(대표 「짧은 교환 코드」)**: 운영 화면 › 외부 연동 › ERP 연동 › **「ERP 열기」** → `POST /admin/erp/handoff`(운영자 · 2단계 확인 뒤) → 60초 · 한 번 코드 → 새 창 `ERP_WEB_URL/#/handoff?code=…` → ERP 서버가 redeem → ERP 화면 로그인.
  - 코드는 **해시만** DB 에 · 원문은 주소 조각(#)에만 잠깐(서버 로그에 남지 않는 부분) · 하루 지난 줄은 만들 때 지움.
- 운영 화면 로그인 방식(토큰 · 저장 위치)은 바꾸지 않았습니다(공유 쿠키 안 씀).
