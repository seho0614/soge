# 783. 줄인 점검 `ONLY=` — 시험만 고친 뒤 고른 시험만 같은 환경으로 — v10.639 (2026-11-22)

## 1. 결론

- 11/22 v10.627 ~ 637 전체 점검에서 회귀 2개가 깨져 시험만 고쳤고, 대표 기준(11/7 「필요한 것만」)대로 **realcheck + 고친 시험만** 다시 돌렸습니다. 그때 세션 임시 스크립트를 썼는데 **회귀 실행기가 하는 「API 를 AI MOCK 으로 다시 띄우기」를 빠뜨려** test_v1104 가 「MOCK 이 아님」으로 실패했고, realcheck 부터 다시 돌려 14분을 더 썼습니다.
- 이번 판부터 줄인 점검도 저장소 스크립트로 합니다.

```bash
ONLY="test_v1104 test_v1623" bash qa/full_check.sh feature/v10.6xx
#   ① realcheck fresh → ② 기능 점검 · ③ 새 시험 건너뜀 → ④ 회귀 실행기를 ONLY 로(그 시험만) → ⑤ main down
#   결과 폴더 기본 ~/check-results/mini_<날짜>_<시각>/summary.txt (전체 점검은 full_)
```

- 회귀 실행기(`qa/run_regression.sh`)가 `ONLY` 를 받으면 **회귀와 똑같은 환경**(AI MOCK 다시 띄움 · HOST 목록에 있는 시험은 서버에서 · 나머지는 sgb-qa 컨테이너 · 사용자 웹 뜰 때까지 기다림 · 결과 셈 reg_tally)으로 그 시험만 하나씩 돌립니다.
- 서비스 코드가 바뀌었으면 ONLY 없이 전체 점검입니다(지금 기준 그대로).
