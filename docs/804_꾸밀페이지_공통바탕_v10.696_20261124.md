# 804. 꾸밀 페이지 — 공통 바탕 (v10.696 · D321 · 2026-11-24)

> 대표 11/24 「수정 가능한 페이지: hero · 각 관의 메인 페이지 · 소개몰(메인 및 구성 수정 가능) · 페이지 목록 관리」 → 「구역 편집(권장)」 · 「한 화면에 모두(권장)」 → 「승인」. 앞 판 docs/803(v10.695).

## 1. 무엇

- 지금 디자인은 그대로 두고, 메인 · 관 메인 · 소개몰 메인을 **구역 단위로** 고칩니다 — 구역 보이기 · 순서 · 글자 · 그림 · (소개몰) 고른 상품 · 구역 사이 블록(관 페이지 블록과 같은 종류 · 공통 조각은 받지 않음).
- 초안 저장은 ADMIN · SUPER, **게시 · 예약 · 바로 되돌리기는 SUPER**(서버가 막음). 게시하면 판이 쌓이고(고치기 · 지우기 막음 · DB) 예전 판으로 초안을 만들거나 바로 되돌릴 수 있습니다.
- **게시한 판이 없으면 사용자 웹은 지금과 같습니다**(코드에 있는 처음 배치). 사용자 웹이 배치를 읽지 못해도 처음 배치로 그립니다.
- 미리보기 링크 — 로그인 없이 저장된 초안을 봄(24시간 · 최대 72시간 · 페이지마다 5개 · 끊기). 주소 끝에 `?lp=<40자>`.
- 예약 게시 — 그때의 초안을 떠 둠(예약 뒤 ADMIN 이 초안을 고쳐도 SUPER 확인 없이 나가지 않음) · 5분 뒤 ~ 90일 · 공개 · 관리 화면을 읽을 때 서버가 게시(배치 줄 더하지 않음).
- 게시 · 예약 게시 · 되돌림은 운영 알림 SITE_LAYOUT_PUBLISHED(INFO)로 한 줄.

## 3. D321 (마이그레이션)

| 무엇 | 내용 |
|---|---|
| `site_layouts` | 열쇠 6줄(HOME · MNY · MAL · BIZ · LED · HLT) · 초안 · 게시된 판 · 예약(떠 둔 배치) · CHECK |

| `perm_route_map` | 새 주소 10개 × 작업 2(gwan-ux · gwans) |
| `help_docs` ADMIN_GUIDE | 새 탭 「페이지 목록 [site-pages]」 절을 지금 판 끝에 붙인 새 판 · 탭 → 절 잇기(docs/808) |
