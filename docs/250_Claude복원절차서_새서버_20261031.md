### 5-2. A — 서버 Claude Code 대화 되살리기 (Claude 또는 사람 · 10분)

```bash
T=20261031_1416                                          # 쓸 백업 시각
mkdir -p ~/restore && tar -xzf ~/claude_work_$T.tar.gz -C ~/restore
P=~/.claude/projects/-home-sgbdev-sogaebank; mkdir -p $P
cp -n ~/restore/claude_work_$T/projects/-home-sgbdev-sogaebank/*.jsonl $P/        # 대화 파일(세션 1개 = 파일 1개)
cp -rn ~/restore/claude_work_$T/projects/-home-sgbdev-sogaebank/*/ $P/ 2>/dev/null  # 세션 부속(작업 기록 · 하위 작업)
cp -rn ~/restore/claude_work_$T/projects/-home-sgbdev-sogaebank/memory $P/          # 기억(없을 때만)
ls $P/*.jsonl | wc -l                                    # 대화 수(10/31 기준 8)
cd ~/sogaebank && claude --resume                        # 목록에서 이어 갈 대화를 고름
```

| 확인 | 맞으면 |
|---|---|
| `claude --resume` 목록 | 지난 대화 제목 · 날짜가 나옴 |
| 고른 대화를 열고 「목록」 | 그 대화의 마지막 상태에서 이어서 답함 |

- 폴더 이름 `-home-sgbdev-sogaebank` 는 작업 폴더 경로(`/home/sgbdev/sogaebank`)에서 나옴 — 사용자 · 경로가 다르면 그 경로에 맞는 이름으로 바꿔 넣음(예: `/home/dev/sogaebank` → `-home-dev-sogaebank`).
- 대화가 길면 이어 열 때 앞부분이 요약된 상태로 시작할 수 있음(정상).
- **읽기만 할 때**(이어 가지 않고 내용 찾기):

```bash
python3 - <<'PY' ~/.claude/projects/-home-sgbdev-sogaebank/<세션번호>.jsonl > ~/restore/session.md
import json, sys
for line in open(sys.argv[1], encoding='utf-8'):
    try: m = json.loads(line)
    except Exception: continue
    if m.get('type') not in ('user', 'assistant'): continue
    c = (m.get('message') or {}).get('content')
    t = c if isinstance(c, str) else '\n'.join(b.get('text', '') for b in (c or []) if isinstance(b, dict) and b.get('type') == 'text')
    if t.strip(): print(f"## {'대표' if m['type'] == 'user' else 'Claude'} · {m.get('timestamp', '')[:16]}\n\n{t}\n")
PY
```
