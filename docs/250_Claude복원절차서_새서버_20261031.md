## 3. 순서

> ⚠ **한 블록씩.** 로그인(3-5)과 AWS 자격 증명은 사람만.

### 3-0. 새 서버 준비 (사람)

```bash
sudo adduser sgbdev                    # 운영 계정(ubuntu)과 나눔 — CLAUDE.md 「이 서버」 기준
sudo apt-get install -y tmux git unzip
#  Claude Code · AWS CLI · git-remote-codecommit · rootless docker 설치는 각 공식 안내대로(설치할 때 확인)
```

### 3-1. 백업 파일 올리기 (집 PC PowerShell)

```powershell
$T = "20261031_1309"        # 올릴 백업 시각 — D:\sgb\backup 의 가장 최근 폴더
scp D:\sgb\backup\$T\full_$T.tar.gz D:\sgb\backup\$T\claude_work_$T.tar.gz D:\sgb\backup\$T\SHA256SUMS_$T.txt <새서버별칭>:~/
```

```bash
cd ~ && sha256sum -c --ignore-missing SHA256SUMS_*.txt      # full · claude_work 「OK」 두 줄
```

### 3-2. 저장소 · 스크립트 (Claude 또는 사람 · docs/222 6-3 과 같음)

```bash
T=20261031_1309
mkdir -p ~/sogaebank && tar -xzf ~/full_$T.tar.gz -C ~
for r in sgb-core sgb-infra sgb-adx sgb-docs; do git clone -q ~/full_$T/repos/$r.bundle ~/sogaebank/$r; done
for r in sgb-core sgb-infra sgb-adx sgb-docs; do git -C ~/sogaebank/$r remote set-url origin codecommit::ap-northeast-2://$r; done
cp ~/full_$T/tools/*.sh ~/ && chmod +x ~/*.sh
```

### 3-3. Claude 설정 · 기억 (Claude 또는 사람)

```bash
mkdir -p ~/.claude/projects/-home-sgbdev-sogaebank
cp ~/full_$T/claude/CLAUDE.md ~/full_$T/claude/settings.json ~/.claude/
cp -r ~/full_$T/claude/memory ~/.claude/projects/-home-sgbdev-sogaebank/
cp ~/sogaebank/sgb-docs/claude/CLAUDE.md ~/sogaebank/CLAUDE.md        # 프로젝트 규칙은 저장소 판이 기준(백업 판보다 최신일 수 있음)
diff -q ~/.claude/CLAUDE.md ~/sogaebank/sgb-docs/claude/answer-style.md && echo "답변 방식 같음"
ls ~/.claude/projects/-home-sgbdev-sogaebank/memory | wc -l            # 기억 파일 수(10/31 기준 18 = 기억 17 + MEMORY.md)
```

### 3-4. 대화 기록 · 입력 기록 (선택 · 지난 대화를 이어 가려면)

```bash
mkdir -p ~/restore && tar -xzf ~/claude_work_$T.tar.gz -C ~/restore
W=~/restore/claude_work_$T
cp -n $W/projects/-home-sgbdev-sogaebank/*.jsonl ~/.claude/projects/-home-sgbdev-sogaebank/
cp -rn $W/projects/-home-sgbdev-sogaebank/*/ ~/.claude/projects/-home-sgbdev-sogaebank/ 2>/dev/null
cp -n $W/history.jsonl ~/.claude/ 2>/dev/null; cp -rn $W/skills $W/plugins $W/file-history ~/.claude/ 2>/dev/null
#  사용자 · 폴더가 다르면(예: /home/dev/sogaebank) 폴더 이름을 경로에 맞게: -home-dev-sogaebank
```

- `cp -n` — 새 서버에 이미 있는 파일은 덮지 않음.
- 대화 기록은 **이어 가기용**이다. 결정 · 절차는 sgb-docs(인계 메모 · decisions) 와 sgb-core docs 가 기준이라, 기록이 없어도 일은 계속된다.

### 3-5. 로그인 (사람 · 대화형)

```bash
cd ~/sogaebank && claude          # 처음 실행 → 로그인 안내대로(브라우저 인증) · 끝나면 /exit
```

- AWS 자격 증명(`aws configure` · CodeCommit 용)도 사람이. **열쇠를 Claude 대화에 붙이지 않는다.**
- 그다음부터는 `bash ~/start-claude.sh`(tmux 작업방 `sgb` · 원격 제어 「소개뱅크」).

### 3-6. 확인 (Claude 와 첫 대화)

| # | 말하기 / 명령 | 맞으면 |

## 4. 되살린 뒤 Claude 가 할 일

1. `~/backup` · 매주 백업 다시 — `bash ~/sogaebank/sgb-infra/tools/backup-full.sh` · 예약(crontab)은 대표가 `!` 로(docs/222 4절).
2. GitHub 보내기 열쇠(`~/.ssh/gh_soge`)는 백업에 없음 → 대표가 새로 만들어 GitHub 배포 키에 등록 · `backup-github.sh` 한 번(docs/223).
3. 인계 메모에 「새 서버로 옮김 · 날짜 · IP」 한 줄 — **IP 가 바뀌면 외부 연동 신청 발신 IP(3.37.95.217)도 바뀜**(CLAUDE.md 「현재 상태 주의」 — 탄력적 IP 를 새 서버로 옮기는 것을 먼저 검토).
