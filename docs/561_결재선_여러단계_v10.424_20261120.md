# 561. 결재선 여러 단계 (v10.424 · 2026-11-20)

> 대표 11/19 20:35 「모두개발」 — 다음 개발 후보 B5 「결재선 여러 단계」. D253.

## 1. 결론
품의 · 경비 청구 · 수동 전표에 **금액 구간별 결재선**(역할 또는 지정 사람 · 1 ~ 5단계 · 마지막은 SUPER)을 둡니다. 결재선이 없으면 지금처럼 SUPER 한 번입니다.

## 2. 위치
- 운영 화면 › 사무 › **결재함** — 내 결재 차례 문서(중간 단계는 여기서 결재 · 반려 · 마지막 SUPER 단계는 각 화면)
- 운영 화면 › 사무 › **결재선** — 종류마다 구간 · 단계(보기 운영자 · 고치기 SUPER · 사유 · 바꾼 기록)

## 3. 규칙
| 규칙 | 막는 곳 |
|---|---|
| 본인 문서 결재 불가 | DB(APV_SELF) |
| 같은 차례에 같은 사람 두 단계 불가 | DB(APV_DUP) |
| 단계는 차례대로 | DB(APV_ORDER) |
| 그 단계 역할 · 사람만(SUPER 는 어느 단계든) | DB(APV_WHO) |
| 마지막 단계는 SUPER | DB(APV_LINE_LAST) — 승인 효과는 기존 SUPER 결재(기존 DB 가드 그대로) |
| 앞 단계가 남았으면 SUPER 승인 막음 | 서버(APV_PENDING · 409) |
| 중간 단계 반려 | 그 차례 끝 · 문서는 청구 상태 그대로(다시 1단계부터) · SUPER 는 언제든 바로 반려 |

- 단계 기록(acct_approval_steps)은 쌓기만. 결재선 바꾼 기록(acct_approval_line_changes)도 쌓기만.
- 결재선을 바꾸면 지금 결재 중인 문서에도 바로 씁니다(문서 금액으로 구간을 다시 고름).
