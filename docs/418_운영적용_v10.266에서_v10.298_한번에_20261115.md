## 8. 적용 뒤 대표 할 일

1. 입점 약관 제17조 요율을 정하면 **소개몰 › 「소개몰 정산」 › 「입점 유형 요율」** 에 적기 — 입점 판매자가 없을 때는 바로 바뀜(예약 없음) · 「대표 할 일」 새 줄 ① 이 ✓.
2. 처리방침 1.1 〔법령 근거〕 · 〔보관 근거 법령〕 빈칸 → 법무 확인 뒤 **관 관리 › 「약관」** 에서 「고치기」 → 시행일 → 「게시」(SUPER) · 「대표 할 일」 새 줄 ② 가 ✓.
3. 입점 약관 1.0 빈칸 채운 뒤 같은 곳에서 「게시」.
4. 요율 인상 「공지」를 판매자센터 · 파트너센터 공지 + 개별 알림으로 하는 방식을 **법무에 알리고**, 알렸으면 **대시보드 › 「대표 할 일」 › 「요율 인상 공지 방식을 법무에 알리기」 「적기」**(SUPER · docs/407 5절).
5. 운영자 게시판이 텔레그램 · 슬랙 「준비 안 됨」을 계속 보이면, 켤 때 **위험감지 › 「운영 알림」** 의 시험 단추로 확인(docs/412).
