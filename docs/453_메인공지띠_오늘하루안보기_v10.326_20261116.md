# 453. 메인 공지 띠 「오늘 하루 안 보기」 (v10.326 · 2026-11-16)

> 대표 「다음개발」(11/16) C. 마이그레이션 없음. 사용자 웹만.

## 1. 바뀐 것 (정확한 위치)

사용자 웹 **메인 첫 화면 › 맨 위 「상단 고정」 공지 띠** 오른쪽 끝에 **✕ 오늘 하루 안 보기**(휴대폰 폭에서는 ✕만 · 누르는 자리 44px).

- 누르면 띠가 바로 사라지고, 그날(**한국 날짜**) 동안 새로 고쳐도 안 보입니다.
- **날짜가 바뀌거나 새 고정 공지가 올라오면(띠의 공지가 달라지면) 다시 보입니다.**
- 이 브라우저에만 적어 둡니다(`localStorage` 의 `sgb.homeNoticeHide` = 날짜 + 공지 번호). 서버 · 회원 기록은 없고, 다른 기기 · 브라우저에서는 그대로 보입니다.
- 저장소를 못 쓰는 브라우저(사생활 보호 창 등)에서는 그 화면에서만 숨기고, 새로 고치면 다시 보입니다.
