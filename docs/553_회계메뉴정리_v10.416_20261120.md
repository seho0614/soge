# 553. 회계 메뉴 정리 (v10.416 · 2026-11-20)

> 대표 11/19 「다음개발 미해결 문제」 → 4개 모두 · 「승인 + 통과하면 병합」 · D251.

## 1. 결론
회계 탭 26개를 **하위 묶음 6개**로 나눠 탭 줄에 이름표를 붙였습니다. 탭 자체(주소 · 권한 · 화면)는 그대로입니다.

| 하위 묶음 | 탭 |
|---|---|
| 장부 | 월 결산 · 전표 · 수동 전표 · 재무제표 · 원장 · 해 마감 |
| 자금 | 은행 맞추기 · PG 정산 · 자금 흐름 · 기간 분석 |
| 매입 · 경비 | 매입 · 경비 청구 · 품의 · 거래처 · 계약 · 수입 · 재고 · 고정자산 |
| 세무 | 신고 자료 · 부가세 신고서 · 법인세 추정 |
| 인사 | 급여 · 퇴직금 · 연차 |
| 설정 · 보고 | 경영 보고서 · 예산 · 계정 · 규칙 |

- 월 결산 첫 화면에 「회계 바로가기」 — 하위 묶음별 단추(볼 수 있는 탭만).
- 업무 보고(일보 · 주보 · 월보 · 업무 일지 · 현황판)는 따로 「보고」 메뉴(⑰).

## 2. 방식 · 까닭
- 메뉴에는 하위 묶음 기능이 없음. 회계를 상단바 그룹 여럿으로 쪼개면 상단바(이미 20개 넘음)가 더 넘침 → 같은 그룹 안에서 **탭 줄을 이름표로 나눔**(`GROUP_SECTIONS` · `sectionsOf`).
- 그룹 `admacc` 의 tabs 배열은 그대로 — 권한 · 순서 · 옛 시험(1381 · 1390)이 보는 글자 그대로.
- 탭 단추([data-tab])는 모두 줄에 그대로 있어 기능 점검(flow_lib · btn_bo) 방식 그대로.
- 하위 묶음에 없는 탭은 줄 끝 「그 밖」에 붙음(빠지지 않음). 개발 때 빠짐 · 두 번 · 그룹 밖을 콘솔에 알림.
