# 693. 소개몰 리뷰 판매자 답글 (v10.555 · 2026-11-21)

## 1. 결론
소개몰 리뷰에 **답글 하나**를 답니다 — **입점 판매자는 자기 상품 리뷰**(판매자센터 › 리뷰 답글), **직판 상품 리뷰는 운영자**(소개몰 › 리뷰 답글). 고치면 **고치기 기록**이 쌓이고, 금칙어는 **기존 금칙어 사전**(소개몰 HLT + 공통)으로 검사해 걸리면 운영 확인 뒤 보입니다. 처음에는 꺼져 있습니다(`smx.review_reply` off — 쓰기가 막히고 공개 화면에도 안 보임). 위치: 운영 SB-ADM-SMX-030(탭 `smx-replies`) · 판매자센터 SB-HLT-SMX-010(`/health/seller/center/reviews`).

| 항목 | 규칙 |
|---|---|
| 누가 | 입점(TENANT · BRAND) 상품 = 그 판매자 계정 본인만 · 직판 상품 = 운영자(ADMIN · SUPER) — DB 트리거 `fn_smx_reply_guard` 가 다시 봄(판매자 흉내 막음) |
| 하나 | 리뷰 하나에 답글 하나(`review_id` 고유) — 다시 쓰면 고치기 · 보이는(VISIBLE) 리뷰에만 |
| 고치기 기록 | 글을 바꿀 때마다 앞 글 · 새 글 · 고친 사람(`hlt_review_reply_edits` · 쌓기만 · 고치지 못함) · 고친 횟수 · 공개 줄에 「고침」 표시(edited) |
| 금칙어 | `fn_check_banned_words(body, 'HLT')` — 걸리면 PENDING(걸린 말 hold_word) · 고쳐 쓰면 저절로 보임(운영이 판정하기 전) · 리뷰와 같은 규칙 |
| 운영 | 보이기 · 가리기(사유 2자 이상 · 판매자에게 보임) — 판매자 답글도 가릴 수 있음 · 가린 답글은 고치지 못함 |
| 알림 | 답글이 **처음** 보이게 될 때 리뷰 쓴 회원에게 한 번(`HLT_REVIEW_REPLY` · 링크 상품 리뷰 탭) |
| 리뷰가 사라지면 | 리뷰를 지우면 답글 · 기록도 함께 지움 · 리뷰가 가려지면(운영 · 반품) 공개 목록에서 함께 안 보임 |
| 공개 표시 | 상품 상세 「리뷰」 줄 아래(상품 문의 답과 같은 모양) — 운영 답글은 「소개몰」 · 판매자 답글은 판매자 이름 |

## 2. 전체 구조
1. 표 `hlt_review_replies`(리뷰 고유 · 쓴 쪽 SELLER · STAFF · 판매자 · 글 · 상태 · 걸린 말 · 가린 사유 · 고친 횟수 · 알림 시각) · `hlt_review_reply_edits`.
2. 트리거 `trg_smx_reply_guard`(누가 · 보이는 리뷰 · 못 바꿈 · 금칙어) · `trg_smx_reply_edit_log`(고치기 기록) · `trg_smx_reply_edits_lock`(기록 못 바꿈).
3. 서버 `src/modules/smx/replies.ts` — 공개 목록에 붙이기 `smxAttachReplies`(health-review.service.ts 패치 4-2 · 6차 b281 이 고치는 SELECT 줄은 건드리지 않음) · 판매자 목록 · 쓰기 · 운영 목록 · 쓰기 · 보이기 · 가리기 · 기록.
4. 운영 화면 `SmxReplies` — 답글 없는 직판 리뷰 · 운영 확인 대기 · 가림 · 모든 답글 · 답글 달기 · 고치기 · 보이기 · 가리기 · 기록.
5. 회원 화면 — 상품 상세 리뷰 줄 `SmxReplyLine`(새 사전 열쇠 없음) · 판매자센터 `리뷰 답글` 화면 · 본문 위 단추 · 사전 `smx.rp`(ko · en 20 · 영어 복수형 ICU 1).
