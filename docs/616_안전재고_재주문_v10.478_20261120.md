# 616. 안전 재고 · 재주문 (v10.478 · 2026-11-20)

## 1. 결론
직판 상품 옵션마다 **최소 재고 · 재주문 수량 · 매입처 · 단가**를 정하면, **재고 위치(판매용 재고 + 국내 발주 중 수량)**가 최소 밑일 때 매시간 운영 알림 **STOCK_REORDER** 와 **재주문 초안**(매입처마다 하나)을 만듭니다. 초안은 사람이 고치고 **「발주로 넣기」를 눌러야** ㉑ 국내 발주(상태 ORDERED)가 됩니다 — **자동 발주 · 거래처로 보내기 없음**. 위치: **회계 › 매입 · 경비 › 안전 재고 · 재주문** · SB-ADM-FIN2-040 · API `/admin/acct/reorder`.

| 단계 | 누가 | 내용 |
|---|---|---|
| 규칙 | SUPER · PAYOUT · ADMIN | 옵션마다 최소 재고(0 ~) · 재주문 수량(1 ~) · 매입처(거래처 · 비우면 초안에서 고름) · 단가(비우면 ⑫ 재고 평균 단가) · 끄기(지우지 않음) |
| 점검 | 정기 작업 `acct_reorder` 매시간 · 「지금 점검」 | 위치 < 최소 → 알림(옵션마다 하나) · 그 옵션이 열린 초안에 없으면 매입처 초안에 줄(수량 = max(재주문 수량, 최소 − 위치)) |
| 초안 | 사람 | 수량 · 단가 바꾸기(0 = 빼기) · 매입처 정하기 |
| 발주로 넣기 | 사람 | ㉑ `addPo`(발주일 오늘 · 제목 「재주문 초안 N번」) → 초안 CONVERTED(po_id) → 발주 중 수량이 위치에 들어가 다음 점검에서 알림 풀림 |
| 버림 | 사람 | 사유 · 다음 점검에서도 모자라면 새 초안 |

| 설정 | 처음 | 뜻 |
|---|---|---|
| `acct.reorder` | on | 점검 · 알림 · 초안(규칙이 없으면 아무것도 안 함 · 회사 안 알림만 · off 면 열린 알림 풂) |

## 2. DB 막음
- 규칙은 직판 옵션만 · 지우지 않음. 초안은 매입처마다 열린 것 하나(유일 색인) · 끝난 초안(CONVERTED · DISMISSED)은 고치지 않음 · 초안 줄은 초안 상태에서만.

## 3. 주의
1. 판매용 재고(hlt_product_options.stock)를 봅니다 — ⑫ 원가 장부(수불부) 수량과 다르면 재고 화면에서 맞추십시오.
2. 발주서 인쇄 · 입고는 ㉑ 국내 발주 화면 그대로(입고 때 매입 · 재고 IN).
3. 소개몰 「주문 받기」가 꺼진 지금은 판매로 줄지 않아 알림이 거의 없음.

## 4. 권한
