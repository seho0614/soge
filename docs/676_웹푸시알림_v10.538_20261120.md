# 676 웹 푸시 알림 — v10.538 (D283 · 2026-11-20)

> 대표 11/20 「(53) ① 웹 푸시 알림」 · D272 서비스 워커(site.pwa) 위 · 모든 스위치 처음 꺼짐 · 방식 처음 ASSUME(밖으로 부르지 않음)

## 1. 결론
- 회원 알림(나의공간 › 알림에 쌓이는 것)을 **브라우저 푸시로도** 보냅니다. 회원이 기기마다 직접 켭니다(나의공간 › 웹 푸시 `/my/push`).
- 새 npm 없이 node crypto 로 Web Push 표준(RFC 8030 · 8291 aes128gcm · 8292 VAPID)을 구현했습니다. 키는 **외부 연동 WEBPUSH**(18번째 · 업체 계약 없음 · 우리가 만듦).
- 처음에는 아무것도 나가지 않습니다: `push.enabled` off(구독 받기) · `push.send` off(보내기) · `push.send_mode` ASSUME.

| push.send | off | 보내기(1분 정기 작업) |

## 5. 켜는 순서(운영 · 대표 승인 뒤)
1. 운영 화면 › 회원 › 웹 푸시 › 「키 만들기」(SUPER) — 연동 키에 공개 · 비밀 키 저장
2. push.vapid_subject = mailto:help@sogaebank.com (연락처 확인 필요)
3. site.pwa on(서비스 워커 등록) → push.enabled on → 직원 기기에서 켜고 「시험 알림」(ASSUME 기록 확인)
4. push.send_mode LIVE → push.send on → 직원 기기에서 실제 수신 확인
- 문제 확인 순서: 운영 알림 MKX_PUSH_NOT_READY(키 · 연락처) → MKX_PUSH_AUTH(키 짝 · 연락처 형식) → 기록의 GONE 비율(브라우저가 구독 취소)
