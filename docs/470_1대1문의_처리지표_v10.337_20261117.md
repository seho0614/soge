## 1. 왜

- v10.333 답변함 · v10.334 답변 틀로 답할 수는 있지만, **얼마나 빨리 · 기한 안에 답하는지**, 어떤 분류 문의가 많은지, 어떤 틀을 쓰는지 볼 곳이 없었습니다.
- 하루 요약(메일 · 텔레그램 · 슬랙)에도 문의 줄이 없어, 답변 전 문의가 쌓여도 운영 화면을 열기 전에는 몰랐습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 새 API `GET /admin/inquiries/stats?days=` | ADMIN · SUPER · 7 ~ 90일(처음 30) — 접수 · 답함 · 아직 답변 전 · 처음 답까지 평균 · 가운데 시간 · 기한 안 수 · 비율 · 분류별 접수 · 답함 · 답변 틀별 쓴 횟수. **처음 답 시각 = 감사 기록 `INQUIRY_ANSWER` 가장 이른 것**(`answered_at` 은 고치면 바뀜) |
| API `POST /admin/inquiries/{id}/answer` | 선택 칸 `templateId` — 고른 답변 틀을 감사 기록(after)에 남김(없는 틀이면 적지 않음) |
| 운영 화면 **회원 › 「1:1 문의」** 맨 위 | 접는 상자 **「최근 30일 접수 · 답함 · 처음 답까지 평균(가운데) · 기한 안 % · 아직 답변 전」** → 펼치면 7 · 30 · 90일 단추 · 분류별 표 · 답변 틀별 표. 「답변 틀 고르기」로 고른 틀이 답변과 함께 보내짐 |
| **하루 요약**(매일 09:00) | 한 줄 더함 — `1:1 문의 답변 전 n · 기한 넘김 m(운영 화면 › 회원 › 1:1 문의) · 어제 접수 k` |
