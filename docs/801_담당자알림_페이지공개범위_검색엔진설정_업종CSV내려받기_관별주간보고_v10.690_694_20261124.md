## 2. D320 (마이그레이션)

| 무엇 | 내용 |
|---|---|
| `gwan_pages.visibility` | ALL · MEMBER(처음 ALL · 첫 화면은 ALL 만 · CHECK) |
| `gwan_pages.seo_description · seo_image · noindex` | 160자 · 관 안 주소나 https · 처음 false |
| 설정 `ops.gwan_weekly` | ADMIN · 처음 on · on/off |
| 켤 조건 `opx_switch_docs` | `ops.gwan_weekly` 한 줄(처음부터 켜짐 · 선행 조건 없음 · 켜기 도우미에 보임) |

- 지우는 문장 없음 · 다시 돌려도 같음.
- 공개 주소 검사(scripts/check-acl.js)의 공개 구역에 `gwan-pages`(관 페이지 찾기 · 미리보기 — v10.666 · 669) 더함(까닭 주석).
