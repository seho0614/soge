# 506. 사이트 점검 중 화면 (v10.371 · 2026-11-18)

> 대표 11/18 「다음」 → 「다음 개발」 → ① 운영자 비밀번호 운영 화면에서 · ② 운영 알림 잠시 끄기 · ③ 사이트 점검 중 화면 · ④ 운영 권한 기한 「모두」 → 계획 「승인 + 통과하면 병합」(여섯 번째 묶음 · 운영은 v10.361 ~ 368 과 함께 다음 묶음). 이 문서는 ③. 마이그레이션 **D239**(설정 넷).

## 1. 왜

- 운영 적용 · DB 작업 때 회원이 반쯤 바뀐 화면을 보거나 결제 · 가입이 실패하는 것을 막을 안내 화면이 없었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D239** | 설정 `site.maintenance_from` · `site.maintenance_until`(`YYYY-MM-DDTHH:MM+09:00` · 비면 점검 없음) · `site.maintenance_note` · `site.maintenance_note_en` — GLOBAL(사용자 웹이 읽는 공개 설정) |
| 사용자 웹 레이아웃 | 시각 안이면 **모든 화면 대신 「서비스 점검 중입니다」**(안내 글 · 예상 끝 · 급한 문의 `footer.phone`) · 시작 24시간 전부터 맨 위 **점검 예정 띠** · 끝이 지나면 저절로 원래 화면. 공개 설정은 5분마다 다시 읽어 최대 5분 늦음 |
| 사전 | `common.maintTitle · maintBody · maintUntil · maintContact · maintSoon`(한 · 영 글자만) |
| 새 API | `GET /admin/maintenance`(ADMIN · SUPER) · `POST /admin/maintenance`(SUPER · 한국 시각 · 끝은 시작 뒤 12시간 안 · 지금 뒤 · 사유 · 감사 `SITE_MAINTENANCE_SET` · 설정 바뀜 기록 사유) · `POST …/clear`(감사 `SITE_MAINTENANCE_CLEAR`) |
| 운영 화면 **첫 화면 › 「공개 직후 지켜보기」** | **「사이트 점검 예약」** 상자(상태 · 예약 · 지우기 · 지금 끝내기) |

- 운영 화면 · API 는 막지 않습니다(운영 화면은 따로 된 앱). 사용자 웹 안 서버 기능(`/api/…` 경로)도 그대로입니다.
