## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `POST /admin/notices` | SUPER | `endsAt`(끝 시각 · 게시보다 뒤 · 422 `BAD_PERIOD`) · `notify`(422 `NOTIFY_NO_AUDIENCE`) 더함 · 응답 `notified`(보낸 수) |
| `PATCH /admin/notices/{id}` | SUPER | 제목 · 본문 · 등급 · 고정 · 끝 시각(null 이면 비움) · 알림 · `reason`(게시 중이면 필수 · 422 `REASON_REQUIRED`) · 404 · 409 `NOTICE_LOCKED` · 422 `NO_CHANGE` · 감사 `NOTICE_UPDATE` |
| `POST /admin/notices/{id}/unpublish` | SUPER | `{reason}`(2자 이상) · 게시 중 → 끝 시각 지금 · 예약 → 초안 · 409 `NOTICE_NOT_LIVE` · `NOTICE_LOCKED` · 감사 `NOTICE_UNPUBLISH` |
| `POST /admin/notices/{id}/publish` | SUPER | 초안 · 예약 → 지금 게시(알림 고른 것이면 보냄) · 내린 · 끝난 공지 → 다시 게시(끝 시각 비움 · 기록) · 409 `NOTICE_PUBLISHED`(게시 중) |
| `GET /admin/notices/{id}/revisions` | SUPER | 고친 기록(최근 50) |
| `GET /admin/notices/audience?grades=A,B` | SUPER | 알림 받을 회원 수 · `sendable` |
| `GET /admin/notices` | SUPER | `status` · `endsAt` · `endedReason` · `notify` · `notifiedAt` · `notifiedCount` · `rateNotice` · `revisions` 더함 |

## 3. DB (D211_notice_manage)

| 것 | 내용 |
|---|---|
| `notices` 칸 | `ends_at` · `ended_reason` · `ended_by` · `updated_at` · `updated_by` · `notify` · `notified_at` · `notified_count` · 검사 `ck_notices_period`(끝 > 게시) |
| `notice_revisions` | 고치기(EDIT) · 내리기(UNPUBLISH) · 다시 게시(REPUBLISH) 때 그 전 내용(jsonb) · 사유 · 한 사람 — 트리거가 고치기 · 지우기 막음 |
| 트리거 `fn_notice_lock_guard` | 수수료율 변경 공지(`hlt_rate_schedules.notice_id` · `cancel_notice_id`)는 게시 뒤 제목 · 본문 · 등급 · 관 · 게시 · 끝 시각을 바꿀 수 없음 · 지울 수 없음(고정 · 알림 칸은 됨) |
| `fn_notice_audience(등급)` | 받을 사람 — 전체 공개가 들면 없음 · 관리자 등급 뺌 · 활동 중 계정 · 「새 공지」 내 알림 끈 사람 뺌 |
| `fn_notice_notify(공지)` · `fn_notice_notify_due()` | 게시된 · 알림 고른 · 아직 안 보낸 공지면 한 번 보냄 / 정기 작업이 부름 |
| 알림 종류 | `NOTICE_PUBLISHED` 「새 공지」(수신 거부 가능) |
| 정기 작업 | `notice_schedule` 10분마다 |
| 지우는 문장 | 없음 · 재실행 안전 · **기존 공지는 그대로**(끝 시각 없음 · 알림 안 함) |

## 4. 지키는 것

| 지키는 것 | 어떻게 |
|---|---|
| 기존 공지 | 칸만 더함 — 끝 시각 · 알림이 비어 있어 보이는 범위 그대로 |
| 수수료율 공지 증거 | 앱 409 + DB 트리거 — 게시한 내용 · 기간을 바꾸거나 지울 수 없음 |
| 고친 흔적 | 그 전 내용은 고친 기록에 쌓기만(고칠 수 없음) · 감사 로그 `NOTICE_UPDATE` · `NOTICE_UNPUBLISH` |
| 알림 한 번 | `notified_at` 이 있으면 다시 안 보냄 |
| 관리자 공지 | 사용자 웹 알림에서 뺌 |
