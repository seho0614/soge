1. 법무에 카카오 줄을 알린 뒤 — 운영 화면 › 약관 › 처리방침 1.0 · 위탁 안내 1.0 「게시」 — 시행일 2026-11-11 · 확인 창의 경고 줄을 읽고 「확인」.

4. 첫 화면에 `재동의 — 개인정보처리방침 1.0: 0 / … · 남음 …` — 회원이 로그인할 때마다 늘어납니다.
5. AI 를 켜려면 운영 화면 › AI 에이전트 › **AI 켜기 단계** 순서대로(키 · 월 상한 → 검수 보조 2주 → AI 상담). 다음 단계가 「할 차례」가 되면 `AGENT_STEP_READY` 알림 · 숫자는 **AI 첫 주 보고**에서 봅니다.

### 4-3. 알아 둘 것

1. 적용 뒤 첫 10분(정기 작업 `launch_watch`)에 새 알림이 생기지 않는 것이 정상입니다 — 운영 처리방침은 아직 게시 전입니다.
2. 공휴일 처음 값의 2027년 날짜는 정리 사이트 2곳 대조이며 관보(월력요항) 원문은 확인하지 못했습니다 — 관보가 나오면 운영 화면에서 맞추십시오. 2027-05-03(노동절 대체)은 넣지 않았습니다.
3. AI 월 상한 80% 경고 기준은 설정 `agent.cap_warn_pct`(1 ~ 99)로 바꿀 수 있습니다.
4. 개발 서버 `~/kits/release` 에 다른 판 킷(v10.203)이 남아 있어도 **v10.206 킷만** 올립니다.
