### 4-2. 검색 등록 (대표 · 적용 확인 뒤)

1. 네이버 서치어드바이저 → 사이트 등록 `https://sogaebank.com` → 소유 확인 → 요청 → 사이트맵 제출 `https://sogaebank.com/sitemap.xml`
2. 구글 서치 콘솔 → 속성 추가(도메인 또는 URL 접두어) → 소유 확인 → Sitemaps 에 `sitemap.xml` 제출
3. 소유 확인 방식(HTML 태그 · 파일 · DNS)은 화면을 보고 알려 주시면 맞춰 드립니다 — 메타 태그 방식이면 코드에 넣는 판이 하나 필요합니다

### 4-3. 알아 둘 것

1. 서버 오류 몰림 알림은 운영 알림으로 남습니다(메일은 SES 를 켠 뒤 하루 요약에 함께). 너무 자주 울리면 운영 화면 설정 `ops.server_error_per_10min` 을 올리고, 끄려면 0.
2. **알려진 결함**: 주소에 `%00`(빈 글자)이 들어가면 서버 오류가 납니다. 로봇이 이런 주소를 두드리면 알림이 헛울릴 수 있습니다 — 다음 판(v10.175)에서 「형식 오류(400)」로 고칠 예정.
