# 703 직원 · 권한 그룹 · 운영자 목록 (v10.561 · D291)

## 1. 결론
운영 화면 그룹 키 acl 「권한 계층」을 「직원 · 권한」으로 바꾸고, 운영자 관련 탭을 한곳에 모읍니다. 새 탭 「운영자 목록」(staff-list)은 운영 역할이 있는 계정만 보여 줍니다.

## 2. 화면
| 위치 | 키 | 이름 | 역할 |
|---|---|---|---|
| 직원 · 권한 › 운영자 목록 | staff-list | 새 탭 | ADMIN · SUPER |
| 직원 · 권한 › 업무별 권한 | perm-admin | 사무 › 권한 관리에서 옮김 | SUPER |
| 직원 · 권한 › 역할 주기 | roles | 권한 계층 › 권한 관리 이름 바꿈 | ADMIN 보기 · SUPER 주기 |
| 직원 · 권한 › 권한 점검 | role-review | 위험감지 › 운영자 권한에서 옮김 | SUPER |
- 탭 키는 그대로(주소 #/perm-admin · #/role-review 그대로). 메뉴 순서: 운영자 목록 · 사원 권한 · 권한그룹 · 업무그룹 · 업무 목록 · 업무별 권한 · 역할 주기 · 권한 점검 · 접속 인증 · 바뀐 기록 · 내 2단계 · 내 비밀번호(새 탭은 562 · 563).
- 위치: NAV_SECTIONS 「회원 · 심사」 묶음 끝(acl) 그대로.
- 옛 시험이 글자로 보는 TABS · GROUPS 줄은 그대로 두고, 이름은 TAB_RENAME · 순서 · 옮김은 덧붙인 코드로.

## 3. API
| 방법 | 주소 | 역할 | 설명 |
|---|---|---|---|
| GET | /admin/staff | ADMIN · SUPER | 운영자(역할 · 기한 · 연결 직원 · 직원 연결 없음 · 퇴사했는데 역할 남음 · 2단계 · 마지막 로그인 · 권한그룹 수) · 메일 원문 · 연결 안 된 직원 목록은 SUPER 만 |
- 읽기 범위는 역할 보유자 GET /admin/reports/roles(ADMIN · SUPER)와 같음. /admin/acct/ 밖이라 세무사는 못 봄.
