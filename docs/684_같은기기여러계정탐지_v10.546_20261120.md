# 684. 같은 기기 여러 계정 탐지 (v10.546 · 2026-11-20)

## 1. 결론
가입 · 로그인 때 사용자 웹이 만든 **기기 표지(무작위 쿠키 값)** 의 **sha256 해시만** 남겨, 최근 30일 같은 표지에 계정이 기준(처음 3개) 이상 모이면 **위험감지 경보(RSK-SFX)** 와 운영 알림을 남깁니다. **브라우저 지문(화면 크기 · 글꼴 · 플러그인 등)은 모으지 않고, 자동 정지는 하지 않습니다.** 처음에는 꺼져 있습니다(`sfx.device_watch` off). 위치: 운영 **위험감지 › 같은 기기 여러 계정**(SB-ADM-SFX-010 · 탭 `sfx-device`).

| 항목 | 규칙(처음 값 · 정책 › 전체 설정에서 고침) |
|---|---|
| 표지 | 사용자 웹 쿠키 `sgb_dm`(무작위 UUID · HttpOnly · 2년) — 서버 액션 머리글 `X-Device-Mark` 로 넘김(API 는 로그인 성공 · 가입 때만 씀) |
| 서버가 남기는 것 | `sha256('sgb-dm:' + 값)` · 계정 · 처음 본 길(가입 · 로그인) · 처음 · 마지막 · 횟수 — 원래 값 · IP · 브라우저 글자는 남기지 않음 |
| 켜기 | `sfx.device_watch` off — 꺼져 있으면 아무것도 쌓지 않음 |
| 기준 | `sfx.device_threshold` 3(2 ~ 20) — 최근 30일 같은 표지 계정 수 |
| 보관 | `sfx.device_keep_days` 180(30 ~ 365) — 마지막으로 본 날부터 지나면 매일 05:20 지움(꺼져 있어도 지움) |
| 경보 | 위험감지 `RSK-SFX`(MEDIUM · `auto_detect` true + `detect_sql` — 잠든 규칙 아님) · 운영 알림 `SFX_DEVICE_MULTI` · 열린 경보가 있으면 다시 넣지 않음(서버 · 자동 탐지 같은 subject `device:<해시 앞 16자>`) |
| 조치 | 자동 정지 없음 — 계정 보기(가린 이메일 · 이름 · 감사 `SFX_DEVICE_VIEW`) 뒤 회원 화면에서 사람이 판단 |

## 2. 전체 구조
1. 사용자 웹 `site/src/lib/session.ts` — 로그인 · 가입 때 `ensureDeviceMark()`(쿠키 없으면 만듦) · 서버 액션 머리글(`fwdHeaders`)이 쿠키가 있으면 `X-Device-Mark` 로 넘김(API 는 로그인 성공 · 가입 때만 씀).
2. API `ContextMiddleware` — `X-Device-Mark` 모양(16 ~ 64자 영숫자 · `-`)만 보고 요청 그릇 `deviceMark` 에.
3. `login-history.ts recordLogin`(성공 때 · 비밀번호 · 간편 로그인 모두) · `auth.service signup`(같은 트랜잭션) → `sfxDeviceSeen` → DB `fn_sfx_device_seen`(꺼짐이면 0 · 안쪽 블록에서 오류를 삼켜 가입 · 로그인을 깨지 않음).
4. 표 `sfx_device_marks`(표지 해시 · 계정 고유) · 위험감지 규칙 `RSK-SFX`.
5. 운영 화면 `SfxDevice` — 스위치 · 기준 · 최근 30일 계정 2개 이상 표지 100 · 계정 보기.

## 5. 처리방침 고칠 곳 · 법무
- **법무 확인 끝(11/20 대표 · 이상 없음)** — 쿠키 무작위 값 해시만 · 브라우저 지문 수집 없음 · 자동 정지 없음.
- 처리방침 「자동으로 모으는 정보」에 한 줄: 「기기 표지(무작위 값을 담은 쿠키 · 서버에는 그 값의 해시만) — 여러 계정 부정 이용 예방 · 마지막 이용일부터 180일 보관」. 게시한 뒤 SUPER 가 `sfx.device_watch` 를 켬(스위치는 그대로 처음 꺼짐).
- 쿠키는 스위치와 상관없이 로그인 · 가입 때 만들어짐(값은 브라우저에만 · 꺼져 있으면 서버는 받기만 하고 버림) — NOTES 3절.

## 6. 주의
1. 머리글은 손님이 바꿀 수 있음 — 표지를 지우거나 바꾸면 피할 수 있음(예방 · 경고용 · 증거로 쓰지 않음).
2. 가족 · 회사 공용 PC · PC방 · 시험 계정은 정상으로 걸릴 수 있음(규칙 `false_positive` 에 적음).
3. 간편 로그인(카카오 · 네이버) 돌아오는 길은 머리글을 넘기지 않음 — 다음 후보(콜백 route 에서 같은 머리글).
