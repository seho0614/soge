# 907. 간주 끈 뒤 처리 도구 — 중개사 재대조 일괄 · 시험 기록 · 시험 하위가맹점 번호 — v10.792 (2026-11-25)

## 1. 결론

- 대표 결정(11/25): 묶음 7 1번 「간주 끈 뒤 처리 도구」. 재대조 결과가 **다름 · 없음이면 알림만 보내고 사람이 판단**합니다(자동 해제 없음 — 명의 도용 · 조회 오류 가능성).
- 위치: 운영 화면 › **오픈 체크리스트** › 「간주 모드 끄는 순서」 바로 아래 **「간주 끈 뒤 처리」** 상자 › 탭 3개.

| 탭 | 하는 일 | 권한 |
|---|---|---|
| 중개사 재대조 | 간주로 승인된 중개사(`v_broker_recheck_pending`)를 국토부 조회로 다시 맞춤 · 한 번에 50건 · 일치는 대상에서 빠짐 · 다름 · 없음은 운영 알림 `BROKER_RECHECK_MISMATCH`(WARN) · 조회 실패는 FAILED(결격 아님) · 다름 · 없음은 운영자가 확인 사유(2 ~ 200자)를 적어 닫음 | 보기 ADMIN · 실행 · 확인 SUPER |
| 시험 기록 | 구독 청구 · 소개몰 결제 · 리드 캐시 충전 · 소개몰 지급 요청의 시험(스텁) 기록 종류별 건수 · 최근 50건 「시험」 표시 | 읽기만 |
| 시험 하위가맹점 번호 | `STUB-SUB-…` 판매자 목록 · 결제대행사 화면에서 받은 실제 번호로 바꾸기(지금 길 `POST /admin/health/sellers/{id}/submerchant` 그대로 · 화면은 `STUB-` 번호를 막음) | ADMIN · SUPER |

- **승인 상태 · 승인 시각은 바꾸지 않습니다.** 재대조 결과는 새 표에만 쌓습니다(`broker_verifications` 를 고치면 `fn_broker_sync` 가 승인 시각을 새로 찍기 때문).
- 국토부 조회 연동(BROKER_LOOKUP_URL · KEY)이 없으면 재대조는 422 `LOOKUP_NOT_CONFIGURED` — 화면 단추도 꺼짐.
