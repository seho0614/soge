# 786. 관 설정 › 오픈 점검 — 허브 관 · 리드관 「업종 1종 이상 승인」 표시 — v10.642 (2026-11-23)

## 1. 결론

- 11/23 대표가 운영 화면 › 사이트 · 관 관리 › 관 설정 › 오픈 점검에서 **소개하고 벌기(EARN)** · **소개리드(LED)** 의 「업종 1종 이상 승인 — 0종 · 미통과」를 보고 절차를 물었습니다.
- 두 관 모두 업종을 직접 갖지 않는 것이 맞습니다.
  1. **EARN 은 허브 관**(`gwans.is_hub`)입니다 — 업종은 하위 관(소개머니 · 소개몰 · 소개창업)에 붙습니다.
  2. **리드관(LED)은 안심소개 상담 축(MAL · CONSULT) 업종**을 그대로 씁니다(결정 gwan-structure-naming #32 · docs/466). 관을 켤 때 DB 검사(`fn_gwan_open_guard`)와 관 노출 API(`updateGwan`)도 이미 이 기준으로 셉니다.
- 화면의 점검만 「그 관에 직접 붙은 업종」을 세서 거짓 「미통과」가 나왔습니다. 이번 판부터
  - 허브 관 → **「해당 없음 — 허브 관(하위 관 N곳 · 승인 업종 M종)」**(통과로 셈)
  - 리드관 → **「상담 업종 N종(안심소개 상담 축 …)」**(상담 업종이 있으면 통과)
  - 다른 관 → 그대로(「N종 승인됨」)
