## 3. 운영 적용 뒤 할 일(사람)

1. 운영 화면 「관 관리 › 번역 › 원문 목록」 → 대상(알림 종류 · 신고 사유 · 요금제 · 소개자 등급 · 업무 등록 안내 · 화면 고정 문구 · 광고 자리 소재)마다 초안을 읽고 고쳐 **승인**
2. 요금제 「혜택」은 **한 줄에 혜택 하나** — 줄 수가 원문과 달라도 됩니다(화면은 줄마다 한 칸)
3. 영어 켜기는 지금처럼 번역 확인 뒤(사이트 설정 `i18n.enabled` · 언어 en)
