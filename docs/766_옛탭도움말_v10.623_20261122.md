# 762. 운영 화면 「?」 도움말 — 옛 탭 설명 넣기 (v10.623 · 2026-11-22)

> 대표 11/22 승인(다음 개발 묶음 ③). v10.616(docs/758)이 새 탭 124개를 넣은 뒤에도 **v10.456 이전에 생긴 탭 119개**는 운영 화면 도움말(help_docs `ADMIN_GUIDE`)에 절이 없어 「?」가 탭 이름 → 사용자 설명서 순으로 찾거나 「아직 없음」이었습니다. 이 판은 그 119개에 절을 더합니다. 마이그레이션 D305(`prisma/migrations/D305_hdx_admin_guide_old_tabs`).

## 1. 결론

1. **절 없는 탭 0.** `web/src/lib/adminMenu.ts` TABS(258개 · 겹침 2개 뺌) 가운데 1판(D300) · 2판(D302)에 `[탭 키]` 절이 없던 탭 **119개** 모두 절을 넣었습니다.
2. 절 글은 **화면에 이미 보이는 글만** 씁니다 — ① 그 탭 머리글 설명(`adminMenu.ts` PAGE `sub`, `PAGE[...] = ...` 로 바꾼 것은 바꾼 글) ② **보는 역할**(`web/src/App.tsx` `TAB_ROLES` · `SUPER_ONLY` · 없으면 ADMIN · SUPER 는 늘 · 회계 탭 가운데 지급 담당이 보는 것은 세무사 ACCOUNTANT 읽기). 화면에 없는 단추 이름 · 스위치는 적지 않았습니다.
3. **본문 한도를 ADMIN_GUIDE 만 2만 → 4만 자로 올립니다.** 2판이 이미 15,216자라 남은 자리(약 4,780자)로는 119개 절이 들어가지 않습니다. 새 판(3판) 본문은 **30,435자 · 54,662바이트**(버리는 DB 로 잼). USER_MANUAL(AI 상담이 읽는 회원 설명서)은 **2만 그대로**.
   - DB: D180 의 열 CHECK(`char_length(body) BETWEEN 100 AND 20000`)를 지우고 `help_docs_body_len`(ADMIN_GUIDE 4만 · 그 밖 2만) 하나로 바꿈.
   - 서버: `src/modules/sec2/tab-help.ts` 의 `MAX`(저장 한도 · 화면 `maxChars`)를 40000 으로 — **이 줄은 같은 판 코드 패치로 함께 바꿔야 합니다**(안 바꾸면 SUPER 가 같은 본문을 저장할 때 422 HELP_TOO_LONG · test_v1594 ② 저장 실패).
   - 요청 본문 크기: Nest 기본 본문 한도 100KB 안(3판 54KB · 4만 자 섞인 글 약 70KB · 4만 자가 모두 한글이면 약 120KB 라 넘을 수 있음 — 그럴 일은 드묾).
4. **새 판으로 더함 · 지우거나 고치지 않음.** 지금 판 끝에 붙인 3판을 만들고(쌓기만 · 1 · 2판은 남음), 탭 → 절 잇기(`sec2_tab_help`) 119줄을 넣습니다(124 + 119 = 243줄). 다시 돌려도 같습니다(버리는 DB 에서 ROLLBACK 안 재실행 판 · 잇기 수 그대로 확인).

## 5. 운영 적용

- 마이그레이션 D305 하나(표 · 함수 · 설정 없음 · 수십 ms). 적용 뒤 4-1 화면 확인: **관 관리 › 화면 도움말** 지금 판 3판 · 「/ 40,000자」 · **검수 › 검수 큐** 「?」 → 「검수 큐」 절.
- 운영에서 SUPER 가 ADMIN_GUIDE 를 이미 고쳤다면 그 판 끝에 붙습니다(같은 탭 키 절은 건너뜀).

## 6. 되돌리기

- 앞 판(v10.622 이하)으로 돌려도 지장 없음 — 옛 서버의 저장 한도는 2만이라 3판(3만 자)을 **그대로 다시 저장**하면 422(새 판은 못 만듦), 「?」 읽기는 그대로 됩니다. 더한 판 · 잇기 줄은 해가 없어 지우지 않습니다(help_docs 는 쌓기만).
