# 446. 공지 한 곳으로(소개광장 › 공지 = 운영 공지) · 공지 알림 기본 켬 — v10.320 (2026-11-16)

> 대표 요청(11/16): 「공지사항 알림을 알림에 추가하고 공지사항을 커뮤니티의 공지사항에 통합하여 공지한다」 → 선택: 알림 **기본 켬** · 통합 **소개광장 공지 = 운영 공지** · 「다음 개발」(계획 승인).
> **마이그레이션 1개 D221(258 → 259) — 운영 적용 때 RDS 스냅샷.** v10.319(docs/445 메인 공지 띠)와 묶어 점검합니다.

## 1. 전에는

| 곳 | 상태 |
|---|---|
| 회원 알림 | 공지 등록 때 「알림」을 **직접 체크**해야 감(처음 값 꺼짐) · 누르면 고객센터 › 공지사항 |
| 소개광장 › 「공지」 탭 | 운영자가 소개광장에 쓴 글(posts · NOTICE)만 — 운영 화면 「공지 등록」 공지는 고객센터 › 공지사항에만 나옴(공지가 두 곳으로 나뉨) |

## 2. 바뀐 것 (정확한 위치)

**공지는 운영 화면 「공지 등록」 한 곳에서만 씁니다.** 같은 공지가 아래 모든 곳에 나옵니다(보는 사람 등급 기준 · 고정 먼저 · 승인된 번역).

| 곳 | 내용 |
|---|---|
| 사용자 웹 **소개광장 › 「공지」 탭** | 맨 위 **「운영 공지」** — 펼치기 · 첨부 · 「새 글」 · 읽음 기록(고객센터와 같은 부품) · 주소 `#n-<id>` 로 그 공지. 그 아래 「소개광장 공지 글」(기존 posts · NOTICE 글 그대로) |
| 소개광장 **「전체」 탭** 첫 쪽 맨 위 | 「상단 고정」 공지 **최대 2줄** → 「공지」 탭의 그 공지 |
| 소개광장 **글쓰기** | 「공지」 게시판으로 쓰기는 **전부터 막혀 있음**(입구 `CreatePostDto` 가 REVIEW · TRADE · QNA 만 · DB 트리거는 운영만) — 바꾸지 않고 시험으로 확인 |
| 회원 **알림**(나의공간 › 알림) | 새 공지 알림을 누르면 **소개광장 › 공지의 그 공지**(`/community?board=NOTICE#n-<id>` · D221) · 단추 이름 「공지 보기」 |
| 머리줄 「새 공지」 점 · 메인 공지 띠(v10.319) | 누르면 소개광장 › 공지 |
| 운영 화면 **노출** › 탭 **「메인 운영」** › 「공지 등록」 | **「알림」 처음부터 체크**(끌 수 있음 · 받는 사람이 기준 이상이면 지금처럼 「모두에게 알림」 확인 문구) · 안내 줄 「소개광장 › 공지 · 고객센터 › 공지사항 · 상단 고정이면 메인 띠 · 소개광장 「전체」 맨 위 · 알림을 켜 두면 …」 |
| 고객센터 › 공지사항 | 그대로(같은 공지) |
