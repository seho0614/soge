## 2. 바로잡은 것 — v10.52 에서 1단계가 닿지 않은 곳

v10.52 는 기준 파일(tokens.css)의 옛 이름을 시트 값으로 바꿨지만, 아래 다섯 틀은 **틀 안에서 같은 이름을 숫자로 다시 정의**하고 있어 그대로였습니다.
그래서 관 화면 · 나의공간은 제목만 페이퍼로지로 바뀌고 본문 글꼴 · 보라 단추는 그대로인 섞인 상태였고, 시안(이런 틀이 없음)과 실제 웹이 달랐습니다.
v10.52 의 정적 시험은 기준 파일만 봐서 걸러내지 못했습니다 — v10.53 시험은 **사용자 웹 CSS 전체**를 봅니다(v10.52 에 돌리면 40곳을 잡음).

| 틀 | 파일 | 다시 정의하던 이름 |
|---|---|---|
| .gw | proto-gwan.css | --pp 계열 · --bl 계열 · --ink · --ink2 · --ink3 · --line · --line2 · --shell · --bg · --f · --sh · --sh2 |
| .mys | proto-my.css | --pp 계열 · --bl · --bl-l · --mink · --mink2 · --mink3 · --mline · --mline2 |
| .w1-vfy | proto-w1.css | --mink 계열 · --mline 계열 |
| .pt-root | proto-partner.css | --pt-ink 계열 · --pt-line 계열 · --pt-pp · --pt-pp-d · --pt-bl-l · 바탕 #E9EAEE |
| .mal-proto | mal.css | --accent(보라) · --accent-w |

**v10.52 는 운영에 올리지 않습니다** — v10.53 을 올립니다.
