## 4. 순서

> ⚠ **명령 블록을 한 번에 붙여 넣지 마십시오.** 4-0 → 4-1 → 4-2 → 4-3 → 4-4 를 **한 블록씩** 실행하고, 결과를 본 뒤 다음으로 넘어갑니다.

### 4-2. RDS 스냅샷 (DB 를 되돌릴 유일한 길)

```
AWS 콘솔 → RDS → 데이터베이스 → sgb-db → 작업 → 스냅샷 생성
이름: sgb-before-v10-55-YYYYMMDD   → 「사용 가능」이 될 때까지 기다림
```

**넘어가기 전 확인 (빠뜨리면 DB 를 되돌릴 길이 없습니다)**

- [ ] RDS → 스냅샷 목록에 `sgb-before-v10-55-YYYYMMDD` 가 있음
- [ ] 상태가 **「사용 가능」**
- [ ] 만든 시각이 4-1 precheck 뒤
- [ ] (지난번 남은 일) `sgb-before-v10-45-20261016` 또는 `sgb-after-v10-45-20261016` 이 있는지도 함께 봄 — 없어도 이번 적용은 진행 가능

