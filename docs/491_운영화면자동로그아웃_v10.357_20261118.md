# 491. 운영 화면 자동 로그아웃 · 운영 역할 로그인 유지 (v10.357 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 운영 화면 자동 로그아웃 · ② 급한 알림 당번 · ③ 개인정보 열람 사유 · ④ 운영자 비밀번호 정책 「모두」 → 계획 「승인 + 통과하면 병합」(세 번째 묶음 · 운영 반영은 v10.356 까지 한 번에 한 뒤). 이 문서는 ①. 마이그레이션 **D236**(273 → 274 · 스냅샷 필요 · v10.358 ~ 360 과 같은 파일).

## 1. 왜

- 운영 화면을 연 채 자리를 비우면 누구나 쓸 수 있었고, 운영 역할도 회원처럼 14일 동안 로그인이 이어졌습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D236** | 설정 `ops.admin_idle_min`(30 · 5 ~ 240분) · `ops.staff_refresh_days`(1 · 1 ~ 14일) |
| 로그인 증표 | 운영 역할(REVIEWER · ADMIN · PAYOUT · SUPER · PARTNER_MAL · PARTNER_AFF)은 다시 받기 증표가 `ops.staff_refresh_days` 일(처음 1일) · 회원은 14일 그대로 · 바꾸면 다음 로그인부터 |
| 새 API `GET /auth/staff-session` | 운영 역할 · 자동 로그아웃 분 · 로그인 유지 일 · 비밀번호 바꾼 지 며칠(v10.360) |
| 운영 화면(모든 화면 위) | 정한 분 동안 마우스 · 자판 · 누름 · 스크롤이 없으면 **1분 전 「n초 뒤 자동 로그아웃」 띠** → 로그아웃. 탭이 여러 개면 가장 최근에 만진 때를 함께 봄 |

## 3. 시험 (test_v1357)

1. ① 코드 — D236 설정 둘 · 증표 · API · 화면(1분 전 띠 · 로그아웃) · 문서 491 · 판 v10.357 · 마이그레이션 274
2. ② API — 운영 역할 로그인 → 다시 받기 증표 기간 1일 · 회원은 14일 · 설정 3일로 바꾸면 운영 역할 3일 · staff-session 값 · 회원 403
3. ③ 화면 — 설정 5분 · 시계를 앞당겨(localStorage 마지막 움직임을 과거로) → 띠 → 로그인 화면

## 4. 운영 적용

- D236 스냅샷. 적용 뒤 운영자는 하루에 한 번 이상 다시 로그인하게 됩니다(2단계 인증을 켜면 그때마다).
- 되돌리기(rollback): 설정은 남고 앞 판은 읽지 않아 14일 · 자동 로그아웃 없음으로 돌아갑니다.
