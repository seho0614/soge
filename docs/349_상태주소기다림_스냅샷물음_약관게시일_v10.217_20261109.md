## 2. apply [3] 스냅샷 물음 늘 — `deploy/aws/apply.sh`

| 올릴 마이그레이션 | 물음 | 대답 |
|---|---|---|
| 있음 | 「RDS 스냅샷을 방금 만들었습니까? 만들었으면 yes」(전과 같음) | `yes` 아니면 멈춤 · 새 판 폴더 지움 |

## 3. 약관 게시일 표시

| 곳 | 전 | 후 |
|---|---|---|
| `GET /terms/doc/{code}` · `GET /terms/index` | — | `publishedAt`(게시한 때 · v10.162 전 게시 판은 null) |
| 사용자 웹 약관 전문 판 줄(SB-HOM-ETC-021) | `판 1.0 · 필수 · 지금 적용 중(첫 판 · 본문 시행일 2026-11-30)` | `판 1.0 · 필수 · 2026-11-08 게시 · 지금 적용 중(…)` — 게시일이 있으면 늘(첫 판이 아니어도) |
| 이용안내 · 약관 표 상태(첫 판 · 적힌 시행일 전) | `발행 · 지금 적용 중(첫 판) · 본문 시행일 …` | `발행 2026-11-08 · 지금 적용 중(첫 판) · 본문 시행일 …`(게시일 없으면 전처럼) |
| 영어 | — | ` · published …` · `Published … · in force now (first version) · …` |
| 운영 화면 약관 표 시행일 칸 | 시행일만 | 아래에 `게시 2026-11-08 18:05`(한국 시간 · 게시 · 보관 판만) |
| postcheck [10] 「게시된 약관」 | `PRIVACY 1.0(11-30)` | `PRIVACY 1.0(11-30 · 게시 11-08)` |

- 운영 화면 API(`GET /admin/terms`)는 v10.162 부터 `publishedAt` 을 내려 왔음 — 화면만 더함.
- 게시 시각은 「게시」 단추(`TermsService.publish`)가 적고 「예정 취소」가 비움. 운영 약관 11개는 11/8 운영 화면에서 게시해 값이 있을 것(운영 DB 는 못 봄 — 적용 뒤 화면으로 확인).
