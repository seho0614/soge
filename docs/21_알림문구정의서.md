# 소개뱅크 — 사용자 알림 문구 정의서

**자동 생성** `node scripts/gen-message-doc.js` · 정본은 `notification_templates`
**이벤트 28 · 템플릿 123 · 운영 경보 5**

---

## 채널별 원칙

| 채널 | 길이 | 쓰는 법 |
|---|---|---|
| 인앱 | 제한 없음 | 본문까지 충분히. 무엇을 해야 하는지까지 |
| 메일 | 제한 없음 | 제목에 `[소개뱅크]` 접두 · 발신전용 안내 |
| **문자** | **90바이트** | 제목만. 상세는 앱으로 유도 |
| 푸시 | 한 줄 | 잠금화면에서 잘립니다 |

**조용한 시간** 21:00~08:00 에는 문자·푸시를 보내지 않습니다. 인앱·메일은 제한 없습니다.

**중복 방지** 같은 이벤트·대상은 10분에 한 번만 발송합니다.

## ★ 수신거부할 수 없는 알림

거래·금전·법정 고지는 끌 수 없습니다. **끄려 하면 DB 가 거부합니다.**

```
NOTIFICATION_OPTOUT_FORBIDDEN: 정산 지급 완료는 수신거부할 수 없습니다.
```

| 이벤트 | 이름 | 왜 |
|---|---|---|
| `LISTING_APPROVED` | 등록 승인 | 노출 시작을 모르면 문의를 놓칩니다 |
| `LISTING_REJECTED` | 등록 반려 | 무엇을 고쳐야 할지 알아야 합니다 |
| `LISTING_RESTRICTED` | 제한업종 지정으로 노출 중단 | 노출 중단은 즉시 알려야 합니다 |
| `BADGE_REJECTED` | 배지 반려 | 반려 사유 전달 |
| `CONTRACT_ISSUED` | 계약서 발급 | 금액이 잠기는 시점입니다 |
| `CONTRACT_SIGN_REQUIRED` | 서명 요청 | 서명하지 않으면 성사되지 않습니다 |
| `DEAL_CONFIRMED` | 성사 확정 | 금전이 오가는 확정 시점 |
| `PAYMENT_REPORTED` | 대금 지급 신고 | 7일 뒤 자동 확정되므로 반드시 알아야 합니다 |
| `SETTLEMENT_REQUESTED` | 정산 신청 접수 | 금전 관련 |
| `SETTLEMENT_PAID` | 정산 지급 완료 | 금전 지급 사실 |
| `SETTLEMENT_HELD` | 분쟁으로 정산 보류 | 보류 사유를 알아야 합니다 |
| `SETTLEMENT_BLOCKED_INDIVIDUAL` | 사업자 전환 필요 | 받을 계좌를 확인하지 않으면 정산이 기록되지 않습니다 |
| `SUBSCRIPTION_RENEWED` | 구독 갱신 | 결제 사실 고지 |
| `SUBSCRIPTION_PAYMENT_FAILED` | 결제 실패 | 방치하면 노출이 줄어듭니다 |
| `PROMO_ENDING` | 무료 기간 종료 예정 | 자동 유료 전환 고지 의무 (B-14) |
| `BUSINESS_APPROVED` | 사업자 인증 완료 | 수령 자격 기준일이 정해집니다 |
| `BUSINESS_REJECTED` | 사업자 인증 반려 | 재신청 안내 |
| `DISPUTE_OPENED` | 분쟁 접수 | 정산이 보류됩니다 |
| `DISPUTE_RESOLVED` | 분쟁 처리 완료 | 처리 결과 통지 |

## 변수 치환

`{name}` 형태이며 발송 시 치환합니다. **치환되지 않은 채로 저장하면 DB 가 거부합니다.**

```
UNRESOLVED_TEMPLATE_VAR: 치환되지 않은 변수가 있습니다 — {amount}
```

`"{amount}원이 지급되었습니다"` 가 사용자에게 나가면 신뢰가 무너집니다.
