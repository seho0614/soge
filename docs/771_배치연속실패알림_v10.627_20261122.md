# 771. 정기 작업 연속 실패 알림 JOB_FAILING — v10.627 (2026-11-22)

## 1. 결론

- 정기 작업(배치)이 실패하면 지금까지는 `job_runs` 에 실패 줄만 남고(운영 알림 › 배치 실행 기록에서 보임) **따로 알리지 않았습니다**. 같은 작업이 며칠씩 조용히 실패할 수 있었습니다.
- 이번 판부터 **같은 작업이 연달아 3번 실패하면 운영 알림 `JOB_FAILING`(CRITICAL)** 을 한 번 올립니다. 급한 알림이라 메일 · 텔레그램 길(켜져 있으면)로도 갑니다. 다음 차례가 성공하면 알림이 저절로 풀립니다.
- 되돌린 상태에서 「이 판에는 없는 작업」(v10.620 UNKNOWN_JOB)은 정상이라 **WARN** 으로만 올립니다(깨우지 않음).
