## 1. 왜

- 전에는 개봉 반품을 재고로 되돌리지 않는 것만 있었고(`restock_skipped = 'OPENED'` · D006) **그 상품이 어디로 갔는지 기록이 없었음**.
- 소개몰은 건강식품 · 화장품만 팔고(의료기기 미판매 · 건강기능식품 잠금), 둘 다 **개봉품 재판매 금지**(법무 확인) → 갈 곳은 폐기 또는 판매자 반송뿐.

## 2. 흐름

| 단계 | 누가 · 어디서 | 무엇이 남나 |
|---|---|---|
| 1 | 운영 › 정산 › 소개몰 정산(반품) — 반품 승인 · 「개봉됨」 · **보관(기본 · 폐기 대기) / 바로 폐기** | 주문은 반품 완료 · 재고로 안 돌아감(전과 같음) · `hlt_open_stock` 에 주문 줄마다 한 행 |
| 1' | 입점 판매자 상품 | 운영자가 무엇을 골라도 **판매자 반송(TO_SELLER)** |
| 2 | 운영 › 거래 › **개봉 반품 재고** — 보관 중인 것을 「폐기」(사유) | 폐기 시각 · 사유 · 누가 · 감사 `HLT_OPEN_DISCARD` |

## 4. API (운영 · ADMIN · SUPER)

| API | 내용 |
|---|---|
| `GET /admin/health/open-stock?state=` | 대장 · 처리별 수(HOLD · DISCARDED · TO_SELLER) |
| `POST /admin/health/open-stock/{id}/discard` | `{note}` → 폐기 · 감사 `HLT_OPEN_DISCARD` |
| `POST /admin/health/returns/{id}/decide` | `openAction`(HOLD · DISCARDED) 칸 더함 — 안 보내면 보관 |
