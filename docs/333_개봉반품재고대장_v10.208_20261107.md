## 0. 먼저 — 법적 확인

개봉된 식품 · 화장품을 다시 파는 것은 식품위생법 · 화장품법(위생 · 표시 · 유통기한)상 문제가 될 수 있습니다. **허용 범위는 법률 확인이 필요합니다.** 그래서 할인 판매는 만들어 두되 스위치는 꺼진 채이고, 켜기는 최고 관리자(SUPER)만 됩니다. 확인 결과 갈래별로 다르면(예: 화장품만) 그때 갈래 제한을 더합니다.

## 1. 흐름

| 단계 | 누가 · 어디서 | 무엇이 남나 |
|---|---|---|
| 1 | 운영 › 거래 › 소개몰 정산(반품) — 반품 승인 · 「개봉됨」 · **보관(기본) / 폐기** | 주문은 반품 완료 · 재고로 안 돌아감(전과 같음) · `hlt_open_stock` 에 주문 줄마다 한 행 |
| 1' | 입점 판매자 상품 | 운영자가 무엇을 골라도 **판매자 반송(TO_SELLER)** — 판매자 상품이라 |
| 2 | 운영 › 거래 › **개봉 반품 재고** — 보관 중인 것을 같은 옵션끼리 골라 「할인 판매로」(값 · 유통기한 · 상태 메모) | 원래 상품을 복제한 **「[개봉 반품] 원래 이름」** 상품(코드 `원래코드-OR개월`) · 옵션 하나 · 재고 = 옮긴 수량 |
| 3 | 스위치 꺼짐 | 그 상품은 **멈춤(STOPPED)** — 손님에게 안 보임 |
| 4 | 최고 관리자가 스위치 켬(같은 탭 「켜기」 또는 사이트 설정) | 멈춰 둔 개봉 반품 상품이 판매 중 · 원래 상품 화면에 「개봉 반품 할인 상품」 줄 |
| 5 | 손님 주문 | **지금 장바구니 · 주문 · 결제 · 환불 흐름 그대로**(새 결제 경로 없음) |
| 6 | 스위치 끔 | 판매 중인 개봉 반품 상품이 모두 멈춤 · 다시 켜면 그것만 판매 |

## 2. 규칙

| 규칙 | 지키는 곳 |
|---|---|
| 처리는 한 방향 — 보관 → 할인 판매 · 폐기만 · 기록은 지우지 못함 · 상품 · 수량 못 바꿈 | DB 트리거 |
| 직판은 보관 · 폐기로 시작 · 입점은 반송만 | DB 트리거 · 서버 |
| 할인 값 < 원래 옵션 값 · 유통기한이 오늘 이후 | DB 함수 `fn_hlt_open_stock_sell` |
| 같은 상품 · 같은 옵션끼리만 한 번에 | DB 함수 |
| 스위치 꺼짐이면 개봉 반품 상품을 판매 중으로 못 바꿈(운영 상품 화면에서도) | DB 트리거 |
| 켜기는 SUPER · 끄기는 ADMIN 도 | 서버(사이트 설정) |
| 개봉 반품 상품은 목록 · 검색 · 같은 성분 · 순위에 안 나옴 — 원래 상품 화면에서만 안내 | 서버(`CARD_FROM`) |

## 3. 손님 화면

| 화면 | 보이는 것 |
|---|---|
| 개봉 반품 상품 상세 | 「개봉 반품 상품」 상자 — 무엇인지 · 원래 상품(이름 · 값 · 링크) · 상태 메모 · 유통기한 · 「개봉 상품이라 단순 변심 반품이 제한될 수 있습니다 — 상품 하자 · 표시와 다름은 반품할 수 있습니다」 |
| 원래 상품 상세 | 스위치가 켜져 있고 판매 중일 때만 「개봉 반품 할인 상품」 — 옵션 · 값 · 남은 수 · 링크 |

## 4. API (운영 · ADMIN · SUPER)

| API | 내용 |
|---|---|
| `GET /admin/health/open-stock?state=` | 대장 · 처리별 수 · 스위치 |
| `POST /admin/health/open-stock/sell` | `{ids, price, note?, expiresOn?}` → 할인 판매 상품 코드 · 상태 · 재고 · 감사 `HLT_OPEN_SELL` |
| `POST /admin/health/open-stock/{id}/discard` | `{note}` → 폐기 · 감사 `HLT_OPEN_DISCARD` |
| `POST /admin/health/returns/{id}/decide` | `openAction`(HOLD · DISCARDED) 칸 더함 — 안 보내면 보관 |
| `GET /health/products/{code}` | `openReturn` · `openFrom` · `openNote` · `openExpiresOn` · `openOffers` 칸 더함 |
