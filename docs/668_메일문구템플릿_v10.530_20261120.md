# 668. 메일 문구 템플릿 편집 (v10.530 · 2026-11-20)

## 1. 결론
지금 코드가 보내는 메일 8가지의 제목 · 본문을 운영 화면 › 회원 › 메일 문구에서 고칩니다(저장 · 되돌리기 · 기본값은 **SUPER**). **자리값 검사**(서버 = DB 트리거) · **미리보기**(보기 값으로 채움 · 보내지 않음) · **판 기록**(쌓기만) · **되돌리기** · **코드 기본값으로**. 발송하는 곳은 지금 글자를 그대로 **코드 기본값(fallback)** 으로 들고 있어, 스위치 `csx.mail_templates`(**처음 꺼짐**)가 꺼져 있거나 · 고친 판이 없거나 · 검사에 걸리거나 · DB 를 못 읽으면 **코드 글자 그대로** 보냅니다(메일은 늘 나감).

## 3. 검사 규칙(서버 `checkMailTemplate` = DB `fn_csx_mail_tpl_guard`)
1. 쓸 수 있는 자리값만(`{이름}` · 소문자 · 밑줄) · 2. 꼭 넣을 자리값(본문 · 제목) · 3. 중괄호는 자리값에만 · 4. **글에 주소(http · https) 직접 쓰기 금지** — 주소는 `{link}` · `{base}` 같은 자리값으로만(피싱 · 잘못된 주소 막음) · 5. 제목 1 ~ 120자 · 줄바꿈 없음(채운 뒤에도 줄바꿈 → 빈칸) · 6. 본문 2 ~ 4,000자.
- 채우기는 한 번만(넣은 값 안의 `{…}` 는 다시 바꾸지 않음).

## 5. 대표 결정 · 확인 거리
1. 켜는 때 — 문구 편집 기능은 **법무 확인 끝(11/20 · 11/21 대표)** · 문구를 고칠 때는 발신자 표시 · 수신 거부 안내가 필요한 메일인지 운영에서 확인한 뒤 스위치를 켬.
2. 코드 기본 문구가 바뀌면(개발) `mail-render.ts` 의 기본 문구도 같이 고쳐야 화면의 「코드 기본 문구」가 맞음(발송은 코드 글자 그대로 — NOTES).
