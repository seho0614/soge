# 345. AI 잠금 글을 「지금 판」 기준으로 바로잡음 — v10.215 (2026-11-08)

> 계기: v10.214(docs/344)가 「운영 상태 한눈에」 AI 줄을 「처리방침 시행 중」 → 「게시됨」으로 고쳤는데, DB 판단 `fn_privacy_ai_ready()` 는 D151(v10.161)부터 **지금 판(`v_terms_current`)** 기준임을 병합 뒤 확인함. 첫 판은 게시 순간 지금 판이라 11/8 운영(처리방침 1.0 첫 판 게시 · 적힌 시행일 11-30)은 맞지만, **앞 판이 있는 새 판은 시행일부터** 풀림 — 「게시됨」은 그 경우 틀림. 하루 요약 「시행되기 전」은 반대로 첫 판일 때 틀림.
> 대표 「다음개발」 → 「하루 요약 AI 문구 고침」 · 절차서는 v10.213 → v10.215 한 번에(11/8).
>
> **마이그레이션 없음** · API 응답 모양 바뀜 없음(글만) · 사용자 웹 바뀜 없음.
