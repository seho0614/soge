# 562. 사내 문서함 (v10.425 · 2026-11-20)

> 대표 11/19 20:35 「모두개발」 — 후보 B6 「사내 문서함」(계약서 밖 회사 문서). D253.

## 1. 결론
정관 · 등기부 · 인감 · 사업자등록 · 규정 · 인증서를 **판으로 보관**합니다. 지우지 않고(보관 끝 표시만), **만료 30일 전부터 운영 알림**(CORP_DOC_DUE)을 보냅니다.

## 2. 위치 · 권한
- 운영 화면 › 사무 › **사내 문서함**
- 올리기 SUPER · ADMIN(파일 용도 CORP_DOC · PDF · JPG · PNG · 20MB) · 열람 SUPER · ADMIN · PAYOUT(REVIEWER 는 못 엶) · 보관 끝 SUPER(사유)

## 3. 규칙
| 규칙 | 막는 곳 |
|---|---|
| 판은 쌓기만 · 판 번호 차례대로 | DB |
| 문서 지우기 없음 · 분류 못 바꿈 · 보관 끝은 되돌리지 않음 | DB |
| 붙은 파일 지우기 막음 | DB(fn_files_acct_guard) |
| 만료 N일 전 알림 · 새 판 · 보관 끝이면 풀림 | 정기 작업 corp_doc_due 09:30 · 설정 acct.corp_doc_due_days(30) |

## 4. API
GET /admin/corp-docs · GET /admin/corp-docs/{id} · POST /admin/corp-docs(감사 CORP_DOC_ADD) · POST /admin/corp-docs/{id}/versions(CORP_DOC_VERSION) · POST /admin/corp-docs/{id}/archive(CORP_DOC_ARCHIVE · SUPER).
