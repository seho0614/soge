# 609 연장 · 야간 · 휴일 근로 — v10.471 (D265 · 2026-11-20)

## 1. 결론
- 직원은 운영 화면 **사무 › 「내 인사」** 아래 상자 「연장 · 야간 · 휴일 근로」에서 일한 날 · 시작 · 끝 · 사유로 신청합니다(앞뒤 31일 · 10분 ~ 16시간 · 끝이 시작보다 이르면 다음 날).
- 관리자(ADMIN · **본인 신청 아님**)가 **회계 › 「인사」 › 탭 「연장 근로」**에서 승인 · 반려(사유) · 승인 취소합니다. 관리자가 직원 대신 신청할 수도 있습니다.
- **주 52시간(기본 40 + 연장 12)** — 그 주(월 ~ 일) 연장 · 휴일 근로 합(신청 + 승인)이 경고 시간(48시간 − 40 = 8시간)을 넘으면 경고 · 승인 합이 연장 한도 12시간을 넘는 승인은 막습니다(설정 `hrx.ot_over_block` on).
- 승인분 수당을 **그 달 초안 급여 대장의 지급액에 더합니다**(SUPER · 다시 셈 · 신청 하나 한 번 · 초안일 때만 되돌림).
- 값은 모두 **일반 원칙**(대표 11/19 「세무사 · 노무사 확인 항목은 일반 원칙으로」 · docs/555)이며 SUPER 가 고칩니다 — **노무사 확인 필요**(6절).

## 2. DB 가 정하는 것(서버 계산을 믿지 않음)
| 칸 | 셈 |
|---|---|
| 분(minutes) | 끝 − 시작(분) · 10 ~ 960 |
| 야간 분(night_min) | [시작, 끝)과 한국 시각 22:00 ~ 06:00 이 겹친 분 |
| 날 종류(day_kind) | 영업일 = WORKDAY(연장) · 토요일 = OFFDAY(무급 휴무일 · 연장 가산 · `hrx.sat_as_holiday` off 일 때) · 일요일 · 공휴일 = HOLIDAY(휴일) |
| 겹침 | 한 직원의 살아 있는 신청(신청 · 승인)은 시간이 겹치지 않음 — 배제 제약 `ex_hrx_ot_overlap`(btree_gist · 이미 켜져 있음) |
| 고치기 | 신청 내용은 못 고침(취소하고 다시) · 지우지 않음 · 급여 대장에 넘긴 승인은 취소 못 함 |

## 3. 수당 셈(일반 원칙 값)
- 통상시급 = 월 기본급 ÷ `hrx.std_month_hours`(처음 209 = 주 40시간 + 주휴 · 월 환산).
- 수당 = 통상시급 × 분/60 × (100% + 가산) — 연장(영업일 · 토요일) OT 50% · 휴일 8시간까지 HOL 50% · 8시간 넘는 분 HOL8 100% · 야간 분에는 NIGHT 50% 를 더함(근로기준법 제56조).
- 기준 시간 `hrx.ot_pay_basis` — **MIN**(처음) 승인 시간과 그날 근태(㉖ 출퇴근)가 겹친 분 중 작은 쪽 · REQUEST 승인 시간 그대로.
- 예: 월 기본급 2,090,000원(시급 10,000원) · 영업일 18:00 ~ 21:00 승인 · 근태 09:00 ~ 20:00 → 겹친 120분 × 150% = 30,000원. 일요일 10:00 ~ 20:00(600분) → 480분 × 150% + 120분 × 200% = 160,000원.

| 설정 | 처음 값 | 뜻 |
|---|---|---|
| `hrx.ot_rates` | OT:50,NIGHT:50,HOL:50,HOL8:100 | 가산율(%) |
| `hrx.week_limits` | BASE:40,OT:12,WARN:48 | 주 기본 · 연장 한도(휴일 포함) · 경고 |
| `hrx.std_month_hours` | 209 | 통상시급 나눗수 |
| `hrx.ot_over_block` | on | 한도 넘는 승인 막기 |
| `hrx.sat_as_holiday` | off | 토요일을 휴일로 셈(취업규칙에 따름) |
| `hrx.ot_pay_basis` | MIN | 수당 기준 시간 |

## 4. 급여 대장으로
1. 회계 › 인사 › 급여에서 그 달 급여 대장(초안)을 만듭니다.
2. 연장 근로 탭 아래 「급여 대장으로」 상자에서 직원별 합계를 보고 **「급여 대장에 넘기기」**(SUPER) — 직원별 지급액(gross)에 더하고 세금 · 4대보험을 다시 셉니다.
3. 잘못 넘겼으면 「되돌리기」(초안일 때만) → 승인 취소 · 다시 승인 · 다시 넘기기. 확정한 급여는 넘기지도 되돌리지도 않습니다(DB 도 막음).
- 그 달 급여 줄이 없는 직원(입사 전 · 퇴사 뒤)은 건너뛰고 알려 줍니다. 연장 수당은 과세 급여로 넣습니다(생산직 비과세 연장수당은 이번 판에 없음 — 세무사).

## 5. 주 52시간 경고 알림
- 정기 작업 `hrx_ot_week`(매일 09:50) — 이번 주 경고 시간을 넘은 직원 수를 운영 알림 **HRX_OT_WEEK** 하나로(이름 없이 수만 · 한도를 넘은 사람이 있으면 CRITICAL · 주에 하나 · 다음 주나 0명이면 풀림).

## 6. 노무사 확인 필요(일반 원칙으로 넣은 것)
1. 통상임금 범위 — 지금은 월 기본급만(고정 수당 · 정기 상여 포함 여부 확인).
2. 상시 5인 미만 사업장은 가산 수당 · 연장 한도 적용이 다름(근로기준법 제11조) — 해당하면 가산율을 0 으로.
3. 포괄임금 · 고정 연장 수당 약정이 있으면 이중 지급 주의.
4. 토요일(무급 휴무일 · 휴일) 구분은 취업규칙 · 근로계약서 기준.
5. 특별연장근로 · 탄력적 · 선택적 근로시간제는 이번 판에 없음.
