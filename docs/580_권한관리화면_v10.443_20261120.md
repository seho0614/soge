## 2. 화면
| 상자 | 할 수 있는 것 |
|---|---|

## 3. API
`GET /admin/perm/overview` · `GET · PUT /admin/perm/role-groups/{key}` · `PATCH /admin/perm/task-groups/{key}` · `PATCH /admin/perm/tasks/{key}` · `GET · PUT /admin/perm/accounts/{id}` · `GET /admin/perm/shadow` · `GET /admin/perm/changes` — 모두 SUPER · 저장은 사유 · 감사(PERM_ROLE_GROUP_SET · PERM_TASK_GROUP_SET · PERM_TASK_SET · PERM_ACCOUNT_SET) · 운영 알림 PERM_CHANGED(INFO).
