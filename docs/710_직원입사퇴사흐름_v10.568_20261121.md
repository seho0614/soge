# 710. 직원 입사 · 퇴사 흐름 (v10.568 · 2026-11-21)

> 대표 11/21 「모두 개발진행」. 직원 · 권한 › 새 탭 「입사 · 퇴사」(키 `staff-cases`). 흩어진 인사 · 권한 일을 **한 흐름의 체크리스트**로 묶고, 끝날 때까지 운영 알림을 남깁니다. SQL `prr_2_v10568_staff_cases.sql`(v10.566 SQL 뒤).

## 1. 결론
- 흐름(`prr_cases`) = 직원 하나 · 종류(입사 JOIN · 퇴사 LEAVE)마다 열린 것 하나.
- 단계 대부분은 **기존 표를 보고 저절로 「됨」** — 새로 만든 셈은 없습니다. 손으로 「됨」은 초대 · 퇴직금 확인 · 서류 보관 셋뿐, 그 밖은 사유와 함께 「건너뜀」.
- 흐름이 열린 동안 운영 알림 `STAFF_CASE_OPEN`(INFO)이 풀리지 않고, 기한을 넘기면 `STAFF_JOIN_OVERDUE`(INFO) · `STAFF_LEAVE_OVERDUE`(WARN)가 한 번 더 올라갑니다(정기 작업 `prr_daily`). 끝내기 · 취소 때 셋 다 풂.

## 2. 단계

### 입사
| 단계 | 「됨」 조건(저절로) | 재사용 · 자세히 |
|---|---|---|
| 직원 대장 | 흐름을 열 때 직원을 고르거나 새로 넣음 | `payroll.addEmployee`(급여 › 직원과 같은 칸 · 주민등록번호 · 계좌 없음) |
| 운영 계정 초대(손으로) | 초대 메일을 적음 또는 이미 연결 | 메일은 **보내지 않음** — 안내문을 돌려줌(복사해 전함) · 그 메일로 가입했는지 알려 줌 |
| 계정 연결 | `acct_employees.account_id` 있음 | 역할 주기에서 직원을 고르면 그 자리에서 연결(v10.563 `assertStaffGrant`) |
| 역할 · 권한그룹 | 운영 역할 하나 이상 + 권한그룹 하나 이상(역할을 받으면 R_역할 그룹이 붙음) | 역할 주기 · 사원 권한 |
| 근로계약서 | `hr_contracts` 서명함(SIGNED) | 근로계약서 탭 |
| 의무교육 | 지금 기간 교육 모두 이수 | `hr-training.myTraining` |

운영 계정이 필요 없는 직원은 초대 · 연결 · 역할을 사유와 함께 건너뜁니다.

### 퇴사
| 단계 | 「됨」 조건 | 재사용 · 자세히 |
|---|---|---|
| 퇴사일 | 직원 대장에 퇴사일 | 흐름을 열 때 넣으면 `payroll.updateEmployee` → D291 트리거가 역할이 남으면 `STAFF_LEFT_ROLE` |
| 운영 권한 거두기 | 연결 계정에 운영 역할 · 권한그룹 · 개별 권한 0(연결 없으면 됨) | 단추 「권한 모두 거두기」 = `staff.revokeAll`(역할 · 마지막 SUPER 409 · 자기 자신 403 · 기록 사유) + 권한그룹 · 개별 지움(`perm_changes`) |
| 장비 반납 | 그 계정이 담당인 IT 자산(`its_assets` ACTIVE) 0 | IT 자산 · 구독 탭에서 담당 바꾸기 · 해지 |
| 퇴직금 추계 확인(손으로) | 재직 1년 미만이면 저절로 됨(근로자퇴직급여 보장법 4조 일반 원칙) | `severance.severanceEstimate`(퇴사 전 마지막 온달 기준) · 금액은 SUPER 에게만 |
| 서류 보관 기한(손으로) | 확인함 | 근로계약서 · 근로자 명부 · 임금대장 · 퇴직 서류 **3년**(근로기준법 42조 · 퇴직한 날부터) · 급여 원천징수 장부 · 증빙 **5년**(국세기본법 85조의3) — 일반 원칙 값 · SUPER 고침 |

## 5. 현장 체크리스트
1. 새 직원: 흐름 열기(새 직원 넣기) → 「초대 메일 적기」 → 안내문 전달 → 가입하면 역할 주기에서 이 직원 골라 역할 → 근로계약서 보내기 · 서명 → 의무교육 → 「흐름 끝내기」.
2. 퇴사: 흐름 열기(퇴사일) → 「권한 모두 거두기」 → IT 자산 담당 바꾸기 → 퇴직금 추계 확인(급여 › 퇴직금) → 서류 보관 기한 확인 → 「흐름 끝내기」.
3. 운영 알림 「입사 · 퇴사 흐름 진행 중」이 남아 있으면 끝나지 않은 흐름이 있다는 뜻.

## 6. 확인할 것 · 한계
- 초대 메일은 보내지 않습니다(메일 길 준비 전) — 안내문만. 메일 원문은 흐름이 끝나면 지웁니다.
- 퇴직금 추계는 `severanceEstimate` 의 달 기준(퇴사 전 마지막 온달)이라 정확한 퇴직금과 다를 수 있음 — 정산은 급여 › 퇴직금 · 노무 확인.
- 흐름을 취소해도 퇴사일 · 거둔 권한은 되돌리지 않습니다.
- 보관 기한(3년 · 5년)은 일반 원칙 값입니다 — 법령 개정 여부는 확인이 필요합니다.
