# 682. 파트너 자료 내려받기 (v10.544 · 2026-11-20)

## 1. 결론
파트너센터에서 **자기 파트너의 리드 · 성과를 CSV** 로 받습니다. **리드 CSV 는 내려받기 승인**(D238 export_requests · 대상 `PTN_LEADS`) 뒤 24시간 안 한 번, **성과 CSV 는 숫자만**이라 승인 없이 받습니다. 받을 때마다 기록(`ptn_export_logs` 쌓기만) · 감사가 남습니다. 대표 · 정산 권한 직원만. 처음에는 꺼져 있습니다(`ptn.export_enabled` off). 위치: 파트너센터 **실적 · 등급 › 자료 내려받기**(`/partner/export` · SB-PTC-VSX-010) · 운영 **파트너사 › 파트너 자료 내려받기**(SB-ADM-VSX-030 · 기록) · 승인 **위험감지 › 감사 › 내려받기 승인**(SUPER · 기존 화면).

| 항목 | 규칙 |
|---|---|
| 누가 | 파트너 대표 · 정산 권한(can_settle) 직원(PartnerActorService.canMoney) — 그 밖은 403 PTN_EXPORT_ROLE |
| 리드 CSV 칸 | 배정 번호 · 배정 · 열람 시각 · 상태 · 시 · 도 · 시 · 군 · 구 · 업종 · 급함 · 요약(전화 · 메일 · 7자리 넘는 숫자 가림) · 이용료 상태 · 금액 — **연락처 칸 없음**(contact_enc 읽지 않음) |
| 리드 기간 · 줄 | 처음 90일 · 366일까지 · `ptn.export_max_rows` 5,000줄까지(넘으면 truncated) · 회수(REVOKED) 배정 뺌 |
| 승인 | 파트너가 사유(2 ~ 150자) 요청 → 운영 알림 `PTN_EXPORT_REQUEST` → 다른 SUPER 승인(혼자면 기존 규칙) → 24시간 안 한 번(`@ExportGate('PTN_LEADS')` 가 쓴 것으로 표시) · 하루 10건 |
| 성과 CSV | 최근 12개월 달마다 받은 리드 · 연락처 열람 · 1시간 안 열람 · 리드 이용료 확정(BILLED) |
| 엑셀 | UTF-8 BOM · 수식 끼워 넣기 막음(= + - @ 로 시작하면 ' 붙임) |

## 2. 전체 구조
1. 표 `ptn_export_logs`(쌓기만 · fn_block_write) · `export_requests_target_check` 에 PTN_LEADS(지금 목록을 읽어 하나만 더함 · D270 · D282 모양).
2. `export-approval.ts` 의 대상 목록 · 이름 · 역할 표에 PTN_LEADS(역할 `[]` — 운영자는 SUPER 만 요청 · 파트너는 `/partner/export/request` 길).
3. 서버 `src/modules/vsx/ptn-export.ts` · `VsxPartnerController`(api/v1/partner) · 운영 `VsxPtnAdminController`.
4. 사용자 웹 `/partner/export`(PtnExportView · 받은 CSV 글을 브라우저에서 파일로 저장) · 실적 · 등급 화면 아래 단추.
