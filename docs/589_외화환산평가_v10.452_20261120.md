# 589. 결산 외화 받을 돈 환산 평가 (v10.452 · 2026-11-20)

> 대표 11/20 03:30 「다음개발」 ㉗ 장부 보강. 마이그레이션 D260 ①(계정) · ③.

## 1. 결론

달 말일까지 **못 받은 수출 받을 돈(외상매출금)** 을 **기말 환율**로 다시 셉니다. 차이는 **외화환산이익(910) · 외화환산손실(955)** 로 말일 전표(FX_REVAL)를 넣고, **다음 달 첫날 되돌림 전표(FX_REVAL_REV)** 를 함께 넣습니다. 그래서 대금을 받을 때의 외환차익 · 차손(⑳ 수출 EXPORT_PAID)은 선적 원화 기준 그대로 맞습니다. 달마다 한 번 · SUPER.

## 2. 셈

| 항목 | 내용 |
|---|---|
| 대상 | acct_exports 선적 · 수출신고 수리 · 대금 회수 중 — 선적일 ≤ 말일 · 회수일이 없거나 말일 뒤 · 수출 매출 전표(EXPORT_SALE) 있음 |
| 건마다 | 평가 원화 = round(외화 합 × 기말 환율) · 차이 = 평가 원화 − 선적 원화(sale_krw) |
| 이익 | 차변 외상매출금 / 대변 외화환산이익 |
| 손실 | 차변 외화환산손실 / 대변 외상매출금 |
| 되돌림 | 다음 달 1일 · 같은 줄 차대 반대 |
| 차이 0 | 전표 없이 기록만 |
| 환율 | 통화마다 SUPER 가 넣음(서울외국환중개 매매기준율 등) · 빠진 통화가 있으면 422 |
| 막음 | 앞으로 올 달 422 · 같은 달 두 번 409 · 말일 · 다음 달 첫날이 마감한 달이면 422 · 기록은 쌓기만 |

## 4. 운영 순서(달마다)

1. 월 마감 전에 회계 › 장부 › 외화 환산에서 그 달 평가.
2. 그다음 회계 › 장부 › 월 결산에서 마감.
3. 수입(⑯) 외화 갚을 돈은 이번 판 대상이 아님(수입은 통관 때 원화로 확정) — 필요하면 세무사와 정함.
