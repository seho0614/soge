# 436. 입점 요율 정하기 한 흐름 — v10.312 (2026-11-15)

> 대표 결정(11/15): 「다음 개발 목록」 → A · B · C · D 모두 · 계획 「승인 + 통과하면 병합」.
> **마이그레이션 없음 · 화면만.** 대표 할 일 「입점 유형 요율 정하기 → 입점 약관 제17조 두 칸」을 시뮬레이션 → 요율 저장 → 약관 칸까지 한 흐름으로 잇습니다.

## 1. 바뀐 것 (정확한 위치)

| 순서 | 곳 | 내용 |
|---|---|---|
| ① | 운영 화면 맨 위 **소개몰** › 탭 **「소개몰 판매자」** › 「판매수수료율 시뮬레이션」 | 표 아래 **「이 요율로 정하기(브랜드 직영관 x% · 일반 입점 y%) → 소개몰 정산」** — 두 값을 이 브라우저에만 잠시 담고(저장 아님) 「소개몰 정산」으로 감 |
| ② | **소개몰** › 탭 **「소개몰 정산」** › **「입점 유형 요율」** 상자 | 「시뮬레이션에서 고른 요율 — **브랜드 직영관 x% 로 바꾸기** · **일반 입점 y% 로 바꾸기** · 지우기」 줄. 누르면 지금 「바꾸기」와 같은 창이 그 값으로 열림(최근 30일 주문 미리보기 · 올림이면 30일 뒤 예약 · 사유) |
| ③ | **관 관리** › 탭 **「약관」** › 「입점 약관 제17조 요율 ↔ 「입점 유형 요율」」 상자 | 초안 판에 운영 요율과 다른(빈칸 · 다름) 줄이 있으면 **「1.0 약관 칸을 운영 요율로 채우기」** — 그 판 「고치기」를 열고 제17조 표의 요율 칸만 운영 값으로 바꾼 뒤 바뀐 줄을 보여 줌 · 「제17조 요율 칸을 … 채웠습니다 — 아직 저장하지 않았습니다 · 되돌리기」 · 저장은 「저장(게시 아님)」 |

- 저장하면 대조 상자가 「같음」이 되고, 빈칸이 다른 곳에 없으면 게시 막힘이 풀립니다(게시는 법무 확인 뒤).
- 요율을 올리는 경우(영향받는 판매자가 있으면) 운영 요율은 시행일까지 「예정」입니다 — 대조는 「예정 예약 값과 같음」으로 보입니다.
