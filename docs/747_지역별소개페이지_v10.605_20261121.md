# 747 지역별 소개 페이지 · 사이트 지도 — v10.605 (17차 ㉑ · 2026-11-21)

## 1. 결론
- 사용자 웹 `/area`(시 · 도 목록) · `/area/{시도}` · `/area/{시도}/{시군구}`(그 지역 게시 매물 30개씩 · 관 거르기 · 많은 업종) · 사이트 지도에 지역 주소.
- 게시 매물이 `lsq.region_min`(3)개 미만인 지역은 목록 · 페이지 · 사이트 지도에 넣지 않음(얇은 페이지 · 한두 명이 드러나지 않게 · 404).
- 보이는 것: 제목 · 한줄 소개 · 업종 · 관 · 금액 · 게시일 — **등록자 이름 · 연락처 · 상세 주소 없음**. 스위치 `lsq.region_pages` 처음 **off**.

## 2. 재사용
| 기존 | 어떻게 |
|---|---|
| 보기 v_listing_region(v10.31) | 지역 판정 그대로(매물 시 · 도 먼저 · 없으면 인증 사업장) — 새 표 없음 |
| 사이트 지도 sitemap.ts · /site/sitemap-entries(v10.174) | 같은 범위(게시 · 켜진 관 · 허브 아님 · HLT 제외)에 지역 줄 더함 |
| 지역별 시세 /price-stats(v10.552) | 화면 모양 · lpx.css 클래스 그대로(새 CSS 없음) |

## 3. API · 화면
| 주소 | 설명 |
|---|---|
| GET /site/lsq/regions | 시 · 도 · 아래 시 · 군 · 구(문턱 이상) · 꺼짐 enabled false |
| GET /site/lsq/regions/listings?sido=&sigungu=&gwan=&page= | 그 지역 매물(422 LSQ_REGION_SIDO · SIGUNGU · 문턱 아래 404) |
| GET /admin/lsq/regions | 공개될 지역 수 · 문턱 아래 · 지역 모름 매물 · 지역 표 100 |
- 사용자 웹 `SB-HOM-LSQ-010` · `SB-HOM-LSQ-020` · 운영 `SB-ADM-LSQ-040`. robots 는 /area 를 막지 않음(그대로).

## 4. 켜는 순서
1. 운영 화면에서 공개될 지역 수 · 문턱 확인 → 2. 대표가 문구 확인 → 3. `lsq.region_pages` 켬 → 4. 사이트 지도(1시간 캐시) 다음 갱신 뒤 /sitemap.xml 에 /area 확인.
