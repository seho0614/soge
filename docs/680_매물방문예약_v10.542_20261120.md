# 680. 매물 방문 예약 (v10.542 · 2026-11-20)

## 1. 결론
매물 주인이 **방문 가능한 시간 칸**을 열고, 회원이 그중 하나를 골라 **요청 → 주인 확정**하는 기능입니다. 확정되면 회원에게 알림, **전날 한 번 더** 회원 · 주인에게 알림이 갑니다. 방문 시각이 지나면 주인이 **방문 끝 · 노쇼**를 표시합니다. 처음에는 꺼져 있습니다(`vsx.enabled` off · **관별 설정 `vsx.gwans` 처음 NONE = 모든 관 꺼짐** — 대표 11/21 「관별로 설정」). 위치: 운영 **검수 › 매물 방문 예약**(SB-ADM-VSX-010 · 탭 `vsx-visits`) · 회원 **나의공간 › 방문 예약**(`/my/visits` · SB-MYP-VSX-010) · 매물 상세 아래 「방문 예약」 칸.

| 항목 | 규칙(처음 값 · 운영 설정 SUPER) |
|---|---|
| 관별 설정 | `vsx.gwans`(NONE 또는 관 코드 쉼표 목록 · 값 무늬 = 서버 `VSX_GWANS_RE`) · 운영 화면 방문 예약 탭 관별 스위치(SUPER · 사유) · **꺼진 관 매물은 칸 열기 · 예약을 서버와 DB 트리거(`fn_vsx_gwan_on`)가 막음 — 422 VSX_GWAN_OFF** · 매물 상세 칸도 안 그림 |
| 칸 열기 | 매물 주인만 · 게시 중(PUBLISHED) 매물만 · 날짜 하나 + 시각 1 ~ 24개(10분 단위) · 길이 10 · 20 · 30 · 40 · 50 · 60 · 90 · 120 · 180 · 240분 |
| 범위 | 오늘부터 `vsx.slot_days` 30일 안 · 매물마다 앞 칸 `vsx.max_open` 60개 · 같은 매물 열린 칸끼리 겹치지 않음(DB) |
| 요청 | 로그인 회원 · 자기 매물 안 됨 · 매물마다 살아 있는 예약 하나 · 모두 10개까지 · 한 줄 메모 200자(연락처 적지 않도록 안내) |
| 칸 하나 = 예약 하나 | 살아 있는(요청 · 확정) 예약은 칸마다 하나(DB 고유 색인) — 동시에 고르면 뒤엣것 409 VSX_SLOT_TAKEN |
| 확정 · 취소 | 주인 확정(방문 전 요청만) · 회원 · 주인 모두 방문 전 취소(까닭 선택 · 상대에게 알림) · 주인이 칸을 닫으면 그 칸 예약은 주인 취소 |
| 저절로 취소 | 방문 시각까지 확정되지 않은 요청은 정기 작업이 취소(SYSTEM) · 회원에게 알림 |
| 전날 알림 | 내일 방문 확정 예약 — 한국 시각 10시부터 한 번(`reminded_at`) · 회원 · 주인 알림함(회원 알림 설정에 따라 메일) |
| 노쇼 · 방문 끝 | 확정 예약 · 방문 시각 뒤 7일 안 · **노쇼 횟수는 매물 주인(회원 화면 · 회원 API)에게 보이지 않음 — 운영 화면(방문 예약 탭 · 지난 180일)에서만**(대표 11/21) · 자동 제재 없음 |

## 2. 전체 구조
1. 표 `vsx_slots`(칸 · 닫기만 · 지우기 막음 · 트리거 `fn_vsx_slot_guard`) · `vsx_bookings`(예약 · 상태 한 방향 · 지우기 막음 · 트리거 `fn_vsx_booking_guard`) · 닫으면 예약 취소 `trg_vsx_slot_close_cascade`.
2. 서버 `src/modules/vsx/visits.ts` · 컨트롤러 `VsxMemberController`(api/v1/vsx) · 운영 `VsxAdminController`.
3. 정기 작업 `vsx_visit`(매시간 · 꺼져 있으면 아무것도 안 함).
4. 회원 화면 `site/src/components/vsx/VisitBook.tsx`(매물 상세 · 로그인 · 스위치 꺼짐이면 아무것도 안 그림) · `VisitsView.tsx`(나의공간).
5. 회원 알림 `VSX_BOOK_REQUEST` · `VSX_BOOK_CONFIRMED` · `VSX_BOOK_CANCELLED` · `VSX_VISIT_REMIND`(링크 /my/visits).

| 방법 | 주소 | 누가 | 오류 |
|---|---|---|---|

| POST | /vsx/listings/{id}/book `{ slotId, memo? }` | 회원(감사 VSX_BOOK) | 409 VSX_OFF · VSX_ALREADY · VSX_SLOT_CLOSED · VSX_SLOT_TAKEN · 422 VSX_GWAN_OFF · VSX_BOOKING_SELF · VSX_LIMIT |
| GET | /vsx/me | 회원 | — |
| POST | /vsx/bookings/{id}/cancel · /confirm · /mark `{ result }` | 회원 · 매물 주인 | 404 · 409 VSX_BOOKING_STATE · 422 VSX_BOOKING_EARLY · LATE |
| GET · POST | /vsx/owner/listings/{id}/slots | 매물 주인 | 409 VSX_OFF · 422 VSX_DATE_RANGE · VSX_TIME · VSX_MAX_OPEN |
| POST | /vsx/owner/slots/{id}/close | 매물 주인 | 409 VSX_SLOT |
| GET | /admin/vsx/visits | ADMIN · SUPER | — |
| POST | /admin/vsx/visits/run | SUPER | — |
| PUT | /admin/vsx/settings `{ visitGwans?, … }` | SUPER(네 기능 설정 한 곳 · 관별 포함 · 사유) | 422 VSX_RANGE · VSX_GWANS · VSX_NOTHING |
