### 왜 p95 · 1500ms 인가
평균은 몇몇 아주 느린 요청을 가리고, 가장 느린 것 하나는 우연에 흔들립니다. 「100번 중 95번은 이 안에 끝남」(p95)이 손님이 느끼는 느림에 가깝습니다. 1.5초는 화면 하나가 여러 API 를 부르는 사용자 웹에서 눈에 띄기 시작하는 값으로 잡았고, 운영 화면 설정에서 바꿉니다(수치는 운영해 보며 조정 필요).

## 3. 운영에서 (적용 뒤)
1. postcheck 에 「API 본문 읽기 — POST 저장 길 정상」 줄이 나오면 정상. **「API 가 JSON 본문을 읽지 못함」이 나오면 바로 rollback.sh** 뒤 알려 주십시오.
2. 「지켜보기」 「느린 응답」 칸이 자주 빨개지거나 SLOW_API 가 자주 울리면 느린 주소 5곳을 알려 주십시오(서버 크기 · 조회 고치기 판단). 너무 자주 울리면 `ops.slow_p95_ms` 를 올리고, 끄려면 0.
3. 회원 투표(켰을 때) 신고는 소개광장 검수 「신고된 회원 투표」에서 처리합니다.
