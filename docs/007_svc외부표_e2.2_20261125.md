# 007. svc 외부 표 — 소개뱅크 표 읽기 전용 (e2.2 · 2026-11-25)

> 설계서 4-3 A안(postgres_fdw — 같은 DB 서버의 다른 데이터베이스 표를 내 표처럼 읽는 기능).

## 무엇
- `tools/erp-svc.sh board|apply` — ① 소개뱅크 DB 에 읽기 전용 사용자 `erp_ro`(표마다 SELECT 만) ② sgb_erp 에 확장 postgres_fdw · 서버 `sgb_src`(updatable false) · 이름 묶음 `svc` · 외부 표 가져오기 ③ 확인(svc.accounts 읽힘 · 쓰기 막힘).
- 표 목록 = `tools/svc-tables.txt`(소개뱅크 ERP 모듈 코드에서 센 32표) + e2.1 목록 두 파일의 소개뱅크 표.
- 쓰기는 두 겹으로 막음: 서버 updatable false · erp_ro 에 SELECT 만. 운영 알림 · 회원 알림은 소개뱅크 내부 API(v10.800).

## 운영(E8 · 사람)
- RDS 에서 확장 · 사용자 만들기는 마스터 사용자로. 암호는 환경 변수 `ERP_RO_PASSWORD` 로만(파일 · 출력에 남기지 않음).
- **RDS postgres_fdw 지원:** AWS 문서상 지원 확장 목록에 있음 · 이 인스턴스에서 실제로 되는지는 E8 전에 확인 필요. 안 되면 설계서 4-3 B안.
