## 2. 오픈 당일 (D-day) — 켜는 순서

> 원칙: **돈이 실제로 오가는 것을 마지막에**(docs/439). 한 줄 켤 때마다 확인 칸을 보고 다음 줄로. 이상하면 그 줄만 되돌림(간주 · 스위치는 다시 켜기 · 끄기가 언제나 됨).

| 차례 | 시각(예) | 할 일 | 위치 | 확인 | 되돌리기 |
|---|---|---|---|---|---|
| 1 | 08:00 | 오픈 직전 정리 `open-prep.sh apply` → `yes` | 운영 서버(ubuntu) | 다시 check — 시험 계정 쓰는 중 0 · 매물 · 요청 · 보이는 글 0 | 계정 상태만 되돌림(지운 것 없음) |
| 2 | 08:20 | 수금 계좌 간주 끄기(사이트 기본 정보에 실제 계좌 3항목 → 저절로 꺼짐) | 사이트 설정 › 기본 정보 | 간주 순서표 1줄 「꺼짐」 | 값 되돌림 |
| 3 | 08:30 | 중개사 간주 끄기 → **간주 끈 뒤 처리 › 중개사 재대조**(50건씩 · 다름 · 없음은 알림만) | 오픈 체크리스트 | 재대조 남은 대상 0 으로 가는 중 · 다름 · 없음은 확인 사유 | `assume.broker` on |

## 4. 멈추고 되돌릴 조건

| 상황 | 할 일 |
|---|---|
| 실제 결제에서 승인 · 취소가 맞지 않음 | `assume.payment` on(결제 간주로) · 소개몰 「주문 받기」 off · 결제대행사 확인 |
| 서버 5xx 가 계속 · 화면이 안 열림 | 사이트 점검 중 화면 켜기 → 원인 확인 → 필요하면 운영 rollback(절차서 · 대표 승인) |
| 개인정보가 잘못 보임 | 해당 화면 스위치 off · 사이트 점검 중 · 법무 · 신고 기한 확인 |
| DB 이상 | 1절 스냅샷 기준으로 판단(복원은 사람 · 대표 승인) |
