# D019 — 법무 질의서 · 외부 연동 준비표 (2026-10-02)

개발로 끝낼 수 없는 두 가지(법무 판단 · 외부 계약/키)를 한 장에 모았습니다. 이 문서는 **보내고 받아 오는 일**의 목록이며, 회신을 받으면 표의 「반영 위치」만 바꾸면 됩니다.

## 2. 외부 연동 준비표

| 연동 | 막는 기능 | 지금 동작 | 연동 후 할 일 |
|---|---|---|---|

## 3. 오픈 직전 순서 (D005 와 같음)

## 6. 법률 · 세무 월 정액 노출형 (마이그레이션 D019 · 2026-10-02 대표 결정)

법무 회신(Q2 · Q3 「문제 없음」)이 다룬 **월 정액 노출형만** 엽니다. 상담 신청(리드)은 만들지 않습니다.

| 규칙 | 구현 |
|---|---|
| 리드 없음 — 소비자가 사무소 정보를 보고 직접 연락 | 업종 방식 `consult_mode = 'LISTING_FEE'`. 상담 신청 `CONSULT_DIRECTORY_ONLY` · 리드 `LEAD_DIRECTORY_ONLY` 로 거부 |
| 노출료는 기간 정액 — 클릭 · 연락 · 성사와 무관 | `consult_directory_entries` 에 건수 연동 칸 없음(MX-19). 노출 켜기는 금액 · 기간 · 입금 근거가 모두 있어야(`ck_directory_active`) |
| 돈으로 순위를 사지 않음 | 공개 목록 순서를 날마다 섞음 |
| 「광고」 표시 | 공개 API · 화면에 표시 |
| 자격 확인 | 변호사 · 법무사(`LEGAL`) / 세무사 · 공인회계사(`TAX`) 자격 승인 + 상담 축 입점 승인 업체만 노출 |
| 결제 | 전자결제 연동 전 — 관리자가 입금 확인 후 노출 기간을 켬 |

| API | 권한 |
|---|---|
| `GET /api/v1/consult/directory/:code` | 누구나 |
| `GET·POST /api/v1/partner/directory` | 회원 · 사업자 (게재 신청) |
| `GET /api/v1/admin/directory` · `POST …/:id/activate` · `…/reject` · `…/end` | 관리자 (사유 필수) |

화면: 사용자 웹 `/mal/consult/CSL_LEGAL` · `/mal/consult/CSL_TAX`(광고 목록 · 직접 연락), `/partner/listings` 게재 신청, 관리자 「정액 노출 관리」.

**검정**: 불변식 175/0(첫 실행 174/1 — 기존 SV-12) · 공격 안전 605 · 뚫림 0(MX-11~20) · 라우트 387 · 백엔드 · 프런트 타입 0 · API 흐름 30/30 · 사이트 · 관리자 빌드 성공 · 시안 31/31.

**정한 것 (10/2 · v10.12 · D020)**: 월 노출료 **기준 금액은 관리자가 등록**합니다 — 시작값 **월 300,000원**(설정 `directory.monthly_fee` · BO 「법률·세무 정액 노출」 탭 맨 위). 노출을 켤 때 금액을 비우면 기준 금액으로 기록하고, 건별로 다른 금액을 적으면 그 금액이 우선합니다(0원은 거부). 기준 금액을 바꿔도 이미 켠 노출의 금액은 그대로입니다. 부가세 포함 여부 · 계약서 문구는 법무 · 세무 확인 대상입니다.

## 7. v10.11 반영 메모 (2026-10-02 · 이 kit)

- 이 문서는 올린 kit(v10.4.7)의 `D009_법무질의_외부연동_준비.md` 입니다. 이 kit 에서는 마이그레이션 번호가 D016~D019 라 파일 이름과 본문 번호를 바꿨습니다.
- §4 의 화면 주소 가운데 **소개하기 안내**는 이 kit 에서 `/mall/give` 입니다(소개코드 발급 · 결제까지 연결 — v10.9). `/mal/give` 로 열면 그리로 보냅니다.
- 상담 신청은 `/consult`(업종 고르기 + 신청서 + 내 상담 신청)와 `/mal/consult` · `/mal/consult/{code}` 양쪽에서 같은 신청서를 씁니다.
- 관리자 화면: 「안심소개 입점 심사」 · 「법률·세무 정액 노출」 탭.
- §2 외부 연동 가운데 **알림톡** — 연동 전에는 개발 환경에서만 인증번호가 화면에 보이고, 운영(NODE_ENV=production)에서는 상담 신청을 받지 않습니다(`NOTIFY_NOT_READY`). **오픈 전에 알림톡 연동이 끝나야 상담 신청이 열립니다.**
- 상담 신청 연락처 파기(6개월) — 올린 kit 에는 함수(`fn_consult_purge`)만 있고 부르는 곳이 없었습니다. 이 kit 은 `pii_purge` 배치가 날마다 부릅니다.
