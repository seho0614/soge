# 334. 메일 반송 · 수신 거부 주소(보내지 않을 주소) — v10.209 (2026-11-07)

> 계기: 대표 「다음개발 모두」 → 메일 반송 표시(A-6) 「꺼진 채로 미리 개발 · 운영 메일을 켜면 동작」(11/7 「승인」).
> 전에는 반송 · 수신 거부를 SES 억제 목록만 막고, 앱 발송 기록은 「보냄」으로 남았음(docs/167 4절).
>
> **마이그레이션 1개(D186 · 223 → 224)** · 새 API 3개(공개 웹훅 1 · 운영 2) · 운영 화면 › 외부 연동 › 메일 안의 한 구역 · 회원 화면은 바뀌지 않음.
> **스위치 `notify.ses_feedback` 처음 off** — 꺼져 있으면 웹훅은 아무것도 하지 않음.

## 1. 흐름

| 단계 | 어디서 | 무엇이 남나 |
|---|---|---|
| 1 | SES 가 영구 반송(Permanent) · 수신 거부(Complaint)를 SNS 주제로 보냄 | — |
| 2 | SNS → `POST /api/v1/webhooks/ses`(로그인 없음) | 주제 · AWS 서명이 맞을 때만 · 받은 기록 `mail_feedback_events`(받는 주소 없이 수만 · 같은 알림 번호는 한 번) |
| 3 | 영구 반송 · 수신 거부 주소 | `mail_suppressions` 에 한 줄(있으면 횟수 +1 · 풀어 둔 것도 다시 막힘) · 일시 반송(Transient)은 막지 않음 |
| 4 | 알림 메일 발송(notify-mail) | 막힌 주소는 보내지 않고 `FAILED` · 까닭 `SUPPRESSED: 반송 · 수신 거부된 주소` |
| 5 | 운영 › 외부 연동 › 메일 › 「반송 · 수신 거부 주소」 | 받기 상태 · 막힌 주소(앞 2글자 · 도메인만) · 최근 7일 · **풀기 SUPER(사유 2 ~ 300자 · 감사 `MAIL_SUPPRESS_RELEASE`)** |

- 막는 대상은 **알림 메일만**. 인증번호 · 비밀번호 찾기처럼 회원이 지금 요청한 메일은 그대로 보냄(SES 억제 목록이 따로 막음).
- 기록은 지우지 못함(DB 트리거 `MAILSUP:`) — 풀기만.

## 2. 웹훅 검사 순서

| 순서 | 검사 | 틀리면 |
|---|---|---|
| 1 | 스위치 `notify.ses_feedback = on` | 200 `OFF`(아무것도 안 함 · 서명 검사도 안 함) |
| 2 | SNS 알림 형식(Type · MessageId) | 400 `SES_FEEDBACK_BAD_INPUT` |
| 3 | `TopicArn` = 사이트 설정 `notify.ses_topic_arn`(비어 있으면 받지 않음) | 403 `SES_FEEDBACK_TOPIC` |
| 4 | 인증서 주소 `https://sns.<지역>.amazonaws.com/….pem` · SNS 서명(SignatureVersion 1 = SHA1 · 2 = SHA256) | 401 `SES_FEEDBACK_BAD_SIGNATURE` |
| 5 | 구독 확인이면 `SubscribeURL`(sns.<지역>.amazonaws.com 만)을 한 번 엶 | 400 |

- SNS 는 본문을 `text/plain` 으로 보냄 → 이 주소에만 글 그대로 읽기를 붙임(`security-headers.ts` · 이름이 다른 함수로 감쌈 — 전체 API 본문 읽기에 영향 없음).

## 3. 켜는 순서(운영 메일을 켠 뒤 · 대표 · AWS 콘솔)

1. SNS 주제 만들기(서울 · 예 `sgb-ses-feedback`) → 구독 추가: 프로토콜 HTTPS · 주소 `https://sogaebank.com/api/v1/webhooks/ses` · **「원시 메시지 전달」 끔**.
2. SES › 확인된 ID(`mail.sogaebank.com`) › 알림 › 반송 · 수신 거부를 1의 주제로(「원래 머리글 포함」은 상관없음).
3. 운영 화면 사이트 설정 `notify.ses_topic_arn` = 1의 ARN → `notify.ses_feedback` = on.
4. SNS 콘솔에서 구독이 「확인됨」으로 바뀌는지 확인(앱이 구독 확인 주소를 엶) · 운영 화면 메일 › 「받기 켜짐 · SNS 주제 있음」.
5. SES 시뮬레이터 주소 `bounce@simulator.amazonses.com` 으로 시험 메일 → 몇 분 뒤 「막힌 주소 1」(시뮬레이터 주소).
- 비용: SNS HTTPS 알림은 월 10만 건 무료 범위 안(반송이 그만큼 나올 일은 없음) — **최신 요금은 AWS 요금표 확인 필요**.
