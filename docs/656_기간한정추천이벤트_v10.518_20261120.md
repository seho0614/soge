# 656. 기간 한정 추천 이벤트 (v10.518 · 2026-11-20)

## 1. 결론
정해진 기간 동안 **직접 추천 1단계 보상(REFERRAL_DIRECT · D189 · D190)의 점수만** 이벤트 점수로 바꿉니다. **예산(이벤트로 줄 점수 합) 상한**이 있고, 예산을 다 쓰거나 기간이 끝나면 **평소 점수**로 돌아갑니다(보상 규칙 표를 고치지 않으므로 「되돌리기」가 따로 없음 · 이미 준 보상은 그대로).
대표 11/20 결정 「추천대로 진행 — **관리자가 이벤트 시행 전 확인 후 등록**」: 운영자가 **시행 전 확인**(약관 확인 · 안내 문구 확인 · 확인한 곳 · 확인 날짜 · 메모)을 채우고, **둘 다 「예」가 아니면 DB 가 시작(ACTIVE)을 막습니다**. 시작 · 끝 · 스위치는 **SUPER** · 모두 감사 기록. 스위치 `prx.ref_event` 는 **처음 꺼짐**.
위치: 운영 **제휴 › 추천 이벤트**(SB-ADM-PRX-020) · API `/admin/prx/ref-events`.

## 2. 1단계만(다단계 아님) — 재확인
- 보상은 지금처럼 `fn_referral_reward` 한 곳에서만 나갑니다. D190 판을 **그대로** 다시 쓰고 **점수 고르는 몇 줄만** 더했습니다: 가입한 사람(invitee)을 **직접 추천한 한 사람(inviter)** 에게만 · 관계마다 한 번(rewarded_at) · 한 달 상한 · 가드 트리거(`fn_referral_reward_guard`) 모두 그대로.
- 이벤트는 「누구에게」를 바꾸지 않고 「몇 점」만 바꿉니다. 위 단계(추천인의 추천인)에게 주는 길은 없습니다(partner-affiliate 결정 · 시험 1518 이 확인).

## 4. 안내 문구 처음 틀(운영자가 고침)
```
[추천 이벤트] {from} ~ {until} 동안 내가 추천한 분이 처음 본인인증을 마치면 추천한 분께 {points}포인트를 드립니다(평소 {base}포인트).
· 내가 직접 추천한 분 한 분마다 한 번만 드립니다(추천받은 분이 다시 추천한 분은 해당하지 않습니다 — 1단계만).
· 지급 시점: 추천받은 분이 이벤트 기간 안에 처음 본인인증을 마친 때.
· 이벤트 예산 {budget}포인트가 모두 쓰이면 기간 전이라도 일찍 끝나며, 그 뒤에는 평소 포인트를 드립니다.
· 이미 받은 보상은 이벤트가 끝나도 그대로입니다. 한 달 받을 수 있는 횟수 제한은 평소와 같습니다.
```
회원에게 알리는 길은 ① 메인 팝업(v10.517)에 이 문구를 붙여 씀 — 회원 화면에 따로 이벤트 칸을 만들지 않음(다음 후보).

## 5. 예산
- 한 건을 줄 때 `쓴 점수 + 이벤트 점수 ≤ 예산` 이면 이벤트 점수 · 아니면 그 건은 평소 점수로 주고 이벤트를 **BUDGET** 으로 끝냄.
- 준 뒤 다음 한 건을 못 덮으면 바로 BUDGET 으로 끝냄(예산 6,000 · 점수 3,000 이면 두 건 뒤 끝).
- 이벤트로 준 건마다 `prx_ref_event_uses`(가입한 사람 한 명에 한 줄 · 쌓기만) · `used` 합.
- 정기 작업 `prx_hourly`(매시간): 기간 끝난 이벤트 ENDED(PERIOD) · 끝난 이벤트 운영 알림 `PRX_REF_EVENT_END`(INFO · 한 번).
