## 2. 내부 IP 를 세지 않는 까닭

1. 운영 Nginx 는 `X-Forwarded-For` 를 접속자 IP(`$remote_addr`)로 **덮어씀** → 손님 요청은 늘 공인 IP 로 보이고 위조할 수 없음(사용자 웹 서버 액션 · `/api` 프록시도 이 값을 넘김)
2. 설정이 어긋나 모든 요청이 내부 IP(127.0.0.1)로 보이더라도 **가입이 통째로 막히지 않고** 상한만 꺼짐
3. 개발 서버 점검(시험이 한 IP 에서 수백 명 가입)과 부딪히지 않음

## 3. 운영에서 쓰는 법 (적용 뒤)

1. 가입 급증 알림(SIGNUP_SPIKE)이 오면 → 운영 화면 첫 화면 **「가입 잠시 막기」** → 원인 확인 뒤 「가입 다시 받기」
2. 공개 동안 **「안내 띠 올리기」** 권장(간주 모드 안내) — 영어 문구는 사이트 설정 `site.notice_bar_en`
3. 「시험 결제 주문」이 보이면 → **「시험 결제 주문 정리」**(주문 받기 꺼짐이면 새로 생기지 않음)
4. 상한 값은 사이트 설정에서(0 이면 끔)
