> 계기: 대표 「검색기능 작동 하지않는다」(11/9). 개발 점검판(자료를 만들어 넣음)에서 모든 검색 길이 정상이었고, 운영 읽기 명령 결과 **매물 1 · 요청 0 · 소개광장 글 2** · 웹 경유 200 · 「태스트」 → 1건 — **고장이 아니라 운영에 찾을 자료가 없어 0건**(인계 메모 62절).
