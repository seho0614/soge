# 660. 파트너 직원 일괄 등록 CSV (v10.522 · 2026-11-20)

## 1. 결론
파트너사 직원 계정을 **CSV 한 장으로 한꺼번에** 등록합니다. 받는 칸은 **email · can_settle 둘뿐**(개인정보 최소), 흐름은 **미리보기 → 확정**입니다. 이미 가입한 회원은 기존 「직원 초대」와 똑같이 초대(받아들이면 합류)하고, 아직 가입하지 않은 사람은 **가입 대기**로 두었다가 같은 이메일로 가입하면 15분 안에 초대로 바꿉니다. **계정을 대신 만들지 않습니다**(약관 동의 · 본인 가입이 먼저). 초대 메일은 **처음 꺼짐**(`pbulk.invite_mail` off). 위치: **파트너사 › 직원 일괄 등록** · SB-ADM-OAPI-020.

## 2. 줄마다 결과
| 결과 | 뜻 | 확정 뒤 |
|---|---|---|
| MEMBER | 가입한 회원 · 다른 사업자 소속 아님 | INVITED — business_members(STAFF · can_settle) |
| PENDING | 가입한 회원이 없음 | PENDING — 원문 이메일 보관(`pbulk.pending_days` 30일) → 가입하면 MATCHED · 기한 지나면 EXPIRED(이메일 지움) |
| DUPLICATE · INVALID · ALREADY · OTHER_BUSINESS · SELF | 파일 안 중복 · 모양 아님 · 이미 직원 · 다른 사업자 · 대표 계정 | SKIPPED |

- 미리보기는 하루 안에 확정 — 지나면 `pbulk_match` 가 취소하고 이메일을 지움.
- 원문 이메일은 **가입 대기 동안만**(DB CHECK `ck_pbulk_row_email_kept`) · 지문(sha256) · 가린 값은 남음.
- 줄 상태는 앞으로만 · 지우지 않음(`trg_pbulk_row_guard`).
- **감사 기록**: 미리보기 `PBULK_PREVIEW` · 확정 때 줄마다 `PBULK_ROW` · 짝 맞춤 `PBULK_MATCH` · 취소 `PBULK_CANCEL`(이메일은 가린 값만).

## 3. CSV
```
email,can_settle
kim@example.com,N
lee@example.com,Y
```
UTF-8 · 쉼표 또는 탭 · 200KB · `pbulk.max_rows`(200)줄. 머리줄이 없으면 첫 칸 = email. 다른 칸이 있으면 422 `PBULK_COLUMNS`.

## 5. 처리방침 고칠 곳 (법무 확인 필요)
| 자리 | 고칠 내용 |
|---|---|
| 수집 항목 | 파트너사가 알려 준 **비회원 이메일**(가입 초대 목적 · 가입 대기 30일 뒤 또는 가입 · 취소 즉시 파기) 한 줄 신설 |
| 수집 경로 | 「제휴 파트너사가 직원 초대를 위해 제공」 — 파트너사가 직원 동의를 받았는지 확인할 책임을 파트너 약관에 둘지 **법무 확인** |
| 초대 메일 | 광고성 정보가 아닌 거래 · 초대 안내로 볼 수 있는지(정보통신망법 제50조) — **법무 확인 뒤** `pbulk.invite_mail` on |

## 6. 개인정보 최소 · 판단
- 이름 · 휴대폰 · 주민번호 칸은 받지 않음 — 가입 때 본인이 넣음.
- 정산 권한(can_settle)은 대표 직원 초대와 같은 칸(대표가 나중에 바꿀 수 있음).
- 운영 화면에서만(규칙 25) — 파트너센터에서 대표가 직접 올리는 화면은 다음 후보.
