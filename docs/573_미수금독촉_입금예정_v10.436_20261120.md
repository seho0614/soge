# 573. 미수금 독촉 · 입금 예정 (v10.436 · 2026-11-20)

## 1. 결론
거래처별 **받을 돈**과 **독촉 단계**(1 안내 → 2 독촉 → 3 최종)를 보고, 단계별 메일을 미리 보고 보냅니다. 거래처가 약속한 **입금 예정**은 자금 흐름 예정에 들어갑니다. 위치: **회계 › 미수금 독촉**(자금 묶음) · SB-ADM-ACC-410.

| 항목 | 내용 |
|---|---|
| 받을 돈 | ⑭ 기간 분석(외상매출금 AR · 먼저 생긴 몫부터 갚음) 그대로 |
| 단계 | 가장 오래된 남은 몫 날수 ≥ 단계 날수(처음 30 · 60 · 90 · SUPER 가 고침 · 1 < 2 < 3) |
| 메일 | acct_dunning_templates(제목 · 본문 · 글자 {party} {amount} {oldest} {days} {company} {phone}) · 받는 주소 = 거래처 대장 contact_email(이름이 전표 거래처와 같아야) |
| 보내기 | 기존 메일 길(메일 준비된 때만) · 지금 보내기 SUPER · 자동은 acct.dunning on 일 때만(**처음 꺼짐**) · 매일 09:35 · 같은 거래처 · 같은 오래된 날 · 같은 단계 한 번 |
| 기록 | acct_dunning_sends(쌓기만 · 주소는 가림 · SENT · FAILED · NO_EMAIL · NOT_READY) |
| 입금 예정 | acct_receipt_promises → acct_cash_plans(IN · 「입금 예정 · 거래처」) · 지킴 · 어김 · 취소 → 자금 흐름 예정 취소 · 예정일 3일 지나면 자동 「어김」 |
| 연체 이자 | 셈하지 않음 |

## 2. 주의
1. 자동 독촉을 켜기 전에 거래처 대장 메일 주소와 문안을 확인하십시오(정책 › 전체 설정 acct.dunning).
2. 받을 돈은 전표 거래처 이름으로 모읍니다 — 같은 거래처를 다른 이름으로 적으면 따로 셉니다.
