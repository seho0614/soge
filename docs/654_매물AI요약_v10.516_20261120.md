# 654. 매물 AI 3줄 요약 (v10.516 · 2026-11-20)

## 1. 결론
새로 게시된 매물을 **기존 AI 어댑터**로 3줄 요약해 **초안**으로 두고, **운영자가 읽고 고쳐 승인한 것만** 매물 상세에 「AI 요약 · 운영자 확인」으로 보입니다. AI 통로 `LSX_SUMMARY`(AI 전체 스위치 · **월 상한** · 스위치 `lsx.ai_summary` **처음 꺼짐**). AI 는 공개를 정하지 않습니다(ai-agent #7).

## 2. 흐름
| 단계 | 내용 |
|---|---|
| 만들기 | `lsx_hourly`(매시간) — 운영자가 「다시 만들기」한 것 먼저, 다음 최근 14일 게시 매물 중 그 판(version) 요약이 없는 것 · `lsx.ai_summary_batch`(10)건 · 40초 예산 · `fn_agent_allowed('LSX_SUMMARY')` · 요금표 모델만(`lsx.ai_summary_model` · 비우면 `agent.review_model`) |
| 보내는 글 | 제목 · 본문(`fn_listing_text`) · 업종 · 시 · 구 — 연락처 · 링크는 표시로(`redactContacts`) · 등록자 이름 · 전화 · 사업자번호 안 보냄 · 글은 자료로만(지시 따르지 않음) |
| 지시 | 사실만 · **추천 · 순위 · 칭찬 말 금지**(INV-11) · 정확히 3줄 JSON |
| 검수 | 검수 › 매물 AI 요약(SB-ADM-LSX-030) — 매물 글 앞부분과 나란히 · 3줄 고쳐 승인 · 반려(사유) · 다시 만들기 |
| 공개 | `GET /site/lsx/listings/{id}/summary` — 승인 · 매물 게시 중 · **매물 판이 같을 때만** · 스위치 켬 · 매물을 고치면 판이 달라져 저절로 내려감 |

- 같은 매물 · 판은 한 번만(부분 유일 색인 `uq_lsx_ai_live`) · 부르기 전에 자리를 잡음(PENDING · 10분 넘으면 다시 줄) · 답 전 일시 오류는 다시 · 답 뒤 오류는 FAILED(다시 부르지 않음 · 비용).
- 시험 엔진(MOCK)은 밖으로 나가지 않고 같은 글(`[시험 요약] 제목 · 업종 · 지역`)을 만듦.

## 3. 표 · API
| 종류 | 이름 |
|---|---|
| 표 | `lsx_ai_summaries`(QUEUED · PENDING · DRAFT · APPROVED · REJECTED · STALE · FAILED) · `fn_agent_allowed` 에 통로 한 줄 · `agent_usage_daily` 통로 CHECK 9개 |
| 설정 | `lsx.ai_summary`(off) · `lsx.ai_summary_model`('') · `lsx.ai_summary_batch`(10) |
| API | `GET /admin/lsx/summaries` · `POST /admin/lsx/summaries/{id}/decide` · `POST /admin/lsx/summaries/request` · `GET /site/lsx/listings/{id}/summary` |

## 4. 처리방침 고칠 곳(규칙 29 · 법무 확인 표시)
- 매물 글(연락처 가린 것)을 AI 처리 위탁사(Anthropic · 기존 AI 상담 · 검수 보조와 같은 곳)로 보냄 — 처리방침 「AI 처리 위탁」 항목의 목적에 「매물 요약」 한 줄 더함 · **법무 확인 필요**(켜기 전).
- 회원 이용약관 · 화면 고지: 「AI 요약은 운영자가 확인했으나 정확한 내용은 본문 기준」.
