# 227. 외부 연동 신청 묶음 2판 (2026-10-29 · v10.147 기준)

> 대표 「다음」 → 추천 2 「외부 연동 신청 묶음」 → 「1 2 3 진행」(10/29).
> **docs/111(v10.56 · 10/22)을 이 문서가 대신합니다** — 그 뒤 v10.128 ~ v10.145 에서 키를 **운영 화면에서 넣게** 됐고(D128), 본인인증 · 알림톡 · 전자계약 · 결제 · 계좌 · 안심번호 **틀이 생겼습니다**. 업종 정정 · 간주 모드 끄기 설명(docs/111 4-1 · 6절)은 그대로 씁니다.
> 성격: **문서만**. 비용 · 기간 · 서류는 업체마다 다르고 바뀔 수 있어 「**업체 확인 필요**」로 적었습니다(웹 검색 안 함).

## 1. 결론

1. **업종 정정이 먼저**입니다 — 새 사업자등록증이 모든 신청서의 첨부입니다(docs/111 4-1).
2. 새 등록증이 나오면 **같은 주에 6곳을 한꺼번에** 신청합니다. 가장 오래 걸리는 것은 알림톡(약 8주) · 본인인증(약 6주)이라 **오픈일은 이 두 개로 정해집니다**.
3. 신청서에 적을 값(2절)은 아래 표를 그대로 옮기면 됩니다. **키를 받으면 운영 화면 › 외부 연동 › 연동 키**에 넣고(값은 채팅 · 메일에 붙이지 않음), Claude 에게는 「무엇을 넣었는지 이름만」 알려 주십시오.

| 단계 | 하는 사람 | 할 일 | 확인 |

| 2 | 대표 | Claude 에게 **이름 · 업체 개발 문서**만 넘김(아래 틀) | — |
| 3 | Claude | 업체 문서로 요청 · 응답 형식을 맞춤(틀은 공개 자료 기준 공통 모양) → realcheck → 풀 리퀘스트 → 운영 적용 | 시험 통과 |

```text

- 운영 화면에 넣은 키 이름: NICE_CLIENT_ID, NICE_CLIENT_SECRET, NICE_PRODUCT_ID
- 운영 .env 에 넣은 주소 이름: NICE_API_BASE, NICE_WINDOW_URL

- 발신 IP 승인일: 2026-__-__ · 시험 계정 있음: 예 / 아니오
```
