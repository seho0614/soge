# 709. 내 사원 카드(본인) (v10.567 · 2026-11-21)

> 대표 11/21 승인. 사무 › 「내 인사」(my-hr) 맨 위에 접는 칸 「내 카드」. 관리자용 사원 카드(docs/698 · v10.559)의 본인 판입니다. 마이그레이션 · 권한 시드 없음.

## 1. 결론

- 운영 계정에 연결된 직원(`acct_employees.account_id` = 로그인 계정 · 재직 중)이 **자기 인사 정보를 한 장에 읽기만** 합니다.
- 새 API `GET /api/v1/admin/me/hr/card` 하나 — **직원 번호를 받지 않음**(늘 나 자신 · 남의 카드를 볼 길이 없음).
- 연결이 없으면 404 가 아니라 **200 + `{ linked: false }`** → 화면은 「연결된 직원이 없습니다」.
- 보는 역할은 다른 내 인사 API 와 같음(`SELF` = 운영 · 검수 · 지급 · 안심 파트너 · 제휴 파트너 담당 + SUPER). **세무사(ACCOUNTANT)는 403**.
- 열람 사유를 묻지 않고 감사 · 개인정보 접속기록도 남기지 않습니다(본인 것 · 베끼는 개인정보 없음).

## 2. 칸 — 관리자 판과 다른 점

| 칸 | 관리자 판(v10.559) | 내 카드(v10.567) |
|---|---|---|
| ① 기본 | 이름 · 입사 · 퇴사 · 재직일 · 연결 계정(가린 메일 · 역할) · **관리자 메모** | 이름 · 입사 · 재직일 · 부양가족 · 내 운영 역할 — **관리자 메모 없음** · 메일 없음 |
| ② 근태 · 휴가 | 이번 달 집계 · 연차(제안 일수 포함) · 최근 휴가 5 | 이번 달 집계 + 오늘 출퇴근 · 연차 생김 · 씀 · 남음 · 최근 휴가 5(내 것) — 제안 일수 없음 |
| ③ 급여 | 월 기본급 · 비과세 · 부양가족 · 최근 6개월 금액 줄 · **퇴직금 추계** | **내 급여명세서 목록**(확정 · 지급만 · 12개 · `lineId` · 금액 없음) → 「보기 · 인쇄」는 기존 `GET /admin/me/hr/payslips/{lineId}` · **퇴직금 추계 없음** |
| ④ 계약 · 교육 · 평가 | 계약서 최근 5(초안 포함) · 의무교육 · 평가 최근 4(진행 중 포함) | 내가 **받은** 계약서(보냄 · 서명함)만 · 의무교육 · 평가는 **닫힌 차례의 내 결과만**(등급 · 상사 평균 · 내 평균 · 목표 수) — 상사 의견 · 목표별 평가자 메모 · 자기 의견 없음 |
| ⑤ 근무 | 연장 근로 이번 주 · 달 · 최근 5 · 이번 주 근무표 | 같음(내 직원 번호만) |
| 열람 | 열람 사유(PiiReasonGate) · 감사 HR_CARD_VIEW · 접속기록 | 사유 없음 · 감사 없음 |
| 「자세히」 | 그 관리자 탭으로(볼 수 있는 역할만) | **같은 화면(내 인사) 안의 그 칸으로 내려감** — 관리자 탭으로 가지 않음 (`links` 값은 모두 `my-hr`) |

- 셈은 새로 만들지 않았습니다 — `hr.myHr`(근태 · 연차 · 휴가 · 명세서 목록) · `hr-contract.myContracts` · `hr-training.myTraining` · `hr-review.myReviews` · `hrx-overtime.otRules` · `hrx-shifts.shiftWeek`(내 줄만 고름)를 부릅니다.
- 평가는 `myReviews`(최근 4 차례)에서 닫힌 것만 고르므로, 최근 4 차례 밖의 오래된 닫힌 평가는 보이지 않습니다(아래 「평가」 칸과 같은 범위).
- 칸 하나가 실패해도 나머지는 보이고 `errors` 에 칸 이름이 들어갑니다.

## 4. 화면

- 사무 › 내 인사 맨 위 `<details>` 「내 카드」 — **펼칠 때 한 번** API 를 부름(내 인사 첫 화면이 무거워지지 않게).
- 칸 그리는 부품은 관리자 사원 카드(`HrCard.tsx`)의 `Sec` · 이름표(`ST_LV` · `HALF` · `ST_CT` · `ST_RV` · `DAY_KIND` · `hm`)를 그대로 가져다 씀 — 두 카드의 칸 모양이 같음.
- 명세서 「보기 · 인쇄」는 내 인사의 기존 인쇄 창(`Hr.tsx` 의 `printSlip`)을 그대로 씀.
- 「자세히」 단추: 출퇴근(`data-my-hr-today`) · 휴가 신청(`data-my-leave`) · 교육 제출(`data-my-training`) · 계약서(`data-my-contracts`) · 목표 · 자기 평가(`data-my-reviews`) · 연장 근로(`data-my-hrx`) · 근무표(`data-my-shifts`) 칸으로 내려감.
- 화면 목록 `SB-ADM-HRS-050`(사무 내 인사 — 내 카드 · `/admin/my-hr/card` · nav `SB-ADM-HRM-050`).

## 5. 권한 · 감사

- 업무 권한(D258) 주소 맵에 넣지 않음 — D259 · D262 · D265 와 같이 **본인 것만 보는 주소는 `@Roles` 만**(perm.guard 「맵에 없는 주소는 @Roles 만」). 마이그레이션 없음.
- 주소가 `/admin/me/hr` 아래라 세무사의 회계 읽기(`/admin/acct` GET)에도 걸리지 않습니다.
- 감사(@Audit) 없음 — 본인이 자기 정보를 보는 것이고 감사 기록에 급여 · 평가를 베끼지 않으려는 것(대표 지시 「감사는 남기지 않거나 idOnly」 중 앞쪽).
