# 98. 소개광장 › 우리동네 맛집 (v10.47 · 2026-10-17)

> 대표 결정 2026-10-17(「추천대로」 · sgb-docs decisions/community-sogae-gwangjang #12 · #13 · map-kakao #11):
> 자료는 **회원 소개 글 + 운영 동네픽** · 카카오 장소는 **이름 · 주소 · 좌표 · ID 만** 저장(자세한 정보는 「카카오맵에서 보기」) · 식당은 영업장이라 **정확한 핀** ·
> 동네는 **직접 고름** · 「현재 위치로」는 브라우저 안에서만 · **관리자 설정으로 처음 꺼 둠** · 서버로 위치를 보내는 「내 주변」은 위치기반서비스사업 신고 뒤.
> 바탕: v10.46 카카오맵(docs/96 · 97). **원칙: 기존 기능에 영향 없음** — 지도 사용(`map.enabled`)이 꺼져 있으면(처음 값) 소개광장은 v10.46 과 같습니다.

## 3. API

| 방법 · 주소 | 권한 | 하는 일 |
|---|---|---|
| `GET /community/food` | 누구나 | `{ enabled, geolocation, regions[] }` — off 면 `enabled:false` |
| `GET /community/food/places?swLat&swLng&neLat&neLng&q` | 누구나 | 지도 범위 안 가게(최대 200 · `truncated`) — 이용자 위치는 받지 않음 |
| `GET /community/food/places/{id}` | 누구나 | 가게 · 소개 글(공개 + 내 검수 중) · 작성자 첫 글자만 |
| `GET /me/community/food/search?q&lat&lng` | 로그인 | 카카오 키워드(서버가 대신) · 음식점 FD6 · 카페 CE7 만 · 1분 30회 · 결과를 10분 기억 |
| `POST /me/community/food` | 로그인 | `{ kakaoPlaceId, title, body, menu?, sponsored }` — 가게(없으면 기억해 둔 찾기 결과로 만듦) + 글(posts FOOD) · 감사 `FOOD_POST_CREATE` |
| `GET /admin/community/food/places?q` | ADMIN · SUPER | 가게 목록(숨긴 것 포함) · 공개 · 검수 중 글 수 |
| `PATCH /admin/community/food/places/{id}` | ADMIN · SUPER | `{ hidden, reason }` — 감사 `FOOD_PLACE_HIDE` |

오류: `MAP_DISABLED`(지도 off) · `QUERY_TOO_SHORT` · `QUERY_TOO_LONG` · `SEARCH_RATE` · `PLACE_SEARCH_FAILED` · `PLACE_NOT_PICKED`(찾은 결과에 없는 가게 · 10분 지남) · `PLACE_HIDDEN` · `HIDE_REASON` · 소개광장 글 규칙 `POST:`(링크 · 하루 5개 · 같은 글) · `POST_FOOD_BOARD` · `TOWN_FOOD_POST`.

## 6. 보안 · 법률

| 항목 | 처리 |
|---|---|
| 이용자 위치 | 서버로 받지 않음 — 지도 네 모서리만. 「현재 위치로」는 브라우저가 지도만 옮김 · 설정 처음 off(위치정보법 확인 뒤 켬) |

| 나쁜 글 · 가게 | 글은 소개광장 신고 · 검수 그대로 · 가게는 운영이 숨김(사유 필수 · 감사) |
| 쿼터 | 가게 찾기만 카카오 로컬을 부름(1분 30회 · 한 사람) · 지도 · 목록은 우리 DB |

## 9. 위치기반 약관 폐기 — 다시 판단 (D101 · 2026-10-19)

realcheck(2026-10-19)에서 검정 **BR-05 · BZ-03 「좌표 컬럼 없음」**이 「기대 0 / 실제 8」로 걸렸습니다. 2026-09-18 위치기반 약관 폐기(`legal.location_waived`)의 근거가 「좌표 컬럼 0개」였기 때문입니다. 운영 점검 `open-check.sh` 도 같은 검사를 합니다.

| 항목 | 내용 |
|---|---|
| 대표 결정 | 2026-10-19 **A안 — 폐기 유지** · 판단을 거친 좌표 칸만 목록에 올리고 검사에서 뺌 (sgb-docs decisions/map-kakao #12) |
| 근거 | 이용자 단말기 위치는 받지도 저장하지도 않음 · 저장하는 좌표는 움직이지 않는 장소의 주소를 바꾼 값(매물 · 시군구 중심 · 가게)뿐 · 「내 주변」은 신고 뒤(#10) |
| D101 | `location_column_allow`(표 · 칸 · 사유 · 결정일) 8줄 — `listing_geo` · `geo_region` · `town_places` · `v_town_places` 의 lat · lng / 검정 보기 `v_location_columns` · `v_location_waiver_broken` 은 목록만 빼고 조건 그대로 / `legal.location_waived_note` 문구 고침 |
| 경보는 살아 있음 | 목록에 없는 좌표 칸이 새로 생기면 BR-05 · BZ-03 · open-check 가 지금처럼 잡음 — 불변식 LOC-1(목록 8개) · LOC-2(목록에서 빼면 다시 잡힘) |
| ★ 확인 필요 | 법률 확인 — 결과가 다르면 `legal.location_waived` 를 off 로 하고 위치기반 약관 · 신고 절차 |
