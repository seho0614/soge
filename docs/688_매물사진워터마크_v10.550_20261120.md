# 688. 매물 사진 워터마크 (v10.550 · 2026-11-21)

## 1. 결론
사용자 웹 **매물 상세 사진 위에 「SogaeBank/소개뱅크」 글자를 겹쳐** 보입니다. **원본 사진 바이트는 그대로** — 새 npm 금지이고 지금 코드에 그림 처리 도구(sharp · jimp · canvas)가 없어서(b279 D279 지각 해시도 같은 까닭으로 안 함) **서버는 표시 정보만**(켜짐 · 글자 · 자리 · 진하기) 돌려주고 화면이 CSS 로 겹칩니다. 처음에는 꺼져 있습니다(`lpx.watermark` off). 위치: 운영 **검수 › 매물 사진 워터마크**(SB-ADM-LPX-020 · 탭 `lpx-photo` · 미리보기).

| 설정 | 값 | 처음 |
|---|---|---|
| `lpx.watermark` | on · off | off |
| `lpx.watermark_pos` | BR · BL · TR · TL · C · TILE(여러 번) | BR |
| `lpx.watermark_opacity` | 10 ~ 60 | 35 |

- 글자는 고정(대표 지시) — 설정으로 바꾸지 않음(`LPX_MARK_TEXT`).
- 공개 `GET /site/lpx/listings/{id}` 의 `watermark` 칸 · 사진이 없는 매물(분류 그림)은 겹치지 않음.
- 글자는 누르기를 막지 않음(pointer-events none) · 화면 읽기는 건너뜀(aria-hidden) · 토큰 색만(어두운 테마 따라감).
