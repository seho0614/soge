- 공지 첨부는 **공지를 볼 수 있는 사람만** 엽니다(목록과 같은 기준 · 아니면 없는 것과 같이 404). 운영(관리자 · 최고 관리자)은 미리 보기로 모두.
- 공지에 붙은 파일은 지울 수 없습니다(DB) · **게시한 수수료율 변경 공지는 첨부도 고칠 수 없음**(입점 약관 제17조 4항 공지 기록 · D211 잠금에 첨부를 더함).
- 요율 알림 발송은 지금처럼 정기 작업 `notify_dispatch`(1분)가 합니다 — 이번 판은 **어느 판매자에게 메일 · 문자가 실제로 나갔는지 세어 보여 주기만** 합니다. 채널이 「준비 안 됨」이면 대기열에 넣는 순간 실패로 남고(사흘 지나면 다시 보내지 않음), 판매자는 「내 알림」 · 판매자센터 공지 · 30일 전 공지로 알게 됩니다.

| API | 권한 | 내용 |

## 3. DB (D217)

1. 파일 용도 `NOTICE_ATTACHMENT`(`ck_files_purpose` 합집합 다시 만듦 · `file_policies` JPG · PNG · PDF 10MB)
2. `notices.attachments uuid[]`(기본 빈 목록 · 3개까지) · `trg_files_notice_guard`(붙은 파일 지우기 막음) · `fn_notice_lock_guard`(첨부도 잠금)
3. `translation_jobs` 대상에 `NOTICE` · `trg_notice_translation_enqueue`(D118 `fn_translation_enqueue` 그대로 · 스위치 꺼져 있으면 넣지 않음)
4. `hlt_rate_notifications`(알림 id · 예약 · 종류 SCHEDULE · CANCEL · REMIND · 알림을 지우면 같이 지워짐) — 예약 · 취소 · 다시 알림 때 앱이 쌓음

지우는 문장 없음 · 재실행 안전(점검용 빈 DB 에서 두 번 적용 확인).

## 5. 운영 적용

- **마이그레이션 1개(D217 · 254 → 255) — 스냅샷 필요**(apply 가 물으면 이름 적기).
- 적용 뒤 확인:
  1. 노출 › 메인 운영 › 콘텐츠 › 「공지 등록」에 「첨부」 줄 · 시험 공지(초안)에 그림 하나 붙여 「열기」로 열리는지 → 초안은 지우지 말고 그대로 두거나 「내리기」
  2. 소개몰 › 소개몰 정산 › 「요율 변경 예정」에 예약이 있으면 「알린 판매자」 칸 「발송 현황」(지금은 메일 · 문자 「준비 안 됨」이 정상 — 메일 설정 · 알림톡을 켜기 전)
  3. 자동 번역 스위치는 꺼진 채 — 켤 때는 관 관리 › 번역 › 「자동 번역」 탭 「노출 중인 글 한꺼번에 넣기」로 지금 공지도 넣음(월 상한 안에서 비용)
- 적용 전 예약된 요율 알림은 묶음 기록이 없어 「발송 현황」이 나오지 않습니다(새 예약 · 취소 · 다시 알림부터).
