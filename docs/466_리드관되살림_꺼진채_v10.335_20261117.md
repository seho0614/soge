# 466. 리드관(소개리드) 되살림 — 꺼진 채 (v10.335 · 2026-11-17)

> 대표 11/17 「남은 개발후보 모두 개발」 → 「리드관 다시 열기」 → 「B. 별도 관으로 되살림」 → 「개발 + 꺼진 채로」. **10/1 폐지 결정(D005 · 결정 기록 gwan-structure-naming #4 · #14)을 뒤집습니다.** 마이그레이션 **D227**(264 → 265 · 스냅샷 필요). 법무 재확인 질의서는 docs/467.

## 1. 왜 · 어떻게

- 리드관은 9월 보류(docs/24 D9 — 개인정보 · 보험 · 의료 부담) → **10/1 폐지**, 리드 업종 8종은 안심소개 「생활 · 금융 상담」 축(CSL_*)으로 옮겨졌습니다(D005).
- 리드 엔진(상담 신청 · 휴대폰 확인 · 배정 · 전달 · 반려 72시간 · 소개캐시 선불 · 환불 · 세금계산서 · 파트너센터 리드 화면 · 운영 화면 파트너사 › 리드 · 반려 · 지갑 · 리드 배정)은 그 축에서 **지금도 돕니다.**
- 그래서 엔진과 업종 자료는 **옮기지 않고**, 리드관은 그 업종을 자기 관 화면으로 보여 주는 관으로 되살립니다. 업종을 다른 관으로 옮기면 상담 신청 게이트(D005 4절) · 자격 심사 · 지난 리드 기록이 함께 흔들리기 때문입니다.
- 관은 **꺼진 채**로 둡니다. 법무 재확인 회신(docs/467) 뒤 최고 관리자가 켭니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D227** | 설정 `lead.legal_ok`(법무 재확인 회신 · 처음 off · on · off) · 관 `LED` 이름 「소개리드」 · 설명을 「폐지」에서 되살림 설명으로(**꺼진 채 그대로**) · 트리거 `trg_lead_gwan_guard` — `lead.legal_ok` 가 on 이 아니면 LED 를 켤 수 없음(422 `INVALID_SETTING`). 지우는 문장 없음 |
| 운영 API(설정 바꾸기) | `lead.legal_ok` 는 **최고 관리자(SUPER)만**(403 `LEAD_SETTING_SUPER`) |
| 사용자 웹 **새 화면 `/lead`**(SB-LED-MAIN-010) | 리드관 메인 — 제목 「소개리드」 · 안내 · 제3자 제공 안내 띠 · 업종 목록(받을 인증 업체 수 · 상담 신청 — 안심소개 상담 화면 `/mal/consult/{code}` 그대로) · 입점 신청 줄. **관이 꺼져 있으면 404** |
| 사용자 웹 머리줄 | 관 주소표에 LED → `/lead`. 켠 관만 메뉴에 나오므로 **꺼진 동안은 아무것도 바뀌지 않음** |
| 사용자 웹 **안심소개** | 리드관을 켜면 「생활 · 금융 상담」 축 탭을 숨기고, 옛 주소 `/mall?axis=consult` 는 `/lead` 로 보냄(같은 업종을 두 곳에 두지 않음) |
| `spec/screens.json` | 이연(deferred)에서 「리드관 보류」 9개(SB-ADM-PTN-010 ~ 080 · SB-PTC-DSH-010)를 뺌(14 → 5) — 화면 본문에 이미 있고 운영 화면 파트너사 탭으로 구현돼 있음 · 새 화면 SB-LED-MAIN-010 |

- 꺼진 동안 사용자 웹 · 운영 화면 · 리드 흐름은 하나도 바뀌지 않습니다(`/lead` 만 404).
- 영어 화면 머리줄의 리드관 이름은 서버 이름(「소개리드」)이 그대로 나옵니다 — 켜기 전에 영어 이름을 정하면 사전에 넣습니다.

## 3. 켜는 순서 (법무 회신 뒤 · 최고 관리자)

> 11/17 대표 「리드관 법무 확인끝」 · 「모두 문제없음」 — 운영 적용 직후 아래 순서로 켭니다.

1. 법무 회신을 받습니다(docs/467 Q1 ~ Q5). 「고쳐야 함」이 있으면 Claude 에게 먼저 알려 주십시오.
2. 운영 화면 **정책 › 「전체 설정」** › `lead.legal_ok` → `on`(사유: 법무 회신 날짜).
3. 운영 화면 **노출 › 「메인 운영」 › 「관 노출」** › 소개리드 → 노출(켜기).
4. 사용자 웹 머리줄에 「소개리드」가 생기고 `/lead` 가 열리는지, 안심소개에서 「생활 · 금융 상담」 탭이 빠졌는지 봅니다.
- 되돌리기: 같은 곳에서 소개리드 노출을 끄면 안심소개 상담 탭이 다시 나옵니다(자료 그대로).

## 5. 운영 적용

- 마이그레이션 D227 하나(264 → 265) — **RDS 스냅샷을 만듭니다.** 설정 하나(`lead.legal_ok` off)를 더합니다.
- 적용해도 리드관은 꺼진 채라 화면이 바뀌지 않습니다.
- 되돌리기(rollback): 프로그램만 앞 판으로 돌아가도 설정 · 트리거는 남습니다. 앞 판은 그 설정을 읽지 않고, 트리거는 LED 켜기만 막으므로 지장이 없습니다.
