# 740. 첫 거래 안내 체크리스트 (v10.598 · 2026-11-21 · 16차 회원 · 성장 ⑭)

## 1. 결론
새 회원의 **나의공간 첫 화면**에 「첫 거래 안내」 카드(8단계)를 보여 줍니다. **새로 모으는 정보는 없고**, 본인의 이미 있는 기록으로 끝났는지만 셉니다. 표시만 하는 기능이라 스위치 `grw.first_steps` 는 처음 **on**(NOTES.md 이유) · 가입 뒤 `grw.first_steps_days`(60)일까지 · 「그만 보기」 가능.

## 2. 단계와 재사용한 기록
| 단계 | 끝남 판단(이미 있는 기록) | 바로 가기 |
|---|---|---|
| 본인인증 | accounts.identity_verified_at | /verify |
| 관심 성향 | member_ad_profiles(성향 저장 · 동의한 분만) | /ai/profile |
| 관심 담기 | favorites | / |
| 첫 문의 | conversations.initiator_id | / |
| 매물 · 요청 등록 | listings · requests(owner) | /register |
| 첫 거래 | deals(사는 쪽 · 파는 쪽 · 소개자 · 취소 아님) | /my/deals |
| 알림 설정 | notification_preferences 한 줄 이상 또는 하루 요약 설정(v10.599) | /my/notifications#prefs |
| 추천 코드 나눔 | introducer_referrals.inviter_id(D189) | /my/recommend |
- 기존 「지금 막혀 있는 단계」 안내(본인인증 → 구독)는 그대로 — 카드는 그 아래 · 내 추천 코드 위.

## 3. 보여 주는 때 · 기록
- 서버가 `show` 와 까닭(OFF · HIDDEN · OLD · DONE)을 돌려줌 · show=false 면 사용자 웹이 그리지 않음.
- `grw_first_steps`(한 사람 한 줄) — 그만 보기(hidden_at) · 다 끝낸 때(all_done_at · 한 번만 · 운영 통계).

## 4. 운영 (SB-ADM-GRW-030)
최근 30 · 60 · 90일 가입자(운영 · 직원 빼고 · 탈퇴 빼고) 중 단계마다 끝낸 수 · 비율 · 다 끝냄 · 그만 보기 — 숫자만.
