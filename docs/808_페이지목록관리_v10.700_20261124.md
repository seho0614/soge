# 808. 페이지 목록 관리 (v10.700 · 2026-11-24)

> 대표 11/24 「페이지목록 관리」 → 「한 화면에 모두(권장)」.

## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 운영 화면 › 관 관리 › **페이지 목록**(새 탭 · ADMIN · SUPER) | 위 표 — 메인 · 소개장터 · 안심소개 · 소개창업 · 소개리드 · 소개몰 메인: 주소 · 상태(처음 배치 · 게시 n판) · 게시 안 한 초안 · 마지막 초안(누가 · 언제) · 예약 · 「편집」 · 「보기 ↗」 |
| 같은 탭 아래 표 | 관 안 페이지 · 새 관 첫 화면: 관 · 페이지 · 상태 · 공개 범위 · 7일 방문 · 마지막 초안 · 예약 · 「관 관리로」 · 「보기 ↗」(편집은 관 관리 › 관 관리 › 관 하나 › 「관 페이지」 그대로) |
| 편집 화면 | 글자 · (메인) hero 안내 장 · 구역(보이기 · ↑ ↓ · 자리마다 블록) · (소개몰) 상품 고르기 · 초안 저장 · 게시(SUPER) · 처음 배치로 초안 · 예약 게시(SUPER) · 미리보기 링크 · 게시 판 기록(이 판으로 초안 · 바로 되돌리기 SUPER) · 저장 안 한 고침 경고 |
| 「?」 도움말 | ADMIN_GUIDE 새 판에 「페이지 목록 [site-pages]」 절 · 탭 → 절 잇기(D321) |

## 2. API

- `GET /admin/site-pages` — 꾸밀 페이지 6과 관 안 페이지(새 관 첫 화면 포함 · 7일 방문)를 한 번에.

## 4. 운영 적용(v10.696 ~ 700 함께)

- 마이그레이션 D321 하나 — RDS 스냅샷.
- 적용 뒤 확인(보기만): 관 관리 › 페이지 목록 — 위 표 6줄 「처음 배치」 · 아래 표 관 안 페이지 · 「?」 를 누르면 「페이지 목록」 절.
- **게시 전에는 사용자 웹이 바뀌지 않습니다.**
