# 690. 지역별 시세 통계 (v10.552 · 2026-11-21)

## 1. 결론
**관 × 업종(상위 분류) × 시 · 도 × 시 · 구 × 달**마다 게시 매물의 **거래(희망) 금액 가운데값**(과 가운데 절반 범위)을 매일 모아, 공개 화면 **지역별 시세**(SB-HOM-LPX-010 · `/price-stats`)와 공개 API(`GET /site/lpx/price-stats`)에 **집계만** 보입니다. **매물 5개 미만 칸은 DB 가 값을 비우고**(CHECK) 공개 화면에서 숨깁니다(`lpx.stats_min` 5 이상). 매물 상세에는 「이 지역 비슷한 매물 가운데값」 한 줄. 처음에는 꺼져 있습니다(`lpx.stats` off). 위치: 운영 **검수 › 지역별 시세 통계**(SB-ADM-LPX-040 · 탭 `lpx-stats`).

| 항목 | 정한 것 |
|---|---|
| 셈 대상 | 그 달(한국)에 게시된(`published_at`) 매물 중 지금 PUBLISHED · ARCHIVED · 거래 금액 > 0 · 시 · 도 있음 |
| 칸 | GROUPING SETS 6벌 — (관 · 업종 · 시도 · 시구) · (관 · 업종 · 시도) · (관 · 업종) · (관 · 시도 · 시구) · (관 · 시도) · (관) |
| 업종 | `fn_lpx_category_root` — 맨 위 분류(모든 업종 = 'ALL') |
| 값 | 가운데값 · 25% · 75%(percentile_cont · 원 단위 반올림) |
| 숨김 | 5개 미만 칸 값 없음(DB) · 공개는 `lpx.stats_min`(5 ~ 50) 칸만 · 아래 지역 숨긴 수만 |
| 모으기 | 매일 04:50 `lpx_stats_daily` — 이번 달 · 지난달 다시 · `lpx.stats_months`(12) 안 빠진 달 채움 · 운영 「지금 셈」(SUPER · 스위치와 상관없이) |

## 2. 전체 구조
1. 표 `lpx_price_stats`(그 달 다시 셈은 함수 안에서 지우고 새로) · 함수 `fn_lpx_stats_refresh(달)` · `fn_lpx_category_root`.
2. 서버 `src/modules/lpx/stats.ts` · 공개 주소 첫 마디 `site`(check-acl 공개 구역 그대로 · 패치 없음).
3. 사용자 웹 `/price-stats`(서버 화면 · JS 없이 GET 폼 · 5분 캐시) · 매물 상세 `LpxOffer` 의 한 줄.

## 5. 확인할 것 · 주의 — **법무 확인 끝(11/21 대표)**
1. **「실제 거래가 아님」 안내** — 게시 매물의 희망 금액이라 시세로 오해될 수 있음(표시 · 광고법 · 부동산 관은 공인중개사법상 시세 표시 경계). 화면 · API 문구에 넣음 · 부동산 관 공개 여부도 법무 확인 끝 — 켜는 때 대표 결정.
2. **재식별** — 5개 미만 숨김 + 시 · 구 단위까지만(동 · 좌표 없음) · 개인정보 처리방침 변경 없음으로 봄(집계 · 개인 식별 불가).
3. 지난달 값은 다음 달 1일 이후에도 늦게 게시 · 내림(ARCHIVED 는 포함 · REJECTED · SUSPENDED 는 빠짐)으로 조금 바뀔 수 있음.
