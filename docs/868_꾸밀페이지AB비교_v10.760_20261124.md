# 868. 꾸밀 페이지 A/B 비교 (v10.760 · 2026-11-24)

> 대표 11/24 「다음개발 후보 모두 제시」 → 「모두 개발 · 점검 뒤에」 → 「동시작업 가능한 경우 동시에」(v10.754 ~ 773 · D328 · docs/862 ~ 881).

## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 편집 화면 › 「A/B 비교」 | A = 게시된 판 · B = 지금 저장된 초안 · 1 ~ 31일 · 페이지마다 하나 · 판마다 방문 수 · 「A 로 끝내기」(그대로) · 「B 로 끝내기(게시)」(B 를 새 판으로) |
| 사용자 웹 | 방문자 쿠키 sgb_ab(a · b · 90일 · proxy 가 처음 방문에 나눠 줌) — b 인 방문자에게 B 판 · 처음 방문 화면은 A |
| 방문 수 | LayoutViewPing 이 쿠키 판(v=a|b)을 같이 보냄 → site_layout_ab_views |

- 시작 · 끝은 게시 권한(SUPER 또는 관 UI/UX 승인) · 수정 가능 · 관 닫힘 규칙 그대로 · 기간이 지나면 B 는 저절로 안 보임(끝내기 전까지 기록은 RUNNING).
- 비교 중에는 그 페이지 화면이 쿠키를 읽어 캐시 없이 그려질 수 있음.
