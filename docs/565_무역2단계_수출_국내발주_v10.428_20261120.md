# 565. 무역 2단계 — 수출 · 국내 구매 발주 (v10.428 · 2026-11-20)

## 1. 결론
- **수출**: 수주 → 선적 → 수출신고 수리 → 대금 회수(앞으로만 · 선적 전에만 취소 · DB 가 막음).
  - 선적 때 선적일 환율로 원화 매출을 잡고(영세율 · 부가세 0), 직판 상품 옵션 품목은 재고에서 나감(⑫ 매출원가 전표가 자동).
  - 수출신고 수리 때 수출신고번호(영세율 근거)를 저장.
  - 대금 회수 때 통장 입금 원화와 매출의 차이는 외환차익 · 외환차손.
- **국내 구매 발주**: 발주 → 입고. 입고하면 ⑫ 매입 관리에 매입이 한 건 생기고, 직판 옵션 품목은 재고 수불부에 입고(재고 전표는 매입 전표가 대신).
- ⑭ 부가세 신고서 「영세율 · 기타」(6) 칸에 수출 매출 합계가 들어감.

## 2. 전표 (일반기업회계기준 · 선적 기준)
| 때 | 전표 | 차변 | 대변 |
|---|---|---|---|
| 선적 | EXPORT_SALE | 외상매출금(AR) | 수출 매출(REV_EXPORT · 401) |
| 선적 | COGS(⑫) | 상품매출원가 | 상품 |
| 대금 회수 | EXPORT_PAID | 보통예금(입금 원화) | 외상매출금(매출액) · 차액 외환차익(907) / 외환차손(952) |
| 입고 | PURCHASE(⑫) | 상품 또는 비용 · 부가세대급금 | 미지급금 |

## 3. 위치 · API
- 회계 › 매입 · 경비 › 수출(SB-ADM-ACC-310) · 국내 발주(SB-ADM-ACC-320).
- `GET · POST /admin/acct/exports` · `POST /admin/acct/exports/{id}/advance` · `/cancel`
- `GET · POST /admin/acct/pos` · `POST /admin/acct/pos/{id}/receive` · `/cancel`
- 감사: ACCT_EXPORT_ADD · ACCT_EXPORT_ADVANCE · ACCT_EXPORT_CANCEL · ACCT_PO_ADD · ACCT_PO_RECEIVE · ACCT_PO_CANCEL.

## 4. 주의
1. 환율은 사람이 넣음(매매기준율 등) — 유니패스 · 은행 연동 없음. 수출신고는 관세사.
2. 영세율 세금계산서(내국신용장 · 구매확인서 · 5번 칸)는 아직 없음.
3. 국내 발주 입고는 같은 공급자 · 날짜 · 합계 매입 막기를 건너뜀(force) — 같은 발주를 두 번 입고하는 것은 상태(ORDERED 만)로 막음.
4. 일반 원칙 적용 — 세무사 확인은 선택.
