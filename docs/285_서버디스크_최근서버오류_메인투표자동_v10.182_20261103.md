## 3. 운영에서 (v10.182 적용 뒤 · 대표)

1. 첫 화면 「지켜보기」의 서버 디스크 줄을 보십시오. 85% 를 넘으면 빨간 칸 · 운영 알림 `DISK_LOW` — 할 일: ① 오래된 백업 묶음 정리(`~/sgb-data/backup/uploads`) ② 남은 옛 판(`~/sgb-releases` — apply 가 하나만 남김) ③ 그래도 모자라면 AWS 콘솔에서 EBS 늘리기(비용은 **최신 요금 확인 필요**).
2. 사이트가 이상하면 위험감지 › 「서버 오류」를 찍어 알려 주십시오(요청 번호로 원인을 찾음).
3. 메인 투표: 적용 직후 메인 「이건 어때?」에 운영이 만든 열린 투표가 자동으로 나옵니다. 원하지 않으면 「이건 어때? 투표」 › 「자동 채우기 끄기」. 비어 있는 종류는 새 투표를 만들어 여십시오.
