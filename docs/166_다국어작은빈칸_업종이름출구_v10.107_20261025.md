## 1. 결론

| 항목 | 내용 |
|---|---|
| 업종 이름 | 응답 출구 `CategoryNameInterceptor` 한 곳에서 바꿈 — `categoryName` · `mainCategory` · `category`(글자) 칸, `category` · `categories` · `candidates` 안 묶음의 `name` 이 **업종 이름과 정확히 같으면** 승인된 번역으로. 리드 · 상담 · 파트너 센터 · 정산 · 업체 목록 · 자격 · 소개자 · AI 추천 · 내 활동 · 대화 요약 등 14곳이 한 번에 · 새 화면도 저절로 |
| 바꾸지 않는 곳 | 운영 화면(`/api/v1/admin…`) · 한국어 · 다국어 꺼짐 · 꺼진 언어 · **검색 팝업 업종 글자**(`search/suggest` 의 `categories` 글자 배열 — 누르면 그 글자로 찾으므로 그대로) |
| 번역 표 | `I18nService.categoryNameMap(lang)` — 승인 · 자동 승인 · 낡지 않은 것만 · 언어마다 60초 기억(영어 요청에 1분에 한 번 조회) · 실패하면 원문 그대로 |
| 요청 예산 영어 글 | 「Budget hidden · Budget negotiable · Up to … · … or more」를 화면 코드에서 빼서 `lib/fmt.ts` 언어 표(`EN_WORDS`)로 — 「Negotiable」과 같은 곳(요청 카드 · 검색 · 요청 상세가 서로 다른 사전 묶음을 써서 사전 대신 이 표) |
| 나의공간 누적 수익 | 다른 언어에서 「1,200,000 KRW」 → 「₩1,200,000」 · 한국어 「1,200,000 원」 그대로 |
| 업종 그림 | 매물 사진이 없을 때 업종 이름 낱말로 고르는 그림(`gw.ts` PHOTO_MAP)에 영어 낱말을 더함 — 번역된 이름이면 모두 기본 그림(shop)이 되던 것(전부터 매물 목록에 있던 증상 포함) · 한국어 낱말이 먼저라 한국어 화면 그림은 그대로 |
| 404 | `connection()` 으로 요청마다 그림 — 전에는 빌드 때 한국어로 한 번 그려 두어 영어 화면에서도 한국어였음 · 응답 코드 404 그대로 |
