# 604. 영업 기회 CRM (v10.466 · 2026-11-20)

## 1. 결론
거래처(회계 › 거래처)마다 **영업 기회**를 두고 **상담 → 견적 → 계약 → 성사 · 실패**를 한 줄로 이어 봅니다. 견적 단계에서는 ㉓ **견적서와 연결**(없으면 견적서 초안을 바로 만들어 연결)하고, **다음 할 일 · 날짜**를 적어 두면 그날 아침 운영 알림이 뜹니다. 위치: **회계 › 설정 · 보고 › 영업 기회** · SB-ADM-SAL-010 · API `/admin/sales/opps`(세무사 읽기 범위 밖).

| 단계 | 뜻 | 바꿀 수 있는 곳 |
|---|---|---|
| LEAD 상담 | 처음 만듦 | 견적 · 계약 · 성사 · 실패 |
| QUOTE 견적 | 견적서를 잇거나 직접 옮김 | 상담 · 계약 · 성사 · 실패 |
| CONTRACT 계약 | 계약 진행 | 견적 · 성사 · 실패 |
| WON 성사 | **끝** — 다시 고치지 않음(DB 도 막음) | 없음 |
| LOST 실패 | 사유 2자 이상 | 「다시 열기」(상담 · 사유) |

| 칸 | 내용 |
|---|---|
| 거래처 | 회계 › 거래처(매출처 · 둘 다) — 만든 뒤 바꾸지 않음(새 기회로) |
| 예상 매출 | 원 · 공급가 기준을 권함 · 견적서 초안의 단가가 됨(과세 한 줄 · 부가세 10% 따로) |
| 담당 | 운영자(SUPER · ADMIN · PAYOUT) — 비우면 만든 사람 |
| 다음 할 일 · 날짜 | 날짜가 오늘이거나 지나면 **매일 08:50 운영 알림 SAL_OPP_DUE**(기회 · 날짜마다 한 번 · 닫거나 날짜를 바꾸면 풀림) |
| 예상 마감 · 메모 | 참고 |
| 기록 | 만듦 · 고침 · 단계 · 견적 · 메모 — 쌓기만(고치거나 지우지 않음) |

## 2. 파이프라인(화면 맨 위)
- 열린 단계(상담 · 견적 · 계약)별 **건수 · 예상 매출 · 가중 매출**(단계 확률 상담 10 · 견적 30 · 계약 70% — 화면 참고용, 회사 정책 값이 아님).
- 이번 달 성사 건수 · 금액(예상 매출 기준) · 실패 · **최근 90일 성사율** · 다음 할 일 오늘 · 지남.
- 실제 매출은 **거래명세서 확정 · 전표**가 기준입니다(회계 › 매출 목표 · 손익).

## 3. 견적서 잇기
1. 같은 거래처의 견적서(취소 아닌 것)를 골라 연결 — 다른 거래처 · 다른 종류 문서는 서버 · DB 가 막음(SAL_QUOTE · SAL_OPP_QUOTE).
2. 고르지 않으면 **견적서 초안**(제목 = 기회 이름 · 품목 1줄 · 단가 = 예상 매출 · 과세)을 만들어 연결 → 회계 › 견적 · 명세서에서 품목을 고쳐 보냄.
3. 상담 단계였으면 견적 단계로 옮김.

## 4. 설정 · 정기 작업
| 설정 | 처음 | 뜻 |
|---|---|---|
| `sales.opp_remind` | on | 다음 할 일 알림(끄면 열린 알림은 풀림) |

정기 작업 `sal_opp_remind` 매일 08:50(job_schedules · 운영 화면 › 정기 작업에서 바로 돌리기).

## 5. 권한
- 탭 `sal-crm` — SUPER · PAYOUT · ADMIN(견적 · 명세서와 같음). 세무사(ACCOUNTANT)는 보지 않음(`/admin/acct/` 밖 · 거래처 담당자 · 영업 메모가 있어서).
- ㉕ 권한 시드: 업무 `sal-crm`(회계 묶음) · 주소 7(GET 2 VIEW · 변경 5 EDIT).
