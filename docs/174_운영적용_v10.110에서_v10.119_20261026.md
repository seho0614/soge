3. **키 확인** → 「키 확인 성공 — 쓸 수 있는 모델 N개」(비용 없음)
4. AI 를 실제로 켜는 것은 따로 — 월 상한 → 처리방침 확인(AI 상담 docs/170 §2 · 검수 보조 docs/165 §2) → 스위치
