# 749 배송 추적 연동(택배사 어댑터 · 처음 off · 간주) — v10.607 (17차 ㉓ · 2026-11-21)

## 1. 결론
- 기존 발송 처리(운영자 · 판매자가 택배사 · 송장번호 → hlt_shipments)는 그대로. 매시간 `lsq_track` 이 배송중(SHIPPED) 주문의 마지막 송장을 조회해 단계(장소 · 시각)를 `lsq_track_events` 에 쌓음.
- 외부 연동 **CARRIER**(18 → 19번째) — 어댑터 + 스위치 `lsq.track` 처음 **off** + 방식 `lsq.track_mode` **ASSUME**(간주 · 밖으로 부르지 않음). LIVE 는 키 `CARRIER_TRACK_KEY`(운영 화면 › 외부 연동 › 연동 키) · 주소 틀 `CARRIER_TRACK_BASE` — 없으면 NOT_READY(운영 알림 LSQ_TRACK_NOT_READY 하루 한 번).
- 배송 완료 반영 `lsq.track_auto_deliver` 처음 **off** · **LIVE 결과일 때만** 기존 배송 기록에 DELIVERED 한 줄(트리거 fn_hlt_ship_apply → 구매확정 · 반품 기한 시작) · 간주 결과로는 절대 안 바꿈.
- 보내는 것: 택배사 코드 · 송장번호 · 키뿐(받는 사람 이름 · 연락처 · 주소 안 보냄).
