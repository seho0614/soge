# 750 반품 · 교환 사진 첨부 · 판정 기록 — v10.608 (17차 ㉔ · 2026-11-21)

## 1. 결론
- 기존 반품 · 교환 신청(hlt_returns · 판정 decideReturn)은 그대로. 그 위에 **사진**(구매 회원 · 그 주문의 입점 판매자)과 **판정 기록**(쌓기만)을 더함.
- 판정 기록: STATE(신청 · 승인 · 반려 · 환불 — DB 트리거가 누가(판매자 · 운영 · 자동) 적음) · INSPECT(상품 상태 · 책임) · NOTE(메모) · 「회원에게 보임」 줄만 회원이 봄 · 고치기 막음(새 메모로).
- 판정 기록은 **근거** — 승인 · 반려 · 환불을 바꾸지 않음. 사진 스위치 `lsq.return_photos` 처음 **off**(처리방침 1.2 게시 뒤 · 반품 사진 보관) · 운영 판정 기록은 꺼져도 됨.

## 2. 재사용
| 기존 | 어떻게 |
|---|---|
| 파일 올리기(D007 · POST /files → complete) | 새 용도 RETURN_PHOTO(JPG · PNG 10MB) · CHECK 는 **지금 목록을 읽어 하나만 더함** |
| attach-images openImage · sendImage | 사진 바이트(회원 · 판매자) · 운영은 기존 GET /files/{id}(열람 기록) |
| 개봉 반품 대장(D185) · 반품 배송비(D290) | 손대지 않음 |

## 3. DB
- `lsq_return_photos`(side BUYER · SELLER · 가리기 hidden_at · 트리거 `trg_lsq_return_photo_guard` — 내가 올린 RETURN_PHOTO · 한쪽 10장)
- `lsq_return_verdicts`(트리거 `trg_lsq_return_verdict_lock` 고치기 막음 · `trg_lsq_return_state_log` hlt_returns INSERT · UPDATE OF state)
- 신청이 지워지면 함께 지워짐(옛 시험 · 정리와 겹치지 않게 DELETE 는 막지 않음).

## 4. API · 화면
