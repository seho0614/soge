# 663. 매물 사진 품질 검사 (v10.525 · 2026-11-20)

## 1. 결론
매물 사진의 **해상도 · 크기 · 비율 · 흐림(근사)** 을 매시간 보고, 켜면 **사진 속 전화번호 · 링크 · 메신저 아이디 글자**를 기존 AI 어댑터로 확인합니다. 결과는 **경고만** — 검수 · 게시를 막지 않습니다. 스위치 `lsy.photo_check` · `lsy.photo_ai` **처음 꺼짐** · AI 는 통로 `LSY_PHOTO`(AI 전체 스위치 · **월 상한**).

## 2. 흐름
| 단계 | 내용 |
|---|---|
| 고르기 | `lsy_hourly` — 최근 30일 안에 바뀐 게시 · 검수 중 매물의 사진(`listing_media` IMAGE) 중 안 본 것 `lsy.photo_batch`(20)장 |
| 규칙 | 파일 머리만(512KB) — JPG SOF · PNG IHDR 로 가로 · 세로 · `SMALL`(짧은 변 < `lsy.photo_min_px` 600) · `TINY_FILE`(20KB 미만) · `BIG_FILE`(8MB 넘음) · `RATIO`(2.5 넘음) · `BLUR`(JPG · 해상도 충분 · 픽셀당 비트 < 0.25) · `UNREADABLE` |
| AI | 5MB 이하 JPG · PNG · 「있다 · 없다 · 종류」만 답하게 · **번호를 옮겨 적지 말라고 지시** · 답에 숫자 묶음 · 링크가 섞여 오면 지움 · 시험 엔진(MOCK)은 밖으로 안 나가고 「없음」 |
| 운영 | 검수 › 사진 품질(SB-ADM-LSY-020) — 경고 · 연락처 의심 · 모두 · 사진 열기 · 다시 보기 |
| 회원 | 나의공간 › 매물 동영상 · 사진 점검(SB-MYP-LSY-010) — 경고 수 · 사진마다 이름표(AI 메모 글은 안 보임) |

- 흐림은 그림을 풀지 않고 **파일 크기로 어림**한 값(새 npm 없음) — 「흐림 의심(근사)」으로 표시.

## 3. 표 · API
| 종류 | 이름 |
|---|---|
| 표 | `lsy_photo_checks`(매물 · 파일 한 줄 · 가로 · 세로 · 크기 · 비율 · 비트 · 경고 · AI 상태 · 연락처 의심 · 종류) · `fn_agent_allowed` 통로 `LSY_PHOTO` · 사용량 CHECK 11통로 |
| 설정 | `lsy.photo_check`(off) · `lsy.photo_ai`(off) · `lsy.photo_min_px`(600) · `lsy.photo_batch`(20) · `lsy.ai_model`('') |
| API | `GET /admin/lsy/photos` · `POST /admin/lsy/photos/recheck` · `GET /me/lsy/listings/{id}/photo-checks` |

## 4. 처리방침 고칠 곳(규칙 29) — **법무 확인 끝(11/20 · 11/21 대표)**
- `lsy.photo_ai` 를 켜면 **매물 사진을 AI 처리 위탁사(Anthropic · 기존 AI 상담 · 검수 보조 · 영수증 읽기와 같은 곳)로 보냄** — 처리방침 「AI 처리 위탁」 목적에 「매물 사진 속 연락처 글자 확인」 한 줄 · **법무 확인 끝(11/20 · 11/21 대표)**. 사진에 사람 얼굴 · 차량 번호가 있을 수 있음을 함께 적을 것.
- 규칙 검사(해상도 등)는 밖으로 나가지 않음.

## 5. 대표 결정 · 확인 거리
1. 켜는 때 · 월 상한 안에서 사진 확인에 쓸 몫(지금은 AI 전체 월 상한 하나를 함께 씀).
2. 경고 기준(짧은 변 600px · 비율 2.5 · 비트 0.25) — 켠 뒤 실제 사진으로 조정.
