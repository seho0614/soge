# 463. 고객센터 홈 · 머리줄 「고객센터」 · 운영 화면 「자주 묻는 질문」 관리 (v10.332 · 2026-11-17)

> 대표 11/17 「고객센터 링크 추가 하고 고객센터 페이지 만들어줘 — 보통의 고객센터 기능(당근 · 네이버 … 포털 참조)」 → 범위 「기본 + 운영 화면 FAQ 관리」. 마이그레이션 **D224**(261 → 262 · 스냅샷 필요).

## 1. 왜

- 고객센터 화면(`/support/new` — 자주 묻는 질문 · 1:1 문의 챗봇 · 운영 안내 · 문의 폼)은 v10.31 부터 있었지만, **머리줄 메뉴에 링크가 없어** 찾을 수 없었습니다(바닥줄 · 1:1 문의 화면에서만 들어감).
- 보통의 고객센터(당근 · 네이버 고객센터)는 맨 위 「무엇을 도와드릴까요?」 찾기 → 자주 찾는 메뉴 → 분야별 질문 · 많이 찾는 질문 → 공지 → 1:1 문의 순입니다. 지금 화면은 질문을 한 줄로만 늘어놓았습니다.
- 질문 글(faqs)은 운영 화면에서 고칠 곳이 없어 마이그레이션으로만 바꿀 수 있었습니다.

- 1:1 문의 챗봇 · AI 상담 · 이용안내는 지금처럼 `GET /faq` 를 읽으므로, 운영 화면에서 고친 글이 함께 바뀝니다.
- 영어 번역이 승인된 질문은 한국어를 고쳐도 옛 번역이 그대로 나옵니다 — 고친 뒤 관 관리 › 다국어에서 번역을 다시 확인합니다(화면 안내 문구에 적음).

## 4. 운영 적용

- 마이그레이션 D224 하나(261 → 262) — **RDS 스냅샷을 만듭니다.** 설정은 없습니다.
- 적용하면 사용자 웹 머리줄에 「고객센터」가 생기고 고객센터 화면 모습이 바뀝니다(질문 글은 그대로 · 분야만 처음 채움).
- 적용 뒤 대표 할 일(선택): 관 관리 › 「자주 묻는 질문」에서 「많이 찾는 질문」 올리기 · 분야 확인 · 오래된 글 고치기.
- 되돌리기(rollback): 프로그램만 앞 판으로 돌아가도 D224 칸(topic · is_top)은 남습니다. 앞 판은 그 칸을 읽지 않아 지장이 없습니다.
