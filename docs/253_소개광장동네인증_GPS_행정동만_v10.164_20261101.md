# 253. 소개광장 동네 인증 — GPS 1회 → 행정동만 (꺼진 채로) (v10.164 · 2026-11-01)

> 대표 결정(10/31 「GPS 동네 인증 도입」 · decisions/community-sogae-gwangjang #17 · map-kakao #16) · 계획 「승인」.
> 마이그레이션 **1개(D154)** · 192. 앞 판: v10.163(docs/252). **설정 처음 off — 켜기 전에 위치기반서비스사업 신고 · 위치기반 약관 게시.**

## 1. 무엇을 하나

회원이 소개광장에서 「동네 인증하기」를 누르면 휴대폰 위치를 **한 번** 받아 서버가 카카오 「좌표 → 행정구역」으로 **행정동 이름 · 코드만** 저장한다. 좌표는 저장 · 기록하지 않는다. 인증은 30일 유효하고, 그동안 그 회원의 글 옆에 「역삼1동 인증」처럼 행정동 끝 낱말만 보인다.

## 2. 바뀐 것

| # | 곳 | 내용 |
|---|---|---|
| 1 | DB **D154** `member_towns` | 회원 · 행정동 코드(10자리) · 이름 · 인증일 · 만료일 — **좌표 칸 없음** |
| 2 | DB `town_verify_logs` | 위치정보 이용 확인 기록 — 누가 · 언제 · 결과 행정동 · 실패 종류 · **좌표 없음** · 수정 · 삭제 금지(`trg_town_log_ro`) |
| 3 | DB `v_member_town_current` | 만료 전 인증만(배지 · 내 동네) |
| 4 | DB 설정 `community.town_verify`(처음 **off**) | 켜고 끄기는 SUPER 만(422 → 403 `TOWN_SETTING_SUPER`) |
| 5 | DB 약관 LOCATION **2.0 초안** | 위치기반서비스 이용약관 — 〔회사명〕 · 〔보관 기간〕 · 〔위치정보관리책임자〕 · 〔법무 검토〕 가 남아 **게시가 막힘**(TERM_HOLES) · 법무 검토 뒤 운영 화면 「약관」 › 「고치기」 → 게시 |
| 6 | 서버 `kakao-local.provider` `coordToRegion` | `GET /v2/local/geo/coord2regioncode.json` → region_type H(행정동) 코드 · 이름만 · 한국 밖 좌표 거절 |
| 7 | 서버 새 API | 공개 `GET /community/town/config`(켜짐) · 회원 `GET /me/town`(내 동네 · 약관 동의) · `POST /me/town/verify`(위도 · 경도 — 33 ~ 39 · 124 ~ 132 밖은 400) · `DELETE /me/town`(언제든 지움) |
| 8 | 서버 오류 | 422 `TOWN_VERIFY_OFF`(꺼짐) · `TOWN_CONSENT_REQUIRED`(지금 시행 중인 LOCATION 약관 미동의 — 약관 게시 전에는 늘 이것) · `TOWN_GEO_NOT_READY`(카카오 REST 키 없음) · `TOWN_NOT_FOUND`(행정동 못 찾음 · 실패 기록 남김) |
| 9 | 서버 소개광장 목록 · 글 | `authorTown` — 쓴 사람이 만료 전 인증을 했으면 행정동 끝 낱말(시 · 구 · 좌표는 내보내지 않음) |
| 10 | 사용자 웹 | 소개광장 목록 위 「동네 인증」 상자(꺼져 있으면 안 그림) · 글 목록 · 글의 작성자 옆 「○○동 인증」 · 사전 ko · en |
| 11 | 명세 | SB-HOM-CMU-010 에 새 API 4개 |

감사 기록(`@Audit`)은 붙이지 않음 — 요청 본문(좌표)이 어디에도 남지 않게. 이용 확인은 `town_verify_logs` 가 대신함.

## 3. 켜는 순서 (사람)

1. 위치기반서비스사업 신고(방송통신위원회 · 절차 · 기간은 신고할 때 확인)
2. 법무가 LOCATION 2.0 초안 확인 → 〔…〕 채움(운영 화면 「약관」 › 「고치기」) → 게시(시행일)
3. 카카오 콘솔에서 REST 키에 「좌표 → 행정구역」 사용 확인 · 운영 화면 지도 키 「키 확인」
4. 운영 화면 › 사이트 설정 `community.town_verify` → on(SUPER)
5. 휴대폰으로 소개광장 → 「동네 인증하기」 → 「○○동 으로 인증했습니다」 · 내 글 옆 배지
