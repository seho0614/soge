# 191. API 오류 글의 영어 — 단계 C(DB 트리거 · 함수 오류) — v10.127 (2026-10-27)

> 대표 「2」(단계 C) 2026-10-27. v10.125(docs/189)의 틀 그대로 — 오류 출구 `DbErrorFilter` 가 DB 오류의 접두어를 떼고 보내는 글을 같은 사전으로 옮김.
> **마이그레이션 없음**(165) · API 사전 1파일.

## 1. 결론

| 항목 | 내용 |
|---|---|
| 범위 | 마이그레이션의 `RAISE EXCEPTION 'PREFIX: 글 %', …` — 트리거 · 함수가 규칙을 막을 때 회원에게 가는 글 **501문장**(계획 때 178은 접두어 수 · 접두어 하나에 글이 여럿) |
| 키 모양 | `DbErrorFilter` 가 보내는 모양 그대로 — 접두어(`REPORT:` · `INV-6 violated:` · `A-14:` …)를 떼고 앞뒤 빈칸 정리 · `%` 자리는 순서대로 `{0}` `{1}` … |
| 사전 | `src/common/i18n/server-text.en.ts` 841 → **1,348문장**(단계 C 501 + 트리거가 자리에 넣는 상태 낱말 6) |
| 뺀 것 | 뒤를 `\|\|` 로 이어 실행 때 모양이 달라지는 글 3개(「… (공인중개사법 9조) —」 등) — 맞출 수 없어 원문 · 같은 함수의 옛 판 글도 함께 넣음(해 없음) |
| 동작 | 단계 A · B 와 같음 — 영어 화면일 때만 · 한국어 · 다국어 꺼짐 · 운영 화면(/admin)은 원문 |
| 남는 한국어 | 자리 값이 회원 자료(상품 이름 · 업체 이름 등)면 그대로 · 심의필 번호 형식 예(「심의필 제2026-0451호」)는 입력할 모양이라 한국어 그대로 |
