## 1. 결론

오픈일을 운영 화면(오픈 체크리스트 · SUPER)에 **한 번 넣으면** 그에 맞춘 날짜들이 함께 보이고, 홍보 기간 종료일이 정해집니다.

| 칸 | 값 | 어디에 |
|---|---|---|
| 오픈일 | 대표가 넣음 | 설정 `service.open_date`(새 · D144) |
| 홍보 기간 종료일 | **오픈 + 3개월**(자동으로 함께 넣음) | 기존 설정 `request.view.limit_from`(D013) — **이날부터 요청 열람 한도가 이미 자동 적용되는 값**(새 동작 아님) |
| 약관 게시 마감 | 오픈 − 7일 · 불리한 변경이 있으면 오픈 − 30일 | 계산만(약관 제14조 · 법령 원문 확인은 terms-publishing 미정 4) |
| 약관 시행일 | 「시행일이 오픈일과 다른 게시 약관 N개」 | 계산만 — **약관은 바꾸지 않음**(게시는 법정 고지 화면 · `publish-terms.sh` 에서 사람이) |
| 남은 날 | 오늘(한국 시간)부터 | 계산만 |

- 오픈 준비 점검에 **권장 줄 「오픈일」**(9번째)이 생깁니다. 오픈 차단은 아닙니다.
- 지난 날짜는 넣을 수 없습니다(`OPEN_DATE_PAST`). 비우면 오픈일만 지우고 홍보 기간 종료일은 그대로 둡니다.
- 홍보 기간 종료일을 따로 바꾸려면 지금처럼 운영 설정에서 `request.view.limit_from` 을 고치면 됩니다(오픈일을 다시 저장하면 다시 오픈 + 3개월).

## 3. 운영에 미치는 것
- 운영 적용 뒤 오픈일은 비어 있습니다 → 「오픈일」 줄은 「꺼짐」(권장) · 오픈 차단 수는 그대로.
