## 2. 바꾼 규칙

| 전 | 후 | 비고 |
|---|---|---|
| 5 ~ 9px | `var(--sgb-r-sm, 7px)` | |
| 9.5 ~ 13.5px | `var(--sgb-r-md, 11px)` | 10px(126곳)이 가장 많았음 |
| 14px 이상 | `var(--sgb-r-lg, 16px)` | |
| 40px 이상 | 999px | 알약 |
| 값이 하나이고 높이의 절반 이상(14 ~ 39px) | 999px | 높이 = height, 없으면 위아래 여백 + 글자 높이로 어림 — 30곳(단추 · 칩 · 검색칸 · 배지) |
| 4px 이하 · % · var() · calc() | 그대로 | 선 · 점 · 막대 끝 · 동그라미(50%) |
| 그림자 — 흐림 16px 이상 또는 아래로 6px 이상 | `var(--sgb-shadow-up, …)` | 팝업 · 메뉴 · 떠 있는 카드 · 메인 카드(--hshadow) |
| 그림자 — 그 밖 | `var(--sgb-shadow, …)` | 바닥 카드 |
| 테두리 고리(0 0 0 Npx) · inset · 고리와 섞인 것 | 그대로 | 고른 칸 · 초점 표시 |

괄호 안 값은 시트 값을 못 읽는 곳(시안의 운영 화면 등)에서 쓰는 대체 값입니다.
