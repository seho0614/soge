# 734. 회원 2단계 인증(선택) (v10.592 · 2026-11-21)

> 15차 보안 · 기반 ⑧. **운영자 2단계 인증(v10.180 D169 · TOTP)을 그대로** 회원에게 엽니다. 스위치 `sec2.member_mfa` 처음 off.

## 1. 결론

- 회원이 나의공간 › 보안 › 「2단계 인증」에서 **스스로 켜고 끕니다**(선택). 켜면 로그인할 때 휴대폰 인증 앱의 6자리 번호(또는 예비 번호)를 넣습니다.
- **증표가 번호 전에 나가지 않습니다** — 비밀번호가 맞으면 증표 대신 「2단계 표」(5분 · 한 번)를 받고, 번호까지 맞아야 증표가 나옵니다.
- 같은 표 `account_mfa`(비밀값 암호화 · 예비 번호 해시 · 5번 틀리면 15분 잠금) · 같은 계산 `common/totp.ts` — 새 패키지 · 외부 업체 없음.
- 간편 로그인(카카오 · 네이버)은 번호를 물을 곳이 없어, **2단계를 켠 회원은 간편 로그인을 막고** 이메일 로그인으로 안내합니다(403 `SEC2_MFA_USE_EMAIL`).

## 2. 흐름

| 단계 | 화면 | API |
|---|---|---|
| 켜기 1 | 나의공간 › 보안 「켜기 시작」 | `POST /me/mfa/setup` → 비밀값 · otpauth 주소(앱에 넣음) |
| 켜기 2 | 앱 번호 넣기 | `POST /me/mfa/enable` → 켜짐 · 예비 번호 10개(이때 한 번만 보임) |
| 로그인 1 | 로그인(이메일 · 비밀번호) | `POST /auth/login` → `{ mfaRequired: true, ticket, expiresIn: 300, message }` |
| 로그인 2 | `/login/mfa`(SB-HOM-SCX-010) | `POST /auth/mfa/member-login { ticket, code }` → 증표 · 이때 마지막 로그인 · 낯선 기기 · 로그인 기록을 남김 |
| 끄기 | 나의공간 › 보안 「끄기」 | `POST /me/mfa/disable { password, code }`(앱 번호 또는 예비 번호) |
| 상태 | 나의공간 › 보안 | `GET /me/mfa` — 열렸는지 · 운영 계정인지 · 켰는지 · 남은 예비 번호 · 비밀번호 있는지 · 잠김 |

- 사용자 웹은 표를 **HttpOnly 쿠키 `sgb_mfa_t`(5분)** 에 둡니다(브라우저 스크립트 · 주소창 · 기록에 남지 않음) · 「로그인 상태 유지」 값도 쿠키 `sgb_mfa_k` 로 이어 감.
- 표 저장: `sec2_mfa_tickets` — 무작위 32바이트의 **sha256 만** · 5분 · 한 번 · 번호 5번 틀리면 표를 버림(다시 로그인) · 하루 지나면 지움.
- 휴대폰을 잃으면: 예비 번호로 로그인 → 끄기 → 다시 켜기. 예비 번호도 없으면 고객센터 「계정」 → 본인 확인 → 운영 SUPER 가 기존 「2단계 인증 초기화」(`POST /admin/accounts/{id}/mfa-reset` · 사유 · 감사 MFA_RESET)로 지움.

## 3. 운영 계정과의 관계

- 운영 역할이 있는 계정은 이 흐름을 쓰지 않습니다(운영 화면 MfaGate 그대로) — 로그인 때 표를 만들지 않고, 회원 화면에서 끌 수도 없음(403 `SEC2_MFA_STAFF`).
- 운영자가 회원 화면에서 켜면 같은 `account_mfa` 줄이라 운영 화면 2단계에도 그대로 쓰임(문제 없음).
- 간편 로그인만 쓰는 계정(비밀번호 없음)은 켤 수 없음(422 `SEC2_MFA_NEED_PASSWORD`) — 켜면 로그인할 길이 없어짐.

## 4. 감사

MFA_ENABLE · MFA_DISABLE · MFA_BACKUP_USED · MFA_LOCKED(after_data 에 `member: true` · 비밀값 · 예비 번호 · 표는 넣지 않음 — `@Audit` 대신 서비스가 직접).

## 7. 켜는 순서

1. 사용자 설명서(help_docs USER_MANUAL)에 「2단계 인증 켜기 · 휴대폰을 잃었을 때」 절을 넣음(AI 상담도 답하게).
2. 고객센터가 「예비 번호 → 본인 확인 → SUPER 초기화」 절차를 앎.
3. SUPER 가 위험감지 › 이상 행동 감지 › 「회원 2단계 열기」(`sec2.member_mfa` on).
- 되돌리기: off — 등록은 남고 로그인 때 번호를 묻지 않음(다시 on 하면 그대로).
- 처리방침: 새로 모으는 개인정보 없음(인증 앱 비밀값은 계정 보안 정보 — 1.2 제9조 「2단계 인증」 문장에 「회원도 선택해 켤 수 있음」 한 마디 권함).
