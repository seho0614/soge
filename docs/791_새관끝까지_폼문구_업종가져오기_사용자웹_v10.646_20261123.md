## 4. 새 관을 여는 순서 (대표 · 운영)

1. 관 관리 › 관 관리 › **새 관 만들기** — 소개 대상 · 코드(3 ~ 4자) · 이름 · 상위 관(보통 「소개하고 벌기」).
2. 관 설정 › **「등록 폼 문구」** — 소개합니다 · 찾습니다 중 하나 이상 저장.
3. 업종 › 업종 승인 › **「새 업종 추가」** 또는 **「다른 관 업종 가져오기」** → **다른 관리자가 승인**.
4. 관 설정 › 「오픈 점검」 확인 → 「공개 상태」 › **「관 열기」**.
5. 사용자 웹 `sogaebank.com/g/<코드 소문자>` · 머리줄 메뉴 확인 · 메인에 카드가 필요하면 노출 › 메인 운영 › 관 노출.

- 새 관 화면은 **일반 관 화면**(목록 · 상세 · 묻고 답하기 · 등록은 소개장터와 같은 폼)입니다. 처음 관(소개장터 · 안심소개 · 소개창업 · 소개몰)처럼 따로 꾸민 첫 화면은 없습니다.
- 다른 언어(영어 등)에서 새 관 이름은 서버 이름(한국어)이 그대로 나옵니다 — 번역 사전에 없는 관이라서.
