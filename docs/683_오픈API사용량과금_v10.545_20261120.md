# 683. 오픈 API 사용량 과금 (v10.545 · 2026-11-20)

## 1. 결론
㊼(D278) 파트너 오픈 API 의 **호출 수를 하루마다 파트너 · 키별로 모아 두고**(`papi_usage_daily`), 달마다 **무료 한도 · 1,000건 단가**로 **청구서 초안**(`papi_bill_drafts`)을 만듭니다. **확정은 사람**(SUPER · 확인 글자) — 실제 청구 · 세금계산서 · 수납은 이 화면 밖에서 담당자가 합니다(이 묶음은 금액을 움직이지 않음). 과금은 처음 꺼져 있습니다(`papi.bill_enabled` off · 하루 사용량 모으기는 늘 돎). 위치: 운영 **파트너사 › 오픈 API 사용량 · 청구**(SB-ADM-VSX-040 · 탭 `vsx-papi-bill`) · 파트너 시스템 `GET /api/partner/v1/usage`.

| 항목 | 규칙(처음 값 · 운영 설정 SUPER) |
|---|---|
| 과금 대상 | 응답 400 아래의 **자료 주소**(leads · services · cash) — 안내 주소(me · docs · usage)는 셈만 · 400 이상(틀린 키 · 범위 · 한도 넘음)은 오류 칸 |
| 모으기 | 정기 작업 `papi_usage` 매일 03:40 · 지난 3일을 다시 셈(papi_daily 03:50 기록 정리 전 · 기록 보관 30일 이상이라 빠짐 없음) · 달 초 7일 안에는 지난달 끝 7일도 다시 |
| 무료 | `papi.bill_free_calls` 파트너마다 달 10,000건(0 ~ 1,000만) |
| 단가 | `papi.bill_price_1k` 1,000건 1,000원(0 ~ 10만 · **부가세 별도 · 임시 값 — 금액은 켤 때 정함**(대표 11/21)) |
| 금액 | 공급가 = (과금 건수 × 단가) ÷ 1,000 원 아래 버림 · 부가세 = 공급가 ÷ 10 버림 · 합계 = 공급가 + 부가세(DB CHECK 와 같은 셈) |
| 초안 | `papi.bill_day` 3일부터 매일 지난달 초안을 만들고 다시 셈(초안만) · 과금 건수 0 이면 만들지 않음 · 무료 수 · 단가는 만들 때 값으로 굳힘 |
| 확정 · 무효 | SUPER · 확정(「확정」) 뒤 숫자는 DB 가 막음 · 무효(사유)는 초안 · 확정 모두 · 무효 뒤 그 달 새 초안 가능 |
| 알림 | 초안이 새로 생기면 운영 알림 `PAPI_BILL_DRAFTS`(INFO) |

## 2. 전체 구조
1. 표 `papi_usage_daily`(날 × 키 · 지우지 않음) · 함수 `fn_papi_usage_rollup(from, to)`(62일까지) · 색인 `ix_ptn_api_requests_partner_at`.
2. 표 `papi_bill_drafts`(파트너 × 달 살아 있는 줄 하나 · 금액 CHECK · 트리거 `fn_papi_bill_guard` · 지우기 막음).
3. 서버 `src/modules/vsx/papi-bill.ts` · 운영 `VsxPtnAdminController` · 파트너 시스템 `VsxPapiUsageController`(㊼ PartnerApiKeyGuard 그대로 · 같은 요청 기록).
4. ㊼ 파일(papi/*)은 **고치지 않음** — 가드 · 기록 · 안내(docs) 그대로. 안내(GET /api/partner/v1/docs)에 usage 줄은 다음에 더함.

## 5. 법무 · 세무 · 확인할 것 · 주의 — **법무 확인 끝(11/21 대표)**
1. 파트너 이용약관의 「API 사용료」 조항 · 고지 — **법무 확인 끝(11/21 대표)**. **사용료 금액(무료 수 · 1,000건 단가)은 과금을 켤 때 정함** — 지금 처음 값(10,000건 · 1,000원)은 임시 그대로.
2. **세무**: 공급가 · 부가세 별도(D243) · 세금계산서 발행은 기존 전자세금계산서(간주 모드) 흐름에서 사람이 — 이 화면은 청구 근거(초안 · 확정)만.
3. 리드 이용료(lead cash)에서 빼는 자동 차감은 하지 않음(돈을 움직이지 않음 · 다음 결정).
4. 「처리방침 고칠 곳」: 없음(파트너 사업자 호출 기록 · 이미 ㊼ 에서 모음).
