| 동네픽 AI | AI 키 · 월 상한 · `agent.enabled` on(AI 켜기 단계) | 사이트 설정 `agent.town_pick.enabled` on → 다음 날 06:00 또는 「지금 고르기」 → **운영자 승인한 것만** 공개 |
| 동네 인증 | 위치기반서비스사업 신고 · LOCATION 약관 법무 확인 · 게시 | 신고번호 `community.lbs_report_no` → `community.town_verify` on(SUPER) — 둘 중 하나라도 없으면 422 로 막힘(정상) |
| 요금제 금액 | 오픈 전 금액 결정 | 정산 › 청구 현황 › 「요금제 금액 · 한도」 › 고치기(사유) |

### 4-3. 알아 둘 것

1. 적용 뒤 다음 날 06:00 정기 작업 `town_pick_daily` 가 돌지만, 스위치가 꺼져 있어 **AI 를 부르지 않고 후보도 만들지 않습니다**.
2. 요금제 금액을 **올리면** 이용 중 구독자는 옛 금액으로 계속 결제됩니다. 기존 구독자에게 올린 금액을 받으려면 미리 알리고 동의를 받는 흐름이 필요합니다(정기결제 증액 규정 — **조문 · 기간은 법률 확인 필요** · docs/332 2절).
3. 개봉 반품은 **팔지 않습니다**(식품 · 화장품 재판매 금지 · 법무 11/7). 보관 → 폐기 한 방향이고 처리 끝난 줄은 고칠 수 없습니다.
4. 개발 서버 `~/kits/release` 에 다른 판 킷(v10.203 · v10.206)이 남아 있어도 **v10.211 킷만** 올립니다.
