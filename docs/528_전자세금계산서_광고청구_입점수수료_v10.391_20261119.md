# 528. 전자세금계산서 — 광고 청구 · 입점 수수료 (v10.391 · 2026-11-19)

> ⑪ 네 번째(D244). 지금까지 광고 청구 · 입점 수수료는 홈택스 등에서 발행하고 번호만 적었습니다 — 정액 노출 · 리드 캐시와 같은 전자세금계산서 흐름으로 바꿉니다.

## 1. 결론

- 운영 화면 **회계 › 신고 자료 › 세금계산서 발행 대상**에서 광고 청구 · 입점 수수료 줄에 **「발행 요청」**(SUPER · PAYOUT) → **「발행」**(SUPER · ADMIN — 전자세금계산서 · 지금은 **간주 모드**: 국세청에 보내지 않고 「간주-문서번호」로 기록 · 승인번호 없음).
- 요청 때 **금액 · 공급받는 자를 그 값으로 고정**(DB 가 고치기를 막음 · 바꾸려면 요청 취소 뒤 다시). 근거마다 요청 하나(취소하면 다시 가능).
  - 광고 청구: 공급가 = 청구 공급가 · 세액 = 청구 부가세 · 공급받는 자 = 광고주(이름 · 사업자등록번호).
  - 입점 수수료: 공급가 = 수수료 · 세액 = 수수료 부가세(⑩) · 확인 · 지급한 정산만 · 공급받는 자 = 입점 판매자.
- 발행되면 근거에 번호를 적음 — 광고 청구서 `tax_invoice_no`(비어 있을 때만) · 입점 정산 `invoice_state = ISSUED` · `invoice_no`.
- 공급받는 분이 개인(사업자등록번호 없음)이면 발행 단추가 막힘 — 카드 · 현금영수증으로 갈음.
- 이미 손으로 번호를 적은 근거는 요청하지 않음(중복 발행 막음). 보낸 뒤 취소는 기존 전자세금계산서 「취소 · 수정 발행」(업체 연동 뒤).
