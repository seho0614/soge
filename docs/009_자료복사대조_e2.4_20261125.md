# 009. 소개뱅크 → ERP 자료 복사 · 대조 (e2.4 · 2026-11-25)

## 무엇
- `tools/erp-copy.sh board [--force] | apply` — 소개뱅크의 ERP 표(E004 목록)를 sgb_erp 로 복사.
  1. erp_ro 에 ERP 표 SELECT 를 잠시 줌 → `src_copy` 외부 표.
  2. **한 트랜잭션**: 이미 복사했으면 멈춤(`erp.copy_done_at` · `--force` 는 점검판만) → ERP 표 비움 → 같은 칸 이름끼리 INSERT(트리거 건너뜀) → 순번 맞춤 → 표마다 줄 수 · 금액 칸 합 대조 · 하나라도 다르면 되돌림.
  3. src_copy 지움 · 권한 거둠 · 대조표 파일(점검판 `~/check-results` · 운영 `~/sgb-data/logs`).
- 소개뱅크 표는 읽기만 — 지우지 않음(E7 읽기 전용 표시 · 지우기는 적용 뒤 2 ~ 4주 따로 승인).

## 점검
- `qa/test_e2_board.py` — ① 표 수 E004 = sgb_erp = 소개뱅크 · 소개뱅크 FK 0 ② svc 읽기 · 쓰기 막힘 ③ 번호 확인 ④ 복사 대조 0 · 두 번째 복사 멈춤.

## 확인 필요
- 운영에서 `session_replication_role = replica` 는 마스터 사용자로(RDS 확인 필요).
