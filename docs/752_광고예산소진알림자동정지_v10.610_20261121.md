# 752. 광고 예산 소진 알림 · 자동 정지 (v10.610 · 2026-11-21)

> 18차 ㉖. 광고 › 새 탭 「광고 예산」(키 `bzx-ad-budget`). SQL `sql/bzx_610_ad_budget.sql`.

## 1. 결론

- 광고 소재(`ad_placements`)마다 **노출 수 또는 클릭 수 상한**을 정합니다. 기간은 **전체(TOTAL)** 또는 **하루(DAY · 한국 날짜)**.
- 셈은 **새 추적 없이 기존 광고 기록 `ad_events`(노출 · 클릭)** 만 읽습니다. 처음 상한 제안 = 그 소재 예약(`ad_bookings`)의 예상 노출.
- 10분마다(`bzx_frequent`) 알림 기준(처음 80%)을 넘으면 · 상한에 닿으면 **운영 알림 `BZX_AD_BUDGET`**(창마다 한 번).
- **자동 정지는 처음 꺼짐**(`bzx.ad_autopause` off · 알림만). 켜면 줄마다 「다 쓰면 자동 정지」를 고른 소재만 `PAUSED`(기존 소재 중지와 같은 상태 · ACTIVE 일 때만).
- 하루 예산으로 멈춘 소재는 **다음 날 첫 차례에 다시 노출**(우리가 멈춘 것만). 「다시 채움」은 셈을 다시 시작하고 우리가 멈춘 소재를 다시 노출 — 슬롯 · 심의 규칙(`trg_ad_active_slot` · `trg_ad_slot_gate`)에 걸리면 멈춘 채 둡니다.
- 광고주에게 메일은 보내지 않습니다(성과 보고서 메일 `prx.ad_report_mail` 과 따로 · 다음 판 후보).

## 3. 셈

| 기간 | 센 기간 | 알림 열쇠 |
|---|---|---|
| TOTAL | `counted_from`(넣을 때 · 다시 채움 때) 부터 | `ad|예산|TOTAL|시작시각|기준%` · `…|100` |
| DAY | 오늘 00:00(한국) 부터 | `ad|예산|YYYY-MM-DD|…` — 날마다 새로 |

- 예산을 고치면 알림 표시(기준 넘음 · 다 씀)를 지우고 셈 시작은 그대로 둡니다.
- 권한: ADMIN · SUPER(광고 과금과 같음) · 스위치 SUPER. 감사 `BZX_AD_BUDGET_SET` · `BZX_AD_BUDGET_RESET` · `BZX_AD_BUDGET_OFF`(번호만).

## 4. 확인할 것

1. 계약(예약) 기준 상한을 정하고 알림만 며칠 보기 → 자동 정지 켜기(SUPER).
2. 하루 예산 소재는 다음 날 0시 뒤 첫 10분 차례에 다시 노출되는지 화면에서 확인.
