# 731. 개발 서버 디스크 정리 강화 (v10.589 · 2026-11-21 · 14차 운영 ⑤)

> 대표 11/21 「모두 개발진행」. 기존 정리 두 곳을 넓힘 — `~/sgb-check.sh` 점검 전 정리(v10.193 · v10.197) · 운영 `deploy/aws/cleanup.sh`(v10.186). **실제 `~/sgb-check.sh` 는 고치지 않았습니다**(아래 3절 제안 패치).

## 1. 결론

- infra 에 **`tools/dev-disk-clean.sh`** 를 더했습니다. 기본은 읽기만, `--apply` 는 yes 를 받고, `--auto` 는 점검 전용(묻지 않음).
- `--auto` 는 지금 sgb-check.sh 가 하던 것(점검 결과 19개 + 새 결과 = 20개 · 이름 없는 이미지 · 볼륨 · 빌드 캐시 4gb · 킷 3판)에 **멈춘 리허설 컨테이너 · /tmp 리허설 찌꺼기 · ops 킷 2판 · 오래된 차이 파일**을 더하고, 디스크가 **80퍼센트 이상**이면 무거운 것(점검 결과 안 그림 · 동영상 · 빌드 캐시 2gb · 14일 넘게 안 쓴 이미지 · npm · pip 캐시)까지 지웁니다.
- 11/21 개발 서버: 디스크 77퍼센트 · 도커 약 14GB · /tmp 약 5.6GB(대부분 다른 작업 폴더 — 도구는 내 리허설 찌꺼기만 지움) · 점검 결과 242MB · 킷 약 550MB.

## 3. `~/sgb-check.sh` 제안 패치(대표 승인 뒤 사람이 · infra `qa/sgb-check.sh` 원본도 같이)

- 도구는 킷을 만들기 **전에** 돌아야 해서 킷 안 사본이 아니라 `~/bin/dev-disk-clean.sh`(예약 작업 사본과 같은 자리) → 없으면 `~/sogaebank/sgb-infra/tools/dev-disk-clean.sh` → 둘 다 없으면 **지금 정리 그대로**.
- `kits-keep-begin` · `kits-keep-end` 표시와 옛 정리 줄은 남깁니다(옛 시험이 글자로 봄 · 도구가 없을 때 대신 돎).

```diff
--- ~/sgb-check.sh
+++ ~/sgb-check.sh
@@
 # v10.193 (docs/302) — 점검 전에 개발 쪽 디스크 자동 정리(개발 · 운영이 같은 디스크). SGB_NO_CLEAN=1 이면 건너뜀
 #   지우는 것: 점검 결과 최근 20개 밖 · 이름 없는 도커 이미지 · 매이지 않은 이름 없는 볼륨 · 빌드 캐시 4GB 넘는 부분 · 킷은 최근 3판만(v10.197)
-if [ "${SGB_NO_CLEAN:-0}" != 1 ]; then
+# v10.589 (docs/731) — 정리 도구가 있으면 그것으로(리허설 컨테이너 · /tmp 찌꺼기 · ops 킷 · 80% 넘으면 무거운 것까지) · 없으면 아래 옛 정리
+DC=~/bin/dev-disk-clean.sh; [ -f "$DC" ] || DC=~/sogaebank/sgb-infra/tools/dev-disk-clean.sh
+if [ "${SGB_NO_CLEAN:-0}" != 1 ] && [ -f "$DC" ]; then
+  bash "$DC" --auto | tail -2
+elif [ "${SGB_NO_CLEAN:-0}" != 1 ]; then
   ls -1dt ~/check-results/*/ 2>/dev/null | tail -n +20 | xargs -r rm -rf
```

- 예약 사본 등록(대표가 `!` 로): `install -m 755 ~/sogaebank/sgb-infra/tools/dev-disk-clean.sh ~/bin/dev-disk-clean.sh`.

## 4. 쓰는 법

```bash
bash ~/sogaebank/sgb-infra/tools/dev-disk-clean.sh            # 읽기만
bash ~/sogaebank/sgb-infra/tools/dev-disk-clean.sh --apply    # yes 받고 모두(⑤ ~ ⑦ 포함)
PRESSURE_PCT=70 bash ~/bin/dev-disk-clean.sh --auto           # 점검 전 · 70% 넘으면 무거운 것까지
```

## 5. 시험 — `qa/test_v1589.py`

- ① 코드 · `bash -n` · 지우는 길이 `$HOME` · `$TMPROOT` 밖으로 가지 않음 · 문서 제안 패치 ② 가짜 HOME · 가짜 도커(붙지 않음)로 읽기만(아무것도 안 지움) · `--auto`(점검 결과 19개 · 킷 3판 · ops 2판만 남김 · 차이 파일 · 가짜 /tmp 찌꺼기) — 서버 진짜 폴더 · 도커는 건드리지 않음.
