# 600. 사내 일정 캘린더 (v10.462 · 2026-11-20)

## 1. 결론
운영자가 **달 · 주 보기** 한 장에서 휴가 · 품의 쓸 날 · 신고 기한 · 계약 만기 · 급여일 · 출장 · 업무 기한을 함께 봅니다. 이 일정들은 **각 화면의 표를 그대로 읽어 모은 것**이라 사본이 없고, 여기서 고치지 않습니다(누르면 그 화면으로). 직접 넣는 일정만 새 표(ofc_events) 하나에 둡니다. 위치: **사무 › 사내 일정** · SB-ADM-OFC-010.

| 종류 | 읽는 곳 | 보는 사람 |
|---|---|---|
| 직접 일정 — 개인 | ofc_events(scope PERSONAL) | 넣은 본인만(SUPER 도 남의 개인 일정은 못 봄) |
| 직접 일정 — 회사 | ofc_events(scope COMPANY) | 운영자 모두 · 넣기 · 고치기 · 지우기는 ADMIN · SUPER |
| 휴가 | acct_leave_requests(승인 · 내 신청 중) + acct_employees | 운영자 모두(이름 · 반차만 · 사유 안 보임) |
| 품의 쓸 날 | acct_requisitions.needed_on(결재 기다림 · 승인 · 출장 품의는 뺌) | 올린 사람 · SUPER · 지급 담당 |
| 신고 · 납부 기한 | month.ts deadlines()(원천세 10일 · 부가세 25일 · 법인세 · 카드 대금 — 주말 · 공휴일이면 다음 영업일) | SUPER · 지급 담당 |
| 급여일 | 같은 셈(acct.pay_day) | 운영자 모두 |
| 계약 만기 · 해지 통보 기한 | acct_contracts(쓰는 중 · end_on · end_on − notice_days) | SUPER · 지급 담당 |
| 출장 | ofc_trips(v10.464) | 본인 것 모두 · 남의 것은 품의 승인된 것만 |
| 업무 기한 | ofc_tasks(v10.463 · 끝나지 않은 것) | 요청한 사람 · 담당자 |

## 2. API
| 방법 | 주소 | 설명 |
|---|---|---|
| GET | /admin/office/calendar?from=&to= | 모은 일정(62일까지 · 비우면 이번 달) |
| POST | /admin/office/events | 직접 일정 넣기(개인 · 회사) |
| PUT | /admin/office/events/{id} | 보낸 칸만 고침(time null = 종일) |
| POST | /admin/office/events/{id}/remove | 지움 표시(DB 가 DELETE 를 막음 · 지운 일정은 고치지 않음) |

- 역할: 운영 역할 모두(SUPER · ADMIN · PAYOUT · REVIEWER · PARTNER_MAL · PARTNER_AFF) · **세무사(ACCOUNTANT) 빠짐** — 주소가 /admin/acct/ 아래가 아니라 세무사 읽기 규칙에 들지 않음.
- 남의 개인 일정은 404(있는지도 알리지 않음) · 회사 일정을 검수 담당 등이 넣으면 403 OFC_EVENT_SCOPE.

## 3. 표 (D263)
- ofc_events — scope · owner_id · title(1 ~ 80) · start_on · end_on(93일까지) · at_time(HH:MM · 서버 · DB 같은 정규식) · memo(400) · removed_at · removed_by.
- 트리거 trg_ofc_event_guard — DELETE 막음 · 지운 일정 고치기 막음 · 종류 · 넣은 사람 바꾸기 막음.
- 권한(D258): 업무 ofc-calendar(사무) · 주소 4줄 · 운영 역할 그룹 R_ADMIN · R_PAYOUT · R_REVIEWER · R_PARTNER_MAL · R_PARTNER_AFF 에 VIEW · EDIT · APPROVE · EXPORT.

## 4. 주의
1. 신고 기한 날짜는 세법 기본(세무사 확인) — 연장 · 특례는 회계 설정에서 바꿈.
2. 휴가는 직원과 운영 계정이 연결된 사람만 「내 신청 중」이 보입니다(회계 › 인사 › 근태에서 SUPER 가 연결).
3. 달 보기 칸이 넘치면 「+n」 — 그날을 누르면 모두 보입니다.
