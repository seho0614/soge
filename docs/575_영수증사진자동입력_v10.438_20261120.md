# 575. 영수증 사진 자동 입력 (v10.438 · 2026-11-20)

> 대표 11/19 「다음개발」. 마이그레이션 D257 ②.

## 1. 결론

증빙 **영수증 사진에서 날짜 · 공급자 · 사업자번호 · 공급가 · 부가세 · 합계 · 종류를 읽어 칸을 채워 줍니다.** 저장은 사람이 확인하고 고친 뒤 기존 「매입 넣기」로 합니다. 처음 꺼져 있고, 켜도 처음 방식은 간주(가짜 값)입니다.

## 2. 위치 · 설정

| 항목 | 값 |
|---|---|
| 화면 | 회계 › 매입 · 경비 › 영수증 읽기 (SB-ADM-ACC-430) |
| 스위치 | `acct.receipt_ai` = off(처음) · on |
| 방식 | `acct.receipt_ai_mode` = ASSUME(간주 · 밖으로 안 나감 · 처음) · AI |
| AI | 운영 화면 › AI 에이전트 › AI 키 · AI 전체 스위치 · 월 상한 안에서만(통로 RECEIPT) · 모델은 agent.review_model |

## 3. 흐름

1. 사진(JPG · PNG · 5MB 까지) 올리기 → 증빙 파일(ACCT_EVIDENCE).
2. 읽기 → 제안 칸(믿음 % · 공급가 + 부가세 ≠ 합계면 믿음 낮춤).
3. 고치기 → 「매입으로 넣기」(사진이 증빙으로 붙음).
4. 읽은 기록은 쌓기만(acct_receipt_reads · 방식 · 모델 · 토큰).

## 4. 주의

1. PDF 는 읽지 않습니다(직접 넣기).
2. 영수증 사진이 AI 공급자(국외)로 갑니다 — 처리방침의 국외 이전 조항(AI) 범위 안인지 확인 뒤 AI 방식을 켭니다.
3. 간주 방식 값은 가짜입니다 — 매입으로 넣지 마십시오(화면에 표시).
