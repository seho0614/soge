# 121. 관리자 스위치 — 간주 모드 · 소개비를 운영 화면에서 (v10.65 · 2026-10-22)

> 대표 지시(2026-10-22): 「5번 진행 관리자 스위치 추가」 — docs/111 에서 찾은 두 가지
>   ① 간주 모드 4종 · 소개비 스위치를 켜고 끄는 단추가 운영 화면에 없었음(관리자 API 를 손으로 불러야 했음)

## 1. 결론

| 항목 | 내용 |
|---|---|
| 운영 화면 | **오픈 체크리스트 › 관리자 스위치** 카드 — 5개 스위치의 지금 값 · 바꾸는 조건(외부 연동 상태) · 바꾸기 단추 |
| 스위치 | 전자세금계산서 간주 · 중개사 인증 간주 · 결제 간주 · 수금 계좌 간주 · 소개비 기능 (끄는 순서대로) |
| 확인 칸 | 「실제로 돌리는 쪽」(간주 끄기 · 소개비 켜기)은 한 번 더 누르게 함 — 무엇이 바뀌는지 문구를 보여 줌. 되돌리는 쪽(간주 다시 켜기 · 소개비 끄기)은 바로 됨 |
| 서버 조건 | 같은 방향으로 바꿀 때 서버도 조건을 봄(`SWITCH_PREREQ`) — 운영 화면을 거치지 않고 API 를 불러도 막힘 |
| 형식 검사 | D105 — feature.referral_fee · feature.success_fee 도 소문자 on / off 만(간주 4종은 처음부터 그랬음) |
| 기록 | 값 저장은 전과 같은 `PATCH /admin/site-settings` — 감사 기록 `SITE_SETTING_UPDATE`(바꾼 사람 · 시각) |
| 권한 | 전과 같음(ADMIN · SUPER) — 새 API 없음 |

## 2. 바꾸는 조건 (docs/111 6-3)

| 스위치 | 실제로 돌리는 쪽 | 조건(서버 · 화면 같음) |
|---|---|---|
| `assume.etax` | off | 외부 연동 ETAX 가 TESTING 또는 LIVE |
| `assume.broker` | off | BROKER 가 TESTING 또는 LIVE |
| `assume.payment` | off | PG 가 TESTING 또는 LIVE |
| `assume.bank` | off | 사이트 기본 정보에 실제 수금 계좌 세 항목(시험용 · 999999- 아님) — 넣으면 트리거가 저절로 끔 |
| `feature.referral_fee` | on | PASS 와 BANK 가 모두 LIVE |

외부 연동 상태는 운영 화면 「외부 연동」 탭에서 바꿉니다. 조건이 맞지 않으면 단추가 꺼져 있고, 마우스를 올리면 조건을 보여 줍니다.
