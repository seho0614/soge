### 4-2. 알아 둘 것

1. **새 기능은 거의 모두 꺼진 채 들어갑니다.** 운영 화면 **정책 › 「기능 스위치 한눈에」** 한 곳에서 무엇이 켜졌는지 · 꺼졌는지 봅니다. 켜는 것은 대표가 하나씩 정합니다(4-3).
2. **처음부터 켜진 것(on)** — 알림 · 표시만 하고 돈 · 회원 화면은 바꾸지 않습니다: 사무 알림(`ofc.task_due_alert` · `ofc.browser_notify`) · 영업 기회 다시 알림(`sales.opp_remind`) · 연장 근로 주 52시간 넘김 막기(`hrx.ot_over_block` — 연장 근로를 입력할 때만) · 자금 계획 경보(`acct.cashplan_alert`) · 안전 재고 재주문 알림(`acct.reorder`) · IT 자산 · 키 · 제안함 알림(`its.*_alert`) · 유통기한 경보(`qlt.expiry_alert`) · 매물 중복 의심 줄 쌓기(`lsy.dup_queue` — 사람이 보는 대기 줄만) · 웹 푸시 밤 시간 쉼(`push.quiet` — 푸시는 꺼짐) · **이상 거래 점수**(`opx.risk_score` · 기준 60 — 높으면 운영 알림 `OPX_RISK_HIGH` · 막지는 않음).
3. **새 정기 작업 32개**(1절 「적용 스크립트」 줄)가 바로 돕니다. 꺼진 스위치의 작업은 아무것도 하지 않고 지나갑니다(작업 기록에 빈 줄만).
4. **매물 목록 「끌어올림」 표시는 최신순에서만** 나옵니다(v10.558). 끌어올리기 자체(`lsx` · 대표 11/20 결정 — 관리자가 OFF · FREE · PAID 전환)는 꺼진 채입니다.
5. **DB 검사 정규식 고침(D289)** — 운영에 이미 있던 결함입니다: 소개창업 정책 글 「출처 주소」 · 제휴상품 사진 주소(https)를 넣으면 500 이 나던 것이 이 판부터 저장됩니다. 지금 값이 든 줄이 없어 다시 붙일 때 바로 끝납니다.
6. 감사 기록 · 개인정보 접속기록 · 설정 바뀐 기록은 이제 **통째 비우기(TRUNCATE)도 막힙니다**(D275). 기록 장기 보관(`opx.archive`) · 디스크 밖 보관(`opx.archive_s3`)은 꺼진 채입니다.
7. 사용자 웹의 오프라인 안내(`sw.js`)는 `site.pwa` 가 off 라 **등록되지 않습니다** — 화면 · 그림 · API 를 캐시하지도 않습니다.
8. 개발 서버 `~/kits/release` 에 다른 판 킷이 있어도 **v10.558 킷만** 올립니다.
