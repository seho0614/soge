# 496. 가입 차단 목록 (v10.362 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 회원 운영 메모 · ② 가입 차단 목록 · ③ 탈퇴 사유 통계 · ④ 역할별 「오늘 할 일」 「모두」 → 계획 「승인 + 통과하면 병합」(네 번째 묶음 · 운영 반영은 v10.360 까지 한 번에 한 뒤). 이 문서는 ②. 마이그레이션 **D237**.

## 1. 왜

- 사기 · 스팸 회원을 정지해도 같은 사람이 다른 메일로 다시 가입할 수 있었습니다. 같은 IP 하루 가입 상한(v10.173)만 있었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D237** | 표 `signup_blocks`(종류 · 값 · 사람은 가린 이메일 이름 · 사유 필수 · 기한 · 풀기 칸) · 지우기 막음 · 풀기는 한 번 · 표 `signup_block_hits`(하루 · 종류 막힌 수) |
| 종류 | **이메일 도메인**(하위 도메인도) · **IP 대역**(하나면 /32) · **사람**(본인인증 고유값 해시 — 회원 상세에서 등록 · 원문 없음) |
| 가입 | 도메인 · 접속 IP 가 걸리면 422 `SIGNUP_BLOCKED` 「지금은 가입할 수 없습니다. 고객센터로 문의해 주십시오.」(이유를 알리지 않음) |
| 본인인증 | 고유값이 걸리면 422 `IDENTITY_BLOCKED` |
| 새 API `GET · POST /admin/signup-blocks` · `POST …/{id}/remove` | 읽기 ADMIN · SUPER · 더하기 · 풀기 SUPER(감사 `SIGNUP_BLOCK_ADD` · `SIGNUP_BLOCK_REMOVE`) · 409 이미 · 422 값 · 사유 · 본인인증 안 한 회원 · 자기 자신 |
| 운영 화면 **위험감지 › 「위험감지」** 맨 위 | **「가입 차단 목록」** — 목록 · 막힌 수(오늘 · 7일) · 더하기 · 풀기 · 최근 푼 것 |
| 운영 화면 **회원 › 회원 상세** | **「이 사람 다시 가입 · 인증 막기」**(SUPER · 사유) |
| 정기 작업 `sla_alert` | 오늘 20번 넘게 막히면 운영 알림 **SIGNUP_BLOCK_SPIKE**(경고) |
| 월간 보안 보고 | 「가입 차단에 막힘 n」 |
