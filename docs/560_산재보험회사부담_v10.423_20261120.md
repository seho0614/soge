# 560. 산재보험 회사 부담 급여 전표 (v10.423 · 2026-11-20)

> ⑲ D252 · ⑱ 에서 요율(ia_company_rate 0.7% · 업종 요율로 고침)만 저장한 것을 급여에 반영 · 위치 **회계 › 인사 › 급여**

## 1. 결론
- 급여 줄에 **company_ia**(산재 회사 부담 = 과세 급여 × 산재 요율 · 10원 미만 버림)를 셉니다. 회사만 내므로 실지급은 그대로입니다.
- 급여 전표(PAYROLL): 차변 **보험료(EXP_INSURANCE)** · 대변 **예수금(4대보험 · INS_PAYABLE)** 에 산재가 더해집니다.
- 급여 화면 「회사 4대보험 · 산재」 칸에 합과 산재를 따로 작게 보여 줍니다.

## 2. 주의
1. 이미 확정한 급여는 0 그대로(그 달 전표도 그대로) — 새로 만드는 급여부터.
2. 산재는 근로복지공단이 사업장에 통지한 업종 요율(출퇴근 재해 요율 포함)로 회계 › 급여 › 요율에서 고칩니다.

## 3. 시험 (test_v1423)
① 코드 · ② 먼 해(2093) 급여 → 산재 = 2,800,000 × 요율 · 실지급 그대로 · 회사 몫 합 · 확정 → 전표 보험료 = 회사 몫 · 차변 = 대변.
