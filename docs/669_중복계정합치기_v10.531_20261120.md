# 669. 중복 계정 합치기 (v10.531 · 2026-11-20)

## 1. 결론
같은 사람의 두 계정을 **본인인증(실명) 일치로만** 하나로 합칩니다. 운영 관리자가 「옛 계정(없어질 쪽) → 남길 계정」으로 **요청**(사유) → **요청한 사람이 아닌 SUPER** 가 확인 글자 **「합치기」** 를 넣고 승인하면 DB 함수 하나(`fn_csx_merge_execute`)가 **한 번에** 처리합니다(실패하면 모두 되돌아가고 요청은 FAILED). **되돌릴 수 없습니다.** 스위치 `csx.account_merge` **처음 꺼짐**. 회원 화면은 없음(회원은 1:1 문의로 요청).

## 2. 본인인증 일치
- 두 계정 모두 **성공한 본인인증**의 `ci_hash`(서버 열쇠 HMAC · 원문 CI 없음)가 같아야 함 · 방식은 **NICE**(점검판은 MOCK 도) · 시험용 STUB(`stub-ci`)은 일치로 보지 않음 · **운영 서버에서 MOCK 은 막음**(IDENTITY_MOCK).

## 4. 끝나면
- 옛 계정 `SUSPENDED` · `token_version` +1 · 상태 바뀜 트리거가 로그인 세션도 끊음 · **다시 ACTIVE 로 못 바꿈**(`trg_csx_merged_source_guard`).
- 남길 계정에 알림 `CSX_ACCOUNT_MERGED`(가린 옛 메일) · 감사 `CSX_MERGE_REQUEST` · `CSX_MERGE_DONE` · `CSX_MERGE_FAILED` · `CSX_MERGE_REJECT`.
- 기록: `csx_account_merges`(계획 plan · 결과 result · 끝난 줄 고치기 · 지우기 막음) · `csx_account_merge_items`(옮긴 줄 하나씩 · 쌓기만).
