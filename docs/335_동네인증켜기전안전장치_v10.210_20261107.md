# 335. 동네 인증(GPS) 켜기 전 안전장치 · 준비 상태 — v10.210 (2026-11-07)

> 계기: 대표 「다음개발 모두」 → 위치 약관 · 동네 인증 GPS(11/7 「승인」). 위치기반서비스사업 신고 · 법률 확인이 먼저라 **켜는 기능은 만들지 않고, 켜지 못하게 막는 장치와 준비 상태만** 만듦.
> 동네 인증 자체(GPS 1회 → 행정동만 · 좌표 저장 안 함)는 v10.164(D154 · docs/253)에 꺼진 채로 있음.
>
> **마이그레이션 1개(D187 · 224 → 225)** · 새 API 1개(운영) · 운영 화면 소개광장 검수 큐 맨 위 한 칸 · 회원 화면은 바뀌지 않음.

## 1. 켜기 막는 조건(DB 트리거 `trg_town_verify_on_guard`)

| 조건 | 없으면 |
|---|---|
| 위치기반서비스 이용약관(LOCATION)이 **게시(PUBLISHED) · 시행일 지남** | 422 `INVALID_SETTING` 「…약관(LOCATION)을 게시해 시행된 뒤에 켤 수 있습니다.」 |
| 위치기반서비스사업 **신고번호** `community.lbs_report_no`(새 설정 · 처음 비어 있음) | 422 `INVALID_SETTING` 「…신고번호(community.lbs_report_no)를 넣은 뒤에 켤 수 있습니다.」 |

- 이미 켜져 있던 값을 다시 저장하는 것은 막지 않음(off → on 으로 바뀔 때만 검사).
- 카카오 REST 키는 DB 밖(운영 화면 연동 키 · .env)이라 트리거가 보지 못함 → 준비 상태 줄에 보이고, 없으면 인증 때 `TOWN_GEO_NOT_READY`(전과 같음).
- 스위치를 켜는 사람은 그대로 SUPER(`TOWN_SETTING_SUPER`).

## 2. 운영 화면 › 소개광장 › 「동네 인증 준비 상태」

| 줄 | 보이는 것 |
|---|---|
| 위치기반서비스 이용약관 | 시행 중인 판 · 없으면 초안 판(2.0 초안) |
| 신고번호 | 있음 / 없음(값은 보이지 않음) |
| 카카오 REST 키 | 있음 / 없음 |
| 초안 빈칸 | 약관 초안에 남은 〔…〕 칸 목록 — 법무에 넘길 것 |

API: `GET /api/v1/admin/community/town-verify/readiness`(ADMIN · SUPER).

## 3. 법무에 넘길 것 — LOCATION 2.0 초안의 빈칸(D154)

| 칸 | 조항 | 메모 |
|---|---|---|
| 〔회사명〕 | 제1조 | 「(주)한국바이오헬스케어 소개뱅크 사업부」 표기 기준(business-entity) |
| 〔보관 기간〕 | 제4조 ② 이용 · 제공사실 확인자료 | 위치정보법 시행령 기준 확인 필요 |
| 〔위치정보관리책임자 이름 · 연락처〕 | 제6조 | 대표가 정함 |
| 〔법무 검토〕 | 제7조 손해배상 · 분쟁 | 법무 문안 |
| 〔시행일〕 | 부칙 | 신고 수리 뒤 |

- 위치기반서비스사업 신고 요건 · 절차 · 처리 기간은 **최신 법령 · 방송통신위원회 안내 확인 필요**.

## 4. 켜는 순서(대표 · 신고 수리 뒤)

1. 방송통신위원회 위치기반서비스사업 신고 → 신고번호 받음.
2. 법무가 3절 빈칸을 채움 → 약관 관리에서 LOCATION 2.0 법무 검토 → 게시(시행일).
3. 사이트 설정 `community.lbs_report_no` = 신고번호 · 외부 연동 › 연동 키 › 카카오 REST 키 확인.
4. 준비 상태 셋 다 ✓ → 시행일이 지나면 SUPER 가 `community.town_verify` = on.
