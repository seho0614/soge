# 544. 법인세 추정 미리보기 (v10.407 · 2026-11-20)

> ⑮ 네 번째(D248). 대표 11/19 「승인 + 통과하면 병합」 — 세율 구간 SUPER 설정 · 중간예납 · 확정 기한 · 세무조정은 세무사.

## 1. 결론

- 운영 화면 **회계 › 법인세 추정**(SUPER · PAYOUT) — 올해(사업연도) 전표의 **수익 − 비용 = 회계 이익**을 과세표준으로 보고 셉니다(**세무조정 없음**).

| 줄 | 셈 |
|---|---|
| 지금까지 | 사업연도 시작 ~ 오늘 이익의 법인세 · 지방소득세 |
| 1년으로 늘리면 | 지금까지 이익 ÷ 지난 달 수 × 12 |
| 중간예납(가결산 추정) | 상반기 이익 × 2 의 세액 ÷ 2 |

- 세율은 설정 **`acct.corp_tax_brackets`**(「과세표준 상한:세율%」 · 마지막 `*`) · 처음 `200000000:9,20000000000:19,300000000000:21,*:24` — **초안**이라 그 해 세법에 맞는지 세무사 확인(해마다 SUPER 가 고침). 지방소득세 `acct.corp_local_rate`(처음 10%) · 사업연도 끝 달 `acct.corp_fiscal_end`(처음 12).
- **기한**(주말 · 공휴일이면 다음 영업일): 중간예납 = 사업연도 시작 6개월 기간 끝 달의 2개월 뒤 말일(12월 결산이면 8월 31일) · 확정 신고 = 끝 달의 3개월 뒤 말일(3월 31일). 화면에 가까운 2개.
- 해 마감 · 풀기 전표(⑭ YEAR_CLOSE · YEAR_REOPEN)는 손익에서 뺍니다. 손익 계정은 기초 잔액이 없어 전표 줄만 셉니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D248** | 설정 `acct.corp_tax_brackets` · `acct.corp_local_rate` · `acct.corp_fiscal_end` |
| API | `GET /admin/acct/corptax` |
| 운영 화면 | 회계 › **법인세 추정**(SB-ADM-ACC-220) |

## 3. 주의

1. 회계 이익 ≠ 과세표준 — 기업업무추진비 한도 · 감가상각 한도 · 이월결손금 · 세액공제 · 감면은 세무사가 합니다. 이 화면은 자금 계획용 어림값입니다.
2. 중간예납은 직전 연도 세액의 절반 방식도 있어 실제 금액과 다를 수 있습니다.
3. 전표는 시스템을 지난 돈과 수동 전표만 담깁니다 — 수동 전표(v10.405)로 빠진 비용을 넣어야 추정이 맞습니다.
4. 법인세 기한을 ⑪ 월 결산 신고 기한 알림(ACCT_DEADLINE)에 붙이는 것은 통합 때 `corpDeadlines()` 로(NOTES).
