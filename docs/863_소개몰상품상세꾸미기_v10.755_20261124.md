# 863. 소개몰 상품 상세 꾸미기 (v10.755 · 2026-11-24)

> 대표 11/24 「다음개발 후보 모두 제시」 → 「모두 개발 · 점검 뒤에」 → 「동시작업 가능한 경우 동시에」(v10.754 ~ 773 · D328 · docs/862 ~ 881).

## 1. 바뀐 것

| 위치 | 내용 |
|---|---|
| 관 관리 › 페이지 목록 › 「소개몰 상품 상세(모든 상품)」 | 안내 띠 글(120자) · 위 · 아래 블록 — **모든 상품 상세에 같이** 나옴(상품마다 따로는 아님) · 소개몰 관 규칙(관이 열려 있으면 고칠 수 없음) |
| 사용자 웹 /health/p/<상품> | 상품 이름 줄 위에 안내 띠 · 위 블록, 맨 아래에 아래 블록 |

- 미리보기는 상품 상세 주소에 ?lp=<링크 끝 40자> 를 붙여 봄(편집 화면 「사용자 웹 열기」는 주소 모양만 보여 줌).
- 상품마다 · 분류마다 따로 꾸미기는 이번에 넣지 않음(필요하면 다음 묶음).
