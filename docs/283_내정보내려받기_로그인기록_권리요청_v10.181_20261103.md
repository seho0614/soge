## 3. 운영에서 (v10.181 적용 뒤 · 대표)

1. **권리 요청이 오면** 위험감지 › 「권리 요청」 → 회원 상세에서 본인 계정인지 확인 → 정정 · 삭제는 해당 화면에서 처리 → 「처리 완료」에 무엇을 했는지 적기(회원에게 그대로 알림). 처리하지 않을 사유가 있으면 「거절」에 사유. 기한 안에 어려우면 「기한 연장」(한 번 · 사유).
2. 하루 요약에 `PRIVACY_REQUEST_DUE` 가 뜨면 그날 처리하십시오.
3. 손님이 「하루 3번」이 부족하다고 하면 `privacy.export_daily` 를 올리십시오(최대 20).
4. 로그인 기록 보관(180일)은 아래 5절 확인 뒤 `privacy.login_history_days` 로 맞추십시오.
