# 480. 못 찾은 낱말 → 「기존 질문에 더하기」 (v10.346 · 2026-11-18)

> 대표 11/18 「다음개발」 ④. 마이그레이션 없음(270).

## 1. 왜

- 「못 찾은 낱말 30일」(v10.336)은 「이 낱말로 새 질문」 · 「다룸」만 있었습니다. 대부분은 **이미 있는 질문을 다른 말로 찾은 것**이라, 새 질문을 만들면 같은 질문이 늘어납니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 새 API `POST /admin/faqs/misses/attach` | ADMIN · SUPER · 감사 `FAQ_MISS_ATTACH` — `{ word, faqId }` → 그 질문의 찾기 낱말(챗봇 낱말)에 붙이고 「다룸」. 이미 있으면 다룸만(`added false`). 404 낱말 · 질문 없음 · 422 `FAQ_MISS_WORD`(찾기 낱말은 20자까지) · `FAQ_KEYWORDS_FULL`(그 질문은 낱말 10개) |
| 운영 화면 **관 관리 › 「자주 묻는 질문」 › 「못 찾은 낱말 30일」** | 줄마다 **「있는 질문 고르기」**(보이는 질문) · **「기존 질문에 더하기」** |

- 붙인 뒤 고객센터에서 그 낱말로 찾으면 그 질문이 나옵니다(찾기 규칙은 그대로). 질문을 고친 때 · 사람도 바뀝니다.

## 3. 시험 (test_v1346)

1. ① 코드 — API(감사) · 화면 단추 · screens.json · 문서 480 · 판 v10.346
2. ② API — 시험 낱말 → 더하기 → 질문 낱말에 있음 · 목록에서 빠짐 · 감사 · 다시 → added false · 없는 질문 404 · 21자 422 · 회원 403
3. ③ 화면 — 고르기 · 더하기 → 목록에서 빠짐

## 4. 운영 적용

- 마이그레이션 · 설정 없음. 되돌리기(rollback): 앞 판에는 단추가 없고, 붙인 낱말은 질문에 그대로 남습니다(지장 없음).
