# 758. 운영 화면 「?」 도움말 — 새 탭 설명 넣기 (v10.616 · 2026-11-21)

> 대표 11/21 승인 「운영자 설명서 새 기능 반영」. v10.594(docs/736)의 「?」 도움말 구조를 그대로 쓰고, **v10.457 ~ v10.614 에서 새로 생긴 운영 화면 탭 124개** 의 설명 절을 운영 화면 도움말(help_docs `ADMIN_GUIDE`)에 더합니다. 기준 코드 c1569(v10.614 까지 합친 판). SQL `sql/hdx_admin_guide_tabs.sql`(앞머리 hdx_ · 메인이 D302 ~ 중 한 번호에 붙임).

## 1. 결론

1. **새 탭 124개 모두 절을 넣었습니다(빠진 새 탭 0).** 새 탭 = `web/src/lib/adminMenu.ts` TABS 줄 주석의 첫 판 번호가 v10.457 이상인 탭 128개 가운데 1판(D300)에 이미 절이 있는 4개(해외 접속 경고 `sec-geo` · 이상 행동 감지 `scx-watch` · 기능 스위치 한눈에 `opx-switches` · 화면 도움말 `scx-help`)를 뺀 것.
2. 절마다 **무엇(하는 일) · 주의(자동으로 하지 않는 것 · 되돌릴 수 없는 것 등) · 켜는 스위치(키 · 처음 값 · 켤 조건)** 를 한두 줄로. **어디서**는 절 묶음 제목(왼쪽 메뉴 그룹)과, 회원 · 파트너 · 판매자 화면에서 일어나는 것은 그 위치를 절 안에 적었습니다.
3. 근거는 판 문서(docs/595 ~ 756)의 결론 · 켜는 순서 · 주의, 탭 머리글(`adminMenu.ts` PAGE 설명), 마이그레이션 `site_settings` 줄(키 · 처음 값 · 설명) · `opx_switch_docs`(켤 조건). 절에 적은 설정 키는 시험이 마이그레이션에 있는지 하나씩 대조합니다.
4. **새 판으로 더함 · 지우거나 고치지 않음.** 지금 판 끝에 붙인 2판을 만들고(help_docs 는 쌓기만 · 1판은 남음), 탭 → 절 잇기(`sec2_tab_help`) 124줄을 넣습니다. 다시 돌려도 같습니다.
5. 본문 길이 **15,216자**(1판 1,944 + 더한 글 13,270 + 이음 2) — 한도 20,000자(help_docs CHECK · 서버 저장 한도) 안. SUPER 가 화면에서 더 쓸 자리는 약 4,780자 남습니다.
