## 3. 법무 검토 요청서 (그대로 보내도 되는 글)

```
제목: 소개뱅크 소개광장 「동네 인증」 위치기반서비스 검토 요청

1. 기능
 - 회원이 소개광장에서 「동네 인증」을 누르면 휴대폰 브라우저 위치(위도 · 경도)를 한 번 받아
   서버가 카카오 「좌표 → 행정구역」 API 로 행정동 이름 · 코드로 바꿉니다.
 - 좌표는 바꾼 즉시 버리고 DB · 기록 어디에도 남기지 않습니다.
 - 저장: 회원 · 행정동 코드 · 이름 · 인증일 · 만료일(30일). 글 옆에 「○○동 인증」 표시.
 - 이용 확인 기록: 누가 · 언제 · 결과 행정동 · 실패 여부(좌표 없음 · 수정 · 삭제 불가).
 - 회원은 언제든 인증을 지울 수 있습니다.

2. 여쭙는 것
 ① 위치기반서비스사업 신고 대상인지(좌표를 저장하지 않고 행정동만 남기는 경우 포함).
    또 단말기 위치를 직접 받는 것이 위치정보사업(등록) 대상인지.
 ② 이용 · 제공사실 확인자료 보관 기간(제4조 ②).
 ③ 약관 2.0 초안 제1조 ~ 제7조 · 부칙 문안과 빈칸(첨부).
 ④ 회원 동의 방식: 「동네 인증」 처음 누를 때 약관 동의를 받는 방식으로 충분한지
    (지금 코드는 시행 중인 위치기반 약관에 동의하지 않으면 인증을 막습니다).
 ⑤ 만 14세 미만 회원 처리(법정대리인 동의) — 가입 연령 정책과 맞는지.

3. 첨부: 약관 2.0 초안 원문 · docs/253(기능 설명)
```
