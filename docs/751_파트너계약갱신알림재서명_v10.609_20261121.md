# 751. 파트너 계약 갱신 알림 · 재서명 (v10.609 · 2026-11-21)

> 대표 11/21 「모두 개발진행」 18차 ㉕. 파트너사 › 새 탭 「파트너 계약 갱신」(키 `bzx-ptn-contract`) · 파트너센터 › 계약(`/partner/contracts`). SQL `sql/bzx_609_partner_contract.sql`(메인이 D292 ~ 에 붙임).

## 1. 결론

- 안심소개 파트너(`partners`)와 맺은 계약을 한 줄씩 적고, **만기 알림 일수(처음 30일) 전부터 운영 알림 `BZX_PARTNER_RENEW`** 를 띄웁니다(계약 · 만기일마다 한 번 · 매일 09:35 `bzx_daily`).
- 갱신은 **새 계약 줄(`prev_id`)로 다시 서명**을 받습니다. 본문 = 계약 머리(상호 · 기간 · 자동 갱신) + 파트너 표준계약서(`contract_templates` `PARTNER_STD` 지금 판) · SHA-256 지문을 고정해 서명 뒤 고칠 수 없습니다(DB 트리거).
- 서명 길은 **처음 간주 서명**(`bzx.partner_esign` off) — 파트너 대표가 파트너센터 › 계약에서 대표자 이름(또는 상호)을 적고 동의하면 서명. 화면 · 응답에 「법적 전자서명 아님」을 늘 표시합니다.
- 켜면(`on`) 기존 전자계약 방식 `esign.provider` 그대로: STUB · MOCK 은 화면 안 시험 서명, **HTTP 는 기존 ESIGN 어댑터(`HttpESign.create` · 서명자 SELLER 자리 1명)** · 키가 없으면 `NOT_READY`(422) — 근로계약서(v10.459)와 같은 규칙.
- 이미 종이로 맺은 계약은 「종이 계약 적기」(`PAPER` · 서명 끝)로 넣어 만기 알림만 받습니다.

## 2. 상태와 정기 작업

| 상태 | 뜻 | 다음 |
|---|---|---|
| SENT | 서명 기다림 | SIGNED(서명) · CANCELED(취소 · 사유) |
| SIGNED | 효력 있음 | EXPIRED(갱신 없이 만기 지남) · ENDED(갱신 계약이 서명돼 넘어감) |
| EXPIRED · ENDED · CANCELED | 끝 | — |

| 정기 작업 `bzx_daily`(매일 09:35) | 운영 알림 |
|---|---|
| SIGNED · 만기까지 알림 일수 안 · 보낸(또는 서명된) 갱신 없음 | `BZX_PARTNER_RENEW` WARN(계약 · 만기일마다 한 번) — 갱신 계약이 서명되면 풀림 |
| SIGNED · 만기 지남 | EXPIRED + `BZX_PARTNER_EXPIRED` WARN / 갱신 서명돼 있으면 ENDED(알림 없음) |
| SENT · 14일 넘게 서명 없음 | `BZX_PARTNER_UNSIGNED` INFO(한 번) |

- 파트너에게 회원 알림 `BZX_PARTNER_CONTRACT`(만기 전 · 서명 요청)는 `bzx.partner_notice` on 일 때만(처음 off · 주소 `/partner/contracts`).

## 4. 권한 · 감사

- 보기 ADMIN · SUPER · 안심 파트너 담당(PARTNER_MAL) / 보내기 · 상태 확인 · 취소 ADMIN · SUPER / 스위치 SUPER.
- 파트너 쪽은 **파트너 대표 계정만**(직원 계정 · 다른 사람은 404).
- 감사: `BZX_PC_CREATE` · `BZX_PC_CANCEL` · `BZX_PC_SIGN`(번호 · 상태만 — v10.565 `pick`) · `BZX_SWITCH`.

## 5. 확인할 것(현장 체크리스트)

1. 파트너 표준계약서 `PARTNER_STD` 가 쓰는 판(is_active)으로 있는지 — 없으면 보내기가 422 `BZX_PC_TEMPLATE`.
2. 기존 종이 계약을 「종이 계약 적기」로 먼저 넣기(만기 · 알림 일수).
3. 전자계약 업체가 정해지면 서명자 자리(SELLER) · 칸 이름 확인 뒤 `bzx.partner_esign` 켜기(SUPER).
4. 파트너 알림(`bzx.partner_notice`)은 파트너 안내 문구 확인 뒤 켜기.
