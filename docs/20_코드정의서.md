## 이 문서를 쓰는 법

코드 라벨은 **화면에 하드코딩하지 않습니다.** 부팅 시 `GET /codes` 로 한 번 받고
로컬에서 씁니다. `"노출 중"`을 `"게시 중"`으로 바꾸는 데 배포가 필요 없습니다.

```tsx
// ✗ 하드코딩
{status === 'PUBLISHED' ? '노출 중' : ...}

// ✓ 서버가 내려준 것
<Badge tone={codes[domain][status].tone}>{item.statusLabel}</Badge>
```

## 금칙어

| 등급 | 수 | 처리 |
|---|---:|---|
| **BLOCK** | 36 | 등록 거부 |
| **WARN** | 23 | 통과 + 자동검수 제외 (사람이 봄) |

**WARN 을 차단하지 않는 이유** — "최고 사양 설비"는 정상 표현이고,
"카톡으로 문의"도 맥락에 따라 다릅니다. 막는 대신 사람에게 보냅니다.
