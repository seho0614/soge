# 452. 공지 읽음 자세히 — 비율 · 등급별 (v10.325 · 2026-11-16)

> 대표 「다음개발」(11/16) B. 원래 후보 「공지 읽음률」은 v10.293 「읽음 n / 대상 m」이 이미 있어 **비율 · 등급별 · 「모두 읽음」 따로**로 고쳐 진행(대표 승인). 마이그레이션 없음. 운영 화면 + 운영 API.

## 1. 바뀐 것 (정확한 위치)

운영 화면 **노출 › 메인 운영 › 하위 탭 「콘텐츠」 › 「공지」 목록 › 「읽음」 칸**

| 칸 | 내용 |
|---|---|
| 읽음 단추 | `읽음 n / 대상 m (p%)` — 누르면 아래에 「공지 읽음 자세히」 상자(다시 누르거나 「닫기」로 닫음) |
| 자세히 상자 | 읽음 · 대상 · 비율 · **「모두 읽음」 표시 n명**(셈에서 뺌 · D222) · 등급별 표(등급 · 대상 · 읽음 · 비율) |

- 기준은 목록과 같습니다: 대상 = 그 등급의 **활동 중** 회원(`fn_notice_grades`) · 읽음 = 펼쳐 본 기록(`notice_reads` 중 `bulk` 아님).
- 한 회원이 여러 등급이면 등급마다 셉니다(등급별 합이 전체보다 클 수 있음).
- 전체 공개 · 관리자만 공지는 대상 수를 세지 않습니다(전과 같음).

## 2. API

`GET /admin/notices/{id}/reads` → `{ id, grades, reads, bulk, target, rate, byGrade: [{ code, name, target, reads, rate }] }` · 없는 공지 404 · 운영 역할만.
