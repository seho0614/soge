# 소개뱅크 — 메시지 정의서

**자동 생성** `node scripts/gen-message-doc.js`
**범위** 화면에 나가는 오류·안내 문구. 알림은 `21_알림문구정의서` 참조

---

## 오류 문구 규약

| 상태 | 의미 | 문구 성격 |
|---|---|---|
| 400 | 형식 오류 | 어느 필드가 잘못됐는지 |
| 403 | 권한·게이트 | **무엇을 하면 되는지** — 막는 게 목적이 아닙니다 |
| 409 | 상태 충돌 | 재시도해도 같다는 것을 알려야 합니다 |
| 422 | 정책 위반 | **그대로 사용자에게 보여도 되는 문장** |

**422 는 프런트가 가공하지 않습니다.** 서버 문구를 그대로 띄웁니다 —
제한업종 차단 문구처럼 관리자가 바꿀 수 있어야 하기 때문입니다.
