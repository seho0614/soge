## 무엇
- 마이그레이션 `E006_ref_check` — `erp_ref_ok(kind, id)` · `erp_ref_assert(kind, id)`(없으면 `ERP_REF_MISSING` · SQLSTATE 23503 = 외래 키 위반과 같은 번호라 지금 오류 처리가 그대로 409 로 감).
- kind: account · product · option · seller · advertiser(모두 uuid).
- 함수 · 조회 안 소개뱅크 표 이름은 **도구가 `svc.` 로 바꿈**(`tools/gen-erp-schema.py` · 읽기 FROM · JOIN 만) — 함수 25개 · 소개뱅크 표 27종(`docs/e2-svc-refs.tsv`).
- svc 를 읽는 조회는 마이그레이션이 아니라 `prisma/svc-views.sql`(svc 를 가져온 뒤 `tools/erp-svc.sh` 가 만듦 — 조회는 만들 때 표가 있어야 함).
- 소개뱅크 표에 **쓰는** 함수(목록의 `write` 줄): fn_acct_tax_invoice_issued · fn_bzx_card_txn_notice · fn_staff_left_role — svc 는 읽기 전용이라 그대로 두고 **E3 에서 알림 outbox · 소개뱅크 내부 API 로 옮김**(그 전에는 이 함수가 불리면 오류).
