# D017 · D018 — 업종 추가 · 상담 신청 API (2026-10-02)

## D017 업종 추가 (대표 결정: 공공·기관 제외 나머지 적용)

광고·마케팅(`CSL_MARKETING`) · 디자인(`CSL_DESIGN`) · IT·소프트웨어(`CSL_IT`) · 제조·생산(`CSL_MANUFACTURE`) · 유통·무역(`CSL_TRADE`) — 사업자 인증 + 축별 입점 승인만 보는 일반 업종.
상담 축은 **공개 20 · 준비 중 2(법률 · 세무) · 보관 2(카드 · 금융)**. 소개장터의 같은 분야와는 별개입니다.

## D018 상담 신청 흐름 · 축별 입점

| API | 권한 | 하는 일 |
|---|---|---|
| `GET /api/v1/consult/categories` | 누구나 | 상담 업종(공개 · 준비 중)과 받을 수 있는 인증업체 수 |
| `POST /api/v1/consult/requests` | 누구나(로그인 없음) | 상담 신청 + 인증번호 발송. 동의 필수, 같은 번호 하루 5건 |
| `POST /api/v1/consult/requests/:id/verify` | 누구나 | 휴대폰 확인 → 리드 생성 → 인증업체 1곳 배분(없으면 NO_PARTNER) |
| `GET /api/v1/partner/axes` | 회원 · 사업자 | 내 축별 입점 상태 |
| `POST /api/v1/partner/axes` | 회원 · 사업자 | 축별 입점 신청(반려된 축만 재신청) |
| `GET /api/v1/admin/partner-axes` | 관리자 | 입점 심사 목록 |
| `POST /api/v1/admin/partner-axes/:id/decide` | 관리자 | 승인 · 반려(사유 5자 이상, 부동산은 중개사 인증 필요) |

- 확인 전에는 리드가 없고(INV-12), 연락처는 `consult_requests` 에 암호문으로만 있으며 6개월 뒤 지웁니다.
- 배분 판정은 `v_consult_eligible_partner` · `fn_consult_deliver` 한 곳에 있습니다(상담 축 승인 + 업종 서비스 승인 + 활동 지역 + 미납 한도 + GATED 자격).
- 알림톡 연동 전: 개발 환경에서만 인증번호를 응답(`devCode`)에 싣고, 운영(`NODE_ENV=production`)에서는 신청을 받지 않습니다(`NOTIFY_NOT_READY`).
