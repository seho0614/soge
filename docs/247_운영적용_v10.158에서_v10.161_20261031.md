## 5. 반영 뒤 (대표 · 법무)

1. 「고치기」로 제휴(PARTNER) · 위탁(OUTSOURCE) 약관 새 판을 저장해도 대상 · 알림이 이어짐 — v10.158 에서 하지 말라던 제한이 풀림.
2. 게시할 때 시행일을 **오늘 뒤**로 넣으면 그날까지 「시행 예정」 · 앞 판 유지 · 재동의는 시행일부터. 처음 게시하는 약관(앞 판 없음)은 시행일과 상관없이 바로 지금 판(가입 동의 · AI 켜기 조건).
3. 법무 검토 묶음 docs/242 **§2 #3** — 코드는 제14조대로(시행일부터 재동의). 법무가 「게시 즉시 재동의」가 맞다고 하면 관 관리 › 약관 › 「재동의 시점」 스위치만 바꿈(SUPER · 감사 기록).
4. 게시는 운영 화면 「약관」 에서만(대표 · SUPER). `publish-terms.sh` · `npm run terms:publish` 는 쓰지 않음.
