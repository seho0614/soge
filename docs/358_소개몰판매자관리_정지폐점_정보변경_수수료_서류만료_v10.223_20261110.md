# 358. 소개몰 판매자 관리 — 정지 · 다시 열기 · 이용 제한 · 폐점 · 정보 변경 요청 · 수수료율 · 서류 만료 알림 · 신청 스위치 나누기 — v10.223 (2026-11-10)

> 계기: 같은 점검(docs/357) · 대표 판매자 권한 「ADMIN · SUPER 만」 · 허가증 만료 「알림만(자동 정지 없음)」(11/9).
> **마이그레이션 1개 D193(230 → 231)** · 새 API 9개(판매자 4 · 운영 5) · 정기 작업 1개 · 설정 1개.

## 1. 전에 없던 것 → 만든 것

| 점검(11/9) | 만든 것 |
|---|---|
| 판매자 정지(PAUSED) · 이용 제한(BLOCKED)은 값만 있고 바꾸는 곳이 없음 | 운영 「정지 · 다시 열기 · 이용 제한 · 폐점」 — 사유 필수(DB 도) · 판매자에게 알림 · 감사 기록 `HLT_SELLER_STATUS` |
| 정지해도 판매 중 상품이 그대로 팔림 | DB 트리거가 따라감 — ACTIVE 에서 벗어나면 판매 중 상품 STOPPED(표시 `off_by_seller_at`) · PAUSED → ACTIVE 면 그때 내린 것만 하나씩 다시 판매(판매 조건이 안 맞는 것은 내린 채로 · 상품 하나가 막혀도 다시 열기는 됨) |
| 판매자가 그만둘 길 없음 | 판매자센터 「폐점(판매자 탈퇴)」 — 진행 중 주문(결제 ~ 배송 완료) · 처리 안 끝난 취소 · 반품 · 지급 안 끝난 정산서 · 정산 안 된 구매 확정 주문이 있으면 막음(미리 보여 줌) · 상품 모두 내림 · 다시 입점은 새로 신청 |
| 승인 뒤 정보를 바꿀 길 없음 | 「정보 변경 요청」 → 운영 승인 · 반려(사유) — 상호 · 대표 · 사업자번호 · 통신판매업 · 전화 · 반품지 · 주소 · 서류(새 유효기간). 판매자당 대기 1건(DB) |
| 판매자별 수수료율을 승인 때만 정함 | 운영 「수수료율」 — 이 판매자만 · 비우면 갈래 기본값 · 사유 필수 · 기록 `hlt_seller_rate_changes` · 알림. 수수료는 주문 때 박히므로(B075) **새 주문부터** |
| 서류 유효기간을 보는 곳이 표의 숫자뿐 | 정기 작업 `seller_license_watch` 매일 09:00 — 만료 30일 · 7일 전 판매자 알림 · 만료일(지난 것 포함) 판매자 알림 + 운영 알림 `SELLER_LICENSE_EXPIRED` 한 번. **자동 정지 없음**(대표 「알림만」) |
| `mall.tenant` 하나가 신청 받기 · 판매 열기를 같이 함 | `mall.tenant_apply`(신청 받기) 새로 · `mall.tenant` 는 판매 열기로만(DB 판매 문). 지금 값을 그대로 옮김(운영 둘 다 off). 켜기는 둘 다 SUPER · 입점 약관 게시 뒤. 중요 설정 바뀜 알림에 더함 |

## 2. 상태와 움직임

| 지금 | 운영이 할 수 있는 것 | 판매자 |
|---|---|---|
| ACTIVE | 정지 · 이용 제한 · 폐점 · 수수료율 | 정보 변경 요청 · 폐점 |
| PAUSED | 다시 열기 · 이용 제한 · 폐점 · 수수료율 | 정보 변경 요청 · 폐점(판매자센터는 열림 · 정지 사유 보임) |
| BLOCKED | 폐점(→ 다시 신청 가능) | 다시 신청 불가 · 사유 보임 |
| CLOSED(새) | — | 새로 신청(심사부터) · 사유 보임 |

## 3. API

| API | 권한 | 내용 |
|---|---|---|
| GET /me/health/seller/account | 판매자 | 정지 사유 · 최근 정보 변경 요청 · 폐점을 막는 것 |
| POST /me/health/seller/change-request · …/cancel | 판매자 | 요청(409 CHANGE_PENDING · 422 NO_CHANGE) · 거두기 |
| POST /me/health/seller/close | 판매자 | 폐점(409 SELLER_OPEN_WORK) |
| GET /admin/health/sellers/change-requests · POST …/{id}/decide | ADMIN · SUPER | 바꿀 값 · 지금 값 나란히 · 승인(반영 · 서류 확인) · 반려(사유) |
| GET /admin/health/sellers/{id}/history | ADMIN · SUPER | 상태 사유 · 수수료율 기록 · 요청 · 폐점 막는 것 |
| POST /admin/health/sellers/{id}/status | ADMIN · SUPER | PAUSE · RESUME · BLOCK · CLOSE + 사유 |
| POST /admin/health/sellers/{id}/commission | ADMIN · SUPER | 수수료율(null = 기본) + 사유(409 SAME_RATE) |
