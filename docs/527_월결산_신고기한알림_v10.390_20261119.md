# 527. 월 결산 요약 · 신고 기한 알림 (v10.390 · 2026-11-19)

> ⑪ 세 번째(D244). 대표 11/19 「월 결산 요약 · 신고 기한(10일 · 25일) 3일 전 · 마감 안 한 달 알림」.

## 1. 결론

- 운영 화면 **회계 › 월 결산**(SUPER · PAYOUT · 처음 지난달): 그 달 전표 수 · 매출 · 비용 · 이익 · 부가세 · 원천세 · 들어옴 · 나감 · 마감 여부.
- **마감 전 할 일** 4줄 — ① 자동 전표 실패 없음 ② 통장 줄 모두 맞춤(은행 맞추기) ③ 세금계산서 발행 끝 ④ 월 마감. 줄마다 「어디서」.
- **신고 기한** — 원천세 **매월 10일**(지난달 지급분) · 부가세 **`acct.vat_months` 의 25일**(처음 1 · 4 · 7 · 10월). 주말 · 공휴일이면 **다음 영업일**(공휴일 표 `public_holidays`).
- 정기 작업 **`acct_deadline`(매일 09:15)** — 기한 **N일 전**(`acct.deadline_days_before` 처음 3)부터 운영 알림 **ACCT_DEADLINE**(같은 기한은 한 번 · 하루 남으면 CRITICAL · 기한이 지나면 저절로 풀림). 매달 **`acct.close_by_day`(처음 10일)** 뒤에도 지난달을 마감하지 않았으면 **ACCT_UNCLOSED**(그 달 한 번 · 마감하면 풀림 · 전표 시작 달 전은 빼고). 끄기 `acct.deadline_alert` off.
- 기한 날짜는 세법 기본 — **세무사 확인 필요**(연장 · 특례가 있으면 설정으로 달 · 날을 바꿈).

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D244** | 설정 `acct.deadline_alert` · `acct.deadline_days_before` · `acct.vat_months` · `acct.close_by_day` · 정기 작업 `acct_deadline` |
| API | `GET /admin/acct/month?ym=` · `GET /admin/acct/deadlines` |

| 운영 화면 | 회계 › **월 결산**(SB-ADM-ACC-050 · 회계 메뉴 첫 탭) |
