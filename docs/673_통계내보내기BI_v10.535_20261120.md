# 673. 통계 내보내기 BI (v10.535 · 2026-11-20)

## 1. 결론
회사 숫자를 **개인 식별 없이** 하루 단위로 모아(`bi_daily_metrics`) 운영 화면에서 보고, **CSV(내려받기 승인)** 로 받고, 외부 BI 도구(메타베이스 · 태블로 · 엑셀 파워 쿼리 등)가 **읽기 전용 보기(bi 스키마)** 로 연결할 수 있게 합니다. 계정 · 이메일 · 휴대폰 · IP · 이름 칸은 만들지 않습니다. **DB 역할(ROLE) · 권한(GRANT)은 마이그레이션이 만들지 않습니다** — 읽기 계정은 운영 서버에서 사람이 만듭니다(5절). 위치: **통합 현황 › 통계 내보내기(BI)** · SB-ADM-DTX-010.

## 2. 지표(bi_metric_defs · 13개)
| 지표 | 이름 | 단위 | 나눔 | 원본 |
|---|---|---|---|---|
| SIGNUP | 가입 | COUNT | — | accounts.created_at |
| LISTING_NEW · REQUEST_NEW | 매물 · 요청 등록 | COUNT | 관 코드 | listings · requests.created_at(초안 포함) |
| DEAL_NEW · DEAL_CONFIRMED | 거래 시작 · 확정 | COUNT | — | deals.created_at · confirmed_at |
| LEAD_NEW | 상담 리드 | COUNT | — | leads.created_at |
| POST_NEW | 소개광장 글 | COUNT | 게시판 | posts.created_at |
| INQUIRY_NEW | 1:1 문의 | COUNT | 문의 종류 | inquiries.created_at |
| ORDER_PAID · ORDER_AMOUNT | 소개몰 결제 주문 · 금액 | COUNT · KRW | — | hlt_orders(결제 · 준비 · 발송 · 배송 끝) — ⑳ 추세 그래프와 같은 셈 |
| SITE_VIEWS · SITE_ENTRIES · GOAL_REACH | 화면 보기(추정) · 첫 화면 · 전환 | VIEW · COUNT | 목표 | D274 site_usage_daily · goals(켜진 날만) |

- 날짜는 **한국 날짜**(`AT TIME ZONE 'Asia/Seoul'`). 나눔 값이 글자 모양(`^[A-Za-z0-9_.:/-]{1,40}$`)이 아니면 `OTHER`, 비면 `-`.
- `fn_bi_daily_build(from, to)` — 그 기간 줄을 지우고 다시 셈. **지표마다 따로 막아**(표 · 칸이 없으면 그 지표만 건너뜀) 하나가 실패해도 나머지는 셈.
- 정기 작업 **bi_daily(매일 04:50)** — 어제까지 3일 다시 셈(늦게 들어온 확정 · 취소 반영) · `bi.keep_days`(처음 1100일) 지난 줄 지움. 다른 셈과 겹치면 건너뜀(advisory lock · 화면은 409 `BI_BUSY`).

## 3. 작은 칸 가림
| 자리 | 숫자 |
|---|---|
| 운영 화면 표(GET /admin/bi/daily) | 정확한 숫자(운영 화면 안) |
| **bi 보기 · CSV**(밖으로 나가는 것) | 나눔 줄(dim 이 있는 줄)의 값이 `bi.min_cell`(처음 3) 미만이면 **비움** · `suppressed = true / Y` |

나눔이 없는 전체 합(예: 하루 가입 1명)은 사람을 가리키지 않아 가리지 않습니다. `bi.min_cell` 0 이면 가리지 않음 · 고치기 SUPER(사유 · 설정 바뀜 기록).

## 4. API · 화면
| API | 권한 | 설명 |
|---|---|---|
| GET /admin/bi | ADMIN | 지표 목록 · 집계 상태 · 설정 · bi 보기와 칸 · 개인 식별처럼 보이는 칸(`v_bi_pii_columns` · 늘 0) |
| GET /admin/bi/daily?from&to&metrics | ADMIN | 기간 400일까지(비우면 지난 30일) · 지표마다 합 · 나눔마다 합 |
| GET /admin/bi/export?from&to&metrics&ticket | ADMIN · **내려받기 승인 BI_DAILY** | CSV(day · metric · label · unit · dim · value · suppressed) · 승인 뒤 24시간 한 번 |
| POST /admin/bi/run | ADMIN · 감사 BI_RUN | 다시 셈(31일 · 오늘까지) |
| PUT /admin/bi/settings | SUPER · 감사 BI_SETTING | 작은 칸 가림 0 ~ 20 · 보관 400 ~ 3650일 · 사유 |

CSV 는 개인정보가 없지만 회사 숫자가 밖으로 나가므로 기존 내려받기 승인(D238 · 위험감지 › 감사 › 「내려받기 승인」)을 그대로 씁니다.

## 5. BI 도구 연결 — 운영 서버에서 사람이 할 일(마이그레이션은 하지 않음)
1. **대표 승인** 뒤, 운영 DB 관리자 계정으로 읽기 전용 계정을 만듭니다(비밀번호는 비밀 보관소 · 이 문서 · 저장소에 적지 않음).
   ```sql
   CREATE ROLE sgb_bi LOGIN PASSWORD '********' CONNECTION LIMIT 3;
   ALTER ROLE sgb_bi SET default_transaction_read_only = on;
   ALTER ROLE sgb_bi SET statement_timeout = '60s';
   GRANT CONNECT ON DATABASE <운영 DB 이름> TO sgb_bi;
   GRANT USAGE ON SCHEMA bi TO sgb_bi;
   GRANT SELECT ON ALL TABLES IN SCHEMA bi TO sgb_bi;
   ALTER DEFAULT PRIVILEGES IN SCHEMA bi GRANT SELECT ON TABLES TO sgb_bi;
   REVOKE ALL ON SCHEMA public FROM sgb_bi;
   ```
2. bi 보기는 **보기 주인 권한으로 원본을 읽으므로**(PostgreSQL 기본 · security_invoker 끔) 읽기 계정에 public 표 권한을 주지 않습니다 — 원본 표(계정 · 주문 등)는 볼 수 없습니다.
3. 접속 길: RDS 보안 그룹은 **BI 도구 서버 IP 한 곳만**(또는 SSH 터널) · 공개 접속 금지 · TLS(`sslmode=require`).
4. 연결 뒤 확인: `SELECT * FROM bi.v_build_state;` · `SELECT count(*) FROM public.accounts;` 가 **권한 없음**이어야 함.
5. 끊을 때: `REVOKE ... ; DROP ROLE sgb_bi;` — 운영 화면에는 계정 · 비밀번호 칸이 없습니다.

| 보기 | 칸 |
|---|---|
| bi.v_metrics_daily | day · metric · dim · value · suppressed |
| bi.v_metric_catalog | metric · label_ko · unit · dim_label · source_ko · sort |
| bi.v_site_usage_daily | day · path · views · entries · engaged · est_views |
| bi.v_site_usage_goals | day · goal · entry_path · n |
| bi.v_build_state | last_day · built_at · row_count |

## 6. 처리방침 고칠 곳
**새로 모으는 개인정보 없음**(기존 표를 숫자로만 묶음 · 화면 사용 통계 D274 는 이미 처리방침 절차를 따름) · **외부 제공 없음**(BI 도구는 회사가 운영하는 도구이고 개인 식별 정보가 없음). 지금 범위는 **법무 확인 끝(11/20 · 11/21 대표)**. 나중에 외부 클라우드 BI(SaaS)를 쓰게 되면 「처리 위탁」 해당 여부만 다시 확인(숫자만이라 해당 없을 가능성이 큼).

## 7. 위험 · 확인
1. 지표 원본 칸이 바뀌면 그 지표만 비어 보임(오류 아님) — 운영 화면 「집계 상태」와 지표 합으로 확인.
2. 큰 기간 다시 셈은 31일까지(운영 부하) · 정기 작업은 3일.
3. bi 스키마는 public 밖 — 문서 도구(DB 목록)가 public 만 읽으면 보기 5개는 목록에 안 나옴(정상).
