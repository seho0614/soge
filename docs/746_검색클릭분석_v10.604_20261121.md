# 746 검색 클릭 분석(익명 · 순위 자료) — v10.604 (17차 ⑳ · 2026-11-21)

## 1. 결론
- 사용자 웹 통합 검색 결과(/search)에서 매물 줄을 누르면 **검색어 · 매물 번호 · 순위(광고 줄 제외) · 관 탭** 만 보냄 → 서버는 **날 × 정규화 낱말 × 관 × 순위 수** 와 **날 × 낱말 × 매물 수** 만 더함.
- 회원 · 방문자 식별 없음: 계정을 읽지 않음 · IP 는 1분 요청 수 제한에만 메모리 · 쿠키 · 방문자 번호 · 브라우저 정보 저장 없음 · DNT · GPC 면 보내지 않고 받지 않음.
- 노출 순위 · 광고 과금에 쓰지 않는 **운영 참고 자료**. 스위치 `lsq.search_click` 처음 **off** · 보관 `lsq.search_click_keep_days`(180일). 처리방침 변경 필요 없음으로 봄(개인정보 없음) — 법무 확인 권함.

## 2. 재사용
| 기존 | 어떻게 |
|---|---|
| 검색어 집계 search_term_stats · logTerm(v10.31) | 같은 손질(소문자 · fn_search_normalize · 숫자 3자리 · @ · 제한업종 버림) · 운영 표에 누적 검색 수 나란히 |
| 회원 화면 사용 통계(v10.508 site-usage) | 보내기 방식(sendBeacon) · 로봇 · DNT · 요청 수 제한 모양 |
| 못 찾은 낱말(D228) | 0건 낱말은 그쪽 그대로(클릭은 결과가 있을 때만) |

## 3. DB
- `lsq_search_clicks(day, term, gwan, pos, clicks)` · `lsq_search_click_items(day, term, listing_id, clicks)` · 함수 `lsq_fn_search_click_add` · 사람 칸 없음(CHECK: 숫자 3자리 · @ 든 낱말 막음).

## 4. API · 화면
| 주소 | 역할 |
|---|---|
| POST /site/lsq/search-click | 공개(site 구역 · @Roles 없음) · 받지 않으면 ok:false + 까닭(OFF · DNT · BOT · RATE · TERM) |
| GET /admin/lsq/search-clicks?days= | 클릭 · 낱말 수 · 평균 순위 · 1 ~ 3위 비율 · 낱말 100 · 순위 분포 · 많이 눌린 매물 50 |
- 사용자 웹 `SB-HOM-LSQ-030`(검색 결과 안 LsqClickBeacon) · 운영 `SB-ADM-LSQ-030`.
