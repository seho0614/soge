# 398. 소개몰 입점(판매자) 이용약관 1.0 — 빈칸 묶음 · 채울 안 · 법무에 물을 것 (2026-11-13 · 문서만)

> 대표 「다음 개발」 → 「입점 약관 빈칸 묶음」 · 계획 「승인 + 통과하면 병합」(11/13).
> 성격: **문서만**(코드 · DB 바뀌지 않음). 운영의 초안(`HLT_SELLER 1.0` · 상태 초안)을 **게시하지 않습니다.** 법무 · 세무에 보낼 묶음입니다.
> 기준 글: 저장소 원문(`prisma/migrations/D155_mall_tenant_apply` 의 초안). 운영 초안은 운영 화면에서 고쳤을 수 있으니, 운영 「고치기」 화면에서 **같은 자리만** 고치십시오(terms-publishing #25).

## 1. 결론

1. 빈칸 · 확인할 곳은 **10곳**입니다. 그중 3곳(권고값)은 안을 그대로 써도 되고, **대표가 정할 것 2곳**(수수료율 2칸)과 **법무 · 세무에 물을 것 4곳**이 남습니다.
2. 이미 대표가 정한 결정 A(판매대금은 판매자에게 직접) · C(반품 배송비 왕복 6,000원 상한) · D(정산 주 1회)는 초안 본문에 들어 있습니다(mall-return-refund #15).
3. **제2조 2호 「판매자 = 사업자」는 제6조 1항(개인도 판매자)과 부딪힙니다.** P2P 원칙(p2p-individual-access)에 맞게 「회원(개인 또는 사업자)」으로 고치는 안을 냅니다(partner-center-account-basis 미정 #9).
4. 게시해도 입점 신청은 열리지 않습니다. 입점 신청 스위치(`mall.tenant`)는 **결제대행사 하위가맹점 · 지급대행 계약 뒤에** 따로 켭니다.

## 3. 법무 · 세무에 물을 것

| # | 물음 | 왜 |
|---|---|---|
| 1 | 제2조 2호를 「회원(개인 또는 사업자)」으로 고쳐도 되는가 · 개인 판매자에게 더 알려야 할 의무(전자상거래법 신원정보 표시 등)가 있는가 | 제6조 1항 · P2P 원칙과 맞추기 |

| 3 | 제5조 통신판매중개자 고지 문구 — H-2 회신 문안 그대로 써도 되는가 | 중개자 책임 범위 |

## 4. 게시 순서 (정확한 위치)

1. 법무 · 세무 답을 받고 수수료율을 정함
2. 운영 화면 맨 위 **관 관리** › 탭 **「약관」** › 「소개몰 입점(판매자) 이용약관 1.0」(초안) 줄의 「고치기」
3. 2절 표대로 10곳을 고치고 「발행 전 할 일」 목록을 지움 → 저장
4. 「바뀐 곳 보기」(v10.263)로 고친 줄만 바뀌었는지 확인
5. 「게시」 — 빈칸(〔〕)이 남아 있으면 단추가 눌리지 않습니다(TERM_HOLES). **첫 판이라 게시 순간부터 지금 판**입니다(terms-publishing #30)
6. 수수료율은 운영 화면 맨 위 **소개몰** › 탭 **「소개몰 판매자」**에서 같은 값인지 확인
7. 입점 신청 켜기(`mall.tenant`)는 결제대행사 하위가맹점 · 지급대행 계약 뒤 — **소개몰** › 탭 **「소개몰 판매자」** › 맨 위 「입점 열기 준비」 점검(v10.229)이 모두 「됨」일 때
