## 1. 바뀐 것 (정확한 위치)

| 줄 | 보여 주는 것 |
|---|---|
| 게시 | 지금 게시 · 예약(시각부터) · 초안(어디에도 안 나옴) · 끝 날짜 |
| 볼 수 있는 사람 | 고른 등급 이름 · 「전체 공개」면 「로그인 안 한 사람도」 |
| 나오는 곳 | 소개광장 › 공지(고객센터 › 공지사항도 이리로) · **상단 고정**이면 메인 첫 화면 공지 띠 · 소개광장 「전체」 맨 위(고정 최근 2건) · 「관리자」만이면 「사용자 웹에 나오지 않음」 |

| 휴대폰 폭 | 360px 상자에 제목 · 본문 모양 |
