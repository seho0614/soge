# 407. 수수료율 인상 예약의 별도 공지사항 — v10.278 (2026-11-13)

> 대표 결정(11/13): 「별도의 공지사항을 등록하여 공지를 한다」 → 「예약 때 공지 초안 자동」 → 계획 「승인 + 통과하면 병합」.
> 입점 약관 제17조 4항 「공지하고 개별 통지」 중 **공지**를 별도 공지사항으로 함(개별 통지는 v10.277 판매자 알림).
> **마이그레이션 1개(246 → 247)** — D209. v10.277(docs/406) 위에 만듦.

## 1. 바뀐 것

| 곳 (정확한 위치) | 내용 |
|---|---|
| 요율 예약(v10.275 의 세 곳 「바꾸기」) | 예약하면 **소개몰 공지 초안**을 같이 만듦 — 제목 「판매 수수료율 변경 안내(시행일 시행)」 · 본문(대상 · 지금 → 새 요율 · 시행일 0시 이후 주문부터 · 사유 · 약관 제17조 4항) · 게시 안 됨 |
| 운영 화면 맨 위 **소개몰** › 탭 **「소개몰 정산」** › **「요율 변경 예정」** 상자 › 「공지」 칸 | 게시 전이면 빨간 **「공지 안 함」** + **「공지 게시」** 단추 → 본문 확인 창 → 게시(맨 위 고정). **게시한 날 + 31일 > 시행일**이면 단추 대신 「30일이 남지 않음 — 취소하고 다시 예약」(API 422 `NOTICE_LATE`). 게시 뒤 「게시 날짜」 |
| 같은 상자 · 예약 「취소」 | 예약 안내를 **이미 게시했으면** 「판매 수수료율 변경 취소 안내」 초안을 만들고, 같은 칸 **「취소 안내 게시」** 로 게시 |
| 사용자 웹 **소개몰 판매자센터**(`/health/seller/center`) | 맨 위 예정 줄 아래 **「소개몰 공지」**(게시된 소개몰 공지 · 고정 먼저 · 최근 5 · 펼쳐 봄 · 한 · 영) |
| 사용자 웹 **파트너센터 공지**(`/partner/notices` · `/partners/notices`) | 게시한 공지가 여기에도 보임(본사 공지 목록 그대로) |
| 정기 작업 `hlt_rate_schedule`(매일 00:05) | 예약한 지 **하루가 지나도 공지를 게시하지 않은** 예정 예약이 있으면 운영 알림 **`RATE_NOTICE_MISSING`(경고)** — 운영 화면 › 운영 알림 |

### 바로잡은 것

- 계획 때 「게시하면 사용자 웹 메인 「메인 공지」에 보임」이라고 했으나 **틀림** — 공지(notices)는 사용자 웹에서 **파트너센터 공지에만** 보였고, 운영 화면 「메인 공지」는 운영자용 목록. 그래서 **판매자센터에 「소개몰 공지」를 더함**.
- v10.275 에서 알림 종류 표(`notification_event_policies`)에 `SELLER_RATE_SCHEDULED` · `SELLER_RATE_SCHEDULE_CANCELED` 가 빠졌음 → D209 에서 더함(내 알림 화면의 이름 · 수신 거부 불가).

### 공지를 게시하지 않으면

예약은 그래도 시행일에 적용됨(개별 알림은 예약 때 이미 감). 「공지 없으면 적용 안 함」은 넣지 않음(대표 승인 11/13 · 예약이 걸려 남는 경우가 생김) — 대신 빨간 표시 · 운영 알림으로 빠뜨림을 막음.

## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `POST /admin/health/rate-schedules/{id}/notice` | ADMIN · SUPER | 예정 예약 → 예약 안내 게시(31일 · 422 `NOTICE_LATE`) · 취소 예약 → 취소 안내 게시 · 409 `NOTICE_DONE` · 감사 `HLT_RATE_NOTICE_PUBLISH` |
| `GET /admin/health/rate-schedules` | ADMIN · SUPER | 공지 칸 더함(`noticeId` · 제목 · 본문 · 게시 시각 · 취소 안내 · `noticeLate`) |
| 세 곳 요율 바꾸기 · 예약 취소 | ADMIN · SUPER | 응답에 `noticeId` · `cancelNoticeId` |
| `GET /me/health/seller/center` | 판매자 | `notices`(소개몰 공지 최근 5) 더함 |

## 3. DB (D209_hlt_rate_notice)

| 것 | 내용 |
|---|---|
| `hlt_rate_schedules` | `notice_id` · `cancel_notice_id`(→ `notices`) — 예약 내용 잠금(v10.275)은 그대로 |
