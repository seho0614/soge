# 532. 직판 재고 수불부 · 매출원가 전표 (v10.395 · 2026-11-19)

> ⑫ 네 번째(D245). 대표 11/19 「직판 재고 수불부 — 이동평균 · 매출원가 전표」(계획 「승인 + 통과하면 병합」).

## 1. 결론

- 운영 화면 **회계 › 재고**(SUPER · PAYOUT): 소개몰 **직판 상품 옵션마다** 회계용 수량 · **이동평균 단가** · 재고 금액 · 판매용 재고(쇼핑몰 수량)와 차이 · 원가 0 으로 나간 줄 수. 상품 이름을 누르면 그 달 수불(들어옴 · 나감 · 남은 수량 · 남은 금액 · 평균).
- **판매용 재고 수량(hlt_product_options.stock)은 그대로** 둡니다(주문 때 빠지고 취소 · 반품 때 돌아옴 · D002 · D027). 수불부는 그 옆의 **원가 장부**입니다 — 단위는 옵션(주문 · 재고 단위와 같음).
- 들어옴 · 나감 네 가지

| 종류 | 언제 | 단가 |
|---|---|---|
| 입고 IN | 운영자가 적음(SUPER · PAYOUT) | 입력(공급가 · 0 보다 큼) |
| 판매 출고 OUT_SALE | 정기 작업 `acct_stock` — **직판 결제 승인 때**(소개몰 직판 매출 전표 MALL_SALE 과 같은 근거 · 주문 줄마다) | 그때 평균 단가 |
| 취소 · 반품 반입 RETURN | 정기 작업 — 판매용 재고가 돌아온 주문(`restocked_at`) | 나갈 때 원가 그대로 |
| 실사 조정 ADJUST | SUPER · 사유 | 늘림 = 지금 평균(재고가 없으면 입력) · 줄임 = 평균 |

- **이동평균** — 들어올 때 평균 = (남은 금액 + 들어온 금액) ÷ (남은 수량 + 들어온 수량). 나갈 때는 평균 단가로 원가.
- **재고가 모자란 채 팔리면** 판매는 막지 않습니다 — 남은 만큼만 원가, 모자란 몫은 **원가 0**(zero_cost)으로 남기고 운영 알림 **STOCK_NEGATIVE**(WARN · 풀리지 않은 것이 있으면 더 넣지 않음). 입고를 늦게 적었으면 「실사 조정」으로 맞춥니다.
- **개봉 반품**(restock_skipped = OPENED · 식품 · 화장품 재판매 금지 · D185)은 재고로 돌아오지 않으므로 반입 없음 — 원가는 매출원가에 그대로 남습니다.
- 출고 시점을 「배송 시작」이 아니라 **결제 승인**으로 한 까닭: 직판 매출 전표(MALL_SALE)가 결제 승인 때 잡히므로 매출과 매출원가가 같은 날 · 같은 달에 들어갑니다.
- 계산(남은 수량 · 금액 · 평균 · 원가 0)은 **DB 트리거 `fn_acct_stock_move`** 가 옵션마다 잠그고 합니다. 수불부는 **쌓기만**(고치기 · 지우기 없음 — 실사 조정으로 바로잡음). 직판(DIRECT) 상품만 적을 수 있습니다.

## 2. 전표 (자동 전표 `acct_journal` · 규칙 초안 — 세무사 확인)

| 근거 | 차변 | 대변 | 비고 |
|---|---|---|---|
| STOCK_IN 입고(매입 번호 없음) | 상품(INVENTORY) | 미지급금(AP) | 매입 번호(⑫ 매입 관리)가 있으면 **입고 전표 없음** — 매입 전표가 이미 「상품」으로 잡음 |
| COGS 판매 출고 | 상품매출원가(COGS) | 상품 | 원가 0 출고는 금액 0 이라 전표 없음 |
| COGS_RETURN 취소 · 반품 반입 | 상품 | 상품매출원가 | |
| STOCK_ADJUST 실사 조정 | 늘림: 상품 / 매출원가 · 줄임: 매출원가 / 상품 | | |

전표 날짜 = 수불 날짜(그 달을 마감했으면 오늘 · late) · 시작일(acct.start_on) 뒤만.

## 5. 주의 · 확인할 것

1. **처음 쓸 때** — 지금 남은 실제 재고를 옵션마다 「입고」(단가 = 매입 단가)로 한 번 적어야 원가가 맞습니다. 적기 전 판매는 원가 0 으로 남고 STOCK_NEGATIVE 가 뜹니다.
2. 이동평균 · 계정(상품 146 · 상품매출원가 451)은 초안 — **세무사 확인**. 선입선출(FIFO)로 바꿔야 하면 알려 주십시오(수불부 구조는 그대로 · 계산 함수만 바뀜).
3. 수불 차례는 **들어간 차례(번호)** 입니다 — 지난 날짜로 입고를 적어도 평균은 적은 때부터 바뀝니다.
4. 판매용 재고와 차이가 나면 화면 「차이」 칸이 빨갛게 — 실사 뒤 「실사 조정」.
