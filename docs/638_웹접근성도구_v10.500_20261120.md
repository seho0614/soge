# 638. 웹 접근성 도구 — 글자 크게 · 고대비 (v10.500 · 2026-11-20)

## 1. 결론
사용자 웹 모든 화면 왼쪽 아래에 **「보기 설정」** 단추를 두었습니다. **글자 크기(보통 · 크게 1.15배 · 아주 크게 1.3배)** 와 **대비(보통 · 고대비)** 를 고르면 **이 브라우저에만 기억**합니다(localStorage `sgb_a11y` · 서버로 보내지 않음 · 개인정보 아님). 적용은 `<html data-a11y-font="l|xl">` · `<html data-a11y-contrast="high">` 속성과 **토큰**(upt-tokens.css 에 둔 · sgb-tokens.css 는 디자인 시트 사본이라 그대로 `--sgb-a11y-zoom-*` · `--sgb-hc-*` · `--sgb-focus*`)만으로 하고, 화면이 그려지기 전에 붙여(작은 시작 스크립트 A11yBoot) 깜박이지 않습니다. DB · API 변경 없음.

| 파일 | 뜻 |
|---|---|
| `site/src/components/upt/A11yTools.tsx` | 단추 · 창(글자 크기 · 대비 · 처음대로 · 닫기) · Esc 로 닫고 단추로 돌아옴 · 고른 값은 `aria-pressed` |
| `site/src/components/upt/A11yBoot.tsx` | 저장된 값을 그리기 전에 `<html>` 에 붙임(값을 끼워 넣지 않는 고정 스크립트) |
| `site/src/styles/upt.css` | `html[data-a11y-font] body { zoom }` · 고대비 때 글자 · 줄 · 링크 토큰(디자인 시트 `--sgb-*` · 옛 `--ink` 계열) 진하게 · 링크 밑줄 · 포커스 테두리 3px |
| `site/src/styles/upt-tokens.css`(새 파일 · sgb-tokens.css 는 디자인 시트 사본 그대로 — test_v1052 · 1067 · 1470) | 새 토큰 — 배율 · 고대비 색 · 포커스 색 · 두께 |

## 2. 판단
1. **글자 크게 = body zoom** — 기존 화면 글자가 대부분 px 로 적혀 있어(rem 이 아님) 뿌리 글자 크기만 바꾸면 커지지 않음. zoom 은 2024 년부터 주요 브라우저 모두 지원(파이어폭스 126+) — 오래된 브라우저에서는 무시되고 브라우저 확대(Ctrl +)를 쓰면 됨.
2. **고대비 = 토큰 바꾸기** — 화면 CSS 를 하나하나 고치지 않고 글자 · 줄 · 링크 토큰만 진하게(흰 바탕 검정 글자 · 진한 파랑 링크 · 대비 7:1 넘게 · WCAG 1.4.6 AAA 수준을 목표). 그림 · 관 포인트 색은 그대로.
3. **이 브라우저에만** — 로그인과 묶지 않음(가족 · 공용 PC). 저장이 막힌 브라우저에서도 그 화면에는 적용.
4. 단추 위치 왼쪽 아래 — 오른쪽 아래 AI 상담 단추와 겹치지 않게 · 누를 자리 44px · 인쇄 때 숨김.
