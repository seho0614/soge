# 623. 운영자 해외 접속 경고 (v10.485 · 2026-11-20)

## 1. 결론
운영 역할 계정이 비밀번호로 로그인할 때 **접속 IP 의 나라**를 보고, **허용 나라(처음 KR) 밖이면 긴급 운영 알림 STAFF_LOGIN_ABROAD**(급한 알림 메일 · 텔레그램 대상)를 남깁니다. **막기(security.geo_block)를 켜면 그 로그인을 막습니다**(403 GEO_BLOCKED · 알림 STAFF_LOGIN_ABROAD_BLOCKED). 나라 판별은 **어댑터(외부 연동 16번째 GEOIP)** — 키가 없으면 **NOT_READY**(판별 못 함 · 막지 않음). **처음 꺼짐(security.geo_watch off) · 판별 간주(ASSUME)**. 위치: **위험감지 › 해외 접속 경고** · SB-ADM-SCU-030 · API `/admin/security/geo`.

| 설정 | 처음 | 뜻 |
|---|---|---|
| `security.geo_watch` | off | 운영 역할 로그인마다 나라를 봄 |
| `security.geo_mode` | ASSUME | ASSUME = 묻지 않고 `security.geo_assume_country` 로 봄(점검판 · 사설 IP 도) / LIVE = 업체(GEOIP · 키가 있어야 바꿀 수 있음) |
| `security.geo_assume_country` | KR | 간주 나라 |
| `security.geo_allow` | KR | 허용 나라(쉼표 · **KR 꼭** · 출장 전에 더함) |
| `security.geo_block` | off | 허용 나라 밖 로그인을 막음(경고를 켠 뒤에만) |

| 키 · .env | 어디 | 뜻 |
|---|---|---|
| **`GEOIP_API_KEY`**(새로) | 운영 화면 › 외부 연동 › 「연동 키」(SUPER · 암호화) | 판별 업체 키(8 ~ 512자 일반 모양) |
| `GEOIP_API_BASE` | .env | 주소 틀 — `{ip}` · `{key}` 자리 · https 만 · 처음 `https://ipinfo.io/{ip}?token={key}` |
| `GEOIP_COUNTRY_PATH` | .env | 응답의 나라 칸(처음 `country` · 두 글자 대문자) |
| `GEOIP_TIMEOUT_MS` | .env | 처음 2000(로그인을 오래 붙잡지 않게) |

## 2. 판정
1. 비밀번호가 맞고 계정이 활동 중인 **운영 역할(SUPER · ADMIN · REVIEWER · PAYOUT · PARTNER_MAL · PARTNER_AFF · ACCOUNTANT)** 만 — 회원은 보지 않음.
2. 나라 = ASSUME(간주) · 캐시(LIVE 결과 · IP 지문 sha256 · 7일) · LIVE(업체). 사설 IP · 키 없음 · 업체 오류 → **판별 못 함(UNKNOWN) — 막지 않음**.
3. 허용 나라 밖 → 기록(ALERT) + **STAFF_LOGIN_ABROAD(CRITICAL)** · 막기 on 이면 기록(BLOCKED) + **STAFF_LOGIN_ABROAD_BLOCKED(WARN)** + 403 **GEO_BLOCKED**(비밀번호는 맞았지만 증표를 주지 않음).
4. 기록 `sec_geo_events` — **IP 앞 두 마디 · 나라 · 판별 출처 · 판정**만(원래 IP 는 DB · 로그에 없음) · 고치지 않음 · **1년 지나면** 정기 작업 `sec_daily_purge`(매일 04:55)가 지움 · 캐시 30일.
5. 이 판정은 ㉒ 접속 인증(허용 IP · 인증번호 · D195) · 낯선 로그인 알림(D179)과 **따로** 돎 — 셋 다 켜면 모두 적용.

## 3. 판단
1. **판별 못 하면 막지 않음** — 업체 장애 · 키 만료가 운영자 전원 잠금이 되지 않게(경고 · 「판별 못 함」 수는 화면에서 봄).
2. **허용 나라에 KR 꼭** — 막기를 켠 채 KR 을 빼면 국내 로그인이 모두 막히므로 서버가 막음(422 GEO_ALLOW_KR).
3. 막기는 SUPER 도 막음 — 해외 출장 전에 허용 나라에 그 나라를 더하고, 돌아오면 뺍니다. 모두 막혔을 때는 서버에서 `security.geo_block` off(설정 · 30초).
4. 업체 판별은 VPN · 로밍 · 클라우드 IP 에서 틀릴 수 있음 — 경고는 「확인할 일」로 봄.

## 4. 켜는 순서(운영 · 대표 승인 뒤)
1. 업체 선정 · 법무 확인(5절) → 2. 연동 키 `GEOIP_API_KEY` · 필요하면 `GEOIP_API_BASE` → 3. 「판별 시험」(8.8.8.8 → US 등) → 4. 방식 LIVE → 5. 경고 켜기 → 6. 1 ~ 2주 기록을 보고(필요하면) 막기.

## 5. 확인 필요(법무 · 대표)
1. **업체에 IP 를 보내는 것** — 개인정보 처리 위탁 · (해외 업체면) **국외 이전** 고지 · 처리방침 반영 여부. 국내 업체(한국인터넷진흥원 후이즈 OpenAPI 등)를 쓰면 주소 틀만 바꿈(`GEOIP_API_BASE` · `GEOIP_COUNTRY_PATH`) — **공식 안내서의 주소 · 칸 이름은 확인하지 못했습니다(2026-11-20)**.
2. 업체 약관(무료 한도 · 상업 이용) · 키 유효기간.
3. 운영자에게 「해외 로그인 경고 · 막기」 사내 고지.
