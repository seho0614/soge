# 772. 미리 검사 · 전체 점검 스크립트를 저장소로 — v10.628 (2026-11-22)

## 1. 결론

- 묶음마다 세션 임시 폴더에 `preNNNN.sh` · `mtNNNN.sh` · `pipeNNNN.sh` 를 새로 만들어 돌렸습니다. 세션이 바뀌면 사라지고, 판마다 손으로 경로 · 시험 이름을 고쳤습니다.
- 이번 판부터 두 스크립트를 **sgb-infra 저장소 qa/** 에 둡니다.
  1. `qa/pre_check.sh <core 작업 트리> [infra 작업 트리] [결과 폴더]` — 형 검사 3종 · 버리는 DB 마이그레이션(두 번 · INV-9 · INV-11 · 정규식 255) · verify-docs · check-acl · 컨트롤러 getter · 옛 시험 코드 부분 main ↔ 작업 트리 비교. `MT_SQL` 로 새 함수 확인 SQL 을 넘길 수 있음.
  2. `NEW="…" HOSTNEW="…" qa/full_check.sh <갈래> [결과 폴더]` — realcheck fresh → 기능 점검 → 새 시험 → 회귀(기대 수는 판정 줄 수를 직접 셈) → main down · 결과 폴더에 `summary.txt`.
- 점검판 포트 · 확인판 · RDS 는 그대로 쓰지 않습니다. 버리는 DB 는 자기 네트워크 · 포트를 열지 않고 끝나면 지웁니다(trap).
