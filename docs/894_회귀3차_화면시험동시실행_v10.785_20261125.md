# 894. 회귀 3차 — 화면 시험 동시 실행(UI_LANE=N) — v10.785 (2026-11-25)

## 1. 결론

- 회귀 630개가 152분 걸리고, 그중 「혼자」 단계가 123분(402개)입니다. 혼자 단계의 대부분은 **화면 시험(playwright) 297개 · 약 90분**입니다. 지금까지는 화면 시험을 하나씩만 돌렸습니다(UI_LANE=0).
- 이번 판부터 `UI_LANE=N`(2 · 3 …)이면 화면 시험을 동시 단계에서 **N개까지 함께** 돌립니다.
  1. 화면 시험끼리도 **설정 키 잠금(set:…) · 정기 작업 잠금(job)은 그대로** — 같은 설정을 만지는 화면 시험은 같이 안 돕니다.
  2. 공유 회원 · 약관 게시 · 로그인 잠금 · 도커처럼 「혼자」 판정(SOLO)인 시험은 예전처럼 혼자 단계에서 하나씩.
  3. 동시 실행 수(PAR)가 화면 자리 수 이하이면 `PAR = N + 1` 로 늘려 화면 시험만으로 자리가 꽉 차지 않게 합니다.
  4. `UI_LANE=1` 은 예전 「화면 한 줄」, `UI_LANE=0`(기본)은 예전과 같습니다.
- 같은 계정 동시 로그인은 막지 않음(세션 수 제한 없음 — `src/modules/identity` 확인)이라 화면 시험이 admin@x.com 으로 함께 로그인해도 서로 끊지 않습니다.
- 기대: 혼자 단계 123분 → 약 35분(SOLO 130개), 화면 시험 90분은 동시 단계에서 N 줄로 나눔 → 전체 약 152분 → **90 ~ 100분(N=2)**. 실제 값은 묶음 6 전체 점검에서 `UI_LANE=2` 로 재어 이 문서에 적습니다.
