| 작업 | 해소되는 항목 | 남는 수 |
|---|---:|---:|
| — | | **18** |
| **① 약관 6종 발행** | TERM 3 + FOOTER 5 = **8** | **10** |

**세 작업 모두 코드가 아닙니다.** 법무 회신 · 사업자 등록 · 외부 계약입니다.

# 1. 작업 ① — 약관 6종 발행

## 1-1. 왜 8건이 한 번에 풀리나

약관 3종이 **필수**라 TERM 에 잡히고, 푸터 링크 5개가 **그 약관을 목적지로** 하기 때문입니다. 발행하면 `v_footer_links.available` 이 true 가 되면서 함께 사라집니다.

실측:

```
시작            18건
SERVICE 발행  → 16건   (TERM 1 + FOOTER 1)
PRIVACY 발행  → 14건   (TERM 1 + FOOTER 1)
LOCATION 발행 → 13건   (FOOTER 1 · 필수 아님)
MARKETING     → 13건   (푸터 링크 없음)
THIRDPARTY    → 12건   (FOOTER 1)
REFUND 발행   → 10건   (TERM 1 + FOOTER 1)
```

## 1-2. 법무에 물어야 할 것

| 약관 | 판단이 필요한 부분 |
|---|---|
| **이용약관** | **C-07 통신판매중개자 지위** — 이게 정해져야 조항이 확정됩니다 |
| 개인정보처리방침 | 3관 구성이라 **소비자 개인정보 조항을 뺄 수 있는지** |
| **위치기반서비스** | **지역 필터가 위치정보에 해당하는지** — 해당하면 신고 의무가 생깁니다 |
| 제3자 제공 동의 | 소개 과정에서 상대방에게 넘기는 정보 범위 |
| 마케팅 수신 동의 | (표준 문안) |
| 환불 정책 | B-14 법정 기준 |

**C-07 을 가장 먼저 받으십시오.** 이용약관 조항과 통신판매업 신고 대상 여부가 여기 걸려 있고, 신고 대상이면 신고번호 발급에 또 시간이 듭니다.

## 1-3. 발행 방법

`docs/19_개인정보처리방침_초안.md` 가 시스템 상태에서 자동 생성돼 있습니다. **법무 검토 시 이 초안을 근거로 쓰십시오** — 방침 문안과 실제 시스템이 어긋나면 그 자체가 위반입니다.

```bash
# 초안 저장 — 기존 버전을 덮지 않고 새 버전을 만듭니다
curl -X PUT $API/admin/terms/SERVICE \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"version":"1.1","title":"이용약관","body":"제1조(목적) …"}'

# 발행 — 내용과 시행일이 없으면 DB 가 거부합니다
curl -X PATCH $API/admin/terms/SERVICE/publish \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"version":"1.1","effectiveFrom":"2026-11-01T00:00:00Z"}'
```

**막히는 경우**

```
TERM_BODY_EMPTY               내용 없이 발행할 수 없습니다
TERM_EFFECTIVE_DATE_REQUIRED  시행일을 지정하십시오
EFFECTIVE_DATE_IN_PAST        시행일을 과거로 지정할 수 없습니다
```

시행일을 과거로 못 넣는 이유는 **동의 이력의 기준이 되는 날짜**이기 때문입니다.

# 2. 작업 ② — 푸터 법정고지 7건

## 2-1. 항목

| 키 | 내용 | 형식 검증 |
|---|---|---|
| `footer.biz_reg_no` | 사업자등록번호 | `000-00-00000` |
| `footer.mail_order_no` | 통신판매업 신고번호 | `제0000-지역-00000호` |
| `footer.address` | 사업장 주소 | 10자 이상 |
| `footer.phone` | 대표 전화 | 지역번호·대표번호 |
| `footer.hosting` | 호스팅 제공자 | 2자 이상 |
| `footer.ceo_name` | 대표자 성명 | 2자 이상 |
| `footer.privacy_officer` | 개인정보 보호책임자 | 2자 이상 |

## 2-2. 입력

```bash
BIZ_REG_NO=123-45-67890 \
MAIL_ORDER_NO=제2027-서울강남-01234호 \
ADDRESS="서울특별시 강남구 테헤란로 1, 2층" \
PHONE=02-1234-5678 \
HOSTING="Amazon Web Services" \
CEO_NAME=홍길동 \
PRIVACY_OFFICER=김보안 \
npm run open:seed
```

**값이 없으면 실행되지 않습니다.** 기본값을 두지 않은 것이 의도입니다.

## 2-3. ★ 자리표시자를 넣지 마십시오

세 겹으로 막습니다.

```
① 저장 시점   SETTING_PLACEHOLDER: footer.ceo_name에 자리표시자 "대표자명"이 남아 있습니다
② 형식 검증   SETTING_FORMAT: 형식이 올바르지 않습니다. 예: 123-45-67890
③ 오픈 차단   트리거를 우회해 넣어도 v_open_blockers 가 잡습니다
```

**"값이 있는 것"과 "값이 맞는 것"은 다릅니다.** 자리표시자가 그대로 푸터에 나가면 통신판매업 고지 위반입니다.

## 2-4. 전제 조건

| 값 | 선행 |
|---|---|
| 사업자등록번호 | **사업자 등록** |
| 통신판매업 신고번호 | **C-07 신고 대상 확정 → 신고 → 발급** |
| 개인정보 보호책임자 | **실제 지정** (값만 넣는다고 끝이 아닙니다) |

# 3. 작업 ③ — 외부 연동 3종

## 3-1. 오픈을 막는 3종

| 연동 | 없으면 | 리드타임 |
|---|---|---|
| **PG 전자결제** | **매출이 발생하지 않습니다** | 5주 |
| **PASS 본인인증** | INV-7 게이트가 무력합니다 | 6주 |
| **1원 계좌인증** | 정산 계좌를 검증할 수 없습니다 | 4주 |

**차단은 아니지만 필요한 3종** — NTS(2주) · 알림톡(8주) · 050 안심번호(미정).

## 3-2. ★ 발신 IP 등록이 진짜 임계 경로입니다

**6종 전부 화이트리스트를 요구하고 심사에 2~4주 걸립니다.**

```
W2   NAT EIP 고정 → 6종 IP 등록 신청
W6   심사 완료 → 연동 착수 가능
W14  알림톡까지 완료 (최장)
```

**코드보다 IP가 먼저 필요합니다.**

관리자 화면(외부 연동 탭)에서 IP를 한 번 넣으면 **6종에 일괄 반영**되고 상태가 `IP_PENDING` 으로 바뀝니다.

```json
{"egressIp":"3.35.100.200","applied":6}
```

## 3-3. 연동 완료 처리

키는 **Secrets Manager 에 넣고 화면에서는 "등록 완료"만 체크**합니다.

```
NOT_STARTED → CONTRACT → IP_PENDING → TESTING → LIVE
```

`LIVE` 로 바뀌면 오픈 차단에서 빠집니다.

> **DB 에 키를 넣지 마십시오.** 백업·복제본에 전부 퍼집니다.

## 3-4. 선행 결정

| # | 결정 | 막는 것 |
|---|---|---|
| 1 | **PG사 선정** | 5주 리드타임이 시작되지 않습니다 |
| 2 | **알림톡 대행사 선정** | 8주 리드타임 |
| 3 | 050 안심번호 도입 여부 (B-19) | INV-2 위험 해소 |

**1번이 가장 급합니다.** PG 없이는 매출이 발생하지 않습니다.

# 5. 일정 역산

**연동이 최장 14주(알림톡)** 이므로 오픈일에서 거꾸로 계산해야 합니다.

```
오픈일
 ← 2주   최종 점검 · DR 리허설
 ← 4주   prod 구축 · 부하테스트 · 취약점 진단
 ← 14주  외부 연동 완료 (알림톡 기준)
 ← 4주   발신 IP 심사
        ↑ 여기가 시작점 — 약 W2
```

## 지금 해야 할 것

```
① PG사 · 알림톡 대행사 선정          ← 안 하면 리드타임이 시작 안 됨
② C-07 판단 → 사업자 등록 · 통신판매업 신고
③ 법무에 약관 6종 의뢰
④ NAT EIP 고정 → 6종 IP 등록 신청    ← 임계 경로
```

**④가 늦어지면 나머지가 통째로 밀립니다.** 코드는 준비돼 있으니 지금 시작할 수 있습니다.
