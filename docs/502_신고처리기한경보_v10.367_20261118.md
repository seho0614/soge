# 502. 신고 처리 기한 경보 (v10.367 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 회원 활동 한 줄 기록 · ② 개인정보 대량 내려받기 승인 · ③ 신고 처리 기한 경보 · ④ DB 복원 시험 기록 「모두」 → 계획 「승인 + 통과하면 병합」(다섯 번째 묶음 · 운영은 v10.361 ~ 364 와 함께 다음 묶음). 이 문서는 ③. 마이그레이션 **D238**(설정 하나 · v10.366 과 같은 파일).

## 1. 왜

- 매물 · 글 · 댓글 신고가 쌓여도 「오늘 할 일」 수로만 보여 오래된 신고를 놓칠 수 있었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 설정 `ops.report_due_hours` | 처음 24 · 1 ~ 168시간 |
| 정기 작업 `sla_alert`(매시간) | 열린 신고(OPEN · QUEUED)가 기한을 넘으면 운영 알림 **`REPORT_OVERDUE`**(WARN · 하나만) · 0건이면 풂 |
| `GET /admin/todo` | 「신고 처리 대기」 줄에 기한 넘김 수(over) — 첫 화면 「오늘 할 일」에 빨간 표시 |
| 운영 화면 **위험감지 › 운영 알림** | 이름 「신고 처리 기한 넘김」 |

## 3. 시험 (test_v1367)

1. ① 코드 — 설정 · 정기 작업 · 오늘 할 일 · 화면 이름 · 문서 502 · 판 v10.367
2. ② 정기 작업 · API — 기한 1시간으로 두고 2시간 전 신고 → 알림 생김 · 오늘 할 일 over ≥ 1 → 처리 → 풀림 · 설정 되돌림

## 4. 운영 적용

- D238 와 함께. 적용 직후 오래된 열린 신고가 있으면 첫 정기 작업에서 알림이 뜹니다(정상).
