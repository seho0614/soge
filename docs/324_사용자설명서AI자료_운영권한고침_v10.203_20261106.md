## 2. 사용자 설명서를 AI 상담 자료로 (D180)

| # | 무엇 | 내용 |
|---|---|---|
| 1 | 표 `help_docs` | 설명서 판을 쌓기만 함(고치기 · 지우기는 DB 가 막음 `HELP_DOC_LOCKED`) · 2만 자 · `v_help_doc_current` = 가장 높은 판. 처음 판 USER_MANUAL 1 = docs/323 본문 |
| 2 | AI 상담 | 지금 읽는 FAQ · 공지 · 약관(4만 자)과 **따로** 설명서 2만 자를 더 읽음(앞 자료가 잘리지 않음) · 절(「### 제목」)마다 `[설명서 m번호]` → 답의 출처로 고르면 「사용자 설명서 › 절 제목」 링크(`/guide/manual#m번호`) · 새 판은 10분 안에 읽음 |
| 3 | 운영 화면 | 관 관리 › **사용자 설명서**(SB-ADM-SIT-090) — 지금 판 · 글자 수 · 절 수 · 판 목록 · 옛 판 보기 · 「이 판 내용을 고치는 칸에 넣기」. 저장은 **SUPER**(새 판 · 같은 글이면 판 안 만듦 · 감사 `HELP_MANUAL_SAVE`) · ADMIN 은 읽기만 |
| 4 | 사용자 웹 | 이용안내 「자세한 사용 설명서」 → **/guide/manual**(SB-HOM-ETC-040) — 장 목차 · 절 제목마다 #m번호 · 표 · 목록. 글을 HTML 로 넣지 않고 줄을 나눠 그림(스크립트가 들어가지 않음) · 영어 화면은 「한국어로만 제공」 안내 · 사이트 지도 |

AI 비용(질문 1건마다 늘어나는 양 · DB 에 적힌 2026-10-06 단가 기준 — **실제 계약 요금은 추가 확인이 필요합니다**):

| 항목 | 값 |
|---|---|
| 늘어나는 입력 | 약 1만 ~ 1만 5천 토큰(설명서 15,348자 추정) |
| 같은 자료를 다시 읽을 때(캐시) | 1백만 토큰당 0.01달러 → 질문 1천 건에 약 0.15달러 |
| 처음 읽을 때 | 1백만 토큰당 0.10달러 → 1천 건에 약 1.5달러 |

- 월 상한(`agent.monthly_cap_usd`)은 그대로 지킴. AI 상담은 처리방침 게시 전에는 켜지지 않음 — 지금 운영 비용 없음.

## 4. 운영 권한 고침 (docs/322 를 쓰다 찾음)

| # | 전 | 뒤 |
|---|---|---|
| 1 | 「시험 결제 주문 정리」 단추가 ADMIN 에게도 보이는데 서버는 SUPER 만 받음 | 단추도 SUPER 에게만 |
| 2 | 텔레그램 대화방 · 하루 요약 · 운영자 낯선 로그인 알림 설정 — 화면은 SUPER 만 · 서버는 ADMIN 도 받음 | 서버도 SUPER(403 `OPS_PUSH_SETTING_SUPER` · 끄기도) |
| 3 | 입점 신청(`mall.tenant`)을 켜고 꺼도 「중요 설정 바뀜」 알림이 없음 | 알림 대상에 더함(D180) |
| 4 | 「모든 기기에서 로그아웃」이 회원 역할만 — 운영 전용 계정은 「운영자 낯선 로그인」 뒤 쓸 수 없음 | 운영 역할도 받음 · 운영 화면 › 권한 계층 › 내 2단계 인증에 단추(지금 비밀번호 · 이 브라우저는 새 증표로 이어 감) |
| 5 | 운영자 2단계 인증 설정을 바꾸는 운영 화면 칸이 없음(서버 `mfa-reset.sh` 만) | 내 2단계 인증 「설정 바꾸기」(SUPER · 켜기는 본인 등록 먼저 — 서버 검사 그대로) |
| 6 | 운영 알림 21종이 화면에 영어 코드로 보임 | 한국어 이름 |

- 지급 담당(PAYOUT) 역할을 주는 길은 **넣지 않음**(대표 결정 · 정산 · 지급을 열 때 다시 정함).
- 확인한 것: 운영자 정지 · 역할 회수는 요청마다 계정 상태 · 역할을 다시 읽어 **다음 요청부터 바로** 적용됨.
