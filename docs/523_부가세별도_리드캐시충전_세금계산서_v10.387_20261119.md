# 523. 부가세 별도 — 리드 캐시 충전 · 충전 때 세금계산서 (v10.387 · 2026-11-19)

> ⑩ 세 번째(D243 · 시작일 `vat.separate_from`). 대표 11/19 「리드 캐시 부가세 별도」 · 「충전 때 매출」.

## 1. 결론

- 시작일 뒤 충전은 **결제 = 충전 금액 + 부가세 10%**(10만 원 충전 → 11만 원 결제). **지갑(유상 잔액)에는 충전 금액만** · 등급 할인(보너스)은 그대로 충전 금액 기준.
- 충전이 끝나면(DONE) **그 충전의 세금계산서 요청 줄**이 생김(`lead_cash_invoices.charge_id` · 공급가 = 충전 금액 · 세액 = 부가세). 발행은 지금처럼 파트너사 › 리드 캐시 › 세금계산서(전자세금계산서 · 간주 모드).
- 달마다 사용액 세금계산서(D076)는 **시작일 전 사용분만**. 시작일에 남은 옛 유상 잔액(부가세 포함으로 받은 돈)을 그 뒤에 쓴 몫은 자동 발행되지 않음 — 운영 전 리드관이 꺼져 있어 지금은 0 · 생기면 수동 발행.
- 환불 — 유상 잔액 환불 금액에 **그 충전의 부가세 몫을 더해 결제 취소**(남은 것을 다 돌려주면 남은 부가세 전부). 이미 발행한 충전 세금계산서는 수정세금계산서를 따로 발행(수동).
