# 486. 고객센터 주간 보고 (v10.352 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① Nginx 적용 알림 · ② 임시 허용 IP(기한) · ③ 지난 판 보기 · 되돌리기 · ④ 고객센터 주간 보고 「모두」 → 계획 「승인 + 통과하면 병합」(v10.348 과 한 묶음 점검). 이 문서는 ④. 마이그레이션 **D234**(v10.350 과 같은 파일).

## 1. 왜

- 고객센터 숫자는 첫 화면(v10.344) · 1:1 문의 지표(v10.337)에 있지만, 한 주를 돌아볼 정리가 없었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D234** | 설정 `ops.cs_weekly`(on) · 정기 작업 `cs_weekly`(월요일 09:10 · 한국) |
| 정기 작업 `cs_weekly` | 지난주(월 ~ 일) 1:1 문의 접수 · 답함 · 처음 답까지 평균 · 기한 안 % · 해결됨 · 아직 · 해결률 · 문의 전 해결 · 못 찾은 낱말 5 · 리드관 신청 · 받을 업체 없음 · 지금 답변 전 · 기한 넘김 → **텔레그램 · 슬랙**(켜 둔 길만) · **운영자 게시판**(하루 요약 칸) · 운영 알림 **CS_WEEKLY**(INFO). off 면 보내지 않음 |
| 새 API `GET /admin/cs-glance/weekly` | ADMIN · SUPER · 같은 글 미리 보기 |
| 운영 화면 **첫 화면 › 「고객센터 한눈에」** | **「주간 보고 미리 보기」** |

## 3. 시험 (test_v1352)

1. ① 코드 — D234(설정 · 정기 작업) · 글 · API · 화면 · 작업 이름 · 문서 486 · 판 v10.352
2. ② API — 미리 보기 글(줄 8 · 날짜 범위 월 ~ 일) · 회원 403
3. ③ 정기 작업 — cs_weekly 실행 → 운영 알림 CS_WEEKLY · 운영자 게시판 한 줄 · ops.cs_weekly off 면 보내지 않음

## 4. 운영 적용

- D234 — 스냅샷(v10.350 과 같이). 처음 보내는 때는 적용 뒤 첫 월요일 09:10.
- 끄기: 정책 › 전체 설정 `ops.cs_weekly` = off.
- 되돌리기(rollback): 앞 판 정기 작업에는 cs_weekly 처리가 없어 월요일에 아무것도 보내지 않고 지나갑니다(설정 · 작업 줄은 남음 · 오류 없음).
