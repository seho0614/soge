# 501. 개인정보 대량 내려받기 승인 (v10.366 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 회원 활동 한 줄 기록 · ② 개인정보 대량 내려받기 승인 · ③ 신고 처리 기한 경보 · ④ DB 복원 시험 기록 「모두」 → 계획 「승인 + 통과하면 병합」(다섯 번째 묶음 · 운영은 v10.361 ~ 364 와 함께 다음 묶음). 이 문서는 ②. 마이그레이션 **D238**(275 → 276 · 스냅샷 필요 · v10.367 · 368 과 같은 파일).

## 1. 왜

- 개인정보가 든 CSV(주민등록번호가 든 원천징수 신고 자료 등)를 권한만 있으면 아무 때나 몇 번이고 받을 수 있었습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D238** | 표 `export_requests`(대상 · 사유 · 요청자 · 결정자 · solo · 쓴 때) · 결정 한 번 · 쓰기 한 번만 · 지우기 막음 · 자기 요청은 solo 일 때만 스스로 |
| 대상 4곳 | `GET /admin/payouts/point-report`(POINT_REPORT) · `GET /admin/audit/export`(AUDIT_EXPORT) · `GET /admin/notices/{id}/reads/export`(NOTICE_READS) · `GET /admin/health/rate-schedules/{id}/reads/export`(RATE_READS) — `@ExportGate` · `?ticket=<승인 번호>` 없으면 422 `EXPORT_NEED_APPROVAL` · 성공하면 쓴 것으로(다시 쓰면 422) |
| 새 API | `GET /admin/export-requests` · `GET …/ready?target=` · `POST /admin/export-requests`(PAYOUT · SUPER · 사유 2 ~ 200자 · 하루 10건 · 감사 `EXPORT_REQUEST`) · `POST …/{id}/decide`(SUPER · 감사 `EXPORT_DECIDE` · 409 `EXPORT_DECIDED` · 422 `EXPORT_SELF_APPROVE`) |
| 승인 규칙 | 요청 → **다른 SUPER** 승인 → 승인 뒤 24시간 안 한 번. 요청자가 SUPER 이고 다른 SUPER 가 없으면 요청 때 스스로 승인(**「혼자 승인」** · solo) |
| 운영 화면 **위험감지 › 「감사」** | **「내려받기 승인」** 상자 — 기다리는 요청 승인 · 거절 · 내 요청 · 최근 결정 |
| 내려받기 단추 4곳 | 누르면 승인 번호부터 — 없으면 사유를 묻고 요청 · 승인되면 바로 받음 · 기다리면 안내 |
| 월간 보안 보고 | 「개인정보 내려받기 n(혼자 승인 · 거절) · DB 복원 시험 …」 한 줄(11줄) |

- 지금 운영은 SUPER 가 대표 한 명이라 대표 요청은 「혼자 승인」으로 바로 받고 기록만 남습니다. 지급 담당(PAYOUT)의 신고 자료 요청은 대표가 승인합니다.
