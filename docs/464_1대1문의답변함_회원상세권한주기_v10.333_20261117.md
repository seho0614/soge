# 464. 운영 화면 「1:1 문의」 답변함 · 회원 상세에서 권한 주기 (v10.333 · 2026-11-17)

> 대표 11/17 「개발 후보 목록」 → 「① 1:1 문의 답변함」 · 「승인 + 통과하면 병합」. 같은 날 「회원 권한을 관리자 · 수퍼 권한을 지정할 수 있도록」 → 「회원 상세에 더하기」. 마이그레이션 **D225**(262 → 263 · 스냅샷 필요).

## 1. 왜

- 회원이 고객센터 문의하기 폼 · 1:1 문의 챗봇 「상담원 연결」로 문의를 넣을 수는 있었지만, **운영 화면에는 문의를 보고 답할 곳이 없었습니다**(`inquiries.answer` 칸만 있고 쓰는 API 가 없음). 「내 문의 내역」의 답변 칸은 늘 「아직 없음」이었습니다.
- 회원에게 운영 권한(ADMIN · SUPER 등)을 주는 칸은 「권한 계층 › 권한 관리 › 역할 주기」에만 있어, 회원 상세에서는 권한이 보이기만 했습니다.

## 2. 바뀐 것

- 비회원 문의는 회원 알림이 없고 메일로만 답이 갑니다. 운영 메일이 준비되기 전(NO_SMTP)에는 답이 「메일 대기」입니다 — 화면 안내에 적음.
- 거래 분쟁은 이 창구가 아니라 거래 › 분쟁에서 처리해야 정산 보류가 걸립니다(화면 안내에 적음).

## 4. 운영 적용

- 마이그레이션 D225 하나(262 → 263) — **RDS 스냅샷을 만듭니다.** 설정은 없습니다.
- 적용 뒤 열린 문의가 있으면 기한이 채워지고, 영업일 1일을 넘긴 것이 있으면 다음 정각 정기 작업 때 운영 알림 「1:1 문의 답변 기한 넘김 n건」이 뜹니다(정상 — 답하면 풀림).
- 되돌리기(rollback): 프로그램만 앞 판으로 돌아가도 D225 칸 · 트리거 · 함수는 남습니다. 앞 판은 그 칸을 읽지 않고, 트리거는 기한만 채우므로 지장이 없습니다. 앞 판에는 답변 화면이 없습니다.
