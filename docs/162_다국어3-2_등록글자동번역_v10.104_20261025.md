## 2. 켜는 순서 (운영 · 대표 승인 뒤 · 사람이)

1. Anthropic 콘솔에서 **새 API 키 발급**(10/25 대화에 붙인 키는 폐기) → 운영 `.env` 에 `ANTHROPIC_API_KEY=…` · `AGENT_PROVIDER=CLAUDE` → pm2 다시 시작
2. 운영 화면 「AI 에이전트」 — 월 상한(`agent.monthly_cap_usd` · 달러 · 소수 둘째 자리까지 · 추천 약 20달러 ≈ 3만 원) · AI 전체(`agent.enabled`) 켜기
3. 「사이트 설정」 `i18n.auto_translate.enabled` on(언어는 `i18n.auto_langs` · 기본 en)
4. 「번역 승인 → 자동 번역」 「노출 중인 글 한꺼번에 넣기」(처음 한 번) → 몇 분 뒤 「끝 · 자동 승인」 확인
5. 손님에게 보이려면 다국어 `i18n.enabled` on + 「언어」 en(영어 문장 확인 뒤)

## 3. 비용 어림(변할 수 있음 — 계약 전 요금표 확인)

요금은 `agent_model_prices`(D116 · 2026-10-06 사본) — Haiku 5.5 입력 100만 토큰당 0.10달러 · 출력 0.50달러. 매물 1건(제목 + 본문) 입력 · 출력 각 약 1,500 토큰 → 1건 약 0.001달러 · **월 1,000건 약 1달러**. 지시문은 같은 글이라 반복분은 프롬프트 캐시 대상이 될 수 있으나(최소 길이 미만이면 캐시 안 됨) 이번 판은 캐시를 켜지 않음.
