# 248. 약관 변경 회원 알림 · 오픈 준비 점검 약관 줄 (v10.162 · 2026-10-31)

> 대표 지시(10/31 「개발후보」 → 「1 2 3 모두」) — ② 시행 예정 게시 때 회원 개별 알림 ③ 오픈 준비 점검에 약관 줄.
> 마이그레이션 **1개(D152)** · 190. 앞 판: v10.161(docs/246 · D151).

## 1. 왜

| 전(v10.161 까지) | 문제 |
|---|---|
| 시행 예정 약관은 사용자 웹 바닥줄 · 약관 화면 알림으로만 알림 | 이용약관 제14조 「고지」를 회원 각자에게 남긴 기록이 없음 — 로그인하지 않은 회원은 모름 |
| 「불리한 변경 30일 전」은 운영 화면 경고 글뿐 | 날짜를 잘못 넣어도 게시됨 |
| 오픈 준비 점검은 필수 약관 「게시 여부」만(오픈 차단 TERM 줄) | 시행일이 오픈일보다 늦어도 · 고지 기간이 짧아도 알 수 없음 |

## 2. 바뀐 것

| # | 곳 | 내용 |
|---|---|---|
| 1 | DB **D152** `terms.published_at` · `terms.is_adverse` | 게시한 때 · 회원에게 불리한 변경 — 고지 기간을 잼(기존 줄은 비워 둠) |
| 2 | DB 알림 종류 `TERM_CHANGE_NOTICE` | 「약관 변경 안내」 · **수신 거부 불가**(제14조 고지) · 주황 카드 |
| 3 | DB 설정 `terms.notify_members`(기본 **on**) | off 면 알림을 만들지 않음 · SUPER 만(v10.161 의 `terms.` 설정 규칙 TERMS_SETTING_SUPER) |
| 4 | 서버 게시 `PATCH /admin/terms/{code}/publish` | 시행 예정이면 **회원마다 알림 1건**(전체 회원 대상 약관만 · ACTIVE · 탈퇴 아님) — 「[약관 변경 안내] 이용약관 1.1」 · 시행일 · 지금 판 → 새 판 · 바뀐 점 · 재동의 안내 · 링크 `/terms?notice={약관}@{판}#upcoming-terms`(취소 안내를 받을 회원을 찾는 기준 · 알림의 template_code 는 알림 양식 표를 가리켜 쓰지 않음) · 응답 `notified` · 요청 `adverse`(불리한 변경) — 앞 판이 있고 시행일이 30일 안이면 422 **`TERM_ADVERSE_30D`** |
| 5 | 서버 예정 취소 `PATCH /admin/terms/{code}/unschedule` | 변경 안내를 받은 회원에게 **「[약관 변경 취소]」** 알림 · 응답 `notified` · 게시한 때 · 불리한 변경 비움 |
| 6 | 메일 · 알림톡 | **새 발송 길 없음** — 기존 `notify_dispatch`(매시간)가 채널이 켜진 뒤 같은 알림을 보냄(메일: `notify.email_verified` · 알림톡: `notify.alimtalk_ready`). 지금은 둘 다 꺼짐이라 사이트 안 알림만 |
| 7 | 운영 화면 › 관 관리 › 약관 | 시행일 옆 **「회원에게 불리한 변경(30일 전 고지)」** 고르기 · 게시 확인 창에 「회원마다 알림이 갑니다」 · 결과에 알림 수 · **「시행 예정 게시 때 회원 알림」 스위치** |
| 8 | DB `v_open_readiness` 권장 줄 2개(**11줄**) | `TERMS_EFFECTIVE` 약관 시행일 — 필수 약관(전체 회원 대상)마다 오픈일 또는 그 전에 시행되는 판 · `TERMS_NOTICE` 약관 변경 고지 기간 — 시행 예정 판이 게시 뒤 7일(불리하면 30일) 지나 시행. 고칠 곳 = 관 관리 › 약관. **오픈 차단은 아님**(권장) — 필수 약관이 아예 없는 것은 이미 오픈 차단 TERM 줄 |

## 3. 계획에서 바꾼 것

- `TERMS_EFFECTIVE` 를 **꼭(오픈 차단)** 이 아니라 **권장**으로 — 꼭이면 오픈일을 정하기 전까지 오픈 차단이 하나 늘고, 리허설(docs/228) · 오픈 차단 수를 보는 시험이 모두 바뀜. 오픈 직전 체크리스트에서 이 줄을 본다(docs/136 에 적을 것 — 오픈일이 정해진 뒤).

## 4. 주의

| 무엇 | 내용 |
|---|---|
| 회원 수가 많을 때 | 게시 한 번에 회원 수만큼 알림 줄(한 문장 INSERT). 메일 · 알림톡은 `notify_dispatch` 가 한 번에 200건씩 · **3일 넘은 알림은 보내지 않음**(v_notify_queue) — 회원이 수천 명이 되면 다시 볼 것 |
| 알림톡 비용 | 알림톡을 켠 뒤 시행 예정 게시 = 회원 수만큼 발송 — 비용이 걱정되면 그때 스위치 off 또는 채널 정책을 따로 |
| 제휴 약관 | 대상이 제휴(PARTNER)인 약관은 회원 알림 없음(파트너 센터 쪽 안내는 그대로) |
| 처음 게시 | 앞 판이 없는 첫 게시는 「시행 예정」이 아니라 바로 지금 판 → 알림 없음 · 불리한 변경 검사 없음 |
