# 637. 앱처럼 설치 — PWA (v10.499 · 2026-11-20)

## 1. 결론
사용자 웹을 휴대폰 · PC 홈 화면에 **앱처럼 설치**할 수 있게 **웹 앱 정보(`/manifest.webmanifest`) · 아이콘 3개 · 아이폰 아이콘 · 서비스 워커(`/sw.js`)** 를 더했습니다. 서비스 워커는 **화면 이동이 네트워크 오류로 실패할 때만 오프라인 안내(`/offline.html` · SB-HOM-UPT-030)를 보여 주고, 앱 화면 · 그림 · 스크립트 · API 는 캐시하지 않습니다**(옛 화면이 남는 문제를 원천 차단). 등록은 **운영 설정 `site.pwa`(처음 off) + 운영 빌드(NODE_ENV=production)일 때만** — off 로 되돌리면 이미 등록된 워커와 우리 캐시를 사용자 웹이 지웁니다(되돌리는 스위치). DB 변경은 설정 한 줄뿐.

| 파일 | 뜻 |

## 2. 판단
1. **캐시 전략 = 「없음」**(네트워크만 · 실패 때 안내 한 장) — 이 서비스는 매물 · 가격 · 주문 상태가 바로 바뀌어야 하고(v10.36 「저장이 안 된다」로 보인 사례), 캐시된 화면이 로그인 상태 · 개인 정보를 다른 사람에게 보일 위험이 있음. 오프라인 읽기 기능은 다음 후보로도 두지 않음.
2. **처음 off** — 서비스 워커는 한 번 깔리면 브라우저에 남으므로, 켜기 전에 점검판에서 확인하고 대표 승인 뒤 켬. 문제가 생기면 off → 다음 방문 때 워커를 지움(워커 파일은 늘 새로 받으므로 VER 를 올려도 바로 바뀜).
3. **운영 빌드에서만 등록** — `next dev` · 점검판 개발 모드에서 워커가 깔려 개발 화면이 꼬이지 않게.
4. **아이콘** — 저장소(site/public)에 따로 그린 로고 그림 파일이 없어 **탭 아이콘과 같은 글자 그림(남색 바탕 S · 주황 밑줄)** 을 그림 만들기(ImageResponse)로 만듦. **로고 원본 그림이 정해지면 바꿀 것**(디자인 원본 그림은 ~/outputs · kit 밖 보관 — 그 안의 로고 사용 여부는 대표 확인 필요).
5. 그림 만들기 · 웹 앱 정보 · 오프라인 한 장은 CSS 토큰을 읽을 수 없어 **디자인 시트 값을 적음**(이름 · 값은 sgb-tokens.css 와 같게 — 바꾸면 함께).

## 3. 켜는 순서(운영 · 대표 승인 뒤)
1. 운영 적용 뒤 `https://sogaebank.com/manifest.webmanifest` · `/pwa-icon/192` · `/sw.js`(머리글 Cache-Control) · `/offline.html` 이 열리는지.
2. 운영 화면 › 정책 › 전체 설정 › `site.pwa` = on(사유) — 공개 설정은 5분 기억이라 최대 5분 뒤 등록 시작.
3. 휴대폰 크롬 › 메뉴 › 「홈 화면에 추가 / 앱 설치」 · 아이폰 사파리 › 공유 › 「홈 화면에 추가」.
4. 비행기 모드 → 앱을 열고 다른 화면 이동 → 오프라인 안내 · 「다시 시도」.

## 5. 생길 수 있는 문제
| 문제 | 해결 |
|---|---|
| 아이콘이 안 바뀜 | 브라우저 · 홈 화면 아이콘 캐시 — 앱을 지우고 다시 설치 |
| 워커가 옛 것 | `/sw.js` 머리글 확인(no-cache) · VER 올림 · `site.pwa` off 뒤 on |
| 아이폰에서 오프라인 안내가 안 보임 | iOS 는 홈 화면 앱에서만 워커가 돎 · 사파리 탭은 브라우저 기본 화면 |
| CSP 보고(정책 보고)에 inline 스크립트 | 오프라인 한 장의 「다시 시도」 · 보기 설정 스크립트 — 보고만 하는 정책이라 막지 않음(막는 정책으로 바꿀 때 해시 추가) |
