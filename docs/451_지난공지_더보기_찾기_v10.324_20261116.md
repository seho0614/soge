# 451. 지난 공지 더 보기 · 찾기 (v10.324 · 2026-11-16)

> 대표 「다음개발」(11/16) A. 마이그레이션 없음. 사용자 웹 + 공개 API.

## 1. 까닭

`GET /notices` 가 최근 30개(고정 먼저)만 돌려줘서, 31번째부터는 소개광장 › 공지에서 볼 길이 없었습니다.

## 2. 바뀐 것 (정확한 위치)

사용자 웹 **소개광장 › 「공지」 탭 › 「운영 공지」 상자**

| 칸 | 내용 |
|---|---|
| 찾기 칸 | 제목 · 본문에 든 글자(100자까지) · 「찾기」 · 찾는 중이면 「찾기 지우기」 · 주소 `?board=NOTICE&nq=…` |
| 지난 공지 더 보기 | 한 쪽 30개 · 30개가 차면 「지난 공지 더 보기 →」 · 2쪽부터 「← 최근 공지」 · 주소 `&np=2` |
| 빈 안내 | 찾는 글자가 든 공지 없음 · 그 쪽에 공지 없음 · 게시 중 공지 없음을 따로 |

- 고정 공지는 순서상 앞 쪽에 먼저 나옵니다(정렬은 전과 같음: 고정 → 게시 최근 순).
- 글 목록의 찾기(`q`) · 쪽(`page`)과 따로 움직입니다(`nq` · `np`).
- 영어 화면에서도 찾기는 **원문(한국어) 기준**입니다. 승인된 번역 글자로는 찾지 못합니다.
- 알림의 `#n-<id>` 주소는 첫 쪽에 있는 공지만 펼친 채 열립니다(30개 밖 오래된 공지는 목록만).

## 3. API

`GET /notices` 에 `q`(제목 · 본문 · 대소문자 무시) · `page`(1부터 · 30개씩) — **값이 없으면 전과 같이 첫 30개**라 메인 띠 · 머리줄 종 · 고객센터 쪽은 바뀌지 않습니다. 잘못된 `page` 는 1쪽.
