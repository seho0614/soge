# 621. 문자 · 메일 캠페인 (v10.483 · 2026-11-20)

## 1. 결론
운영자가 **광고 문자 · 메일**을 만들어 **마케팅 수신 동의자에게만** 보냅니다. **21:00 ~ 08:00(한국)에는 야간 광고 동의자에게만** 보내고 나머지는 08:00 뒤로 미룹니다. 제목 · 글 앞 **(광고)** · 보낸 곳 이름 · 연락처 · **무료 수신 거부**(메일은 링크 · 문자는 080 번호)는 **서버가 붙입니다**(운영자가 지울 수 없음). 보내기는 **기존 어댑터만** — 메일은 SES SMTP(MailService) · 문자는 알림톡 대행사의 문자 주소. **처음 꺼짐(campaign.enabled off) · 방식 간주(ASSUME — 보내지 않고 기록만)**. 위치: **회원 › 문자 · 메일 캠페인** · SB-ADM-SCU-010 · API `/admin/marketing/*` · 공개 `/site/unsubscribe`.

| 단계 | 누가 | 내용 |
|---|---|---|
| 1 초안 | ADMIN · SUPER | 이름 · 채널(메일 · 문자) · 제목(메일) · 글(10 ~ 2,000자 · 문자 600자) · 대상(동의한 모든 회원 · 90일 안 로그인한 동의 회원) |
| 2 받을 사람 보기 | ADMIN · SUPER | 마케팅 동의 · 2년 넘은 동의(뺌) · 받는 곳 없음(뺌) · 반송 · 거부 주소(뺌) · 보낼 수 · 야간 동의 수 — 이름 · 주소는 안 보임 |
| 3 나에게 시험 | ADMIN · SUPER | 운영자 본인 메일 · 휴대폰으로(ASSUME 이면 기록만) · 광고 표기가 붙은 글 미리보기 · 하루 20번 |
| 4 보내기 | **SUPER** | 켜짐 · 확인 글자 「보내기」 · 연락처(문자는 080 번호) · LIVE 면 메일 · 문자 준비 → **받는 사람을 지금 동의자로 고정** · 예약 시각(60일 안 · 없으면 바로) |
| 5 보냄 | 정기 작업 `mkt_campaign_send` 5분마다 | `campaign.batch`(처음 200)만큼 · 보낼 때 **동의를 다시 봄**(그 사이 철회하면 건너뜀) · 야간은 야간 동의자만 |
| 취소 | ADMIN · SUPER | 초안 · 대기 · 보내는 중 → 아직 안 보낸 사람은 건너뜀(사유) |

| 설정 | 처음 | 뜻 |
|---|---|---|
| `campaign.enabled` | off | 보내기 · 정기 작업(초안 · 시험은 꺼져도 됨) |
| `campaign.send_mode` | ASSUME | ASSUME = 보내지 않고 「간주(ASSUMED)」 / LIVE = 실제로 보냄(보내기를 누를 때 방식이 캠페인에 고정됨) |
| `campaign.sender_name` | (주)한국바이오헬스케어 소개뱅크 사업부 | 메일 끝 「보낸 곳」 |
| `campaign.sms_name` | 소개뱅크 | 문자 앞 「(광고)소개뱅크」 |
| `campaign.contact` | (빔) | 메일 끝 「연락처」 — **비면 보내기 막음** |
| `campaign.optout_phone` | (빔) | 문자 끝 「무료거부 080…」 — **문자는 비면 보내기 막음** |
| `campaign.sms_from` | (빔) | 문자 발신번호(사전 등록) — **문자 LIVE 는 비면 막음** |
| `campaign.batch` | 200 | 5분에 보내는 수(1 ~ 1,000) |

| .env | 뜻 |
|---|---|
| `CAMPAIGN_SMS_URL` | 알림톡 대행사의 문자(SMS · LMS) 발송 주소 — 키 · 인증 머리글은 알림톡과 같음(`ALIMTALK_KEY` · `ALIMTALK_AUTH_HEADER` · `ALIMTALK_AUTH_PREFIX` · 결과 번호 `ALIMTALK_RESULT_ID_PATH`) · 본문 `{ from, to, text, type: SMS | LMS, ad: true }`(대행사가 정해지면 칸 이름 확인) |

## 2. 서버가 지키는 것(정보통신망법 제50조 · 법무 확인 필요)
1. **사전 동의** — 받는 사람 = 약관 `MARKETING` 의 **가장 최근 동의 줄이 동의**인 활동 회원(v_term_consent_current) · 보낼 때 그 순간 유효한 동의(`fn_consent_at`)를 **DB 트리거가 다시 봄**(`MKT_NO_CONSENT`).
2. **야간(21 ~ 8시)** — 약관 `MARKETING_NIGHT` 동의가 있어야 보냄 · 없으면 08:00 뒤로 미룸 · 트리거도 막음(`MKT_NIGHT`) · 보낸 줄에 야간 표시.
3. **(광고) 표기 · 전송자 · 연락처** — 메일 제목 앞 「(광고)」 · 끝에 「보낸 곳 · 연락처」 / 문자 앞 「(광고)이름」.
4. **무료 수신 거부** — 메일 끝 링크(`/api/v1/site/unsubscribe?t=…` · 사용자 웹 도메인이 API 로 넘김) / 문자 끝 「무료거부 080…」. 글에 「수신 거부」를 쓰면 막음(두 번 나가지 않게 · `MKT_OPTOUT_TEXT`).
5. **수신 거부 처리** — 링크를 열면 확인 단추만(메일 검사기가 미리 열어도 철회되지 않게) · 누르면 `MARKETING` · `MARKETING_NIGHT` 동의를 **철회**(약관 동의 기록 term_agreements 에 「거부」 한 줄 — 고치거나 지우지 않는 기록) · 아직 안 보낸 다른 캠페인 줄도 멈춤 · 처리 결과 알림(나의공간 › 알림 · 이벤트 `CONSENT_OPTOUT`) · 기록 `mkt_unsubscribes`.
6. **2년 재확인** — 2년 넘은 동의는 받는 사람에서 뺌(재확인 통지 기능은 이 판에 없음 — 6절).
7. **반송 · 수신 거부 주소(D186 mail_suppressions)** — 메일은 건너뜀(SUPPRESSED). 광고 수신 거부를 이 표에 넣지는 않습니다(넣으면 거래 · 법정 알림 메일까지 막힘).
8. 감시 보기 `v_mkt_consent_violation` — 보낸 그 시각에 동의(야간이면 야간 동의)가 없던 줄 · **늘 0**(목록 화면 「동의 위반 감시」).

## 3. 기록 · 개인정보
- `mkt_campaigns`(지우지 않음 · 보내기 뒤 글 못 고침 — DB 가 막음) · `mkt_campaign_sends`(받는 사람 한 줄 · 받는 곳은 가린 값 `ab***@x.com` · `***1234` · 상태 QUEUED → SENT · ASSUMED · SKIPPED · FAILED · 지우지 않음) · `mkt_unsubscribes`(쌓기만).
- 수신 거부 열쇠는 HMAC(JWT_SECRET 에서 나눈 키 · 캠페인 · 회원) — DB 에는 **지문(sha256)만**. JWT_SECRET 을 바꾸면 그 전 메일의 링크는 「맞지 않습니다」 화면(080 · 고객센터로 거부 가능).
- 실패: 연결 · 시간 초과 · 업체 5xx 는 3번까지 다시(RETRY) · 그 밖은 FAILED(까닭 200자). LIVE 인데 메일 · 문자가 준비되지 않으면 그 캠페인을 멈추고 운영 알림 **MKT_CAMPAIGN_STUCK**.

## 4. 방식 준비(LIVE)
| 채널 | 준비 |
|---|---|
| 메일 | MailService 준비됨(SMTP_USER · SMTP_PASS · 보내는 주소 · `notify.email_verified` on) |
| 문자 | `CAMPAIGN_SMS_URL` · `ALIMTALK_KEY` · `campaign.sms_from` · `campaign.optout_phone` |
알림톡(카카오)은 정보성 메시지만 허용돼 **광고에 쓰지 않습니다**(친구톡 · 브랜드 메시지는 이 판 범위 밖).

## 5. 켜는 순서(운영 · 대표 승인 뒤)
1. 법무 확인(6절) → 2. 설정에서 연락처 · 080 번호 · 발신번호 · 보낸 곳 → 3. `campaign.enabled` on(방식 ASSUME 그대로) → 4. 초안 · 받을 사람 · 나에게 시험 → 5. 메일 준비(SES) 확인 뒤 `campaign.send_mode` LIVE → 6. 작은 대상(RECENT_90)부터.

## 6. 확인 필요(법무 · 대표)
1. **정보통신망법 제50조 · 시행령 제61조** 표기 문구(「(광고)」 위치 · 전송자 명칭 · 연락처 · 수신 거부 안내 글) — 이 판의 글자가 법정 표기와 맞는지.
2. **수신 동의 2년마다 확인 통지**(제50조의8) — 이 판은 2년 넘은 동의를 빼기만 함. 통지 메일은 다음 묶음 후보.
3. **수신 거부 · 철회 처리 결과 통지**(14일 안) — 이 판은 나의공간 알림 + 결과 화면. 메일 · 문자 통지가 필요한지.
4. **080 무료 수신 거부 번호** 운영(대행사 080 서비스 · 접수 결과를 사람이 동의 기록에 반영하는 방법) — 이 판은 080 접수를 자동으로 받지 않음.
5. 발신번호 사전 등록 · 대행사 광고 문자 약관 · 야간 발송 제한.
