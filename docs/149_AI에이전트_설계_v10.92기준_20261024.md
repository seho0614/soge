### 3-3. 표 (안 · 0단계 마이그레이션)

```sql
CREATE TABLE agent_conversations (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  channel text NOT NULL CHECK (channel IN ('SITE_CHAT','REVIEW_SHADOW','AUDIT','SETTLE')),
  account_id uuid REFERENCES accounts(id), guest_key text,        -- 비회원은 쿠키 값 해시
  status text NOT NULL DEFAULT 'OPEN' CHECK (status IN ('OPEN','HANDED_OFF','CLOSED')),
  inquiry_id uuid REFERENCES inquiries(id),                         -- 사람에게 넘긴 1:1 문의
  created_at timestamptz NOT NULL DEFAULT now(), purge_after timestamptz NOT NULL);   -- 보관 기간(제안 90일 · 법무 회신 뒤 확정)
CREATE TABLE agent_messages (id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  conversation_id uuid NOT NULL REFERENCES agent_conversations(id) ON DELETE CASCADE,
  role text NOT NULL CHECK (role IN ('user','assistant','tool')), body text NOT NULL,
  model text, input_tokens int, output_tokens int, cache_read_tokens int, stop_reason text,
  created_at timestamptz NOT NULL DEFAULT now());
CREATE TABLE ai_review_opinions (id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  review_item_id uuid NOT NULL REFERENCES review_items(id), suggestion text NOT NULL CHECK (suggestion IN ('APPROVE','REJECT','UNSURE')),
  reason_codes text[], note text, model text NOT NULL, created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (review_item_id, model));
CREATE TABLE agent_usage_daily (day date NOT NULL, channel text NOT NULL, model text NOT NULL,
  requests int NOT NULL DEFAULT 0, input_tokens bigint NOT NULL DEFAULT 0, output_tokens bigint NOT NULL DEFAULT 0,
  cost_usd numeric(10,4) NOT NULL DEFAULT 0, PRIMARY KEY (day, channel, model));
-- 스위치: agent.enabled · agent.review_shadow.enabled · agent.chat.enabled · agent.chat.member_lookup.enabled (모두 false)
-- 값: agent.monthly_cap_usd(0 — 0 이면 아무것도 안 부름) · agent.guest_daily_limit(20) · agent.member_daily_limit(100)
```

일치율 뷰 `v_ai_review_agreement` — AI 제안과 사람 결정(APPROVED · REJECTED)의 일치 비율 · 최근 2주 · 건수.

### 3-4. 검수 보조(1단계)

1. 검수 줄이 들어오면(`review_items` QUEUED) 배치가 5분마다 모아 Claude 에 보냄 — 급하지 않아 **배치 API(50% 할인)** 도 가능.
2. 넣는 것: 매물 글 칸 · 관 · 분류 · 자동검수 이유(`manual_reasons`) · 금칙어 결과 · 정책 요약(캐시).
3. 받는 것: `{ suggestion, reason_codes[], note }`(정해진 형식).
4. 운영 화면 검수 줄 옆에 「AI 의견: 반려 제안 — 연락처 기재」 · 사람이 결정하면 일치 여부를 셈.
5. **통과 기준(제안 · 미정 #3)**: 2주 · 100건 이상 · 승인/반려 방향 일치 90% 이상 → 그 뒤에도 자동 처리는 하지 않음(의견만).

### 3-5. 고객응대 ① 안내(2단계)

- 사이트 공통 단추(`SB-HOM-AGT-010`) → `POST /api/v1/agent/chat`(스트리밍).
- 지식: 이용안내 · 자주 묻는 질문 · 공지 · 정책(약관 발행본 요약) — 서버가 시스템 지시문에 넣고 **프롬프트 캐시**.
- 답할 수 없는 것(돈 · 분쟁 · 개인 사정 · 법률 판단 · 모르는 것) → 「담당자에게 넘길까요?」 → 1:1 문의 생성 + 운영 알림.
- 화면 첫 줄에 **「AI 상담입니다 · 정확하지 않을 수 있습니다」**(인공지능기본법 AI 고지 — 법무 확인).
- 안전 거절(`stop_reason: refusal`)이면 정해진 문장 + 사람에게 넘김.
