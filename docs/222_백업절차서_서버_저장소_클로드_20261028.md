### 3-1. 서버 디스크 스냅샷 (사람 · 콘솔)

**한 번 찍기**(지금 · 운영 적용 전마다)

```
EC2 → 인스턴스 → 3.37.95.217 인스턴스 → 「스토리지」 탭 → 볼륨 ID
 → 작업 → 스냅샷 생성 → 설명 sgb-dev-full-YYYYMMDD · 태그 Name = sgb-dev-full-YYYYMMDD
 → EC2 › 스냅샷에서 「완료」까지(처음 10 ~ 30분)
```

- 서버를 끄지 않고 찍는다(확인판이 멈추지 않음). 찍는 순간 쓰던 파일은 덜 저장될 수 있다 — 운영 DB 는 RDS 라 디스크에 없어 위험이 낮다. **「이미지(AMI) 만들기 · 재부팅」은 확인판이 몇 분 멈추므로 쓰지 않는다.**

**매일 자동**(한 번 설정)

```
EC2 → 볼륨 → 그 볼륨 → 태그 관리 → Backup = daily 더하기
EC2 → 수명 주기 관리자(Data Lifecycle Manager) → 정책 만들기 → EBS 스냅샷 정책
 → 대상: 태그 Backup = daily
 → 일정 1: 매일 03:00 KST(18:00 UTC) · 보관 7개
 → 일정 2: 매주 일요일 · 보관 4개
 → 태그 복사 켜기 → 만들기
```

### 3-3. 저장소 4개 묶기 (Claude · 개발 서버)


### 3-5. Claude 작업 (Claude · 개발 서버)

```bash
D=$(date -u +%Y%m%d); W=$(mktemp -d -p ~/backup); O=$W/claude_work_$D; mkdir -p $O/scratchpad
```
