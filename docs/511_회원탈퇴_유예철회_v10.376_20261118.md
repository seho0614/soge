# 511. 회원 탈퇴 유예 · 철회 (v10.376 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① 분쟁 · 정산 처리 기한 · ② 운영 적용 확인표 · ③ 운영 알림 주간 통계 · ④ 회원 탈퇴 유예 · 철회 「모두」 → 계획 「승인 + 통과하면 병합」(일곱 번째 묶음 · 운영은 v10.372 한 번에 다음 묶음). 이 문서는 ④. 마이그레이션 **D240**(설정 · 칸 · 함수 둘).

## 1. 왜

- 실수로 탈퇴한 회원이 되돌릴 길이 없었습니다(거래 없는 회원은 다음 파기 배치에서 바로 파기).

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 설정 `member.withdraw_grace_days` | **처음 0 = 꺼짐**(지금과 똑같음) · 0 ~ 30일 · 켜기 전 처리방침 · 약관 문구를 고칠 것 |
| 보관 기한 트리거 `fn_set_retention_on_withdraw` | 거래 없는 탈퇴의 파기 날 = 탈퇴한 날 + 유예 날 수(거래 있으면 5년 그대로) |
| 탈퇴 함수 `fn_account_withdraw` | 취소한 뒤 다시 탈퇴하면 같은 줄을 새 사유 · 때로(`canceled_at` 비움) — 나머지는 D102 그대로 |
| 칸 `account_withdrawals.canceled_at` | 「탈퇴 취소」한 때 |
| 로그인 | 비밀번호가 맞은 유예 중 탈퇴 계정 → 403 **`WITHDRAW_PENDING`**(「… 까지 취소 가능」) |
| 새 API `POST /auth/withdraw/cancel` | 공개 · 이메일 · 비밀번호(틀리면 로그인 실패와 같이 셈) · 유예 안 · 파기 전이면 계정 되살림(ACTIVE · 탈퇴 시각 · 보관 기한 비움) · 감사 `ACCOUNT_WITHDRAW_CANCEL` · 409 `WITHDRAW_CANCEL_CLOSED` |
| 사용자 웹 **나의공간 › 계정 › 회원 탈퇴** | 유예가 켜져 있으면 안내 줄 · 파기 날 · 확인 체크 문구(\`agreeGrace\`) · \`GET /me/withdraw/check\` 에 \`graceDays\` |
| 사용자 웹 **로그인** | `WITHDRAW_PENDING` 이면 **「탈퇴 취소하고 로그인」** 단추 → 취소 → 바로 로그인 |

- 탈퇴 때 끊긴 것(정기 결제 카드 · 구독 해지 예약 · 비밀번호 재설정 링크)은 되살리지 않습니다 — 회원이 다시 등록 · 신청합니다.

## 3. 법무 확인 · 시행 결정

- **2026-11-18 대표: 「탈퇴유예, 법무확인 7일유예 시행 한다」** — 법무 확인 끝 · 유예 **7일**로 시행.
- 켜는 순서(운영 · 대표 · SUPER): ① 개인정보 처리방침 · 이용약관 새 판에 아래 문구를 넣어 게시(시행일) → ② **시행일이 된 뒤** 정책 › 전체 설정 `member.withdraw_grace_days` = `7`(사유 「처리방침 n.n 시행 · 탈퇴 7일 유예」). 문구 게시 전에 켜지 않습니다(처리방침에 적힌 보유 기간과 실제가 달라짐).
- 처리방침을 바꿀 때 미리 알리는 기간 · 방법은 이번 판 게시 화면의 「시행 예정」 안내를 그대로 씁니다(구체 기간은 최신 법령 · 법무 확인 기준).

### 3-1. 넣을 문구 (초안 — 지금 게시된 판의 조항 번호에 맞춰 넣음)

| 문서 | 넣을 곳 | 문구 |
|---|---|---|
| 개인정보 처리방침 | 「처리 및 보유 기간」 표 · 회원 정보 줄 | 회원 탈퇴 시: 탈퇴 후 **7일(탈퇴 철회 기간)**이 지나면 지체 없이 파기합니다. 다만 거래 기록이 있는 경우 관계 법령(전자상거래법 등)에 따라 5년간 보관한 뒤 파기합니다. |
| 개인정보 처리방침 | 「파기 절차 및 방법」 | 회원이 탈퇴를 신청하면 7일 동안 계정을 이용할 수 없게 막아 두고, 그 기간 안에 회원이 로그인해 탈퇴를 철회하면 계정을 되살립니다. 7일이 지나면 이메일 · 이름 · 연락처 등 회원 정보를 파기합니다. |
| 이용약관 | 「회원 탈퇴 및 자격 상실」 조항 | 회원은 언제든지 탈퇴를 신청할 수 있습니다. 탈퇴 신청 후 7일 이내에는 로그인하여 탈퇴를 철회할 수 있으며, 이 경우 탈퇴 시 내려간 게시물 · 등록한 결제 수단 · 구독은 회원이 다시 등록하여야 합니다. 7일이 지나면 탈퇴가 확정되며 되돌릴 수 없습니다. |

- 영어 판이 있으면 같은 뜻으로(withdrawal can be canceled within 7 days by signing in · deleted after 7 days).

### 3-2. 켠 뒤 달라지는 것

- 탈퇴 화면: 「탈퇴한 뒤 7일 안에 다시 로그인하면 탈퇴 취소」 안내 · 확인 체크 「7일이 지나면 되돌릴 수 없다」 · 거래 없는 회원도 「탈퇴 7일 뒤 파기」.
- 로그인: 7일 안의 탈퇴 계정은 비밀번호가 맞으면 「탈퇴 처리 중 — … 까지 취소 가능」 · **「탈퇴 취소하고 로그인」**.
- 파기 배치(pii_purge 03:30): 거래 없는 탈퇴는 탈퇴 7일 뒤 날짜부터 파기. 켜기 **전에** 탈퇴한 계정은 그때 정한 날(바로) 그대로.
- 탈퇴 때 내려간 매물 · 요청(ARCHIVED) · 끊긴 카드 · 구독 해지 예약은 취소해도 되살리지 않습니다(회원이 다시).
