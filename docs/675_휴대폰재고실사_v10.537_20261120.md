# 675. 휴대폰 재고 실사 (v10.537 · 2026-11-20)

## 1. 결론
휴대폰으로 운영 화면을 열어 **카메라로 바코드 · QR 을 읽어** ㊶ 로트 재고와 ㉟ 고정자산을 셉니다. 카메라 읽기는 브라우저 기본 기능 **BarcodeDetector** 를 쓰고(새 npm 없음), 지원하지 않는 브라우저(아이폰 사파리 등)는 **손 입력** 칸(블루투스 리더기도 글자 입력처럼 들어옴)으로 같은 일을 합니다. 로트는 새 **로트 실사 회차**(열기 → 읽기 → 닫기 → SUPER 차이 조정), 자산은 ㉟ 자산 실사 API 를 그대로 부릅니다. 위치: **소개몰 › 휴대폰 실사** · SB-ADM-DTX-030.

## 2. 휴대폰에서
| 항목 | 내용 |
|---|---|
| 화면 폭 | 운영 화면 1240px 아래 서랍 메뉴(v10.457) 그대로 · 이 화면은 한 줄(최대 640px) · 단추 높이 44px · 입력 글자 16px(휴대폰 확대 막음) |
| 카메라 | `'BarcodeDetector' in window` 이고 `getUserMedia` 가 있을 때 「카메라로 읽기」 — 뒤 카메라(`facingMode: 'environment'`) · QR · Code128 · EAN-13/8 · Code39 · UPC-A · DataMatrix 중 브라우저가 지원하는 것만 · 0.25초마다 읽기 · **같은 글자 2.5초 안에는 다시 안 셈** · 읽으면 짧게 진동 |
| https | 카메라는 **https 주소에서만** 열림(운영 화면 주소) — 점검판 http 에서는 손 입력만 |
| 손 입력 | 카메라가 없거나 권한을 거절하면 손 입력 칸 · Enter 로 보냄 · 보낸 뒤 비우고 다시 초점(리더기 연속 읽기) |
| 개인정보 | 카메라 그림은 브라우저 안에서만 읽고 **서버로 보내지 않음** — 읽은 글자(코드)만 보냄 |

## 3. 로트 실사(새 · qlt_lot_counts · qlt_lot_count_lines)
| 단계 | 규칙 |
|---|---|
| 열기 | 남은 수량이 있는 로트(정상 · 보류 · 회수)를 **열 때 장부 수량(expected)** 과 함께 줄로 · **한 번에 한 회차만**(DB 고유 색인 · 두 번째는 409) |
| 읽기 | ① 로트 QR `SGB-LOT-000123`(· `LOT-123` · 숫자) → ② 로트 번호 그대로 → ③ 상품 바코드(D256 acct_barcodes) 차례로 찾음 · 여럿이면 고르기 목록 · 못 찾으면 404 |
| 세기 | 기본 한 번 읽을 때 **+1** · 「수량 넣고 읽기」면 그 수로 · **처음 센 때의 장부 수량(book_qty)** 을 함께 남김 → 차이 = 센 수 − book_qty(센 뒤 출고 · 입고가 있어도 차이는 그대로) |
| 늦은 로트 | 열린 뒤 등록한 로트를 읽으면 줄을 더함(added_late · expected = 그때 수량) |
| 고치기 | 열린 회차만 · 센 수 · 메모 · 「세지 않음」으로 되돌리기 |
| 닫기 | 세지 않은 줄이 남으면 422 · 「그대로 닫기」면 그 줄은 차이 셈에서 빠짐 · 닫으면 못 고침(DB 트리거) |
| **차이 조정** | 닫은 회차 · **SUPER** · 줄마다 한 번 — D271 로트 조정(`adjustLot` = 원가 수불부 실사 조정 한 줄 + 로트 수불) · 같은 트랜잭션에서 조정 표시(adjusted_at) |
| 라벨 | 「QR 라벨 인쇄」 — 회차 줄의 로트 QR(SGB-LOT-…) · 상품 · 로트 번호 · 유통기한(lib/qr.ts · 인쇄 창) |

## 4. 자산 실사(㉟ 그대로)
열린 자산 실사 회차를 고르고 QR(`SGB-AST-000123`)을 읽으면 `POST /admin/hrx/stocktakes/{id}/scan`(둔 곳 함께) — 없음 · 메모 · 닫기 · 처분은 회계 › 자산 실사 화면. 권한도 ㉟ 그대로(hrx-stocktake 업무 · ADMIN · 지급 담당).

## 5. API(로트)
| API | 권한 | 설명 |
|---|---|---|
| GET · POST /admin/qlt/lot-counts | ADMIN · PAYOUT | 회차 목록 · 열기(감사 QLT_COUNT_OPEN) |
| GET /admin/qlt/lot-counts/{id} | 〃 | 줄 · 셈 |
| POST /admin/qlt/lot-counts/{id}/scan | 〃 | 읽기(+1 · counted) |
| PUT /admin/qlt/lot-counts/{id}/lines/{lotId} | 〃 | 고치기 |
| POST /admin/qlt/lot-counts/{id}/close | 〃 | 닫기(감사 QLT_COUNT_CLOSE) |
| POST /admin/qlt/lot-counts/{id}/lines/{lotId}/adjust | **SUPER** | 차이 조정(감사 QLT_COUNT_ADJUST) |

## 6. 처리방침 고칠 곳
없음 — 회원 개인정보를 모으지 않음(카메라 그림은 저장 · 전송하지 않고, 상품 · 자산 코드만 서버로).

## 7. 위험 · 확인
1. BarcodeDetector 는 안드로이드 크롬 · 엣지에서 됨 · 아이폰 사파리 · 파이어폭스는 없음(손 입력 · 리더기) — 실제 기기 확인 필요(현장 체크리스트: 휴대폰 크롬으로 운영 화면 https 열기 → 카메라 권한 허용 → 로트 QR 라벨 한 장 읽기).
2. 회차가 오래 열려 있으면 그동안 출고분은 book_qty 기준으로 차이가 맞음 — 그래도 하루 안에 닫기를 권함.
3. 조정은 원가 장부에 실사 조정 줄을 만듦(되돌리기는 반대 조정) — SUPER 만.
