# 793. 관 페이지 — 새 관 첫 화면 블록 편집 · 관 안 페이지 등록 (v10.650 ~ 652 · D311 · 2026-11-24)

> 대표 11/24 「새로운 관 생성시 페이지 등록기능, 페이지편집기능 추가」 → 「둘 다 · ADMIN 작성 · SUPER 게시」 → 계획 → 「모두 적용」
> = ① 계획대로 ② 관 안 페이지는 처음 관에도 ③ SUPER 는 혼자 고치고 바로 게시(두 사람 확인 없음). 앞 판 docs/791 · 792.

## 1. 쓰는 법

| # | 할 일 | 위치 |
|---|---|---|
| 1 | 관 고르기 | 운영 화면 › 관 관리 › 관 관리 › 하위 탭 **「관 페이지」**(관리자 ADMIN 도 보임) |
| 2 | **첫 화면 만들기**(운영 화면에서 만든 새 관만) 또는 **새 페이지**(주소 · 제목 — 모든 관 · 허브 빼고) | 같은 화면 |
| 3 | 블록 더하기 · 위아래 옮기기 · 빼기 → **초안 저장** | 「편집」 |
| 4 | 미리보기(글 · 순서) 확인 → **게시**(SUPER) | 같은 화면 |
| 5 | 사용자 웹 확인 — 새 관 첫 화면 `/g/<코드>` · 관 안 페이지 `/<관 주소>/info/<주소>`(예: /money/info/guide · /g/edu/info/guide) | 사용자 웹 |
| 6 | 고칠 때 — 초안을 고쳐 저장(사용자 웹은 그대로) → 다시 게시하면 새 판. 예전 판은 「이 판으로 초안」 → 게시. 내리려면 「숨기기」(SUPER) | 같은 화면 |

- 관 안 페이지 주소는 **/info/** 아래입니다. 소개몰의 `/health/p/…`(상품)와 겹치지 않게 했습니다.
- 게시된 관 안 페이지는 관 화면에 작은 메뉴 줄로 나옵니다(「관 메뉴에 보임」을 끄면 메뉴에서만 빠짐).

## 2. 블록 9종(v10.654 사진 묶음 더함 · 8절)

| 블록 | 넣는 것 | 규칙 |
|---|---|---|
| 머리 띠 | 제목 · 한 줄 설명 · 그림 주소 · 단추 1개 | 제목 꼭 · 80자 |
| 글 | 제목 · 글(5,000자) | **굵게** · 줄 앞 「- 」 목록 · [글자](주소) 링크만 — HTML 태그는 받지 않음 |
| 바로가기 단추 | 1 ~ 4개(글자 · 주소) | 주소는 `/…`(관 안) 또는 `https://…`만 |
| 사진 | 그림 주소 · 그림 설명(꼭) · 아래 글 | 그림 주소도 같은 규칙 |
| 매물 목록 | 제목 · 개수 1 ~ 20 · 정렬(최신 · 인기 · 소개비 · 마감) · 업종 | 그 관 게시 매물 |
| 업종 칩 | 제목 | 그 관 승인 업종 |
| 공지 | 제목 · 개수 1 ~ 10 | 그 관 공지 |
| 자주 묻는 질문 | 제목 · 질문 · 답 1 ~ 20쌍 | 펼침 |

- 한 페이지 블록 30개까지. 그림은 편집 화면에서 **「그림 올리기」**로 바로 올리거나(v10.653 · 7절) 주소(`/…` · `https://…`)를 넣습니다.

## 8. 편집에 사진 추가 (v10.654)

> 대표 11/24 「페이지 이미지는 아니고, 편집에 사진추가 하는 기능」 → 세 가지 모두.

| # | 기능 | 쓰는 법 |
|---|---|---|
| 1 | **「+ 사진 추가」** | 편집 화면의 블록마다 아래(블록이 없으면 맨 위)에 있음 — 누르고 여러 장 고르거나 **사진을 끌어 놓으면** 그 자리에 사진 블록으로 바로 들어감(설명 처음 값 = 파일 이름) |
| 2 | **글에 사진 넣기** | 글 블록의 「글에 사진 넣기(커서 자리)」 — 커서가 있던 줄에 사진이 끼워짐(글 칸에 `![설명](주소)` 한 줄로 보임 · 끌어 놓기도 됨) · 사용자 웹은 글 사이에 사진으로 그림 · 한 글에 20장까지 |
| 3 | **사진 묶음** 블록(새 블록) | 「블록 더하기」 › 사진 묶음 — 여러 장을 한 줄 2 · 3 · 4장 격자로 · 사진마다 설명 · 아래 글 · 30장까지 |

- 사진은 모두 JPG · PNG 5MB 까지 · 올리는 길은 7절과 같음(PAGE_IMAGE · 서버가 실제 바이트 확인).
- 블록 종류는 이제 9가지(사진 묶음 더함) · 마이그레이션 더함 없음.

## 9. HTML 불러오기 · 내려받기 · HTML 로 편집 · 복사 · 편집 보강 (v10.655)

> **HTML 은 그대로 저장하지 않습니다.** 불러온 HTML · 고친 HTML 은 모두 블록으로 바꿔 초안에 넣고, 서버는 블록을 다시 검사합니다(스크립트 · 외부 코드가 들어갈 길 없음).

| # | 기능 | 위치 · 쓰는 법 |
|---|---|---|
| A | **HTML 불러오기** | 편집 화면 › 「불러오기 · 내려받기」 › 「HTML · 블록 파일 불러오기」 — .html 파일 고르기 또는 붙여 넣기 · 「지금 초안을 바꿈 / 뒤에 붙임」 · 제목 → 머리 띠(바로 아래 짧은 문단은 설명) · 소제목 → 글 블록 제목 · 문단 · 목록 · 굵게 · 링크 → 글 · 그림 → 사진(HTML 에 박힌 그림 data:image 는 올려서 주소로) · 접는 질문(details) → 자주 묻는 질문 · **스크립트 · 스타일 · 표 · iframe · 입력 칸 · javascript 주소는 빼고 「뺀 것」 목록으로 알림** |
| B | **HTML 내려받기** | 「HTML 내려받기(초안)」 · 「게시 판 내려받기…」에서 판 고르기 — HTML 파일 하나(스크립트 없음 · 그대로 열어 봄 · 다시 불러오면 같은 블록) |
| C | **블록 파일** | 「블록 파일 내려받기(초안)」 · 게시 판 블록 파일 · 불러오기(.json · format sgb-gwan-page) — 백업 · 다른 페이지에 그대로 |
| D | **다른 페이지 복사** | 「다른 페이지 복사」 — 관 고르기 → 페이지 「가져오기」(그 페이지의 초안 · 바꿈 / 뒤에 붙임) |
| E | **편집 보강** | 블록마다 「복제」 · 「실행 취소」(20단계) · **저장 안 한 고침 경고**(목록으로 나가기 · 창 닫기) · 「휴대폰 폭(375px)으로 미리보기」 · 「판 비교」(게시 판 ↔ 지금 초안 — 더함 · 뺌 · 바뀜) |

- 확인: 개발 서버 점검용 크롬에서 변환기 왕복 시험 — 스크립트 · 스타일 · iframe · 표 · javascript 링크 · 그림 빠짐 · 블록 파일 왕복 같음 · 내려받은 HTML 다시 불러오기 같음(박힌 그림 자리표만 다름 — 올린 뒤 주소로).
