# 549. 업무 보고 — 일보 (v10.412 · 2026-11-20)

> ⑰ 첫 번째(D250). 대표 11/19 「일보 · 주보 · 월보 … 둘 다」(보고 모양 + 운영 기능) · 「개발 모두 진행」.

## 1. 결론

- 운영 화면 새 메뉴 **보고 › 일보**(ADMIN · SUPER)에서 하루(한국 날짜) 숫자를 한 장으로 봅니다.
- 담는 것: 회원(가입 · 탈퇴) · 거래(매물 · 요청 · 소개 · 성사) · 소개몰(주문 · 결제 · 취소 · 반품) · 매출(전표 기준 공급가 · 비용 · 이익) · 고객센터(문의 · 답변 · 답변 전 · 기한 넘김) · 운영 알림(경고 · 긴급) · 회계 할 일(열린 회계 알림 · 다가오는 신고 기한) · 업무 일지(몇 명 · 몇 건 · 몇 시간) · 서버 디스크.
- **숫자만** — 이름 · 연락처 · 개별 금액은 넣지 않습니다(보내기 · CSV 도 같음).
- 정기 작업 `ops_report`(매일 07:00)가 **전날 일보**를 남깁니다(같은 기간 정기 작업 보고는 한 번). 「지금 만들어 남기기」는 몇 번이든 새 줄.
- 남긴 보고는 `report_snapshots`(쌓기만 · 고치기 · 지우기 DB 가 막음). 남긴 보고가 없는 날은 화면이 지금 계산해 보여 주고 저장하지 않습니다.
- 이미 있는 「운영 하루 요약」(launch_digest · 매일 09:00 · 텔레그램)은 그대로입니다 — 일보는 같은 성격의 숫자를 기간별로 남기고 비교하는 것.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D250** | `report_snapshots`(쌓기만) · 정기 작업 `ops_report`(07:00) |
| API | `GET /admin/work-reports/view?kind=DAY&period=` · `POST /admin/work-reports/make` · 감사 `REPORT_MAKE` |
| 운영 화면 | 보고 › **일보**(SB-ADM-WRP-010) |

## 3. 주의

1. 매출은 전표 기준(공급가 · 부가세 뺌 · 해 마감 전표 뺌) — 회사 장부 전체가 아니라 소개뱅크 시스템을 지난 돈입니다.
2. 「만들 때」 칸(답변 전 · 기한 넘김 · 확인 안 한 긴급 · 회계 알림 · 디스크)은 보고를 만든 순간의 값입니다.
3. 경로 이름은 `work-reports` — 회원 신고(`/admin/reports/...`)와 헷갈리지 않게.
