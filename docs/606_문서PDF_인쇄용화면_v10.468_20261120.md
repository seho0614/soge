# 606. 문서 PDF(인쇄용 화면) (v10.468 · 2026-11-20)

## 1. 결론
**견적서 · 주문서 · 거래명세서 · 발주서 · 급여명세서**를 A4 인쇄용 새 창으로 열고, 위의 **「PDF 로 저장」** 단추로 브라우저 인쇄 창을 띄워 **대상(프린터) = 「PDF로 저장」**을 고르면 PDF 파일이 됩니다. **서버에 PDF 라이브러리를 설치하지 않습니다**(npm 의존성 더하지 않음 · DB 바뀜 없음). 공용 인쇄 창 `web/src/lib/printDoc.ts` · 화면 SB-ADM-SAL-030.

| 문서 | 여는 곳 | 파일 이름(창 제목) |
|---|---|---|
| 견적서 · 주문서 · 거래명세서 | 회계 › 견적 · 명세서 › 열기 › 「인쇄」 | 문서 번호(예: Q-2611-0001) |
| 발주서 | 회계 › 견적 · 명세서 › 「발주서 인쇄」 | 발주서 P-000001 |
| 급여명세서(관리) | 회계 › 인사 › 급여명세서 › 한 줄 「인쇄」 | 급여명세서_2026-11_이름 |
| 급여명세서(본인) | 사무 › 내 인사 › 급여명세서 「보기 · 인쇄」 | 같음 |

## 2. PDF 로 저장하는 법(직원 안내 · 창 위에도 같은 글)
1. 「PDF 로 저장」을 누릅니다(인쇄 창이 뜸).
2. **대상(프린터)**을 **「PDF로 저장」**으로 고릅니다(크롬 · 엣지 · 웨일 같음 · 사파리는 왼쪽 아래 「PDF」).
3. 용지 **A4** · 여백 **기본** · 「배경 그래픽」을 켜면 표 머리 바탕도 나옵니다.
4. 「저장」 → 파일 이름은 창 제목(문서 번호 · 급여명세서_달_이름)이 기본으로 들어갑니다.
- 팝업이 막혀 창이 안 뜨면 주소창 오른쪽 팝업 차단을 이 사이트만 허용하고 다시 누릅니다.

## 3. 인쇄 모양(@media print)
- `@page { size: A4; margin: 14mm 12mm }` · 위 단추 줄(「PDF 로 저장」 · 「인쇄」 · 「닫기」 · 안내)은 **인쇄할 때 숨김**.
- 표 머리줄은 쪽이 넘어가도 다시 찍힘(`thead { display: table-header-group }`) · 한 줄이 두 쪽으로 갈라지지 않음.
- 견적서 · 거래명세서 · 발주서는 끝에 **공급자 (인)** 칸 · 맨 아래 출력 시각.
- 급여명세서는 지급 · 공제를 나란히(좁은 창은 아래로) · 실지급액 · 회사 부담(참고) · 안내에 「개인 정보 — 저장한 파일은 본인에게만 전달」.
- 글자 12 · 13 · 14 · 24px · 모서리 7 · 999px · 폭 640px 기준(디자인 기준 · 인쇄 창이라 운영 화면 색 토큰 대신 검정 · 회색 이름 색).

## 4. 바뀐 파일
- `web/src/lib/printDoc.ts`(새) — `openPrint({ title, body, kind, sign })` · 팝업이 막히면 false.
- `web/src/app/admin/Erp.tsx` — `printHtml` 이 openPrint 를 부름(견적서 · 주문서 · 거래명세서 · 발주서 본문은 그대로).
- `web/src/app/admin/Hr.tsx` — `printSlip` 이 openPrint 를 부름(관리 · 내 인사 둘 다).
- 서버 · DB 바뀜 없음 — 인쇄 자료는 이미 있는 API(`GET /admin/acct/sales-docs/{id}` 회사 정보 포함 · `GET /admin/acct/sales-docs/po/{id}/print` · `GET /admin/acct/payslips/{lineId}` · `GET /admin/me/hr/payslips/{lineId}`).
