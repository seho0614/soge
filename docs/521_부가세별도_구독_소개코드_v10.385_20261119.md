# 521. 부가세 별도 — 구독 · 소개코드 결제 (v10.385 · 2026-11-19)

> 대표 11/19 세무 답 「부가세는 별도」 → ⑩ 계획 「승인 + 통과하면 병합」 · 법무 확인 끝남(11/19). 마이그레이션 **D243**(세 판 함께). 이 문서는 ①. ② 입점 정산은 docs/522, ③ 리드 캐시는 docs/523.

## 1. 결론

- **시작일 설정 `vat.separate_from`**(운영 화면 정책 › 전체 설정 · **SUPER** · 처음 비어 있음 = 지금과 같음). 그 날(한국 00:00)부터 **결제 = 요금(공급가) + 부가세 10%**(부가세 = 내림(공급가 × 10%) · 정액 노출과 같은 셈).
- 시작일은 **오늘 이후 날짜만**(지난 결제는 바꾸지 않음 · 422 `VAT_START_PAST`) · SUPER 아니면 403 `VAT_SETTING_SUPER`. 「예약 변경」(D241)으로 시행일 00:00 에 넣어도 됩니다.
- 표시 요금(요금제 금액 · 소개코드 단가)은 그대로 공급가 — 결제창 · 「이번에 결제할 금액」에는 부가세를 더한 금액과 「(부가세 ○원 포함)」.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D243** | 설정 `vat.separate_from` · 함수 `fn_vat_separate(시각)` · `fn_vat10(공급가)` · `subscription_invoices.supply · vat`(시작일 뒤 청구만 · 공급가 + 부가세 = 금액) · `referral_code_payments.vat`(금액 = 단가 × 건수 + 부가세) · `v_billing_due` 금액 = 묶인 요금 + 부가세 · 끝에 `supply · vat` 칸 |
| 첫 결제 `POST /subscriptions` | 결제사 승인 금액 = 요금 + 부가세 · 청구서에 공급가 · 부가세 |
| 정기 결제(recurring-batch) | `v_billing_due` 금액(부가세 포함)으로 청구 · 청구서에 공급가 · 부가세 · 묶인 요금(가격 인상 보호)은 공급가에 그대로 |
| 소개코드 추가 결제 | 금액 = 단가 × 건수 + 부가세 · `GET /me/referral-codes/quota` 에 `extraCodeCharge` · `extraCodeVat` · `vatSeparate` |
| 요금제 목록 `GET /subscription-plans` | `chargePrice` · `extraCodeCharge` · `vatSeparate` 칸 더함 |
| 사용자 웹 | 요금제 고르기 결제 금액 · 결제 단추 · 소개코드 결제 단추가 결제 금액(부가세 포함)으로 |
| 환불 | 그대로 — 그 기간 청구 금액 전부(부가세 포함)를 취소 |
| 전표(⑨) | `SUB_PAID` · `SUB_REFUND` · `REFCODE_PAID` — 부가세 칸이 있으면 그 값(공급가 · 부가세예수금) · 없으면 전처럼 `acct.sub_vat_included` |
