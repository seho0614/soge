# 686. 번역 메모리 (v10.548 · 2026-11-20)

## 1. 결론
승인 · 자동 승인된 번역을 **(언어, 원문 열쇠)** 로 모아 두고, 자동 번역 배치(translate_jobs)가 **엔진을 부르기 전에** 같은 원문이면 그 번역을 그대로 씁니다(비용 0). **사람이 넣거나 승인한 번역(HUMAN)이 먼저**이고 엔진 번역(MACHINE)은 사람 것을 덮지 못합니다. 처음에는 꺼져 있습니다(`sfx.tm` off). 위치: 운영 **관 관리 › 번역 메모리**(SB-ADM-SFX-030 · 탭 `sfx-tm`).

| 항목 | 규칙 |
|---|---|
| 열쇠 | `fn_sfx_tm_key(원문)` = md5(앞뒤 공백 떼고 공백을 한 칸으로 줄인 원문) · 언어마다 한 줄 |
| 채우기 | `content_translations` 가 APPROVED(사람) · AUTO_APPROVED(엔진)일 때 트리거 `trg_sfx_tm_feed` — 지금 원문과 같은 번역만 · 소개광장 글 · 댓글(POST · COMMENT) · 점검판 MOCK · 메모리에서 온 줄(TM)은 넣지 않음 |
| 사람 먼저 | MANUAL 이거나 사람이 승인한 번역 = HUMAN · 자동 승인 = MACHINE · HUMAN 은 MACHINE 이 덮지 못함 · 운영이 고치면 HUMAN |
| 쓰기 | `translate.service` 의 엔진 부르기 바로 앞(`sfxTmApply`) — 칸마다 찾아 엔진 `TM` · 자동 승인으로 저장 · 남은 칸만 엔진 · 모두 쓰면 결과 `TM_REUSED` · 「다시 시도」(FORCE)는 엔진으로 |
| 안전 | 쓸 때 금칙어(BLOCK) · 원문에 없는 연락처(`suspiciousTranslation`) 다시 검사 — 걸리면 그 칸은 엔진으로 · 끈 줄(is_active false)은 쓰지 않음 |
| 보관 | `sfx.tm_keep_days` 365(90 ~ 999) 쓰이지 않은 줄은 매일 05:20 지움 |
| 화면 | 찾기(원문 · 번역 글자) · 출처 거르기 · 고치기(300자까지 — 긴 번역은 관 관리 › 번역에서) · 끄기 · 「지금 번역으로 채우기」(최근 2000줄) |

## 2. 전체 구조
1. 엔진 CHECK 에 `TM` 더함(D118 목록 + TM) · 표 `sfx_tm`(열쇠 CHECK = 함수 결과) · 트리거 · `fn_sfx_tm_backfill(limit)`.
2. 서버 `src/modules/sfx/tm.ts` · 패치 `translate.service.ts`(import · 엔진 앞 한 덩어리) · 운영 `Translations.tsx` 결과 이름 `TM_REUSED`.
3. 소개광장 「번역 보기」(board-translate)에는 넣지 않음 — 회원 글 · 댓글은 메모리에 남기지 않기로(NOTES 3절).
