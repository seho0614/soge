# 809. 페이지 수정 가능 스위치 · 관 열림 규칙 (v10.701 · D322 · 2026-11-24)

> 대표 11/24 「페이지 목록에서 슈퍼유저가 수정 가능 여부를 지정하고, 수정 가능 시 수정할 수 있다 · 엔진의 기능은 수정 불가 · 디자인적인 부분은 변경 가능 · 관이 열려 있는 상태에서 변경 불가 · 관을 닫고 수정 가능」
> → 관 열림 규칙 「말씀대로 — 열려 있으면 편집 불가」 · 메인 「스위치만 따름(권장)」. 앞 판 docs/808.

## 1. 규칙

| 페이지 | 수정 가능 스위치(SUPER) | 관 열림 규칙 | 처음 |
|---|---|---|---|
| 메인 · 관 메인 5 · 허브 메인(꾸밀 페이지) | 수정 불가면 초안 저장 · 게시 · 예약 · 처음 배치로 · 되돌리기 모두 422 **SITE_LAYOUT_LOCKED** | 관 메인 · 허브 메인은 **그 관이 열려 있으면 422 SITE_LAYOUT_GWAN_OPEN** — 관 관리 › 관 설정에서 관을 닫은(중지) 뒤 고치고, 다 고친 뒤 다시 엶 · 메인은 관 규칙 없음 | **수정 불가** |
| 관 안 페이지 · 새 관 첫 화면 | 수정 불가면 저장 · 게시 · 예약 · 되돌리기 · 번역 초안 422 **GWAN_PAGE_LOCKED** | (이번 판은 넣지 않음 — 대표 확인 뒤) | **수정 가능**(지금까지처럼) |

- **엔진 기능은 고칠 수 없습니다** — 검색 · 목록 · 정렬 · 주문 · 정산 · 업종 등은 코드 그대로이고, 꾸밀 페이지는 디자인(글자 · 그림 · 순서 · 숨기기 · 블록 · 소개몰 고른 상품)만 바꿉니다.
- 미리보기 링크 만들기 · 끊기는 잠겨 있어도 됩니다(보기만).
- 예약 게시는 그 시각에 수정 불가이거나 관이 다시 열려 있으면 **기다립니다**(풀리면 게시).
- 관 「닫기」 = 관 설정의 공개 상태 끄기(중지 · is_active) — 연 날(opened_at)은 그대로라 다시 열면 그대로 운영(DB 가 「연 관은 닫을 수 없음」은 opened_at 기준).
- 운영에서 관을 닫는 동안 그 관은 손님에게 안 보입니다(목록 · 등록 중지) — 짧게 닫고 고친 뒤 바로 엽니다.
