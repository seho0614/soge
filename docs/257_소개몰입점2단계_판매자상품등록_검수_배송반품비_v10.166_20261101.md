# 257. 소개몰 입점 2단계 — 판매자센터: 상품 등록 → 운영 검수 · 배송비 · 반품비 (꺼진 채로) (v10.166 · 2026-11-01)

> 대표 결정(11/1 · decisions/mall-return-refund #15 — C 반품 배송비는 판매자가 정하되 왕복 6,000원 상한 · A 판매대금 판매자 직접 귀속) · 계획 「승인」(판 5개 중 2번째).
> 마이그레이션 **1개(D156)** · 194. 앞 판: v10.165(docs/256).

## 1. 무엇을 하나

입점 승인된 판매자가 판매자센터에서 상품을 초안으로 등록하고 「검수 요청」을 하면, 운영이 소개몰 정산 화면에서 통과 · 반려한다. 통과한 상품만 판매자가 「판매 시작」을 누를 수 있고, 그때 **DB 가** 검수 통과 · 판매자 승인 · 결제대행사 하위가맹점 등록 · 입점 켜짐(`mall.tenant`)을 모두 본다. 판매자는 기본 배송비 · 무료 기준 · 회원 사정 왕복 반품비(6,000원 상한)를 정한다 — 주문 · 반품 계산에 쓰는 것은 v10.167.
