# 603. 브라우저 알림 (v10.465 · 2026-11-20)

## 1. 결론
운영 화면을 **열어 둔 동안** 급한 운영 알림 · 나에게 온 결재 · 업무 요청을 **브라우저 알림(Notification API)**으로 띄웁니다. 서버 푸시 · 서비스 워커 · VAPID 키가 없어 외부 연동이 아니고, 창을 닫으면 오지 않습니다. **계정마다 켜고 끄며(처음 꺼짐)** 브라우저가 허락할 때만 띄웁니다. 위치: **사무 › 내 알림** · SB-ADM-OFC-040.

| 종류 | 무엇 | 누구 |
|---|---|---|
| OPS | 급한 운영 알림(CRITICAL · 확인 안 함 · 풀리지 않음 · 묻는 때부터 24시간 안) | ADMIN · SUPER 만(운영 알림 화면을 보는 역할) |
| APV | 결재 차례 — 결재함(v10.424 inbox)과 같은 셈(중간 단계 · 마지막 SUPER 단계) | 운영 역할 모두 |
| TASK | 나에게 온 업무 요청 · 내 업무 기한 오늘 · 내일 · 지남 · 내가 요청한 업무 끝남 · 내 업무 새 댓글 | 운영 역할 모두 |

## 2. 어떻게 도나
1. 사무 › 내 알림 「켜기」 → 브라우저가 한 번 허락을 물음(거절하면 켜지지 않음 · 주소창 자물쇠 › 알림 › 허용).
2. 운영 화면(Console)의 보이지 않는 부품 BrowserNotify 가 ofc.notify_poll_sec(처음 60초 · 30 ~ 300)마다 GET /admin/me/notify/feed 를 물음.
3. 서버는 지금 띄울 만한 것을 열쇠(key)와 함께 돌려주고, 화면은 이 브라우저에서 이미 띄운 열쇠를 빼고 새것만 띄움(한 번에 4건 이상이면 「새 알림 n건」 하나). 알림을 누르면 그 화면으로.
4. 이미 띄운 열쇠는 이 브라우저 localStorage 에 계정마다(최근 300개) — 막힌 브라우저(사생활 창 등)는 메모리만(새로 고치면 한 번 더 뜰 수 있음).

## 3. 켜고 끔을 서버에 두는 까닭(localStorage 가 아니라)
- 한 PC 를 여러 운영자가 번갈아 쓰면 브라우저 저장은 계정을 섞음 — 서버(ofc_notify_prefs)는 계정마다 정확함.
- 꺼진 계정은 서버가 feed 를 빈 목록(on:false)으로 돌려 일을 하지 않음 · 전체 끄기(ofc.browser_notify off)도 서버 한 곳에서.
- 브라우저 「허락」은 브라우저마다 따로라, 새 브라우저에서는 「켜기」를 한 번 더 눌러 허락만 받으면 됨(계정 설정은 그대로).

## 4. 단추 자리
상단바 · 왼쪽 트리(AdminTree · v10.457)는 고치지 않습니다. 켜기 단추는 **사무 › 내 알림** 탭(사무 그룹 = 내 인사 · 결재함 · 업무 요청 · 출장 — 알림 종류와 같은 묶음 · 권한 계층 그룹 글자를 옛 시험이 보지 않게 바꾸지 않으려고). 알림을 묻는 부품은 탭과 상관없이 Console 에 한 번 놓음(그리는 것 없음).

## 5. API · 설정 · 표 (D263)
| 방법 | 주소 | 설명 |
|---|---|---|
| GET | /admin/me/notify | 내 설정 · 전체 스위치 · 묻는 간격 · OPS 가능 여부 |
| PUT | /admin/me/notify | enabled · kinds(OPS · APV · TASK) · 전체 꺼져 있으면 켜기 422 OFC_NOTIFY_OFF |
| GET | /admin/me/notify/feed?since= | 지금 띄울 것(켜지 않았거나 전체 끄면 on:false · 빈 목록) |

- ofc_notify_prefs(account_id · enabled 처음 false · kinds) · 설정 ofc.browser_notify(on) · ofc.notify_poll_sec(60).
- 본인 것만이라 권한 주소 맵에 넣지 않음(내 인사와 같음 · @Roles 만) · 업무 ofc-notify(VIEW · EDIT).
- 세무사 빠짐(결재 · 업무가 없음).
- 알림 글에는 금액 · 개인정보를 넣지 않음(제목 · 이름까지).

## 6. 주의
1. 화면을 닫거나 컴퓨터가 잠들면 오지 않습니다 — 급한 운영 알림은 지금처럼 메일 · 텔레그램이 기본입니다.
2. 브라우저 · 운영체제의 「방해 금지」가 켜져 있으면 보이지 않을 수 있습니다(「시험 알림」으로 확인).
3. 묻는 간격을 너무 짧게 하면 운영자 수 × 1분마다 결재함 셈을 합니다 — 처음 60초.
