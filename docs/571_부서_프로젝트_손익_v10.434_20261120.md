# 571. 부서 · 프로젝트별 손익 (v10.434 · 2026-11-20)

## 1. 결론
부서(관 · 사업부) · 프로젝트를 만들고 전표에 꼬리표를 붙여 **부서 · 프로젝트별 매출 · 비용 · 이익**을 봅니다. 위치: **회계 › 부서 손익**(설정 · 보고 묶음) · SB-ADM-ACC-390.

| 항목 | 내용 |
|---|---|
| 표 | acct_depts(처음 HQ 본사 공통) · acct_projects(코드 · 이름 · 부서 · 기간 · 끝남) |
| 꼬리표 차례 | ① 전표 꼬리표 acct_entry_tags(사람이 정함) > ② 근거 꼬리표 acct_source_tags(매입 PURCHASE · 경비 EXPENSE_APPROVED · 수동 전표 MANUAL 번호에 전표 만들기 전에도) > ③ 돈 흐름 기본 부서 acct_rule_dept |
| 셈 | v_acct_line_tags · 계정 종류(REVENUE · EXPENSE) · 해 마감 전표 뺌 · 꼬리표 없는 몫은 「정하지 않음」 |
| 기록 | acct_tag_changes(쌓기만 · 사유) |
| 권한 | 부서 · 프로젝트 · 기본 부서 SUPER / 꼬리표 · 보기 SUPER · PAYOUT |

## 2. 판단 — 왜 전표 줄에 칸을 더하지 않았나
전표 줄(acct_lines)은 쌓기만(D242 · 고치기 막음)이라 나중에 부서를 바꿀 수 없습니다. 그래서 **전표 단위 꼬리표**로 따로 두고, 셀 때 합칩니다. 한 전표를 여러 부서로 나누는 것(배부)은 다음에(수동 전표로 나눠 넣기).
매입 · 경비 넣기 화면에서 바로 고르는 칸은 아직 없고, 「부서 손익 › 전표 꼬리표」 또는 근거 꼬리표 API 로 붙입니다(다음 판에서 넣기 화면 연결).
