| 1 | **빈 글자 → 형식 오류(400)** | 주소 · 검색어 · 본문에 빈 글자(`%00` · `\u0000`)가 섞여 DB 가 받지 않으면(`invalid byte sequence … 0x00` · `unsupported Unicode escape sequence`) 500 대신 **400 `VALIDATION_ERROR` 「형식이 올바르지 않습니다 (0x00).」**(영어 사전 있음) — 서버 오류로 세지 않음(알림이 헛울리지 않음) |

| 3 | **검색 결과용 정보** | 매물 상세: **대표 주소**(canonical · `?ref=` 같은 꼬리가 붙어도 하나로) · 공유 미리보기에 첫 사진 · 이동 경로(홈 → 관 → 매물) 구조화 정보 · **공개(PUBLISHED) 아닌 매물은 검색에 싣지 않음**(noindex). 소개몰 상품 상세: 대표 주소 · 설명 · 그림 · **상품 구조화 정보**(이름 · 코드 · 분류 · 별점) — **가격 · 재고는 「주문 받기」가 켜져 있을 때만**(꺼진 채 「구매 가능」으로 싣지 않음) |

## 3. 운영에서 (적용 뒤)

1. 구글 서치 콘솔 → 속성 추가(URL 접두어 `https://sogaebank.com`) → 「HTML 태그」 → `content="…"` 따옴표 안 값만 복사 → 운영 화면 설정 `seo.verify_google` 에 넣기 → 5분 뒤 「확인」
2. 네이버 서치어드바이저 → 사이트 등록 → 「HTML 태그」 → 같은 방식으로 `seo.verify_naver`
3. 확인 뒤 각 사이트에 `https://sogaebank.com/sitemap.xml` 제출 · **값은 지우지 않음**(지우면 소유 확인이 풀림)
4. 등록 화면 · 절차는 바뀔 수 있음 — 등록할 때 화면 기준
