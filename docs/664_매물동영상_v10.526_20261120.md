# 664. 매물 동영상 (v10.526 · 2026-11-20)

## 1. 결론
회원이 매물마다 **짧은 MP4 동영상 1개**를 붙이고, **운영자가 확인(승인)한 것만** 매물 상세에 보입니다. 올리기는 **기존 파일 길 그대로**(새 파일 용도 `LISTING_VIDEO` · MP4 · 50MB 상한), 용량 · 길이는 서버가 다시 확인합니다. 스위치 `lsy.video` **처음 꺼짐**.

## 2. 흐름
| 단계 | 내용 |
|---|---|
| 올리기 | `POST /files`(purpose `LISTING_VIDEO`) → PUT → `complete` — 크기 · SHA-256 · 매직바이트(MP4 ftyp) 확인(기존 그대로) |
| 붙이기 | `POST /me/lsy/listings/{id}/video` — 내 매물(게시 · 검수 중 · 임시 · 반려) · 내 READY 파일 · `lsy.video_max_mb`(30) · **길이는 서버가 MP4 머리(moov › mvhd)로 잼**(`lsy.video_max_sec` 60) · 못 읽으면 422 · 새로 붙이면 앞 영상은 REPLACED |
| 검수 | 검수 › 매물 동영상(SB-ADM-LSY-030) — 운영 · 검수 담당이 `GET /files/{id}` 로 보고 승인 · 반려(사유 · 회원에게 보임) |
| 공개 | `GET /site/lsy/listings/{id}/video` — 스위치 켬 · 매물 게시 중 · 영상 승인 · 파일 READY 일 때만 **5분짜리 주소**(S3 서명 · LOCAL 토큰) |
| 빼기 | `DELETE /me/lsy/listings/{id}/video` — 붙은(대기 · 승인) 영상 파일은 지우지 못함(`trg_lsy_video_file_guard` · 먼저 빼기) |

- `fn_file_can_read` 는 **고치지 않음** — 공개 주소는 이 API 가 조건을 보고 직접 만들고, 주인 · 운영(ADMIN · SUPER · REVIEWER)은 기존 규칙으로 엶.
- `ck_files_purpose` 는 D269 목록 그대로 + `LISTING_VIDEO`(나중 묶음이 이 제약을 다시 쓰면 목록을 합칠 것 — NOTES).
- 매물 글을 고쳐도 승인한 영상은 그대로(영상이 바뀌면 다시 검수).

| 종류 | 이름 |
