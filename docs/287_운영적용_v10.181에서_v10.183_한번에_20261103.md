### 4-2. 알아 둘 것

1. **`DISK_LOW` 가 뜨면**(디스크 85% 이상) 순서대로: ① 오래된 백업 묶음 정리(`~/sgb-data/backup/uploads`) ② 남은 옛 판(`~/sgb-releases` — apply 가 하나만 남김) ③ 그래도 모자라면 AWS 콘솔에서 EBS 늘리기(비용은 **최신 요금 확인 필요**). 기준은 운영 화면 설정 `ops.disk_warn_pct`(0 이면 끔).
2. 사이트가 이상하다는 말이 오면 위험감지 › 「서버 오류」를 찍어 보내 주십시오 — 요청 번호로 원인을 찾습니다. API 를 다시 띄우면(적용 · pm2 restart) 목록이 비워집니다.
3. 메인 투표 자동 채우기를 원하지 않으면 「이건 어때? 투표」 › 「자동 채우기 끄기」. 비어 있는 종류는 새 투표를 만들어 열어야 메인에 나옵니다.
4. docs/284 4-2 ~ 4-5(검색 등록 · 올린 파일 백업 등록 · 알아 둘 것 · 2단계 인증 켜기)는 **그대로 유효**합니다 — 이번 적용과 관계없이 하시면 됩니다.
