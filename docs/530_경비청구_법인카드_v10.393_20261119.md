# 530. 경비 청구 · 법인카드 (v10.393 · 2026-11-19)

> ⑫ 두 번째(D245). 대표 11/19 「승인 + 통과하면 병합」 — 경비 청구 · 법인카드(SUPER 승인 · 본인 건 불가 · 카드 CSV).

## 1. 결론

- 운영 화면 **회계 › 경비 · 법인카드**에서 운영자 누구나(ADMIN · PAYOUT · REVIEWER · 파트너 담당 · SUPER) **개인 돈으로 쓴 경비**를 청구합니다 — 쓴 날(오늘까지) · 비용 계정 · 금액(부가세 포함) · 공제 부가세 · 증빙 종류 · 내용 · 증빙 파일 3개(JPG · PNG · PDF · 10MB).
- **승인 · 반려는 SUPER 만**, **본인 청구는 승인 · 반려할 수 없습니다**(API 가 막고 DB 트리거도 `EXPENSE_SELF` 로 다시 막음). 반려는 사유(2 ~ 200자).
- **지급 처리는 지급 담당(PAYOUT)** — 승인된 것만 · 본인 경비는 본인이 지급 처리할 수 없음. 통장 출금은 ⑪ 은행 맞추기에서 이 전표와 맞춥니다.
- 상태는 앞으로만 — 청구 → 승인 → 지급함 / 청구 → 반려 · 취소(본인 · 청구 상태만). **청구 내용은 고치지 않습니다**(취소하고 다시 청구). 지우지 않습니다.
- **간이영수증은 매입세액 공제가 안 되어 부가세 0**(DB 도 막음). 카드 영수증 · 현금영수증(지출 증빙) · 세금계산서는 공제 부가세를 적으면 부가세대급금으로 갑니다(「÷ 11 채우기」 단추).
- **법인카드** — 카드사 홈페이지 「이용 내역 → 엑셀(CSV) 저장」 파일을 올리면 머리줄 이름으로 이용일 · 가맹점 · 이용 금액 · 승인번호 · 카드번호(끝 4자리만 남김) · 취소 칸을 찾습니다. **같은 줄은 한 번만**, 취소는 음수.
- 카드 줄마다 **계정(비용 · 자산) · 공제 여부**를 고르고 「장부에 넣기」(되돌리지 않음 · 바로잡기는 수동 전표) 또는 「넣지 않음」(개인 사용 등 · 사유).
- 카드 대금(통장에서 빠져나감)은 ⑪ 은행 맞추기에서 처리합니다 — 여기서는 **미지급금(법인카드)** 에 쌓기까지. 화면에 그 잔액이 보입니다.

## 2. 전표 규칙 (초안 · 세무사 확인)

| 돈 흐름 | 근거 | 차변 | 대변 | 증빙 |
|---|---|---|---|---|
| 경비 청구 승인 `EXPENSE_APPROVED` | 승인 시각 | 고른 비용 계정(금액 − 부가세) · 부가세대급금(부가세) | 미지급금(금액) | 청구한 증빙 |
| 경비 지급 `EXPENSE_PAID` | 지급 처리 시각 | 미지급금 | 보통예금 | 없음 |
| 법인카드 사용 `CARD_TXN` | 장부에 넣은 줄(이용일이 시작일 뒤) | 고른 계정(금액 − 부가세) · 부가세대급금(공제 ÷ 11) | 미지급금(법인카드) | 법인카드 |
| 법인카드 취소(음수) | 〃 | 위의 반대 | | |

- 예 — 택시비 33,000원(카드 영수증 · 공제 3,000원): 여비교통비 30,000 · 부가세대급금 3,000 / 미지급금 33,000.
- 간이과세자 · 면세 가맹점 · 접대비(기업업무추진비)는 공제하지 않습니다(「공제」 칸을 끔).
- 전표는 정기 작업 `acct_journal`(매시간) 또는 「지금 전표 만들기」가 만듭니다. 마감한 달이면 오늘 날짜(late).

## 4. 주의

1. 목록 — SUPER · PAYOUT 은 모든 청구, 나머지 운영자는 **자기 청구만** 봅니다.
2. 증빙 파일은 **본인이 올린 것**만 붙일 수 있고, 보기는 올린 사람 · ADMIN · SUPER · REVIEWER · 지급 담당(PAYOUT · v10.392 파일 규칙).
3. 카드 CSV 는 한 번에 3,000줄 · 95,000자까지 — 크면 기간을 나눠 올림. 카드사마다 머리줄이 달라 처음은 일반 형식, **카드사 이름 · 예시 한 줄을 받으면 이름을 더함.**
4. 카드 줄의 가맹점 · 금액은 보기 · 올리기 SUPER · PAYOUT 만.
