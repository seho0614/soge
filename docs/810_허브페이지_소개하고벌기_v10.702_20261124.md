## 1. 바뀐 것

| 곳 | 내용 |
|---|---|
| 사용자 웹 **/earn** | 허브 관(EARN · 소개하고 벌기)이 **열려 있을 때만** 보임(아니면 404) · 머리 띠(관 이름 · 설명 · 아이콘 · 대표 색) · **하위 관 카드**(상위 관이 EARN 이고 열린 관 · 누르면 그 관) · 이용 안내 글 |
| 관 관리 › 페이지 목록 › 「소개하고 벌기(허브) 메인」 | 제목 · 설명 · 이용 안내 글 · 구역(하위 관 카드 · 이용 안내) 순서 · 숨기기 · 맨 위 · 구역 뒤 블록 — 허브도 관이라 **열려 있으면 고칠 수 없음**(docs/809) |
| 공개 `GET /gwans` | 칸 `parentCode`(상위 관) 더함 |

- 메뉴 · 메인에 허브 링크는 더하지 않았습니다(허브는 메뉴에서 빼는 규칙 그대로) — 주소 /earn 으로 들어감.
