# 776. 도움말 저장 크기(KB) 표시 · HELP_TOO_BIG — v10.632 (2026-11-22)

## 1. 결론

- 서버는 한 번에 **100KB** 까지 본문을 받습니다. 한글은 한 자에 3바이트라, 운영 화면 도움말 한도 **4만 자(v10.623)는 약 12만 바이트**로 100KB 를 넘습니다. 3만 3천 자쯤부터 저장이 **500 오류**로 실패할 수 있었습니다(11/22 회귀 test_v1203 에서 드러남 · 서버 기록 「request entity too large」).
- 이번 판부터
  1. 두 편집 화면(관 관리 › 사용자 설명서 · 관 관리 › 화면 도움말)에 **글자 수와 함께 크기(KB / 95KB)** 를 보이고, 넘으면 저장 단추를 막습니다.
  2. 서버는 **95KB 를 넘으면 422 `HELP_TOO_BIG`**(KB · 글자 수 함께)으로 막습니다.
  3. 100KB 를 넘어 본문을 받지 못하면 500 대신 **413 `PAYLOAD_TOO_LARGE`**(어느 주소든)로 답합니다.
- 한글만이면 실제로 들어가는 양은 약 3만 2천 자입니다. 글자 한도(설명서 2만 · 도움말 4만)는 그대로 둡니다.
