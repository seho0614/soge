# 457. 공지 읽음 CSV (v10.329 · 2026-11-16)

> 대표 「다음 개발 목록 전체 추천」(11/16) A3 · 계획 「승인 + 통과하면 병합」(회원 줄 포함 · 최고 관리자만 · 이름 가림 · 감사 기록). 요율 공지 열람 CSV(v10.300 · docs/420)와 같은 방식. 마이그레이션 없음.

## 1. 바뀐 것 (정확한 위치)

운영 화면 **노출 › 메인 운영 › 하위 탭 「콘텐츠」 › 「공지」 목록 › 「읽음」 단추 → 「공지 읽음 자세히」 상자** › **「CSV 받기」**(「닫기」 옆)

| CSV 부분 | 내용 |
|---|---|
| 머리 | 제목 · 공지 게시(한국) · 열람 등급 · 읽음 / 대상(비율 — 전체 공개 · 관리자 공지는 「세지 않음」) · 「모두 읽음」 표시 수 · 받은 때(한국) |
| 등급별 표 | 등급 · 대상 · 읽음 · 비율(화면 상자와 같은 셈) |
| 회원 줄 | 회원 번호(앞 8자리) · 이름(가림 · 홍○동) · 회원 상태 · 해당 등급 · 처음 펼침 · 마지막 펼침 · 펼친 횟수 · 「모두 읽음」만(예 · 아니오) — 펼쳐 본 회원 먼저, 「모두 읽음」만 누른 회원은 뒤(마지막 · 횟수 칸 비움) · 5만 줄까지 |

- 엑셀용(UTF-8 BOM · CRLF) · `=`, `+`, `-`, `@` 로 시작하는 칸은 앞에 `'`(수식 막기).
- **최고 관리자(SUPER)만** — 서버도 막음. 받을 때마다 감사 기록 **`NOTICE_READS_EXPORT`**(공지 번호 · 줄 수 · 읽음 · 대상). 바꾸는 것 없음.
- 회원 정보가 든 파일입니다 — 개인정보 접속기록 월 점검(v10.179) 때 이 감사 줄도 함께 봅니다.

## 2. API

`GET /admin/notices/{id}/reads/export` → `{ filename, csv, rows, note }` · 없는 공지 404 · SUPER 아니면 403.
