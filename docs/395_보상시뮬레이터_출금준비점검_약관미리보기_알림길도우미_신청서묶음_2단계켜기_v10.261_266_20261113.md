## 3. 알아 둘 것

1. 시뮬레이터 원천징수는 **한 사람 한 달 몫을 한 번 출금**한다고 보고 셉니다(소득세 = 율 ÷ 1.1 · 10원 아래 버림 · 지방소득세 = 소득세의 10% · 10원 아래 버림 — 서버 출금과 같은 식). 실제 세율 · 신고는 **세무 확인이 필요**합니다.
2. 운영은 지금 원천징수율이 비어 있으면 출금 점검 「위험 1」, 지급 담당이 따로 없으면 「위험」이 하나 더 나옵니다 — 적용 뒤 바로 보입니다.
3. 알림 길 도우미의 「시험 성공」은 **마지막 시험** 기준입니다 — 값을 바꾼 뒤에는 다시 보내 확인하십시오.
