## 2. 흐름 · 막는 것

1. 로그인 회원 「전화하기」 → 서버: 매물 공개 · 본인 아님 · 소개 금지 업종 아님 · 등록자 휴대폰 있음 · 하루 10번 → 같은 회원 · 매물 번호가 10분 넘게 남았으면 다시 씀 → 업체에서 050 번호(24시간) · 그 회원의 소개코드 유입(매물 단위)이 있으면 묶음
2. 통화가 끝나면 업체 → `POST /webhooks/safenum`(서명 · 5분) → 통화 시각에 그 번호를 쓰던 사람 찾기(돌려준 뒤 다른 사람이 받은 같은 번호와 섞이지 않게 · 업체 시각이 초 단위이거나 조금 어긋나도 받은 시각보다 2분 이르면 받음) → `call_logs` 1행(건 번호는 해시) → 트리거가 소개 기록
3. 24시간 지나면 배치가 업체에 돌려줌(실패해도 우리 쪽은 닫고 까닭을 남김)
