# 755. 법인카드 사용 즉시 알림 (v10.613 · 2026-11-21)

> 18차 ㉙. 회계 › 자금 › 새 탭 「카드 사용 알림」(키 `bzx-card-notice` · 법인카드 한도 뒤). SQL `sql/bzx_613_card_notice.sql`.

## 1. 결론

- 카드 이용 줄(`acct_card_txns` — ⑫ 카드 CSV · 다음에 카드사 승인 알림이 들어와도 같은 표)이 **들어오는 순간 DB 트리거가 알림 대기 한 줄**(`bzx_card_notices` · 같은 줄은 한 번)을 쌓습니다. 트리거는 카드 CSV 올리기를 절대 막지 않습니다(실패해도 WARNING 만).
- 10분마다(`bzx_frequent`) **`bzx.card_notify` on 일 때만**(처음 off) 보냅니다:
  - **쓰는 사람**(D261 카드 한도 `acct_card_limits.holder_id`) — 회원 알림 `BZX_CARD_USE`(사용 · 취소 한 건마다 · 금액 · 가맹점 · 이번 달 한도 몇 %).
  - **운영 알림 `BZX_CARD_USE`(WARN)** — 규칙에 걸린 줄을 그 차례에 묶어 한 번.
- 꺼진 동안 쌓인 줄은 **사흘 뒤 SKIPPED**(켤 때 옛 줄이 한꺼번에 가지 않게).
- 카드 끝 4자리만 · 승인번호 · 카드 번호 전체는 넣지 않습니다.

## 2. 규칙

| 표시 | 조건 | 운영 알림 |
|---|---|---|
| BIG 큰 금액 | 한 건 ≥ `bzx.card_big_amount`(처음 500,000원 · SUPER · 10,000 ~ 100,000,000) | 예 |
| HOLIDAY 주말 · 공휴일 | 쓴 날이 토 · 일 또는 `public_holidays` | 예 |
| NO_LIMIT 한도 없는 카드 | 한도 표에 없는(또는 꺼진) 끝 4자리 | 예 |
| OVER 한도 넘김 | D261 셈(`cardUsage` 재사용) 이번 달 한도 넘음 | 예 |
| NEAR 한도 기준 넘음 | 같은 셈 · 기준 %(acct.card_alert_pct) | 아니오(매일 09:40 `ACCT_CARD_LIMIT` 그대로) |
| CANCEL 취소 | 음수 금액 | 아니오 |

## 4. 권한 · 확인할 것

- SUPER · 지급 담당(카드 한도 탭과 같음) · 탭 키가 `acct-` 가 아니고 주소가 `/admin/bzx` 라 **세무사(ACCOUNTANT) · 운영 관리자(ADMIN)는 못 봄**.
1. D261 카드 한도에 카드마다 「쓰는 사람」을 정해야 회원 알림이 갑니다(없으면 운영 화면 목록만).
2. 쓰는 사람에게 알림이 가는 것을 직원에게 미리 알린 뒤 켜기(SUPER) — 개인정보(사용 내역)가 본인에게만 감.
