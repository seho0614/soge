# 484. 임시 허용 IP — 기한 (v10.350 · 2026-11-18)

> 대표 11/18 「다음개발」 → ① Nginx 적용 알림 · ② 임시 허용 IP(기한) · ③ 지난 판 보기 · 되돌리기 · ④ 고객센터 주간 보고 「모두」 → 계획 「승인 + 통과하면 병합」(v10.348 과 한 묶음 점검). 이 문서는 ②. 마이그레이션 **D234**(271 → 272 · 스냅샷 필요 · v10.352 와 같은 파일).

## 1. 왜

- 출장지 · 외부 작업 자리 IP 를 잠깐 더했다가 빼는 것을 잊으면 계속 열려 있습니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D234** | 칸 `staff_ip_allow.expires_at`(비면 기한 없음) |
| API `POST /admin/staff-access/allow` | `expiresDays` 1 · 3 · 7 · 14 · 30(선택) |
| 운영 화면 **권한 계층 › 「접속 인증」 › 「허용 IP」** | 「더하기」 옆 **기한 고르기**(기한 없음 · n일 뒤 빠짐) · 표에 **「기한」** 칸(지나면 빨강) |
| 인증 면제 | 기한이 지나면 **바로** 면제가 끊김(그 IP 도 인증번호) |
| 정기 작업 `sla_alert`(매시간) | 기한 지난 IP 를 목록에서 뺌(감사 `STAFF_IP_ALLOW_EXPIRE`) · 감시 서비스가 있으면 남은 목록으로 **Nginx 적용 요청** · 남는 IP 가 하나도 없으면 빼지 않고 경고 **STAFF_IP_EXPIRE_LAST** |
| Nginx 반영 스크립트 · 「적용」 · 마지막 IP 막음 | 기한 지난 IP 는 셈에서 뺌 |

## 3. 시험 (test_v1350)

1. ① 코드 — D234 · DTO · 면제 쿼리 · 정기 작업 · 화면 · 문서 484 · 판 v10.350 · 마이그레이션 272
2. ② API — 기한 3일로 더함 → expiresAt · 31일 400 · 기한을 과거로 바꾸면 면제 끊김(접속 인증 상태) · 스크립트에서 빠짐
3. ③ 정기 작업 — 다른 기한 없는 IP 가 있을 때 sla_alert → 기한 지난 IP 빠짐 · 감사 · 모두 기한 지났으면 남김 · 경고
4. ④ 화면 — 기한 고르기 · 기한 칸
