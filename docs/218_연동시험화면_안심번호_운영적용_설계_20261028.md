## 3. v10.145 — 050 안심번호 틀

```
로그인 회원이 매물 상세 「📞 전화하기」
  → POST /listings/{id}/safe-number   서버: 등록자 휴대폰에 연결된 050 번호를 업체에서 받음(24시간 · 같은 회원 · 같은 매물은 다시 씀)
                                       소개코드로 들어온 방문이면 코드를 함께 묶음(safe_numbers.code)
  → 화면에 050 번호 · 「누르면 전화 연결」(tel:)
  → 통화가 끝나면 업체 → 우리  POST /webhooks/safenum  (서명 검사 · 같은 알림 한 번)
       → call_logs 1행(건 사람 번호는 해시만 · 통화 시간) → 기존 트리거가 소개 기록(CALL · 90일)
  → 24시간 지나면 배치가 번호를 돌려줌(업체 해제)
```

| 항목 | 내용 |
|---|---|
| 방식 `safenum.provider` | NONE(처음 · 지금과 같음 — 「준비 중」 안내) · MOCK(점검판 — 050-0000-xxxx 가짜 번호 · 가짜 통화 단추) · HTTP(업체) |
| 막는 것 | 로그인 회원만 · 하루 10번 · 등록자 휴대폰 없음 · 본인 매물 · 비공개 매물 · 부동산 등 소개 안 되는 업종 → 안내 글 |
| 저장하지 않는 것 | 건 사람 실번호(해시만) · 녹음(받지 않음) |
| 마이그레이션 | D141 — 키 이름 `SAFENUM_WEBHOOK_SECRET` · 설정 · 배치 `safenum_release` · `safe_numbers` 에 회원 · 업체 번호 id 칸 |
| 화면 | 매물 상세 「전화하기」 → 번호 표시 · 운영 화면 「안심번호」(방식 · 키 · 발급 · 통화 수 · 기록) · 시험 test_v1145 |
