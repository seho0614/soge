# 610 근무표 · 교대 — v10.472 (D265 · 2026-11-20)

## 1. 결론
- 운영 화면 **회계 › 「인사」 › 탭 「근무표」**에서 직원 × 월 ~ 일 칸에 교대 유형을 고르고 저장합니다(여러 칸 한꺼번에 · 비우면 지움 · 「지난주 복사」는 빈 칸만).
- 칸 옆에 그날 근태(㉖ 출퇴근)를 보이고, **근무표와 다른 칸**을 표시합니다(표시만 · 근태를 고치지 않음).
- 직원은 **사무 › 「내 인사」** 아래에서 이번 주 · 다음 주 자기 근무표를 봅니다.

## 2. 교대 유형(처음 값 · SUPER 고침)
| 코드 | 이름 | 시각 | 휴게 |
|---|---|---|---|
| DAY | 주간 | 09:00 ~ 18:00 | 60분 |
| EARLY | 조출 | 07:00 ~ 16:00 | 60분 |
| LATE | 오후 | 13:00 ~ 22:00 | 60분 |
| NIGHT | 야간 | 22:00 ~ 07:00(다음 날) | 60분 |
| OFF | 휴무 | — | — |
- 유형은 지우지 않음(쓰지 않음으로) · 근무 · 휴무 종류는 바꾸지 않음(새 유형으로) · 코드는 영문 대문자로 시작 2 ~ 16자.
- 칸을 넣을 때 DB 가 유형의 시각 · 휴게를 칸에 옮겨 적습니다 — 나중에 유형을 고쳐도 지난 근무표는 그대로.

## 3. 근태와 다름(오늘까지 · 여유 `hrx.shift_grace_min` 처음 10분)
| 표시 | 뜻 |
|---|---|
| 근태 없음 | 근무 칸인데 출근 기록 없음(그 전날까지) |
| 휴가 | 근무 칸 · 출근 없음 · 그날 연차 쓴 날(acct_leave_uses) 있음 |
| 늦음 | 출근이 교대 시작 + 여유 뒤 |
| 일찍 감 | 퇴근이 교대 끝 − 여유 앞 |
| 퇴근 없음 | 출근만 있고 퇴근 없음(그 전날까지) |
| 근무표에 없는 날 일함 | 칸이 없거나 휴무인데 출근 기록 있음 |
- 주 계획 시간(휴게 뺌)이 기본(`hrx.week_limits` BASE 40) · 한도(BASE + OT = 52)를 넘으면 붉게 표시합니다.

## 4. 막는 것
- **7일 넘게 지난 칸**은 넣기 · 바꾸기 · 지우기를 서버와 DB 가 모두 막음(`HRX_SHIFT_PAST`) — 지난 근무표는 기록으로 남김.
- 칸 시각을 직접 고치지 않음(유형을 바꿔서) · 입사일 ~ 퇴사일 밖의 날은 넣지 않음.
