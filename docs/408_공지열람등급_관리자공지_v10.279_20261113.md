공지마다 등급을 **하나 이상** 고르고, **하나라도 맞으면** 봄. 파트너 등급은 심사 중 · 정지는 빼고 **활동 중만**(머리줄 아이콘은 심사 중도 보이지만 공지는 활동 중 기준).

## 3. API

| API | 권한 | 내용 |
|---|---|---|
| `GET /notices` | 누구나(로그인하면 그 등급) | 보는 사람 등급(관리자 등급 뺌)에 맞는 게시 공지 |
| `POST /admin/notices` | SUPER | `grades`(필수 · 하나 이상) · 422 `GRADE_REQUIRED` · `GRADE_INACTIVE` |
| `POST /admin/notices/{id}/publish` | SUPER | 초안 지금 게시 · 409 `NOTICE_PUBLISHED` · 감사 `NOTICE_PUBLISH` |
| `GET /admin/notice-grades` · `PATCH /admin/notice-grades/{code}` | SUPER | 등급 보기 · 이름 · 순서 · 사용 · 감사 `NOTICE_GRADE_UPDATE` · 404 · 422 `NO_CHANGE` |
| `GET /admin/staff-notices` | 운영 역할 전부 | 관리자 공지 |
