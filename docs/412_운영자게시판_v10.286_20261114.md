## 2. API (운영 역할 모두 · `GET /admin/site-settings` · `PATCH` 보관 기간은 SUPER)

| API | 내용 |
|---|---|
| `GET /admin/ops-board?kind&from&to&unread&page` | 목록(고정 먼저 · 50줄) |
| `GET /admin/ops-board/{id}` | 글 · 댓글 · 확인한 사람 · 고친 기록 |
| `POST /admin/ops-board` | 운영자 글 · 감사 `OPS_BOARD_POST` |
| `PATCH /admin/ops-board/{id}` | 쓴 사람 · SUPER — 제목 · 본문(기록) · 고정 · 자동 글은 고정만 · 403 `NOT_AUTHOR` · 409 `AUTO_POST_LOCKED` · `POST_TAKEN_DOWN` · 422 `NO_CHANGE` · 감사 `OPS_BOARD_UPDATE` |
| `POST /admin/ops-board/{id}/take-down` | 쓴 사람 · SUPER · 사유 · 감사 `OPS_BOARD_TAKE_DOWN` |
| `POST /admin/ops-board/{id}/comments` · `POST …/read` | 댓글(감사 `OPS_BOARD_COMMENT`) · 확인함 |
