# 455. 오래된 공지 바로 열기 — 30개 밖 공지도 펼친 채 (v10.327 · 2026-11-16)

> 대표 「다음 개발 목록 전체 추천」(11/16) → A1 · A2 · A3 「승인 + 통과하면 병합」. v10.324(docs/451) 남은 빈틈 — 알림 · 주소 `#n-<id>` 로 온 공지가 첫 쪽(30개) 밖이면 목록에 없어 펼쳐지지 않았음. 마이그레이션 없음. 알림 주소(D221)는 그대로.

## 1. 바뀐 것 (정확한 위치)

사용자 웹 **소개광장 › 「공지」 탭 › 「운영 공지」 상자** (v10.328 부터 제휴 파트너센터 › 공지사항 · 안심 파트너센터 › 공지 · 알림 › 「공지사항」 탭도 같음 · docs/456)

| 경우 | 보이는 것 |
|---|---|
| 주소 끝 `#n-<id>` 공지가 지금 쪽에 있음 | 전과 같음 — 그 줄이 펼친 채(v10.322) |
| 지금 쪽에 없음(오래된 공지 · 찾기 · 다른 쪽) | 찾기 칸 아래 **「지난 공지」** 표가 붙은 한 건이 **펼친 채** · 그 자리로 내려감 · 펼쳤으니 읽음 기록 · 「새 글」이면 지움 |
| 볼 수 없는 공지(게시 끝 · 내림 · 내 등급 아님 · 없는 번호) | 「이 공지는 볼 수 없습니다 — 게시가 끝났거나 내 등급에 보이지 않는 공지입니다.」 한 줄 |

## 2. API

`GET /notices/{id}` → 공지 한 건(목록 `GET /notices` 한 줄과 같은 칸 · `unread` · `files`) · 목록과 같은 기준(게시 중 · 끝나지 않음 · 보는 사람 등급 · 관리자 등급 뺌)이 아니면 **404** · 승인된 번역이 있으면 화면 언어로(`X-Lang`).
