# 593. 거래처별 원장 (v10.456 · 2026-11-20)

## 1. 결론
거래처마다 **받을 돈(외상매출금) · 갚을 돈(미지급금 · 법인카드 미지급금)**의 기초 · 늘어남 · 줄어듦 · 기말을 보고, 한 거래처를 누르면 전표 줄과 잔액이 나옵니다. 위치: **회계 › 장부 › 거래처 원장** · SB-ADM-FIN-040.

| 항목 | 내용 |
|---|---|
| 찾는 규칙 | 전표 거래처 이름(acct_entries.party) = ⑯ 거래처 대장 이름 — ⑭ 기간 분석 · ㉓ 독촉과 같음 |
| 대장 없는 이름 | 요약에 「대장 없음」 표시(누를 수 없음) — 대장에 같은 이름을 넣으면 한 줄로 모임 |
| 기간 | 기본 이번 달 1일 ~ 오늘 · 한 번에 1년까지 |
| CSV | 기초 · 줄 · 기말 — 거래처 이름 · 금액이 들어가 **내려받기 승인**(대상 ACCT_LEDGER · ⑬ 계정별 원장과 같음) |
| 보는 사람 | SUPER · PAYOUT · 세무사(읽기 · 내려받기 요청) |

## 2. 주의
1. 같은 거래처를 다른 이름으로 적은 전표는 따로 셉니다.
2. 해 마감 전표는 뺍니다.
