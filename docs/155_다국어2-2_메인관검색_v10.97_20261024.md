## 2. 규칙(2-1 그대로 + 더한 것)

| 규칙 | 지키는 곳 |
|---|---|
| 꺼짐 = 전과 같은 화면 | `request.ts` 가 `i18n.enabled` 를 먼저 봄 |
| 관 이름 — 한국어일 때는 늘 서버 이름, 다른 언어만 사전 | 관 화면 제목(메타) · 관 첫 화면 숨은 제목 · 검색 결과의 관 이름도 같은 규칙 |
| 서버 축 글(이름 · 성격 · 판정 · 급매 띠 · 규제 · 운영 「관 UI/UX 관리」) — 한국어일 때만 얹음, 다른 언어는 사전 글 · **노출 여부만 서버** | `withServerAxes(…, locale === 'ko')` |
| 정렬 이름 — 한국어는 화면이 넘긴 이름 그대로(화면마다 「최신」 · 「최신순」이 다름), 다른 언어만 사전 | `SortSelect` |
| 서버 자료(매물 · 상품 이름, 배지 이름, 광고 소재, 투표, 날씨 지역, 서버 축 이름, 안내 문장)는 그대로 | 3단계(콘텐츠 번역) |
| 숫자는 문자열로 끼움 — 사전이 `1,000` 처럼 쉼표를 붙이지 않게 | 화면 숫자 모양 그대로 |
| 검색 · 조회 값(주소의 `keyword` · `q`, 서버 코드)은 한국어 그대로 · 이름만 사전 | 메뉴 · 탭 · 정렬 |
| 「이/가」 조사 — 영어에 자리를 둘 수 없어 키 두 개(`totalI` · `totalGa`) | 소개장터 · 관 첫 화면 |
