## 1. 결론

| 항목 | 내용 |
|---|---|
| 바뀌는 화면 | 일반 화면 전부 — 관 목록 · 상세 · 나의공간 · 파트너센터 · 검색 · 등록 · 로그인 등 |
| 그대로인 화면 | 메인 · 소개장터 메인(/money) · 소개광장 · 소개몰 · 생활금융 상담 — 이미 받은 디자인을 맞춰 둔 화면이라 2단계에서 옮김 |
| 바뀌는 것 | 색(주색 보라 → 관 색 · 관 밖 남색) · 모서리(7 · 11px) · 글꼴(본문 나눔스퀘어 네오 · 제목 페이퍼로지) · 흐린 글자 대비 |
| 바뀌지 않는 것 | 화면 코드(.tsx)의 클래스 · 구조, 금액 · 경고 · 광고 색, DB |

## 2. 방식

1. 기준은 `styles/sgb-tokens.css`(디자인 시트) 하나입니다.
2. `styles/tokens.css` 의 옛 이름(`--pp` · `--ink` · `--line` · `--accent` · `--r-*` · `--f` 등)은 화면 CSS 3,000여 곳이 쓰므로 지우지 않고 **시트 값을 가리키게** 했습니다.
3. 관 색은 `<main data-sgb-gwan="…">`(components/Chrome.tsx)를 따라 바뀝니다. 주소 → 관: /money 소개장터 · /mall · /mal 안심소개 · /biz 소개창업 · /health 소개몰 · /community 소개광장, 그 밖은 남색.
4. 옛 주색 `--pp` 는 글자색(35곳)과 흰 글자 단추 바탕(31곳)에 함께 쓰여, 둘 다 읽히는 `--sgb-point-text`(흰 바탕 대비 4.5 이상)를 가리킵니다. 소개장터 #B85E00 · 소개몰 #12883E · 소개광장 #D24502 · 안심소개 · 소개창업 · 남색은 시트 색 그대로.
   시트 색 그대로의 바탕(#FFA03E 등) + 남색 글자 단추는 **4단계(단추 3종)** 에서 바꿉니다.
5. 묶어 둔 화면은 `styles/proto-common.css` 가 바뀐 옛 이름을 모두 전 값으로 되돌려 둡니다.

## 4. 알려 둘 것

1. 주황(`--or`) · 회색 단계(`--g*`)는 이번에 바꾸지 않았습니다 — `--or` 를 시트 주황(#FFA03E)으로 바꾸면 글자로 쓰인 곳이 더 흐려집니다(대비 2.8 → 2.0). 2 · 5단계에서 쓰임새별로 나눕니다.
2. 나눔스퀘어 네오는 400 · 700 · 800 굵기만 있어, 500 은 400 으로 · 600 은 700 으로 보입니다(10/21 대표 확인 「ok」).
3. 나눔스퀘어 네오는 Noto Sans KR 보다 글자 폭이 넓어 한 줄 글이 넘칠 수 있습니다.
4. 소개장터 메인(/money)도 흐린 글자(`--sgb-ink-3`)는 진해집니다(같은 시트 값을 씀).
5. `qa/site_mny.py`(집 PC 화면 시험)의 「소개장터 글꼴은 /money 에서만 받음」 항목은 이번 결정으로 맞지 않게 됩니다 — realcheck 에는 들어 있지 않습니다.
