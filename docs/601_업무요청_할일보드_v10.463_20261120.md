# 601. 업무 요청 · 할 일 보드 (v10.463 · 2026-11-20)

## 1. 결론
운영자끼리 **업무를 요청하고 담당자가 진행 · 완료**하는 칸반(요청 · 진행 · 완료)입니다. 담당자를 비우면 나에게 맡기는 「할 일」이 됩니다. 기한이 지나면 보드에 「기한 지남」, 매일 09:10 기한 지난 업무 **수**를 운영 알림으로 보냅니다(제목 · 사람 이름은 넣지 않음). 위치: **사무 › 업무 요청** · SB-ADM-OFC-020.

| 누가 | 할 수 있는 것 |
|---|---|
| 담당자 | 진행(요청 → 진행) · 완료(요청 · 진행 → 완료) · 요청으로 되돌림(진행 → 요청) · 댓글 |
| 요청한 사람 | 담당 바꾸기(끝나지 않은 것 · 「요청」 칸으로 돌아감) · 취소(사유) · 다시 열기(완료 → 진행) · 댓글 |
| SUPER | 모두 보기(view=all) · 위 모든 것 |
| 그 밖 | 보이지 않음(404) |

## 2. API
| 방법 | 주소 | 설명 |
|---|---|---|
| GET | /admin/office/tasks?view=mine\|requested\|both\|all&q= | 칸반 세 칸 + 취소 + 고를 운영자(끝난 · 취소한 것은 30일까지) |
| GET | /admin/office/tasks/{id} | 내용 · 댓글 · 상태 바뀜 기록 · 내가 할 수 있는 것(can) |
| POST | /admin/office/tasks | 요청 · 할 일(제목 2 ~ 100 · 내용 2000 · 기한 오늘 이후 · 중요) |
| POST | /admin/office/tasks/{id}/move | to = DOING · DONE · REQUESTED |
| POST | /admin/office/tasks/{id}/assign | 담당 바꾸기 |
| POST | /admin/office/tasks/{id}/cancel | 취소(사유 2 ~ 200) |
| POST | /admin/office/tasks/{id}/comments | 댓글(1 ~ 1000 · 쌓기만) |

오류: 403 OFC_TASK_WHO(그 사람이 할 일이 아님) · 409 OFC_TASK_STATE(그 칸으로 못 옮김 · 이미 그 칸 · 끝난 것 취소) · 422 OFC_TASK_TITLE · BODY · ASSIGNEE · DUE · MOVE · REASON · COMMENT.

## 3. 표 · 설정 · 정기 작업 (D263)
- ofc_tasks — 상태 REQUESTED · DOING · DONE · CANCELED · priority NORMAL · HIGH · due_on · started_at · done_at · canceled_at · cancel_note.
  트리거 trg_ofc_task_guard — DELETE 막음 · 제목 · 내용 · 요청한 사람 고치기 막음 · 옮길 수 있는 칸만(요청 → 진행 · 완료 · 취소 / 진행 → 요청 · 완료 · 취소 / 완료 → 진행) · 취소한 것 바꾸기 막음.
- ofc_task_comments — COMMENT · STATE · ASSIGN · 쌓기만(fn_block_write).
- 설정 ofc.task_due_alert(처음 on) · 정기 작업 ofc_task_due 매일 09:10 · 운영 알림 OFC_TASK_OVERDUE(하루 하나 · 다음 날 다시 셈 · 0 이거나 꺼지면 풀림).
- 개인 알림(나에게 온 요청 · 기한 내일까지 · 지남 · 끝남 · 댓글)은 v10.465 브라우저 알림.
- 권한(D258): 업무 ofc-tasks(사무) · 주소 7줄.

## 4. 주의
1. 제목 · 내용은 고치지 않습니다 — 바뀐 내용은 댓글로 덧붙입니다(누가 언제 무엇을 바꿨는지 남기려고).
2. 끌어서 옮기기(드래그)는 없습니다 — 카드를 눌러 단추로 옮깁니다(권한 확인을 단추마다 하려고).
