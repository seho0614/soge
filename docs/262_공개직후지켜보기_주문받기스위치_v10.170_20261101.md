# 262. 공개 직후 지켜보기 · 소개몰 「주문 받기」 스위치 (v10.170 · 2026-11-01)

> 대표 「다음」 → 「1 2」 → 「3번도 같이」(11/1). 배경: 11/1 사용자 웹 **전체 공개**(domain-dns #11 · open-blockers #27) — 간주 모드 · 결제대행사 계약 전이라 **시험 결제로 돈을 받지 않은 「결제 완료」 주문**이 생길 수 있음.

## 2. 운영에서 쓰는 법 (적용 뒤)

1. 운영 화면 첫 화면 「공개 직후 지켜보기」 → **「주문 받기 끄기」** — 결제대행사 연결 전까지 꺼 둠(대표 확인 뒤)
2. 시험 결제 주문 칸이 0 보다 크면 그 주문은 돈을 받지 않은 주문 — 고객에게 안내 · 취소(운영 화면 소개몰 주문)
3. 결제대행사 연결 · 간주 결제 off 뒤 「주문 받기 켜기」

운영은 지금 v10.158 이라 이 판을 쓰려면 docs/249 → 254 → 261 → 이 판(v10.169 → v10.170 절차서는 다음에)이 필요합니다. **그 전까지는 운영 화면 › 소개몰 상품에서 직판 상품 「판매 중지」가 같은 효과입니다.**
