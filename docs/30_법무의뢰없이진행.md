**작성일** 2026-09-04
**전제** 법무 자문을 당장 받지 않기로 하셨습니다.
**결론** **1건은 미룰 수 없습니다.** 나머지는 미룰 수 있습니다.

# 2. ① C-07 은 미룰 수 없습니다

## 2-1. 왜

**약관 문구 문제가 아니라 신고 의무 문제입니다.**

```
통신판매중개자 해당 → 통신판매업 신고 의무
                   → 신고 없이 영업하면 전자상거래법 위반
                   → 3천만원 이하 벌금
```

**약관을 안 쓰고 넘어갈 수는 있어도, 신고를 안 하고 넘어갈 수는 없습니다.**

푸터의 `footer.mail_order_no` 도 여기 걸려 있어 오픈 차단이 풀리지 않습니다.

## 2-2. 변호사 없이 확인하는 방법

**이건 자문이 아니라 사실 확인에 가깝습니다.**

| 경로 | 비용 | 소요 |
|---|---|---|
| **관할 지자체 경제과 문의** | 무료 | 1~3일 |
| **공정거래위원회 상담** (1670-0700) | 무료 | 당일 |
| 국민신문고 질의 | 무료 | 7~14일 |

**물어볼 내용을 그대로 옮겨 드립니다.**

> 사업자 간 거래를 소개·연결하는 온라인 플랫폼을 운영하려 합니다.
>
> - 플랫폼은 거래 대금을 수령하거나 보관하지 않습니다
> - 소개비는 거래 당사자가 소개자에게 직접 지급합니다
> - 플랫폼 수익은 구독료와 광고입니다
> - 이용자는 전원 사업자이며 소비자 거래는 없습니다
>
> 이 경우 통신판매업 신고 대상인지, 통신판매중개자에 해당하는지 알고 싶습니다.

**"소비자 거래가 없다"는 점이 판단의 핵심입니다.** 전자상거래법은 소비자 보호가 목적이라, B2B 전용이면 결론이 달라질 수 있습니다.

## 2-3. 답이 나오면

| 결과 | 할 일 |
|---|---|
| **신고 대상** | 신고 → 번호 발급(2~3주) → 푸터 입력 · 약관 제3조② 작성 |
| **신고 대상 아님** | 푸터에서 해당 항목 제거 · 약관에 "중개자 아님" 명시 |

**어느 쪽이든 코드는 이미 대응됩니다.** 신고 대상이 아니면 `footer.mail_order_no` 를 필수에서 빼면 됩니다.

```sql
UPDATE site_settings SET is_required_for_open = false
 WHERE key = 'footer.mail_order_no';
```

# 3. ②③ 은 미룰 수 있습니다

## ② 위치기반서비스 약관

**현재 설계로는 해당하지 않을 가능성이 높습니다.**

| 위치정보법 대상 | 이 서비스 |
|---|---|
| 단말기의 실시간 위치 | **수집하지 않음** |
| GPS · 기지국 · Wi-Fi | 사용하지 않음 |
| — | **회원이 직접 입력한 시·군·구** |

**"내가 입력한 우리 회사 주소"는 개인위치정보가 아닙니다.**

**당장의 조치** — 이 약관을 발행하지 않고 푸터 링크에서 제외합니다. 필수 약관이 아니라 오픈 차단에도 안 잡힙니다.

```sql
UPDATE footer_links SET is_active = false WHERE target_ref = 'LOCATION';
```

**나중에 GPS 기반 "내 주변" 기능을 넣는다면** 그때 반드시 검토해야 합니다.

## ③ 제3자 제공 동의

**보수적으로 "제3자 제공"으로 처리하면 안전합니다.**

| 판단 | 필요한 것 |
|---|---|
| 제3자 제공 | **별도 동의** + 제공 항목·목적·보유기간 고지 |
| 위탁 | 처리방침에 수탁자 명시 (동의 불필요) |

**제3자 제공이 더 엄격합니다.** 엄격한 쪽으로 처리하면 나중에 "위탁이었다"로 밝혀져도 문제가 없습니다.

초안이 이미 그렇게 작성돼 있습니다 — 별도 동의 + 항목·목적·기간 명시.

# 4. 지금 할 수 있는 것

## 4-1. 회사가 아는 값 20곳 채우기

```bash
# 약관 본문의 자리표시자
sed -i 's/〔회사명〕/주식회사 소개뱅크/g'  docs/terms/*.md
sed -i 's/〔전화〕/02-1234-5678/g'         docs/terms/*.md
sed -i 's/〔성명·직위〕/홍길동 이사/g'      docs/terms/*.md
sed -i 's/〔시행일〕/2026년 11월 1일/g'     docs/terms/*.md
sed -i 's/〔관할 법원〕/서울중앙지방법원/g' docs/terms/*.md
```

> **`gen-terms-draft.js` 는 DB 값에서 회사명·전화를 읽습니다.**
> 푸터 설정을 먼저 채우면 약관에도 자동 반영됩니다. 손으로 고치면 재생성 시 덮어씁니다.

**순서** — 푸터 설정 입력 → `npm run docs` → 약관 본문에 자동 반영.

## 4-2. 약관 4종 먼저 발행

**C-07 과 무관한 것들입니다.**

| 약관 | C-07 의존 | 발행 가능 |
|---|:-:|:-:|
| 이용약관 | **●** (제3조②) | ✗ |
| 개인정보처리방침 | | ○ |
| 마케팅 수신 동의 | | ○ |
| 제3자 제공 동의 | | ○ |
| 구독 환불 정책 | | ○ |
| 위치기반 약관 | | (미발행 권장) |

```bash
EFFECTIVE_FROM=2026-11-01 npm run terms:publish PRIVACY MARKETING THIRDPARTY REFUND
```

**실측 결과 — 오픈 차단 18 → 11건.**

```
18  시작
 ↓  ① 수탁사 선정 (PG·알림톡 등) → 방침의 수탁자 표가 채워짐
 ↓  ② 회사 사실 채우기 (회사명·전화·보호책임자·시행일)
 ↓  ③ 약관 4종 발행 (PRIVACY · MARKETING · THIRDPARTY · REFUND)
13
 ↓  ④ 위치기반 링크 비활성
12
 ↓  ⑤ 신고 대상 아니면 mail_order_no 를 필수에서 제외
11  남은 것 — 이용약관 1 · 푸터 1 · 설정 6 · 연동 3
```

**약관은 이용약관 하나만 남습니다.** 나머지 10건은 법무와 무관한 실무 작업입니다.

> **①이 선행입니다.** 개인정보처리방침의 수탁자 표가 `integrations.provider` 에서 나오므로,
> PG사·알림톡 대행사를 정해야 `〔선정 예정〕` 이 사라집니다.

## 4-3. 나머지 작업은 그대로 진행

법무와 무관한 것들이 오히려 더 오래 걸립니다.

| 업무 | 소요 | 법무 필요 |
|---|---|:-:|
| **PG사 · 알림톡 대행사 선정** | — | ✗ |

| 외부 연동 6종 | 최장 14주 | ✗ |
| 인프라 구축 | 4주 | ✗ |
| **검수 담당자 채용** | 8주 | ✗ |
| 공급측 매물 확보 | — | ✗ |

**이것들을 먼저 하시면 됩니다.** C-07 답이 오는 사이에 병행됩니다.

# 5. 미루면 생기는 위험

**정직하게 말씀드립니다.**

| 항목 | 미룬 채 오픈하면 |
|---|---|
| **통신판매업 신고** | **전자상거래법 위반 — 3천만원 이하 벌금** |
| 이용약관 미발행 | 분쟁 시 계약 조건을 주장할 근거가 없습니다 |
| 개인정보처리방침 미발행 | **개인정보보호법 제30조 위반 — 과태료** |

**이용약관과 개인정보처리방침 없이 오픈하는 것은 선택지가 아닙니다.** 그래서 `v_open_blockers` 가 막고 있습니다.

## 최소 요건

```
□ 통신판매업 신고 대상 여부 확인      ← 무료 · 1~3일
□ 개인정보처리방침 발행              ← 초안 있음
□ 이용약관 발행                     ← 제3조②만 확정하면 가능
□ 환불 정책 발행                    ← 초안 있음
```

**나머지는 미뤄도 됩니다.**

# 6. 권장 순서

```

```

# 7. 나중에 법무를 받게 되면

**오픈 후에도 늦지 않은 것들입니다.**

| 항목 | 왜 나중에도 되나 |
|---|---|
| 위치기반 약관 | 발행하지 않았으므로 문제 없음 |
| 제3자 제공 판단 | 엄격한 쪽으로 처리해 뒀음 |
| 약관 문구 정교화 | 변경 절차가 있음 (7일 전 공지) |
| 분쟁 조항 검토 | 실제 분쟁이 생기기 전까지 |

**약관은 변경할 수 있습니다.** 시행일 7일 전(불리한 변경은 30일 전) 공지하면 됩니다. 처음부터 완벽할 필요는 없습니다.

**다만 신고 의무는 변경 대상이 아닙니다.** 그것만 확인하십시오.
