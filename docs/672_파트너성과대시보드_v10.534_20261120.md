# 672. 파트너 성과 대시보드 (v10.534 · 2026-11-20)

## 1. 결론
안심소개 파트너의 **받은 리드 · 연락처 열람 · 응답 속도 · 리드 전환(성사) · 리드 이용료 · 받은 정산**을 **기간 그래프(30일 날마다 · 90일 주마다 · 12개월 달마다)** 로 보여 줍니다. 파트너센터는 **자기 파트너 것만**, 운영 화면은 **모든 파트너 합 · 파트너별 · 순위**를 봅니다. 새 표 없이 있는 기록을 세는 DB 함수 하나(`fn_ptn_perf_series` · 읽기만)로 셉니다.

위치: 파트너센터 **성과 추이**(SB-PTC-SLX-010 · `/partner/trend` · 「실적 · 등급」 아래 단추) · 운영 **파트너사 › 파트너 성과**(SB-ADM-SLX-030 · 탭 `slx-ptn-perf` · ADMIN · SUPER · 안심 파트너 담당 PARTNER_MAL).

| 숫자 | 무엇으로 세나(한국 시각) |
|---|---|
| 받은 리드 | `lead_deliveries`(거둔 REVOKED 뺌) · 받은 때(delivered_at) |
| 연락처 열람 · 열람률 | 같은 줄의 열람 시각(viewed_at)이 있는 것 |
| 응답 속도 | 받은 뒤 열람까지 분 — **가운데 값**(타일) · 평균 · 1시간 안 열람 비율 |
| 리드 전환(성사) · 전환율 | `partner_fulfillment_reports` 소비자 확인(CONFIRMED) · 확인한 때 — 전환율 = 성사 ÷ 받은 리드 |
| 리드 이용료 확정 | `lead_fees` BILLED · 확정한 때(billed_at) |
| 받은 정산 | `partner_settlements` PAID · 지급한 때 · 실지급액(net_amount) |
| 앞 기간 | 같은 길이의 바로 앞 기간 — 받은 리드 · 성사의 변화율 |

## 2. 누가 무엇을 보나
1. **파트너센터**: 로그인한 사람의 파트너(대표 또는 합류한 직원 — 기존 `PartnerActorService.forMember`)만. 다른 파트너 숫자 · 순위는 없음(경쟁사 단가 · 실적 노출 막음).
2. 돈 칸(이용료 · 정산)은 **대표 · 정산 권한 직원(canMoney)** 만 — 그 밖 직원은 서버가 비워 보냄(`money: false`).
3. **운영 화면**: 모두 합(기본) · 순위(받은 리드 · 성사 · 이용료 · 100곳) · 파트너를 누르면 그 파트너만. 읽기만이라 고치는 API 없음.

## 3. 전체 구조
- DB: `fn_ptn_perf_series(partner, from, to, unit)` — 묶음(일 · 주(월요일) · 월)마다 받은 리드 · 열람 · 응답 분(평균 · 가운데) · 성사 · 이용료 · 정산 · 기간 800일까지 · 단위 · 기간이 틀리면 PTN_PERF_UNIT · PTN_PERF_RANGE.
- 색인 3(`ix_ld_partner_delivered` · `ix_pfr_partner_consumer` · `ix_lead_fees_partner_billed`) — 기간 셈이 느려지지 않게.
- 서버 `src/modules/slx/partner-perf.ts`(기간 → 단위 · 요약 · 앞 기간 · 순위) · 컨트롤러 `SlxPartnerController` · `SlxPartnerAdminController`.
- 파트너센터 `site/src/app/partner/trend/page.tsx` — 서버에서 SVG 그래프(브라우저 스크립트 없음 · 색 토큰 `slx.css`) · 기간 표 · 숫자 4칸.
- 운영 화면 `SlxPartnerPerf`(Slx.tsx) — 기간 단추 · 요약 표 · 그래프 · 순위 표.

## 6. 주의 · 확인
1. 성과 숫자는 「성사 = 소비자 확인」 기준이라 소비자가 확인하지 않으면 전환율이 낮게 보임 — 화면 안내에 적음.
2. 알림톡 연동 전(간주)에는 리드 등급 · 열람이 적어 그래프가 비어 보일 수 있음.
3. 새로 모으는 개인정보 없음 — 이미 있는 기록을 세기만(처리방침 고칠 곳 없음). 순위의 파트너 이름은 사업자 상호(개인 이름 아님).
