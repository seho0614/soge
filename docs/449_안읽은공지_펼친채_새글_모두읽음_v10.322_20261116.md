## 2. 「모두 읽음」과 기록 (D222)

1. 공지 읽음 기록 표 `notice_reads` 에 칸 **`bulk`**(처음 false)를 더함. 「모두 읽음」은 `bulk = true` 로만 적음(펼치지 않음).
2. 운영 화면 **노출 › 메인 운영 › 콘텐츠 › 공지 목록 「펼쳐 본 회원」** 수는 `bulk` 를 **빼고** 셈 — 실제로 펼친 사람만.
3. **요율 변경 공지**(소개몰 요율 인상 예약 안내 · 취소 안내 — `hlt_rate_schedules.notice_id · cancel_notice_id`)는 「모두 읽음」 **대상이 아님** — 입점 약관 제17조 4항 「읽음」 증거는 판매자가 펼친 기록만 남음.
4. 「모두 읽음」 뒤 실제로 펼치면 `bulk = false` · 처음 펼친 때 = 그때 · 횟수 1 부터.
5. 새 API `POST /me/notices/read-all` → `{ ok, marked, unreadNotices }`.
