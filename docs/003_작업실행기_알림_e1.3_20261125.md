# 003. ERP 작업 실행기 · 소개뱅크 알림 보내기 — e1.3 (2026-11-25)

## 1. 결론

- 1분마다 「지금 돌 차례인 작업」을 고르고 **겹치지 않게**(`pg_try_advisory_lock`) 돌립니다.
- **주인 스위치** `erp_settings` `erp.jobs_owner` — `SGB`(지금 · 소개뱅크 scheduler 가 회계 · 인사 작업을 돌림)면 ERP 는 정기 실행을 하지 않음 · E7 에서 `ERP` 로 넘김(같은 날 두 번 돌지 않게 한 곳만).
- 주기 꼴: `every Nm`(마지막 실행에서 N분) · `daily HH:MM`(한국 시각 · 오늘 아직 안 돎).
- 실패하면 기록 + 소개뱅크 운영 알림 `ERP_JOB_FAIL`(ONCE) · 다음 성공 때 RESOLVE — 알림은 v10.800 `POST /internal/erp/alerts`.

| 항목 | 내용 |
|---|---|
| E003 | `erp_jobs`(코드가 등록한 이름만 돎) · `erp_job_runs`(90일 보관) · 첫 작업 `erp_heartbeat`(10분 · 기록만) · `erp_runs_purge`(매일 04:40) |
| API | `GET /api/v1/admin/jobs`(ADMIN · SUPER) · `POST /api/v1/admin/jobs/{name}/run`(SUPER · 주인이 SGB 여도 손 실행 됨 · 감사 `ERP_JOB_RUN`) |
| 끄기 | `ERP_JOBS=off`(시험 · 점검판에서 타이머 끔) |

- 회계 · 인사 정기 작업 23개는 E3 · E4 에서 이 실행기로 옮깁니다.
