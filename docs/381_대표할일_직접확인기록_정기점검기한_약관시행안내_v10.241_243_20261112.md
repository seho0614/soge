# 381. 대표 할 일 직접 확인 기록 · 정기 점검 기한 줄 · 시행일 앞 약관 안내 — v10.241 ~ v10.243 (2026-11-12)

> 대표 「다음」 → 후보 3가지 「모두」 → 계획 「승인 + 통과하면 병합」(11/12).
> **마이그레이션 D201 하나(238 → 239)** — 표 하나 더함 · 지우는 것 없음 · 스위치 · 설정 값을 바꾸지 않음 · 사용자 웹 바뀌지 않음.

## 1. 왜

v10.240 첫 화면 「대표 할 일」 카드의 직접 확인 3줄(요금제 금액 확정 · 법무 · 세무 · EBS 스냅샷 예약)은 DB 로 알 수 없어, 끝내도 늘 「직접 확인」으로 남았습니다. 또 매달 · 분기 정기 점검(개인정보 접속기록 · 운영자 권한 · 권리 요청 기한)은 경보는 있지만 다음 기한이 어디에도 한눈에 보이지 않았고, 약관 시행일(처리방침 등 8종 11-30)이 다가와도 따로 알리는 곳이 없었습니다.

### 알아 둘 것

1. 「끝남」은 적은 사람의 말을 그대로 믿습니다(실제로 끝났는지는 보지 않음). 잘못 적었으면 「다시 아직」을 적습니다 — 앞 기록은 남습니다.
2. 운영에서는 처리방침 등 8종의 본문 시행일이 11-30이라 **11-27(SOON) · 11-30(TODAY)** 에 INFO 알림이 한 번씩 뜹니다. 이 8종은 첫 판이라 게시 순간부터 이미 지금 판이고 AI 잠금도 이미 풀려 있습니다 — 알림은 날짜를 알려 줄 뿐입니다.
3. 알림은 09:00 하루 요약 때 만들어집니다. 그 사이 API 가 꺼져 있었으면 그날 것을 다음 날 만들지 않습니다(3일 창 안이면 SOON 은 다음 날 나옴).
