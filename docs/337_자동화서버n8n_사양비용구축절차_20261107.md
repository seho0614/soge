# 337. 자동화 서버(n8n · OpenClaw) — 사양 · 비용 · 구축 절차 (2026-11-07 · 문서만)

> 계기: 대표 「다음개발 모두」(11/7) → n8n 은 **새 EC2 가 필요해 이 개발 서버에서는 개발하지 않고 사양 · 비용 · 구축 절차 문서만**(11/7 「승인」).
> 기준 결정: `sgb-docs/decisions/automation-server-n8n.md` #1 ~ #21 · 미정 1 ~ 10 · `ai-agent.md` · 옛 절차서 `소개뱅크_자동화서버_셋업절차_v2.0_20261015.md`(설치 명령의 기준 · 이 문서는 그 뒤 바뀐 것과 사양 · 비용 · 순서만).
> **코드 · 마이그레이션 없음.** 소개뱅크 서비스는 n8n 없이 지금처럼 동작함(아래 1절).

## 0. 결론

| 항목 | 추천 |
|---|---|
| 만들 때 | **오픈 뒤 · 알림톡 대행사가 정해진 뒤**(지금 n8n 에 맡길 일이 거의 없음 — 1절) |
| 서버 | AWS 서울 EC2 **t3.medium(2 vCPU · 4GB) · gp3 40GiB · 탄력적 IP 1개** · Ubuntu 24.04 · 운영 서버와 같은 VPC |
| 비용(추정) | **월 약 45달러 ≒ 6 ~ 7만원**(서버 · 디스크 · IP · 백업 · API · 알림톡 · 영상 제외) — **AWS 요금표에서 최신 확인 필요** |
| 도커 | 이 서버에서 **n8n 용으로만**(#9) · OpenClaw 는 도커 없이 전용 계정(Node 24.16+) |
| 첫 워크플로 | ① 사이트 점검(5분마다 · 실패 시 텔레그램) ② n8n 백업 매일(서버 밖) — 돈 · 게시 · 발송은 넣지 않음(#17 · #18) |

## 1. 지금 n8n 없이 이미 하는 일 (중복 만들지 말 것)

| 일 | 지금 누가 | 판 |
|---|---|---|
| 정기 배치(정산 · 만료 · 백업 · 동네픽 06:00 등) | 운영 서버 배치 호출기 `sgb-jobs` + `job_schedules` | v10.196 ~ |
| 급한 운영 알림 · 하루 요약 | 소개뱅크 API → 메일 · **텔레그램 직접**(`ops.telegram_chat`) | v10.197 · v10.200 · v10.201 |
| AI 상담 · 검수 보조 · 번역 · 동네픽 | 소개뱅크 API → Claude **직접 호출**(`AgentProvider` · 결정 ai-agent 「B 직접 호출」) | v10.104 ~ v10.211 |
| 반송 · 수신 거부 받기 | SES → SNS → 소개뱅크 API | v10.209 |

→ n8n 이 맡을 것은 **밖에서 사이트를 보는 일 · 알림톡 전달 · 마케팅 · 영상 · 대표 비서(OpenClaw)** 뿐. `AgentProvider` 의 `N8N` 은 자리만 있고 쓰지 않음.

## 2. 사양

| 항목 | 값 | 이유 |
|---|---|---|
| 인스턴스 | t3.medium (2 vCPU · 4GB) | n8n + n8n 전용 Postgres + OpenClaw(Node) — 2GB 는 n8n 공식 최소 근처라 여유 없음 |
| 디스크 | gp3 40GiB | 도커 이미지 · n8n 실행 기록 · 백업 임시 |
| 운영체제 | Ubuntu 24.04 LTS | 운영 서버와 같은 계열 |
| 네트워크 | 운영 서버와 같은 VPC · **탄력적 IP 1개**(알림톡 발신 IP 로 등록 · 미정 2) | 운영 서버 IP(3.37.95.217)는 바꾸지 않음 |
| 보안 그룹 | 들어옴: 22 은 쓰지 않음(Session Manager) · 443 은 Telegram 콜백을 쓸 때만(미정 5) / 나감: 443 | OpenClaw 는 명령을 실행하는 에이전트 — 운영 비밀값과 분리(#7) |
| IAM | Session Manager · S3 백업 쓰기(경로 하나) · CodeCommit 읽기(#15) | 최소 권한 |
| DB 접근 | RDS 읽기 전용 역할 `sgbreport`(필요한 표만 · #14) — 쓰기는 소개뱅크 API 로만 | 「판단은 소개뱅크, 전달은 n8n」(#17) |

| S3 백업 | 수 GB | 1달러 미만 |

- 9/24 추정 「월 6 ~ 7만원」과 같은 범위. **요금은 바뀌므로 만들기 전에 AWS 요금 계산기에서 다시 확인**(확인할 수 없음 — 이 서버에서는 AWS 요금표를 조회하지 않음).
- 따로 드는 것: Claude API(소개뱅크 AI 월 상한과 별도로 OpenClaw 사용분) · 알림톡 건당 요금(대행사 계약) · 영상(TTS · Veo — 미정 7).
- 1년 예약(Savings Plan)이면 서버 값이 약 30 ~ 40% 낮아질 수 있음 — 6개월 써 보고 결정 권함.

## 4. 구축 절차 (사람 · 대표 승인 뒤 · 단계마다 확인)

설치 명령은 옛 절차서 v2.0 을 따르고, 아래 순서와 바뀐 점만 지킵니다.

| 단계 | 할 일 | 확인 |
|---|---|---|
| 1 | EC2 만들기(2절 사양 · 이름 `sgb-auto`) · 탄력적 IP · IAM 역할 · 예산 경보(월 60달러) | Session Manager 로 접속됨 |
| 2 | 도커 설치 · **n8n 버전 고정**(설치 당일 안정판 번호를 적어 둠 · #16) + n8n 전용 Postgres 컨테이너 · `N8N_ENCRYPTION_KEY` 를 서버 밖(대표 보관)에도 적어 둠 | `docker compose ps` 둘 다 healthy |
| 3 | n8n 화면은 **밖에 열지 않음** — Session Manager 포트 포워딩으로만 접속 | 공인 IP:5678 이 닫혀 있음 |
| 4 | 운영 RDS 에 `sgbreport` 역할(읽기 전용 · 필요한 표만) — 운영 DB 작업이라 **스냅샷 뒤 사람이** | `INSERT` 가 거절됨 |
| 5 | 첫 워크플로 ① 사이트 점검: `https://sogaebank.com/` · `/api/v1/health` 5분마다 → 2번 연속 실패면 텔레그램(봇은 소개뱅크 알림 봇과 **다른 봇** · #16) | 일부러 틀린 주소로 알림 1건 |
| 6 | 첫 워크플로 ② 백업: n8n 워크플로 · 자격 증명(암호화된 채) 내보내기 → S3(미정 3) 매일 | S3 에 파일 · 되살리기 1번 연습 |
| 7 | OpenClaw(도커 없이 · 전용 계정 · docker 그룹 제외 · Node 24.16+) · Telegram 봇 연결 · 소개뱅크 자료는 **n8n webhook 으로만**(#14) | OpenClaw 계정에 운영 키 · DB 주소 없음 |
| 8 | 운영 Nginx: 운영 화면 허용 IP 에 자동화 IP 를 넣을지 결정(사이트 점검은 공개 주소라 필요 없음) | — |

## 5. 하지 않는 것

- 돈 · 원장 · 권한 · 게시 · 회원 발송 판단(#17) — 소개뱅크 서버가 판단, n8n 은 전달만.
- 운영 서버에 n8n · 도커 설치(#4 · #9).
- 이 개발 서버(3.37.95.217 · t3.large)에 자동화 서버를 겸해 올리기 — 개발 전용.
