## 3. 구조

### 3-1. 언어 판별 (결정 #7 ②)

| 순서 | 규칙 |
|---|---|
| 1 | 쿠키 `sgb_lang`(ko · en · …)가 있으면 그 언어 |
| 2 | 없으면 한국어. 브라우저 언어(Accept-Language)가 영어면 **「English available」 안내 띠**만 보여 줌(자동으로 바꾸지 않음) |
| 3 | 머리줄 언어 단추로 고르면 쿠키 저장(1년) · 로그인 회원은 `accounts.preferred_lang` 에도 저장 |

주소는 그대로입니다(`/listings/…`). **알아 둘 점** — 주소에 언어가 없으면 검색 엔진(구글 등)은 한국어판만 모읍니다. 해외 검색 노출이 중요해지면 `/en/…` 주소 방식(결정 #2 의 옛 설계)으로 다시 정해야 합니다(9절 결정 4).

### 3-2. 화면 글 (사전)

- 파일: `site/src/i18n/ko.json` · `en.json` — 이름 붙인 문장(`header.login`, `listing.fee.label` …).
- 서버 화면(server component)은 쿠키를 읽어 그 언어 사전으로, 손님 화면(client component)은 같은 사전을 내려받아 씁니다.
- 도구: **next-intl**(쿠키 방식 · 주소 접두어 없이 쓰는 모드 지원) 추천 · 대안은 자체 함수(`t(key)`) — 9절 결정 5. 판 번호 · 호환성은 설치 때 확인 필요.
- 빠진 영어 문장은 **한국어를 그대로** 보여 줍니다(빈칸 금지) · 점검 스크립트가 빠진 키 수를 셉니다.
- 금액은 원(₩) 그대로 · 날짜 · 숫자는 언어별 형식(Intl).

### 3-3. 콘텐츠 번역 (결정 #6 3분류 · 「승인된 번역만 화면에」)

| 분류 | 대상 | 번역 시점 | 화면에 나가는 조건 |
|---|---|---|---|
| 운영 글 | 공지 · 자주 묻는 질문 · 약관 · 소개몰 상품 · 관 · 분류 이름 · 이용안내 | **미리**(운영자가 저장할 때) | 운영자 **승인** 뒤 |
| 등록 글 | 매물 · 요청 · 파트너 서비스 | **자동**(검수 승인 뒤 번역 줄에 넣음) | 금칙어 재검사 통과 시 자동 승인(9절 결정 6) · 운영자가 언제든 내림 |
| 게시판 글 · 댓글 | 소개광장 글 · 댓글 | **볼 때**(처음 연 사람이 요청 → 저장 · 다시 씀) | 「기계 번역」 표시와 함께 바로 |

원문이 고쳐지면 번역은 **낡음(STALE)** 으로 바뀌고, 다시 번역 · 승인될 때까지 원문(한국어)을 보여 줍니다.
약관 번역에는 **「참고용 번역 · 한국어본이 우선합니다」**를 늘 붙입니다(결정 #11).

### 3-4. 표 (안 · 1단계 마이그레이션)

```sql
-- 언어 목록 · 켜짐
CREATE TABLE i18n_langs (code text PRIMARY KEY, name text NOT NULL, rtl boolean NOT NULL DEFAULT false,
                         is_active boolean NOT NULL DEFAULT false, sort_order int NOT NULL DEFAULT 0);
-- 콘텐츠 번역 한 칸 = 한 줄
CREATE TABLE content_translations (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  target_type text NOT NULL,            -- LISTING · REQUEST · POST · COMMENT · NOTICE · FAQ · TERM · HLT_PRODUCT · GWAN · CATEGORY
  target_id   text NOT NULL,
  field       text NOT NULL,            -- title · body · question · answer …
  lang        text NOT NULL REFERENCES i18n_langs(code),
  text        text NOT NULL,
  source_hash text NOT NULL,            -- 원문 해시 — 다르면 낡음
  status      text NOT NULL DEFAULT 'DRAFT' CHECK (status IN ('DRAFT','APPROVED','AUTO_APPROVED','MACHINE','STALE','REJECTED')),
  engine      text NOT NULL,            -- MANUAL · CLAUDE · N8N
  translated_at timestamptz NOT NULL DEFAULT now(),
  approved_by uuid REFERENCES accounts(id), approved_at timestamptz,
  UNIQUE (target_type, target_id, field, lang)
);
ALTER TABLE accounts ADD COLUMN preferred_lang text;
-- 스위치: i18n.enabled(false) · i18n.engine(MANUAL) · i18n.board_on_view(false)
```

원문 표는 건드리지 않습니다(번역은 옆 표). 화면 API 는 `?lang=` 대신 쿠키 언어를 보고, **승인된 줄(APPROVED · AUTO_APPROVED · MACHINE)만** 원문 대신 내려 줍니다.

### 3-5. 번역 엔진 (결정 #6 교체형)

| 엔진 | 쓰임 | 조건 |
|---|---|---|
| MANUAL | 1단계 기본 — 운영자가 번역을 직접 넣음 | 없음 |
| CLAUDE | 소개뱅크 API 가 직접 Claude 호출(공식 SDK `@anthropic-ai/sdk`) | API 키 · 월 상한 |
| N8N | 결정 #6 의 운영 방식 — n8n `translate` 흐름 | **자동화 서버(n8n) 구축 뒤**(지금 없음) |

엔진은 `TranslateProvider` 하나로 감싸 갈아 끼웁니다. 결제 · 국세청 어댑터와 같은 방식입니다.

### 3-6. 금칙어 · 검수 (미정 #5)

추천 — **원문(한국어)으로 검수하고, 번역문도 금칙어 검사**를 한 번 더 합니다. 번역문에서 걸리면 그 번역만 내리고 운영자에게 알립니다(원문 노출은 그대로).

## 5. 비용 (변할 수 있음 — 계약 전 요금표 확인 필요)

번역에 Claude 를 쓸 때(요금은 Anthropic 공개 표 · 2026-10-06 기준 사본):

| 모델 | ID | 입력 / 출력(100만 토큰당) | 쓰임 |
|---|---|---|---|
| Claude Haiku 5.5 | `claude-haiku-5-5` | $0.10 / $0.50(입력 10만 토큰 이하) | 등록 글 · 게시판(양이 많음) |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | $2 / $10 | 운영 글 · 약관(품질 우선) |

어림 — 매물 1건(제목 + 본문) 입력 · 출력 각 약 1,500 토큰 · 월 1,000건 · 영어 1개 언어 · Haiku: 입력 150만 × $0.10 + 출력 150만 × $0.50 ≈ **월 1달러 안팎**. 급하지 않은 번역은 배치(Batches API · 50% 할인)로 더 줄일 수 있습니다. 같은 지시문은 프롬프트 캐시(읽기 약 0.1배)로 줄입니다.
비용보다 큰 것은 **사람 승인 시간**(운영 글)입니다.
