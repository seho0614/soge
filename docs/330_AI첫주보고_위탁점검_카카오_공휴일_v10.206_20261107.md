## 4. 위탁 목록 점검

| 서비스 | 「쓰는 중」 판단 |
|---|---|
| Amazon Web Services | 늘(서버 · 저장소 · 메일) |
| Anthropic | AI 키가 있음(운영 화면 또는 .env) |
