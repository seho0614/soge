# 1. UI 미작성 10건

**전부 백오피스이고, API는 이미 다 있습니다.** 화면만 붙이면 됩니다.

## 1-1. 왜 안 만들었나

**3관이 확정돼 있어 관을 새로 만들 일이 없습니다.** 이 10건 중 9건이 "관을 늘리고 메인을 재구성하는" 기능인데, 리드관은 보류 상태이고 그마저도 열려면 업종 승인·검수 인력·정산 흐름이 먼저 필요합니다. **화면보다 조건이 먼저입니다.**

## 1-2. 목록

| 우선 | 화면 ID | 이름 | API | 안 만든 이유 |
|---|---|---|:-:|---|
| P1 | `SB-ADM-MAIN-010` | 메인 운영 · 배너/광고 | ✅ | **광고 계약이 없습니다.** 팔 광고가 없는데 게재 화면부터 만들 이유가 없습니다 |
| P1 | `SB-ADM-SIT-010` | 관 목록 · 현황 | ✅ | 관이 3개 고정. 대시보드에서 이미 매물·검수 수를 봅니다 |
| P1 | `SB-ADM-SIT-030` | 관 설정 (8개 탭) | ✅ | 관 설정을 바꿀 일이 없습니다. 업종·정책은 별도 화면에 있습니다 |
| P2 | `SB-ADM-MAIN-020` | 메인 운영 · 관 노출 | ✅ | 3관 전부 노출 중 |
| P2 | `SB-ADM-MAIN-030` | 메인 운영 · 화면 구성 | ✅ | 메인 구성을 바꿀 근거가 없습니다. 오픈 후 이용 데이터를 보고 판단 |
| P2 | `SB-ADM-MAIN-040` | 메인 운영 · 콘텐츠 | ✅ | 공지 API 는 있으나 오픈 전 쓸 일이 없습니다 |
| P2 | `SB-ADM-SIT-020` | 새 관 만들기 | ✅ | **리드관 보류.** 열려면 업종·인력·정산이 먼저 |
| P2 | `SB-ADM-SIT-050` | 통합 메인 · 허브 | ✅ | 관 3개를 한 화면에 모을 이유가 약합니다 |
| P2 | `SB-ADM-SIT-060` | 공유 경계 · 영향 범위 | ✅ | 관이 늘어야 의미가 생깁니다 |
| P2 | `SB-MNY-EVT-010` | 이벤트존 · 커뮤니티 | ✅ | **담을 콘텐츠가 미확정.** 프로토타입 주석에도 미정으로 남아 있습니다 |

## 1-3. 만들어야 할 시점

| 계기 | 만들 화면 |
|---|---|
| **광고주 첫 계약** | `MAIN-010` 배너/광고 |
| **리드관 재개 결정** | `SIT-020` · `SIT-030` · `SIT-010` |
| **관 4개 이상** | `SIT-050` 허브 · `SIT-060` 공유 경계 |

| **커뮤니티 정책 확정** | `MNY-EVT-010` 이벤트존 |

**지금 만들면 쓰지 않는 화면이 늘어날 뿐입니다.**

# 2. 관리자 화면 없는 콘텐츠 3건

하드코딩을 걷어내 DB로 옮겼는데, **바꾸는 화면은 아직 없습니다.** 지금은 SQL 로 수정합니다.

| 테이블 | 내용 | 급한가 |
|---|---|---|
| `faqs` | FAQ 8건 | **중간** — 오픈 후 문의가 늘면 자주 고칩니다 |
| `ui_messages` | 법적 근거 있는 문구 12건 | 낮음 — 함부로 고치면 안 되는 것들입니다 |
| `gwan_form_copy` | 관별 등록 폼 문구 6건 | 낮음 — 3관 고정이면 바뀔 일이 적습니다 |

**FAQ 관리 화면만 오픈 전에 붙이는 것을 권합니다.** 나머지 둘은 오히려 아무나 못 바꾸는 편이 낫습니다 — `ui_messages` 는 지우면 표시 의무 위반이 될 수 있습니다.

# 3. 오픈 차단 18건

**여기가 실제 임계 경로입니다.** 전부 코드가 아닙니다.

## 3-1. 법무 회신 대기 — 8건

| 구분 | 항목 | 막는 것 |
|---|---|---|
| TERM | 이용약관 | **C-07 통신판매중개자 지위** 확정 후 조항 확정 |
| TERM | 개인정보처리방침 | 3관 구성이라 소비자 조항 제외 여부 |
| TERM | 구독 환불 정책 | B-14 법정 기준 |
| FOOTER | 위 3종 + 위치기반·제3자 제공 링크 | 약관이 발행돼야 목적지가 생깁니다 |

**약관 6종 골격은 이미 DB에 있습니다.** 법무가 본문을 주면 `PUT /admin/terms/{code}` → `PATCH .../publish` 로 발행하면 차단이 자동으로 풀립니다.

**위치기반서비스 약관** 하나는 판단이 필요합니다 — **지역 필터가 위치정보에 해당하는지**에 따라 신고 의무가 갈립니다.

## 3-2. 값 입력 대기 — 7건

```
footer.biz_reg_no       사업자등록번호
footer.mail_order_no    통신판매업 신고번호   ← C-07 신고 대상 확정 후
footer.address          사업장 주소
footer.phone            대표 전화
footer.hosting          호스팅 제공자
footer.ceo_name         대표자 성명
footer.privacy_officer  개인정보 보호책임자
```

**형식은 DB가 검증합니다.** 자리표시자("대표자명")를 넣으면 저장 자체가 거부되고, 우회해 넣어도 오픈 차단이 잡습니다.

> **개인정보 보호책임자는 값만 넣는다고 끝이 아닙니다.** 실제 지정과 내부 절차가 있어야 합니다.

## 3-3. 외부 연동 — 3건 (오픈 차단)

| 연동 | 리드타임 | 없으면 |
|---|---|---|
| **PG** 전자결제 | 5주 | **매출이 발생하지 않습니다** |
| **PASS** 본인인증 | 6주 | INV-7 게이트가 무력합니다 |
| **1원 계좌인증** | 4주 | 정산 계좌를 검증할 수 없습니다 |

**차단은 아니지만 필요한 것 3종** — NTS(2주) · 알림톡(8주) · 050 안심번호(미정).

### ★ 발신 IP 등록이 진짜 임계 경로입니다

**6종 전부 IP 화이트리스트를 요구하고 심사에 2~4주 걸립니다.**

```
W2   NAT EIP 고정 → 6종 IP 등록 신청
W6   심사 완료 → 연동 착수 가능
W14  알림톡까지 완료 (최장)
```

**코드보다 IP가 먼저 필요합니다.** 관리자 화면(외부 연동 탭)에서 IP를 한 번 넣으면 6종에 일괄 반영됩니다.

**모든 연동은 어댑터로 분리돼 있어 키만 주입되면 스텁이 실연동으로 바뀝니다.** 코드 수정이 필요 없습니다.

# 4. 이연 화면 14건

**의도적으로 뺀 것들입니다.**

| 사유 | 수 | 화면 |
|---|---:|---|
| **리드관 보류** | 9 | `ADM-PTN-010~080` · `PTC-DSH-010` |
| **반응형 흡수** | 5 | `HOM-DTL-M10` · `HOM-REQ-M30` · `{G}-LST-010` |

**반응형 5건은 사라진 게 아니라 통합된 것입니다.** 상세 화면이 하나이므로 PC 문의 단절이 구조적으로 재발하지 않습니다.

**리드관 9건은 `100_lead` 마이그레이션을 폴더만 옮기면 재개됩니다.** 다만 개인정보·보험·의료 부담을 함께 들고 오므로 3관 안정화 후 판단하십시오.

# 5. 미결 5건 (코드 외)

| # | 항목 | 성격 |
|---|---|---|
| 1 | **오픈 목표일** | **유일한 임계 미결.** 외부 연동 최장 14주를 역산해야 합니다 |
| 2 | 법무 회신 | 약관 6종 · 개인정보처리방침 |
| 3 | 사업자 등록 · 통신판매업 신고 | 푸터 값의 전제 |
| 4 | **PG사 · 알림톡 대행사 선정** | 계약 착수의 전제 |
| 5 | 프런트 인력 계획 | 유지·확장 |

**4번이 3번째로 급합니다.** PG사를 정하지 않으면 5주 리드타임이 시작되지 않고, PG 없이는 매출이 발생하지 않습니다.

# 6. 권장 순서

```
지금        ① PG사·알림톡 대행사 선정
            ② 사업자 등록 · 통신판매업 신고 (C-07 판단 후)
            ③ 법무에 약관 6종 의뢰

W2          ④ NAT EIP 고정 → 6종 IP 등록 신청     ← 여기가 시작점
W3~W4       ⑤ NTS 실연동 (키 주입만)
W6~W10      ⑥ PG · PASS · 1원 인증
W12~W14     ⑦ 알림톡

병행        ⑧ FAQ 관리 화면 (BO)
오픈 후      ⑨ UI 미작성 10건 — 필요해질 때
```

**④가 늦어지면 나머지가 통째로 밀립니다.** 코드는 준비돼 있으니 지금 시작할 수 있습니다.
