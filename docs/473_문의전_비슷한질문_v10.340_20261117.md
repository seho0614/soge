# 473. 문의하기 폼 「혹시 이 질문인가요?」 (v10.340 · 2026-11-17)

> 대표 11/17 「다음개발」 → ① 문의 전 비슷한 질문 · ② 답변 만족도 · ③ 리드관 경고를 운영 알림으로 · ④ 회원용 이용 흐름 「모두」 → 계획 「승인 + 통과하면 병합」. 이 문서는 ①. 마이그레이션 **D230**(267 → 268 · 스냅샷 필요).

## 1. 왜

- 회원이 문의하기 폼에 바로 적으면, 이미 자주 묻는 질문에 있는 답도 1:1 문의로 들어옵니다.
- 문의를 보내기 전에 비슷한 질문을 보여 주면 회원은 바로 답을 얻고, 운영자는 같은 답을 덜 씁니다.

## 2. 바뀐 것

| 곳 | 바뀐 것 |
|---|---|
| 마이그레이션 **D230** | `faq_daily` 에 칸 `deflect`(그날 「이걸로 해결됨」 수 · 사람 정보 없음). 지우는 문장 없음 |
| 새 API `POST /faq/{id}/deflect` | 공개(로그인 없이) · 그날 줄에 +1 · 숨긴 질문 404 |
| 사용자 웹 **고객센터 문의하기 폼** | 제목 아래 **「혹시 이 질문인가요?」** — 제목 낱말(2자 이상)이 질문 · 챗봇 낱말에 많이 든 순으로 3개 · 펼치면 답(「…에서 보기」 단추) · **「이걸로 해결됨」** → 「도움이 되어 다행입니다. 문의는 보내지 않으셔도 됩니다.」(같은 브라우저 질문마다 하루 한 번 셈). 문의는 그대로 보낼 수 있음 |
| 운영 화면 **회원 › 「1:1 문의」** 지표 상자 | 줄 끝 **「문의 전 해결 n」**(최근 7 · 30 · 90일) |
| 운영 화면 **관 관리 › 「자주 묻는 질문」** 표 | 셈 칸에 「문의 전 해결 n」(30일 · 있을 때만) |
