# 705 사원 권한 · 회원 · 직원 분리 (v10.563 · D291)

## 1. 결론
사원(운영자)마다 권한그룹 · 기한 · 개별 더하기/빼기를 「사원 권한」에서 붙이고, 회원 쪽 화면 · 기능에서 운영자를 떼어 냅니다. 새 운영 역할은 직원 대장 연결이 있어야 줍니다.

## 2. 바뀌는 규칙
| 곳 | 전 | 후 | 오류 코드 |
|---|---|---|---|
| 회원 상세 권한(MemberRoles) | 주기 · 거두기(SUPER) | 보기만 + 「직원 · 권한 › 역할 주기」 링크 | — |
| PATCH /admin/accounts/{id}/status · 회원 일괄 정지(opx-bulk) | 자기 · SUPER 계정만 막음 | 운영 역할 있는 계정은 SUPER 만 | 403 STAFF_TARGET_SUPER_ONLY |
| GET /admin/accounts | 모두 | 기본 회원만 · staff=include · staff=only · 줄마다 isStaff | — |
| 캠페인 대상(문자 · 메일 · 월간 뉴스레터 · 소개몰 문자 대상 수) | 동의자 모두 | 운영자 뺌(시험은 「나에게 시험 보내기」) | — |
| POST /admin/reports/roles(역할 주기) | 사유 · 자기 · 기한 | 안쪽 역할(검수 · 운영 · 최고)은 직원 대장 연결 필수 — employeeId 로 그 자리에서 연결 · 외부 역할(세무사 · 파트너 담당)은 연결 없으면 기한 꼭 | 422 STAFF_EMPLOYEE_REQUIRED · STAFF_EXTERNAL_EXPIRY · STAFF_EMPLOYEE_LEFT · 409 HR_LINK_TAKEN |
| 직원 퇴사(left_on) | — | 연결 계정에 운영 역할이 남으면 운영 알림 STAFF_LEFT_ROLE(WARN · D291 트리거) · 급여 › 직원 「퇴사」 뒤 「운영 역할도 거둘까요?」 | — |
| 옛 운영자 중 직원 연결 없음 | — | 막지 않음 · 운영자 목록에 「직원 연결 없음」 | — |

## 3. 새 API
| 방법 | 주소 | 역할 |
|---|---|---|
| GET | /admin/perm/staff | SUPER — 사원마다 권한그룹 · 개별 · 실제 업무 수 · 조합 어긋남 |
| GET | /admin/staff/employees/{id}/roles | SUPER — 직원 계정에 남은 운영 역할 |
| POST | /admin/staff/{accountId}/revoke-all | SUPER — 운영 역할 모두 거두기(사유 · 409 NO_SUCH_ROLE · STAFF_LAST_SUPER · 403 SELF_GRANT) · STAFF_LEFT_ROLE 풀림 |
- 사원 권한 저장은 옛 PUT /admin/perm/accounts/{id} — 같은 거래에서 조합 검사(422 PERM_CONFLICT) 더함.

## 4. 현장 체크리스트
1. 운영 적용 전 급여 › 직원에 운영자 직원을 넣어 두기(없으면 새 역할을 못 줌 · 옛 역할은 그대로).
2. 운영자 목록 「직원 연결 없음」 줄 → 역할 주기에서 직원 고르기로 연결(안쪽 역할 다시 주기) 또는 회계 › 인사 › 근태에서 연결.
3. 외부(세무사 · 파트너 담당) 계정은 기한 확인.
