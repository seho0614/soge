# 386. 적용 결과 파일 보기 · 서버 자원 추세 · 대표 할 일 주간 알림 — v10.247 ~ v10.249 (2026-11-12)

> 대표 「다음개발」 → 후보 3가지 「모두」 → 계획 「승인 + 통과하면 병합」(11/12).
> **마이그레이션 D203 하나(240 → 241)** — 표 하나 · 설정 하나 · 정기 작업 하나 더함 · 지우는 것 없음 · **적용 스크립트(apply · precheck · postcheck · rollback) 바뀌지 않음** · 사용자 웹 바뀌지 않음.

## 1. 왜

운영 적용 때마다 precheck · postcheck 출력을 터미널에서 복사해 보내야 했고, 디스크는 그 순간 값과 85% 경보만 있어 언제쯤 찰지 알 수 없었습니다. 「대표 할 일」은 하루 요약 한 줄에 묻혀 눈에 덜 띄었습니다.

### 알아 둘 것

1. 결과 파일 시각은 **운영 서버 시각**(파일 이름)입니다 — 운영 서버가 UTC 면 한국 시각보다 9시간 이릅니다.
2. 결과 파일은 `cleanup.sh` 가 오래된 것부터 지울 수 있습니다 — 지워진 파일은 목록에서 빠집니다.
3. 추세의 첫 줄은 **적용한 날 첫 `launch_watch`(10분 안)** 에 생기고, 기울기는 기록이 **3일** 쌓인 뒤부터 나옵니다.
4. 주간 알림은 지금 운영처럼 텔레그램 · 슬랙이 꺼져 있으면 **나가지 않고** 운영 알림(INFO)에만 「보낸 길 없음」으로 남습니다. 끄려면 설정 `ops.owner_todo_weekly` = off.
