# 415. 공지 목록 걸러 보기 · 고객센터 · 파트너센터 읽음 기록 · 머리줄 안 읽은 공지 점 — v10.292 ~ 294 (2026-11-14)

> 대표 결정(11/14): 공지 · 요율 후속 묶음 2 · 계획 「승인 + 통과하면 병합」.

- 「읽음」은 공지를 **펼친 것**만 셉니다(목록만 연 것은 아님) — 입점 약관 제17조 4항 「공지를 봤다」 기록과 같은 기준.
- 관리자 등급 공지는 사용자 웹에 나오지 않으므로 읽음 · 점에 들지 않습니다.

## 2. API

| API | 권한 | 내용 |
|---|---|---|
| `GET /admin/notices` | SUPER | 쿼리 `status`(DRAFT · SCHEDULED · LIVE · ENDED · TAKEN_DOWN · 그 밖은 무시) · `q`(제목에 든 글자 · 100자) · `page`(1부터 · 50줄씩) · 줄마다 `total`(걸러진 전체 수) · `page` · `reads` · `target`(전체 공개 · 관리자만이면 null) — 응답은 전처럼 배열 |
| `POST /me/notices/{id}/read` | 로그인 회원 | 새 API — 나에게 보이는 게시 중 공지만(아니면 404 `NOT_FOUND`) · 처음 · 마지막 · 횟수 · 돌려줌 `{ ok, unreadNotices }` |
| `GET /notices` | 누구나 | 줄마다 `unread`(로그인했고 최근 30일 · 아직 안 펼침) |
| `GET /me/summary` | 로그인 회원 | `unreadNotices`(최근 30일 안 펼친 공지 수) — 머리줄 `/cart-count` 가 `nt` 로 넘김 |
