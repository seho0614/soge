# 646. 회원 화면 사용 통계 (v10.508 · 2026-11-20)

## 1. 결론
사용자 웹(sogaebank.com)의 **화면별 방문 · 이탈 · 전환**을 **외부 분석 도구 없이** 직접 셉니다. 저장하는 것은 **하루(한국 날짜) × 화면 주소 묶음의 수**뿐이고, **계정 · IP · 브라우저 정보 · 방문자 쿠키는 남기지 않습니다.** 스위치 `site.usage_stats`(처음 **off** · 켜기 SUPER)를 켜기 전에 아래 5절 처리방침 문구를 먼저 게시하는 것을 권합니다(**법무 확인**). 위치: **통합 현황 › 화면 사용 통계** · SB-ADM-MLX-040 · 보내기 SB-HOM-MLX-030(모든 화면 공통 · 그리는 것 없음).

## 2. 무엇을 · 어떻게
| 항목 | 내용 |
|---|---|
| 보내는 것 | 화면이 바뀔 때 한 번 `POST /site/usage/beat` { p: 지금 화면 주소, e: 이 탭의 첫 화면(첫 화면이면 없음), s: 둘째 화면인지, g: 완료 화면 목표 } |
| 주소 묶기(서버) | 물음표 · # 뒤 버림(검색어 등) · 4단계까지 · uuid · 숫자 · 25자 넘는 조각 · 영문 숫자 아닌 조각 · 대문자 + 숫자 코드(상품 · 매물 코드)는 `:id` — 예 `/community/:id` · `/health/p/:id` · `/admin` · `/api` 는 받지 않음 |
| 저장 | `site_usage_daily`(day · path · views · entries · engaged · est_views) · `site_usage_goals`(day · goal · entry_path · n) — 칸이 이것뿐(시험이 칸 목록을 봄) |
| 이탈 | 첫 화면(entries) 가운데 둘째 화면으로 이어지지 않은 비율 = (entries − engaged) ÷ entries |
| 전환 | 가입 완료(/signup/done) · 주문 완료(/health/order/done) · 문의 보냄(/support/done) · 글 올림(/community/…?posted) · 매물 등록(/my/listings?published · review) · 요청 등록(/request/new → /request/…) — 첫 화면별 수 |
| 표본 | `site.usage_sample` 100%(1 ~ 100) — 탭마다 한 번 정함 · 「추정 보기」 = 보기 × 100 ÷ 표본 |
| 상한 | 하루 주소 묶음 `site.usage_path_cap` 3000 넘으면 `/_other` · IP 지문 1분 120번(메모리에서만 · 저장 안 함) |
| 보내지 않음 | 스위치 off · 브라우저 「추적 안 함」(DNT) · GPC · 로봇 브라우저 · 저장소가 막힌 브라우저 |
| 보관 | `site.usage_keep_days` 400일 뒤 정기 작업 `mlx_daily_purge`(04:35)가 지움 |

## 3. 브라우저 쪽 (UsageBeacon · 루트 layout)
- **쿠키를 만들지 않음.** 탭 안 메모만 `sessionStorage`(`sgb_usage` — 첫 화면 주소 · 몇째 화면 · 표본 여부 · 마지막 주소) — 탭을 닫으면 사라지고, 서버로는 첫 화면 주소(e)만 감(사람을 가리키는 번호 아님).
- `navigator.sendBeacon`(안 되면 fetch keepalive) · 화면에 그리는 것 없음 · 실패해도 화면은 그대로.
- 로그인 쿠키가 있으면 사이트 프록시(proxy.ts)가 토큰을 붙여 넘기지만 **API 는 이 주소에서 계정을 읽지 않음**(코드 · 시험으로 고정 — 저장 칸에 계정이 없음).

## 4. 쿠키 동의가 필요한가 (검토 · 법무 확인)
| 기준 | 판단(초안) |
|---|---|
| 개인정보 보호법 제30조(처리방침에 「자동 수집 장치의 설치 · 운영 및 거부」) | 개인정보를 모으지 않고 쿠키도 만들지 않아 **동의 대상은 아님**으로 봄 — 그래도 투명하게 처리방침에 「자체 사용 통계(개인 식별 정보 없음)」를 적고 거부 방법(DNT · GPC)을 안내 |
| 개인정보 보호법 · 행태정보(맞춤형 광고) | 광고 · 개인별 추천에 쓰지 않음(하루 묶음 수뿐) → 행태정보 처리 아님 |
| 정보통신망법 | 영리 광고 · 접근 권한(앱) 해당 없음 |
| 해외 이용자(EU ePrivacy 5(3) · GDPR) | 단말기 저장소(sessionStorage)를 「꼭 필요한 것」이 아닌 통계에 쓰면 **동의가 필요하다는 해석**이 있음 — 해외 이용자를 받을 때(다국어 켬) 동의 띠 또는 그 나라 이용자 끄기를 다시 판단 |
- 결론(초안): **국내 기준 동의 띠 없이 운영 가능 · 처리방침 고침 후 켬** — 최종은 **법무 확인**.
