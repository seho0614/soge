# 741. 알림 하루 요약 받기 (v10.599 · 2026-11-21 · 16차 회원 · 성장 ⑮)

## 1. 결론
회원이 **나의공간 › 알림**에서 「하루 요약 받기」를 켜면, 매일 **08:00** 지난 24시간 알림을 **한 통**(GRW_DIGEST)으로 묶어 보냅니다. **메일 준비 전(지금)에는 사이트 알림만** 갑니다. 스위치 `grw.digest` 처음 **off**(켜기 SUPER).

## 2. 재사용한 기능
| 기능 | 쓰는 곳 |
|---|---|
| 회원 알림 `notifications` · `fn_notify`(D063 · 회원이 끈 종류는 안 감) | 요약 한 통도 fn_notify 로(회원이 「알림 하루 요약」 종류를 끄면 안 감) |
| 알림 종류 정책 `notification_event_policies.optout_allowed` | 묶는 것은 **끌 수 있는 알림**만 · 돈 · 계약(끌 수 없음)은 바로 |
| 알림 메일 보내기(notify_dispatch · NotifyMailSender · OPTED_OUT 처럼 FAILED + 까닭으로 닫는 방식) | 메일 준비 뒤 묶는 알림 메일은 대기열에 들어갈 때 `DIGEST: 하루 요약으로 묶어 보냄` 으로 닫음 |
| 가격 변동 묶음 알림(v10.503 · mbx_price_digests 모양) | 하루 한 번 고유 표 `grw_digest_sends` |

## 3. 동작
| 경우 | 사이트 알림 | 메일 |
|---|---|---|
| 스위치 off · 회원 끔 | 하나하나(전과 같음) | 전과 같음 |
| 스위치 on · 회원 켬 · 메일 준비 전 | 하나하나 그대로 + 08:00 요약 한 통 | 없음(채널 준비 안 됨 — 전과 같음) |
| 스위치 on · 회원 켬 · 메일 준비 뒤 | 하나하나 그대로 + 08:00 요약 | 끌 수 있는 알림 메일은 닫고 **요약 한 통만** · 끌 수 없는 알림은 바로 |
- 알림이 없는 날은 보내지 않음 · 같은 날 두 번 보내지 않음 · 요약 글은 제목 5줄 + 「외 n건」.

## 4. 처리방침
새로 모으는 개인정보 없음(회원 설정 한 칸) — 처리방침 고칠 곳 없음으로 봄. 회원 안내 문구는 나의공간 › 알림 상자.
