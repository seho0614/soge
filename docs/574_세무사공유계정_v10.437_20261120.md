# 574. 세무사 공유 계정 (v10.437 · 2026-11-20)

> 대표 11/19 「다음개발」 → ㉔ 4개 모두 · 「승인 + 통과하면 병합」. 마이그레이션 D257 ①.

## 1. 결론

세무사에게 **회계 화면을 읽기만 하는 계정**을 기한을 두고 줍니다. 고치기 · 넣기는 막히고, 내려받기는 승인이 필요하며, 질문을 남기면 SUPER 가 답합니다.

## 2. 위치

| 화면 | 위치 |
|---|---|
| 권한 주기 | 권한 계층 › 권한 관리 · 회원 상세 › 권한 — 역할 「세무사(읽기 전용 · 기한 꼭)」 · 기한 7 · 30 · 90일 |
| 세무사 화면 | 회계 › 설정 · 보고 › 세무사 (SB-ADM-ACC-420) |

## 3. 규칙

| 항목 | 내용 |
|---|---|
| 역할 | ACCOUNTANT — D173(파트너 담당) 방식 그대로 역할 CHECK · 역할 기록 · 보유자 보기 |
| 기한 | 꼭 있어야 함(1 ~ 365일 · DB 미룬 트리거 ACCOUNTANT_EXPIRY · 화면은 7 · 30 · 90일) · 지나면 로그인 때 역할에서 빠지고 매시간 정기 작업이 거둠 |
| 읽기 | 서버 권한 검사가 `/api/v1/admin/acct` 아래 GET 중 지급 담당(PAYOUT)이 볼 수 있는 것만 엶 · 화면도 같은 탭만 보임 |
| 쓰기 | POST · PATCH · PUT 은 역할이 없어 403 — 예외: 질문 남기기 · 내려받기 요청 |
| 증빙 | 회계 증빙(ACCT_EVIDENCE)만 열람 · 사내 문서 · 회원 파일은 못 엶 |
| 내려받기 | 전표 · 신고 자료 · 원장 · 장부 보관 CSV 는 요청 → SUPER 승인 → 받음 |
| 접속 기록 | 운영 화면 API 를 부를 때마다 한 줄(acct_accountant_access · 쌓기만) |
| 질문 | 달 · 전표마다 질문(쌓기만) · SUPER 답(쌓기만) |
| 2단계 인증 | 운영 역할과 같은 범위(설정이 켜지면 세무사도) |

## 4. API

| API | 권한 |
|---|---|
| `GET /admin/acct/accountant?ym=` | SUPER · PAYOUT · ACCOUNTANT |
| `POST /admin/acct/accountant/notes` | ACCOUNTANT(SUPER) |
| `POST /admin/acct/accountant/notes/{id}/reply` | SUPER |

## 5. 주의

1. 세무사 화면에도 고치기 단추가 보일 수 있으나 서버가 403 으로 막습니다.
2. 회계 화면에는 경비 청구한 운영자 이름 · 포인트 출금 합계 같은 회계 정보가 보입니다(회원 연락처 · 주민번호 화면은 못 봄).
