# 908. 상담 신청 — 메일 인증번호만으로 받기 스위치(처음 꺼짐) — v10.793 (2026-11-25)

## 1. 결론

- 대표 결정(11/25): 묶음 7 2번 「상담 신청 메일 인증번호 대안 — **스위치 꺼진 채 · 켜기는 법무 판단 뒤**」(open-blockers #8).
- 지금까지(v10.43 · 10/15 「둘 중 하나로 확인」)는 메일 보내기가 준비되면(notify.email_verified = on) **알림톡이 없어도 메일만으로** 상담 신청이 열렸습니다. docs/892(SES 보내기)를 마치는 순간 법무 판단 없이 열리는 구멍이었습니다.
- 이제 **메일만으로 받는 것은 설정 `consult.mail_otp` = on 일 때만**입니다(처음 off · SUPER).

| 알림톡 | 메일 | consult.mail_otp | 상담 신청 |
|---|---|---|---|
| 됨 | 됨 | 상관없음 | 받음 — 같은 번호를 휴대폰 · 메일로(둘 중 하나로 확인 · 그대로) |
| 됨 | 안 됨 | 상관없음 | 받음 — 휴대폰으로 |
| 안 됨 | 됨 | **off(처음)** | **받지 않음** `NOTIFY_NOT_READY` |
| 안 됨 | 됨 | on | 받음 — 메일로(휴대폰 번호는 확인되지 않음) |
| 안 됨 | 안 됨 | 상관없음 | 받지 않음(개발 환경만 devCode) |

- 켜는 곳: 운영 화면 › 사이트 설정 › 전체 설정 › `consult.mail_otp`(SUPER). 켜기 조건은 스위치 안내(opx_switch_docs)에 적음 — 법무 판단 · 메일 보내기 준비(docs/892).
- 지금 운영은 메일 · 알림톡 모두 안 됨이라 **달라지는 것 없음**(계속 닫힘).
