# 422. 요율 시행 때 공지 열람 기록 고정 — v10.301 (2026-11-15)

> 대표 결정(11/15): 「다음」 → 「A · B · C 모두」 · 계획 「승인 + 통과하면 병합」.
> **마이그레이션 D218(255 → 256 · v10.302 와 함께).** 입점 약관 제17조 4항 「30일 전 공지」를 판매자가 **시행 전에 봤는지**를, 요율이 시행되는 순간의 모습으로 굳혀 남깁니다. v10.300 「읽음 기록」은 지금 값이라 시행 뒤 펼치거나 판매자가 바뀌면 달라지기 때문입니다.

## 1. 바뀐 것 (정확한 위치)

| 판 | 곳 | 내용 |

- 굳힌 줄은 판매자를 가리켜, 그 판매자 줄은 지울 수 없습니다(폐점 · 상태 바꾸기는 됨).

| API | 권한 | 내용 |
|---|---|---|
| `GET /admin/health/rate-schedules/{id}/reads?view=frozen` | ADMIN · SUPER | 굳힌 줄 · `view: 'frozen'` · `frozenAt` · `read`(대상이고 시행 전 읽음) · 줄마다 `readBefore`. 굳힌 기록이 없으면 **409 `READS_NOT_FROZEN`** · `view` 없거나 `now` 면 v10.300 과 같음(`frozenAt` 은 함께 옴) |

| `GET /admin/health/rate-schedules` | ADMIN · SUPER | 줄마다 `readsFrozenAt` 더함 |
