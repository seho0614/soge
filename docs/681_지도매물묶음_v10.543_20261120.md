# 681. 지도 매물 묶음 (v10.543 · 2026-11-20)

## 1. 결론
지도에서 **가까운 매물을 묶어 수만** 돌려주는 **공개 API**(`GET /api/v1/listings/map/clusters` · 로그인 없음)입니다. 돌려주는 것은 **묶음 가운데 좌표 · 매물 수**뿐 — 매물 id · 제목 · 주소 · 매물 좌표는 싣지 않습니다(결정 map-kakao #3 「A안 · 시 · 구 중심 · 핀 없음」 그대로). 처음에는 꺼져 있습니다(`map.cluster_enabled` off · 격자 단계 `map.cluster_grid` off). 위치: 운영 **검수 › 지도 매물 묶음**(SB-ADM-VSX-020 · 탭 `vsx-map` · 미리보기).

| 카카오 지도 단계(level) | 방식 | 가운데 |
|---|---|---|
| 10 ~ 14 | SIDO 시 · 도 묶음 | 그 시 · 도 안 시 · 구 중심(geo_region)의 매물 수 무게 평균 |
| 7 ~ 9 | SGG 시 · 구 묶음 | 시 · 구 중심(공개 화면 「둘레 원」과 같은 점) |
| 1 ~ 6 | GRID(켰을 때만 · 화면 범위가 2.5도 안일 때) | 정확 좌표를 격자(단계마다 0.02 ~ 0.08도 · 약 2km 넘음)로 묶은 **격자 가운데** · 격자에 `map.cluster_min` 3개 아래면 그 매물은 시 · 구 묶음으로 합침 |
| 꺼져 있으면(1 ~ 6) | SGG | 위와 같음 |
| 지도 · 카카오 키 없음 | LIST | 좌표 없이 시 · 구별 수 목록(화면은 목록으로) |

- 게시 중(PUBLISHED) 매물만 · 관(gwan) 고르기 · 같은 질문은 60초 기억(서버 메모리 · 500개).
- 화면 범위(swLat · swLng · neLat · neLng)는 넷을 함께 · 국내 범위만.

## 2. 전체 구조
1. 표 없음 · 설정 3(`map.cluster_enabled` · `map.cluster_grid` · `map.cluster_min`).
2. 서버 `src/modules/vsx/map-clusters.ts` · 공개 컨트롤러 `VsxMapController`(api/v1/listings · @Roles 없음).
3. **check-acl**: 주소 첫 마디가 `listings` — 이미 공개 구역(PUBLIC_OK)이라 check-acl.js 패치 없음. 두 마디 주소(`map/clusters`)라 `GET /listings/{id}` 와 겹치지 않음.
4. 정확 좌표(listing_geo)는 **DB 안 셈에만** 쓰고(공개 보기 v_* 가 아님 → MAP-1 불변식 그대로 0) 밖으로는 격자 번호에서 만든 가운데만 나감.

## 3. API
| 방법 | 주소 | 누가 | 오류 |
|---|---|---|---|
| GET | /listings/map/clusters?level=&gwan=&swLat=&swLng=&neLat=&neLng= | 누구나 | 422 MAP_LEVEL · MAP_GWAN · MAP_BBOX |

## 5. 법무 · 확인할 것 · 주의 — **법무 확인 끝(11/21 대표)**
1. **격자 단계(map.cluster_grid)**: 정확 좌표를 2km 넘는 격자로 묶어 격자 가운데 · 수만 내는 방식 — **법무 확인 끝(11/21 대표)**. 스위치는 처음 off 그대로 · 켜는 때는 대표 결정(결정 map-kakao 에 한 줄).
2. 매물이 아주 적은 시 · 구는 시 · 구 묶음 수가 1 이어도 그대로 보임(지금 공개 화면의 시 · 구 표시와 같은 정밀도).
3. 사용자 웹 지도 화면(목록 지도 보기 · map-kakao #4 의 2차)은 이번 묶음에 없음 — API 만 준비(다음 묶음 후보).
