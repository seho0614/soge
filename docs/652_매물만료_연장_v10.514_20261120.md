# 652. 매물 만료 · 연장 (v10.514 · 2026-11-20)

## 1. 결론(대표 결정 11/20)
「**매물 만료는 관리자가 지정한다. 등록 확정 시 기간을 지정, 기본은 6개월.**」
- 게시 확정(검수 승인) 단계에서 운영자가 만료 기간을 고름 — **1 · 3 · 6 · 12개월 · 직접 날짜**, 기본 **6개월**(`lsx.expiry_default_months` · SUPER 가 바꿈 · 처음 6).
- 만료일은 매물마다 한 줄(`lsx_listing_expiry`)에 저장 — 「마지막 수정 뒤 N일」 방식은 쓰지 않음.
- 만료 예고는 회원 알림(`lsx.expiry_warn_days` · 처음 **7일 전**) · **연장은 운영자만**(날짜 바꾸기 · 사유 · 감사) · 회원은 「연장 요청」만 · 만료되면 **내림**(ARCHIVED · 지우지 않음).
- 스위치 `lsx.expiry` **처음 꺼짐** — 켜기 전에는 내리지 않고 날짜만 저장 · 표시.

## 2. 만료일이 정해지는 길
| 길 | 만료일 |
|---|---|
| 검수 승인(`PATCH /admin/reviews/{id}`) | 새 칸 `expiryMonths`(1 · 3 · 6 · 12) 또는 `expiresOn`(YYYY-MM-DD · 그 날 끝 · 36개월 안). **안 보내면 기본 6개월**(옛 승인 흐름 · 옛 시험 그대로). 값이 틀리면 422 `LSX_EXPIRY_RANGE` — 승인 전체가 되돌아감(같은 트랜잭션) |
| 자동 승인 · 그 밖의 게시 | DB 트리거 `trg_lsx_expiry_default`(게시로 바뀌는 순간)가 기본 기간 |
| 고쳐서 재검수 뒤 다시 게시 | **남은 만료일이 있으면 그대로**(고쳐도 기간이 늘지 않음) · 지났으면 기본 기간 · 검수자가 승인 칸에서 고르면 그 값 |
| 운영 화면 › 검수 › 매물 만료 · 연장 | 개월(지금 만료일부터) · 직접 날짜 · 사유 · 감사 `LSX_EXPIRY_SET` · 만료로 내린 것은 「연장 · 다시 게시」(restore — 아래 2-1) |
| 회원 연장 요청 → 운영 승인 | 요청 개월(또는 고친 값) · 만료로 내린 매물은 다시 게시 · 알림 `LSX_EXTEND_OK` / 반려 `LSX_EXTEND_NO`(사유) |
| **처음 적용(D276)** | 이미 게시 중인 매물 = **게시일 + 6개월**, 이미 지났으면 **적용일 + 30일 유예**(한꺼번에 내려가지 않게 · set_kind BACKFILL) |

### 2-1. 만료 매물을 다시 게시할 때 — 「내용이 바뀌었을 때만 검수」(대표 결정 11/20)
| 경우 | 처리 |
|---|---|
| 만료 뒤(또는 연장 요청 뒤) 내용 그대로 | **바로 게시**(전에 승인한 내용 · 기록 RESTORE) |
| 내용이 바뀜(제목 · 본문 · 금액 · 사진 · 지역 · 등록 칸 등) | 기존 검수 흐름 — `IN_REVIEW` + 검수 줄(`ReviewRepository.enqueue` · 자동검수 · 사람 검수 그대로 · 기록 QUEUED) · 승인되면 정한 만료일로 게시 |
| 회원이 이미 고쳐 재검수 중(IN_REVIEW) | 날짜만 바꾸고 검수 결과를 따름 |
| 견줄 지문이 없음 | 바뀐 것으로 봄(검수 — 안전한 쪽) |
- 비교: 만료로 내릴 때 내용 지문 `fn_lsx_listing_fp`(매물 줄에서 상태 · 판 · 조회 · 시각 같은 칸을 뺀 나머지 + 사진 파일 차례 + 지역 → md5)을 `expired_fp` 에, 연장 요청 때 `req_fp` 에 저장 → 다시 게시 때 지금 지문과 견줌. 모르는 새 칸은 내용으로 셈(바뀌면 검수 쪽).
- 옛 검수 흐름 · 옛 시험 글자는 그대로(검수 줄을 새 방식으로 만들지 않음).

- 검수 상세(SB-ADM-REV-020) 오른쪽 「노출 만료」 고르기(기본 표시는 설정 값) — 매물일 때만 승인 본문에 실음.

## 3. 정기 작업 `lsx_daily`(08:10 · 스위치 on 일 때)
1. 예고: 게시 중 · 만료일이 예고 기간 안 · 그 만료일로 아직 안 알림 → `LSX_EXPIRY_SOON`(만료일마다 한 번 · 끌 수 없는 이용 통지).
2. 내림: 게시 중 · 만료일 지남 → `status = ARCHIVED` · `expired_at` · 끌어올림 효과 지움 · `LSX_EXPIRED` 알림. 한 건씩(다른 매물 트리거 오류가 전체를 막지 않게 · 실패는 기록 FAIL) · 50건 넘게 내리거나 실패가 있으면 운영 알림 `LSX_EXPIRE_BATCH`.
- 켜기 전 확인: 운영 화면 「날짜 지남」 수 → 필요하면 **한꺼번에 유예**(SUPER · 오늘 + N일 · `POST /admin/lsx/expiry/grace`).
