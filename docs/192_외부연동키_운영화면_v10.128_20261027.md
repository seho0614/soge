## 2. 어떻게 동작하나

1. 키를 넣으면 DB 함수 `fn_integ_secret_set` 이 **키마다 형식**을 보고(아래 표) 암호화해 저장합니다. 비공개 키면 외부 연동 줄의 「키 등록 완료」가 저절로 켜집니다.
2. API 의 `IntegrationSecretService` 가 운영 화면 키를 풀어 **`process.env` 에 얹습니다** — 띄울 때 · 1분마다 · 저장 · 지운 직후.
   연동 코드(결제 · 계좌 · 국세청 · 중개사 · 세금계산서 · 메일 등)는 전부터 부를 때마다 `process.env` 를 읽으므로 **고치지 않았습니다**.
3. 지우면 띄울 때의 `.env` 값으로 돌아갑니다(없으면 그 연동은 간주 · 시험 · 「준비 중」).
4. 결제창 클라이언트 키(공개 키)는 사용자 웹이 **빌드 때 굳히던 값 대신** `GET /api/v1/site-settings/payment` 로 받습니다(받기 전 · 못 받으면 결제 단추를 막음 · 1분 기억).
   서버는 시크릿 키와 짝(test/live)이 맞을 때만 공개 키를 줍니다 — 결제창은 실제인데 승인은 시험(스텁)이 처리하는 일을 막음.
5. 다시 읽기는 한 줄로 돕니다(1분 타이머와 저장 · 지우기가 겹쳐 지운 키가 되살아나지 않게). 띄울 때 못 읽으면 오류로 남기고 3초 간격으로 다시 시도합니다.
6. 카카오맵 · 날씨 · AI 키는 이 구역에서 넣지 않습니다(각 구역 — 그쪽 기억을 바로 비움).

### 다국어 켜기(함께 고침)

| 손님이 언어를 고르려면 | 어디서 |
|---|---|
| ① 다국어 켜기(`i18n.enabled`) | 운영 화면 › 번역 › 언어 › **「다국어 켜기」(새 단추 · 확인 창 · 감사 SITE_SETTING_UPDATE)** |
| ② 그 언어 켜기(예: 영어) | 같은 화면 아래 언어 표의 「켜기」 |

둘 다 켜면 **1분 안에** 사용자 화면 머리에 언어 단추가 나옵니다(사용자 웹이 언어 목록을 1분 기억). 승인하지 않은 번역은 한국어 그대로 보이므로 번역 초안 승인 뒤 켜는 것을 권합니다.

## 5. 운영에서 할 일 (적용 뒤 · 대표 · 운영자)

1. 운영 화면 › 외부 연동 › 「연동 키」에 업체에서 받은 키를 넣습니다(계약된 것만).
2. 실제 호출을 확인한 뒤 그 연동의 간주 모드를 끄고 상태를 LIVE 로 바꿉니다(키를 넣는 것만으로는 바뀌지 않음).
3. `.env` 에 이미 넣은 키는 그대로 두어도 됩니다 — 운영 화면에 넣으면 그 값이 먼저 쓰입니다.
4. **토스는 시크릿 키 · 클라이언트 키를 같은 계정(같은 test/live)으로 함께** 넣으십시오 — 한쪽만 바뀌면 결제창과 승인이 어긋납니다.
