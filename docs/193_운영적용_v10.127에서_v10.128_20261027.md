## 6. 반영 뒤 (대표 · 운영 화면)

### 6-1. 다국어 켜기 — 번역 초안 승인 뒤

1. 운영 화면 › 관 관리 › 번역 › 원문 목록에서 영어 초안(「승인 대기」)을 읽고 고쳐 승인(docs/187 3절)
2. 번역 › **언어** → 영어 「켜기」 → 위 **「다국어 켜기」**(확인 창)
3. **1분 안에** 사용자 웹 머리에 언어 단추가 나옴 — 끄려면 「다국어 끄기」

### 6-2. 외부 연동 키 — 계약된 업체만

1. 운영 화면 › 외부 연동 › 「연동 키」 → 업체 콘솔에서 받은 키를 붙여 넣고 **저장** → 끝 4자리 · 「이 화면에서 넣음」
2. **토스는 시크릿 키 · 결제창 클라이언트 키를 함께**(같은 계정 · 같은 test/live) — 한쪽만이면 시험 결제 그대로 + 경고
3. 키를 넣어도 **간주 모드 · 연동 상태는 그대로** — 실제 호출을 확인한 뒤 운영 스위치에서 간주를 끄고 상태를 LIVE 로
4. `.env` 에 이미 있는 키는 그대로 두어도 됨(운영 화면 키가 먼저)
