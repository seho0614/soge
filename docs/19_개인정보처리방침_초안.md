# 개인정보처리방침 (초안)

> **자동 생성 초안입니다.** `node scripts/gen-privacy-policy.js`
> 실제 스키마와 보관 현황에서 뽑았습니다. **법무 검토 후 게시하십시오.**
> 〔 〕 부분은 시스템이 알 수 없는 항목이라 직접 채워야 합니다.

---

## 제1조 (총칙)

노명석이(가) 운영하는 소개뱅크(이하 "회사")는
개인정보보호법에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게
처리하기 위하여 다음과 같이 개인정보처리방침을 수립·공개합니다.

회사는 **사업자 간 소개·알선을 중개하는 플랫폼**으로, 거래 당사자가 주고받는
소개비를 수탁하지 않으며 결제·정산 대금을 보관하지 않습니다.

## 제2조 (수집하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 필수 (회원가입) | 이메일, 성명, 비밀번호 | 이용자 직접 입력 |
| 선택 | 전화번호 | 이용자 직접 입력 |
| 본인확인 시 | **연계정보(CI) 해시** | 본인확인기관 제공 |
| 사업자 인증 시 | 사업자등록번호, 상호, 대표자명, 사업장 주소 | 이용자 직접 입력 |
| 정산 신청 시 | 계좌번호(암호화), 예금주 | 이용자 직접 입력 |
| 상담 신청 시 (비회원 포함) | 이름, 휴대폰 번호(암호화), 지역(시·도, 시·군·구), 상담 내용 | 이용자 직접 입력 |
| 자동 생성 | 접속 IP, 접속 일시, 브라우저 정보, 방문자 식별자 | 서비스 이용 과정 |

> **연계정보(CI)는 해시값만 보관하며 원문을 저장하지 않습니다.**
> 주민등록번호는 수집하지 않습니다.

## 제3조 (개인정보의 처리 목적)

| 목적 | 근거 |
|---|---|
| 회원 가입·관리, 본인확인 | 계약의 이행 |
| 사업자 자격 확인 | 법령상 의무 이행, 계약의 이행 |
| 소개 연결 및 거래 성사 기록 | 계약의 이행 |
| 상담 신청을 인증업체에 전달 (안심소개 「생활 · 금융 상담」) | 정보주체의 동의 |
| 소개비 정산 (사업자에 한함) | 계약의 이행 |
| 구독료 결제 | 계약의 이행 |
| 부정 이용 방지, 분쟁 처리 | 정당한 이익 |
| 서비스 안내·알림 발송 | 계약의 이행 (마케팅은 별도 동의) |

## 제4조 (개인정보의 보유 및 이용 기간)

회사는 보유 기간이 지나면 지체 없이 파기합니다. **파기는 매일 자동으로 실행되며,**
**기한을 넘긴 건이 있으면 운영 경보가 발생합니다.**

| 보유 항목 | 보유 기간 | 근거 |
|---|---|---|
| 회원 계정 — 이메일·성명·전화 | 탈퇴 후 거래이력 有 5년 / 無 즉시 | 전자상거래법 제6조 |
| 본인인증 — CI 해시 (원문 미보관) | 계정 파기 시 함께 | 개인정보보호법 제21조 |
| 사업장 주소 — 우편번호·도로명·시군구·상세주소 (개인사업자는 자택인 경우 있음) | 계정 파기 시 함께 | 개인정보보호법 제21조 |
| 접속 기록 — IP·User-Agent | 1년 후 마스킹 | 통신비밀보호법 준용 |
| 유입 기록 — IP 해시·방문자키 | 만료 90일 후 제거 | 개인정보보호법 제21조 |
| 관심 성향 — 6문항 답변·세그먼트 (선택 · 동의 필수) | 이용자가 해지하면 즉시 삭제 / 계정 파기 시 함께 | 개인정보보호법 제21조 |
| 소개자 프로필 — 활동지역·소개 가능 분야·대상 유형 | 계정 파기 시 함께 | 개인정보보호법 제21조 |
| 소개 초대 — 초대 대상 표기명 (연락처는 발송 후 즉시 파기) | 동의 시 연결 기록으로 / 미동의 시 14일 후 만료 | 개인정보보호법 제21조 |
| 상담 신청 — 이름·휴대폰(암호화)·지역·상담 내용 | 업체에 전달되기 전: 신청 후 6개월 (휴대폰 확인을 마치지 않은 신청은 하루 뒤 연락처 삭제) / 업체에 전달된 뒤: 90일 | 개인정보보호법 제21조 · 동의서 |

**탈퇴 시 처리**

- 거래·정산 이력이 **없는** 경우 — 즉시 파기
- 거래·정산 이력이 **있는** 경우 — 5년 보관 후 파기 (전자상거래법)
- 파기 시 이메일·성명·전화·CI 해시·계좌번호를 삭제하며,
  거래 기록의 무결성을 위해 식별 불가능한 형태의 계정 기록만 남습니다.

## 제5조 (개인정보의 제3자 제공)

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음은 예외입니다.

- 이용자가 **소개 연결에 동의**한 경우, 거래 상대방에게 상호·담당자명·연락 수단이 제공됩니다
- 이용자가 **상담 신청 시 제3자 제공에 동의**한 경우, 그 업종의 **인증업체 1곳**에 이름·휴대폰 번호·지역·상담 내용이 제공됩니다
  (목적: 상담 연락 · 휴대폰 확인을 마친 신청만 · 업체가 연락처를 연 때 제공 · 보유 기간: 상담 종료 시 또는 최대 6개월).
  받아 간 업체는 로그인한 신청자의 「내 상담 신청」에서 확인할 수 있습니다
- 법령에 따라 수사기관이 적법한 절차로 요구하는 경우

## 제7조 (이용자의 권리와 행사 방법)

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- 개인정보 열람 — 마이페이지 또는 고객센터
- 정정·삭제 요구 — 마이페이지에서 직접 수정하거나 고객센터로 요청
- 처리정지 요구 — 고객센터
- 회원 탈퇴 — 마이페이지

회사는 요구를 받은 날부터 **10일 이내**에 조치하고 결과를 알려 드립니다.

## 제8조 (개인정보의 파기 절차 및 방법)

회사는 보유 기간이 지나거나 처리 목적이 달성되면 지체 없이 파기합니다.

| 구분 | 내용 |
|---|---|
| 파기 절차 | 파기 사유가 발생한 개인정보를 선정하고, 개인정보 보호책임자의 승인을 받아 파기합니다. |
| 전자적 파일 | 복구할 수 없는 방법으로 영구 삭제합니다. |
| 출력물 | 분쇄하거나 소각합니다. |

다른 법령에 따라 보존해야 하는 정보는 그 기간 동안 별도 분리해 보관하며, 
보관 외의 목적으로 이용하지 않습니다.

> **소개 초대**는 예외적으로 더 빨리 지웁니다. 초대 대상의 연락처는 
> 발송 직후 파기하며, 재발송하려면 소개자가 다시 입력해야 합니다 — 
> 동의하지 않은 분의 연락처를 보관하지 않기 위해서입니다.

## 제9조 (개인정보 자동 수집 장치의 설치·운영 및 거부)

회사는 이용자 맞춤 서비스를 위해 쿠키(cookie)를 사용합니다.

| 구분 | 내용 |
|---|---|
| 사용 목적 | 로그인 유지, 접속 빈도 분석, 소개 요청 유입 경로 확인 |
| 거부 방법 | 브라우저 설정에서 쿠키 저장을 거부할 수 있습니다. |
| 거부 시 영향 | 로그인이 유지되지 않아 일부 서비스 이용이 어려울 수 있습니다. |

> 유입 경로 확인에는 **IP 해시**를 씁니다. 원본 IP 를 그대로 보관하지 않으며, 
> 만료 90일이 지나면 제거합니다.

## 제10조 (만 14세 미만 아동의 개인정보)

회사의 서비스는 사업 목적의 연결을 다루므로 **만 14세 미만 아동을 대상으로 하지 않습니다.**
만 14세 미만 아동의 가입 사실이 확인되면 지체 없이 해당 정보를 파기합니다.

## 제11조 (가명정보의 처리)

회사는 통계 작성과 서비스 개선을 위해 가명정보를 처리할 수 있습니다.
이때 특정 개인을 알아볼 수 있는 정보는 별도 분리해 보관하며, 
가명정보를 다시 식별하려는 시도를 하지 않습니다.

> **분류 이력**이 여기 해당합니다. 입력 문장에 개인정보가 섞일 수 있어 
> 90일 뒤 지우며, 어휘 개선 외의 목적으로 쓰지 않습니다.

## 제12조 (개인정보의 안전성 확보 조치)

| 조치 | 내용 |
|---|---|
| 비밀번호 | 복호화 불가능한 단방향 암호화(bcrypt) |
| 계좌번호 | 암호화 저장 |
| 연계정보(CI) | 해시값만 저장, 원문 미보관 |
| 접근 통제 | 권한 분리, 운영 계정 상시 접근 권한 없음 |
| 접근 기록 | **개인정보 조회 이력을 별도 보관하며 위·변조를 차단** |
| 전송 구간 | HTTPS 암호화 |
| 자동 파기 | 보유 기간 경과 시 매일 자동 파기, 지연 시 경보 |
