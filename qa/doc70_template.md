## 1. 언어 단추 (G-138)

### 1-1. 증상과 원인

| # | 증상 | 원인 |
|---|---|---|
| 1 | 머리줄의 「한국어 ▾」 단추가 세로 87px(머리줄은 58px) | 단추 안의 「▾」가 **로그인 상자의 스타일**(안쪽 여백 30px · 테두리)을 받아 63×73 상자가 됨 |
| 2 | 로그인 화면 — 제목 「로그인」이 회색, 「로그인」 「사업자로 회원가입」 「성향 분석하고 등록하기」가 32px 로 납작 · 글자가 왼쪽 | 로그인 상자 · 단추가 **언어 단추의 스타일**(글자색 · 여백 6px)을 받음 |
| 3 | 단추를 눌러도 언어 목록이 안 보임 — 단추에서 834px 아래(화면 맨 아래)에 열림 | 선택자가 떨어져 나간 스타일 조각이 바로 뒤의 `.lang{position:relative}` 를 삼킴 |

1 · 2 는 한 뿌리입니다 — 언어 단추와 로그인 화면이 **같은 이름(`.lgb` · `.lgc`)** 을 쓰고 있었습니다. 두 번째 것은 이번에 원인을 따라가다 찾았습니다(요청하신 것은 1번).

### 1-2. 고친 것

```css
/* 전 — 두 곳이 같은 이름 */
.lgc{background:#fff;border:1px solid …;padding:30px 28px;width:100%;max-width:420px}   /* 로그인 상자 */
.lgb{width:100%;padding:13px}                                                         /* 로그인 단추 */
…
.lgb{display:flex;…;padding:6px 10px;…}    /* 언어 단추 */
.lgc{color:var(--g400);font-size:10px}      /* 언어 단추의 ▾ */

/* 지금 — 언어 단추 쪽 이름을 바꿈 */
.lngb{display:flex;…;padding:6px 10px;…}
.lngc{color:var(--g400);font-size:10px}
```

그리고 선택자 없이 남아 있던 조각(`padding:15px 18px;border:1.5px solid var(--bl);…transition:.15s}`)을 지웠습니다. 이 조각은 v10.1 시안에도 있던 것이고, **원래 어느 요소의 스타일이었는지는 남아 있지 않습니다**(지워도 달라지는 화면이 없는 것은 그림 비교로 확인했습니다).

### 1-3. 다른 화면에 영향이 없는지 — 그림 비교

스타일을 고치면 글자가 같아도 모양이 달라질 수 있어, 앞 판(v10.21)과 **화면 189장을 그림으로 찍어** 견줬습니다(`qa/proto_pixel.py`).

| 구분 | 화면 수 | 판정 |
|---|---|---|
| 점 하나 같음 | __PXSAME__장 | 언어 단추가 없는 화면 전부 |
| 머리줄의 언어 단추 자리만 다름(그 아래는 점 하나 같음) | __PXHEAD__장 | 의도한 변화 |
| 머리줄 밖까지 다름 | 2장 — 로그인(login) · 소개창업 랜딩(listb) | 의도한 변화 |

## 4. 알아 두실 것

1. **실제 웹에는 세 축이 없습니다.** 이번 것은 시안입니다. 실제 웹에 만들려면 DB 의 축 값 · API · 화면 · 운영 화면이 모두 필요합니다.
2. **목록의 단추 이름이 둘 바뀌었습니다** — 운영지원 「자문 요청」→「상세 보기」, 교육 「수강 신청」→「상세 보기」. 신청 단추는 상세 안으로 옮겼습니다. 공고 · 정책의 「공고 보기」는 그대로입니다.
3. **「지원」 갈래는 처음에 비어 있습니다.** 공고 상세에서 「업체 소개 요청」을 눌러야 쌓이고, 시안은 저장하지 않으므로 파일을 다시 열면 비워집니다.
4. **날짜는 볼 때마다 달라집니다.** 오늘 기준으로 계산하므로 내일 열면 하루씩 밀립니다(지난 날짜가 다시 생기지 않게 한 것).
5. **정책 · 교육의 내용은 지어낸 예시입니다.** 기관 이름이 실제 기관이라 화면에 「시연용 견본」을 표시했습니다. 「지원 대상」 같은 칸의 글도 예시입니다.
6. **인력 축의 문구는 앞 판 그대로 두었습니다** — 「채용 기업이 성사 수수료를 냅니다」 「개인 구직자를 …」 등. 답하신 대로 축을 열었지만, 이 문구들이 법무 회신 내용과 맞는지는 회신 문서를 보지 못해 **확인하지 못했습니다.**
7. **빠른 매칭의 「요청 보내기」는 그대로 안내 글입니다** — 상세가 아니라 요청 단추라 손대지 않았습니다.
8. **스타일 이름 겹침은 이번이 세 번째입니다**(G-131 후기 · G-138 언어 단추 · G-139 배지). 시안 전체의 이름 겹침을 한 번에 찾는 점검은 하지 않았습니다 — 이번에는 앞 판과의 그림 비교로 「바뀐 곳이 의도한 곳뿐」인지만 봤습니다.
