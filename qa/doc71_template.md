## 4. 바꾼 곳

### 4-1. 서버

| 길 | 내용 |
|---|---|
| `GET /community/board` (새 길) | `board` · `q` · `page` · `size` → `{ items, total, page, size, pages }`. 보이는 범위는 글 목록과 같음(공개 글 + **내** 검수 대기 글). 검색은 `fn_search_match(제목, 본문, 검색어)` — 두 글자 이상인 낱말이 **모두** 든 글. 순서는 고정 글 → 최신순 → id. `size` 1~50(기본 10) · 검색어 50자까지(넘으면 400) · 없는 게시판 400 · 같은 이름을 두 번 보내도 500 이 아님 |
| `GET /community/posts` · `/community/posts/:id` | 응답 모양 그대로. **작성자만 가림**: 첫 글자 + `OO` · 운영자(ADMIN · SUPER)는 「운영자」 · 탈퇴는 「(탈퇴)」 — 목록 · 글 상세 · 댓글 |
| `GET /admin/community/queue` | 그대로(운영자는 이름 전체를 봄) |

4. **한 글자 낱말은 검색에서 빠집니다**(서버의 검색 규칙 — 다른 목록의 검색과 같음).
