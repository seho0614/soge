## 1. 시안 — 바꾼 것

### 1-1. 매물 상세가 한 틀 (SB-MNY-DTL-010 · SB-MAL-DTL-010 · SB-BIZ-DTL-010)

| 구역 | 내용 | 값의 출처 |
|---|---|---|
| 사진 · 분류 · 제목 · **금액** · 지역 · 조회/관심/등록 · 매물번호 | 누른 카드의 값 | 매물 장부(아래 1-2) |
| 등록자 줄 「질문하기 · 전화하기」 | 그림 1 그대로 | 견본(홍길동) |
| 소개자 실적 4칸 | 그림 1 그대로 — 누적수익 칸에 「소개자가 공개를 켠 경우에만 보입니다」 설명 | 견본 |
| 상세 설명 · 조건표 | 견본 3건(고깃집 · 식자재 공급처 · 물류창고)은 원래 글. **그 밖의 매물은 넘겨받은 분류 · 지역 · 금액으로 만든 글** | 장부 값 |
| 문의 내용 | 견본은 원래 7건, 그 밖은 일반 질문 5건 | — |
| 소개자 후기 · 소개 내용 상자 | 그림 1 그대로(소개 내용은 매물의 분류 · 지역 · 금액 · 등록) | 견본 + 장부 값 |
| **맨 아래 줄** | 「관심 담기 · 질문 N · 공유하기 · 신고 · 1:1 문의 시작」 | — |
| 관별 안내 | 안심소개: 부동산 노출료 안내 + 「이 매물 소개하기」(소개코드 공유) / 소개장터: 소개비 협의 안내 / 공통: 귀속 안내 | 앞 판 그대로 |

맨 아래 줄은 답하신 대로 합쳤습니다 — 「♡ 관심 18」→「관심 담기」(누르면 「관심 담김」), 「지금 바로 문의하기」→「1:1 문의 시작」, 「신고」는 새로. 「질문 N」 「공유하기」는 그대로입니다.

### 1-2. 매물 장부와 주소

카드가 쓰는 자료에 매물번호를 붙여 두고, 상세는 주소의 번호로 그 매물을 찾아 그립니다.

```js
// sgb/spec/proto.html — 매물 장부 (itemsInit)
// 소개장터 5101~ · 안심소개 6101~ · 소개창업 7101~ · 급구급매 8101~ · 마이 관심은 그 번호(L-3301 → 3301)
// 견본 3건은 앞 판의 번호 그대로: 소개창업 1042 · 소개장터 4471 · 안심소개 4468
ITEMS["5102"] = { no:"5102", g:"MNY", t:"맥북 프로 16형 M2 16GB 512GB", cd:"가전 · 디지털", p:"289만원", r:"경기 성남시", a:"2시간 전", l:18, k:"mac" };

// 주소:  #/g/mny/l/5102   →  화면 dtlm 이 ITEMS["5102"] 를 그림
// 문의방: #/g/mny/chat/5102 →  위쪽 요약 · 「리스팅 보기」 · 「돌아가기」가 그 매물
```

| 주소 | 열리는 것 |
|---|---|
| `#/g/mny/l/5102` | 소개장터 상세 — 그 매물 |
| `#/g/biz/l/1042` · `#/g/mny/l/4471` · `#/g/mal/l/4468` | 앞 판의 견본 3건(그대로) |
| `#/g/mal/l/99999999` (없는 번호) | 그 관의 견본 |
| `#/g/biz/chat/7103` | 그 매물의 문의방 |
| `#/chat/8821` (매물 없이) | 견본(소개창업 고깃집) 문의방 |

실제 서비스에서는 서버의 매물 id 가 이 번호 자리에 옵니다(`/money/{id}` · `/mall/{id}` · `/biz/{id}`).

### 1-3. 그 밖

| # | 화면 | 바꾼 것 |
|---|---|---|
| 1 | 마이 「관심」 | 「보기」 · 「1:1 문의」가 항목의 관 · 번호로(전에는 전부 소개장터 상세 · 한 문의방) |
| 2 | 문의방 | 위쪽 요약 · 대화 · 예상 소개비 상자가 그 매물 기준. 「리스팅 보기」 · 「돌아가기」가 처음 매물로(왕복 6건 중 5건 실패 → 0건) |
| 3 | 소개광장 글 목록 | 글 6건이 보이고 제목이 그 글의 상세(`#/community/{번호}`)로 — 전에는 **빈 표**였습니다(5절 G-132) |
| 4 | 마이 > 프로필 · 사업자 정보 | 「공개 설정 — 누적수익 공개」 선택 칸(기본 꺼짐) |
| 5 | 돌아가기 글 | 옛 관 이름 「소개머니 · 소개몰」→「소개장터 · 안심소개」(G-121) |
| 6 | 카드 사진 | 랜딩 · 전체 목록 · 상세가 같은 사진을 쓰도록 한 곳에서 고름 |

화면 수 189장 · 화면 ID 는 그대로입니다. 앞 판과 다른 화면은 16장입니다(매물 상세 3 · 문의방 2 · 카드가 있는 목록 7 · 마이 관심 · 소개광장 글 목록 · 프로필 · 창업 등록의 돌아가기 글).

## 2. 실제 웹 — 바꾼 것

### 2-1. 매물 상세 (`/money/{id}` · `/mall/{id}` · `/biz/{id}`)

원칙 — **실제 웹에는 서버에 있는 진짜 값만** 냅니다. 시안의 견본 숫자(128건 · 15,680,000원 · 신용 86점)는 넣지 않았습니다.

| 그림 1의 구역 | 실제 웹 | 값의 출처 |
|---|---|---|
| 사진 | 분류 그림 + 「사진 준비 중」 | 사진 등록 기능 전 — 분류 이름으로 7종(자동차 · 부동산 · 기계 · 식품 · 에너지 · 창업 · 기타) 중 고름 |
| 분류 · 제목 · 배지 | 그대로 | `GET /listings/{id}` |
| 금액 | **소개비**(매물 금액 항목이 서버에 없습니다) | `desiredFee` |
| 조회 · 관심 · 등록 시각 · 지역 | 그대로 | `viewCount`(새로) · `likeCount` · `publishedAt` · `regionNames` |
| 신용 점수 | 넣지 않음 | 서버에 없음 |
| 등록자 줄 | 상호 · 사업자 인증 · 가입 연월 · 「질문하기」(공개 문의로) · 「전화하기」(준비 중 안내) | `owner.joinedAt`(새로) |
| 소개자 실적 | 총 소개 · 성사(계약) · 성사율 — **누적수익은 본인이 켠 경우에만 4번째 칸** | `owner.totalDeals` · `confirmedDeals` · `successRate` · `settledAmount`(새로) |
| 상세 설명 | 본문 + 조건표(분류 · 지역 · 소개비 · 등록) | `body` |
| 문의 내용 | 공개 문의(기존 기능) | `GET /listings/{id}/questions` |
| 소개자 후기 | 실제 후기 — 작성자는 「김○○」, 연락처는 가림. 없으면 「아직 후기가 없습니다」 | `GET /listings/{id}/reviews`(새로) |
| 맨 아래 줄 | 「관심 담기 · 질문 N · 공유하기 · 신고 · 1:1 문의 시작」 | 아래 2-2 |
| 안심소개의 「소개코드 공유」 | 그대로 | — |

### 2-2. 맨 아래 줄의 동작

| 버튼 | 로그인 전 | 로그인 뒤 |
|---|---|---|
| 관심 담기 | 로그인 화면으로 → **로그인하면 보던 매물로 돌아옴** | 「관심 담김」으로 바뀌고 DB 에 저장 · 위쪽 관심 수 +1 · 다시 누르면 빠짐 |
| 질문 N | 공개 문의 자리로 내려감 | 같음 |
| 공유하기 | 주소 복사 안내 | 같음 |
| 신고 | 신고 화면(`/report/listing/{id}`) — 로그인 · 본인인증 필요(기존 규칙) | 신고 화면 |
| 문의 버튼 | 「본인인증 후 문의할 수 있습니다」 | 자격이 되면 「1:1 문의 시작」→ 문의방 / 사업자 전환 전이면 그 안내 / 내 매물이면 「내가 등록한 매물입니다」(눌리지 않음) |

문의할 수 있는지는 화면이 계산하지 않고 **서버가 판정한 값**을 그대로 씁니다(기존 방식).

### 2-3. 누적수익 공개 설정 (`/my/account` → 「공개 설정」)

```
[ ] 누적수익 공개 — 내 매물 상세의 「소개자 실적」에 누적수익(정산받은 소개비 합계)을 보여 줍니다.
    꺼 두면 총 소개 · 성사(계약) · 성사율만 나옵니다.                         [공개 설정 저장]
```

기본은 꺼짐입니다. 가리는 일은 화면이 아니라 **DB 의 뷰가** 합니다 — 켜지 않은 회원의 누적수익은 API 응답에 아예 실리지 않습니다(3절).

## 4. 알아 두실 것

1. **소개자 실적의 뜻** — 서버 집계는 그 회원이 **소개자로 참여한 거래**(소개코드로 귀속된 거래) 기준입니다. 지금 개발 자료에서는 대부분 0건입니다. 매물을 올린 사람의 판매 실적까지 넣을지는 정해 주시면 바꿉니다.
2. **누적수익은 지금 0원** — 소개비 중개 기능이 정책상 꺼져 있어(정산 완료 금액이 생기지 않음) 공개를 켜도 0원으로 나옵니다. 기능을 켠 뒤에 값이 생깁니다. 시험에서는 정산 완료 거래 1건(700,000원)을 넣어 켜면 보이고 끄면 사라지는 것을 확인하고 지웠습니다.
3. **금액 자리 = 소개비** — 서버에 매물 금액(가격) 항목이 없습니다. 시안처럼 매물 금액을 보이려면 등록 양식 · DB 에 항목을 더해야 합니다.
4. **실제 웹의 색 · 글꼴은 그대로** — 이번에는 구성(형식)만 그림 1에 맞췄습니다. 보라 · 주황 색과 글꼴은 디자인 맞춤 판에서 다른 화면과 함께 바꿉니다.
5. **시안의 사진은 5종** — 시안에 든 견본 사진이 5장(자동차 · 노트북 · 실내 · 카페 · 상가)이라, 태양광 매물에 상가 사진이 나오는 식입니다. 카드와 상세는 같은 사진입니다(5절 G-137).
6. **시안의 소개자 · 실적 · 후기는 견본** — 어느 매물을 눌러도 홍길동 · 128건입니다(말씀드린 대로).
7. **후기를 쓸 수 있는 사람** — 거래 당사자(구매자 · 판매자) 중 사업자 계정입니다(기존 권한). 소개자 본인은 쓸 수 없습니다.
