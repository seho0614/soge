# 소개뱅크 화면 ID 기능 코드 예약표 v1.1 (레지스트리 대조)

Oct 1, 2026 · @박세호

## 0. 개요, 결론, v1.0 대비 정정

예약표 v1.0(문서 248개 ID 기준)을 실제 화면 레지스트리 `sgb/spec/screens.json` v1.2(2026-10-01)와 대조해 확정한 판입니다. v1.0을 대체합니다.

1. **기능 코드 107개**: 구현(레지스트리에 화면 있음) 76 · 계획(문서에만 있음) 29 · 예약만 1(TRS) · 폐기 1(WAL).
2. **영역 코드**: 구현 12개. v1.0의 `AI`는 레지스트리에서 \*\*`AIS`\*\*입니다.
3. **코드를 바꿔야 하는 구현 화면은 3건**입니다(v1.0 판단은 1건).

### 0-1. v1.0과 직전 결정에서 바로잡은 것

## 1. 레지스트리 대조 결과와 정합성 문제

레지스트리와 프로토타입 v10.3.2는 거의 같지만, 레지스트리 안에 같은 화면이 "사용 중"과 "폐기"에 동시에 들어 있는 문제가 있습니다.

### 1-1. 대조 대상

| 출처 | 내용 | 화면 수 |
| --- | --- | --- |
| `sgb/spec/screens.json` v1.2 (10/01) | screens(사용 중) · deferred(보류) · retired(폐기) | 187 · 14 · 18 |
| `SGB_Prototype_v10_3_2.html` | 본문에 나오는 화면 ID | 189 |

프로토타입과 레지스트리 차이는 2건뿐입니다: 프로토타입에만 `SB-ADM-SRV-000`, 레지스트리에만 `SB-ADM-PAY-010`(지급 데스크).

### 1-3. 구현본의 기능 코드 사용 현황

레지스트리 사용 중 화면 187개에 쓰인 기능 코드는 **76개**입니다. v1.0에 없던 구현 코드 8개(ADB · AIS · BDG · BIL · COD · CTR · INT · NTF)를 추가했고, v1.0의 문서상 코드 30개는 "계획"으로 표시했습니다(광고주·퍼블리셔·판매자센터·소개창업 축 화면 등).
