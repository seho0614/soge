# 소개뱅크 AI 검색 기능 적용 문서 (v1.0)

작성일 2026-09-25 · 09.22 업무레포트 기준 정리

## 1. 목적

메인페이지의 탐색 방식을 관별 카테고리 브라우징에서 **AI 자연어 검색**으로 전환하기 위한 기능 정의 및 적용 범위를 확정한다.

## 2. 핵심 컨셉

여러 사이트를 합친 통합몰이 아니라, "AI가 탐색비용을 줄여주고 → 비교해주고 → 거래처로 연결하고 → 이용자가 재소개해 수익창출"하는 구조가 핵심 차별점이다.

## 3. 처리 흐름

사용자 목적 입력 → 의도 분석 → 상품/서비스/전문가/창업정보 검색 → 비교 → 해당 페이지 연결

정보가 부족하면 AI가 역질문(예: "공사 예정일은?", "쓰레기 처리비 포함인가요?")을 하고, 답변을 반영해 재검색한다.

## 4. 시나리오 예시

| 구분 | 입력 예시 | AI 처리 | 결과 |
| --- | --- | --- | --- |
| 쇼핑 | "30만원 이하 부모님 추석선물, 식품 제외, 후기 좋고 재구매 많은 것" | 조건 필터링 | 팝업: 최저가·N개 사이트 비교·평점·재구매율·구매증가 추이 + \[가격비교\]\[구매하기\]\[소개하기\] |
| 사람소개 | "송파구 30평 식당 철거+원상복구, 예산 1천만원" | 역질문(공사예정일/쓰레기처리비) → 답변 반영 | 추천업체 3개 + 평균견적 + 후기 + 상담요청 |

## 5. 결과 정렬/분류

AI추천 / 인기순 / 가격순 / 재구매순 / 소개순 — 검색조건은 사용자가 자유롭게 설정 가능하다.

## 6. 화면 이동 원칙

메인페이지는 AI 검색·비교까지만 담당하고, 세부 처리(실제 구매·상담·계약)는 각 관의 해당 페이지로 이동해 계속 진행한다. 메인이 모든 기능을 떠안지 않는다.

## 7. 적용 전 확인 필요 사항

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 관 매핑 | 소개몰이 부동산 전용(점포·상가·장비·시설)으로 재정의되고, 상품 유통은 소개머니 쪽 직영 마켓(농수산물 산지직거래, B2B 대상)으로 이동함. 예시1(개인용 쇼핑)이 어느 관에 매핑되는지 미확정 | 확인 필요 |
| 결과 노출 방식 | 팝업형 vs 상세페이지형 | 확인 필요 |
| AI 역질문 범위 | 어디까지 질문할지 기준 없음 | 확인 필요 |
| 검색 대상 회원 | 직영 마켓이 B2B 기업회원 전용이라면, 이 AI검색기가 일반 소비자(B2C)를 대상으로 하는지 기업회원(B2B)을 대상으로 하는지 미정 | 확인 필요 |

## 8. 개발 관점 이슈

- 의도분석(NLU), 비교엔진, 역질문 대화형 흐름은 전부 신규 개발 항목으로 기존 로드맵·화면정의서에 반영되어 있지 않음
- 7절의 확인 필요 사항이 해소되기 전에 개발에 착수하면 관 매핑을 임의로 가정하게 될 위험이 있음
