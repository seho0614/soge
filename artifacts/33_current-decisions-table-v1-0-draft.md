# 소개뱅크 현행 확정표 v1.0 (초안)

Sep 24, 2026 · @박세호

## 결론

소개뱅크는 **소개형 4관 · 판매형 1관 · 광고 네트워크**의 세 체계를 한 회사가 운영하는 구조로 확정되어 있습니다(통합설계서 v10, 2026-09-15). 여기에 **제휴 파트너센터**가 별도 서비스로 붙습니다(2026-09-22 결정).

지금 대표 결정이 필요한 것은 **6건**, 결정이 아니라 외부 회신을 기다리는 관문이 **1건**(전자금융업 등록 의무)입니다.

### 이전 답변 정정

직전 대화에서 "문서끼리 어긋나는 곳 5건"을 제시했으나, 통합설계서 v10을 대조한 결과 **4건은 이미 v10에서 정리된 사항**이었습니다. 옛 문서(수익구조 문답 v1.0, 9/09)가 갱신되지 않아 충돌처럼 보였던 것입니다.

| # | 직전 답변의 충돌 | 실제 상태 | 근거 |
| --- | --- | --- | --- |
| 1 | 자금 수탁 (INV-11) | **정리됨** — INV-11 폐기, 에스크로 부활 | v10 §2-3 |
| 2 | 소개거래 에스크로 (B-04) | **정리됨** — 소개형엔 에스크로 없음 | v10 §2-2 |
| 3 | 리드관 수익 | **미결** — 아래 D2 | v10 §1-1 vs 법무 결과 |
| 4 | 광고 과금 정액 vs CPC | **정리됨** — 내부 지면 정액 · 외부 네트워크 CPC 병존 | v10 §1-2 |
| 5 | 개인 사용자 | **정리됨** — 소개형은 사업자 간, 건강몰은 소비자 구매 (A-00R2) | v10 §2-2 |

### 사용법

1. §확정 사항표는 **바꾸지 않는 기준**입니다. 다른 문서와 다르면 이 표가 우선합니다.
2. §결정 요청의 각 줄에 대표가 A/B를 고르면, 그 줄이 확정 사항표로 올라갑니다.
3. 결정 후 §고칠 문서 목록대로 옛 문서를 갱신합니다.

## 확정 사항표

아래 항목은 대표 결정 또는 법무 회신으로 확정된 것입니다. 근거는 통합설계서 v10(9/15), 7체계 재편 보고서(9/15), 파트너센터 결정(9/22)입니다.

### 1. 체계 구조

| 체계 | 관·서비스 | 거래가 끝나는 곳 | 플랫폼이 돈을 만지나 | 당사자 |
| --- | --- | --- | --- | --- |
| 소개형 | MNY 소개머니 · MAL 소개몰 · BIZ 소개창업 · LED 소개리드 | 플랫폼 **밖** | 만지지 않음 (소개비 공제 0 — 정책) | 사업자 ↔ 사업자 |
| 판매형 | HLT 건강몰 (직판 + 브랜드 직영 + 입점) | 플랫폼 **안** | 만짐 (통합수취 + 에스크로) | 사업자 ↔ **소비자** |
| 광고 | ADS (내부 지면 + 외부 퍼블리셔) | — (용역) | 만짐 (예치 + 에스크로) | 광고주 ↔ 퍼블리셔 |
| 제휴 | 파트너센터 (별도 DB·백엔드, 서브도메인, 본체 계정 SSO) | 제휴상품 판매처 | 회사 자기비용으로 수수료 지급 (법무: 수탁 아님) | 회사 ↔ 파트너 |

**대원칙:** 체계끼리 섞지 않습니다. 회원·인증·주소·결제창구만 공유합니다. 코드상 7체계(CORE·MNY·MAL·BIZ·LED·HLT·ADS)로 나뉘어 있습니다.

### 2. 관 경계와 거래 대상

| ID | 확정 내용 |
| --- | --- |
| A-01 | 관 경계 = **고정자산이 넘어가는가.** 안 넘어감 → 소개머니, 자산 자체 → 소개몰, 사업 통째 → 소개창업 |
| A-00R2 | 소개형 4관의 거래는 **사업자 간**. 건강몰은 **소비자가 구매 당사자** |
| 건강몰 품목 | 건강기능식품 · 일반식품 · 화장품 판매. **의료기기는 광고만 가능, 판매 불가** |
| C-07 | 회사 지위 = **통신판매업자 겸 통신판매중개자** (법무 회신 수령) |

| INV-L1\~L3 | 리드관 — 1리드 = 1사업자 독점 배분 |

### 4. 플랫폼 수익원

| --- | --- | --- |

| 제휴 | — (회사가 비용 지급) | 제휴상품별 건당 정액, 주문 시점 단가 고정, 귀속 72시간 마지막 클릭 |

### 5. 돈의 흐름

| 돈 | 흐름 | 플랫폼 경유 |
| --- | --- | --- |
| 소개비 | 등록자 → 소개자 직접 | **없음** |
| 구독·코드 | 회원 → 소개뱅크 (Toss 자동결제) | 있음 |
| 건강몰 대금 | 소비자 → PG → 소개뱅크 대표가맹점 → 에스크로 → 구매확정 후 판매자 | 있음 |
| 광고비 | 광고주 → 예치 → 클릭 시 보류 7일 → 퍼블리셔 / 소개뱅크 배분 | 있음 |
| 제휴 수수료 | 소개뱅크 → 파트너 (트랙별 분리 정산·세금계산서) | 회사 비용 |

**폐기된 원칙:** INV-9R(공제 금지) · INV-11(자금 수탁 금지) — 2026-09-15 대표 결정.

## 결정 요청

대표가 고를 것은 6건입니다. 급한 순서로 놓았고, 권고안을 굵게 표시했습니다.

| # | 결정 | 선택지 | 권고 | 권고 이유 | 급한 정도 |
| --- | --- | --- | --- | --- | --- |
| D1 | 회사 명의 — 푸터가 두 개 | A. (주)소개뱅크 · 박세호 / B. (주)한국바이오헬스케어 소개뱅크 사업부 · 노명석 | 대표 판단 | 통신판매업 신고 주체, 광고 세금계산서 발행 주체, 약관 당사자가 모두 여기서 갈림 | 최상 |
| D2 | 리드관 수익 방식 | A. 리드 확인비용(건당) 유지 / B. **정액 광고 자리만** / C. 보험·의료만 광고, 일반 업종은 건당 | **C** (법무 재확인 전제) | 법무 결과는 보험·의료의 건당 유상 제공을 막음. v10은 여전히 "리드 확인비용"을 수익으로 적음. 금지 범위가 업종 한정인지 리드관 전체인지 확인 필요 | 높음 |
| D3 | 소개비 보호장치 | A. 완전 폐기 / **B. 소개비 표 한정 검정 1건 존치** | **B** | INV-9R 폐기로 소개비 공제를 기계적으로 막는 장치가 사라짐. B는 광고·건강몰을 막지 않음 | 높음 |
| D4 | 외부 퍼블리셔 배분율 | 60% / **70%** / 80% | **70%** | 설계서 권고값. 시장 비교 근거는 문서에 없어 추가 확인 필요 | 높음 |
| D5 | 개인 소개자 허용 | A. 사업자 전용 유지 / B. 개인도 소개만 허용 | **A 유지 → A-09 회신 후 재결정** | 개인 허용 시 원천징수(B-03 전제 붕괴)·직업소개사업 등록 위험 | 보통 (회신 대기) |
| D6 | 첫 화면 | A. 인기 상품 목록(현재) / **B. 「짝」 화면** (SELL↔BUY 연결 + 소개비 합계) | **B** | 1차 사용자가 소개자. 재방문 이유가 "새 짝이 떴는가"임. `side` 필드 신설이 선행 | 보통 |

### 결정이 아닌 관문 — 전자금융업 등록 의무

에스크로 부활로 회사가 남의 돈을 보관합니다. 결제대금예치업·전자지급결제대행업 등록이 필요하면 **§5 돈의 흐름이 통째로 바뀝니다.** 개발로 풀 수 없고 회신을 기다려야 합니다.

| # | 확인할 것 | 어디에 | 상태 |
| --- | --- | --- | --- |
| R-1 | 에스크로·PG 등록 의무 | 변호사 + 금융위 | 확인 필요 |
| R-2 | 광고주 충전금이 선불전자지급수단인지 | 변호사 | 확인 필요 |
| R-3 | **PG사 서비스로 갈음 가능한가** (가장 빠른 길) | 토스페이먼츠 서면 | 발송 여부 확인 필요 |

위 R-1\~R-3의 발송·회신 상태는 9/15 이후 기록을 확인할 수 없습니다.
