# 쇼츠여긴어때 분석 · 소개뱅크 콘텐츠 자동화 체계 v1.0

Sep 27, 2026 · @박세호

## 0. 한 장 요약

**결론:** 쇼츠여긴어때의 핵심은 "콘텐츠 제작 대행"이 아니라 **"등록 한 번 → 회원 이름으로 매일 자동 발행 → 정액 과금"** 체계입니다. 소개뱅크에는 이 체계를 **매물·요청 등록과 연결된 유료회원 혜택**으로 옮기는 것이 가장 맞습니다. 외주 계약이 아니라 자체 자동화 서버(n8n) 위에 구축하는 것을 추천합니다.

**핵심 발견 5가지**

1. **입력은 하나뿐입니다.** 개인형은 "주제 한 줄", 중고차형은 "매물 등록(사진·차종·연식·가격)" 하나로 쇼츠·블로그·카드뉴스가 한 세트로 나옵니다.
2. **회원마다 전용 홈페이지를 자동으로 엽니다.** `{회원이름}.onoffclass.com` 서브도메인 구조이고, 신청 즉시 생성됩니다.
3. **과금은 정액 두 단계입니다.** 개인형 월 50만원, 플랫폼 운영형 월 300만원(회원 수 무관). 여기에 모집자에게 회원 이용료의 10%를 매달 주는 수당 기능이 있습니다.
4. **"무료로 뿌리는" 변형이 있습니다.** 세무사형은 거래처 30곳에 홈페이지·콘텐츠·주간 정책자금 브리핑을 무료로 주고, 기장 이탈 방지와 신규 유치에 씁니다.
5. **규제 대응이 영업 문구 자체입니다.** 업종별 금지 표현, 검색 순위 미보장, "정보 매칭까지만(알선·중개 안 함)"을 먼저 밝힙니다.

**추천 적용안 (우선순위 순)**

1. 소개뱅크 자체 홍보 채널 자동화 — 파이프라인을 먼저 검증
2. 매물·요청 등록 → 자동 콘텐츠 생성을 유료회원 등급 혜택으로 제공
3. 소개창업·기업회원용 "주간 정책자금 브리핑" — 세무사형의 이탈 방지 장치를 차용

**가져오지 않을 것:** 모집 수당 10%(다단계 오해 소지), "회원 수만큼 수익" 문구, 구글 블로거 중심 발행.

## 1. 실측 — 운영 주체와 기술 구조

한 개의 공통 시스템에 업종별 사이트 52곳을 서브도메인으로 붙인 **멀티사이트(여러 사이트를 한 시스템으로 운영) 구조**입니다.

| 항목 | 실측 내용 | 비고 |
| --- | --- | --- |
| 서비스명 | 쇼츠여긴어때 (업종별 쇼츠·블로그 자동화) | [메인](https://nlaw4.onoffclass.com/) |
| 운영 규모 | 사이트 52곳 · 쇼츠 425편 · 블로그 312편 | 메인 페이지 게시 수치, 검증 불가 |
| 도메인 구조 | `onoffclass.com`의 서브도메인 (예: `nlaw4`, `ncar1`, `tax3`) | 회원 사이트도 `{내이름}.onoffclass.com` |
| 페이지 구조 | `?pn=spage&code=숫자` 형식의 공통 템플릿 | 한 코드로 모든 사이트를 그리는 방식으로 보임(추정) |
| 자동 발행 채널 | 유튜브, 구글 블로거 | 제공 중 |
| 준비 중 채널 | 인스타그램, 스레드, 페이스북 | Meta 앱 심사 승인 후 제공 예정이라고 명시 ([중고차 포탈](https://ncar1.onoffclass.com/?pn=spage&code=40)) |
| 화면 제작 | 촬영 없이 생성형 AI 이미지 + 이미지를 영상으로 바꾸는 기술 | 한의원 사례 설명 |

| 관리자 | 주제 한 줄 입력 → 당일 콘텐츠 생성, 대표는 확인만 | 메인 페이지 시연 영상 |

**소개뱅크 관점 메모:** 사례 목록에 "세바썬에너지"(쇼츠 2편)가 있습니다. SEBA SUN과 같은 회사인지 확인이 필요합니다.

## 2. 실측 — 정보구조(메뉴 체계)

메뉴는 **"누가 쓰나(상품) → 어느 업종인가 → 무엇이 나오나(결과물) → 신청"** 네 묶음으로 짜여 있습니다. 방문자가 자기 자리를 먼저 고르게 하는 구조입니다.

| 묶음 | 메뉴 | 코드 | 역할 |
| --- | --- | --- | --- |
| 상품 | 개인 사이트 운영 | 30 | 내 사업장 콘텐츠 (월 50만원) |
| 상품 | 플랫폼 운영 | 40 | 회원을 모아 되파는 자리 (월 300만원) |
| 업종별 플랫폼 | 변호사 · 세무사 · 병원 · 탐정 · 중고차 · 한의원 | 41\~46 | 업종별 맞춤 제안서 페이지 |
| 결과물 견본 | 웹툰 · 롱폼 · 쇼츠 · 블로그 | 60\~63 | 실제 발행물 모음 (쇼츠 36편 목록 등) |
| 전환 | 신청하기 | 20 | 업종·상호·담당자·연락처 입력 폼 |
| 운영 | 관리자 로그인 | login | 운영자·회원 관리 화면 |

**회원 사이트 메뉴** ([검품중고차](https://ncar1.onoffclass.com/?pn=spage&code=40) 실측): 포탈 · 딜러 목록 · 플랫폼 소개 · 계산기 · 쇼츠 · 블로그 · 카드뉴스 · 신청 · 로그인/회원가입. 콘텐츠 3종이 메뉴에 그대로 쌓이고, 업종 도구(중고차 계산기)가 하나 붙습니다.

**지역 페이지:** "119탐정센터 광주지사 · 부산지사 · 울산지사 · 대구지사"처럼 같은 틀에 지역명만 바꾼 페이지를 반복 생성합니다. 중고차형 제안서에도 지역 페이지를 무제한 만든다고 적혀 있습니다.

## 3. 실측 — 상품·가격 체계

상품은 **"콘텐츠를 사는 자리(개인형)"와 "파는 자리(플랫폼형)"** 두 층이고, 둘 다 정액·선불·셋업비 없음·약정 없음입니다.

| 상품 | 월 요금 | 대상 | 제공량 | 과금 방식 |
| --- | --- | --- | --- | --- |
| 개인 사이트 운영 | 50만원 | 개별 사업장 | 쇼츠 30 · 블로그 30 · 카드뉴스 · 홈페이지 1 | 정액 선불 |
| 플랫폼 운영 | 300만원 (신청 페이지에는 200\~300만원) | 회원을 모을 운영자 | 회원당 개인형과 같은 양 | 회원 수 무관 정액 |
| 세무사형 | 300만원 | 세무사 사무소 | 거래처 30곳까지 홈페이지·콘텐츠·주간 정책자금 브리핑 | 거래처 1곳당 약 66,000원 꼴, 거래처는 0원 |
| 중고차 딜러형 | 50만원 | 회원 딜러 | 매물 기반 매일 1세트 | 운영자가 정한 회원 요금 (권장가) |

**플랫폼형의 돈 흐름** ([중고차 플랫폼 제안](https://nlaw4.onoffclass.com/?pn=spage&code=45))

1. 운영자 → 제작사: 월 300만원 정액
2. 회원 → 운영자: 운영자가 정한 금액 (권장가 월 50만원)
3. 모집자 → 회원 이용료의 10%를 매달 지급하는 수당 기능을 시스템으로 지원
4. 손익분기: 회원 6명. 이후 늘어나는 회원분은 운영자 몫으로 안내

**가격 설계의 특징:** 제작 원가가 회원 수에 비례해 늘어도 운영자에게는 정액이므로, 제작사는 AI 자동화로 회원당 원가를 낮게 유지한다는 전제입니다. 페이지마다 가격 표기가 다른 점(300만원 vs 200\~300만원)은 확인이 필요합니다.

## 4. 실측 — 제작·발행 체계

입력 하나에서 결과물 3\~4종을 뽑고, 언어만 바꿔 곱하는 **"1 입력 → N 결과물 × M 언어"** 구조입니다.

| 입력 유형 | 사용하는 곳 | 나오는 결과물 |
| --- | --- | --- |
| 주제 한 줄 | 개인형 (병원·세무·변호사 등) | 쇼츠 1 + 블로그 1 (매일) |
| 매물 정보 (주소·사진·차종·연식·가격) | 중고차 딜러형 | 쇼츠 + 블로그 + 카드뉴스 1세트 |
| 거래처 정보 (업종·지역·업력·매출·고용 인원) | 세무사형 정책자금 브리핑 | 매주 월요일 자동 매칭 리포트 |
| 롱폼 1편 | 화장품 | 쇼츠·블로그·웹툰으로 재가공 |

**결과물 규격**

1. **쇼츠:** 세로 영상. 대본·성우·자막·편집 포함. 매물형은 상호·전화번호를 영상에 넣습니다.
2. **블로그:** 글마다 이미지 포함, 구글 블로거 자동 발행.
3. **카드뉴스:** 블로그 한 편을 7장 카드로 재구성. 인스타그램 캐러셀(여러 장 넘기는 게시물)용.
4. **롱폼:** 5\~7분, 원장 목소리 복제 (한의원형).
5. **다국어:** 같은 영상에 언어별 음성·자막·명패만 교체. 추가 제작비 없음.

**정책자금 브리핑의 작동 방식** ([세무사형](https://nlaw4.onoffclass.com/?pn=spage&code=42))

1. 거래처 등록 (업종·지역·업력·매출·고용 인원)
2. 월요일 아침 자동 매칭 → 지원 가능 사업 리포트 생성
3. 사무소 이름으로 링크 발송, 업체는 로그인 없이 열람
4. 지난주 대비 새 사업에 NEW 표시
5. 별도 "1분 진단" 페이지: 7개 항목 입력 → 지원 가능 사업 수·목록 즉시 표시

**콘텐츠 인물 장치:** "AI 세무사 김세라"처럼 가상 진행자를 내세운 쇼츠가 있습니다.

## 5. 실측 — 영업·온보딩 체계

영업의 핵심은 **첫 편을 먼저 만들어 보여 주기**입니다. 고객이 준비할 자료를 0으로 만들고, 실물로 설득합니다.

**개인형 온보딩** ([신청 페이지](https://nlaw4.onoffclass.com/?pn=spage&code=20))

| 시점 | 할 일 |
| --- | --- |
| 1일차 | 15분 통화로 업종과 하는 일 확인 (자료 준비 불필요) |
| 3일차 | 홈페이지와 첫 쇼츠·블로그 제작해 보여줌 |
| 7일차 | 유튜브·구글 블로거 연결, 자동 발행 시작 |
| 이후 | 매일 발행, 고객은 확인만 |

**플랫폼형 온보딩** (중고차·세무사 제안서)

| 시점 | 할 일 |
| --- | --- |
| 1주차 | 운영자 이름·로고·색상·도메인으로 전체 교체 (화이트라벨: 남의 제품에 내 상표를 붙여 파는 방식) |
| 2주차 | 시연용 회원 3곳(세무사형은 거래처 5곳) 먼저 개설 — 영업용 실물 |
| 3주차\~ | 영업 시작, 신청 즉시 회원 홈페이지 자동 생성, 다음 날부터 발행 |
| 상시 | 회원 수·발행량·수당을 관리자 화면에서 월 단위 확인 |

**신청 폼 항목:** 업종(8종 선택) · 상호 · 담당자 · 연락처 (필수) / 지역 · 이메일 · 필요 사항 (선택) / 개인정보 수집 동의.

**설득 문구의 구조:** 고민 4개(시간 없음, 채용 부담, 방치된 홈페이지, 외국인 고객 놓침) → 실제 사례 52곳 링크 → 손익분기표 → "미리 밝혀둘 것"(한계 고지) 순서입니다.

## 6. 실측 — 규제·고지 체계

업종별로 **"만들지 않는 문구"를 먼저 정해 두고**, 그 한계를 영업 문구에서 스스로 밝히는 방식입니다. 소개뱅크의 광고 심의 금칙어 방식과 같은 원리입니다.

| 업종 | 쓰지 않는 표현 | 대신 하는 것 |
| --- | --- | --- |
| 변호사 | 승소율, 성공 보장, 구체 수임료 | 상황별 법률 정보 |
| 병원 | 효과 단정, 최상급 표현 | 시술 원리 설명 |
| 화장품 | 효능 단정, 질병 치료 표현, 비포애프터 | 바르는 방법 중심 |
| 금융·투자 | 종목 추천, 수익 보장 | 기초 설명 + 모든 콘텐츠에 투자 유의 고지 |
| 탐정 | 미행·추적 광고, 조사 장면 | 상담·자료 정리·법률 전문가 연계까지만 (신용정보법 제40조 근거로 설명) |
| 세무사 | 환급률·절세액 보장 | 제도·기한 안내 |
| 정책자금 | 금리·한도 단정 표시 | 공고 확인 안내 병기, 알선·중개 안 함 (정보 매칭까지) |

**공통 고지 3가지**

1. **검색 순위를 보장하지 않습니다.** 매일 콘텐츠를 쌓는 것이 일이고 순위는 결과라고 밝힙니다.
2. **영업은 대신하지 않습니다.** 회원 모집은 운영자 몫이라고 명시하고, 인맥·거래처 없이 시작하는 것은 권하지 않는다고 적습니다.
3. **선불, 셋업비·약정 없음, 중단 시 다음 달부터 청구 중지.**

**채널 현황도 사실대로 적습니다.** 인스타그램·스레드·페이스북은 Meta 앱 심사 전이라 준비 중이고, 그전까지는 완성본을 받아 직접 올리라고 안내합니다.

**주의할 점:** 탐정 항목의 법 조항 해석은 이 사이트의 설명입니다. 소개뱅크가 인용하려면 별도 법무 확인이 필요합니다.

위 줄은 모든 상품에 공통인 제작 흐름이고, 아래 줄은 플랫폼형에서만 생기는 돈 흐름입니다. 소개뱅크가 옮길 것은 위 줄 전체와 아래 줄의 "회원 → 운영자" 부분이며, 점선의 모집 수당은 옮기지 않습니다.

## 8. 소개뱅크에 가져올 것 · 버릴 것

가져올 것은 **등록이 곧 홍보가 되는 구조**이고, 버릴 것은 **사람을 모으면 돈이 되는 구조**입니다. 후자는 소개뱅크의 단일 단계 원칙·금지 문구와 충돌합니다.

### 8-1. 가져올 것 (채택 권고)

| # | 요소 | 소개뱅크에서의 모습 | 근거 |
| --- | --- | --- | --- |
| 1 | 매물 등록 → 콘텐츠 자동 세트 | 소개장터·안심소개 등록(팝니다/삽니다) 시 쇼츠·카드뉴스·블로그 자동 생성 | 중고차형과 같은 입력 구조. 등록 자체가 홍보가 됨 |
| 2 | 회원 전용 페이지 자동 개설 | 기업회원별 "업체 소개 페이지" (매물·콘텐츠가 자동으로 쌓임) | 유료회원 등급의 눈에 보이는 혜택 |
| 3 | 주간 정책자금 브리핑 | 소개창업·기업회원에게 매주 지원사업 매칭 리포트 | 매주 받을 이유 = 이탈 방지. 소개창업의 창업 지원 축과 일치 |
| 4 | 업종별 금지어 + 한계 고지 | 광고 심의 금칙어 테이블을 콘텐츠 생성에도 공용 | 이미 구축한 심의 방식 재사용 |
| 5 | 첫 편 선제작 영업 | 입점 제안 시 그 업체 매물로 쇼츠 1편을 먼저 만들어 보여줌 | 준비 자료 0, 실물 설득 |
| 6 | 지역 페이지 반복 생성 | 안심소개 태양광·부동산의 지역별 안내 페이지 | 검색 유입용, 같은 틀에 지역만 교체 |
| 7 | 채널 현황 사실 고지 | 인스타그램 자동 게시는 Meta 심사 전까지 "준비 중" 표기 | 과장 없는 고지가 신뢰 요소 |

### 8-2. 버릴 것 (채택하지 않음)

| # | 요소 | 버리는 이유 |
| --- | --- | --- |
| 1 | 모집 수당 (회원 이용료 10% 매월) | 가입시킨 사람에게 계속 수당이 가는 구조는 다단계 오해 소지. 소개뱅크는 거래 성사 기준 단일 단계 소개비만 유지 |
| 2 | "회원을 모으면 그 수만큼 수익" 문구 | 금지 문구("수익 보장", "누구나 월 ○○만원")와 같은 성격 |
| 3 | 화이트라벨 재판매 | 소개뱅크는 자체 브랜드 플랫폼. 남에게 브랜드를 빌려주는 사업은 범위 밖 |
| 4 | 구글 블로거 단독 발행 | 국내 B2B 검색 환경을 고려하면 네이버 대응을 따로 검토해야 함 (자동 게시 가능 여부는 추가 확인 필요) |
| 5 | 목소리 복제·가상 진행자를 기본 기능으로 | 동의·표시 부담이 큼. 필요한 회원만 선택 기능으로 |

## 9. 소개뱅크 적용 체계

소개뱅크판 체계는 **매물·요청 등록 → 자동 콘텐츠 → 승인 → 발행 → 매물 링크로 유입** 순서이며, 관마다 규칙 강도만 다르게 둡니다.

### 9-1. 관별 적용

| 관 | 입력 | 자동 결과물 | 규칙 강도 |
| --- | --- | --- | --- |
| 소개장터 | 팝니다·삽니다 등록 | 쇼츠 + 카드뉴스 (삽니다는 "구합니다" 카드) | 기본 금지어 |
| 안심소개 (부동산·태양광 등) | 인증 회원의 매물 등록 | 쇼츠 + 블로그 + 지역 페이지 | 인증(VERIFIED) 회원만 생성, 등록번호·사무소명·대표자 자동 표기 |
| 소개창업 | 창업계획·기업 정보 | 주간 정책자금·지원사업 브리핑 | 정보 매칭까지만, 투자·자금 알선 문구 금지 |
| 소개뱅크몰 (건강관) | 상품 등록 | 카드뉴스 + 블로그 | 건강식품 효능 표현 금지어, 기존 심의 승인본 대조 |
| 소개리드 (의료·보험 등 8종) | 파트너 소개 정보 | 자동 생성 제외 또는 관리자 검수 필수 | GATED — 사람 승인 없이는 발행 불가 |

### 9-2. 과금 위치

1. **무료회원:** 매물 등록만 가능, 자동 콘텐츠 없음 (또는 월 1세트 체험).
2. **유료회원:** 등급별 월 N세트 + 업체 소개 페이지 + (소개창업) 주간 브리핑.
3. **등급별 편수와 요금:** 30편 시범 운영으로 편당 원가를 실측한 뒤 정합니다. 지금 숫자를 정하면 근거가 없습니다.

### 9-3. 데이터 구조 (초안)

```sql
-- 금지어·필수고지: 광고 심의 금칙어와 같은 테이블로 합치는 것을 권고
CREATE TABLE content_rule (
  id         BIGSERIAL PRIMARY KEY,
  gwan       VARCHAR(20) NOT NULL,  -- MARKET, SAFE, STARTUP, MALL, LEAD
  category   VARCHAR(30),           -- HEALTHFOOD, REALESTATE, SOLAR ...
  rule_type  VARCHAR(10) NOT NULL CHECK (rule_type IN ('BLOCK','NOTICE')),
  phrase     TEXT NOT NULL,
  active     BOOLEAN NOT NULL DEFAULT TRUE
);

-- 콘텐츠 작업: 원 매물(listing)과 반드시 연결
CREATE TABLE content_job (
  id           BIGSERIAL PRIMARY KEY,
  business_id  BIGINT NOT NULL,          -- 기업회원
  listing_id   BIGINT,                   -- 원 매물·요청 (브리핑은 NULL)
  gwan         VARCHAR(20) NOT NULL,
  kind         VARCHAR(15) NOT NULL,     -- SHORTS, BLOG, CARDNEWS, BRIEFING
  script       TEXT,
  status       VARCHAR(15) NOT NULL DEFAULT 'DRAFT',
               -- DRAFT → CHECKED → APPROVED → PUBLISHED / REJECTED / WITHDRAWN
  approved_by  VARCHAR(50),
  target_url   TEXT,                     -- 매물 링크 + 추적 코드
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  CHECK (status NOT IN ('APPROVED','PUBLISHED') OR approved_by IS NOT NULL)
);

-- 회원 업체 페이지
CREATE TABLE member_page (
  business_id  BIGINT PRIMARY KEY,
  slug         VARCHAR(40) UNIQUE NOT NULL,  -- sogaebaenk.co.kr/p/{slug}
  published    BOOLEAN NOT NULL DEFAULT FALSE
);
```

**서브도메인 대신 경로 방식(`/p/{slug}`)을 권고합니다.** 회원 페이지가 모두 소개뱅크 도메인 아래에 쌓여 검색 신뢰가 본 사이트로 모이고, 인증서·도메인 관리가 단순해집니다.

### 9-4. 불변식 (DB가 집행할 규칙, 제안)

| 코드 | 규칙 | 집행 위치 |
| --- | --- | --- |
| INV-CT1 | 사람 승인(`approved_by`) 없이 APPROVED·PUBLISHED가 될 수 없다 | CHECK |
| INV-CT2 | BLOCK 금지어가 하나라도 있으면 CHECKED로 넘어갈 수 없다 | 상태 전이 트리거 |
| INV-CT3 | 소개리드 GATED 업종은 관리자 검수 기록 없이 발행할 수 없다 | 발행 트리거 |
| INV-CT4 | 안심소개 부동산 콘텐츠는 인증(VERIFIED) 사업자만 생성할 수 있다 | INSERT 트리거 (INV-BR1과 같은 원리) |
| INV-CT5 | 원 매물이 비노출·삭제되면 연결된 콘텐츠의 링크를 WITHDRAWN으로 돌린다 | 상태 변경 트리거 |

INV-CT5가 중요한 이유: 유튜브에 올라간 영상은 매물이 거래 완료된 뒤에도 남습니다. 링크 끝이 "거래 완료" 안내로 바뀌어야 허위 매물 표시 문제가 생기지 않습니다.

## 10. 단계별 실행 절차와 비용·자원

순서는 **자체 채널로 검증 → 회원 혜택으로 확장 → 브리핑 추가**입니다. 앞 단계의 실측 원가가 다음 단계의 요금 근거가 됩니다.

| 단계 | 할 일 | 끝났다는 기준 | 기간(추정) |
| --- | --- | --- | --- |
| 1 | 관별 주제표 30개 + 금지어 사전 초안 | 주제 30개, 5개 관 금지어 등록 | 1주 |
| 2 | n8n 흐름: 대본 → 금지어 검사 → 이미지 → 영상 → 음성·자막 | 사람 개입 없이 쇼츠 1편 생성 | 1\~2주 |
| 3 | Telegram 승인 단계 + 유튜브 쇼츠 자동 게시 | 승인 버튼 한 번에 게시 | 1주 |
| 4 | 소개뱅크 자체 채널 30편 시범 | 편당 원가·클릭·매물 유입 실측표 | 4주 |
| 5 | 매물 등록 → 자동 콘텐츠 연결 (`content_job`, 불변식 INV-CT1\~5) | 등록 1건에 세트 1개 자동 생성 | 2\~3주 |
| 6 | 업체 소개 페이지 (`/p/{slug}`) + 유료 등급 혜택 설계 | 시연 회원 3곳 운영 | 2주 |
| 7 | 소개창업 주간 브리핑 (지원사업 DB + 매주 매칭) | 5곳에 4주 연속 발송 | 3\~4주 |

**필요한 자원**

1. **서버:** 이미 결정한 자동화 서버(EC2, Docker)를 사용합니다. 영상 합성 부하가 커지면 사양 상향이 필요할 수 있습니다.
2. **AI 사용료:** 대본·이미지·영상 변환·음성 합성 4종. 영상 변환이 가장 비쌉니다. 공급사별 단가는 자주 바뀌므로 추가 확인이 필요하고, 4단계 실측값을 기준으로 삼습니다.
3. **사람:** 대표 승인 하루 5\~10분(추정), 1단계 초안 작성, 5단계 이후 개발 인력.
4. **비교 기준:** 쇼츠여긴어때 개인형 월 50만원(쇼츠 30 + 블로그 30)이 회원 1곳당 자체 원가의 상한선입니다. 이보다 비싸면 자체 구축의 의미가 줄어듭니다.
5. **정책자금 DB:** 지원사업 공고를 모아 정리하는 작업이 매주 필요합니다. 쇼츠여긴어때는 12개 사업을 관리한다고 밝힙니다. 수집 방법(공공데이터 등)은 추가 확인이 필요합니다.

## 11. 위험과 대응 · 현장 체크리스트

가장 큰 위험은 **회원 이름으로 나가는 자동 콘텐츠의 책임 소재**입니다. 사람 승인을 DB 규칙으로 강제하는 것이 기본 대응입니다.

| 위험 | 대응 |
| --- | --- |
| 의료·보험·건강식품 광고 규정 위반 | 소개리드는 자동 생성 제외 또는 검수 필수(INV-CT3), 건강관은 효능 금지어 + 심의 승인본 대조 |
| 부동산 표시·광고 규정 | 인증 회원만 생성(INV-CT4), 필수 표기 자동 삽입. 콘텐츠가 "표시·광고"에 해당하는지는 중개사인증 설계서 Q1 법무 회신에 포함 |
| 거래 완료 후에도 영상이 남음 | 링크 끝을 "거래 완료" 안내로 전환(INV-CT5), 설명란에 등록일 표기 |
| 유튜브가 반복 생성 콘텐츠를 불리하게 다룰 가능성 | 주제·화면 구성에 변화, 발행량은 품질을 보며 증가. 최신 정책 확인 필요 |
| AI 생성물 표시 의무 | 영상·설명란에 "AI 생성" 표시 기본 적용. 적용 범위는 법무 확인 필요 |
| 회원 계정 연동(유튜브 인증) 관리 | 1단계는 소개뱅크 채널 하나로 시작, 회원 채널 연동은 6단계 이후 |
| 인스타그램 자동 게시 | Meta 앱 심사가 선행. 쇼츠여긴어때도 아직 준비 중으로 표기 |
| 정책자금 정보 오류 | 금리·한도는 단정하지 않고 공고 확인 안내 병기, 알선·중개 문구 금지 |
| 모집 수당 요청이 들어올 때 | 채택하지 않음(8-2). 소개비는 거래 성사 기준 단일 단계만 |

**현장 체크리스트**

- [ ] 세바썬에너지가 이 서비스를 쓰는지, 쓴다면 조회수·문의 수·실제 비용
- [ ] 쇼츠여긴어때 플랫폼형 가격 300만원 vs 200\~300만원 중 실제 견적
- [ ] 관별 주제 30개 확보
- [ ] 금지어 사전에 5개 관 모두 등록
- [ ] 유튜브 API 인증 발급 (소개뱅크 채널)
- [ ] Telegram 승인 흐름 동작
- [ ] 게시물 링크 추적 코드 동작
- [ ] AI 생성 표시 문구 확정
- [ ] 거래 완료 매물의 링크 전환 동작
