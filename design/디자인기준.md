# 소개뱅크 디자인 기준 (v10.68)

> 이 문서는 `sgb-infra/qa/gen_design_doc.py` 가 기준 파일(`sgb-core/site/src/styles/sgb-tokens.css` · `sgb-buttons.css`)에서 만듭니다. **손으로 고치지 마십시오** — 값을 바꾸려면 기준 파일을 고치고 스크립트를 다시 돌립니다.
> 결정 기록: `decisions/design-standard.md`(#1 ~ #15) · 원본 시트: `design/SGB_DesignGuide_v1.html`(2026-10-09 「소개뱅크 전체 페이지 공통 디자인 가이드」)

## 0. 원칙

1. **디자인 값(색 · 글자 · 모서리 · 그림자 · 화면 폭 · 단추)은 디자인 시트가 기준**입니다. 화면 구성 · 기능 · 문구는 시안이 기준입니다(project-rules 2절).
2. 새 CSS · 화면 코드는 **숫자를 직접 쓰지 않고 아래 이름(`var(--sgb-…)`)** 을 씁니다. 옛 이름(시안 토큰 `--ink` · `--accent` …)은 이 값을 가리키는 별칭으로만 남아 있습니다.
3. **글자와 바탕의 대비는 4.5 이상**(웹 접근성 기준). 흰 바탕 · 화면 바탕 · 관 연한 바탕 모두에서 봅니다.
4. 그림 부품(상품 · 분야 그림 · 날씨 아이콘) · 로고 · 지도 · 아이콘 선 · 막대는 이 기준 밖입니다(#14 ③).
5. 실제 웹과 시안(`spec/proto.html`)은 **같은 고침 스크립트**로 함께 고칩니다. 시안 안 시트 사본은 `sgb-tokens.css` 와 글자 그대로 같아야 합니다.
6. **운영 화면(`web/`)도 같은 기준**입니다(v10.67 · v10.68). `web/src/styles/sgb-tokens.css` · `sgb-buttons.css` 는 사용자 웹 파일의 **글자 그대로 사본** — 값을 바꿀 때는 두 곳 모두(test_v1067 · v1068 이 확인). 옛 이름(`--accent` · `--ink` · `.btn-ok` …)은 시트 값을 가리키는 별칭입니다.

## 5. 단추 3종

모양은 하나 — 높이 40px · 모서리 `var(--sgb-r-sm)` · 14px 굵게, 작은 단추 32px · 13px. **색만 관을 따릅니다**(#13 · `sgb-buttons.css`).

| 종류 | 이름(새 화면) | 바탕 | 글자 | 테두리 |
|---|---|---|---|---|
| 주요 | `sgb-btn sgb-btn--pri` | `var(--sgb-point)` | `var(--sgb-on-point)` | 바탕과 같음 |
| 보조 | `sgb-btn sgb-btn--sec` | `#ffffff` | `var(--sgb-navy)` | `var(--sgb-line)` |
| 줄 | `sgb-btn sgb-btn--line` | `#ffffff` | `var(--sgb-point-text)` | 글자와 같음 |

작게: `sgb-btn--sm` 을 더함. 옛 꾸밈 이름(.pri · .ghost · .p2primary · .sm · .lg)과 상태(.on · .off · .danger · :disabled)는 구분해서 고칩니다. 칩 · 탭 · 검색 단추는 알약, 메인 동그란 검색 단추 · 소개장터 검색칸은 그대로입니다.
