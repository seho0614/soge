## 5. 주의 (10/22 메모 5절에 더함)

- **다국어 화면 글자**: 새 화면 글자는 코드에 직접 쓰지 말고 사전(`site/src/i18n/messages/ko/<묶음>.json` · `en/…`)에. 화면 전용 묶음을 쓰는 브라우저 부품은 그 부품을 그리는 서버 화면이 `<Msgs ns={[…]}>` 로 감싸야 함 — **안쪽 `<Msgs>` 는 바깥 사전을 덮음**(합치지 않음 · 안의 부품이 쓰는 묶음을 모두 적을 것). 레이아웃 감싸기: `/my` `['my','myDeal','order']` · `/partner` `['partner','partnerOps','affiliate']` · `/partners` `['affiliate','partner']`
- **금액 · 시각 표기**는 `useFmt()`(브라우저 · async 아닌 서버 부품) · `await getFmt()`(async 서버 부품) — 한국어는 옛 글자 그대로 나오게(옛 식을 `f.ko ?` 갈래로)
- **한국어가 그대로인지 보는 법**: 바꾸기 전 main 판 점검판에서 기능 점검(`func_check.sh`)을 돌려 화면 목록(`site_crawl.json`)을 얻고, 그 목록 전체를 바꾸기 전 · 뒤로 떠서 글자 비교(숫자 · 시험 자료 꼬리는 지움) — 스크립트 사본은 이 세션 scratchpad 의 `snapall.py` · `cmpj.py`(다음 세션에서 필요하면 다시 만들 것)
- **영어 켜고 시험**: `i18n.enabled` on + `i18n_langs.en` on → `docker restart sgb-site` — **사용자 웹은 다시 켤 때 운영 방식으로 다시 빌드(몇 분)** · 시험을 이어 돌릴 때는 `/login` 이 200 이 될 때까지 기다린 뒤 다음 시험
- **사용자 웹 캐시**: `apiGet` 은 로그인 토큰 · `X-Lang` 을 붙여 캐시가 사람 · 언어마다 따로 생김(언어끼리 안 섞임) · 누구에게나 같은 공개 응답은 `apiGetPublic`(v10.103) · 승인한 번역은 손님 화면에 최대 몇 분(분류 목록 5분) 뒤
- **404 화면**은 빌드 때 미리 그려 둔 판이라 언어 쿠키를 보지 않음(전에도 같음 · docs/159 §3-1)
- 서버 쪽 번역 얹기는 `I18nService.overlay`(승인 · 자동 승인만 · 기계 번역은 게시판만 · 낡은 줄 제외) — 저장 · 결제 · 비교에 쓰는 값에는 얹지 말 것
- 점검판 DB 는 판을 바꿔도 이어짐 — v10.103 의 D117 은 main 에 병합되었으므로 다음 갈래는 155 위에서

- **AI 엔진 시험**: 점검판 API 를 `AGENT_PROVIDER=MOCK docker compose -f docker-compose.yml -f docker-compose.site-prod.yml up -d api` 로 띄우면 시험 엔진(밖으로 안 나감 · 「[MOCK en] …」). `docker-compose.yml`(sgb-infra) api 에 `AGENT_PROVIDER` · `ANTHROPIC_API_KEY` 칸이 비어 있음 — **키를 점검판 · 저장소에 넣지 말 것**
- **이미 적용된 마이그레이션 파일을 고치면 점검판이 시작을 멈춤**(변경감지) — 병합 전 갈래에서 고쳤다면 점검판 DB 를 `docker compose down -v` 로 처음부터(10/25 D119 때 그렇게 함 · 그 뒤 `func_check.sh` 로 시험 자료를 다시 채움 · 소개광장 흐름은 시험 글을 지우고 끝나므로 test_v1101 · 1105 는 글을 스스로 만듦)
