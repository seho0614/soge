## 원칙

1. 로그인은 **소개뱅크 운영자 계정** — ERP 는 비밀 키를 갖지 않고, 소개뱅크 `introspect` 에 토큰을 물어 확인합니다(1분 캐시). 화면은 짧은 교환 코드로 넘겨받습니다.
2. 권한(업무별 task)은 **소개뱅크 한 곳**에서 줍니다.
3. 데이터베이스는 같은 RDS 안 `sgb_erp` · 소개뱅크 자료는 읽기 전용(`svc` 스키마)으로만 읽습니다.
4. 소개뱅크에 쓰는 길은 내부 API(운영 알림 · 회원 알림) 하나뿐입니다.
5. 판 번호는 `e1.0` 부터 따로 셉니다. 운영 반영은 소개뱅크와 함께 한 번에(절차서 하나).
