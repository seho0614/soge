## 요약

1. **소개뱅크 도메인은 sogaebank.com 하나**입니다(10/12 확인 · 10/15 대표 재확인). 문서 · 킷의 `sogaebaenk.co.kr` 은 등록조차 되어 있지 않은 주소입니다.
2. 10/12 에 가비아 A 레코드 **@ · www · admin → 3.37.95.217** 이 반영됐고, 세 주소에 **HTTPS 인증서**가 발급됐습니다(만료 2027-01-10 · 자동 갱신).
3. 네임서버는 **가비아 그대로** — Route 53 이전은 필요할 때(와일드카드 인증서 등) 합니다.
4. 기존 파트너센터 서버는 도메인 연결을 끊었고 **IP 주소로만** 열립니다.
5. ⚠ 운영 규칙 — **`nginx-render.sh` 를 다시 실행하지 않습니다**(인증서 줄이 지워져 https 가 끊김).
