# 소개뱅크 결정 정리 — 다국어

- 기준일: 2026-10-15 (재조사판)
- 범위: 대상 국가 · 언어 · 번역 방식 · 적용 범위 · 다국어 kit · 언어 선택 단추
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 대상은 **11개국 → 언어 7개**(영어 · 일본어 · 독일어 · 프랑스어 · 인도네시아어 · 베트남어 · 아랍어) · **1차는 영어**.
2. 적용 범위는 화면 글 + **게시물 · 등록 문서**까지.
3. 번역 엔진은 **갈아 끼우는 구조**(운영은 n8n 번역 · 준비 전 수동) · **승인된 번역만 화면에** · 언어는 **쿠키로 판별**(주소 그대로).
4. 다국어 1단계 kit(v10.17 · 스위치 꺼짐)을 만들었으나 **본선(v10.41)에는 없는 것으로 보입니다** — 다시 얹을지 정해야 합니다.
5. 다국어 적용 전까지 **실제 웹의 언어 선택 단추는 숨김**.
