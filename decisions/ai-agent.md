# 소개뱅크 결정 정리 — AI 에이전트

- 기준일: 2026-10-24 (10/15 재조사판 + v10.92 기준 설계 · docs/149)
- 범위: AI 에이전트(고객응대 · 검수 보조 · 감사 · 정산 보조) 적용 범위 · 단계 · 사람 확인 · n8n 연동 · 산출물
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. AI 에이전트를 적용하고(10/4) **고객응대용도 포함** — 고객응대는 **3단계**(안내 → 본인 정보 조회 → 신청서 초안)로 나눕니다.
2. 에이전트는 **n8n 과 연동** · 범위에 **다국어 + 검수 · 감사 · 정산 등 자동화 가능 부분** 포함.
3. **AI 는 승인 · 반려 · 확정 · 지급을 하지 않습니다** — 검수 보조는 병행(shadow) 모드로 시작, 사람 글 없는 감사 확인은 서버가 거부.
4. 산출물 — **통합 설계서 v1.0**(Claude Docs) · 킷 **v10.17-rc1 · rc2**(전부 꺼진 채) · n8n 연동 묶음 v1.0 ~ 1.2.
5. ~~⚠ v10.17-rc2 본선 반영~~ → **2026-10-24 쓰지 않고 v10.92 위에 새로**(docs/149).
6. **2026-10-24 「추천대로」** — 0단계 틀(꺼짐 · 월 상한 0) 개발 · 다음은 **검수 보조(병행)** · 호출은 **소개뱅크가 Claude 직접 호출**로 시작(n8n 은 나중에 갈아 끼움) · 검수 보조 모델 Sonnet 5.5 · 월 10달러부터 · 외부 전송 고지는 법무 검토 뒤 켬.
