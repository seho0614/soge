# 소개뱅크 결정 정리 — 약관 발행

- 기준일: 2026-10-15 (재조사판)
- 범위: 약관 9종(이용약관 · 개인정보처리방침 · 구독 환불 · 제3자 제공 · 위탁 · 마케팅 · 야간 광고 · 맞춤형 광고 · 판매 약관) + 파트너 이용약관 · 발행 · 재동의 · 시행일
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 약관 수정본은 **「검토 완료 — 진행해도 됨」**(10/9) — 글은 `scripts/terms-text.js` **한 벌**로 관리.
2. **시행일 2026-11-11**(9/23 부터 잡힌 값 · 10/9 재확인) · 발행 전 가입 계정은 **다음 로그인 때 동의**.
3. 개인정보 처리 **위탁은 「알림」**(동의 아님).
4. 파트너 이용약관(PARTNER 1.0)은 **발행하기로 결정**(10/10)했으나 운영 DB 에서는 **아직 초안**.
5. 운영 서버 약관은 **발행 2 · 초안 7**(v10.35 기준) — 실제 발행 명령 실행 기록은 없습니다.

```bash
npm run open:check                                    # 「미발행 약관」 줄 확인
EFFECTIVE_FROM=2026-11-11 npm run terms:publish       # 9종(위치기반 빼고)
EFFECTIVE_FROM=<시행일> bash scripts/publish-terms.sh PARTNER   # 파트너 이용약관
npm run open:check                                    # TERM 차단 0
```
