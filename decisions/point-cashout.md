# 소개뱅크 결정 정리 — 포인트 출금(현금 지급) · 원천징수 · 주민등록번호

- 기준일: 2026-11-09 (v10.219 · D190 · sgb-core docs/352 · 운영 절차서 docs/353)
- 범위: 회원 포인트를 현금으로 받는 것(출금 신청 · 확정 · 지급 · 반려) · 원천징수 · 신고 자료 · 주민등록번호 수집과 파기
- 상태: **유효** / **대체됨**

## 요약

1. **현금화 가능 포인트는 모두 출금 가능** · 최소 **10,000원** · 1포인트 = 1원 · 회사가 자기 돈(마케팅비)으로 보내는 것이라 소개비가 아님(INV-9 예외).
2. 원천징수율은 **SUPER 가 운영 화면에서 정함** · 처음 값 **3.3%**(소득세 3.0 + 지방소득세 0.3 · 10원 미만 버림).
3. 돈은 **신청(회원) → 확정(ADMIN) → 지급 기록(PAYOUT · 확정한 사람과 다른 사람)** 을 거쳐야만 나감.
4. 주민등록번호는 **스위치(꺼진 채)** — 처리방침에 수집 줄을 게시한 뒤에만 SUPER 가 켬 · 암호화 보관 · 가린 값만 보임 · **마지막 지급 다음 해 1월 1일부터 5년** 지나면 자동 파기.
