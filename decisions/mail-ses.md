# 소개뱅크 결정 정리 — 메일(Amazon SES)

- 기준일: 2026-10-15 (재조사판)
- 범위: 회사 메일함 · 서비스 자동 발송(인증 · 알림) 구축 방식 · 킷의 메일 발송 모듈
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 메일은 **두 용도 모두** — 회사 메일함(직원 송수신) + 서비스 자동 발송(인증 · 알림).
2. 방식은 **Amazon SES(발송) + 외부 메일함(수신)** — EC2 에 메일 서버를 직접 설치하지 않습니다. 계정 수 **6 ~ 20개**.
3. **메일 구축 절차서 v1.0**(10/7)이 있으나 **옛 도메인 · Route 53 전제**로 쓰여 있어 sogaebank.com · 가비아 DNS 기준으로 고쳐야 합니다.
4. 킷에는 메일 발송 모듈(SMTP · 설정이 없으면 보내지 않음)이 이미 있습니다. 발송 수단이 없어 상담 인증번호 · 비밀번호 찾기는 **운영에서 막혀 있거나 고객센터로 우회**합니다.

## 2. 미정 사항

| # | 무엇 | 지금 상태 | 정할 것 |
|---|---|---|---|
| 1 | **절차서 v1.0 고쳐 쓰기** | 발신 하위 도메인 `mail.sogaebaenk.co.kr` · 반송 `bounce.mail…` · DNS = Route 53 전제로 작성 · 실제는 **sogaebank.com · 가비아 DNS**(10/12 확인) | sogaebank.com · 가비아 기준 v1.1 |
| 2 | 외부 메일함 서비스 | 절차서 14절 기본값 = Google Workspace Business Starter(대안 네이버웍스 · 하이웍스) · 연간 약정 · **대표 확정 기록 없음** | 서비스 확정(요금은 최신 확인 필요) |
| 3 | 공용 주소 · 발신 주소 | 기본값 = `help@` · `admin@` · `dmarc@` 그룹 · 발신 `no-reply@mail.…` · 확정 기록 없음 | 주소 확정 |
| 4 | SES 발송 한도 해제(샌드박스 해제) 신청 | 기본값 = 예상 발송량 하루 300 ~ 2,000통 · 신청 기록 없음 | 신청 |
| 5 | **킷 연결 방식** | 킷은 SMTP(nodemailer) · 절차서 예시는 SES API(SDK) 코드 | SES SMTP 자격증명으로 붙일지 · API 로 바꿀지 |
| 6 | 도메인 인증 — SPF · DKIM · DMARC · MX | 미구축 · 가비아 DNS 에 등록 | 레코드 작성(빠뜨리면 메일 중단 · 스팸 분류) |
| 7 | 기존 메일 유무 | 법인 Google 계정 · 카페24 · 가비아 쓰던 메일이 있는지 확인 필요(절차서 14-2) | 확인 |
