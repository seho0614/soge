# 소개뱅크 결정 정리 — 메일(Amazon SES)

- 기준일: 2026-10-25 (10/15 재조사판 · v10.43 · v10.85 · **절차서 v1.2** 반영)
- 범위: 회사 메일함 · 서비스 자동 발송(인증 · 알림) 구축 방식 · 킷의 메일 발송 모듈
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 메일은 **두 용도 모두** — 회사 메일함(직원 송수신) + 서비스 자동 발송(인증 · 알림).
2. 방식은 **Amazon SES(발송) + 외부 메일함(수신)** — EC2 에 메일 서버를 직접 설치하지 않습니다. 계정 수 **6 ~ 20개**.
3. **메일 구축 절차서 v1.0**(10/7)이 있으나 **옛 도메인 · Route 53 전제**로 쓰여 있어 sogaebank.com · 가비아 DNS 기준으로 고쳐야 합니다.
4. ⚠ 정정(10/15): v10.41 · v10.42 코드에는 메일 발송 모듈이 **없었습니다**(#2 의 MailSender 는 본선에 없음). **v10.43 에서 새로 만듦** — SES SMTP · 새 패키지 없음 · 상담 인증번호를 메일로(sgb-core `docs/92`).
5. **구축 기준 문서 = 절차서 v1.2(sgb-core `docs/167` · 10/25)** — 스위치 `notify.email_verified` 하나로 인증번호 · 알림 메일이 함께 켜짐(v10.85) · 반송 · 신고는 SES 계정 수준 억제 목록 + CloudWatch 경보(코드 없음) · 코드 · 운영 적용은 필요 없음(운영 v10.90 에 포함).
