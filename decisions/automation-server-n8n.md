## 요약

1. **최종(10/15 18:39)** — 소개뱅크 서비스 서버는 **1대 · 도커 없음**, 자동화(n8n + OpenClaw)는 **AWS 의 별도 EC2 1대**, 도커는 **그 서버에서 n8n 용으로만**, OpenClaw 는 도커 없이 전용 계정.
2. 이유 — n8n 은 **3.0 부터 Docker 로만 배포** · OpenClaw 는 **Node 24.16+ / 26.1+**(Node 22 미지원) · OpenClaw 는 명령을 실행하는 에이전트라 운영 비밀값과 분리 · 자동화 장애가 서비스에 번지지 않게.
3. 용도 3종 — **운영 자동화 · 대표 개인 AI 비서 · 마케팅 · 콘텐츠 자동화**.
4. 사내 알림은 **카카오 알림톡**(심의 전에는 Telegram 알림 봇), 대표 비서 채널은 **Telegram**.
5. 원칙 — **판단은 소개뱅크 서버, 전달은 n8n** · OpenClaw 는 소개뱅크 자료를 **n8n webhook 으로만** 다룸 · 밖으로 나가는 일은 **사람 승인 뒤**.
