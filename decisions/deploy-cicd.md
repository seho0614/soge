# 소개뱅크 결정 정리 — 배포 · CI/CD · 저장소

- 기준일: 2026-10-15 (재조사판)
- 범위: 소스 저장소 · 자동 빌드 · 배포 · 버전 관리 · 리포지토리 · 권한 · 지금의 수동 적용 · 서버 구성 · 적용 이력
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 소스는 **AWS CodeCommit**, 자동 빌드 · 배포는 **CodePipeline + CodeBuild + CodeDeploy**(Jenkins 없음) · 버전은 **SemVer 태그** · 리포지토리 **4개** — 다만 **아직 도입 전**(저장소 커밋 0).
2. 지금 실제 배포는 **킷 zip 수동 적용** — PC 점검(realcheck) → 대표 승인 → precheck → RDS 스냅샷 → apply → postcheck.
3. **스테이징 서버는 두지 않습니다**(10/15).
4. 서버 구성(10/15) — 소개뱅크 **서비스 서버 1대 · 도커 없음** · 자동화(n8n · OpenClaw)만 별도 EC2(n8n 용 도커는 그 서버에만).
5. 적용 이력 — 9/30 첫 배포(마이그레이션 43) → **10/12 v10.35**(131) → **10/15 v10.41**.
