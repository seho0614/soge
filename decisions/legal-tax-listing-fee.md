# 소개뱅크 결정 정리 — 법률 · 세무 정액 노출료 · 세금계산서 · 분쟁 접수

- 기준일: 2026-10-15 (재조사판)
- 범위: 안심소개 법률 · 세무 사무소의 월 정액 노출(리드 없음) · 노출 조건 · 부가세 · 기간 연장 · 세금계산서 · 분쟁 접수
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 법률 · 세무는 상담 신청(리드)을 받지 않고 **월 정액 노출**만 — **300,000원 + 부가세 30,000원 = 월 330,000원**.
2. 노출 대상은 **자격 승인 + 상담 축 입점 승인**을 모두 받은 사무소, 노출은 **입금 확인 뒤** 켭니다.
3. 연장은 **A안(연장 신청 + 입금 확인)**, 금액은 **연장 신청 때의 기준 금액**, 입금 없이 종료일이 지나면 **자동 종료**.
4. 세금계산서는 **입금 확인 건마다 · 발행 주체 = 소개하는 자(운영 법인)**. 업체(ASP) 연동 전에는 **홈택스 직접 발행 → 승인번호 수동 입력**.
5. 분쟁 접수는 **모든 회원(개인 포함)**.
