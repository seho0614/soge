# 소개뱅크 결정 정리 — 디자인 기준(디자인 시트) · 디자인 통일

- 기준일: 2026-10-22
- 범위: 사용자 웹 · 시안의 디자인 값(색 · 글자 · 모서리 · 그림자 · 화면 폭 · 단추)의 기준과 통일 순서
- 상태: **유효** / **대체됨**

## 요약

1. **디자인 값의 기준은 디자인 시트(2026-10-09 「소개뱅크 전체 페이지 공통 디자인 가이드」) 하나** — 코드로는 `sgb/site/src/styles/sgb-tokens.css`.
2. 화면 구성 · 기능 · 문구는 지금처럼 **시안이 기준**(project-rules 2절에 단서로 추가).
3. 글꼴도 시트대로 **사이트 전체**(제목 페이퍼로지 · 본문 나눔스퀘어 네오) — 10/9 「소개장터에만」을 대체.
4. 주황 · 초록 관(소개장터 · 소개몰 · 소개광장)의 단추 글자는 **남색**(흰 글자는 대비 2.0 ~ 3.3 으로 읽기 어려움).
5. 6단계로 옮김 — v10.52 에서 1단계(기준 파일 하나로).
