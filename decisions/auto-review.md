# 소개뱅크 결정 정리 — 자동검수 · 금칙어

- 기준일: 2026-10-22
- 범위: 매물이 검수에 들어갈 때의 자동 판정(`fn_auto_review_reasons`) · 금칙어(`banned_words`) 검사 · 자동검수 정책 값
- 상태: **유효** / **대체됨**

## 요약

1. 판정 규칙은 **DB 함수 한 곳**에 있습니다 — 앱에 복제하지 않음(「왜 자동 승인됐는가」를 설명할 수 있게). 검수 화면 · 수정 화면도 같은 함수를 부릅니다.
2. 사람이 볼 이유가 하나도 없으면 자동 승인 · 노출, 그중 5% 는 표본 감사.
3. 2026-10-22 점검 7건을 v10.69 ~ v10.71 에서 모두 고침(sgb-core docs/125 ~ 127).
