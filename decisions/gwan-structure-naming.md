# 소개뱅크 결정 정리 — 관 구성 · 이름

- 기준일: 2026-10-15 (재조사판 — 프로젝트 기록 · 프로젝트 문서 · 킷 v10.41 · 지난 대화 대조)
- 범위: 관 구성과 이름, 헤더 메뉴, 업종 배치(보험 · 의료 · 태양광 · 리드), 안심소개 상담 신청 방식
- 상태: **유효** = 지금 기준 / **대체됨** = 뒤 결정으로 바뀜(→ 무엇으로) · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 관은 **소개장터 · 안심소개 · 소개창업 · 소개몰** 4개이고, 헤더 메뉴도 이 이름 · 이 순서입니다.
2. 이름 변경은 **표시 이름만** 바꿨습니다 — 관 코드와 주소(/money · /mall · /health)는 그대로입니다.
3. 쇼핑몰 관 이름은 9/26 「소개뱅크몰」 → **10/7 「소개몰」**(약관 글까지 고침).
4. 「소개리드(리드관)」는 **10/1 폐지**, 보험 · 의료 등은 안심소개에서 자격 확인 후 받습니다.
5. 안심소개 상담 신청은 **로그인 없이 휴대폰 확인 → 인증업체 1곳**, 신청자 이메일도 전달합니다.
6. 10/13 P2P 결정으로 모든 관이 본인인증 개인에게 열렸습니다(`p2p-individual-access.md`).
