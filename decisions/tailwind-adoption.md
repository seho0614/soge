- 기준일: 2026-10-15 (재조사판)
- 범위: 프런트 스타일을 Tailwind CSS 로 옮기는 범위 · 대상 · 방식 · 상태
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. Tailwind CSS 를 적용합니다 — **디자인 유지 · hero(메인) · 제휴영업 페이지 제외 · 나머지 전부** · 대상은 **시안 + 실제 웹**.
2. 10/2 에 실제로 만들었습니다(v11.1 · 킷 v10.13 바탕) — **기존 CSS 는 한 줄도 고치지 않고** 접두어 `tw:` 로 덧입히는 방식.
3. 그러나 **본선에는 아직 적용되지 않았습니다**(v10.29 「넣지 않음 — 확인 뒤」 · 10/11 상태 「미뤄 둔 것」).
4. 결정은 유효 — **v11.1 을 v10.41 위에 다시 적용할지**가 남은 핵심입니다.
