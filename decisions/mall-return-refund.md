# 소개뱅크 결정 정리 — 소개몰(옛 소개뱅크몰 · 건강관) 반품 · 교환 · 환불

- 기준일: 2026-10-15 (재조사판)
- 범위: 소개몰 직판 상품의 배송비 · 반품 · 교환 · 환불 · 재고 · 구매확정 · 판매 범위
- 이름: 9/26 「소개뱅크몰」 → 10/7 「소개몰」(`gwan-structure-naming.md`)
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. 배송비는 **전 상품 무료**(10/8). 회원 사정(단순 변심 · 잘못 주문) 반품은 **왕복 배송비 6,000원을 빼고 환불**.
2. 회원 사정 교환은 **교환 배송비 6,000원을 신청 때 온라인 결제** · 회사 사정이거나 반려면 돌려드림.
3. 교환할 상품이 없으면 **14일 입고 대기 뒤 반품**(원하면 바로 · 이때 전액 환불 + 교환 배송비 환급).
4. **개봉된 반품은 재고로 잡지 않음.**
5. 판매 범위 — 건강식품 · 화장품 열림 · 건강기능식품 잠금 · 의료기기 팔지 않음.
