# 소개뱅크 결정 정리 — 구독 · 소개코드

- 기준일: 2026-10-15 (재조사판)
- 범위: 요금제별 소개코드 건수 · 추가 발급 · 매물별 코드 · 귀속 · 소개 제안 한도 · 구독 주체
- 관련: 요청 열람 한도는 `business-entity-operating-policy.md`
- 상태: **유효** / **대체됨** · 이유 「기록 없음」 = 이유가 남아 있지 않음

## 요약

1. **BASIC(0원) 무료 소개코드는 0건**(10/10 「시안대로 정책까지」) — 필요하면 **건당 30,000원 결제 후 발급**.
2. 포함 건수는 **모든 등급이 월 단위**(매월 1일 지급 · 이월 없음) · 본인인증 전에는 무료분 없음.
3. 소개코드는 **매물별** — 그 매물의 거래에만 소개자가 붙습니다(운영 설정으로 「전체」 전환 가능).
4. 유료 요금제도 포함 건수를 넘으면 **결제 후 발급**.
5. 10/13 P2P 로 **개인도 구독 시작 · 원장 조회** 가능.
